## 摘要
大型语言模型（LLM）定义了文本上的分布，可视为不确定性的概率表示：采样K个响应会产生一个信念状态——模型认为合理的响应。现有工作将此表示用于解码或选择性预测等窄任务，且通常需要人工干预，无法直接控制生成。我们提出信念增强生成（BAG）：通过提示将LLM锚定在其自身的信念状态中，让模型对这些K个样本进行推理，以决定对话策略：回答、澄清或回避。在多轮模糊问答场景中，我们发现LLM默认很少澄清或回避，忽略了输入或事实的不确定性。BAG在六个模型上提高了问答准确率，并且与仅使用提示的基线相比，产生了更忠实于信念状态的策略决策。然而，区分何时澄清与何时回避仍然具有挑战性。

## Abstract
Large language models (LLMs) define a distribution over text, which can be viewed as a probabilistic representation of uncertainty: sampling K responses yields a belief state - responses a model deems plausible. Existing work exploits this representation for narrow tasks like either decoding or selective prediction, and often requires manual interventions, not controlling generation directly. We propose Belief-Augmented Generation (BAG): grounding LLMs in their own belief state via the prompt and letting them reason over these K samples to decide on a conversational strategy: answer, clarify, or abstain. In a multi-turn ambiguous QA setting, we find that LLMs by default rarely clarify or abstain, ignoring uncertainty about the input or facts. BAG improves QA accuracy across six models and yields strategy decisions more faithful to the belief state than prompt-only baselines. Disentangling when to clarify from when to abstain, however, remains challenging.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：大型语言模型（LLM）在对话中面对不确定性（如输入歧义、事实知识不足）时，默认直接回答，很少主动澄清或放弃回答，忽略了不确定性信息。
- **背景**：现有方法要么将信念状态（多次采样得到的响应集合）用于解码（如最小贝叶斯风险解码、自一致性），要么用于选择性预测（如语义不确定性检测），但均需人工干预，无法直接控制生成策略。此外，已有证据表明LLM不能忠实地反映其内在分布的不确定性。
- **动机**：利用LLM自身强大的文本推理能力（类似检索增强生成RAG中的证据推理），将信念状态以明文形式注入提示，让模型自主决定是直接回答、提出澄清问题还是放弃回答，从而提升对话质量。

## 2. 方法论：核心思想、关键技术细节

### 核心思想：Belief-Augmented Generation (BAG)
- 对给定输入x，从模型分布Pθ(Y|x)中采样K个响应（无偏采样，K=10），构成信念状态Bθ(x) = (Y^(1), …, Y^(K))。
- 将用户问题x和信念状态B一起放入新的Prompt中，让模型分析这些样本，并根据以下四种直觉选择策略：
  1. **直接回答（Direct Answer）**：样本之间事实一致，回答反映多数信念。
  2. **澄清（Clarification）**：样本对应问题的不同解释，需要用户澄清意图。
  3. **放弃（Abstain）**：样本因事实性矛盾而不可靠（类似幻觉），礼貌拒绝回答。
  4. **回答应代表整个信念状态**（类似最小贝叶斯风险）。

### 具体Prompt变体
- **BAG1**：最基础版本，关注候选答案一致性。
- **BAG2**：更详细指令，包含不确定性专用语言和最小贝叶斯风险直觉，区分放弃与澄清。
- **BAG3**：两步指令：先聚类样本，再推测每个聚类对应的问题解释，从而判断是歧义还是幻觉。
- **BAG+**：在澄清交互后（模型提问→模拟用户回答→模型再次采样），再次应用BAG决定最终回答或放弃。

### 算法流程
1. 用户提问（Turn 1）。
2. 模型采样K个响应构建信念状态。
3. 通过Prompt分析信念状态，选择并执行策略：直接回答、提出澄清问题、放弃。
4. 若提出澄清问题，模拟用户回答（使用Gemini-2.5-Flash扮演用户，基于真实意图给出保守回答）。
5. 可选项（BAG+）：基于三回合历史再次采样K个响应，再次决策回答或放弃。

## 3. 实验设计

### 数据集

- **用户意图**：每个消歧-答案对视为一个独立的用户意图。

### 对比方法
- **直接生成（Direct Generation）**：标准基线，不进行任何策略增强。
- **消歧上界（Disambiguation Oracle）**：给出消歧后的问题（若存在）或原问题，代表完全消除歧义下的最佳表现。
- **策略增强生成（SAG）**：仅通过提示（无信念状态）引导模型选择策略，作为消融基线。
- **BAG1/2/3**：三种信念增强提示变体。
- **BAG+ / SAG+**：在澄清交互后再次应用BAG或SAG。

### 评估指标
- **One Intent**：模型回答是否匹配随机选取的一个用户意图（严格）。
- **Any Intent**：模型回答是否匹配任意一个意图（宽松上界）。
- **策略路由质量**：分析不同策略子集上的基线准确率和歧义占比。
- **信念状态忠实度**：用语义熵（Semantic Entropy）量化信念状态的不确定性，检查策略选择与熵值是否一致。

## 6. 主要结论与发现

1. **默认策略不足**：六种LLM直接生成时极少澄清或放弃（仅约3%），倾向于直接回答，忽略不确定性和歧义。
2. **BAG提升准确率**：BAG+在one intent指标上显著优于直接生成和SAG+，甚至常超过消歧上界。
3. **策略贡献分解**：直接回答、澄清和放弃三个策略都对BAG的增益有正向贡献，但权重因模型而异。例如Qwen3主要靠放弃策略提升，Gemini三种策略相对均衡。
4. **忠实度更高**：BAG的策略选择与信念状态熵值更一致（低熵→直接回答，高熵→澄清/放弃），而仅提示的SAG则不匹配。
5. **澄清降低不确定性**：澄清交互后，信念状态熵值平均降低（Gemini降幅最大54%），但部分模型因知识不足无法利用澄清。
6. **区分澄清与放弃仍困难**：模型有时将幻觉变异误判为解释变异，提出不存在的歧义问题；澄清子集中仍包含大量非歧义问题，说明歧义检测本身极难。

## 7. 优点

- **方法新颖且实用**：首次将信念状态直接作为prompt一部分，让LLM自主推理生成策略，无需额外训练或外部数据，可适用于任何模型（包括闭源）。
- **设计巧妙**：利用采样多样性的不同来源（解释变异 vs 事实变异）区分澄清与放弃，并由模型通过指令自行判断。
- **实验严谨**：多模型、多prompt变体、多指标（准确率、策略路由、忠实度），并包含人工评估（97%判据一致率）。
- **对实际应用有启发**：可扩展至何时检索外部信息（RAG）、何时调用工具等更丰富策略；BAG+体现了多轮交互的潜力。
- **资源友好**：只需推理，无需微调，K=10采样可并行化，成本可接受。

## 8. 不足与局限

- **数据集局限**：仅在AmbigQA一个数据集上评估，测试集不公开；标注可能过时（Pletenev et al., 2025），歧义注释基于Wikipedia而非真实用户意图，且偏向美国中心。
- **信念状态质量受限**：信念状态反映模型认为合理的响应，不一定与外部世界一致（高一致性仍可能错误）。未来需提升信念状态质量。
- **区分澄清与放弃仍不完善**：模型常将幻觉解释为不存在的歧义，提出误导性澄清；且澄清子集中歧义占比仅51%-76%，反映歧义检测本身极难。
- **模拟用户交互**：使用Gemini-2.5-Flash模拟用户回答，虽然保守设计（约5%回答“I don't know”），但可能偏离真实用户行为（真实用户可能更合作）。
- **计算成本未详细分析**：未比较不同K值的影响，未讨论长上下文带来的推理开销。
- **策略种类有限**：仅实验了三种策略（回答、澄清、放弃），未涉及长格式回答、检索增强等更丰富策略。
