## 摘要
我们提出了连续分布式耦合策略梯度（CDCPG）算法，用于具有连续状态和动作空间的网络化马尔可夫决策过程中的协作强化学习。每个智能体在有界图邻域内维护一个局部actor，局部最小二乘时序差分critic通过局部转移核的谱随机特征表示来评估截断的动作值函数。该分析有四个贡献。首先，截断的动作值函数被构造为邻域上的条件期望，从而产生一个适定的局部Bellman理论，消除了朴素截断论证中的延续核不匹配问题。其次，我们揭示了归一化随机特征在时序差分稳定性方面的维度障碍，并证明了一个无条件的激励界，该界将稳定性简化为一种对称的持续激励条件，可通过在线矩阵集中证书进行监控。第三，在智能体交互的指数空间衰减、激励条件以及目标平滑性下，CDCPG使用$\widetilde{\mathcal{O}}(ε^{-2})$个共享oracle样本，将每个智能体的平均驻点度量驱动到显式表征的近似底座的任意超出$ε$范围内，并且超出量的依赖性与光滑非凸一阶速率相匹配；每个智能体的计算和通信由邻域大小而非网络大小决定。第四，自适应局部性规则选择平衡截断和图形衰减残差与目标精度的半径。在网络化线性二次基准上的实验证实了局部性和特征维度的预测。

## Abstract
We develop the Continuous Distributed Coupled Policy Gradient (CDCPG) algorithm for cooperative reinforcement learning in networked Markov decision processes with continuous state and action spaces. Each agent maintains a local actor over a bounded graph neighborhood, and a localized least-squares temporal-difference critic evaluates a truncated action-value function through a spectral random-feature representation of the local transition kernel. The analysis makes four contributions. First, the truncated action-value function is constructed as a conditional expectation over the neighborhood, yielding a well-posed localized Bellman theory that removes the continuation-kernel mismatch of naive truncation arguments. Second, we expose a dimensional obstruction to temporal-difference stability for normalized random features and prove an unconditional excitation bound that reduces stability to a symmetric persistence-of-excitation condition, monitorable through an online matrix-concentration certificate. Third, under exponential spatial decay of agent interactions, the excitation condition, and smoothness of the objective, CDCPG drives an averaged per-agent stationarity measure to within any excess $ε$ of an explicitly characterized approximation floor using $\widetilde{\mathcal{O}}(ε^{-2})$ shared-oracle samples, and the excess dependence matches the smooth nonconvex first-order rate; per-agent computation and communication are governed by the neighborhood size rather than the network size. Fourth, an adaptive-locality rule selects the radius that balances truncation and graph-decay residuals against the target accuracy. Experiments on a networked linear-quadratic benchmark corroborate the locality and feature-dimension predictions.

### 2. 论文提出的方法论

#### 核心思想

- **局部化原则**：每个智能体在固定半径 κ 的图邻域内维护局部 actor 与 critic，利用指数空间衰减（B2 假设）截断长程依赖，使计算和通信开销由邻域大小 \(D_\kappa\) 而非网络大小 n 决定。
- **条件期望截断**：定义截断动作值函数  
  \(\bar{Q}^\pi_i(x) = \mathbb{E}_{\nu^\pi}[Q^\pi_i(S,A) \mid X^\kappa_i = x]\)，  
  其中 \(X^\kappa_i\) 为局部状态-动作窗口。这避免了朴素截断的延续核不匹配，通过辅助局部 Bellman 算子 \(\bar{T}^\pi\)（γ-压缩）得到适定的局部不动点。
- **谱随机特征（RFF）**：利用高斯转移核的平移不变性，通过 Bochner 分解构造归一化随机特征 \(\hat{\phi}_{i,\kappa}, \hat{\mu}_{i,\kappa}\)，获得全局 L1 核近似定理（Theorem 1），近似精度为 \(O(\sqrt{\tilde{g}_\alpha^2 D_\kappa d_S / m})\)。
- **TD 稳定性假设**：
  - 均匀版本（Assumption 4）：TD 矩阵 \(M^\theta_i = H^\theta_i - \gamma C^\theta_i\) 的最小奇异值满足 \(\sigma_{\min}(M^\theta_i) \ge \mu_M(m)>0\)，概率 \(\ge 1-\delta_M(m)\)。
  - 提出**维度障碍**（Proposition 2）：\(\sigma_{\min}(M^\theta_i) \le (1+\gamma)L^2/\sqrt{m+1}\to 0\)，因此不存在与特征维度无关的稳定性下界。
  - 通过折扣占用恒等式**导出无条件激励界**（Lemma 3）：\(\sigma_{\min}(M^\theta_i) \ge (1-\sqrt{\gamma})\lambda_{\min}(H^\theta_i)\)，将 TD 稳定性简化为对称特征协方差 \(H^\theta_i\) 的持续激励条件。
  - 轨迹条件版本（Assumption 5）与矩阵-Bernstein 诊断（Proposition 3）提供事后证书，控制虚假认证概率。

- **算法流程（CDCPG）**：
  1. 预处理：为每个智能体独立采样 m 个随机特征对。
  2. 每轮迭代：共享数据集 \(D_s^{(k)}\)（用于 LSTD）和 \(D_g^{(k)}\)（用于梯度估计）。
  3. 各智能体并行：构造 LSTD 矩阵 \(M_i^{(k)}\) 和右端项 \(b_i^{(k)}\)，求解正则化 LSTD 解 \(\hat{w}_i^{(k),\mathrm{raw}}\)，并将系数投影到半径 \(W^*\) 内。
  4. 定义线性 critic：\(\hat{Q}_i^{(k)}(z) = \tilde{\phi}_{i,\kappa}^{\mathrm{raw}}(z)^\top \hat{w}_i^{(k)}\)。
  5. 聚合 κc 邻域内 critic 值形成梯度估计 \(\hat{g}_i^{(k)}\)。
  6. 执行投影梯度更新：\(\theta_i^{(k+1)} = \Pi_{\Theta_{0,i}}(\theta_i^{(k)} + \eta \hat{g}_i^{(k)})\)。

- **核心理论结果**：
  - Theorem 6：在均匀 TD 稳定性假设下，采用共享 oracle，达到平均每智能体投影梯度映射驻点性 \(n^{-1}\|\bar{G}_\eta\|^2 \le \epsilon + \epsilon_{\mathrm{floor}}(\kappa,m)\)，总 oracle 样本数 \(\widetilde{\mathcal{O}}(\epsilon^{-2})\)。
  - 结构底座 \(\epsilon_{\mathrm{floor}}\) 包含四项：bin 内波动、截断残差、RFF 残差、图衰减聚合残差。
  - Theorem 7：轨迹条件版本，通过可预测事件分解和停时过程得到“前缀加权”不等式，隐含全局有利事件界。
  - 自适应局部性诊断（Proposition 4）选择半径 \(\kappa^*\) 使截断与图衰减残差低于目标精度。

### 6. 论文的主要结论与发现

- CDCPG 在 LCQ 上以 κ=1 的邻域 critic 配合 κπ=0 的局部 actor，达到与集中式基线几乎相同的性能（差距 0.55% 以内），显著优于 IPG、MAAC、Networked AC。
- 收敛速度更快：CDCPG 13 轮达到 90% 参考改进，Centralized 需 25 轮，局部基线需 55–133 轮。
- 随机特征维度 m 增加时，相对 Q 误差以约 \(1/\sqrt{m}\) 的速率下降（拟合斜率 −0.46），与 Theorem 1 的 RFF 核近似理论相容。
- 奖励协方差随图距离几何衰减，速率 \(\hat{\rho}=0.86\)，满足固定局部性复杂度成立的图尾条件（\(\tilde{\delta}=0.86<1\)）。
- κ 消融显示截断半径增大单调提升性能，连续跳比率约 0.5，与指数衰减预期一致；λ 在小值区间平坦，λ=1 破坏性能，符合非对称 TD 矩阵正则化分析的定性预测。
- 核心理论结论：在共享生成模型和结构性假设下，CDCPG 以 \(\widetilde{\mathcal{O}}(\epsilon^{-2})\) 样本达到“到结构底座”的驻点性，计算/通信仅依赖邻域大小；特征维度 m 是问题原语而非可调精度参数，且存在维度相关的稳定性下界不可能性。
