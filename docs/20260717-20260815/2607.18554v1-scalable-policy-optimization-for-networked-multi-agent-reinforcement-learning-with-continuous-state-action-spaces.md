## 摘要
我们提出了连续分布式耦合策略梯度（CDCPG）算法，用于具有连续状态和动作空间的网络化马尔可夫决策过程中的协作强化学习。每个智能体在有界图邻域上维护一个局部执行器，而局部最小二乘时序差分评价器通过局部转移核的谱随机特征表示来评估截断动作值函数。本文的分析有四个贡献。第一，截断动作值函数被构造为邻域上的条件期望，从而产生了一个适定的局部贝尔曼理论，消除了朴素截断论证中的续核失配问题。第二，我们揭示了归一化随机特征在时序差分稳定性方面的维度障碍，并证明了一个无条件的激励界，该界将稳定性简化为对称的持续激励条件，可通过在线矩阵集中证书进行监控。第三，在智能体交互的指数空间衰减、激励条件以及目标平滑性下，CDCPG 使用 (O͂(ε^{-2})) 次共享预言机样本，将平均每智能体平稳性度量驱动到显式表征的近似下限的任意超出量 ε 之内，且该超出量的依赖关系与平滑非凸一阶速率相匹配；每个智能体的计算和通信由邻域大小而非网络大小决定。第四，自适应邻域规则选择平衡截断残差和图衰减残差与目标精度的半径。在网络化线性二次基准上的实验证实了邻域性和特征维度的预测。

## Abstract
We develop the Continuous Distributed Coupled Policy Gradient (CDCPG) algorithm for cooperative reinforcement learning in networked Markov decision processes with continuous state and action spaces. Each agent maintains a local actor over a bounded graph neighborhood, and a localized least-squares temporal-difference critic evaluates a truncated action-value function through a spectral random-feature representation of the local transition kernel. The analysis makes four contributions. First, the truncated action-value function is constructed as a conditional expectation over the neighborhood, yielding a well-posed localized Bellman theory that removes the continuation-kernel mismatch of naive truncation arguments. Second, we expose a dimensional obstruction to temporal-difference stability for normalized random features and prove an unconditional excitation bound that reduces stability to a symmetric persistence-of-excitation condition, monitorable through an online matrix-concentration certificate. Third, under exponential spatial decay of agent interactions, the excitation condition, and smoothness of the objective, CDCPG drives an averaged per-agent stationarity measure to within any excess $ε$ of an explicitly characterized approximation floor using $\widetilde{\mathcal{O}}(ε^{-2})$ shared-oracle samples, and the excess dependence matches the smooth nonconvex first-order rate; per-agent computation and communication are governed by the neighborhood size rather than the network size. Fourth, an adaptive-locality rule selects the radius that balances truncation and graph-decay residuals against the target accuracy. Experiments on a networked linear-quadratic benchmark corroborate the locality and feature-dimension predictions.

## 一、论文的核心问题与整体含义（研究动机和背景）

- **研究对象**：网络化多智能体强化学习（MARL）中的连续状态-动作空间问题。在该类系统中，每个智能体的动力学、奖励和观测仅受附近邻居影响，而非均匀地受所有智能体影响。
- **核心挑战**：联合状态-动作空间随智能体数量 n 呈指数增长，集中式方法难以扩展；纯分散式方法又难以实现协调。局部化方法作为原则性的中间方案，利用网络的空间结构实现可扩展性。
- **关键障碍**：现有可扩展网络化 MARL 方法（如 Qu 等人[3]–[5]）主要针对离散状态-动作空间。将衰减驱动框架扩展至连续域时存在多个非平凡困难：截断与核逼近误差相互作用、策略评估需要条件良好的设计矩阵的函数逼近、TD 稳定性缺乏可监控的显式条件等。
- **论文目标**：提出 CDCPG 算法，在连续状态-动作空间中实现每个智能体的计算和通信开销仅由局部邻域大小（而非网络规模）决定的可扩展强化学习，同时提供显式的有限样本复杂度保证。

## 二、论文提出的方法论

### 1. 核心思路

CDCPG 算法采用**局部 actor + 局部 critic** 的结构：
- 每个智能体 i 在 κ 跳邻域内维护局部策略；
- 通过谱随机特征（RFF）表示局部转移核，由局部 LSTD（最小二乘时序差分）critic 评估截断的动作值函数；
- 梯度估计聚合邻域内多个 critic 的信息，实现局部化信用分配。

### 2. 关键技术细节

- **条件期望截断**：将截断 Q 函数定义为局部邻域条件期望，避免朴素截断产生的延续核失配问题，得到适定的局部 Bellman 理论（Proposition 1）。
- **频谱随机特征表示**：利用局部转移核的平移不变性，通过 Bochner 分解构造归一化随机特征（Definition 1），并对 RFF 逼近误差给出全局 L1 控制（Theorem 1）。
- **TD 稳定性假设**：揭示了随机特征 TD 矩阵的维度障碍（Proposition 2：不存在与维度无关的稳定性下界），并提出特征维度感知的 TD 稳定性假设（Assumption 4）。Lemma 3 证明无条件激励界：σ_min(M) ≥ (1−√γ) λ_min (H)，将 TD 稳定性简化为对称协方差的持续激励条件。
- **轨迹条件版本**（Assumption 5）：提供矩阵-Bernstein 诊断（Proposition 3），以受控的误认证概率监控已执行轨迹上的 TD 稳定性。
- **正则化 LSTD**：采用带范数投影的岭正则化 LSTD 求解局部 critic 权重（Definition 4, Algorithm 1）；分析中论证了在非对称 M 下 λI 不应视为正定岭，取 λ* = 0 最优（Remark 1）。
- **分布式策略梯度**：基于策略梯度定理构造局部梯度估计器（公式 37），聚合邻域内 critic 信息；在 κπ = 0 时利用塔性质实现原始/条件特征涨落的精确抵消（Corollary 2）。
- **自适应邻域诊断**（Proposition 4）：给出在选择临界半径 κ* 的规则，使截断和图衰减残差降至目标精度以下，属偏置平衡诊断而非速率改进。

### 3. 核心算法流程（文字说明）

Algorithm 1（CDCPG with projected updates）：
1. 预处理：为每个智能体独立采样随机特征参数（频率和相位）；
2. 每轮迭代 k：共享采样数据集 D_s（LSTD 用）和 D_g（梯度用）；
3. 各智能体并行：计算 LSTD 矩阵 M 和目标向量 b，求解带阈值判断的岭正则化 LSTD 得到原始权重，经范数投影得到最终 critic 权重；
4. 构建线性 critic（不加值裁剪），收集邻域内 critic 权重；
5. 计算局部梯度估计，进行投影梯度更新。

## 六、论文的主要结论与发现

1. **条件期望截断**解决了连续域中局部 Bellman 截断的适定性问题，消除了延续核失配。
2. **维度障碍**表明 TD 稳定性的维度无关下界不可能存在，须以固定 m 为问题原始量进行分析；激励条件（对称特征激发）将稳定性假设简化为可监控的持续激励条件。
3. **样本复杂度**：在指数空间衰减、激励条件和目标平滑性下，CDCPG 以 Õ(ε⁻²) 次共享预言机调用达到超出显式结构下限的 ε 精度——与平滑非凸一阶速率的指数一致；单智能体计算和通信由邻域大小而非网络规模决定。
4. **结构下限**：显式刻画了四分量结构下限（within-bin、截断、RFF、图衰减），并揭示通用包络下认证的 within-bin 惩罚随 m 至少线性增长（属上界分析产物，非真实算法误差下界）。
5. **自适应邻域诊断**可选择平衡截断与图衰减残差的半径，但非速率改进。
6. **实验验证**：CDCPG 在 LCQ 上以 κ = 1 邻域 critic 匹配集中式全信息基线的性能（差距约 0.11 个百分点），优于局部策略基线；m 扫描的拟合斜率 −0.46 与 Õ(1/√m) 理论趋势兼容；λ 扫描在 λ ≥ 1 时性能崩溃，与正则化偏置分析和侧条件规模一致。
