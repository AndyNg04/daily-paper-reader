## 摘要
卷积神经网络（CNN）能高效捕获局部特征，但由于其有限的感受野，难以处理全局上下文。另一方面，变换器通过自注意力有效捕获全局依赖，但存在高冗余和高计算成本的问题。因此，为兼具CNN和变换器的优势，我们提出了一种统一模型（UniCon-Former），旨在为动态手势识别提供稳健且高效的表现。这种统一方法有助于模型同时学习局部和全局特征。在每个变换器阶段的开始，卷积投影有助于降低变换器块输入向量的维度。这就在每个变换器阶段形成了金字塔结构。这些特性使UniCon-Former比普通变换器更能减少资源消耗，使其能够灵活学习多尺度和高分辨率特征，而这正是手势识别所需的。我们使用NVGesture和Briareo数据集进行了实验，并以更少的参数和MACs取得了最先进的结果。

## Abstract
Convolutional Neural Networks (CNNs) capture local features efficiently but struggle with global context due to their limited receptive field. On the other hand, transformers effectively capture global dependencies through self-attention but suffer from high redundancy and computational costs. Thus, to leverage the advantages of both CNNs and transformers, we propose a unified model (UniCon-Former) that aims to provide robust and efficient performance on dynamic hand gesture recognition. The unified approach helps the model to learn both local and global features. At the beginning of each transformer stage, the convolution projections help in decreasing the dimension of the input vectors of the transformer block. This creates a pyramidal structure at each transformer stage. These features enable the UniCon-Former to reduce resource usage than vanilla transformers, making it flexible for learning multi-scale and high-resolution features, which is required in hand gesture recognition. We have performed experiments with NVGesture and Briareo datasets and achieved state-of-the-art results with fewer parameters and MACs.

  - **CNN**：能够高效提取局部特征（如边缘、纹理），但由于感受野有限，难以建模全局上下文依赖。
  - **Transformer**：通过自注意力机制能够有效学习全局依赖关系，但存在**高计算冗余**（对所有 token 进行盲目的相似度比较）和**计算成本高**的问题。
- **核心问题**：如何设计一个既能高效提取局部特征、又能充分建模全局上下文，同时保持较低计算复杂度的动态手势识别模型？
- **整体思路**：提出一种**统一卷积变换器（UniCon-Former）**，在 Transformer 每个阶段前引入卷积投影，构建金字塔结构，以融合 CNN 与 Transformer 的优势，同时降低资源消耗。

## 2. 论文提出的方法论

### 2.1 核心思想
- 在每个 Transformer 阶段开始时，使用**卷积投影**对输入向量进行降维，形成**金字塔结构**。
- 这一设计使得模型能够在不同阶段学习**多尺度、高分辨率特征**，适应手势形状和大小变化。
- 相比普通 Transformer，资源占用更低，同时具备 CNN 的局部建模能力和 Transformer 的全局建模能力。

### 2.2 模型整体流程
1. **特征提取**：输入手势视频序列，使用预训练的 **ResNet-18** 提取帧级特征，得到维度为 `N = B × T × D` 的特征（B 为批大小，T 为帧数，D = 512）。将 B×T 记为 L，则特征表示为 `L × D`。
2. **位置编码**：按照传统 Transformer 方式加入位置嵌入，然后将特征作为 Q、K、V 输入到 UniCon-Former。
3. **卷积块（C-Block）**：Q、K、V 三个向量均先经过 C-Block。C-Block 为**深度可分离卷积**，包含：
   - Depthwise Conv（3×3）
   - BatchNorm2d
   - Point-wise Conv2d（1×1）
   - 公式表示为：`Q = Conv(F)`
4. **多头注意力（MHA）**：在 C-Block 输出上添加类令牌（class token），送入多头注意力模块。
5. **前馈与残差**：注意力输出依次经过两个线性层（FC），前后使用 dropout（0.1），并添加跳跃连接和层归一化。编码器输出为：
   - `E(x) = Norm(x + FC(MultiHead(Q, K, V)))`
6. **分类**：对编码结果进行**平均池化**（`H(x) = AvgPool(E(x))`），再通过线性分类器得到概率分布。

### 2.3 多模态晚期融合
- 采用与 [7] 类似的**晚期融合**策略：各模态独立训练模型，测试时对不同模态的预测概率求和，选择最大概率对应的类别。
- 融合公式：
  - `y = arg max_j Σ_i P(ω_j | x_i)`
  - 其中 n 为模态数，P(ω_j|x_i) 为第 i 帧输入属于类别 ω_j 的概率。
