## 摘要
自然语言用户偏好为个性化大语言模型提供了可解释的接口。然而，通用偏好摘要常常包含与特定下游任务无关的信息。直接提供完整偏好摘要会浪费上下文容量并引入跨任务干扰，而手动设计任务特定的偏好视图则难以扩展。在本工作中，我们研究\emph{任务特定偏好适应}：给定通用用户偏好摘要和下游任务，推导出一种任务条件化表示，在去除冗余上下文的同时保留足够的决策相关证据。为此，我们提出\textsc{AlignXada}，一种无需训练的元学习框架，通过诱导可复用的文本精炼策略，将通用偏好摘要适应为任务特定摘要。该精炼策略由元学习器通过语言强化学习迭代优化。在13个任务和三个下游模型（共39个任务-模型组合）上，\textsc{AlignXada}平均提升3.82分，改善了33个组合，同时仅保留原始画像令牌的22.8\%，并在36个组合上优于RAG。进一步的扩展忠实度分析表明，精炼后的画像在很大程度上仍基于源偏好，同时保留了任务相关的个性化信号，这表明画像侧的适应可以作为通用记忆构建在终身个性化智能体中的实用补充。

## Abstract
Natural language user preferences provide an interpretable interface for LLM personalization. However, universal preference summaries often contain information irrelevant to a particular downstream task. Directly supplying the full preference summary therefore wastes context capacity and introduces cross-task distraction, while manually designing task-specific preference views is difficult to scale. In this work, we study \emph{task-specific preference adaptation}: given a universal user preference summary and a downstream task, derive a task-conditioned representation that preserves sufficient decision-relevant evidence while removing redundant context. To this end, we propose \textsc{AlignXada}, a training-free meta-learning framework that induces reusable textual refinement policies for adapting universal preference summaries to task-specific ones. The refinement policy is iteratively optimized by a meta learner through verbal reinforcement learning. Across 13 tasks and three downstream models (39 task--model cells), \textsc{AlignXada} achieves an average gain of 3.82 points, improving 33 cells while retaining only 22.8\% of the original profile tokens and outperforming RAG in 36 cells. An extended faithfulness analysis further shows that the refined profiles remain largely grounded in the source preferences while preserving task-relevant personalization signals, suggesting that profile-side adaptation serves as a practical complement to universal memory construction for lifelong personalized agents.

## 二、论文提出的方法论

- **核心思想**：提出 **AlignXada**，一种**无需训练（training-free）的元学习框架**，通过归纳可复用的自然语言“文本精炼策略”（refinement policy），将通用偏好摘要改写为任务特定画像。策略由元学习器通过**语言强化学习（Verbal Reinforcement Learning）**迭代优化。
- **关键设计——策略与执行解耦**：元学习器负责生成策略文本，一个冻结的精炼器（refiner）负责执行策略改写画像，下游模型消费改写后的画像进行推理。所有模型均保持冻结，仅策略文本在归纳过程中被更新。这使适应过程透明、可控，支持人类介入诊断与修正，并天然兼容开源与闭源模型。
- **问题形式化**：给定用户通用偏好摘要 $P_u$ 和任务 $\tau$，目标是学习任务特定的文本策略 $\phi^{(\tau)}$，使精炼画像 $\tilde{P}_u = R(P_u, \phi^{(\tau)})$ 能最大化下游模型 $M$ 在支持集 $S^{(\tau)} = \{(P_{u_i}, x_i, y_i)\}_{i=1}^{b}$ 上的任务分数 $\text{Score}_\tau(M(x_i, \tilde{P}_{u_i}), y_i)$。
- **算法流程（双阶段）**：
  1. **少样本策略归纳（Few-shot Policy Induction）**：
     - **Rollout（展开）**：对当前策略 $\phi_t$，在支持集每个示例上应用精炼器 $R$ 改写画像，查询下游模型 $M$ 生成预测，并用任务特定评估函数计算分数，记录完整的 rollout 记录 $\mathcal{R}_t$。
     - **Update（更新）**：将 rollout 记录聚合为结构化文本反馈 $E_t$（含平均分、实例级预测和分数、代表性失败模式等），元学习器 $\pi_{\text{meta}}$ 依据反馈修订策略，生成 $\phi_{t+1}$。更新提示要求遵循预定义策略模式、做针对性修订、避免记忆支持实例的具体规则。
     - **策略选择**：在开发集上评估每个候选策略，经过 $T$ 轮迭代后返回开发集性能最高的策略 $\phi^{(\tau)}$。
  2. **策略部署（Policy Deployment）**：冻结最终策略，对任意新用户的通用画像执行改写，供下游模型做个性化推理。
- **自适应诊断采样（Adaptive Sampling）**：将候选示例按四种转移状态——improved（原始错/精炼对）、regressed（原始对/精炼错）、stable-success（均对）、persistent-failure（均错）——分层均匀分配反馈预算，为元学习器提供既含纠错信号又含稳定化信号的全面反馈。

## 六、主要结论与发现

- **主实验**：在 39 个任务-模型组合上，AlignXada 提升 33 个，平均提升 **+3.82 分**；仅保留原画像 **22.8%** 的 token。三个下游模型分别提升 Qwen3-8B +2.27、DeepSeek-V4-Flash +7.00、GPT-5-mini +2.19。
- **对比 RAG**：AlignXada 在 36 个 cells 严格优于 RAG、1 个持平、仅 2 个落后，平均优势 **+7.28 分**；RAG 平均反而让 raw 基线降低 3.46 分，说明任务导向的偏好重组优于查询级检索。
- **压缩与收益解耦**：性能增益与 token ratio 几乎不相关（$r=0.06$），表明收益来自保留证据效用的提高而非依赖更长画像。
- **异构性结论**：最优偏好表示既依赖任务也依赖下游模型——同一任务上不同模型的增益方向可能反转（如 Professional Email 在 Qwen3-8B 为 −1.50、DeepSeek-V4-Flash 为 +12.50），且所有回归均小于 1.58 分，最大增益达 +14.77 分。
- **源基准有效性**：在更干净的 PersonaMem-v2 上平均提升 +1.30（9 项任务中 7 项改善），在 MemoryCD 上 +1.69（4 项全改善），说明收益不局限于跨域噪声移除。
- **超参分析**：$b=20$ 时平均增益 +2.58 且压缩率最好（20.5%）；12/13 的策略在 5 轮内收敛，额外轮数主要使困难的评分预测任务受益。
- **忠实度审计**：97.5% 的细化画像声明被源画像支持、97.9% 无幻觉、99.8% 无矛盾；条件于源画像包含金标证据时，83.3% 被精炼画像保留，关键遗漏率 15.3%。源画像本身仅有 34.0% 的金标偏好证据覆盖率，说明主要瓶颈在于上游画像的证据完备性而非精炼器的忠实度。

- **对比基线的覆盖范围有限**：RAG 基线仅采用 BM25 词法检索 + 固定 768 token 预算，未与更先进的密集向量检索、混合检索或“摘要重排序”类方法对比；因此只能证明“优于该具体检索实现”，尚不能断言任务导向精炼在检索范式上的普适优势。
- **对强元学习器的隐性依赖**：默认元学习器与精炼器均为 Gemini-2.5-Pro，跨元模型实验仅验证了 DeepSeek-V4-Flash 的可行性；较弱或较小的开源模型能否产出同等质量的策略文本与改写结果尚未得到系统验证，框架的“低门槛”主张需更充分的弱模型证据支撑。
- **语言与多语言场景未验证**：所有实验均基于英文偏好画像与英文任务；偏好表述的改写策略在不同语言、文化语境或多语混合画像上的迁移性尚无实验证据，限制了其在全球范围真实代理中的适用性论断。
- **隐私与安全考量不足**：通用画像本身包含大量个人敏感信息，将其交由外部元学习器聚合反馈、生成候选策略并反复调用闭源模型，会引入数据出境与隐私泄露风险；论文未讨论差分隐私、本地化推理或脱敏技术在此流程中的适配方案。

## 九、改进方向与展望

- **支持集构建的智能化**：将当前“随机/预算受限”的支持集采样升级为基于多样性、难度与任务熵的主动选择，并研究支持集偏差对策略泛化的量化影响，以提升策略在低资源场景下的鲁棒性。
- **策略先验与元知识库**：在历史任务-模型组合上积累策略文本，构建“策略先验库”，使新任务可通过少样本检索或元提示初始化策略，从而减少归纳轮数并缓解符号反转的不稳定性。
- **扩展对比与消融纵深**：引入向量检索、混合检索、动态摘要重写（query-aware summarization）等更强基线；同时增加对弱元学习器（如 Qwen3-8B 担任 meta/refiner）、多语言（中、德、日等）与多偏好源（用户手动标注、隐式反馈推断）的系统测试。
- **忠实度与证据完备性的协同优化**：既然上游画像自身的金标证据覆盖率仅 34.0%，未来工作可把“证据补全”（如从原始交互记录中检索缺失偏好）与“证据精炼”联合建模，从根本上突破当前“改写信息不高于输入信息”的天花板。
- **隐私友好的部署形态**：探索策略归纳在本地方执行的可行路径（如小参数元学习器 + 安全聚合），或在反馈传递前对用户身份与敏感条目做脱敏，使框架在隐私敏感场景中可落地。

## 十、总结

AlignXada 以“任务特定偏好适应”为核心问题，用一套无需训练的元学习框架将通用偏好摘要压缩并重组为任务条件化画像，在 13 个任务 × 3 个异构模型上取得了平均 +3.82 分、仅保留 22.8% token 的显著成果，并通过忠实度审计确认了收益的真实来源是“证据效用的重组”而非“更长上下文”。其策略与执行解耦的设计兼具可解释性、可控性与跨模型兼容性，为终身个性化代理的画像侧适配提供了实用范本。与此同时，评估环境偏理想化、支持集代表性假设、任务-模型增益的不稳定性以及对强元学习器的依赖，构成了其向真实生产环境迁移的主要障碍。总体而言，这是一项问题清晰、方法简洁、实验充分、论证扎实的研究，其价值不仅在于性能提升，更在于为“如何将通用记忆转化为任务可用表示”这一通用性问题开辟了以自然语言策略为载体的新路径。
