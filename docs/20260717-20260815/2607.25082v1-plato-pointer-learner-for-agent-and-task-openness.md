## 摘要
开放智能体系统（OASYS）在现实世界领域中日益普遍，其中智能体集合与任务集合随时间不可预测地变化。这种开放性，包括智能体开放性（AO）和任务开放性（TO），对多智能体强化学习（MARL）构成了根本性挑战，因为后者通常假设固定的状态和动作空间。现有方法只能部分解决开放性问题：填充和掩码方法引入了人为边界，而最近的基于图或超图的方法处理了单一维度的开放性，但仍依赖限制性假设。在本文中，我们提出了面向智能体与任务开放性的指针学习器（PLATO），它结合了基于指针网络的演员网络与集中式图神经网络（GNN）评论家网络，并在集中训练与分散执行的范式下使用多智能体近端策略优化进行训练。我们的基于指针的演员网络直接在当前任务集合上输出分布。这直接支持变化的动作空间，无需掩码或重新训练。我们的GNN评论家网络将智能体-任务交互编码为随任务和智能体组成而改变形状的图。这些组件共同考虑了AO和TO，且没有现有方法的边界限制。我们在任务与智能体开放马尔可夫博弈（TaAgO-MG）中形式化PLATO，扩展了先前的任务开放公式，并证明它在由此产生的无界状态和动作空间上是良定义的。我们使用开放智能体系统评估方法倡议（MOASEI）的野火抑制领域评估PLATO，该环境专为开放式多智能体系统评估而设计，我们证明了强性能以及在OASYS中比最先进的基线更一致的零样本泛化能力。

## Abstract
Open agent systems (OASYS) are increasingly prevalent in real-world domains where the sets of agents and tasks change unpredictably over time. Such openness, including agent openness (AO) and task openness (TO), poses a fundamental challenge to multi-agent reinforcement learning (MARL), which typically assumes fixed state and action spaces. Existing methods address openness only partially: padding and masking approaches introduce artificial bounds, while recent graph-based or hypergraph methods handle one dimension of openness but still depend on restrictive assumptions. In this paper, we introduce Pointer Learner for Agent and Task Openness (PLATO), a pointer-network-based actor combined with a centralized graph neural network (GNN) critic, trained with multi-agent proximal policy optimization under a centralized training and decentralized execution paradigm. Our pointer-based actor outputs distributions directly over the current task set. This directly supports changing action spaces without masking or retraining. Our GNN critic encodes agent-task interactions as a graph that changes shape with task and agent composition. Together, these components consider AO and TO without the boundedness of existing approaches. We formalize PLATO in a Task-and-Agent-Open Markov Game (TaAgO-MG), extending prior task-open formulations, and prove it is well-defined over the resulting unbounded state and action spaces. We evaluate PLATO with the Methods for Open Agent Systems Evaluation Initiative (MOASEI) wildfire suppression domain, an environment designed for open multi-agent system evaluation, and we demonstrate strong performance and more consistent zero-shot generalization than state-of-the-art baselines in OASYS.

### 一、核心问题与整体含义（研究动机与背景）

*   **现实背景**：在真实世界的多智能体系统（MAS）中，智能体集合与任务集合往往不是固定不变的。智能体可能中途加入或离开（例如消防员耗尽灭火剂后退出补充），任务也可能随机涌现或消失（例如火灾在任意位置点燃或扑灭）。这种动态变化被称为“开放性”（Openness）。
*   **核心挑战**：传统多智能体强化学习（MARL）方法**假设固定的状态空间和动作空间**，因此在开放系统中无法直接应用。当智能体或任务数量变化时，策略需要重新定义或重新训练，这严重制约了系统的鲁棒性和可部署性。
*   **现有方法不足**：
    *   **Padding与Masking**：人为设定最大数量上限，引入人为边界，无法处理超出上限的情况。
    *   **图/超图方法**：DGN（图卷积强化学习）可处理变化邻居，但假定固定动作集，不处理任务开放；DICG（深度隐式协调图）灵活但操作于有界和填充输入；MOHITO（超图actor-critic）明确处理任务开放（TO），但**未处理随机智能体开放（AO）**，且依赖假设固定的智能体集。
*   **本文目标**：同时处理智能体开放性（AO）与任务开放性（TO），使策略在**无界的智能体与任务空间中良定义**，无需重新训练或人为边界。

### 二、方法论：核心思想、关键技术细节与算法流程

**1. 核心思想**

*   将动作选择从“固定索引分类”重构为**基于内容的指向（Content-based Pointing）**：每个智能体（agent）形成上下文向量（Query），通过注意力机制与当前可用任务特征（Key）匹配，直接在**当前任务集合**上输出行动分布。
*   采用**CTDE（集中训练与分散执行）**范式，训练时可使用全局信息，执行时仅依赖局部观测。

**2. 关键技术组件**

*   **TaAgO-MG 形式化**（Task-and-Agent-Open Markov Game）：
    *   扩展 TaO-MG，将智能体集 `N` 与任务集 `X` 均作为随时间变化的集合。
    *   定义生成函数 `Ψ`，负责更新状态、动作空间、转移函数与奖励函数，以适配任务和智能体的任意变化。
*   **指针演员网络（Pointer Actor）**：
    *   **观测分解（Preprocessor）**：将局部观测分解为智能体特征矩阵 `O^t_N` 和任务特征矩阵 `O^t_X`。
    *   **编码器（Encoder）**：
        *   **智能体编码（处理AO）**：对智能体特征矩阵取四种统计量（均值、方差、最小值、最大值），生成固定长度向量 `d^t`，再经 MLP 生成单一查询向量 `q^t`。该操作具有置换不变性（Lemma 1）。
        *   **任务编码（处理TO）**：对每个任务特征独立经 MLP 生成键（Key）`k^t_x`，另附加一个 NO-OP 键。
    *   **指针解码器（Pointer Decoder）**：使用单步加性注意力（Additive Attention），计算查询与每个任务键的兼容性得分 `u^t_x = v^T tanh(W_K k^t_x + W_q q^t)`，再经 Softmax 归一化，直接得到当前任务集合上的策略分布，支持无界的任务数量变化。
*   **GNN 评论家网络（Critic）**：
    *   将开放全局状态构建为**二分智能体-任务图** `G^t = <X^t, N^t, E^t>`，节点集随智能体和任务数量变化。
    *   使用 GCN（图卷积网络）进行消息传递，学习节点间关系；经过均值池化和 MLP 输出标量状态价值 `V(s^t)`。
*   **训练算法**：使用 **MAPPO（多智能体PPO）** 进行训练，PPO 剪切目标优化演员，价值回归损失优化评论家，GAE 计算优势。

**3. 理论保证**

*   **良定义性（Theorem 1）**：证明了 actor 和 critic 在**可数无限的开放智能体-任务空间**上是良定义且置换不变的。
*   **复杂度分析（Theorem 2）**：每时间步的训练复杂度为 **O(|N^t|² + |N^t||X^t|)**，与智能体和任务数量呈多项式关系。

**4. 算法伪代码（文字描述）**

### 三、实验设计：数据集 / 场景 / Benchmark / 对比方法

*   **实验域**：**MOASEI 野火抑制（Wildfire Suppression）域**。网格化的地图上，消防员智能体在固定位置与火焰（任务）交互。
*   **开放性设置**（4种Setup）：
    *   **S0**：封闭基线（无火势蔓延、无随机点火、无限灭火剂）。
    *   **S1**：内生任务开放性（火势蔓延概率 0.6，补充成功率 1.0）。
    *   **S2**：外生任务开放性（随机点火概率 0.6，补充成功率 0.8）。
    *   **S3**：联合开放（火势蔓延 + 随机点火 + 补充成功率 0.6），最苛刻条件。
*   **网格规模**：评估了 2×3、3×3、4×4，以及零样本泛化测试 5×5。
*   **对比方法**：
    *   **智能基线（Smart Baselines）**：DGN、DICG、MOHITO（最接近的先验方法，针对TO设计）。
    *   **朴素启发式基线（Naive Baselines）**：NOOP（始终不动作）、Random（随机选择）、Strongest（优先扑灭最强火）、Weakest（优先扑灭最弱火）。
*   **评估指标**：
    *   **性能**：回合回报（Episode Return）。
    *   **效率**：每次战斗动作的奖励（Reward per Fight）。
    *   **行为指标**：灭火次数（Putouts）、烧毁数（Burnouts）、NOOP比率。
*   **评估模式**：
    *   **原生评估（Native）**：在相同网格上训练与测试。
    *   **零样本评估（Zero-shot）**：在未见过网格上部署训练策略（如 2×3→3×3, 3×3→4×4, 3×3→5×5），检验泛化性。

1.  **性能优势**：在**原生评估**中，PLATO 在 3×3 的 S2、S3 和 4×4 的 S1–S3 上取得**统计学显著的SOTA性能**。在无开放性（S0）下，所有学习方法表现相当。
2.  **效率优势**：PLATO 在多次设置中实现了最高的每次战斗奖励，尤其在联合开放性（S2/S3）下，展示出更高效的任务优先级排序与灭火剂分配。
3.  **泛化优势**：**零样本评估**中，PLATO 在跨网格迁移（如 3×3→5×5 的 S1–S3）时表现**更一致的优越性**，DGN 在开放环境中性能退化严重，MOHITO 在部分情境下出现负收益，说明 PLATO 具有更稳健的泛化潜力。
4.  **消融发现**：
    *   **编码器（MLP vs LSTM）**：原生评估中无显著差异；但在零样本的联合开放（S3）下，LSTM 编码器有优势，尤其配合加性打分器时。
    *   **打分器（加性 vs 点积）**：原生评估中无显著差异；零样本下，在联合开放场景，LSTM+加性打分器（lstm+add）最佳；在封闭场景（S0），MLP+点积（mlp+dot）最佳。
    *   **结论**：架构选择的影响与任务开放程度**强相关**，不存在普适最优组合。

### 七、优点：方法或实验设计上的亮点

1.  **对开放性的完整支持**：PLATO 是首个**同时处理智能体开放性（AO）与任务开放性（TO）**的统一MARL框架，无需固定边界或重新训练。
2.  **理论基础扎实**：形式化 TaAgO-MG，并给出良定义性、置换不变性与计算复杂度的**严谨证明**，且附加了基于指针策略的具体理论边界的分析（Lemma 2/3）。
3.  **架构设计优雅**：指针 actor 直接输出任务集上的分布，自然适应动作空间变化；GNN critic 动态编码交互图，适应状态空间变化。二者配合相得益彰。
4.  **实验全面且严谨**：涵盖多种开放性组合、网格规模、智能与朴素基线、零样本迁移，并配备了系统的消融实验与严格统计检验，结果可信度高。
5.  **公平的超参数调优**：所有方法均使用 Optuna 进行公平的超参数优化，降低了因超参数设置不当导致基线性能不佳的偏差风险。

### 八、不足与局限

1.  **任务的单动作假设**：TaAgO-MG 中**为每个任务设定了一个动作**（如“扑灭火x”），不支持任务具有多个动作的场景。论文计划在后续工作中扩展，目前限制了方法的适用范围。
2.  **完全可观测假设**：当前框架假设**全可观测状态**（CTDE训练时）。对部分可观测环境（如局部视野、隐藏状态）需要进一步扩展。
3.  **未处理框架开放性（FO）**：方法聚焦于 AO 与 TO，忽略了智能体内部目标、偏好或能力的变化（FO），不能处理此类更复杂的开放维度。
4.  **实验领域局限**：仅在火宅抑制一个域中验证结果，缺乏跨域实验证明通用性。其他测试域（Eck等人提出）留待未来研究。
5.  **零样本性能的波动性**：PLATO 的零样本性能虽整体更一致，但在某些特定迁移路径（如 2×3→4×4 的 S3）下表现并不最佳，说明其泛化能力仍有提升空间。
6.  **计算成本与可复现性**：实验使用海量 CPU 计算资源，复现成本极高。且论文中未提供代码链接（在预印本环境中），稍降低可复现性。
