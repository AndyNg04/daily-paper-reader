## 摘要
当前语言模型的基准测试主要评估其在完全明确的任务上的执行能力。然而，真实用户的任务往往是模糊的。用户带着不完整、探索性甚至不一致的目标而来，要求助手在执行任务之前首先确定预期任务。我们将这一问题研究为任务对齐：即与用户就其预期任务达成一致的能力。我们引入了一个通用框架，将明确任务转换为不明确的交互，并将其形式化为一个POMDP，其中模型必须从部分且不断演变的用户意图中推断出潜在任务。我们通过事后的人工用户研究验证了我们的用户模拟器。在购物、编程和职业工作场景中，我们发现，尽管模型在任务明确后通常表现良好，但模型在任务对齐方面仍然存在困难：当前模型过早行动、交互效率低下，且无法解决模糊请求。在模糊情况下，模型平均仅能在22-32%的时间内恢复用户的预期任务。在相同设置下的人类研究中，人类达到了48%，优于所有被评估的模型。我们表明，通过监督微调和强化学习进行后训练可以改善任务对齐，但模型在通过交互解决不确定性方面仍落后于人类。总之，我们的结果表明，当前模型仍然缺乏实现可靠代理所需的关键交互能力。

## Abstract
Current benchmarks for language models primarily evaluate execution on fully specified tasks. However, real user tasks are often ambiguous. Users arrive with incomplete, exploratory, or even inconsistent goals, requiring the assistant to first determine the intended task before carrying it out. We study this problem as task alignment: the ability to align with a user on their intended task. We introduce a general framework for converting specified tasks into underspecified interactions, formalized as a POMDP in which the model must infer a latent task from partial and evolving user intent. We validate our user simulator post hoc with a human user study. Across shopping, coding, and professional work settings, we find that while models often perform well once the task is specified, models still struggle with task alignment: current models act prematurely, interact ineffectively, and fail to resolve ambiguous requests. Models on average recover the user's intended task only 22-32% of the time under ambiguity. In a human study in the same setting, humans reach 48%, outperforming all evaluated models. We show that post-training with supervised fine-tuning and reinforcement learning improves task alignment, but models still lag behind humans in resolving uncertainty through interaction. Together, our results suggest that current models still lack key interaction abilities required for reliable agency.

## 一、论文的核心问题与整体含义

**研究动机**：当前大语言模型（LLM）的基准测试主要集中于"完全指定任务"（fully specified tasks）的执行能力——模型在给定目标、约束和成功标准的前提下完成任务。然而，现实世界中的用户几乎不会以完整规格开始交互，其目标往往是不完整、探索性、含糊甚至前后不一致的。因此，实际部署中的瓶颈从"执行已知任务"转向了"确定用户真正意图的任务"。

**核心问题**：模型能否在任务模糊的情况下，通过交互与用户达成"任务对齐"（task alignment）——即在执行前识别出用户意图中的正确任务？作者指出，任务对齐是下游任务完成的前提条件；即使模型能力再强，如果未能察觉缺失信息、假设用户意图并过早行动，也会导致失败。

**整体含义**：论文提出，现有模型虽然已具备较高的任务执行能力，但缺乏可靠代理（agency）所需的交互式澄清与意图推断能力，任务对齐正在成为制约模型实际可用性的主要瓶颈。

## 二、论文提出的方法论

### 2.1 核心思想

论文提出一个**领域通用框架**，将完全指定的任务评估转化为"欠指定交互"（underspecified interactions）的任务对齐评估。核心思路是：给定一个领域及其任务规范空间 X_T，构造一个交互场景，其中真实任务规范 x* 是隐变量，仅通过用户模拟器部分地、渐进地暴露，并随时间从抽象走向具体。

### 2.2 POMDP 形式化

从助手的视角，任务对齐被形式化为一个部分可观测马尔可夫决策过程（POMDP）：

**M_T = ⟨S, A, T, R, Ω, O⟩**

- **状态 S**：s_t = (x*, i_t, h_t)，其中 x* 是固定的真实规范，i_t 是用户当前意图状态，h_t 是提交执行前的对话历史。
- **观测 Ω**：助手仅能观察到对话历史 h_t（确定性观测函数），x* 和 i_t 均隐藏。
- **动作 A**：a_t = (m_t^a, e_t, ρ_t)，包括自然语言响应、停止信号（是否提交执行）以及候选集上的排名（仅作为测量工具，不泄露给对话）。
- **转移 T**：真实规范固定不变，仅对话历史和意图状态演变；用户策略 π_u 和意图演化器 E 均由 LLM 实现，模拟器拥有对 x* 的特权访问。

### 2.3 评估指标

论文设计了两类互补的指标：

**（1）任务恢复行为**
- **CommitAcc@1**：提交时真实规范排名第一的比例
- **CommitRank（ĉ_t）**：归一化排名，取值 [0, 1]
- **CommitReward**：α·ĉ_T* − λ·T*（α=1.5，λ=0.02），衡量准确性与交互成本之间的权衡

**（2）不确定性解决**
- **TotalIG** = Ĥ_0 − Ĥ_T*，即助手信念熵在对话前后的累计信息增益
- **四象限分类**：将每次交互按提交时的正确性（rank 是否第一）与置信度（熵高低）分为"自信正确/侥幸正确/自信错误/诚实不确定"四类

### 2.4 任务构造流程

每个基准任务都经过三步转换：
1. **初始化意图状态**：用 LM 将 x* 改写为三个意图层级（抽象/中等/具体）的用户话语
2. **构造候选集 C**：生成 14 个扰动变体 + 真实规范，|C|=15
3. **验证候选集**：通过空对话探测确保 x* 不会通过模式泄漏（top-1 泄漏率接近随机基线 6.7%）

## 六、论文的主要结论与发现

1. **模型在任务对齐上表现糟糕**：抽象意图下，CommitAcc@1 平均仅 22.01%（购物）、27.59%（GDPVal）、32.17%（Terminal-Bench），即使允许 15 轮交互仍如此。

2. **过早起行为普遍**：GPT-5.4 系列在 1-2 轮内就提交执行；提交时机的模型内跨域一致性极高（Spearman ρ ≥ 0.92），说明提交行为是稳定的模型特征。

3. **任务能力与任务对齐是可分离的轴**：在购物场景中，14 个模型能力饱和（NDCG 81.1-88.4%）但对齐表现差异近三倍；方差分解显示，高达 39% 的方差由与能力正交的成分解释，对齐需独立测量。

4. **对齐轴具有领域通用性**：跨领域行为的 Kendall's W = 0.62（能力残差化后仍为 0.58），说明存在一个稳定的、跨领域的模型行为轴。

5. **人类显著优于所有模型**：人类在匹配购物子集上达到 48% 的 CommitAcc@1，超过最强模型 GLM-5.1 的 36.9%。通过"推理-回放"实验证明，**人类优势源于沟通能力而非推断能力**——当 LLM 使用人类对话记录进行推断时，中位数准确率翻倍至 49.5%。

6. **用户模拟器接近人类行为**：人类 vs 模拟用户条件下，CommitReward（0.98 vs 0.95）、CommitAcc@1（40.9% vs 42.0%）、T*（13.24 vs 12.45）均在 1 SEM 内。

7. **后训练可改进但仍有缺口**：SFT 和 RL 均将 CommitReward 提高约 2.5 倍，RL 将"自信错误"从 53.0% 降到 18.8%，将"诚实不确定"从 32.0% 提升到 57.5%；但训练后模型（22.5-27.5%）仍低于人类（48%）。

## 七、优点

1. **问题框架新颖且通用**：将任务对齐形式化为 POMDP，可适用于任何可规范化的任务基准，为评估"意图发现"能力提供了统一范式。

2. **指标设计精巧**：任务恢复与不确定性解决的双维度指标，结合四象限分类法，能区分"侥幸正确"与"自信正确"、"自信错误"与"诚实不确定"，揭示模型行为深层差异。

3. **测量与对话解耦**：排名 ρ_t 在独立会话线程中获取，不干扰交互过程，是一个干净的测量仪器。

4. **实验设计严谨**：
   - 用 Shopping 作为能力饱和的控制变量，隔离对齐与能力
   - 候选集泄漏探测排除信息泄漏
   - 意图演化器消融验证模拟器必要性
   - 人类研究含交叉验证（人类助手 + 人类用户）

5. **人类对比有洞见**："推理-回放"实验巧妙地将沟通能力与推断能力分离，定位了人类优势的真正来源。

6. **训练结果提供了改进路径**：证明了后训练能改善对齐行为，特别是提升置信度校准。

## 八、不足与局限

1. **训练范围窄**：SFT/RL 仅限 Qwen3.5-9B 和购物场景；收益是否迁移到更大骨干、闭源模型或能力受限的 GDPVal/Terminal-Bench 场景尚不清楚。

2. **用户模拟器的固有局限**：虽然人类对比验证表明模拟器行为接近真实用户，但 LLM 模拟器无法覆盖完整真实用户分布——包括真正的任务不确定性、偏好漂移、矛盾心理、对话挫败感、分心或出于隐私的选择性披露。绝对数值与特定模拟器设计绑定，而非一个规范化的用户模型。

3. **模拟器设计敏感性**：意图演化器消融显示其选择对测量结果有实质性影响（移除后 CommitReward 显著上升），说明绝对数值对设计决策敏感。

4. **人类研究覆盖有限**：
   - 仅购物场景（更通俗，不需要专业技能）
   - 人类用户所提供的任务为已完成购买（大致对应"具体"层级），无法捕捉真实世界中常见的抽象意图
   - 样本量较小（5 个商品，50 个参与者）

5. **置信度指标选择性偏差**：仅 5 个能输出 logprobs 的模型参与不确定性分析，9 个模型（包括表现最好的 Gemini-3.1-Pro、GLM-5.1）被排除，可能导致不确定性相关结论存在选择偏差。

6. **能力基线的标准化问题**：GDPVal 和 Terminal-Bench 使用 Artificial Analysis 排行榜的归一化 Elo/分数，不同模型间的原始分差异可能被压缩或放大。

7. **缺少对用户满意度/体验的直接测量**：指标关注任务准确性和不确定性，未测量界面中的用户主观满意度、交互效率感知或信任度。
