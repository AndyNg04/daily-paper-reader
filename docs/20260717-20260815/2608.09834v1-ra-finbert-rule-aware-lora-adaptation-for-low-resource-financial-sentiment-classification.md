## 摘要
金融情感分析将非结构化的金融新闻转换为可支持市场分析和决策的量化信号。现有的资源高效金融自然语言处理工作主要集中于压缩或自适应预训练语言模型，而较少关注将上下文表示与轻量级规则派生特征相结合。本研究开发了规则感知FinBERT（RA-FinBERT），这是一种参数高效框架，将低秩自适应（LoRA）与三个连续的基于VADER的情感比例（正面、负面和中性）以及一个来源级元数据特征相集成。标准化后的四维特征向量直接与768维的FinBERT最终层[CLS]表示拼接，并通过一个轻量级分类头进行处理。与结构匹配的纯文本FinBERT模型相比，该设计仅引入了1,024个额外的可训练权重。RA-FinBERT与纯文本FinBERT和轻量级DistilBERT基线进行了对比评估，用于金融新闻标题和描述的三分类情感分类。在留出测试集上，RA-FinBERT达到了69.89%的准确率和0.634的宏F1分数，而纯文本FinBERT分别为63.44%和0.526。中性类别的召回率从18.18%提高到45.45%。该框架支持CPU和GPU执行，为计算资源受限条件下的金融情感分类提供了一种轻量级且实用的方法。这些发现表明，规则派生的情感信息和来源元数据可以为上下文FinBERT表示提供互补信号，并以极小的额外模型复杂度提升性能。

## Abstract
Financial sentiment analysis converts unstructured financial news into quantitative signals that can support market analysis and decision-making. Existing work on resource-efficient financial NLP has largely focused on compressing or adapting pretrained language models, with less attention to combining contextual representations with lightweight rule-derived features. This study develops Rule-Aware FinBERT (RA-FinBERT), a parameter-efficient framework that integrates low-rank adaptation (LoRA) with three continuous VADER-derived sentiment proportions (positive, negative, and neutral) and a source-level metadata feature. The standardized four-dimensional feature vector is directly concatenated with the 768-dimensional final-layer FinBERT [CLS] representation and passed through a lightweight classification head. This design introduces only 1,024 additional trainable weights relative to a structurally matched text-only FinBERT model. RA-FinBERT was evaluated against text-only FinBERT and a lightweight DistilBERT baseline for three-class sentiment classification of financial-news titles and descriptions. On the held-out test set, RA-FinBERT achieved 69.89% accuracy and a macro F1 score of 0.634, compared with 63.44% and 0.526 for text-only FinBERT. Neutral-class recall increased from 18.18% to 45.45%. The framework supports both CPU and GPU execution, offering a lightweight and practical approach to financial sentiment classification under constrained computational resources. These findings indicate that rule-derived sentiment information and source metadata can provide complementary signals to contextual FinBERT representations and improve performance with minimal additional model complexity.

## 2. 方法论

### 2.1 总体架构

- RA-FinBERT = FinBERT 文本编码器 + LoRA 参数高效适配 + 四维辅助数值特征直接融合。
- 文本处理：标题与描述拼接，最大长度 128 token；取 FinBERT 最终层 [CLS] 位置的 768 维隐藏状态作为文本表示。
- LoRA 配置：插入所有 12 层的 Query 和 Value 投影，秩 r=16，缩放因子 α=16；预训练权重冻结，仅训练 LoRA 的 A/B 矩阵、对应 Q/V 偏置和分类头。

### 2.2 辅助特征与融合方式

- 构建四维数值向量：`[pos, neg, neu, source_weight]`，其中前三者为 VADER 输出的正面、负面、中性情感比例（均界于 0–1），`source_weight` 为来源级元数据特征（取值 1.0 或 1.5）。
- **重要设计决定**：VADER compound 分数被排除在输入之外，因为测试标签正是由 compound 阈值化得到的，避免特征与标签的直接目标变量重叠。
- 特征标准化：StandardScaler 仅在训练分区上拟合，再应用于验证和测试分区。
- 训练正则化：以概率 p=0.1 对完整四维向量进行整体掩码（whole-vector masking），防止模型过度依赖辅助输入；验证和测试阶段不使用掩码。

### 2.3 融合与分类

- 最终输入：`f = [h_CLS; v_hat] ∈ ℝ⁷⁷²`，即 768 维 CLS 表示与四维数值向量直接拼接，无额外数值编码器。
- 分类头：772 → 256（ReLU + dropout 0.1）→ 3 类输出。
- 由于直接拼接，第一个分类层从 768×256 变为 772×256，**精确增加 1,024 个可训练权重**。
- 训练目标：加权交叉熵，类别权重基于训练集计算（正 0.4919，中性 1.9120，负 0.5961），AdamW 优化器（weight decay 0.01，梯度裁剪 1.0）。
- 标签构造：基于 VADER compound 分数阈值化（≥0.05 为正，<0.05 绝对值为中性，≤−0.05 为负）。

## 3. 实验设计

### 3.1 数据集与基准

- **数据集**：Kaggle 公开数据集 *Financial News Sentiment vs Market 2020*，选取 614 条样本（正 295 / 中性 76 / 负 243），文本为新闻标题+描述，中性类严重欠表示。
- **数据划分**：分层划分（seed=42），训练 429 / 验证 92 / 测试 93（测试支撑：正 45、中性 11、负 37）。
- **对比方法**：
  - **Text-only FinBERT**：结构化匹配的主对比模型——相同预训练检查点、相同 [CLS] 提取方式、相同 LoRA 设置、相同加权损失策略，区别仅在于无四维辅助输入（分类头 768→256→3）。
  - **DistilBERT**：次级轻量基线，但 backbone、tokenizer、类别不平衡处理策略（WeightedRandomSampler + 普通交叉熵）均不同。

### 3.2 共享超参数

- 最大序列长度 128、batch size 8、10 epochs、学习率 1e-4、LoRA r=16 / α=16、早停 patience=5、随机种子 42；最佳 checkpoint 按验证准确率选取。
- 评估指标：测试准确率、宏 F1、各类别精确率/召回率/F1、混淆矩阵。

## 4. 资源与算力

- **CPU 环境**：消费级笔记本（Intel Core Ultra 5 225H + 32GB 内存，无独立 GPU），完整 10-epoch 训练约需 1–2 小时。
- **GPU 环境**：Google Colab 的 NVIDIA T4，对应流程约 5–10 分钟完成。
- **单 epoch 耗时（T4）**：DistilBERT 约 3.68 秒，Text-only FinBERT 约 7.27 秒，RA-FinBERT 约 7.31 秒。
- 作者明确说明运行时为**描述性报告，而非正式性能基准**；软件栈轻量（PyTorch、Transformers、pandas、NumPy、scikit-learn），无分布式训练。

## 5. 实验数量与充分性评估

- **实验规模有限**：仅 1 个数据集、1 种数据划分、1 个随机种子、无独立测试集交叉验证；测试集仅 93 条，中性类仅 11 条（一条正确预测即改变约 9.1 个百分点中性召回率）。
- **消融实验缺失**：未对单个辅助特征（pos/neg/neu/source_weight）做消融分析，无法确认各特征的独立贡献；掩码概率也未被系统性验证。
- **对比公平性**：RA-FinBERT 与 text-only FinBERT 的匹配设计较公平，能较好隔离辅助特征的贡献；但 DistilBERT 的对比涉及 backbone、分词器、不平衡处理策略等多重差异，只能视为次级参照。
- **总体充分性**：作为概念验证（proof-of-concept）尚可，但**不足以支撑"一致性优势"的强结论**；作者自述需重复分层运行、交叉验证或 bootstrap 置信区间来量化不确定性。

## 6. 主要结论与发现

- **性能提升**：RA-FinBERT 在测试集上准确率 69.89%、宏 F1 0.634，优于 text-only FinBERT（63.44% / 0.526）和 DistilBERT（59.14% / 0.527）。
- **类别层面改善**：中性召回率从 18.18% 大幅提升至 45.45%（多正确分类 3 条），负类召回率从 62.16% 提升至 75.68%；但正类召回率略有下降（75.56% → 71.11%），提升并非各类均匀。
- **错误模式变化**：相对 text-only FinBERT，中性→正类错误减少（8→4）、负→正类错误减少（13→8），说明辅助特征主要帮助区分易混淆的边界样本。
- **参数效率**：RA-FinBERT 总参数 110,273,030，可训练参数 806,915（约 0.73%），相对 text-only 仅增加 1,024 个可训练权重。
- **核心主张**：规则派生的情感比例（pos/neg/neu）和来源元数据可作为上下文 FinBERT 表示的**互补信号**，以极小的模型复杂度代价显著提升低资源金融情感分类性能，尤其在少数类（中性）上。

## 7. 优点与亮点

1. **极简融合设计**：直接拼接（concatenation）而非复杂注意力/门控机制，无额外数值编码器，增参数仅 1,024，保持了"轻量"方法的本色。
2. **精心构造的匹配对比**：text-only FinBERT 在 backbone、LoRA 设置、损失策略、分类头结构上完全对齐，使性能差异可较干净地归因于四个辅助输入。
3. **特征与标签解耦的自觉性**：明确排除 compound 分数（因标签由它派生），体现方法设计中对数据泄漏风险的审慎。
4. **资源友好**：同时支持 CPU 与 GPU 执行，训练时间在消费级硬件上可接受，贴近真实受限环境需求。
5. **方法迁移潜力**：提出"规则/专家先验 + 预训练模型"融合的通用模板，可推广到评分规则、启发式指标、领域指数等其他结构化知识。

## 8. 不足与局限

- **样本量与统计效力不足**：614 条总样本、93 条测试集、11 条中性样本，性能波动大；仅单划分、单种子，无置信区间，结果外推需谨慎。
- **弱标签问题**：测试标签由 VADER compound 阈值化生成，本质上是"规则系统的自洽性验证"而非对真实人类情感判断的评估；pos/neg/neu 与标签同源，难以建立独立的外部有效性。
- **缺少消融与敏感性分析**：未单独评估各辅助特征的贡献，未比较不同掩码概率、不同 LoRA 秩/插入层，也未有对不平衡策略的匹配化对比。
- **类别间收益不均衡**：正类召回率不升反降，说明融合特征并非无条件有益，可能对某些类别引入偏差。
- **外部有效性受限**：仅单数据集、单语言（英语）、单一时间窗口，未验证跨市场周期、不同新闻源、其他语言的迁移性。
- **对比基线的局限**：DistilBERT 的对比因策略差异不宜作严格结论；未与 adapter、prefix tuning 等其他 PEFT 方法、以及更复杂的融合架构（门控、注意力融合等）进行实证比较。
