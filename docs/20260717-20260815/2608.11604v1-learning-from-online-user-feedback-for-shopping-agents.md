## 摘要
基于大语言模型的购物代理正日益部署于真实电子商务平台，产生海量用户交互日志，为改进这些代理提供了宝贵的监督信号。然而，现有方法主要依赖离线训练信号，如用户-物品交互或合成偏好数据，而很大程度上忽视了用户自然对话反馈中蕴含的丰富监督信息。此外，可用的在线反馈具有异质性、稀疏性和噪声性，难以自动转化为可靠的学习信号。为应对这些挑战，我们提出了LOFA框架，使购物代理能够直接从未经人工标注的真实在线交互日志中学习。LOFA将基于可验证购买结果的强化学习与反馈感知的在策略蒸馏相结合，后者能够识别用户对话中的指令并将其转化为密集的词级监督。这两个互补的目标同时捕获了协作行为模式和用户特定偏好。在真实电子商务日志上的大量实验表明，LOFA在推荐质量、响应有用性和用户满意度对齐方面持续优于强基线，突显了从真实在线用户反馈中学习购物代理的有效性。

## Abstract
Large language model-based shopping agents are increasingly deployed in real-world e-commerce platforms, generating massive amounts of user interaction logs that provide valuable supervision for improving these agents. However, existing approaches primarily rely on offline training signals, such as user-item interactions or synthetic preference data, while largely overlooking the rich supervision contained in users' natural conversational feedback. Moreover, the available online feedback is heterogeneous, sparse, and noisy, making it difficult to transform into reliable learning signals automatically. To address these challenges, we propose LOFA, a framework that enables shopping agents to learn directly from real online interaction logs without human annotation. LOFA combines reinforcement learning over verifiable purchase outcomes with feedback-aware on-policy distillation, which identifies users'in-dialogue directives and converts them into dense token-level supervision. These complementary objectives capture both collaborative behavioral patterns and user-specific preferences. Extensive experiments on real-world e-commerce logs demonstrate that LOFA consistently improves recommendation quality, response helpfulness, and user-satisfaction alignment over strong baselines, highlighting the effectiveness of learning shopping agents from real online user feedback.

## 2. 方法论

- **核心思想**：将在线反馈分为两类互补信号：
  - **显式行为反馈（Explicit Behavioral Feedback）**：用户最终是否购买某个商品，提供结果级、可靠但稀疏的监督。
  - **对话内指令反馈（In-Dialogue Directive Feedback）**：用户在后续对话中表达的批评、偏好修正、隐含约束等，提供细粒度但稀疏、异质的监督。
- **关键技术细节**：
  1. **行为反馈学习**：从日志中抽取成功购买会话，构建训练数据，使用 **GRPO**（Group Relative Policy Optimization）进行强化学习。
     - 奖励函数包含两部分：
       - **格式奖励** \(R_{\text{fmt}}(\tau)\)：输出格式违规时惩罚为 -1，否则为 0。
       - **推荐奖励** \(R_{\text{rank}}(\tau)\)：以购买商品为目标，计算生成推荐列表的 **NDCG@10**。
     - 总奖励为：若格式违规则总奖励 -1，否则为推荐奖励。
  2. **指令反馈学习**：
     - **反馈挖掘**：使用 LLM（DeepSeek-V3.2）作为评判器，将用户后续反馈分类为五类：显式批评、隐式推导、纯负面反馈、比较偏好、话题转移/放弃。其中前四类作为有效监督，话题转移类被丢弃；同时生成原因解释。
     - **反馈感知教师构造**：学生模型只能观察部署时的上下文 \(X_t^S\)；教师模型额外获取特权信息（上一轮回复、用户反馈、反馈类别、解释），得到 \(X_t^T\)，用于评估学生响应并提供修正性指导。
     - **在策略蒸馏（On-Policy Distillation）**：学生生成响应 \(\hat{a}_t\) 后，教师在该生成轨迹上计算每 token 分布的**反向 KL 散度**作为损失，实现密集 token 级监督。
  3. **训练流程**：采用**顺序训练**——先进行 GRPO（学习购买结果），再进行 OPD（学习对话指令）。论文实验表明 **RL → OPD** 优于 **OPD → RL**。

## 3. 实验设计

- **数据集**：
  - 来自京东真实部署的购物代理 **Jingyan** 的匿名交互日志。

  - **NoThink**（禁用推理模式）

## 6. 主要结论与发现

- 学习**显式行为反馈**显著提升推荐质量（NDCG、Recall、MAP 大幅提高）。
- 学习**对话内指令反馈**显著提升回复对用户问题的解决能力（SR 明显提高）。
- **两者互补**：RL 主要改善推荐准确性，OPD 主要改善对话响应质量；联合训练效果最佳。
- **训练顺序重要**：RL → OPD 优于 OPD → RL，先学习可靠的结果级监督再学习细粒度指令更有效。
- 基于反馈驱动优化远优于推理时自我反思（Self-Reflection）。
- SFT 因缺少推理链，效果明显劣于 RL/OPD 方法。
- 消融显示推荐奖励是行为学习的关键；隐式推导类反馈对 OPD 贡献最大；即使纯负面反馈也能提供有效监督。
- LOFA 在不同模型规模（4B/8B）上均表现稳定。
