## 摘要
通过表面肌电（sEMG）进行手部姿态识别是假肢控制的基础。在该领域，深度学习方法已成为黄金标准。然而，当前架构难以扩展；随着手部动作数量的增加，模型性能通常会下降。性能退化与解码扩展手势集的统计复杂性增加有关，并受到最先进方法局限性的加剧，这些方法主要依赖低延迟的单模态卷积架构。卷积在局部操作，限制了模型捕获长距离序列模式的能力。单模态设置无法利用来自表征运动执行的协调信号的互补信息，例如惯性数据和眼动跟踪数据。这些局限性促使架构在跨模态生理序列中整合局部和全局特征。为弥合这一差距，本研究引入了EMG-CrossFormer，一种端到端的混合卷积-Transformer架构，用于无缝的多模态整合。EMG-CrossFormer通过级联交叉注意力融合层组合任意数量的单模态编码器的表示，并使用可学习的手势查询解码融合后的表示。EMG-CrossFormer在四个NinaPro数据集（DB2、DB3、DB7和DB10）上进行了评估，并与使用递增模态数量的六种最先进模型进行了基准比较。仅使用sEMG时，EMG-CrossFormer在DB2、DB3、DB7和DB10上的平均准确率分别达到72.33%、52.48%、79.16%和73.49%。加入惯性信号后，性能提升至90.66%、80.40%、92.79%和92.06%。这些结果表明，联合局部-全局特征建模改善了仅sEMG的解码性能，而多模态融合显著放大了这一优势，突显了这两种设计原则对于复杂手部姿态识别的价值。

## Abstract
Hand gesture recognition via surface electromyography (sEMG) is fundamental to prosthetic control. In this field, deep learning approaches have become the gold standard. However, current architectures struggle to scale; model performance typically decreases as the number of hand movements increases. Performance degradation is tied to the increased statistical complexity of decoding expanded gesture sets and compounded by the limitations of state-of-the-art methods, which primarily rely on low-latency unimodal convolutional architectures. Convolutions operate locally, limiting model's ability to capture long-range sequential patterns. Unimodal setups cannot leverage complementary information from coordinated signals characterizing movement execution, such as inertial and eye-tracking data. These limitations motivate architectures that integrate local and global features across multimodal physiological sequences. To bridge this gap, this study introduces EMG-CrossFormer, an end-to-end hybrid convolutional-transformer for seamless multimodal integration. EMG-CrossFormer combines representations from an arbitrary number of unimodal encoders through cascaded cross-attention fusion layers, and decodes the fused representations using learnable gesture queries. EMG-CrossFormer was evaluated on four NinaPro datasets (DB2, DB3, DB7, and DB10) and benchmarked against six state-of-the-art models using an increasing number of modalities. Using only sEMG, EMG-CrossFormer achieved mean accuracies of 72.33%, 52.48%, 79.16%, and 73.49% on DB2, DB3, DB7, and DB10, respectively. Incorporating inertial signals improved performance to 90.66%, 80.40%, 92.79%, and 92.06%. These results show that joint local-global feature modeling improves sEMG-only decoding and that multimodal fusion substantially amplifies this benefit, underscoring the value of both design principles for complex hand gesture recognition.

## 2. 论文提出的方法论

- **核心思想**：将任意数量的单模态编码器输出的令牌序列（token sequences），通过级联的交叉注意力融合层逐步整合，再使用可学习的“手势查询”（learnable gesture queries）从融合表示中解码出各个手势类别。整体设计受DETR启发。
- **架构组成**：
  - **单模态骨干网络**（Unimodal Backbone）：支持两种实现，均将原始信号映射为令牌序列 $\mathbf{z}_{enc}^m \in \mathbb{R}^{L_m \times d}$：
    - **1D深度卷积骨干**（EMG-CF 1D）：轻量，提取通道级时间特征，参数少。
    - **2D多尺度卷积骨干**（EMG-CF 2D）：将多通道信号视为伪图像，采用多尺度并行卷积核，捕捉时空模式，性能更高但计算量大。
  - **融合层**：将sEMG作为第一模态（主模态），其他模态依次通过“非因果Transformer解码器层”进行定向级联融合。每个辅助模态添加可学习“模式令牌”（mode token）以帮助上下文理解。融合过程包含自注意力和交叉注意力，公式为：
    - $\bar{\mathbf{z}}_{enc}^m = \mathbf{z}_{enc}^m + \mathbf{E}^m_{pos}$（主模态）；$\bar{\mathbf{z}}_{enc}^m = \mathbf{z}_{enc}^m + \mathbf{E}^m_{pos} + \mathbf{1}_{L_m}\mathbf{t}^m_{mode}$（辅助模态）
    - $\mathbf{z}_{fuse}^{(m)} = LN(\hat{\mathbf{z}}^{(m)} + FFN(\hat{\mathbf{z}}^{(m)}))$，其中包含MHA交叉注意力。
  - **查询解码器**：4层标准Transformer解码器，使用可学习手势查询，通过交叉注意力利用融合表示，联合推理所有手势。
  - **预测头**：共享两层FFN，输出每个查询的类别对数。
- **损失函数**：复合损失，包括主分类交叉熵、辅助交叉熵（对编码器和融合输出）、监督对比损失（对齐嵌入空间）、以及手部特征回归损失（L1），实现深度监督。
- **数据处理**：sEMG经过毫伏转换、DC去除、带通滤波（20–500 Hz）、重采样至1 kHz，并划分100/150/200 ms窗（重叠90%）；加速度计和眼动数据也经重采样和统一窗口化。数据增强采用信号扭曲（PCHIP插值）。
- **训练细节**：LAMB优化器，混合精度，学习率分层设置（骨干5e-4，融合/解码器5e-5），梯度裁剪0.1，batch size 128，sEMG-only训练200 epochs，多模态100 epochs。

## 3. 实验设计

- **数据集**：四个公开NinaPro数据集：

  - **DB7**：20名健康+2名截肢受试者，sEMG+ACC，40+rest。
  - **DB10**：30名健康+15名截肢受试者（排除6名），sEMG+ACC+眼动（gaze），10种抓握+休息，10次重复。
- **评估协议**：受试者内（intra-subject）评估：训练集使用重复1、3、4、6（DB10额外加7、8），测试集使用重复2、5。
- **对比方法**：
  - 深度模型：Shallow CNN、ResNet-1D、MKCNN（多尺度CNN）、NKDFF（多模态CNN，融合sEMG+ACC）。
  - 传统机器学习：SVM、随机森林（RF），使用29种手工特征。
- **模态配置**：仅sEMG；sEMG+ACC；sEMG+ACC+Gaze（仅DB10）。
- **窗口长度**：100 ms、150 ms、200 ms三种。

## 6. 论文的主要结论与发现

- **仅sEMG时**：EMG-CF 2D在所有数据集和窗口长度下均取得最高平均平衡准确率（DB2: 72.33%，DB3: 52.48%，DB7: 79.16%，DB10: 73.49%），但相对传统RF和MKCNN的提升幅度较小（通常1–2个百分点）。验证了局部-全局联合建模对sEMG解码的有效性。
- **加入加速度计后**：性能显著提升（DB2达到90.66%，DB3 80.40%，DB7 92.79%），且EMG-CrossFormer的提升幅度最大，在截肢者数据集（DB3）上相比仅sEMG提升高达31.43个百分点（100 ms窗口）。

- **整体结论**：多模态融合能显著提升sEMG手势识别，而基于交叉注意力的融合策略优于简单特征拼接；现代混合架构可有效利用互补生理信号，缩小健康与截肢受试者间的性能差距。

## 7. 优点

- **架构灵活性**：支持任意数量的输入模态，单模态编码器可替换（如1D或2D），便于扩展新信号（如EEG、场景视频）。

- **查询解码**：借鉴DETR的可学习查询方案，让模型联合推理所有手势之间的相互关系。

## 8. 不足与局限

- **可解释性不足**：模型是“黑盒”，缺乏对生理特征和注意力模式的解释，在康复应用中削弱了可靠性和信任度。
