## 摘要
通过表面肌电图（sEMG）进行手部手势识别是假肢控制的基础。在该领域，深度学习方法已成为黄金标准。然而，当前架构难以扩展；随着手部动作数量的增加，模型性能通常会下降。性能退化与解码扩展手势集的统计复杂性增加有关，并受到最先进方法局限性的加剧，这些方法主要依赖于低延迟的单模态卷积架构。卷积在局部操作，限制了模型捕获长距离序列模式的能力。单模态设置无法利用来自表征运动执行协调信号的互补信息，例如惯性数据和眼动追踪数据。这些局限性促使架构在跨模态生理序列中整合局部和全局特征。为弥补这一差距，本研究引入了EMG-CrossFormer，一种端到端的混合卷积-Transformer架构，用于无缝的多模态整合。EMG-CrossFormer通过级联交叉注意力融合层结合任意数量单模态编码器的表示，并使用可学习的手势查询解码融合后的表示。EMG-CrossFormer在四个NinaPro数据集（DB2、DB3、DB7和DB10）上进行了评估，并与六个最先进模型在使用递增模态数量下进行了基准比较。仅使用sEMG时，EMG-CrossFormer在DB2、DB3、DB7和DB10上的平均准确率分别为72.33%、52.48%、79.16%和73.49%。结合惯性信号后，性能提升至90.66%、80.40%、92.79%和92.06%。这些结果表明，联合局部-全局特征建模改善了仅sEMG解码，而多模态融合显著放大了这一优势，突显了这两种设计原则在复杂手部手势识别中的价值。

## Abstract
Hand gesture recognition via surface electromyography (sEMG) is fundamental to prosthetic control. In this field, deep learning approaches have become the gold standard. However, current architectures struggle to scale; model performance typically decreases as the number of hand movements increases. Performance degradation is tied to the increased statistical complexity of decoding expanded gesture sets and compounded by the limitations of state-of-the-art methods, which primarily rely on low-latency unimodal convolutional architectures. Convolutions operate locally, limiting model's ability to capture long-range sequential patterns. Unimodal setups cannot leverage complementary information from coordinated signals characterizing movement execution, such as inertial and eye-tracking data. These limitations motivate architectures that integrate local and global features across multimodal physiological sequences. To bridge this gap, this study introduces EMG-CrossFormer, an end-to-end hybrid convolutional-transformer for seamless multimodal integration. EMG-CrossFormer combines representations from an arbitrary number of unimodal encoders through cascaded cross-attention fusion layers, and decodes the fused representations using learnable gesture queries. EMG-CrossFormer was evaluated on four NinaPro datasets (DB2, DB3, DB7, and DB10) and benchmarked against six state-of-the-art models using an increasing number of modalities. Using only sEMG, EMG-CrossFormer achieved mean accuracies of 72.33%, 52.48%, 79.16%, and 73.49% on DB2, DB3, DB7, and DB10, respectively. Incorporating inertial signals improved performance to 90.66%, 80.40%, 92.79%, and 92.06%. These results show that joint local-global feature modeling improves sEMG-only decoding and that multimodal fusion substantially amplifies this benefit, underscoring the value of both design principles for complex hand gesture recognition.

- **研究背景**：表面肌电（sEMG）信号驱动的上肢假肢控制已有数十年临床历史，深度学习方法已成为当前研究中的主流方案。但现有深度模型普遍存在**扩展性差**的问题：随着需要识别的手势类别数量增加，模型性能显著下降。
- **核心瓶颈**：
  - 主流架构多为**单模态、低延迟卷积网络**，卷积的局部感受野限制了模型捕捉长程时序依赖的能力；
  - **单模态设置**（仅 sEMG）无法利用与运动执行高度相关的互补信号（如加速度计、眼动数据）；
  - 目前评估协议常省略相似手势（依据定量分类学），导致性能被高估，且缺乏可复现的公平基准。
- **研究意义**：论文旨在解决上述局限，提出一种**既能建模局部特征、又能捕捉全局时序依赖，且支持任意数量模态无缝融合**的统一架构，以提升复杂手势识别的准确性和假肢控制的实用性。

## 2. 论文提出的方法论

- **核心思想**：设计一个端到端的混合卷积-Transformer模型 **EMG-CrossFormer**，通过“局部特征提取 → 多模态交叉注意力融合 → 可学习查询解码”的流程，同时利用局部时空特征与全局上下文信息，并整合多模态生理信号。
- **四大模块**：
  1. **单模态骨干（Unimodal Backbone）**：将每个输入模态信号映射为紧凑的 token 序列（长度 L_m、嵌入维度 d）。论文尝试两种实现：
     - **1D 深度可分离卷积骨干（EMG-CF 1D）**：基于堆叠深度卷积+池化，低参数量，仅建模时间模式；
     - **2D 多尺度卷积骨干（EMG-CF 2D）**：将多通道信号视为伪图像，用多个并行卷积核捕捉多频率尺度时空特征。每个骨干后接线性投影层对齐嵌入维度。
  2. **融合模块（Fusion Layers）**：采用**级联的非因果 Transformer 解码器层**。首个主模态（sEMG）作为初始融合状态；对每个辅助模态，通过自注意力（更新当前融合表示）和交叉注意力（以融合表示作为 Query，辅助模态表示作为 Key/Value）逐步融合。辅助模态额外加入可学习的**模态 token** 以提供模态标识。融合后保持主模态的序列长度。
  3. **查询解码器（Query-based Decoder）**：借鉴 DETR 的思路，使用**可学习的手势查询（learnable gesture queries）**，通过自注意力（查询间）和交叉注意力（查询对融合表示）联合推理所有手势，输出解码表示。
  4. **前馈网络（FFN）**：对每个解码后的手势查询独立做类别预测，经 softmax 输出概率。
- **关键公式**（以文字说明）：
  - 模态表示先加位置编码，辅助模态再加模态 token（式1）；
  - 融合过程采用级联 Transformer 解码层，每层包括：自注意力（对当前融合表示）、交叉注意力（融合表示作为 Q，辅助模态作为 K/V）、前馈网络和层归一化（式2、式3）；
  - 训练损失为复合损失，包括带标签平滑的交叉熵、监督对比损失（作用于解码器和各编码器表示）、辅助交叉熵（融合和编码器中间输出）以及手写特征回归损失（L1）。
- **训练细节**：
  - 优化器为 LAMB，混合精度训练，梯度裁剪；
  - 数据增强采用信号扭曲（PCHIP 插值）；
  - 单模态设置中，将 sEMG 分为前臂（8通道）和上臂（4通道）两个“虚拟模态”以建模肌肉协同；多模态中 sEMG 保持完整，加速度计/眼动作为第二/第三模态。

## 3. 实验设计

- **数据集**：使用四个 Ninapro 公开数据集：
  - **DB2**：40名健康受试者，12通道 sEMG + 加速度计，40个手势+静息；
  - **DB3**：11名截肢患者（实际使用9名，剔除2名），同样 sEMG + ACC；
  - **DB7**：20名健康 + 2名截肢受试者，sEMG + ACC；
  - **DB10**：30名健康 + 15名截肢受试者，sEMG + ACC + **眼动凝视数据**，10种抓握+静息。
- **窗口设置**：100 ms、150 ms、200 ms，窗移 10%（90% 重叠）。
- **评估协议**：采用**受试者内**（intra-subject）划分：训练集用重复1、3、4、6（DB10另加7、8），测试集用重复2、5；指标为**平衡准确率**（同时报告 F1 和 Cohen's kappa）。
- **对比方法**：
  - 传统机器学习：SVM、随机森林（RF）；
  - 深度学习：Shallow CNN、ResNet-1D、MKCNN、NKDFF（NKDFF为多模态模型，可与 sEMG+ACC 比较）。
- **统计检验**：采用受试者级配对 Wilcoxon 符号秩检验 + Benjamini-Hochberg FDR 校正，报告均值配对差异和 bootstrap 置信区间。

## 6. 论文的主要结论与发现

- **sEMG-only 结果**：EMG-CF 2D 在所有数据集和窗口长度上均取得最高平衡准确率：
  - DB2：72.33%（200 ms）、DB3：52.48%（200 ms）、DB7：79.16%（200 ms）、DB10：73.49%（200 ms）。
  - 相对最强基线（RF 或 MKCNN）提升较小（约0.8–2.1 pp），但部分差异具有显著统计意义。
- **sEMG+ACC 结果**：多模态融合大幅提升性能：
  - DB2：90.66%、DB3：80.40%、DB7：92.79%（EMG-CF 1D）、DB10：92.06%（EMG-CF 2D，100 ms）。
  - 相比 sEMG-only 平均提升 15–30+ pp；截肢受试者（DB3）在 100 ms 窗口下提升达 31.43 pp。
- **加入眼动（DB10）**：对 EMG-CF 1D 有帮助，但对 EMG-CF 2D 并未超过 sEMG+ACC 的配置；作者认为眼动对预测意向更有价值，而非解码已执行动作。

- **总体结论**：联合局部-全局特征建模能改善 sEMG 解码；多模态融合显著放大该优势，是复杂手势识别和假肢控制的有效设计原则。

## 7. 优点

- **架构创新**：将卷积局部特征提取与 Transformer 全局建模结合，并通过级联交叉注意力进行多模态融合，避免了简单的特征拼接造成的模态利用不充分问题。

- **评估规范**：使用平衡准确率、配对统计检验、FDR校正、bootstrap CI，并公开代码和数据，强调可复现性。
