## 摘要
类人私密对话需要的不仅仅是流畅的响应生成：系统必须保持人设、关系、记忆、有限知识、特定媒介的时机，以及连贯的多轮主线。我们提出了AnthroDial，这是一个闭环框架，将拟人化对话表述为系统架构、可执行评估和诊断对齐的联合问题。它结合了(1)一个基于角色条件的调度式对话运行时，配备人设卡和场景卡、长期记忆、虚拟时间以及单次消息决策；(2)一个可执行基准，包含L0有效性门控、五个回合级维度和五个对话级维度；以及(3)一个后训练流水线，为SFT过滤出16,436个调度决策示例，并应用具有认知诊断和ZPD感知奖励的GRPO。该奖励为每个行为维度维护卡尔曼滤波的能力估计，对能力缺陷较大的维度赋予更高权重，并使用rollout分数作为任务级ZPD匹配，以将优化集中在可学习的薄弱技能上。在一个包含55个人设、50个场景、50个人设-场景绑定以及每个模型100个角色条件案例的基准上，我们评估了16个系统，涵盖前沿基线、开放模型、思考/不思考变体以及SFT/RL消融。最强的未训练基线达到32.00%的严格ACC，而Qwen3.6-27B-SFT+RL达到39.00%的严格ACC和98.5的综合得分。在9B不思考设置中，SFT和RL将严格ACC从0.00%提高到13.00%和18.37%。这些结果表明，当生成、评估和奖励塑形共享相同的行为维度时，拟人化对话将受益匪浅。

## Abstract
Human-like private chat requires more than fluent response generation: a system must preserve persona, relationship, memory, bounded knowledge, medium-specific timing, and a coherent multi-turn arc. We present AnthroDial, a closed-loop framework that formulates anthropomorphic dialogue as a joint problem of system architecture, executable evaluation, and diagnostic alignment. It combines (1) a role-conditioned scheduled dialogue runtime with persona and scenario cards, long-term memory, virtual time, and single-draft message decisions; (2) an executable benchmark with an L0 validity gate, five per-turn dimensions, and five dialogue-level dimensions; and (3) a post-training pipeline that filters 16,436 scheduled-decision examples for SFT and applies GRPO with a cognitive-diagnostic, ZPD-aware reward. The reward maintains Kalman-filtered capability estimates for each behavioral dimension, upweights dimensions with larger capability deficits, and uses rollout scores as task-level ZPD matches to focus optimization on learnable weak skills. On a benchmark with 55 personas, 50 scenarios, 50 persona-scenario bindings, and 100 role-conditioned cases per model, we evaluate 16 systems spanning frontier baselines, open models, thinking/no-think variants, and SFT/RL ablations. The strongest non-trained baseline reaches 32.00% strict ACC, while Qwen3.6-27B-SFT+RL reaches 39.00% strict ACC and a 98.5 overall score. In the 9B no-think setting, SFT and RL improve strict ACC from 0.00% to 13.00% and 18.37%. These results show that anthropomorphic dialogue benefits when generation, evaluation, and reward shaping share the same behavioral dimensions.

## 1. 核心问题与研究动机

### 1.1 核心问题
- **拟人化对话不仅是“流畅应答”**：现有对话系统能生成流利、礼貌、完整的回复，但在私密聊天场景中仍不像一个真实的人——存在过度解释、急于总结、助手口吻、社交不当、忘记已建立事实、人设漂移、违背媒介约束、生硬结束对话等行为偏差。
- **拟人化是一个多维系统属性**：不仅要生成语法正确的语句，还必须同时满足人设（persona）、人际关系、长期记忆、有限知识、媒介节奏（如微信聊天）、虚拟时间状态和多轮对话弧（dialogue arc）的一致性。
- **现有方法缺乏闭环机制**：一般对话系统将生成、评估、偏好对齐分开处理，导致评估结果难以反馈到训练中，无法针对具体薄弱行为维度进行定向优化。

### 1.2 核心定义
- 论文将“拟人化对话”定义为**行为层面的可观测约束满足**，而非本体论意义上的“像人”：即系统生成的对话是否满足特定人设、关系、场景、历史、媒介和时间状态下真实人际交流的可观测约束，不涉及意识、情感或人类身份声明。

### 1.3 研究动机
- 拟人化对话需要**架构（runtime）、评估（benchmark）、对齐（alignment）三者统一设计**，并且让评估诊断结果直接驱动训练信号，形成闭环。
- 作者提出 AnthroDial 框架作为这一思路的具体实现，目标是让生成、评估、奖励塑形共享同一套行为维度，从而系统性地提升拟人化质量。

## 2. 方法论

### 2.1 核心思想
- **闭环框架**：将拟人化对话的构建分为三个相互耦合的环节——
  1. **对话运行时（Runtime）**：模拟具有人设、记忆、虚拟时间、调度机制的私聊系统；
  2. **可执行基准（Executable Benchmark）**：以 L0 有效性门控 + 五维局部 + 五维全局的层级评估来度量拟人化质量；
  3. **对齐层（Alignment）**：将评估结果转化为 SFT 数据和 CDT-ZPD 感知的 GRPO 奖励，用于后训练。
- **核心设计理念**：生成、评估、训练信号共享同一套行为维度，使系统能对薄弱维度进行定向优化。

### 2.2 问题形式化
- 对话实例的条件上下文为：
  - **c = (p_a, p_b, s, m_a, m_b, h<t, τ)**，其中 p 为人设卡，s 为场景卡，m 为长期记忆，h<t 为历史，τ 为虚拟时间状态。
- 模型输出为一个“待发送草稿决策”（scheduled draft decision）：
  - **y_t = (u_t, Δt_t, e_t)**，其中 u_t 为文本消息，Δt_t 为预计发送延迟，e_t 为沉默/结束决策。
- 对话质量定义：
  - **L0 门控 g(D)**：若对话包含致命失败（如暴露 AI 身份、违反媒介约束、硬重复、角色矛盾、危险建议、将旧记忆当作当前事件），则该对话视为无效；
  - 通过 L0 后，按加权评分公式 **Q(D) = Σ w_d q_d(D)** 计算综合分数。

### 2.3 核心架构组件
- **角色条件调度式对话运行时**：
  - 人设卡（身份、年龄、职业、性格、兴趣、弱话题、表达习惯、知识边界）；
  - 场景卡（关系、地点假设、触发事件、情绪基调、对话目标、预期时长）；
  - 长期记忆（对特定对象的持久印象，经记忆更新器 U_φ 逐轮更新）；
  - 短期会话记忆压缩（F_ψ 将超长历史折叠为摘要，保留关键事实、情绪变化、承诺和未解决问题）；
  - 虚拟时间（模拟快速回应、延迟回应、被打断、离线状态、长停顿和自然结束）。
- **单草稿调度机制（Single-Draft Scheduling）**：
  - 每个说话者最多持有一个未发送草稿 b_{i,n} = (u_{i,n}, a_{i,n}, e_{i,n})，其中 a_{i,n} 为绝对虚拟发送时间；
  - 调度器每次发送最早待发送草稿；对方收到消息后被唤醒，并可选择保留、修改或替换自己的未发送草稿；
  - 该机制将时间、沉默、打断、自我跟进、结束等行为显式建模为模型输出，而非提示词的隐式副作用。
- **技能演化（Skill Evolution）**：失败样本按维度归属到技能文件，通过多数归因选择待更新技能，并由 E_ω 更新技能文本；下一轮合成数据生成会使用更新后的技能，使评估结果成为生成的反馈源。

### 2.4 评估基准设计
- **L0 有效性门控**：由 10 条硬/主要约束组成，致命约束直接判无效（AI 身份暴露、媒介违规、非共处宣称、输出格式违规、硬重复、人设硬事实矛盾、安全违规等）。
- **5 个局部维度（D1–D5）**：对话自然度、内容简洁与信息密度、人设一致性、知识与行为边界、分段与节奏；
- **5 个全局维度（E1–E5）**：上下文事实一致性、场景与关系适配、社会情感适配、主动性、对话弧可用性。
- 每个维度由细粒度复选框组成，维度分数为通过复选框占比；最终综合分数为 S = 100 × (0.5·Sturn + 0.5·Sdialogue)；严格 ACC 要求所有复选框全部通过。

### 2.5 训练流水线
- **SFT 数据构造**：
  - 共 16,436 个调度决策样本（content + delay + closure），每个样本来自运行时保存的独立 SFT 记录；
  - 覆盖 334 张唯一场景卡、261 张唯一人设卡、400 个定向角色对；
  - 数据来源为通过严格过滤（L0 通过 + 全局满分 + 局部 >0.95）的接受对话，以及经修复重新验证的对话。
- **RL 阶段：CDT-ZPD 引导的 GRPO**：
  - 每个行为维度维护一个卡尔曼滤波的能力估计 θ_{k,t}，平滑噪声观测并跟踪能力变化；
  - **能力缺陷加权**：d_{k,t} = 1.20 − θ_{k,t}，对历史能力较低的维度赋予更高奖励权重；
  - **ZPD 匹配因子**：ω_{k,t}(D) = exp(−(ẑ_k(D) − θ_{k,t})² / 2σ²_k)，当前任务分数接近能力估计时给予最大权重，集中于“正在发展区”的技能；
  - 每个组（局部/全局）内做自适应权重归一化；
  - 组奖励 = 0.9×加权连续分数 + 0.1×严格全通过信号；
  - 最终奖励 = 0.7×R_legacy + 0.3×R_CDT-ZPD，兼顾传统质量锚定和薄弱维度适应性优化。

- **局部流畅性与全局拟人质量脱钩**：9B SFT+RL no-think 在 D1/D2/D5 局部维度得分很高，但在全局上下文一致性 E1、场景适配 E2 等维度明显落后；仅靠局部自然不能保证整体对话可信。
- **后训练能带来超越测试时思考的行为改变**：27B 思考模式下，SFT+RL 相比 SFT 大幅提升严格 ACC；9B 不思考模式下，SFT/RL 从 0% 提升至 18.37%，说明训练内化拟人行为是有效的。
- **主动性不是简单“多问问题”**：持续追问“然后呢”往往是规划能力弱的表现；真正的主动性可表现为自我披露、轻微打趣、话题转换、行动提议或优雅收尾。
- **有效性（validity）与质量应分开报告**：多个模型在有效样本上得分高但有效样本率很低，作为合成数据生成器仍不可靠；对数据构建而言 L0 有效率与平均分同样重要。
- **类别严格 ACC 暴露剩余困难场景**：完整系统在科技类严格 ACC 为 0.0%、财经为 12.5%，即使连续分数已很高——说明这些场景中存在某个必查约束难以同时满足。

## 7. 优点

- **闭环设计**：将生成、评估、训练信号统一到同一行为维度体系，使评估诊断结果直接驱动数据筛选和奖励塑形，而非仅作为离线报告指标。
- **拟人对话问题建模较完整**：将人设、关系、记忆、虚拟时间、消息节奏、沉默/中断/自我跟进/结束等行为显式建模为可执行输出，而非提示词副产品。
- **单草稿调度机制设计精巧**：使多消息爆发、等待、修改草稿、被中断后丢弃草稿等私聊行为成为可观测、可评判的模型输出。
- **L0 门控 + 分级评分分离了“有效”与“质量”**：既能生成高质量训练数据，又可保留失败样本用于修复、偏好构建和回归测试。
- **CDT-ZPD 奖励设计有理论依据**：将认知诊断（Kalman 滤波能力估计）、最近发展区（ZPD 匹配）、精通学习（弱技能加权）三者结合，使 RL 奖励动态聚焦于“弱但可学”的技能，而非一味拉高已强维度。
- **消融设计能区分测试时思考与训练效益**：27B think 和 9B no-think 双轨设计提供了不同部署需求的验证。
- **报告粒度丰富**：模型级、维度级、类别级、逐案例轨迹四个层级均有报告，且失败样本留下裁判理由文本，便于审计与修复。

## 8. 不足与局限

- **算力与训练细节缺失**：未报告 GPU 型号、数量、训练时长、RL rollout 批次大小、观测噪声参数选择依据等关键复现信息。
- **评估依赖单一自动裁判**：Qwen3.5-397B 作为唯一评判者可能存在长度、位置、风格、模型家族偏见；论文承认自动裁判可能有偏，且未提供与人类评估的一致性指标。
- **统计效能有限**：每模型仅 100 案例（每人设/场景仅约 2 例），严格 ACC 的类别分析受小样本影响较大；未报告置信区间和显著性检验。
- **跨规模/跨模式比较受限**：27B 轨道用 think、9B 轨道用 no-think，两轨道的优势不可直接归因于模型规模或推理模式，论文也承认此混合设计。
- **“修复后数据”的过滤标准偏严**：要求对话级平均分 = 1.0 且回合平均 >0.95，可能降低数据多样性；技能演化若过拟合基准产物也可能削弱泛化性。
- **媒介与文化特异性**：当前基准围绕中文微信风格私聊构建，较强的结论仅适用于该媒介；论文虽声称框架可迁移到其他媒介，但未做实证验证。
- **合成数据自举风险**：模型生成的数据再用于训练，可能放大自我偏差或基准伪影（benchmark artifact）。
- **伦理边界仅靠基准约束不足**：论文承认拟人化系统有欺骗和过度信任风险，但指出部署策略必须与基准优化分离，本工作不解决部署层面的披露与监管问题。
