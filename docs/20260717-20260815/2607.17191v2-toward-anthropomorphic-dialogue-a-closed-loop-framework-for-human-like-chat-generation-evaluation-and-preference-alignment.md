## 摘要
类人私密对话不仅仅需要流畅的回复生成：系统必须保持人格、关系、记忆、有限知识、特定媒介的时序以及连贯的多轮叙事弧。我们提出AnthroDial，一个闭环框架，将拟人化对话表述为系统架构、可执行评估和诊断性对齐的联合问题。它结合了(1)一个基于角色条件调度的对话运行时，包含角色与场景卡片、长期记忆、虚拟时间和单稿消息决策；(2)一个可执行基准，具有L0有效性门控、五个回合级维度和五个对话级维度；(3)一个后训练流水线，筛选16,436条调度决策示例用于SFT，并应用带认知诊断和最近发展区(ZPD)感知奖励的GRPO。该奖励维持每个行为维度的卡尔曼滤波能力估计，对能力缺陷较大的维度加权，并使用rollout得分作为任务级ZPD匹配，以将优化集中在可学习的薄弱技能上。在一个包含55个角色、50个场景、50个角色-场景绑定以及每个模型100个角色条件案例的基准上，我们评估了16个系统，涵盖前沿基线、开放模型、思考/不思考变体以及SFT/RL消融。最强未训练基线达到32.00%严格准确率，而Qwen3.6-27B-SFT+RL达到39.00%严格准确率和98.5总分。在9B不思考设置中，SFT和RL将严格准确率从0.00%提升至13.00%和18.37%。这些结果表明，当生成、评估和奖励塑形共享相同的行为维度时，拟人化对话会受益。

## Abstract
Human-like private chat requires more than fluent response generation: a system must preserve persona, relationship, memory, bounded knowledge, medium-specific timing, and a coherent multi-turn arc. We present AnthroDial, a closed-loop framework that formulates anthropomorphic dialogue as a joint problem of system architecture, executable evaluation, and diagnostic alignment. It combines (1) a role-conditioned scheduled dialogue runtime with persona and scenario cards, long-term memory, virtual time, and single-draft message decisions; (2) an executable benchmark with an L0 validity gate, five per-turn dimensions, and five dialogue-level dimensions; and (3) a post-training pipeline that filters 16,436 scheduled-decision examples for SFT and applies GRPO with a cognitive-diagnostic, ZPD-aware reward. The reward maintains Kalman-filtered capability estimates for each behavioral dimension, upweights dimensions with larger capability deficits, and uses rollout scores as task-level ZPD matches to focus optimization on learnable weak skills. On a benchmark with 55 personas, 50 scenarios, 50 persona-scenario bindings, and 100 role-conditioned cases per model, we evaluate 16 systems spanning frontier baselines, open models, thinking/no-think variants, and SFT/RL ablations. The strongest non-trained baseline reaches 32.00% strict ACC, while Qwen3.6-27B-SFT+RL reaches 39.00% strict ACC and a 98.5 overall score. In the 9B no-think setting, SFT and RL improve strict ACC from 0.00% to 13.00% and 18.37%. These results show that anthropomorphic dialogue benefits when generation, evaluation, and reward shaping share the same behavioral dimensions.

该论文聚焦于**拟人化对话系统**的构建问题。研究动机是：现有人机对话系统虽然在流畅性、指令遵循能力上不断提高，但在真实私聊场景下仍存在明显短板。

具体问题包括：

- **过度解释与总结**：模型倾向于像助手一样回答，带有"助理姿态"，而不是像真实人类那样自然对话
- **缺乏人设一致性**：模型常因忽略人物性格、关系、偏好而"出戏"
- **记忆与时间缺陷**：模型会重复提问、遗忘已确立的事实、把旧记忆当作当前事件处理
- **媒介约束缺失**：不遵守私聊礼仪（即时回复、延迟、打断、沉默等），没有自然的对话节奏
- **对话弧线不完整**：无法自然推进对话或合理地结束交流

论文将"拟人化对话"定义为**行为层面的属性**，而非本体论意义上的"像人"：它并不声称系统具有意识或情感，而是要求生成的可观察对话行为满足特定约束，使交互看起来像真实人际交流。

论文的核心主张是：要使对话拟人化，需要**生成、评估与对齐三者共享同一套行为维度**，形成闭环约束，而非将拟人化视为单一指标或仅靠风格转换问题。

## 2. 方法论

### 2.1 核心思想：三层闭环框架

AnthroDial框架包含三个耦合组件，形成一套单一流水线：

| 层级 | 功能 | 关键机制 |
|------|------|----------|
| **角色条件调度运行时** | 生成拟人化对话 | 角色卡片、场景卡片、长期记忆、虚拟时钟、单稿调度 |
| **可执行基准** | 评估拟人化行为 | L0有效性门控 + 5个逐轮维度 + 5个对话级维度 |
| **后训练对齐层** | 训练模型 | SFT + CDT-ZPD引导GRPO，使用诊断性奖励 |

### 2.2 关键设计：状态表示与单稿调度

对话实例的条件化上下文为：
```
c = ( pa, pb, s, ma, mb, h<t, τ )
```
其中 pa/pb 是角色卡片（人格、年龄、职业、言论习惯等），s 是场景卡片（关系、触发事件、情绪基调），ma/mb 是长期记忆，h<t 是对话历史，τ 是虚拟时间状态。

**模型必须在决策步骤输出一个带计划的"草稿决策"：**
```
yt = ( ut, Δtt, et )
```
其中 ut 是消息文本，Δtt 是计划发送延时，et 是沉默或结束指令。这一设计使时序、沉默、打断、自我追问、结束对话等行为变成模型的显式输出，而非提示词的隐性副作用。

**每个说话者最多维护一个待发送草稿**，调度器按最早的绝对发送时间发出消息。若接收者已有未发送草稿，则需保留、修改或替换它。这种"单稿调度"机制暴露了普通逐轮生成所掩盖的行为模式（等待、快速追问、事件打断后丢弃过期草稿、自然结束对话）。

### 2.3 智能评估：分层检查与诊断

**L0 有效性门控**（可执行性检查）：过滤致命失败样本，包括AI身份泄露、文本媒介违规（声称发送图片/链接）、同处一室幻觉、输出格式错误、硬重复、人设硬事实冲突、安全/伦理违规等。L0门控将"样本是否有效"与"有效样本质量多高"**分开报告**。

**十个行为维度**（五个局部 + 五个全局）：

- **局部 D1–D5**：口语自然度、简洁信息密度、人设一致性、知识与行为边界、分段与节奏
- **全局 E1–E5**：事实与时间线一致性、场景与关系契合、社交情感适配、主动性、对话弧线可用性

**分数计算**：每个维度含若干二分检查项，逐轮评分使用五回合上下文窗口，全局评分针对完整对话。严格ACC要求所有维度所有检查项全部通过，与连续分数分开报告。

### 2.4 训练：CDT-ZPD 引导 GRPO

**SFT 阶段**：从接受（pass）和修复后重新验证的对话中提取 16,436 条调度决策示例，训练内容与延时和结束行为。

**RL 阶段核心：认知诊断 + 最近发展区(ZPD)感知奖励**

- **卡尔曼滤波能力估计**：对每个维度（D1–D5、E1–E5）维护潜伏能力估计 θk,t，利用批平均分数通过标量卡尔曼滤波平滑更新
- **能力缺陷加权**：缺陷乘子 dk,t = 1.20 − θk,t，对历史上较弱维度施加更大的奖励压力
- **ZPD匹配项**：对当前rollout，用该维度得分作为当前任务可达性的经验估计，计算与能力估计的高斯匹配因子，使奖励集中在"当前能力可学习"的任务上：
```
ωk,t(D) = exp[−(ẑk(D) − θk,t)² / 2σ²k]
```
- **最终奖励混合**：R = 0.7·Rlegacy + 0.3·RCDT-ZPD，其中 Rlegacy 使用固定权重，RCDT-ZPD 使用自适应权重。

## 6. 主要结论与发现

1. **闭环框架有效性**：Qwen3.6-27B-SFT+RL（思考模式）达到 39.00% 严格ACC 和 98.5 总分，较最强非训练基线（Gemini-3.5-Flash，32.00%）提升7个百分点。

2. **后训练先于测试时思考**：27B思考模式下，SFT使严格ACC从16.00%升至19.00%，SFT+RL大幅提升至39.00%；9B无思考模式下，SFT+RL将严格ACC从0.00%提升至18.37%。RL带来的行为改进不能归因于更长推理。

3. **局部流畅与全局拟人质量脱节**：9B SFT+RL无思考模型在D1（自然度）、D2（简洁性）、D5（节奏）上取得最强均分，但E1（上下文一致性）、E2（场景契合）、E3（社交情感）仍较弱，说明单轮自然不等于整体拟人。

4. **主动性不等于多问问题**：E4结果表明，有效主动性可通过分享个人反应、轻调侃、推进话题、提出行动方案或优雅结束来实现，反复追问反而是对话规划薄弱的信号。

5. **有效性与质量需分开报告**：部分模型在有效案例中得分高但有效案例占比低，作为数据生成器仍不可靠，支持L0门控与质量评分分离的设计。

6. **类别间存在剩余难点**：即使在连续分数高的科技和理财类别，严格ACC仍然很低（科技0.0%、理财12.5%），揭示了平均质量掩盖的对齐缺陷。

## 7. 优点

- **维度统一性**：生成、评估与奖励共享同一套十个行为维度，保证了"测什么→练什么→评什么"的闭环一致性，是方法论上的一大亮点。
- **可执行行为评估**：将评判标准从模糊的整体印象细化为具体的二分检查表和L0致命约束，使评估可复现、可审计、可诊断。
- **调度作为一等公民**：将时序、沉默、打断显式纳入模型输出空间，而非仅靠提示词，这一设计更真实地反映私聊行为。
- **诊断式奖励设计**：卡尔曼滤波跟踪能力 + 能力缺陷加权 + ZPD匹配的组合，将"评估痕迹"转化为适应性训练信号，避免了聚合分数掩盖弱维度的问题。
- **分级报告体系**：有效性与质量分开、连续分数与严格接受率分开、逐维度与逐类别报告，有效避免"平均分掩盖缺陷"的评估陷阱。
- **单一评审模型的零温度控制**：降低了评分方差，提高了模型间比较的稳定性。
