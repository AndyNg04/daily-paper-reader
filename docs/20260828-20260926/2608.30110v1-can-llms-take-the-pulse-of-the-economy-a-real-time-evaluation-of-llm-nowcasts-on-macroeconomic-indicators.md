## 摘要
对主要宏观经济指标进行即时预测，即在官方发布前估计指标在当前参考期的取值，对货币政策和金融市场至关重要，各国央行也投入专门的经济学家团队来生成此类估计。大语言模型（LLM）智能体是完成这一任务的有前景的候选者，它们将广泛的世界知识与实时网络搜索相结合，并支持比机构即时预测更高频率的查询。然而，评估其即时预测能力颇具挑战：GDP 和 CPI 等主要指标被广泛报道，并可能在预训练期间被记忆，因此任何基于历史发布数据的评估都容易受到数据污染的影响。为解决这一问题，我们提出 LiveMacroEval，一个实时、抗污染基准，其中 LLM 智能体在截至每次官方发布的发布前窗口内，为十六个美国主要宏观经济指标生成逐小时即时预测。即时预测质量通过基于公告窗口股票收益的 LiveMacro Score 和来自模拟 Polymarket 风格交易的 LiveBetting Score 进行评估，并以美联储地区银行的即时预测、彭博 ECOS 专业共识以及 auto-ARIMA 基线作为对照。在为期六个月、使用四个配置了网络搜索的最先进 LLM 智能体的情况下，总体即时预测准确率与机构及专业基准大致相当，而不同单项指标的表现差异很大。这凸显了 LLM 智能体作为宏观经济状况实时估计器的潜力。

## Abstract
Nowcasting headline macroeconomic indicators, i.e., estimating an indicator's value for the current reference period before its official release, is critical for monetary policy and financial markets, and central banks devote dedicated teams of expert economists to producing such estimates. Large language model (LLM) agents are a promising candidate for this task, combining broad world knowledge with real-time web search and supporting queries at higher frequency than institutional nowcasts. Evaluating their nowcasting capability is, however, challenging: headline indicators such as GDP and CPI are widely reported and likely memorized during pretraining, so any evaluation on historical releases is vulnerable to data contamination. To address this, we introduce LiveMacroEval, a live, contamination-resistant benchmark in which LLM agents produce hourly nowcasts for sixteen major U.S. macroeconomic indicators over a pre-release window closing at each official release. Nowcast quality is assessed through a LiveMacro Score against announcement-window equity returns and a LiveBetting Score from simulated Polymarket-style trading, with Federal Reserve regional-bank nowcasts, the Bloomberg ECOS professional consensus, and an auto-ARIMA baseline as comparators. Over six months with four state-of-the-art LLM agents configured with web search, aggregate nowcast accuracy is broadly comparable to the institutional and professional benchmarks, with performance varying widely across individual indicators. This highlights LLM agents' potential as real-time estimators of macroeconomic conditions.

## 二、方法论：核心思想与关键技术细节

### 1. 核心思想
- **实时抗污染设计**：每个指标的预测窗口从参考月最后一周开始，在官方发布时刻关闭（跨度数周至数月）。窗口内所有预测均在严格实时流程中生成，目标值尚未发布，因此不可能进入训练语料或检索内容，抗污染性由构造保证。
- **高频逐小时即时预测**：智能体每小时生成一次预测，形成完整的发布前修订轨迹，而非单一终点预测。
- **从预测误差到市场相关收益**：摒弃传统 MSE/MAE，提出两个根植于经济学与金融学理论的指标。

### 2. 关键技术细节

**（1）LiveMacro Score（基于公告窗口股票收益）**
- 动机：宏观发布的"意外成分"（发布值减去专业共识）因果性地驱动股价，而发布水平本身已被共识定价。
- 标准化意外：$S_i = (X_i - X_i^c)/\sigma_i$，其中 $\sigma_i$ 为历史意外标准差。
- 市场反应 $r$：以 E-mini S&P 500 期货在发布时点 $[-5, +30]$ 分钟窗口内的对数收益度量，遵循高频事件研究惯例以隔离因果效应。
- 历史回归（无截距）：$r = \sum_i \beta_i S_i + u$，使用 **Huber-ridge 稳健回归**在 2010 年 1 月至 2025 年 10 月的 2,163 个时间戳分组事件上估计并冻结。
- 评分公式（有界 out-of-sample $R^2$ 变体）：
  $$\text{LiveMacro} = \frac{SS_{cons} - SS_{model}}{SS_{cons} + SS_{model}}$$
  其中 $SS_{model} = \sum_g (r_g - \hat{r}_g)^2$，$SS_{cons} = \sum_g (r_g - r_g^c)^2$。+1 为完美预测，0 与共识持平，趋近 -1 为远差于共识。
- **经济含义**：$\beta_i$ 自动为高市场影响力指标（CPI、非农、GDP）加权，为低影响力指标降权，使 16 个指标可汇总为单一可比较数字。

**（2）LiveBetting Score（模拟 Polymarket 交易）**
- 每个指标对应一组互斥数值桶，每个桶为二元合约（命中支付 1 美元）。
- 每小时在发布前，将 1 美元押在包含智能体最新预测的桶上，以市价 $p$ 买入 $1/p$ 份。
- 累计收益：$R_i = \frac{1}{N_i}\sum_\tau \left(\frac{\mathbb{1}\{\hat{b}_i(\tau)=b_i^\star\}}{p_{\hat{b}_i(\tau)}(\tau)} - 1\right)$
- **设计意图**：桶价即群体隐含概率，流动性已内化于收益中——只有真正"战胜人群"才能获得高回报。

**（3）智能体设计**
- 基础配置：单一网络搜索智能体，系统提示设定角色与输出纪律，用户提示提供目标月、发布月、变量单位、规模护栏与严格输出格式。
- 每小时发出两次独立调用（产出核心组 / 需求与部门组），隔离故障并控制输出长度。
- 进阶配置：工具增强智能体（接入金融分析插件）、多智能体团队（编排者 + 研究者 + 独立验证者）。

## 六、主要结论与发现

1. **总体精度与专业共识相当**：GPT-5 以 +0.004 的 LiveMacro Score 领先，与 Bloomberg ECOS 共识在统计上不可区分（打平）；其余 LLM 略低于共识但高于 auto-ARIMA（Qwen3-80B 除外）。
2. **逐指标表现差异极大**：平均智能体仅在 4/16 指标上贡献为正（ISM 制造业、成屋销售、建筑许可、工业生产）；CPI、零售销售、PCE 价格指数合计占其缺口的 87%。
3. **主题异质性明显**：在供给与生产、住房主题上 LLM 显著超越共识；在需求与通胀上普遍落后（仅 GPT-5 接近零）；劳动力市场得分聚集在零附近。
4. **LiveBetting 上具竞争力**：在实际 GDP 上，4 个 LLM 均获正累计收益，其中 3 个击败亚特兰大 GDPNow（仅纽约联储领先）；在失业率上，领先 LLM 超过芝加哥联储 CHURN；但 CPI 上顶级经济学家模型（克利夫兰联储、Bloomberg）仍全面领先。
5. **修订轨迹可解释**：GPT-5 对 2026 年 3 月 CPI 的预测在 4 月 8 日 EIA 石油报告与 FOMC 纪要发布窗口内从约 2.7% 跳升至约 3%，方向与幅度均与汽油分项贡献估算一致。
6. **多智能体团队是唯一超越共识的配置**：其预测意外幅度更小（0.26 vs 实际 0.62）、方向正确率更高（54% vs 普通提示 38%），验证了"规模与方向权衡"的理论条件 $\kappa < 2\phi$。
7. **复制检验排除抄袭**：终端缺口中位数 0.42σ，修订共动相关性中位数仅 0.11，大修订在美联储发布时点呈反聚集（$\Delta_{share} < 0$）。

## 七、优点（方法或实验设计的亮点）

- **抗污染设计由构造保证**：严格发布前实时评估，从根本上规避了历史数据记忆问题，为经济相关实时任务提供了可复制的评测范式。
- **指标设计有理论根基**：LiveMacro Score 基于高频事件研究识别因果效应，用 $\beta_i$ 自动按市场影响力加权；LiveBetting Score 用逆价格收益经济学，直接度量"战胜人群"能力，避免误差尺度不可比问题。
- **系统性的替代解释排除**：附录 F 的三项复制检验、附录 G 的引用构成分析、附录 K.4 对传统误差聚合器失效原因的量化论证，显著提升了结论可信度。
- **高频轨迹带来可解释性**：逐小时预测使事件研究式归因成为可能，将预测修订与具体经济事件（EIA 报告、FOMC 纪要）绑定，兼具科学发现价值。
- **公平的基线对齐**：终值快照设计与 Bloomberg 终值共识对齐信息集；附录 H 透明披露各基线可用信息；附录 T 完整记录数据许可与使用条款。
- **理论与实证结合**：附录 S.3 给出 LiveMacro Score 的精确分解 $\text{Score} > 0 \iff \kappa < 2\phi$，将"多智能体为何胜出"从描述性观察提升为可检验的代数条件。

## 八、不足与局限

- **发布事件数量有限**：实时抗污染设计决定了高价值发布仅月度/季度一次，六个月窗口的发布事件数在统计上偏少；这是结构性约束而非数据集选择，无法在不牺牲时间效度的前提下完全消除。
- **地域覆盖单一**：全部指标与参考即时预测均为美国口径。作者指出欧元区是可自然扩展的方向（Eurostat、ECB SPF、Eurosystem 即时预测），但未在本文实施。
- **指标间表现高度不均**：在通胀类指标上存在结构性劣势（锚定预期机制 + 克利夫兰联储专用油气模型），在急转弯月份（耐用品、工业生产、零售销售）四智能体同向犯错，说明方法尚不稳健。
- **智能体设计实验样本小**：三种配置仅共同运行约一个月，每设计仅单一实时配置观测，非多随机种子受控实验；多智能体团队成本约 15 分钟/次，优势伴随成本。
- **工具增强实验受限**：金融分析插件未提供付费数据订阅凭证，结果仅界定免费层配置，不能推广至完全授权配置。
- **算力披露不足**：未报告 GPU 型号、数量或推理总时长，虽然评估为 API 推理，但复现成本信息缺失。
- **潜在偏差风险**：LLM 理由分析为自我报告，记录的是智能体声称的行为而非实际生成机制；事件窗口识别的因果解释依赖高频事件研究的标准识别假设。
- **评分构造的视野敏感性**：抽样 bootstrap 下 GPT-5 点估计从 +0.004 降至 -0.010，说明评分对信息集对齐方式敏感，作者将其归因于构造性不对称而非预测质量下降，但这一解释本身仍需更多检验。
