## 摘要
对话式任务助手（CTAs）是多模态对话系统，通过语音、文本、图像和视频交互，支持用户完成烹饪和DIY等复杂的现实世界任务。此前的用户研究主要集中于受控环境，导致对真实世界中CTAs大规模使用情况的理解有限。在本工作中，我们基于数千名真实环境中的用户，开展了一项关于CTA使用的大规模研究。我们对大规模真实世界数据的分析揭示了以下方面的新认识：(i) 用户与CTA的交互流程，(ii) 用户意图，(iii) 用户对话特征，以及 (iv) 与用户满意度相关的行为因素。我们的发现揭示了CTAs未来研究的关键机会，特别是在用户交互设计和任务参与方面，并以具体的设计指南作为结论。

## Abstract
Conversational Task Assistants (CTAs) are multimodal dialogue systems that support users in complex real-world tasks such as cooking and DIY through voice, text, image, and video interactions. Prior user studies have focused on controlled settings, leaving limited understanding of real-world CTA usage at scale. In this work, we present a large-scale study of CTA usage based on thousands of users in-the-wild. Our large-scale real-world data analysis unveils new understandings of (i) user-CTA interaction flows, (ii) user intents, (iii) user conversational traits, and (iv) behavioral factors associated with user satisfaction. Our findings reveal key opportunities for future research in CTAs, particularly in user interaction design and task engagement, concluding with concrete design guidelines.

## 2. 方法论

### 2.1 核心思想
以"大规模真实使用数据 + 多维度行为刻画"替代受控实验，通过系统级阶段追踪与用户特征分类体系，定量描述用户行为并识别与满意度相关的信号。

### 2.2 系统设计（数据来源系统 TWIZ-v2）
- **三大设计原则**：模块化架构、多模态集成、上下文感知响应。
- **模块化架构**：基于 Cobot 框架，服务端无函数编排对话管理与模块访问；数据库保存对话历史，搜索系统负责任务检索。
- **对话管理**：事件驱动、基于阶段的状态机，分两大宏观阶段：
  - *Task Grounding*：Greeting、Task Search、Task Overview；
  - *Task Execution*：Task Steps、Task Completed。
  - 支持 Q&A 与多模态交互子流程，允许临时偏离主流程而不失对话连续性。
- **意图检测**：结合 BERT 神经分类器、音素级相似度信号与规则启发式的投票式决策机制，以应对语音系统的 ASR 错误。
- **任务建议与搜索**：混合搜索（文本 + 语义），内容来自 WikiHow（DIY）与 Whole Foods Market（食谱）。
- **多模态交互**：LLM 驱动的任务问答（结合对话上下文提示）、趣味事实、基于跨模态文本-视觉嵌入相似度的视频帧检索与控制。
- **响应设计**：模板 + LLM 生成，控制长度与措辞多样性；命令置于句末以助记忆；用启发式 + RoBERTa 攻击性语言分类器做安全检测。
- **自适应任务分块**：按长度与格式线索切分步骤，降低认知负荷，适配语音交互的工作记忆限制。

### 2.3 数据分析方法
- **数据过滤**：仅保留 ≥3 轮的对话，剔除超过 10% 轮次与 CTA 功能无关（如音乐、智能家居）的会话。
- **四维分析框架**：(1) 用户–CTA 交互流程；(2) 用户意图分布；(3) 用户对话特征（采用 [11] 的八种用户特征分类体系）；(4) 用户满意度行为因素。
- **满意度建模**：在 Choi 等 [7] 的通用特征基础上扩展 CTA 特有信号（意图、任务阶段、用户特征），共 **39 个特征**，用 Spearman 相关分析特征与评分的关联。
- **评分主观性评估**：抽样 100 段对话（每评分等级 20 段，触摸输入 <20%），由 3 名标注者以用户视角独立评分，采用 Spearman 相关、一致率与 Fleiss' κ 评估。

## 6. 主要结论与发现

- **交互流程**：
  - 对话在阶段间呈递减趋势，从 Search/Task Overview 到 Task Steps 流失尤为明显，说明大量用户处于探索/评估状态而非真正执行任务。
  - Task Steps 是交互最密集阶段（占 29.7% 轮次）；Search 次之。
  - 用户 **68.5%** 的交互时间花在 Task Grounding，凸显任务发现与引导的重要性。
- **用户意图**：
  - **64.7%** 的轮次使用触摸控制（因可靠性高于语音）。
  - 语音意图以任务导航为主（Next Step 最高频），其次是 Search、Confirmation、Start Task。
  - 复杂意图（Questions、Replace Ingredients）较少，用户以线性导航为主。
  - Fallback 占 8.6%，Out-of-Scope 与 Sensitive 请求常见，反映非合作行为的存在。
- **对话特征**：
  - Engagement 平均 6.8 轮；Cooperativeness 约 80%；Task Exploration 平均完成约一半步骤。
  - Tolerance 有限，用户通常容忍 1–2 次 fallback 后即结束会话。
  - Verbosity 低（μ=2.8 词）、Emotion 多为中性（μ=0.54）、Fluency 较高（μ=0.82）、Repetition 低。
- **真实 vs. 众包**：
  - 复杂动作在真实交互中仅占 8.8%，众包数据中高达 47.5%。
  - 真实话语更短（2.9 vs. 12.8 词）、更嘈杂、更口语化。
  - 非合作行为在真实交互中约占 17%，众包数据中基本缺失。
- **满意度**：
  - 平均评分 3.44，集中于 1 和 5，设备类型间差异不大。
  - 是否开始任务与满意度强相关：未开始 3.05 vs. 开始 3.84；完成任务最高 4.17。
  - 领域差异：食谱 4.01 > DIY 3.72。
  - 最强正相关：Task Progression（0.26）、Start/Completion（0.24）、到达 Task Execution（0.23）；负相关：Greeting 轮次（-0.16）、用户 Verbosity（-0.14）、Search（-0.08）。
  - 无单一特征强相关，满意度是行为与上下文因素的综合结果。
- **评分主观性**：标注者间一致性高（ρ=0.70，80%，κ=0.59），但与用户评分一致性低（ρ=0.24，61%，κ=0.22）；标注者评分更严格（2.7 vs. 3.4）。

## 9. 潜在改进与未来方向

- **从相关走向因果**：本文所有满意度信号均为相关性分析，未来可通过 A/B 测试、干预实验（如强制任务分块粒度、控制响应长度、改变任务接地流程）来验证设计指南的实际因果效应。

- **会话动态的时序建模**：当前多为静态统计，未来可对会话内行为序列（如 fallback 出现时机、意图转移路径）建模，刻画满意度形成的动态过程。
- **融合非对话信号**：结合界面点击流、停留时间、语音停顿等日志信号，构建更立体的用户体验画像。
- **伦理与隐私**：大规模真实用户数据的使用需进一步讨论脱敏、同意机制与数据治理，尤其涉及敏感请求与用户身份信息。

## 10. 对后续研究的启发

- **数据集构建警示**：真实交互中复杂动作仅占 8.8%，而众包数据高达 47.5%，且真实话语更短、更嘈杂、含约 17% 非合作行为——这提示基于众包训练或评测的 CTA 模型可能严重高估真实场景表现，后续数据集应主动纳入噪声、非合作与短话语样本。
- **任务接地不可忽视**：用户 68.5% 的交互时间花在 Task Grounding，且"是否开始任务"与满意度强相关。这提示研究者应将任务发现、选择与引导视为一等公民，而非仅优化任务执行阶段。
- **模态选择的行为依据**：64.7% 轮次使用触摸，说明在带屏设备上用户偏好可靠的低成本输入，语音更多承担导航功能。混合主动、多模态路由的设计应基于此类真实偏好而非理论假设。

- **设计指南的可操作化**：10 条指南（G1–G10）为工程实现提供了具体锚点，可作为 CTA 开发 checklist 或自动化评估维度。
