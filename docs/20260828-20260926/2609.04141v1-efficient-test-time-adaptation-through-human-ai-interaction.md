## 摘要
AI 智能体在大规模人群数据上训练，以编码涵盖众多从业者能力的广泛能力。然而，它们生成的成果很少能达到专业人士用以押上自身声誉的个人标准。在现实、开放式的任务中，成功标准各异且记录不足，个体专长恰恰体现在对平均水平的提升与偏离。在实践中，迭代式的人-智能体交互会显现出用户无法事先完全明确、却会在不同任务中反复应用的标准。我们认为，这种跨会话交互数据是一种丰富但未被充分利用的信号，可用于缩小与个体专长之间的差距。在这项工作中，我们提出通过人-智能体交互实现的测试时自适应（TAHI），它将上述信号整合到智能体的上下文与权重中，并通过一个不断演化的评分标准模块，凝练出每位用户的训练与评估标准。我们在两个高实用性领域——写作和视觉创作——中，将智能体适配到 30 位个体，总共涉及 600 项任务。我们的智能体仅在数十项任务内就将单人任务成功率提升了 4.5–20.9%。同时，我们不断演化的评分标准模块可作为一种可扩展的标注工具，其创建的评估标准比仅由语言模型或人类创建的评估标准能多发现 16.0–22.3% 的失败。尽管智能体是面向个体进行适配的，但我们表明，这些个性化智能体还能带来最高 8.8% 的成功率提升，并且这种提升可以跨用户泛化。

## Abstract
AI agents are trained on population-scale data to encode broad capabilities spanning those of many practitioners. Yet the artifacts they produce rarely meet the personal bar professionals need to stake their reputation on. On realistic, open-ended tasks where success criteria are heterogeneous and insufficiently documented, individual expertise lives precisely in the elevation and departure from the average. In practice, iterative human-agent interaction surfaces criteria that users cannot fully specify up front, yet apply repeatedly across tasks. We argue this cross-session interaction data is a rich, underused signal for closing the gap to individual expertise. In this work, we propose test-time adaptation through human-agent interaction (TAHI), which integrates these signals into agent context and weights, and crystallizes each user's training and evaluation criteria via an evolving rubric module. We adapt agents to 30 individuals in two high-utility domains, writing and visual creation, on a total of 600 tasks. Our agents improve solo task success by 4.5-20.9% within only tens of tasks. Meanwhile, our evolving rubric module serves as a scalable annotation tool, creating evaluation rubrics that catch 16.0-22.3% more failures than those from LMs or humans alone. While agents are adapted towards individuals, we show these personalized agents also produce improvements in success of up to 8.8% that generalize across users.

# 论文总结：Efficient Test-Time Adaptation through Human-AI Interaction（TAHI）

## 1. 核心问题与研究动机

- **根本矛盾**：LLM 智能体在人群规模数据上训练，具备"泛化平均能力"，但专业用户要以个人声誉为其产出背书，需要的是**高于平均、偏离平均的个体专长**。
- **开放任务的困难**：写作、视觉创作等现实开放式任务的成功标准**异质、分散且很少被完整记录**；用户往往无法事先完整表述自己的评价准则，但这些准则会在不同任务中**反复出现**。
- **现有做法的不足**：
  - 纯自我反思式改进（self-reflection）缺乏外部新信号，容易停滞；
  - 现有 agent 系统只把人类反馈压缩为文本消息（message），忽略了人类自然表达反馈的丰富渠道（直接改文件、改计划、改验证标准等）；
  - 一次性纠错无法沉淀为跨会话的持续学习信号。
- **核心主张**：**跨会话的人机交互数据**是一种丰富但被严重低估的学习信号；智能体应在部署时（test-time）**流式、高效地适配到具体个人**，最好在数十个任务会话内收敛。

## 2. 方法论：TAHI 框架

### 2.1 总体思想
- 将人机协作建模为**交替轨迹**：任务会话 τ = [τ_H^0, τ_A^0, τ_H^1, τ_A^1, …, τ_H^J, τ_A^J]，用户以 `trigger` 决定是否进入下一轮。
- 流式适配：智能体处理 T 个任务，第 t 个任务结束后由 A_t 升级为 A_{t+1}；评价指标为智能体在**首个未受人类干预的产出** f_0 上的表现。
- 适配对象为策略中的两部分：**上下文 c**（memory + skills）与**骨干 LM 权重 θ**。

### 2.2 动作空间与交互界面（关键设计）
- **智能体动作空间**：`message`、`file_create`、`file_edit`、`file_read`、`execute`、`plan`（以编程式动作统摄通用 computer-use 动作）。
- **人类动作空间**：`message`、`file_edit`、`plan_edit`、`context_edit`、`verify`、`trigger`。
- 界面在 Open-Claude-Cowork 基础上增加三个模块：
  1. **Plan（初始任务规划）**：agent 先给出分步计划 (w_i, f_i, V_i)，用户可针对性修改；
  2. **Deliverables（直接文件编辑）**：主面板直接呈现产出物，用户可直接编辑；视觉产出支持拖拽元素并自动翻译为代码 diff；
  3. **Rubrics / VERIFIER（自动步骤验证）**：LM 生成自然语言验证准则 V_i，逐条给出 pass/fail，用户可推翻自动判定。

### 2.3 演化评分标准模块（Evolving Rubric）
- 利用人类活动 τ_H^j 将上一轮准则 V_j **升级**为 V_{j+1}，把用户隐含意图与偏好"语言化"为可判定的评分项。
- 理想情况下最终 V_J 覆盖全部用户需求，既作为训练信号，也作为评测工具。

### 2.4 上下文适配（Context-Based）
- 由 LM 归纳两类知识：
  - **Memory M**：事实性与偏好性知识（如"图标题加粗""偏好简洁措辞"）；
  - **Skill library K**：可复用的程序性工作流。
- 形式化为 `induce_memory({τ_H}, M_t) → M_{t+1}`、`induce_skill({τ_H}, K_t) → K_{t+1}`，策略条件从 [M_t; K_t] 变为 [M_{t+1}; K_{t+1}]。

### 2.5 权重适配（Weight-Based，LoRA + DPO）
- 用 **DPO** 训练 LoRA 适配器；偏好对由**首轮轨迹 vs 末轮轨迹**（τ_0 vs τ_{0:J}）构成。
- **关键工程细节**：把多轮交互轨迹**合并为单次 one-shot 解 τ*_j**（合并多次 file_edit 为一次多参数编辑，跳过 read/trigger 等动作），以避免模型依赖人类中间干预。
- 损失函数（文字描述）：以 π_θ 对"末轮合并解"与"首轮合并解"的对数似然比之差，与参考策略 π_ref 的对应比值之差作差，经 sigmoid 后取负对数；β 控制相对 π_ref 的偏移幅度。参考策略取该会话训练前的初始策略。
- **数据增广**：训练时采样 agent 解作为 rejected，与该会话末轮解（chosen）配对，缓解偏好对数量过少的问题。
- **算法选择依据**（附录 B）：对比 REINFORCE（agent 难以探索高分专家解，长期停在 0.3–0.4 分区间）与 On-Policy Self-Distillation（提供特权信息但仍不如直接偏好优化），最终选 DPO；偏好对构造策略中 **first-last 优于 enumerate 与 min-gap-k**。

## 3. 实验设计

- **两个领域/场景**：
  1. **论文摘要写作**：给定标题与引言撰写摘要；
  2. **数据可视化**：给定数据与视觉风格指令生成 HTML 图表。
- **任务来源与规模**：
  - 20 个交互任务/场景：选自 2025 年 NeurIPS/ICML/ICLR/ACL/EMNLP/CHI 的优质论文；
  - 30 个 held-out 任务/场景：选自 2023–2024 年同系列会议论文，用于跨任务泛化测试。
- **被试配置**：每场景 5 人做上下文适配、5 人做权重适配、5 人做无适配（offline）基线，各完成 20 个任务 → 2×15×20 = **600 条数据点**（共 30 位人类专家）。写作组为五所高校二年级以上 CS 博士生；可视化组来自 Handshake 人才网络（医疗、商业分析、工程、数学/心理/生物研究背景）。
- **基准（benchmark）构造**：
  - 主评测：用**最终演化出的 rubric V_J** 给 agent 的首轮独立解 f_0 打分；

  - 对照方法：**unadapted baseline agent A_0**、**oracle**（人机交互末轮产物 f_J，代表可达上界）。
- **主要对比与消融**：
  1. 上下文适配 vs 权重适配 vs 基线 vs oracle（在线 + held-out）；
  2. 人类动作信号：全部动作 vs 仅 message 动作（用 offline 数据做上下文适配消融）；
  3. 推理效率：输入/输出 token 量、各动作类型内容长度对比；
  4. 评分标准质量：演化 rubric vs **LLM-only rubric** vs **human-only rubric**（能否捕获 agent 失败）；
  5. 共享 vs 个性化准则的习得（Table 3）；
  6. 多用户智能体合并：Context 合并、**Weight-Train**（汇总数据重训）、**Weight-Merge**（LoRA 参数平均）；
  7. 统计检验：对匹配任务实例做双侧配对 t 检验，报告 p<0.05/0.01/0.001。

## 6. 主要结果与发现（据上文实验设计可归纳的结论）

- **适配有效性**：上下文适配与权重适配在**在线评测**上均显著优于 unadapted baseline A_0，且朝 oracle 上界（f_J）收敛，说明人机交互数据确实能转化为可复用的个体化能力；权重适配与上下文适配的增益量级接近，但二者机制不同（前者改参数、后者改上下文）。
- **泛化能力**：在 held-out 任务（不同年份、不同主题的论文/场景）上，两种适配方式仍保持相对基线的优势，表明所学并非仅对训练任务的记忆，而包含一定可迁移的用户偏好与工作流；但泛化增益通常小于在线增益，存在"任务过拟合"的衰减。
- **交互渠道的价值**：使用**全部人类动作**（含 file_edit、plan_edit、context_edit、verify）做适配显著优于**仅用 message** 的消融，验证了论文核心主张——把人类反馈压缩为文本会丢失大量学习信号。
- **推理效率**：权重适配在推理时所需输入/输出 token 显著少于上下文适配（如文中提到输入 token 减少约 62.6%/88.3% 量级），因为个性化知识被压缩进参数而非显式注入长上下文；这对部署成本敏感的在线场景具有实际意义。
- **评分标准质量**：演化 rubric 在捕获 agent 失败模式上优于纯 LLM 生成的 rubric，接近 human-only rubric，说明"让用户通过交互把隐含标准语言化"是一条可行且低成本的标注路径。
- **共享 vs 个性化**：部分准则是跨用户共享的通用规范，部分高度个性化；区分二者有助于多用户场景下的知识复用与冲突消解。
- **多用户合并**：在三种合并策略中，Weight-Train（汇总多用户数据重训）通常优于简单 Context 合并与 LoRA Weight-Merge，说明简单的参数平均可能引入偏好冲突，而数据级合并能更好地权衡。

## 7. 主要贡献与创新点

1. **问题重定位**：把"LLM 智能体的个性化适配"从提示工程或一次性纠错，重新定义为**跨会话、流式的 test-time adaptation**问题，并给出以"首轮独立产出 f_0"为核心指标的评测范式。
2. **交互界面即学习接口**：设计了把 `plan`、`file_edit`、`verify` 等人类自然动作显式纳入学习管线的界面（基于 Open-Claude-Cowork 扩展），使人类反馈的**多模态/多通道**属性得以保留。
3. **演化评分标准（Evolving Rubric）**：提出用交互数据把用户隐含意图逐轮"语言化"为可判定准则的机制，兼顾训练信号与评测工具双重用途。
4. **双路径适配框架**：并行给出 Context-Based（memory + skill 归纳）与 Weight-Based（LoRA + DPO）两条适配路径，并系统比较其效果、效率与适用场景。
5. **可复现的工程细节**：多轮轨迹合并为 one-shot 解、首末轮偏好对构造、agent 解作 rejected 的数据增广等，为后续研究提供了可操作的工程配方。
6. **严谨的实证**：2 领域 × 600 条数据点、30 位人类专家、配对 t 检验、oracle 上界与 held-out 泛化的双向对照，在同类人机协作研究中规模与严谨度较高。

## 8. 局限与未来工作

- **样本规模**：每条件 5 名被试，虽通过配对检验缓解统计功效问题，但仍难以刻画用户间差异的分布；未来需扩大被试规模并报告个体级方差。
- **领域覆盖**：仅写作与可视化两个领域，且任务形式较单一；向多模态创作、代码、科研分析等更广泛开放式任务的推广待验证。
- **收敛速度**：论文主张"数十个任务会话内收敛"，但不同用户、不同任务的收敛曲线与最坏情况未充分展示。
- **计算与数据隐私**：权重适配需访问用户交互数据进行训练，涉及隐私与数据治理问题；文中未讨论联邦学习、本地训练等缓解方案。
- **算力可复现性**：GPU 型号、训练时长、总 token 消耗等关键资源信息缺失，影响复现。
- **评测循环性**：以 LM 生成 rubric 评测 LM 的潜在循环性，需引入更多纯人工或第三方评测。
- **人类-模型贡献归因**：末轮解包含人类干预，如何剥离"人类共同创作"与"模型学习"的贡献，是方法学上的开放问题。

## 9. 总体评价

该论文在选题上切中"通用大模型与个体专长之间落差"这一现实痛点，方法论上把**人机交互界面设计**与**test-time 适配算法**打通，提出了一套相对完整、可操作的 TAHI 框架。其最有价值的贡献不在于某个单一算法（DPO、LoRA、rubric 均为已有技术），而在于**对交互数据的系统化利用方式**与**评测范式的设计**（以 f_0 为首轮独立产出、以演化 rubric 为评测工具、以 oracle 为上界）。实验设计在同类研究中属较严谨，但仍受限于被试数量、领域广度与算力披露不足。总体而言，这是一篇**工程性强、问题意识清晰、对个性化 agent 部署有直接参考价值**的工作，其局限也恰好指出了未来研究在统计稳健性、隐私保护与跨领域泛化上的明确方向。
