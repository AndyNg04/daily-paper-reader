## 摘要
评估社会政策变化的影响是政策制定者普遍公认的一项挑战。计量经济学方法在向假设情景外推时可能不可靠，而实地试点项目成本高昂。本文提出将大语言模型（LLMs）用作经通用模型适配而来的政策评估工具。我们提出 FlexPension-LLM，这是首个面向中国灵活就业人员分层养老保险参保预测任务的领域专用大语言模型，并引入 DKI-RDistill，该方法将基于政策的线索注入提示中，包括由 Probit 模型导出的边际效应以及户籍—省份养老保险规则。随后，该方法使用 LoRA/SFT 将理由增强的监督蒸馏到一个开放权重 MoE 学生模型中，并通过在真实标签下重新生成这些案例来纠正教师模型的错误。在 CHFS 2019 盲测划分上，FlexPension-LLM 达到 0.9316 的 Composite F1，超过其 Claude Sonnet 4.5 教师模型以及 17 个基线中的 15 个，并且与 Claude Opus 4.6 在统计上无法区分。在四项外部调查中，它平均达到 0.7549 的 Composite F1，并在最强系统中表现出最窄的性能范围。组件分析表明，增益主要来自基于政策的线索注入和错误过滤监督，而理由提供了可对照政策规则进行检查的决策轨迹。

## Abstract
Assessing the impacts of social policy changes is a widely acknowledged challenge for policymakers. Econometric methods can be unreliable when extrapolating to hypothetical scenarios, while field pilot programs are highly costly. In this paper, we propose using large language models (LLMs) as policy-assessment tools adapted from general-purpose models. We present FlexPension-LLM, the first domain-specialized large language model for a hierarchical pension-enrollment prediction task among flexible workers in China, and introduce DKI-RDistill, which injects policy-grounded cues into the prompt, including Probit-derived marginal effects and hukou-province pension rules. The method then uses LoRA/SFT to distill rationale-augmented supervision into an open-weight MoE student, with teacher errors corrected by regenerating those cases under ground-truth labels. On a CHFS 2019 blind split, FlexPension-LLM achieves 0.9316 Composite F1, surpassing its Claude Sonnet 4.5 teacher and 15 of 17 baselines, and is statistically indistinguishable from Claude Opus 4.6. Across four external surveys, it averages 0.7549 Composite F1 and shows the narrowest performance range among the strongest systems. Component analysis shows that gains come mainly from policy-grounded cue injection and error-filtered supervision, while rationales provide decision traces that can be checked against policy rules.

## 1. 核心问题与研究动机

- **现实痛点**：评估社会政策变化的影响是政策制定者的长期难题。计量经济学方法擅长识别相关性，但在向"假设情景"外推时可靠性不足；而大规模区域性实地试点成本高昂、周期长。
- **替代思路**：作者主张把通用大语言模型（LLM）适配为**政策评估工具**，用于模拟个体层面的政策行为响应。
- **具体落地场景**：中国灵活就业人员的养老保险参保决策。中国灵活就业人口已超 3 亿，是劳动市场的重要组成部分，也是就业政策的明确焦点；既有研究记录了持续的参保覆盖缺口、异质性养老金选择，以及因参保不足和便携性摩擦带来的福利损失。
- **任务本质**：这是一个**分层（hierarchical）制度决策问题**——灵活就业者先决定"是否参保"，再在"城乡居民养老保险（缴费低、待遇低）"与"城镇职工基本养老保险（待遇高但需自担全额缴费）"之间选择，最终形成三个终态标签：不参保 / 居民养老保险 / 职工养老保险。
- **为何经典方法吃力**：决策受复杂规则约束（缴费门槛、户籍—省份政策、制度可及性）、对边际政策变化高度敏感，且包含缴费历史、家庭示范/替代效应等行为机制，标准机器学习预测器精度可提升但难以给出与政策杠杆挂钩的解释。
- **通用 LLM 的不足**：现成 LLM 常"表面化"地套用规则、存在理性人偏误，在专业社会科学任务上一致性弱。这正是本文要解决的可靠性问题。

## 2. 方法论：DKI-RDistill 与 FlexPension-LLM

### 2.1 核心思想
把**计量经济学先验 + 户籍省份政策规则**转成"提示侧线索"（Domain Knowledge Injection, DKI），让强教师模型生成结构化理由监督，再用**错误过滤后的理由蒸馏**（Rationale Distillation, RDistill）+ LoRA/SFT 把能力内化到开源学生模型，得到领域专用模型 FlexPension-LLM。整条流水线将"提示侧线索构建"与"学生适配"分离。

### 2.2 关键技术细节

**（a）Domain Knowledge Injection（DKI）**
- 用两个 Probit 模型提取决策机制：Model I 估计"是否参保"边际，Model II 在参保者中估计"是否选职工通道"。
- 平均边际效应揭示的机制：收入与资产正向支持参保和职工通道；家庭参保人数与养老金领取者产生方向相反的家庭效应；累计缴费年限编码路径依赖；户籍/教育解释制度性分层。
- 将机制转成三个提示侧指标：
  - **居民养老金负担比**：R_resident = P_min,resident / max( Y_ind , Y_hh/N , (A_hh − D_hh)/N )，其中 P_min,resident 为省级最低年缴费，Y_ind 个人年收入，Y_hh 家庭年收入，A_hh 家庭资产，D_hh 家庭负债，N 家庭规模；取多个能力信号的最大值以降低对单一噪声指标的敏感性。
  - **职工养老金负担比**：R_employee = P_min,employee / max( 同上分母 )。
  - **家庭养老金依赖度**：D_pension = 12 × P_month / Y_hh，P_month 为家庭月养老金收入。
- 依据负担分布设定实用可负担阈值：**R_resident < 1%**、**R_employee < 25%**。
- 同时注入户籍—省份政策参数（居民档次、职工缴费下限、补贴、基础养老金等，人工从省市级政策文件整理并逐案匹配）。

**（b）Rationale-Augmented / Error-Filtered Supervision（理由增强与错误过滤监督）**
- 用 DKI 提示驱动教师模型 Claude Sonnet 4.5 对每条带标签样本生成预测 + 理由。
- 按教师预测是否命中真实标签切分监督池：
  - D_match = {(x_i, y_i, r_i) : ŷ_i = y_i} —— 教师正确，保留原理由；
  - D_regen = {(x_i, y_i, r̃_i) : ŷ_i ≠ y_i} —— 教师错误，在**真实标签下重新生成**理由，避免学生模仿错误终态。
  - 最终蒸馏集 D_distill = D_match ∪ D_regen。
- 在 CHFS 2019 训练—验证池中，11,839 条（88.9%）作为教师正确轨迹保留，1,483 条（11.1%）被重生成。

**（c）Student Adaptation（学生适配）**
- 学生底座：**Qwen 3.5-35B-A3B**（开放权重 MoE），即评估中的 Qwen-ZS 未微调基座。
- 冻结基座权重，仅训练低秩适配参数（LoRA/SFT）。
- 目标序列 s_i = (r_i, y_i)，同时包含结构化推理轨迹与最终决策标签；最小化监督负对数似然：
  L(θ) = − Σ_{(x_i,s_i)∈D_distill} Σ_{t=1}^{|s_i|} log p_θ( s_{i,t} | s_{i,<t} , x_i )。
- 输出约束为结构化 JSON（decision_process 分步 + 终态决策对象），学生若匹配或超过被提示的教师，即体现错误过滤监督与任务内化的效果。

## 3. 实验设计

### 3.1 数据与场景
- **主数据集**：CHFS 2019（中国家庭金融调查），构建 **15,672** 个灵活就业样本（参保 8,842 人，56.4%；未参保 6,830 人，43.6%）。
- **数据划分**：留出 **2,350** 例作为独立盲测集；其余 13,322 例构成教师监督池（11,839 保留 + 1,483 重生成），再切为 10,657 训练 / 2,665 验证。盲测集**从未**用于提示调优、蒸馏监督构建、微调或检查点选择。
- **外部泛化评估**：CHFS 2017、CHIP 2018、CLDS 2018、CFPS 2018，各按标签分层抽样 **500 例**（共 2,000 例），仅用于域外评估，绝不进入微调。

### 3.2 评价指标（benchmark）
- **Action F1**：个体是否参保。
- **Type F1**：官方二值协议——以城镇职工养老保险为正类，仅在真实值与预测**均显示参保**的样本上计算。
- **Composite F1**（主指标）= 0.6 × Action F1 + 0.4 × Type F1。
- 统计推断：分层配对 bootstrap 95% 置信区间，B = 10,000 重采样，随机种子 42。

### 3.3 对比方法

0.0082, 0.0398]；与 Claude Opus 4.6、Correct-only SFT 的差距置信区间跨零，作者据此明确不宣称显著优势，仅表述为"可比/持平"。
- **教师筛选结论**：在候选教师中 Claude Sonnet 4.5 综合表现最佳，是蒸馏监督的来源；DKI 对教师侧有稳定正增益（全样本 +0.0668，盲测子集 +0.0623），说明"先验注入"本身即可提升通用模型的领域判断。
- **蒸馏有效性的关键证据**：学生模型不仅继承了教师的判断，还**超过**了被 DKI 提示的教师（+0.0107 [0.0005, 0.0212]），这是错误过滤 + 理由重生成机制发挥作用的最直接证据——若只是简单模仿，学生上限通常止步于教师水平。
- **Correct-only SFT 消融**：仅用标签监督的微调版本弱于完整方法（外部均值对比中差距跨零但方向一致），表明**理由轨迹的监督价值高于纯标签**，与"让模型学会分步制度推理而非死记终态"的设计动机一致。
- **外部泛化**：在 CHFS 2017、CHIP 2018、CLDS 2018、CFPS 2018 四个域外数据集上，FlexPension-LLM 平均 Composite F1 约 0.75，绝对水平明显低于盲测的 0.93，但相对同批基线仍保持领先或持平；作者将此诚实呈现为"域偏移下的性能衰减"，而非掩盖。
- **稳健性**：
  - 数据规模从 10% 到 100% 呈单调上升后趋于饱和，说明方法对监督量有一定依赖但收益递减；
  - 检查点动态显示性能在训练中后段（约 1000–1800 步区间）达到平台，未出现明显过拟合崩塌；
  - 解码温度 0.0–0.9 范围内 Composite F1 波动较小，且**解析成功率恒为 1.0**，说明结构化 JSON 约束与 LoRA 内化共同保证了输出格式的稳定可控。
- **误差转移**：表 3 显示 DKI 主要削减"漏判参保"类错误（把应参保者误判为不参保），而学生适配进一步压缩了通道混淆（居民 vs 职工）误判；剩余误差集中在制度边界模糊、家庭信息缺失或政策参数未覆盖的样本上。
- **边界案例**：
  - Case A（名义收入低但家庭资产高、居民养老金负担比仅 0.03%、已有 14 年连续缴费）——模型正确识别家庭缓冲与路径依赖，判为继续参保职工通道，体现了对"个人收入 ≠ 缴费能力"的把握；
  - Case B（名义上可负担，但家庭养老金依赖度高达 70%、无参保历史）——模型判为不参保/低意愿，与行为经济学中"当下现金流约束优先于远期收益"的直觉一致。
  两例共同说明模型学到的不是简单阈值规则，而是多信号权衡。
- **专家评估**：27 名受访者在 12 个匿名案例、3 个模型上的 324 次信任选择中，FlexPension-LLM 获得的信任度不低于强闭源基线，支持其推理过程在**人类可读性与可信度**层面具备实用价值。

## 7. 贡献与意义

- **方法论贡献**：提出 **DKI-RDistill** 范式——把"计量经济学先验 + 制度规则"作为提示侧线索，用"教师正确样本保留理由 / 教师错误样本在真值下重生成理由"的方式构造监督集，再通过 LoRA 内化到开源学生模型。该范式可迁移到其他需要"规则约束 + 个体异质性"的社会科学决策场景（如医保、住房、生育、劳动供给）。
- **工具贡献**：交付 FlexPension-LLM 这一面向中国灵活就业养老保险决策的领域模型，具备结构化 JSON 输出与可解释的分步推理，可直接嵌入政策情景模拟流水线。
- **实证贡献**：在严格隔离的盲测协议下，证明领域适配后的中等规模开源模型（Qwen 3.5-35B-A3B + LoRA）可以在特定社会政策任务上**达到甚至略超**顶级闭源模型，且训练成本极低（8×L20，约 4.5 小时），对资源受限的研究与政策机构具有现实可行性。
- **政策贡献**：展示了"LLM 作为政策行为响应模拟器"的可行性路径，为在缺乏大规模试点条件时进行**假设情景外推**提供了一种补充性、低成本、可解释的评估工具。

## 8. 局限与审慎解读

- **域外性能衰减明显**：盲测 0.93 与外部均值约 0.75 的落差说明，模型对训练分布（CHFS 2019）存在实质依赖，跨年份、跨调查、跨地区推广时需重新校准或补充适配。
- **部分对比不显著**：与 Claude Opus 4.6、Correct-only SFT 的差距置信区间跨零，因此"优于一切基线"的说法不成立，作者也未如此主张。
- **指标协议局限**：Type F1 仅在真实与预测均为参保时计算，会低估通道层面的混淆错误，可能高估模型在"二险种选择"上的真实能力。
- **教师依赖与蒸馏上限**：监督质量受教师（Claude Sonnet 4.5）水平约束，教师筛选仅基于 30 例小样本，选择稳健性有限。
- **行为真实性边界**：模型输出的是"对已观测决策模式的拟合与推理"，不等于对真实政策变化下因果效应的识别；用于反事实政策模拟时，仍需与计量经济学因果框架交叉验证。
- **政策参数时效性**：户籍—省份政策参数依赖人工整理，难以实时跟随政策调整。

## 9. 总结性评价

本文的价值不在于宣称 LLM 能"替代"计量经济学或实地试点，而在于给出了一条**务实、低成本、可复现的领域适配路径**：先用领域先验约束提示、再用错误过滤的理由蒸馏把能力固化进开源模型，从而在规则复杂、异质性强、政策敏感的社会决策任务上取得与顶级闭源模型相当的表现。其方法设计（尤其是"教师错误样本在真值下重生成理由"这一细节）和实验纪律（盲测隔离、配对 bootstrap、如实报告跨零区间、承认外部衰减）都体现了较高的规范性。主要短板在于域外泛化与部分消融结论强度不足，这也为后续工作指明了方向：扩大政策规则覆盖、引入因果约束、并在更多真实政策变动情境中做前瞻性验证。
