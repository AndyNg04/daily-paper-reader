## 摘要
检索增强生成（RAG）已成为通过利用外部知识来缓解大型语言模型（LLMs）幻觉的重要方法。尽管对简单查询有效，但传统RAG在处理信息高度碎片化的大规模非结构化语料库时存在困难。基于图的RAG（GraphRAG）引入知识图谱以捕获结构关系，从而实现对复杂推理的更全面检索。然而，现有的GraphRAG方法依赖孤立、片段级的提取来构建图，缺乏对整个语料库的全局视角。因此，这些方法常常导致主题不一致、逻辑冲突和结构碎片化的图，从而降低检索性能。本文提出MemGraphRAG，一种新颖的框架，引入基于记忆的多智能体系统以确保高质量的图构建。具体来说，MemGraphRAG采用由共享记忆支持的智能体协作社会，在整个提取过程中提供统一的全局上下文。该机制使智能体能够动态解决逻辑冲突并保持整个语料库的结构连通性。此外，我们提出了一种针对所构建图定制的记忆感知层次化检索算法。在多个基准上的大量实验表明，MemGraphRAG以可比的效率优于最先进的基线模型。我们的代码可在https://github.com/XMUDeepLIT/MemGraphRAG获取。

## Abstract
Retrieval-Augmented Generation (RAG) has become an essential method for mitigating hallucinations in Large Language Models (LLMs) by leveraging external knowledge. Although effective for simple queries, traditional RAG struggles with large-scale, unstructured corpora where information is highly fragmented. Graph-based RAG (GraphRAG) incorporates knowledge graphs to capture structural relationships, enabling more comprehensive retrieval for complex reasoning. However, existing GraphRAG methods rely on isolated, fragment-level extraction for graph construction, lacking a global perspective on the whole corpus. As a result, these methods frequently lead to thematically inconsistent, logically conflicting, and structurally fragmented graphs that degrade retrieval performance. In this paper, we propose MemGraphRAG, a novel framework that introduces a memory-based multi-agent system to ensure high-quality graph construction. Specifically, MemGraphRAG employs a collaborative society of agents supported by shared memory, which provides a unified global context throughout the extraction process. This mechanism allows agents to dynamically resolve logical conflicts and maintain structural connectivity throughout the corpus. Furthermore, we propose a memory-aware hierarchical retrieval algorithm tailored for the constructed graph. Extensive experiments on multiple benchmarks demonstrate that MemGraphRAG outperforms the state-of-the-art baseline models with comparable efficiency. Our code is available at https://github.com/XMUDeepLIT/MemGraphRAG.

# 论文详细总结：MemGraphRAG

## 一、核心问题与整体含义（研究动机和背景）
- **问题**：现有 GraphRAG 方法在构建知识图谱时采用孤立、片段级的提取（isolated chunk-level extraction），缺乏对整个语料库的全局视角。这导致三个关键缺陷：
  - **主题不相关**（Thematic Irrelevance）：提取的三元组常偏离核心主题。
  - **逻辑不一致**（Logical Inconsistency）：不同片段间出现矛盾事实（如生日冲突、时间冲突、粒度冲突）。
  - **结构碎片化**（Structural Fragmentation）：关键实体重复或散落在不连通的子图中，削弱多跳推理能力。
- **背景**：传统 RAG 对复杂多跳查询效果差；GraphRAG 虽能捕获结构关系，但因构建图质量低，反而常引入噪声，性能甚至不如朴素 RAG。前期实验发现：GraphRAG 召回率虽高但相关性低（如 GFM-RAG 召回 84.3% 但相关性仅 38.5%）。
- **含义**：提出一种基于**共享全局记忆**的多智能体系统，在构建图的过程中保持全局一致性、解决冲突并连接碎片，从而提升检索和生成质量。

## 二、方法论：核心思想与关键技术细节
### 2.1 核心思想
将知识图谱构建视为**全局记忆**与**图结构**共同演化的动态过程，通过多智能体协作实现“提取—检测—修正”闭环。

### 2.2 整体架构
- **全局记忆（Global Memory, M）**：三层层次化记忆：
  - **本体层 M_ont**：存储模式（schema）及提取频率。
  - **事实层 M_fac**：存储具体三元组。
  - **段落层 M_pas**：存储原始文本证据。
  - 双向关联：模式-实例对齐（Φ），事实-证据映射（Ψ）。
- **层次化索引图（Hierarchical Indexing Graph, G）**：包含三个视图：
  - 语义本体图 G_ont（模式级）
  - 事实图 G_fac（实体-关系）
  - 源证据图 G_pas（段落级）
- **多智能体组（Multi-Agent Group, A）**：
  - 提取代理 A_ext：从文档提取候选模式/事实/段落并存入记忆。
  - 冲突检测代理 A_det：监控事实层，识别冗余、异常和逻辑冲突。
  - 冲突解决代理 A_res：利用记忆中的证据解决冲突。

### 2.3 图构建过程
1. **主题去噪（Unified Schema Filtering）**：
   - 新提取的模式先处于“候选”状态；只有当其频率 ≥ 阈值 τ 时才晋升为“稳定”模式。
   - 只有对应稳定模式的三元组才被激活进入下游图结构，过滤低频噪声。
2. **一致性维护（Global Adjudication）**：
   - 新激活三元组触发冲突检测：基于语义相似度和结构约束找出冲突集 F_conf。
   - 冲突解决代理检索相关段落证据，采用三种策略：
     - 互斥冲突：丢弃错误事实。
     - 时间冲突：添加时间属性区分。
     - 粒度冲突：细化谓词（如 born_city vs. born_country）。
3. **结构统一（Memory-Guided Bridging）**：
   - 类型桥接：共享相同模式类型的实体之间添加边。
   - 相似性桥接：嵌入相似度超过阈值的实体之间添加边。
   - 最终合并三个视图形成全局图 G。

### 2.4 在线检索算法（Memory-guided Online Retrieval）
- **多层记忆过滤**：并行从 M_ont、M_fac、M_pas 检索 top-K 候选，仅保留相似度 > τ 的模式和事实；若无有效结构证据则退化为标准 RAG。
- **结构感知节点初始化**：
  - 实体节点：基于相关事实的平均语义相似度。
  - 类型节点：模式相关性 × log(degree+1)⁻¹ 抑制高中心度节点。
  - 段落节点：语义相似度 × 信息密度项（IDF 聚合 + log 归一化），并加阻尼系数 α=0.05。
- **个性化 PageRank（PPR）**：起始分布为 v^(0)，迭代 v^(k+1) = (1-λ)Wv^(k) + λv^(0)，λ=0.5。收敛后选取 top-K 段落和 top-M 实体送入 LLM。
