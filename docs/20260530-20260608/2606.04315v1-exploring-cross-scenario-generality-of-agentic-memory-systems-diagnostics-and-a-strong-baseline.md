## 摘要
大语言模型智能体积累的历史会超出其上下文窗口，这推动了关于记忆系统的研究日益增多。然而，现有大多数设计仅针对单一场景（多轮对话或单条轨迹格式），几乎没有证据表明它们能够泛化到智能体在部署中遇到的各种异构轨迹。我们在五个场景下重新审视了八个记忆系统以及一个用于搜索问题的智能体框架：单轮问答、多轮对话、智能体轨迹问答、记忆压力测试以及长周期智能体任务。该框架通过工具调用自行管理平面文本文件存储，在跨任务排名中表现最佳，这表明记忆性能的关键在于赋予智能体对存储和检索的主动控制权，而非在固定流水线后设置被动存储。我们将这一见解实例化为AutoMEM，一个具有自管理工具接口的智能体记忆框架，在我们评估的系统中实现了最佳的跨场景通用性。

## Abstract
LLM agents accumulate histories that outgrow their context windows, motivating a growing literature on memory systems. Yet most existing designs are tuned to a single scenario (multi-session chat or a single trajectory format), and there is little evidence that they generalize across the heterogeneous trajectories agents encounter in deployment. We revisit eight memory systems plus an agentic harness for search problems, on five scenarios: single-turn QA, multi-session chat, agentic-trajectory QA, memory stress tests, and long-horizon agentic tasks. The harness, which self-manages flat text-file storage via tool calls, achieves the best cross-task ranking, suggesting that memory performance hinges on giving the agent active control over storage and retrieval rather than on a passive store behind a fixed pipeline. We instantiate this insight in AutoMEM, an agentic memory harness with a self-managed tool interface that achieves the best cross-scenario generality among the systems we evaluate.

### 论文的主要结论与发现

1.  **无单一方法称霸**：在所有五个场景中，没有一种记忆系统能全面领先。而一个简单的**智能体框架（DCI-Lite）** 反而获得了最佳的平均跨任务排名。
2.  **索引式记忆的两种失效模式**：
    - **表示层失效**：在构建时，如HippoRAG的实体-关系知识图谱，会丢弃非实体关系的轨迹信息（如步骤索引、动作标签），导致这些信息在检索前就已丢失。
    - **检索层失效**：即使存储了全部信息（如PlugMem的“原始轨迹存储”），被动的检索接口（如依相似度路由）无法可靠地找到所需信息，主动的智能体驱动检索才能弥补这一缺陷。
3.  **主动控制优于被动流水线**：DCI-Lite和AutoMEM的成功证明，**让代理在查询时主动决定如何组织和检索记忆**，比在构建时预先固化索引模式更有效、更具通用性。
4.  **索引的适用条件**：索引化方法只有在满足两个条件时才值得其构建成本：**1）工作量能摊薄构建开销**（足够多的共享查询）；**2）工作任务需要这种结构**（即问题需要跨单元的聚合信息）。
5.  **动态智能体任务的策略局限**：在ALFWorld等需要实时决策的动态任务中，任何记忆设计都未带来显著提升。性能瓶颈在于智能体（actor）的策略本身，而非记忆系统。手写优化规则和强化学习参数训练能带来巨大提升，但这超出了非参数化记忆系统的能力范围。

### 不足与局限

1.  **缺乏分级预算路由**：AutoMEM对所有步骤（规划、判断、回答）都使用相同的强骨干模型（Qwen3-32B）。论文指出，规划和判断是低熵任务，可以使用更便宜的模型，而强模型只用于回答。缺少这个路由会显著增加计算成本。
2.  **判断提示变化的影响**：在对话式问答中，不同严格程度的判断提示会改变方法排名的相对顺序。论文使用了严格的事实判断器，但提示的变化是一个值得关注的潜在偏差来源。
3.  **“记忆”定义与范围局限**：
    - **以检索为重心**：论文的“记忆”本质上是一个“检索”系统，侧重于历史和静态信息的查找。对于需要模型**更新现有记忆**（如用户信息变更）或**解决冲突信息**的场景，其能力未被评估。
    - **非参数化局限**：论文明确指出，对于提升智能体（actor）基础策略等任务（如ALFWorld），非参数化的记忆系统存在天花板。要突破这一天花板，需要参数更新（如强化学习后训练）。
4.  **实验规模的局限**：为了控制成本，实验使用了固定大小的子集，而非每个数据集的完整版本。虽然论文保证了方法间的可比性，但极端大规模场景下的性能仍有待验证。
5.  **应用限制与安全性**：论文在研究伦理部分提到了潜在风险。AutoMEM给代理赋予了控制记忆存储的工具调用接口，在包含用户数据的部署环境中，需要额外的安全防护措施（如访问控制、内容过滤、审计日志），这些问题不在论文研究范围之内。
