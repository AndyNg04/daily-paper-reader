## 摘要
持久化LLM智能体需要记忆表示，使得在长期交互中人物理解的形成过程明晰化。现有智能体记忆方法强调信息保留与检索，但对于如何将累积的交互证据抽象为人物理解却鲜有阐述。我们将这一过程视为图式形成，即情境证据被抽象为可重复使用的模式与稳定的人物层面断言。为此，我们提出PersonaTree——一种结构化生命周期记忆框架，通过三级人物树结构实现上述理念，并为从证据到断言提供明确的支持路径。PersonaTree通过保守写入、置信度引导的整合以及查询条件化的路径检索来维护这棵树，仅返回每个查询所需的证据深度。在六个涉及人物理解与持久记忆的基准测试中，结合三种回答骨干，PersonaTree在18个紧凑分数中排名第一，并在16个设置中进入前两名。消融实验表明，层次结构提升了在KnowMe上的抽象人物理解能力，而支持路径检索在可比上下文预算下提升了在RealPref上的对齐效果。

## Abstract
Persistent LLM agents require memory representations that make the formation of person understanding explicit across long term interaction. Existing agent memory methods emphasize information retention and retrieval, yet give limited account of how accumulated interaction evidence is abstracted into person understanding. We view this process as schema formation, where situated evidence is abstracted into reusable patterns and stable person level claims. We introduce PersonaTree, a structured lifecycle memory framework that realizes this view as a three level persona tree with explicit support paths from evidence to claims. PersonaTree maintains the tree through conservative writing, confidence guided consolidation, and query conditioned path retrieval, returning only the evidence depth required by each query. Across six person understanding and persistent memory benchmarks with three answer backbones, PersonaTree ranks first in 12 of 18 compact scores and reaches the top two in 16 settings. Ablations show that hierarchy improves abstract person understanding on KnowMe, while support path retrieval improves RealPref alignment under a comparable context budget.

- **整体含义**：将人物理解视为一个**生命周期记忆问题**——记忆状态不仅要存储信息，还要作为推理用户模型的结构化基础，使抽象解释有据可查。

## 2. 方法论：核心思想、关键技术细节、算法流程（文字说明）

### 核心思想
- **PersonaTree**：一个**三级人物树**（树形结构图，节点由支持边连接），将长期交互组织为：
  - **叶节点（Leaf）**：带时间戳的事件级证据（每个交互段压缩为一条记录）。
  - **中间节点（Mid）**：可复用的行为/状态模式（如偏好、趋势、触发条件）。
  - **根节点（Root）**：稳定的人物层面断言（如价值观、原则、硬边界）。
- **支持路径（Support Paths）**：每条边记录下层证据如何支撑上层抽象，使每个抽象声明可追溯至其证据链。

### 生命周期操作
1. **在线证据插入（Online Evidence Insertion）**：
   - 新交互转换为带属性（域、事件类型、角色等）的叶节点。
   - 与现有中间节点进行**模式兼容性检查**（κ函数）和**证据验证器**（ψ函数，判断支持/冲突/无关）。
   - 匹配得分：s_match = α·cos(emb) + β·ψ，若超过阈值θ_M则挂载到最佳中间节点；否则成为孤儿叶节点。
2. **置信度更新与短期激活**：
   - 在**对数几率空间**进行更新：L_t = (L_{t-1} - L_base)e^{-λΔt} + L_base + ω_E，再通过sigmoid映射到[0,1]。
   - 支持证据增加ω_E，冲突证据减少，时延衰减使陈旧证据置信度回归基线。
3. **离线整合（Offline Consolidation）**：
   - 周期性后台处理：聚类孤儿叶节点 → 合并兼容中间节点 → 提升成熟中间节点为根节点（要求高置信度、多支持、时间覆盖）。
   - 同时修剪陈旧/低置信度节点，限制每个中间节点保留的证据叶数量。
4. **查询条件路径检索（Query-Conditioned Path Retrieval）**：
   - **路由模型**预测查询所需抽象级别h∈{L,M,R}及属性约束。
   - 从候选支持路径中，在**Token预算B_q**下选择最优子集：C* = argmax Σ [r(q,x) - λ_b·tok(x)]。
   - 渲染器支持三种深度：d=0仅根、d=1根+中间、d=2根+中间+叶。

### 人物理解实例化
- 属性向量用面向人物的描述符：叶节点存储事件摘要、场景标签、情绪等；中间节点存储模式类型（偏好、状态、触发）；根节点存储特质类型（性格、价值、原则、身份、硬边界）。
- 模式兼容性和证据验证规则按此模式定义，但生命周期运算符保持通用。
