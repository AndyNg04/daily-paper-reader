## 摘要
语言智能体越来越多地被部署于不断累积的多模态信息之上，然而现有基准假设的是人-人交互形式，包含稀疏的视觉信息和直白的内容，既不评估对真实多模态文件交互的推理，也不解读隐含的用户信息。为此，我们提出M$^3$Exam，一个基于真实用户-智能体交互、以查询为中心的多模态对话记忆基准，其多维度评估涵盖跨模态基础关联和隐含信息推理。对多模态大模型和记忆系统的基准测试揭示了跨模态基础关联、跨会话推理以及累积多模态上下文效率成本方面持续存在的差距。我们进一步提出M$^3$Proctor，一种多模态记忆方法，它能检测查询模态偏差并按需仅消耗原始视觉资源，在将索引构建时间和检索令牌数削减超过70%的同时，将准确率提升13%。

## Abstract
Language agents are increasingly deployed over accumulating multimodal information, yet existing benchmarks assume a human-human form with sparse visuals and straightforward content, evaluating neither reasoning over authentic multimodal file interaction nor the interpretation of concealed user information. We therefore introduce M$^3$Exam, a query-centric multimodal conversational memory benchmark built on realistic user-agent interaction, with multi-dimensional evaluation spanning cross-modal grounding and implicit information inference. Benchmarking MLLMs and memory systems reveals persistent gaps in cross-modal grounding, cross session reasoning, and the efficiency cost of accumulating multimodal context. We further propose M$^3$Proctor, a multimodal memory method that detects query modality bias and consumes raw visual sources only on demand, improving accuracy by 13% while cutting index-construction time and retrieved tokens by over 70%.

2.  **现有基准的局限性**：

    *   文档问答基准（如SlideVQA）虽然涉及多模态推理，但限制在单个文档和单轮交互内。

3.  **核心问题**：如何构建一个能更真实反映用户-智能体交互场景的基准测试，以评估智能体在长期、多会话、多模态历史中进行信息检索、跨模态推理和隐含意图解读的能力？同时，如何解决现有记忆系统在检索时“不加区分地注入视觉信息”导致的效率和准确性下降问题？

#### 二、 论文提出的方法论：核心思想、关键技术细节

1.  **M^3Exam基准测试**：
    *   **核心思想**：构建一个以查询为中心（query-centric）的多模态对话记忆基准。它模拟用户在多个会话中与智能体进行交互，积累文本、图片、PDF文档等多模态历史。每个测试点是一个查询问题，智能体需要从累积的对话历史中检索相关证据并回答。
    *   **构建流程**：
        1.  **输入源（Source Inputs）**：基于15个预设的“人物画像（Persona）”、“核心事件（Core Event）”和“多模态文件库（File Pool）”进行合成。
        2.  **时间线构建（Timeline Construction）**：利用LLM根据人物画像和核心事件生成一个按时间顺序排列的“核心事件链”，并加入“干扰事件（Distractor Events）”来模拟真实的聊天噪音。
        3.  **多轮对话合成（Multi-Turn Conversation Synthesis）**：通过“事件滑动窗口”的方式模拟用户-智能体之间的多轮对话，每个对话会话都包含了相关的多模态文件（如图片、PDF）。对话会进行分段质量控制。
        4.  **问题库构建（Question Bank Synthesis）**：从生成的对话中采样，并使用LLM生成8种类型的问题，形成一个“平衡的、推理密集型”的问题库。
    *   **问题类型（8种）**：分为**记忆（Memorizing）**、**推理（Reasoning）** 和**解读（Interpreting）** 三大类。
        *   **记忆**：单会话检索（SS）、文件管理（FM）、事实判断（FJ）
        *   **推理**：多会话分析（MS）、多模态推理（MR）、时序推理（TR）
        *   **解读**：隐含推断（II）、主题推理（TH）
    *   **数据规模**：包含239个多会话对话，跨越15个人物画像场景，总计3025轮交互，1799个多模态工件，5150个评估问题。其中34.9%的问题需要跨模态基础，14.9%的问题需要隐含推断。

2.  **M^3Proctor代理基线（Proxy Baseline）**：
    *   **核心思想**：现有记忆系统是“模态不可知（modality-agnostic）”的，不加区分地检索和注入所有视觉信息，既淹没了关键证据，又浪费了巨大的token预算。M^3Proctor的核心思路是“按需检索（Retrieve on Demand）”，通过检测查询的模态偏差（Modality Bias），决定是否使用原始视觉源。
    *   **关键技术细节**：
        *   **多模态索引构建（Multimodal Index Construction）**：
            *   将图像、图表、文档等原始模态投影成“文本替代物（Textual Surrogate）”（如图像标题、图表文字转录、文档摘要）。
            *   为每个文本块（chunk）附加一个“模态标签（Modality Tag）”，指示其来源（I：图像，P：文档，C：图表）。
            *   为每个会话创建一个紧凑的“会话摘要（Session Summary）”，作为对话历史的小型时间线，弥补跨回合切分的信号碎片问题。
        *   **模态感知推理（Modality-Aware Inference）**：
            *   **偏差检测（Bias Detection）**：使用一个指令微调的LLM，判断查询问题是否需要某种特定模态（图像、文档、图表）的信息来回答，得到一个二进制向量 b(q)。
            *   **偏差感知重排序（Bias-aware Re-ranking）**：使用文本密集检索获得初选结果后，根据查询的模态偏差 b(q) 和候选文本块的模态标签 m(c)，对结果进行重排序，将携带相关模态的文本块排名提升。公式为 `s(q, c) = cosine(q, c) + Σ(λ_m * b_m(q) * m(c))`。此过程不涉及原始多模态数据的计算。
            *   **成本感知模态级联（Cost-aware Modality Cascading）**：
                *   **Stage 1（文本级）**：仅使用文本替代物（标题、转录、摘要等）来回答问题。
                *   **置信度检查（Confidence Test）**：判断文本级答案是否可靠（u(ˆa1)=1）或模态偏差是否未被满足（β(q)=1）。如果可靠，则结束；否则进入Stage 2。
                *   **Stage 2（原始源级）**：通过一个融合了“检索块中携带模态m的比例”、“模态偏差”和“表面词汇线索”的证据分数 e_m(q) 来决定是否加载原始视觉源。只有当这个分数超过阈值时，才将原始图片、PDF等加载到提示词中。

#### 五、 论文的主要结论与发现

1.  **M^3Exam难度很大**：最强的前沿MLLM（GLM-5.1）在拥有“黄金证据”的情况下也仅获得0.549的总体分数，说明该基准远未被解决。有记忆模块的系统普遍优于无记忆模块的MLLMs。
2.  **核心瓶颈是跨模态和隐含意图推理**：所有系统在处理**多模态推理（MR）** 和**隐含推断（II）** 这类问题时性能显著下降。这揭示了现有系统在多模态基础关联和复杂隐含意图解读方面的能力不足。
3.  **M^3Proctor达到了前沿水平**：
    *   在基于7B骨干模型的记忆系统中，M^3Proctor取得了**最高总体分数（0.484）**。
    *   它超越了所有基于相同骨干的记忆系统，甚至在某些指标上超过了一些检索增强的前沿MLLMs（如GPT-5.4, Claude-Opus-4.6等）。
    *   其提升主要集中在对视觉证据依赖度高的**MR**、**FM**和需要隐含推断的**II**问题上。
4.  **M^3Proctor在效率上实现了数量级优势**：其索引构建时间（72秒）和平均每查询token消耗（4,591）都远低于其他多模态记忆系统（如MIRIX的43,271秒，NGM的26,988 tokens），因为它只在26.4%的查询真正需要时才升级到原始视觉源。这表明“模态感知的按需升级”策略能以极低的成本实现高精度。

#### 六、 优点

1.  **新颖的基准（Novelty）**：M^3Exam是首个同时评估“记忆”、“推理”和“解读”这三个维度，并特别针对“隐含用户意图推断”和“真实文档级多模态交互”的基准，填补了当前评估体系的空白。
2.  **方法的创新性**：M^3Proctor提出的“模态偏差感知”和“按需级联”策略，是对当前“一刀切”式多模态检索方法的有力改进。它将模态作为一等信号引入到检索和推理流程中，思想简洁且高效。
3.  **实验设计严谨全面**：实验设计覆盖了从闭源大模型到开源记忆系统的广泛基线，并进行了多角度、深层次的分析（消融、效率、级联行为），结论的说服力强。
4.  **结果显著**：M^3Proctor在提升准确率的同时，大幅降低了计算开销，这种“效率-准确率”的双重提升在实际应用中非常有价值，为解决多模态长对话记忆问题提供了一个高效、可行的基线方案。

#### 七、 不足与局限

1.  **评估场景的局限性**：当前基准主要关注“单轮问答（single-turn QA）”，即根据累积的历史回答单个问题。论文自身指出，真实世界中往往涉及更动态、更长的多轮交互，用户的意图会演变，记忆也需要迭代更新。这是未来可扩展的重要方向。
2.  **混合评估的挑战**：基准测试结合了“特定答案类型”的问题（如文件管理FM中的图像ID，事实判断FJ中的单选题），这导致评估指标不统一。论文巧妙地对不同问题类型应用了不同的EM评分规则，这虽然合理，但也增加了评估的复杂性。
3.  **隐含推断能力的局限性**：论文指出，虽然M^3Proctor在记忆和推理上取得了进步，但在“解读导向”（interpreting-oriented）的问题（如TH和II）上，能力仍然有限。如何更好地模拟和理解用户的隐含状态，进行更深层的上下文解读，是一个重要的未来研究方向。
4.  **数据依赖**：基准测试的构建依赖于LLM生成，尽管有严格的质量控制（自检+人工审查），但最终的合成数据可能仍存在与真实用户交互的偏差，无法完全模拟真实场景的复杂性和噪声。
5.  **“仅按需”策略的适用范围**：M^3Proctor的级联策略依赖于“模态偏差”的准确检测。如果偏差检测失败（例如，一个需要看图的查询被误判为仅需文本），则性能会下降。虽然论文展示了级联的积极效果，但并未深入分析偏差检测错误的场景及其影响。
