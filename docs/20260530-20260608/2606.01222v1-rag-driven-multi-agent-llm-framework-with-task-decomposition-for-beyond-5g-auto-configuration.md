## 摘要
虽然大语言模型通过将自然语言的人类意图转换为机器可读的配置，为意图驱动的网络管理提供了一条有前途的路径，但在多步骤和复杂任务中，它们常常出现幻觉和结构不一致的问题。为了解决这些挑战，本文提出了一种基于检索增强和任务分解的多智能体大语言模型框架，用于超越5G网络自动配置。该框架采用语义检索增强生成流程，确保其输出与技术标准和供应商特定手册保持一致。此外，它引入了一种模块化架构，用于配置生成、闭环配置验证和网络部署，其中复杂任务被分解为由专门智能体处理的较小子任务。在这种架构中，配置验证智能体识别出幻觉配置参数，并通过低计算量的段级重新生成进行纠正。使用OpenAirInterface模拟器的性能评估实验表明，所提出的基于任务分解的配置和验证方法相比于整体方法将平均成功率提高了22.7%，在网络配置中达到了94.4%的成功率。

## Abstract
While Large Language Models (LLMs) offer a promising path toward intent-driven network management by translating natural language human intents into machine-readable configurations, they often suffer from hallucinations and structural inconsistencies in multi-step and complex tasks. To address these challenges, this paper proposes a retrieval-augmented and task decomposition-based multi-agent LLM framework for Beyond 5G network auto-configuration. The framework employs a semantic retrieval-augmented generation pipeline to ensure that its outputs are aligned with technical standards and vendor-specific manuals. Furthermore, it introduces a modular architecture for configuration generation, closed-loop configuration verification, and network deployment, in which complex tasks are decomposed into smaller sub-tasks handled by specialized agents. In this architecture, hallucinated configuration parameters are identified by the configuration verifier agent and corrected through low computational segment-level regeneration. The performance evaluation experiments with the OpenAirInterface emulator demonstrate that the proposed task decomposition-based configuration and verification approach improves the average success rate by 22.7% over monolithic methods, achieving 94.4% success in network configuration.

## 1. 核心问题与整体含义（研究动机和背景）

随着Beyond 5G（B5G）网络的异构性与复杂度不断增加，网络配置和运维管理高度依赖专家知识。传统意图驱动网络管理通过大语言模型（LLM）将自然语言人类意图转换为机器可读的配置，提供了一个有前途的路径。然而，在多步骤、复杂任务中，LLM 常出现幻觉（hallucination）和结构不一致（structural inconsistencies），导致生成的配置在语法上看似合理，但在语义上不一致或操作上不可行。同时，网络配置任务高度依赖标准合规性、供应商特定约束和平台相关实现。因此，如何确保LLM生成的配置既符合3GPP等技术标准，又满足实际部署要求，成为关键挑战。

## 2. 方法论：核心思想、关键技术细节

**核心思想**：提出一个检索增强（RAG）、任务分解（Task Decomposition）的多智能体LLM框架，用于B5G网络自动配置。框架包含三个主要层：配置生成、闭环配置验证、网络部署，并通过人类在环（Human-in-the-loop）监督确保安全可靠。

**关键技术细节**：

- **语义RAG管道**：离线索引供应商提供的示例配置文件和基础配置参数（包括参数定义、数据类型、允许范围、依赖关系、计算方法等），运行时通过top-k最近邻搜索检索最相关的上下文，经后检索过滤后注入到提示中，确保输出与标准一致。
- **多智能体编排器**：位于服务管理与编排（SMO）平台，协调三个专用智能体：
  - **配置生成智能体（CGA）**：将任务按领域分解为逻辑参数组（例如gNB域分为CU、DU、RU参数组；CN域、UE域分别处理），由各自的段生成智能体并发生成严格格式化的配置段，最后聚合为域级配置，再由协调器组合成完整候选配置包。
  - **配置验证智能体（CVA）**：将配置分解为相同逻辑段，每个段由段验证智能体检查缺失参数、无效值、参数依赖冲突和语法错误，生成结构化评估报告（JSON格式，包含二元有效性指示和问题列表）。仅将失效段送回CGA进行选择性地重新生成，有效段保留。迭代直至所有段符合要求。
  - **网络部署智能体（NDA）**：根据验证通过的配置和用户意图，生成启动网络元素的shell命令，在人类审批后执行。
- **闭环自优化机制**：CGA与CVA之间形成迭代反馈循环，利用LLM的自我修正能力，仅对问题段进行低计算量的再生。
