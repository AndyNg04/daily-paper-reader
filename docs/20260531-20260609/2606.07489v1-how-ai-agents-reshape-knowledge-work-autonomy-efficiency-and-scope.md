## 摘要
前沿AI系统正从对话式助手转向执行端到端任务的自主代理，从而弥合智能与实用性之间的差距。利用Perplexity的搜索和计算机产品的生产数据，我们通过研究AI代理如何加速和重塑知识工作来考察这一转变。三项关键实证发现浮现出来。首先，利用近乎相同的初始查询对会话作为自然实验，比较同一底层任务在两种产品上的尝试，计算机每个用户会话执行26分钟的自主工作，而搜索为33秒。计算机自动化了任务分解和执行，而搜索用户可能需手动编排和实施。结果，计算机将后续查询分布转向验证和扩展等更高阶的工作。自主性还提高了执行质量，计算机上每个查询的不满率比搜索低55%。其次，由于其自主性优势，计算机在匹配任务上将完成时间从269分钟减少到36分钟，相比仅配备搜索的人类，估计时间和成本分别降低了87%和94%。第三，计算机改变了用户尝试的工作范围：计算机查询更常跨越职业边界，需要更高阶认知，依赖更广泛专业知识，采取将相互依赖的子任务捆绑到单一查询中的复合任务形式，并解锁了同一用户在搜索使用中基本缺失的工作活动。综合来看，证据表明AI代理加速工作流程、提高输出质量、降低成本，并扩展自动化工作的广度和深度。

## Abstract
Frontier AI systems are bridging the gap between intelligence and utility by shifting from conversational assistants to autonomous agents that execute tasks end to end. Using production data from Perplexity's Search and Computer products, we study this transition by examining how AI agents accelerate and reshape knowledge work. Three key empirical findings emerge. First, using sessions with near-identical initial query pairs as natural experiments for the same underlying task attempted with both products, Computer performs 26 minutes of autonomous work per user session, versus 33 seconds for Search. Computer automates task decomposition and execution that Search users might otherwise manually orchestrate and implement. As a result, Computer shifts follow-up query distribution toward higher-order work such as verification and extension. Autonomy also increases execution quality, with per-query dissatisfaction rates 55% lower on Computer than on Search. Second, due to its autonomy advantage, Computer reduces completion time from 269 to 36 minutes on matched tasks, lowering estimated time and cost by 87% and 94%, respectively, compared to humans equipped with Search alone. Third, Computer changes the scope of work that users attempt: Computer queries more often cross occupational boundaries, require higher-order cognition, draw on broader expertise, take the form of composite tasks that bundle interdependent subtasks into a single query, and unlock work activities that are essentially absent from Search usage among the same users. Together, the evidence indicates that AI agents accelerate workflows, enhance output quality, reduce costs, and expand the breadth and depth of automated work.

## 2. 方法论

- **核心思想**：构建一个个体层面的任务级理论框架。每个任务由若干步骤（steps）组成，步骤越多价值越高。两种模式（对话/代理）有不同的成本结构：
    - 对话模式：固定成本低（f_C），但每步边际成本高（m_C）。
    - 代理模式：固定成本高（f_A），因需更多说明和验证；但每步边际成本低（m_A）。
    - 用户选择使总成本 C = f + m*s 最小化。
- **重要阈值**：存在一个步骤数阈值 s* = (f_A - f_C)/(m_C - m_A)，低于该阈值偏向对话，高于该阈值偏向代理。
- **资源预算约束**：用户面对B资源，最大化总价值，本质是0-1背包问题。
- **预测**（命题）：
    1. 代理扩展可负担任务边界（更高价值任务）。
    2. 总价值增加。
    3. 当预算被耗尽时，总盈余和价值-成本比增加。
    4. 盈余变化可分解为集约边际（成本节省）、扩展边际（新任务进入）和退出边际。
- **实证方法**：
    - 利用同一用户发起的近似相同初始查询（余弦相似度>0.99）进行匹配（10,000对），实现自然实验对比。
    - 用工具调用追踪代理自主执行时间。
    - 效率估算采用三种三角验证：基于工具映射、基于LLM估计、用户访谈。

## 6. 论文的主要结论与发现

- **自主性**：Computer每会话自主执行26分钟 vs Search的33秒（48倍）。Computer的后续查询更集中于验证和扩展，而非简单跟进。用户不满率降低55%。
- **效率**：匹配任务上，Search+人类平均269分钟，Computer+人类平均36分钟（时间节省87%）；成本节省94%（人力成本为主）。每增加一步，节省时间2.39分钟、成本1.94美元。
- **范围扩张**（跨职业）：Computer查询中跨出用户主要职业的比例比Search高9个百分点（59% vs 50%）。
- **范围扩张**（垂直复杂度）：
    - Computer查询中71%是抽象（非例行）任务（vs Search 53%）；50%是“创造”级认知（vs 26%）。
    - Computer查询要求更多的O*NET知识领域（平均2.40 vs 1.74）。
    - Computer查询涉及更多工作活动（例如GWA: 2.95 vs 2.24; TS: 3.81 vs 2.38）。
    - 23%的Computer查询涉及至少一个用户从未在Search中尝试过的任务语句（fine-grained level）。
- **整体**：AI代理加速工作流、提升质量、降低成本、并拓展工作范围。

## 7. 优点

- **自然实验设计**：利用同一用户发送近乎相同初始查询来构造匹配对，有效控制任务内容和用户特征差异，提高因果推断可信度。
- **多方法三角验证**：效率估算结合工具映射、LLM独立估计和用户访谈，减少单一方法的偏差。
- **敏感性分析**：对关键假设（人工时间、监督时间）进行系统扰动，证明结论稳健。
- **范围量化**：使用O*NET多层次框架（GWA/IWA/DWA/TS）精细刻画任务复合性，差异具有统计学和实际意义。

## 8. 不足与局限

- **窗口期短**：仅三个月，用户为早期采用者（偏付费、高活跃），可能不适用于更广泛人群和长期使用。
- **匹配法局限**：仅覆盖具有近似Search对等的Computer查询，缺少那些完全新颖的任务，而这些任务的增益可能更大，未被充分估计。
- **效率估算假设**：工具映射的人工时间、监督时间由研究者设定；LLM估计本身也有误差。虽经敏感性检验，但绝对数值仍需谨慎解读。
- **仅观察Perplexity生态**：无法得知用户在其他工具（如Claude、ChatGPT、Coding agent）上的行为，可能遗漏对外部活动的替代或补充效应。
- **任务代理性问题**：会话题可能不完美对应任务单元（一个任务可能跨多个会话，一个会话含多个任务）。
- **依赖LLM分类**：范围分析（认知复杂度、知识广度、O*NET活动）依赖LLM自动标注，存在测量误差，虽然趋势明显但可能影响细粒度准确度。
- **用户访谈偏差**：25名受访者自愿参与，存在回忆和选择偏差，仅作补充佐证。
- **未涉及市场层面**：只研究个体层面，没有涉及企业、消费者剩余或劳动力市场总均衡效应。
