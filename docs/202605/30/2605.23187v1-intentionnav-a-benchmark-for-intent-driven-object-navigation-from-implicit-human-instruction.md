## 摘要
现有的物体导航基准通常告知具身智能体要寻找的物体类别，例如微波炉或椅子。面向人类的具身人工智能往往接收到更为间接的请求，如“我需要加热食物”或“房间感觉闷”。智能体必须推断出能满足需求的物体，在场景中找到对应的实例，并判断目标是否达成。我们将这种设定研究为意图驱动的物体导航，并引入 IntentionNav，这是一个诊断性基准，用于评估基于隐式人类指令的主动物体搜索。每个 episode 提供自由文本意图、RGB-D 观测和位姿，但隐藏目标物体名称。IntentionNav 包含 500 个意图，涵盖 176 个 Isaac Sim 场景和 64 个目标类别。每个意图被重写为四种受控的指令风格，并标注了四种意图模式之一，从而在匹配的几何布局下将表面措辞与语义线索类型分离。这种配对设计支持对目标推断、语言鲁棒性、邻域可达性和终端成功率的分析，而不仅仅是汇总成功率。我们使用固定的主动导航智能体评估了三个视觉语言模型。模型在 48.3% 的 episode 中识别出预期目标，在 68.7% 的 episode 中进入其 2 米邻域，但仅 24.9% 成功终止，且仅有 5.5% 达成 1 米内的定位成功。事件脚本类意图的成功率最高（28.7%），而物理状态和可供性意图的成功率较低（19.2% 和 18.5%），表明间接人类意图仍然是主动具身搜索中目标选择、视觉验证和终端定位的瓶颈。

## Abstract
Existing object navigation benchmarks usually tell an embodied agent which object category to find, such as microwave or chair. Human-facing embodied AI is often asked something less direct: "I need something to warm this food" or "the room feels stuffy." The agent must infer the object that can satisfy the need, find a scene-grounded instance, and decide whether the goal has been reached. We study this setting as intent-driven object navigation and introduce IntentionNav, a diagnostic benchmark for active object search from implicit human instructions. Each episode provides a free-text intent, RGB-D observations, and pose, but withholds the target object name. IntentionNav contains 500 intents over 176 Isaac Sim scenes and 64 target categories. Each intent is rewritten in four controlled instruction styles and annotated with one of four intent modes, separating surface phrasing from semantic cue type under matched geometry. This paired design supports analysis of target inference, language robustness, neighborhood reachability, and terminal success rather than only aggregate success. We evaluated three VLMs using a fixed active-navigation agent. Models identify the intended target in 48.3 percent of episodes and enter its 2 m neighborhood in 68.7 percent, but terminate successfully in only 24.9 percent and achieve grounded 1 m success in 5.5 percent. Success is highest for event-script intents (28.7 percent) and lower for physical-state and affordance intents (19.2 percent and 18.5 percent), showing that indirect human intent remains a bottleneck for target selection, visual verification, and terminal localization in active embodied search.

## 1. 论文核心问题与整体含义

- **研究动机**：现有物体导航基准（如 ObjectNav）直接告诉智能体要寻找的物体类别（如“微波炉”），而人类在真实交互中常以间接、模糊的意图下达任务（如“需要加热食物”“房间有点闷”）。这要求智能体不仅完成导航，更要在没有类别名的情况下，从意图中推断出目标物体，并在场景中找到具体实例、决定何时停止。
- **整体含义**：论文提出 **意图驱动的物体导航** 这一新设定，并构建了专门的诊断基准 **IntentionNav**，旨在系统评估具身智能体从隐式人类指令出发，完成“意图理解→目标推理→主动搜索→落地终止”全链条的能力，而非仅看最终成功率。其核心关注点是将语言上的意图推理与视觉、导航行为分离，定位失败发生在哪一环节。

## 2. 方法论

- **任务形式化**：将意图驱动导航定义为目标模糊的主动搜索问题。智能体接收自由文本意图 `u`，获得 RGB‑D 观测和位姿，但绝不知道真正的目标类别 `c⋆` 和实例。它必须在探索中借助场景视觉证据，从多个可能的物体类别中锁定唯一的目标实例并停止在附近。
- **基准构建**：
  - **自动候选生成**：在 176 个 Isaac Sim 室内场景中，利用场景图、相机视角等生成 17,624 个候选意图集合，每个意图再写成四种英文风格（正式、自然、随意、情绪化）。
  - **人工筛选与诊断标注**：通过目标名称防泄漏、视觉答案唯一性、物理唯一性等严格门控，筛选出 **500 个高质量意图**，对应 **64 个目标类别**，并保证每种意图均有四种风格（共 2000 条指令）。每个意图还标注了四种**意图模式**（事件脚本、内部状态、物理状态、可供性），用于考察不同推理类型的影响。
  - **配对设计**：同一意图的不同风格共用相同的场景、目标及其位置，从而可将成功率的差异纯粹归因于语言表述，而非环境变化。
- **评估框架**：
  - 采用固定的**参考导航智能体**（模块化感知、建图、规划器），仅替换后端 VLM 进行实验。
  - 定义多级诊断指标：
    - **IM**（意图匹配，预测类别是否正确）
    - **SR**（终端位置是否在目标 2 m 内）
    - **GSR**（终点 1 m 内且最终画面中目标可见）
    - **OSR**（轨迹中是否曾进入目标 2 m 邻域）
    - **SPL**（路径效率）和 **TL**（成功轨迹长度）
  - 计算诊断差距：`ginfer = IM – SR` 衡量意图推断的损失；`gterm = OSR – SR` 衡量“到达邻域但未成功停止”的损失；`gprec = SR – GSR` 衡量终端定位与视觉验证的损失。

## 3. 实验设计

- **数据集 / 场景**：在 **VLNVerse** 仿真环境（基于 Isaac Sim）的 176 个室内场景上运行，覆盖客厅、卧室、浴室、厨房等。每条指令对应的场景、起点、目标均固定。
- **对比的模型与方法**：评估了 **三个视觉‑语言模型**：
  - **GPT‑5.4**
  - **Qwen3.6‑Plus**
  - **Gemini‑3.1‑Flash‑Lite**
  所有模型共享相同的导航流水线（感知、检测、建图、终止条件），仅 VLM 负责从意图和观测中推断目标类别和探索方向。因此对比的是不同 VLM 在固定导航框架下的表现。
- **诊断消融实验**：在 Gemini 模型上进行了**显式目标诊断**，将指令直接替换为真实目标类别名，而保留完全相同的场景和导航设定，以孤立意图推理环节的困难。

## 4. 资源与算力

- 文中明确提到：对三个模型在 **2000 个 episode** 上的完整评估，总计约需 **150 GPU‑小时**，使用 **NVIDIA RTX 5090** 进行本地运行。由于部分 VLM 通过外部 API 调用，实际墙钟时间受 API 延迟影响更大。

## 5. 实验数量与充分性

- **总实验规模**：3 个模型 × 2000 个 episode（每个模型覆盖全部 500 个意图的 4 种风格）＝ **6000 次导航评估**。
- **其他实验**：显式目标诊断实验（额外 500 个 episode）；对意图模式标签的双人标注一致性检验（100 条样例，κ = 0.86）；质量审计中的多轮人工审查与修正。
- **充分性与公平性**：实验通过**配对设计**严格控制了场景、目标位置等变量，语言风格成为唯一控制因素。四个意图模式覆盖了真实人类意图的主要类型，分层分析系统且详尽。不同模型共享完全相同的感知和规划组件，保证了对比的公平性。实验数量和变量控制足以支撑论文的诊断目标。

## 6. 主要结论与发现

- **整体成绩低下**：三个模型平均 IM 为 0.483，OSR 为 0.687，但最终 SR 仅 0.249，GSR 更是低至 0.055。这说明智能体常常能“猜到目标”、“走到附近”，却很难在正确位置停下来并确认目标。
- **失败主因在终止阶段**：诊断差距 `gterm = 0.438` 远大于 `ginfer = 0.234`，表明大部分失败发生在已经进入目标邻域之后，即**视觉证据积累、终端决策和近距离精确定位**是最大瓶颈。
- **意图模式影响显著**：**事件脚本类意图**成功率最高（均值 0.287），而**物理状态类**和**可供性类**最低（0.192 和 0.185）。这说明依靠活动或情境推断目标相对容易，仅依赖功能描述或环境条件则困难得多。
- **显式目标仍有较高失败**：即使直接告知目标类别，SR 也仅提升到 0.448，GSR 也只有 0.124。这证明除了意图推理，感知、搜索和定位自身也是顽固的短板。
- **风格鲁棒性有限**：四种风格下整体成功率波动不大，但同一意图在所有风格下均成功的比例（CSR）仅有 5.6%–9.6%，存在明显的个案级不稳定现象。

## 7. 优点

- **诊断性设计**：将“意图→导航”链拆解为可量化差距，能够指出系统瓶颈具体位置，而不仅给出一个总成功率。
- **语言与语义正交控制**：通过控制指令风格和意图模式，同一场景可独立分析表述方式和推理类型的影响，避免了混淆变量。
- **严格的质量保证**：自动生成加人工筛选、目标防泄漏、物理唯一性验证和多轮质量审计，保证了基准的干净性和科学性。
- **可复现的评估框架**：固定导航智能体，仅替换 VLM，易于对比不同模型的长处与短板，且提供了完整的指标与同义词词汇表。

## 8. 不足与局限

- **仿真单一性**：所有实验限于 Isaac Sim 的虚拟室内场景，未涉及真实世界部署中传感器噪声、动态环境等挑战。
- **语言与任务受限**：仅支持英语、单意图、单目标的静止家庭环境，无澄清对话、多轮交互或多人协作，距离真实人机交互尚有距离。
- **时间与交互限制**：导航步长固定为 30 步（约双倍人类路径点），终止判决依赖瞬时视觉证据而非累计置信度，可能夸大了终端失败。
- **指标依赖**：IM 使用有限的同义词词汇表进行匹配，无法完全覆盖灵活的自然语言表达；自动评分法官（VLM）和编写流程可能引入未知偏差。
- **系统可控性**：外部 VLM 服务的行为可能随时间更新而变化，长期复现需要记录具体版本；部分场景资源和模型权重未随论文公开。
