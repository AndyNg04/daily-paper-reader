## 摘要
使用工具的大语言模型智能体不仅需要判断是否需要额外信息，还需要确定哪一信息来源能够消除不确定性。现有主动式方法通常侧重于向用户澄清或对环境进行核实，却未显式判断每项决策应依赖的信息来源。我们将这一问题表述为在执行（ACT）、澄清（CLARIFY）和核实（VERIFY）之间进行不确定性路由，并提出主动式不确定性路由框架 PROUR。PROUR 将行动不确定性分解为不同合理用户目标解释之间的分歧，以及每种解释下仍然存在的熵：前者表明用户侧存在歧义，后者表明缺少世界侧证据。为从路由选定的来源获取信息，我们利用以模式为条件的信息增益奖励训练查询生成器，使其在 CLARIFY 模式下识别用户目标，在 VERIFY 模式下确定下一步行动。在 $τ$-bench 的零售和航空任务中，PROUR 的平均成功率达到 28.17%，比此前最强的方法高出 4.57 个百分点，同时交互步骤减少 2.17 步。所学策略无需重新训练即可泛化至更强的任务智能体及 $τ^3$-bench 的事务处理领域，表明依据不确定性来源进行信息获取有助于提升主动式智能体的表现。

## Abstract
Tool-using LLM agents must decide not only whether additional information is needed, but also which source can resolve the uncertainty. Existing proactive approaches often specialize in either user clarification or environment verification, without explicitly determining the appropriate information source for each decision. We formulate this problem as uncertainty routing among ACT, CLARIFY, and VERIFY, and propose PROUR, a proactive uncertainty routing framework. PROUR decomposes action uncertainty into disagreement across plausible user-goal interpretations, which signals user-side ambiguity, and the entropy remaining within each interpretation, which signals missing world-side evidence. To acquire information from the routed source, a query generator is trained with a mode-conditioned information-gain reward, targeting user-goal identification under CLARIFY and next-action identification under VERIFY. On $τ$-bench, PROUR achieves 28.17% average success rate across retail and airline, outperforming the strongest prior method by 4.57% while using 2.17 fewer interaction steps. The learned policy further generalizes to stronger task agents and transactional domains of $τ^3$-bench without retraining, demonstrating the benefit of source-aligned uncertainty resolution for proactive agents.
