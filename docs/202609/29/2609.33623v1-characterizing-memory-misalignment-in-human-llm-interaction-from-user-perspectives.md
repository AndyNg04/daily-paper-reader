## 摘要
尽管记忆功能增强了基于大语言模型的对话智能体的个性化能力，但它也存在记忆失配问题，即记忆内容或其使用方式不符合用户预期。我们采用混合方法，从用户视角研究记忆失配的表现及缓解方式。首先，我们收集了记忆使用数据（N=28，457条记录）和日记研究数据（N=32，304份报告），据此建立了涵盖记忆摄入、存储与管理、检索与解释三个阶段共14种失配类型的分类体系。其次，我们与12名经验丰富的人机交互研究者开展了四场共同设计工作坊，构建了应对记忆失配的设计空间，其中包含按交互形式、介入时机和干扰程度三个维度组织的12种候选交互策略。最后，一项有121名用户参与的快速约会式设计评估揭示了用户偏好的异质性：相比需要较高认知投入的因果图检查或被动式审计日志，用户更倾向于主动控制机制。综合这些发现，我们指出用户监督自主权与交互负担之间的张力，并倡导设计能够感知交互阻力的记忆机制，以平衡用户监督与对话流畅性。

## Abstract
While memory enhances personalization in LLM-based conversational agents, it suffers from memory misalignment, where memories violate user expectations. We present a mixed-methods investigation to characterize and mitigate memory misalignment from user perspectives. First, we collected data from memory usage (N=28, 457 entries) and diary study (N=32, 304 reports), which yielded a taxonomy spanning 14 misalignment types across memory intake, storage and management, retrieval and interpretation stages. Second, four co-design workshops with 12 experienced HCI researchers derived a design space to tackle memory misalignment issues, consisting of 12 candidate interaction strategies structured across interaction form, placement and intrusiveness dimensions. Finally, a speed dating with 121 users reveals preference heterogeneity, where users prioritize proactive controls over cognitively demanding causal graph inspections or passive audit logs. Synthesizing these findings, we highlight the tension between supervisory agency and interaction overhead, and advocate for friction-aware memories that balance user oversight with conversation smoothness.

## 1. 核心问题与整体含义

- **研究问题**：对话式大语言模型会保存并调用用户信息，以减少重复说明、提供个性化回答；但系统对信息的**记录、保留或使用**，可能不符合用户当下的意图与预期。论文将这种差异称为“记忆失配”。
- **关键视角**：记忆失配不等同于事实错误。一条记忆即使准确，也可能因涉及隐私、已经过时，或被用在不合适的场景而造成不适。例如，用户平时偏好简短回答，不意味着节日祝福也应被压缩。
- **研究目标**：回答三类问题——失配有哪些表现、可以怎样通过交互设计缓解，以及用户如何评价这些设计。其整体含义是：评估智能体记忆，不能只看“记住了多少、检索得多准”，还要看用户能否决定**记什么、保存多久、何时调用以及如何纠正**。

## 2. 方法论与研究流程

这是一项**以用户研究为主的混合方法研究**，并未提出或训练新的记忆模型。整体流程为“识别问题 → 共创方案 → 评估偏好”。

1. **建立失配分类**：研究者分别分析用户导出的聊天机器人记忆，以及日常使用中的记忆体验报告；通过开放编码、持续比较和多位作者讨论，将案例归入记忆生命周期的三个阶段，并参考认知心理学中的记忆错误分类。
   - **摄入阶段（I1–I5）**：过度推断、把第三方信息误归给用户、身份误推断、虚构记忆，以及用户虽承认信息准确却拒绝其被持久保存。
   - **存储与管理阶段（I6–I8）**：信息过时、概括粒度不当、复杂任务约束被简化到失去用途。
   - **检索与解释阶段（I9–I14）**：使用过时的时间或地点信息、使用过于粗略的记忆、漏用相关记忆、调用虚构记忆、在不适合的情境中过度套用记忆，以及引用过细或敏感的个人信息。

2. **共创缓解策略**：12名有经验的 HCI 研究者在四场工作坊中提交24个概念，研究团队通过亲和图与主题分析，将其整合为**12种交互设计**。它们涵盖任务后确认记忆去向、任务前设置记忆边界、逐条授权、细粒度控制、记忆模式切换、默认保护敏感信息、记忆库编辑、自然语言更新、活动时间线，以及因果解释等。
   - 设计空间有三个维度：**交互形式**（面板、桌面伴侣、对话）、**放置位置**（聊天内或聊天外）、**干扰程度**（低、中、高）。
   - 一个重要设计思想是将“**读取旧记忆**”与“**写入新记忆**”分开控制：用户可能希望当前任务使用既有偏好，却不希望本次临时对话被长期保存。

3. **评估设计偏好**：研究者为12种设计制作故事板和高保真交互原型；每位受试者随机体验其中三种，进行评分与排序。分析采用参与者内标签置换检验处理不完整区组评分数据，并用 **Plackett–Luce 排序模型**估计各设计的相对偏好权重；开放反馈则进行定性编码。这些方法衡量的是**用户感知和选择**，而非策略部署后的实际纠错率。

## 6. 主要结论与发现

- **失配贯穿整个记忆生命周期**：问题既可能始于把一次性查询误写成长期偏好，也可能发生在记忆过期未更新，或回答时把准确记忆用错场景。
- **用户总体更偏好可操作的主动控制**：排序模型中，任务后决定记忆去向（D1）、任务前设置边界（D2）、细粒度控制（D7）和记忆模式切换（D8）权重较高；桌面伴侣提醒（D6）和活动时间线（D12）较低。被动展示“系统做了什么”，通常不如让用户直接修改、授权或阻止。
- **控制权与交互负担存在张力**：逐条确认虽能提升监督，却可能造成提示疲劳；完整因果链便于追责，却不适合作为日常默认界面。论文因此主张“**感知交互阻力的记忆设计**”：在自然任务节点提供轻量确认，按风险触发更强干预，仅在需要时展开详细溯源。
- **边界应具有情境性**：工作、私人生活、临时任务和敏感披露不宜被合并为单一用户画像；历史记忆是否可用于当前任务，也应与当前内容是否可被保存分别决定。
