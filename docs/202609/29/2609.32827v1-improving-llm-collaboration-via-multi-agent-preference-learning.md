## 摘要
已有多项研究探索了多智能体强化学习（MARL）在大语言模型协作中的应用。然而，在实践中构建可靠的奖励信号并不容易，因为完整、准确的评价指标通常难以获取，也难以整合。偏好学习通过从人类或人工智能的比较反馈中学习，提供了另一种途径，但其在多智能体系统中的应用仍缺乏充分研究。为填补这一空白，我们从去中心化和中心化协作两个视角，对基于偏好的多智能体系统（MAS）进行形式化建模，并提出一个通用的多智能体偏好学习框架（MAPL）来解决这些问题。MAPL通过比较当前方案与不同智能体生成的去中心化或中心化方案，实现迭代更新。我们分别采用基于学习得到的奖励模型、从人类反馈中学习的多智能体强化学习（MARLHF），以及多智能体直接偏好优化（MADPO）来实现MAPL。在协作写作、编程、工具使用和旅行规划任务上的实验表明，MAPL能够提升协作质量和效率，其性能接近采用固定且明确定义的奖励信号的MARL。在MAPL框架内，MARLHF在大多数任务上的表现通常优于MADPO，但仍对数据覆盖范围、智能体模型与比较模型，以及底层MARL算法较为敏感。

## Abstract
Several works have explored multi-agent reinforcement learning (MARL) in LLM collaboration. However, constructing reliable rewards is difficult in practice, as complete and accurate metrics are often unavailable and hard to aggregate. Preference learning provides an alternative by learning from comparative human or AI feedback. Yet, its extension to multi-agent systems remains underexplored. To address this gap, we formulate preference-based multi-agent systems (MAS) from decentralized and centralized collaboration perspectives. We also introduce a general multi-agent preference learning framework (MAPL) to solve these problems. MAPL allows iterative updates by comparing the current solution with decentralized or centralized solutions generated by various agents. We instantiate MAPL using MARL from human feedback (MARLHF) with a learned reward model and multi-agent direct preference optimization (MADPO). Experiments on collaborative writing, coding, tool use, and travel planning show that MAPL can improve collaboration quality and efficiency while approaching the performance of MARL with fixed, well-defined rewards. Within MAPL, MARLHF generally outperforms MADPO on most tasks but remains sensitive to data coverage, agent and comparator models, and the underlying MARL algorithms.

# 1. 核心问题与研究意义

- **问题**：多智能体大语言模型可以分工完成写作、编程和规划任务，但通常未经专门的协作训练。用多智能体强化学习（MARL）改进协作时，又需要完整、准确、可汇总的奖励函数；现实任务往往难以满足这一条件。
- **研究思路**：与其为每个方案指定精确分数，不如比较两个团队方案的优劣，并据此训练智能体。论文研究如何将这种偏好学习用于**去中心化**协作（各智能体仅依据本地信息行动）和**中心化**协作（依据共享信息协调行动）。
- **整体含义**：MAPL为难以设计显式奖励的协作任务提供了一条训练路径；但论文同时表明，比较反馈的价值取决于数据是否覆盖有效协作方式，以及被训练智能体能否实现比较模型所展示的行为。

# 2. 方法论：MAPL框架与两种实现

- **问题建模**：论文分别用基于偏好的 Dec-POMDP 和 MPOMDP 描述去中心化、中心化协作。训练目标仍是提高团队的累计质量，但训练主要接收的是**整条联合轨迹之间的偏好**，而非每一步的真实奖励。
- **MAPL的迭代流程**：
  1. 让当前智能体团队和一个“比较模型”针对同一任务分别生成方案。
  2. 比较两条联合轨迹，得到优选与劣选样本；丢弃平局。
  3. 从中保留优选方案质量较高的样本，并通过回放缓冲区混合不同训练阶段的数据。
  4. 用偏好对更新团队，重复上述过程。
- **三种信息结构**：**Dec-Dec**（去中心化团队与比较模型）、**Cen-Cen**（两者均中心化）、**Dec-Cen**（去中心化团队、中心化比较模型）。最后一种设置可以测试团队能否从拥有更完整信息的比较模型中学习。
- **两种优化实现**：
  - **MARLHF**：先用 Bradley–Terry 式成对偏好损失训练奖励模型，使优选轨迹的预测累计奖励高于劣选轨迹；再固定该模型，用带参考策略 KL 约束的 MARL 更新智能体。主要实现采用同一任务的多条采样轨迹构造**组相对优势**，以组均值作基线，不另行训练 critic。
  - **MADPO**：不显式训练奖励模型，而将一条轨迹的隐式奖励写成当前策略相对参考策略的对数概率比之和，直接提高优选轨迹相对于劣选轨迹的概率。
- **关键区别**：MARLHF多一道奖励建模和在线策略优化步骤，成本更高，但能利用新采样方案继续探索；MADPO流程较简洁，却更依赖偏好样本本身的质量和覆盖范围。

# 6. 主要结论与发现

- **偏好训练确实能改善协作，但“接近奖励式MARL”取决于任务和指标。** 例如，TLDR 中 MADPO Dec-Dec 得分 **92.9**，接近 MAGRPO 的 **93.5**；Travel 中 MARLHF Cen-Cen 的常识约束通过率为 **76.4%**，接近 MAGRPO 的 **76.2%**。但最强的 oracle 奖励基线 CoLLM-CC 在 Travel 上达到 **84.3%**，不能笼统认为MAPL全面追平所有奖励式MARL方法。
- **匹配的信息结构更可靠**：Cen-Cen在多数任务上表现较好；Dec-Dec经训练也能取得可观收益。Dec-Cen通常较差，说明中心化比较模型利用的信息或能力，去中心化智能体未必能够复制。
- **MARLHF通常比MADPO稳健，但并非处处占优**。例如，Travel 的 Dec-Dec 常识通过率分别为 **70.5%** 与 **41.5%**；而在TLDR的Dec-Dec设置下，MADPO得分 **92.9**，高于MARLHF的 **86.3**。
- **更多或更强的比较样本不必然更好**：混合新旧样本的衰减缓冲区通常有利；仅增加离线样本、扩大比较模型或增加智能体数量，均可能因数据质量、能力差距及信用分配难度而失效。MARLHF中，组相对优势方法也明显优于所测试的 actor–critic 替代方案。

# 7. 论文优点

- 将**协作的信息结构**纳入偏好学习问题建模，而不只是把单智能体DPO直接用于多智能体输出。
- 在统一框架内比较**显式奖励模型加MARL**与**直接偏好优化**，有助于辨析两条路线的收益、稳定性和资源代价。
- 消融覆盖数据新鲜度、比较模型能力、优化算法及智能体规模，揭示了一个实用结论：**比较对象是否与目标团队“学得了、做得到”同样重要**。
- 提供具体训练配置、硬件和显存记录，便于评估复现与应用成本。

# 8. 不足与局限

- **真实偏好验证不足**：主要实验由人工设计的奖励函数生成标签，并据此挑选高质量偏好对。这证明了框架在可计算评价下的潜力，却尚未证明它在奖励标准未知、标注存在分歧时仍同样有效。
- **任务与规模有限**：主要是两智能体、较短或经筛选的任务；三智能体结果具有任务依赖性，不能据此推断可稳定扩展至大型团队和长时程交互。
- **整轨迹反馈稀疏**：方案好坏容易比较，但难以确定是哪位智能体、哪一步造成差异；任务越长，奖励建模与信用分配越困难。
- **方法依赖可实现性与数据分布**：MADPO的推导包含较强的策略分布可实现性假设；实践中较强或拥有更多信息的比较模型可能产生目标团队无法学会的方案。MADPO在Travel上还出现训练后期退化。
- **效率结论应谨慎解读**：并行分工有降低部分顺序依赖的潜力，但本文未充分给出质量、训练总成本和实际推理延迟之间的统一比较；MAPL训练本身也可能比直接使用已知奖励的MARL昂贵。
