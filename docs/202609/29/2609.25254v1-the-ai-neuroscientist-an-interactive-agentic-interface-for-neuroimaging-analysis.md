## 摘要
神经影像数据分析需要专门的编程和统计学知识，这限制了缺乏计算背景的研究人员开展此类分析。我们提出“AI 神经科学家”，一种用于交互式数据探索的语言智能体。该系统将大语言模型（LLM）与神经影像工具集相结合，可执行质量控制、建模和可视化。研究人员由此可以直接使用自然语言查询数据质量并指定分析参数，为小规模数据探索提供一种透明、交互式的替代方案，以取代传统的脚本化分析流程。我们使用功能性近红外光谱（fNIRS）数据展示了这些能力，并通过一套定制的 fNIRS 基准测试，将该智能体与配备代码沙箱的通用大语言模型智能体进行比较评估。未来，我们将扩展该架构，使其适用于包括功能性磁共振成像（fMRI）数据在内的其他模态，并将基准测试扩展至更多 fNIRS 任务。

## Abstract
Analyzing neuroimaging data requires specialized coding and statistical expertise, which limits accessibility for researchers without computational backgrounds. We present the AI Neuroscientist, a language agent for interactive data exploration. The system integrates a large language model (LLM) with a neuroimaging toolset to perform quality control, modeling, and visualization. This allows researchers to query data quality and specify analysis parameters directly in natural language, providing a transparent and interactive alternative to conventional scripted pipelines for small-scale data exploration. We demonstrate these capabilities using functional near-infrared spectroscopy (fNIRS) data, and evaluate the agent on a custom fNIRS benchmarking suite against general-purpose LLM agents with code sandboxes. Future extensions will generalize the architecture to additional modalities, including functional magnetic resonance imaging (fMRI) data, and expand the benchmarking suite to additional fNIRS tasks.

## 1. 核心问题与整体含义

- **研究问题：**fNIRS、fMRI 等神经影像分析需要处理专用数据格式、检查信号质量、选择预处理参数并进行统计建模。即使已有标准化工具，缺乏编程背景的研究者仍难以独立完成和核查这些步骤。
- **论文目标：**构建一个自然语言交互界面，让研究者能够询问“数据是否干净”、调整质量控制（QC）阈值、运行模型并查看结果，而不必亲自编写串联各工具的脚本。
- **适用定位：**系统面向**单受试者或少量实验运行的小规模交互式探索**，并非无人值守的批处理系统，也不用于临床决策。其核心意义是让语言模型协调成熟的分析工具，而不是让模型凭语言知识直接给出科学结论。

## 2. 方法论：受约束的工具调用与证据驱动分析

- **智能体架构：**系统采用基于 LangGraph/LangChain 的 ReAct 智能体，将用户请求路由到预先注册的 fNIRS 专业工具。流程按“数据发现与 QC → 分析与多重比较校正 → 可视化 → 结果解释”推进，避免在检查数据质量或校正显著性之前作出推断。
- **分阶段处理输入：**系统兼容 SNIRF/BIDS 强度数据、光密度（OD）数据及已有的血红蛋白浓度 MAT 文件，并将它们统一为共享记录对象。强度数据进入光密度转换、通道筛选、运动伪迹修复和 HbO/HbR 估计流程；已转换的数据则跳过相应上游步骤，避免重复预处理。
- **主要工具与算法：**
  - QC 包括心跳频段信噪比、头皮耦合指数（SCI）、通道评级及基于中位数绝对偏差（MAD）的振幅尖峰检测。
  - 建模包括事件提取、分段、采用典型血流动力学响应函数的广义线性模型（GLM），以及 Benjamini–Hochberg 假发现率（FDR）校正。
  - 各阶段保存可检查的中间产物，如通道掩码、GLM 估计、校正后的显著性掩码、ERP 曲线和脑区拓扑图。
- **视觉解释机制：**面对需要解读图像的问题，智能体先检索已生成的图，再将选中的图像附加到第二轮推理中，使解释至少能够对应具体的视觉产物，而非仅依赖对话记忆。

## 3. 实验设计与比较对象

- **基准测试 `fnirs_bench`：**共 **6 个任务**，覆盖三类能力：
  - **T1a–c：心跳信号 QC。**分别使用合成数据、真实混合质量数据和真实低信噪比数据，输出逐通道可用掩码及受试者可用性判断。
  - **T2a–b：振幅尖峰检测。**分别使用合成数据和真实运动伪迹数据，输出与通道及时间点对齐的尖峰掩码。
  - **T3：解剖定位判断。**比较符合右手任务预期的左侧运动区激活图，与传感器坐标旋转后不再解剖合理的图。
- **数据来源：**合成任务基于公开的 MNE 手指—拇指敲击运动记录构造；真实 OD 数据来自 OpenNeuro BIDS 导出，包括 ds007554 和 ds007420。另有一个右手手指敲击 fNIRS 运行用于端到端交互案例展示。
- **对比方法与运行方式：**专业智能体以 **gpt-5-nano** 为模型骨干，调用固定工具；两个通用智能体分别使用 **gpt-5-nano** 和 **claude-sonnet-5**，在隔离代码沙箱中自行编写或执行分析代码。每个智能体在每项任务上独立运行 **5 次**。
- **评价方式：**心跳 QC 主要使用好通道集合的 F1 和受试者判断准确性；尖峰检测使用掩码交并比（IoU）；定位任务采用文本关键词规则。此外，最终分数会扣除跨次运行的**工具调用轨迹不一致**和**数值掩码方差**，因此不只衡量单次产物是否正确。

## 5. 实验数量、充分性与公平性

- **实验规模：**量化评估包含 6 个任务 × 3 类智能体 × 每任务 5 次运行，约 **90 次任务运行**；另有一例完整交互流程。合成与真实数据兼有，但任务范围主要集中在 QC 和尖峰检测，视觉判断仅有一个双图任务。
- **较为客观之处：**评测使用统一提示、隔离的任务输入与输出目录、未向智能体开放的参考结果，并重复运行以考察稳定性；同为 gpt-5-nano 的专业版与通用版也提供了有价值的对照。
- **仍需谨慎之处：**
  - 数值任务的参考答案来自特定的确定性算法，而专业智能体已配备相应或近似的专用工具；结果有力地说明了**工具匹配与编排的优势**，但不能单独证明其具有更强的通用科学分析能力。

## 6. 主要结论与发现

- 在六任务平均最终得分上，**AI Neuroscientist 为 0.79 ± 0.05**，高于 Claude 通用智能体的 **0.45 ± 0.07** 和同骨干 GPT 通用智能体的 **0.14 ± 0.06**。优势主要来自真实低信噪比 QC 和真实运动尖峰检测；专业工具的稳定调用也减少了可靠性扣分。
- **解剖定位任务三者均约为 0.5**：专业工具优势没有延伸到这一开放式视觉判断，智能体仍可能把旋转后不合理的激活图误判为符合预期。
- 端到端案例表明系统可以响应用户调整 QC 阈值、运行 GLM 与 FDR 校正，并生成交互图。不过，案例中的显著激活广泛分布，作者也提示低信噪比、系统性生理信号及模型残差自相关可能影响解释；**“通过 FDR”不等于结果已经具有充分的神经科学有效性**。

## 7. 优点与亮点

- **贴合实际工作流：**把自然语言请求映射到明确的 QC、建模和可视化操作，并允许研究者交互式调整参数。
- **中间结果可核查：**保存通道评级、统计掩码及图像等产物，比只返回一段模型回答更便于追溯。
- **科学约束较清晰：**强调先 QC、后推断，并在报告显著激活前进行多重比较校正。
- **评测考虑重复稳定性：**除产物质量外，还检查多次运行的工具轨迹和数值输出，揭示通用智能体临时重写分析代码时的脆弱性。

## 8. 不足与局限

- **模态与任务覆盖有限：**目前验证集中在 fNIRS；fMRI、EEG 等仍属未来计划，基准也尚未充分覆盖完整预处理、GLM 正确性和复杂视觉解释。
- **质量控制可能被参数调整削弱：**案例中放宽心跳 SNR 阈值后，原本被判为较差的数据进入了分析；更关键的是，记录显示后续 **GLM 仍使用全部通道**，未自动排除先前标记的 4 个红色通道。这说明“QC 门控”在展示流程中尚未落实为严格的建模约束。
- **统计解释仍有风险：**案例使用的简单 GLM 未对时间序列残差自相关作 AR 建模，且缺乏短距通道回归；FDR 无法消除前处理、模型设定或全局生理干扰造成的偏差。
- **视觉推理与应用效果未证实：**定位任务暴露出自信误判；论文也没有证明该界面相较专家脚本能提高统计有效性、科学发现率或真实研究者的工作效率。因此，现阶段更适合作为**有人监督的探索与辅助分析工具**，而非独立的结论生成系统。
