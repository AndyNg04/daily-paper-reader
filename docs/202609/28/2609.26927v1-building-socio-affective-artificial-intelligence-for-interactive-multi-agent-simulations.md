## 摘要
本文旨在提出设计原则和软件架构，以支持人类与多个智能体在动态模拟世界中交互。这一研究将当前通用人工智能（AI/AGI）的发展与基于 Transformer 的对话智能体日益普及及计算能力的提升联系起来。在梳理当前及以往关于多智能体心智理论（具备社会和情感感知能力的智能体）的研究后，本文认为，整合设计智能体之间及其与人类之间的交互，对于理解如何在未来的人机推理系统中实现可持续性与有效治理至关重要。本文提出了名为“AGIMUD”的软件，它整合了：（A）智能体行为与交互中的社会感知推理和情感；（B）面向人类用户、人工智能体和模拟世界的多模态交互方案；（C）通过网络分布式处理人工智能任务，以支持多个自主智能体。这些整合使得以多人地下城（MUD）形式重建动态世界成为可能，智能体与人类可在其中同时进行实时交互。代码见：https://github.com/dberga/AGIMUD。

## Abstract
The objective of this article is to provide design principles and a software architecture for enabling interaction between humans and multiple agents in simulated dynamic worlds. This connects the current era of general artificial intelligence (AI/AGI) with the proliferation of transformer-based conversational agents and the increased computational capabilities. Given an overview of current and previous multi-agent theories of mind (socially and affectively-aware agents), the existence of an integrative design of agent interactions with themselves and with humans must be crucial for understanding how to create sustainable and governance in future human-agent reasoning systems. In this work is presented a software "AGIMUD" that integrates: A. socially-aware reasoning and emotion in agent behavior and interaction, B. a design of human multimodal scheme for human users, artificial agents and simulated worlds, and C. distributing the AI processing through the network to enable multiple autonomous agents. These integrations allow the dynamic world recreation as multi-user dungeons (MUDs) where both agents and humans can interact simultaneously in real time. Find the code online in https://github.com/dberga/AGIMUD.

# 1. 核心问题与研究背景

- **问题**：如何让人类与多个自主智能体在持续变化的模拟世界中同时交互，并使智能体的行动兼顾情绪、社会认知、合作公平与世界规则。
- **动机**：传统规则式智能体难以覆盖复杂情境；大语言模型虽能生成灵活的对话和行动意图，却可能产生幻觉、遗忘世界状态，或提出不符合物理与社会规则的行动。论文因此尝试将语言模型的生成能力与可验证的规则系统结合。
- **整体定位**：AGIMUD 是一个面向多人文字冒险世界（MUD）的**开源软件架构与概念验证**，重点不是训练新模型，而是组织模拟世界、社会情感决策和人机网络交互。

# 2. 方法论与关键技术

- **模块化模拟架构**：将输入输出、文本处理、模拟世界模块（SWM）和语言模型处理分离。世界按离散的 *epoch* 更新，语言模型可异步生成意图，避免同步推理阻塞世界运行。世界、实体、条件和规则由配置文件及模板生成。
- **“生成意图—规则筛选—执行行动”流程**：语言模型提出候选意图后，系统结合行动目录、实体状态及规则进行检查；社会推理核心为可行动作评分，再选择效用最高者。论文将这一过程概括为感知、推断他人状态、验证规范、生成目标、决策规划五个阶段。
- **社会推理核心**：综合四类机制：
  - **Schwartz 价值观**：用个人价值权重衡量行动与自身动机的契合程度；
  - **Ostrom 制度规则**：衡量行动的规则遵守情况和可能受到的制裁；
  - **Montes–Sierra 信念机制**：比较自身信念与对他人信念的估计，并在通信异常时施加差异惩罚；
  - **Shapley 值**：用于表征合作贡献与分配公平性。  
  总体上，系统最大化“个人价值收益＋规范收益－信念差异惩罚－公平性惩罚”。论文给出了公式，但实际效果取决于各项分数与权重的设定。
- **情绪—推理—行为闭环**：智能体具有愤怒、恐惧、厌恶、悲伤、喜悦、惊讶六类情绪，以及中性状态。事件触发情绪评估；健康、体力和既有情绪影响强度；情绪再影响目标与行动倾向。行动结果反过来触发新的情绪评估。实现中还设置了情绪记忆、持续时间和衰减。
- **人机交互与网络**：当前实现主要通过文字命令和聊天让用户、智能体访问同一世界，提供中心服务器及 P2P 两种运行方式，并演示本地语言模型客户端。语音、手势、生理传感器及 2D/3D 引擎接入主要属于**架构设计或后续扩展方向**，不应视为已完成的多模态实测能力。

# 3. 实验设计、场景与对比

- **没有标准外部数据集或统一 benchmark**。评估主要使用作者配置和生成的 MUD 生存式世界、角色档案、事件、规则及预期行动；论文也没有与其他多智能体框架开展同条件、同指标的实测对比。

- **情绪单元测试**：在独立的情绪模块中检查事件到情绪的映射、健康与体力对强度的影响、事件序列中的情绪惯性、行动倾向，以及无新事件时的持续与衰减。

# 6. 主要结论与发现

- **架构可行性**：论文展示了可配置世界、社会推理、情绪更新、文字命令和语言模型聊天客户端能够在同一 MUD 系统中组合运行。
- **社会推理存在明显退化**：50 次测试最终**全部选中同一个**“可持续共享采集”行动；在 41 项有预期结果的测试中，仅 **11 项匹配，匹配率 26.8%**。作者将其归因于多个合作行动效用相同形成的平台，以及行动目录顺序的平局裁决；较大的信念差异和制度惩罚也压制了行为多样性。
- **情绪模块通过预设功能检查**：事件按配置映射到六类情绪，强度随身体状态及前一状态变化，并能在无新事件后衰减回中性。这证明了实现的规则运行，**不等同于证明情绪具有心理真实性**。
- **模拟统计具有一定跨规模一致性**：所报告的五种规模中，平均健康与 AI 状态熵的相关系数约为 **−0.64 至 −0.67**；饥饿与状态熵约为 **＋0.50 至＋0.56**。这些是模拟系统内部的相关现象，不能直接解释为因果关系或对现实群体的预测。

# 7. 优点与亮点

- 将**语言模型生成**与**可检查的世界规则**分层，便于限制不合世界状态的行动，并保留配置灵活性。
- 在同一框架中组织价值观、制度治理、信念归因、合作公平和情绪反馈，为研究这些因素如何共同影响智能体行为提供了可修改的实验平台。
- 提供代码、世界模板、客户端命令和跨规模模拟结果；同时如实报告了行动选择全部收敛、匹配率偏低这一不理想结果。

# 8. 不足与局限

- **规则有效性尚未建立**：公式和参数主要由系统设计指定；“符合预设规则”不能直接推出真实的心智理论能力、公平性或伦理安全性。尤其当前效用平台使不同合作行动难以区分。
- **缺乏关键对照**：未比较去掉情绪、制度规则或信念惩罚后的行为，也未与其他框架在相同任务上比较，因此无法归因各组件的增益。
- **人机与分布式主张验证有限**：三名语言模型客户端的聊天是示例，不是用户研究；多模态交互、P2P 状态一致性及大规模实时运行缺少对应实测。
- **统计解释须谨慎**：世界与角色由系统自身生成，相关性可能主要反映内置规则；部分变量与所有活动指标的相关性恒为零，提示这些变量在测试中可能没有有效变化或未充分参与机制。
- **复现与表述问题**：角色规模与相关性样本量存在不一致；论文关于行动目录“验证”的描述也同时允许将未知意图加入可行集合，因此“阻止无效或有害行动”的保证仍需更严格的测试与界定。
