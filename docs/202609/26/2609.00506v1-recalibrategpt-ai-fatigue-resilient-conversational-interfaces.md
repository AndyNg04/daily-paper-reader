## 摘要
大型语言模型能力强大，但其界面常常退化为“输入 → 阅读 → 重新输入”的循环，造成对话式 AI 疲劳、认知负荷，并最终导致任务被放弃。为缓解这一问题，我们提出 RecalibrateGPT，一个引入五种跨轮次操作符（Anchor、Replay、Delta、Scope 和 Steer）的系统；每种操作符针对一种不同的疲劳类型，通过一个结构化面板，只需单击即可作用于完整对话历史，从而重新校准 LLM 响应。用户通过 AssistiveButton 在三种操作符面板布局之一中调用这些操作符：Vertical、Arc 或 Tablet。我们对同样的 12 名高级 LLM 用户进行了两项试点研究。最初的形成性定性研究识别出四种疲劳类型的分类体系（重新输入、扫描、决策瘫痪和上下文漂移），并为 RecalibrateGPT 推导出两个设计目标。后续的定量评估发现，它将感知认知工作量减少了一半（NASA-TLX = 2.7），同时感知可用性很高（SUS = 86.5），这表明 AI 疲劳不只是模型质量问题，而是一种交互流程成本，界面可以将其消除。

## Abstract
Large language models are powerful, but their interfaces often devolve into a type $\rightarrow$ read $\rightarrow$ retype loop, creating conversational AI fatigue, cognitive load, and eventual task abandonment. To mitigate this, we present RecalibrateGPT, a system introducing five cross-turn operators (Anchor, Replay, Delta, Scope, and Steer) that each target a distinct fatigue type, recalibrating LLM responses through a structured panel by acting on the full conversation history with a single click. Users invoke these operators through the AssistiveButton in one of three operator palette layouts: Vertical, Arc, or Tablet. We conducted two pilot studies with the same 12 advanced LLM users. An initial formative qualitative study identifies a taxonomy of four fatigue types (retyping, scanning, decision paralysis, and context drift) and derives two design objectives for RecalibrateGPT. A follow-up quantitative evaluation finds it reduces perceived cognitive workload by half (NASA-TLX = 2.7) at high perceived usability (SUS = 86.5), suggesting AI fatigue is not just a model-quality issue but an interaction-flow cost that interfaces can remove.

# RecalibrateGPT 论文中文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：大型语言模型（LLM）能力强大，但其对话界面常常退化为“输入 → 阅读 → 重新输入”（type → read → retype）的循环。用户不得不反复重述目标、纠正漂移、跟上不断变化的回答，并管理逐轮累积的上下文。
- **后果**：长期使用会产生“对话式 AI 疲劳”，带来认知负荷、挫败感、决策瘫痪，最终导致任务被放弃；在高风险领域（如临床诊断、法律解释）尤为严重。
- **关键立场**：论文主张 AI 疲劳**不只是模型质量问题，更是一种交互流程成本**，可以通过界面设计来消除。
- **现有工作缺口**：
  - 已有系统（如 DirectGPT、Cells and Lenses、Graphologue、ChainForge 等）的操作单位仍是**单轮响应**；
  - 没有系统针对**会话级疲劳**设计操作符；
  - 也没有系统在三种几何布局（Vertical、Arc、Tablet）下定义作用于完整对话历史的操作符。

## 2. 方法论

### 2.1 核心思想

- 提出 **RecalibrateGPT**，引入 **五种跨轮次操作符（cross-turn operators）**，每个针对一种疲劳类型，通过结构化面板**一键作用于完整对话历史**（而非仅上一条回复），重新校准 LLM 响应。
- 将交互循环从“输入 → 阅读 → 重输”转化为更轻量的“输入 → 阅读 → 点击”。

### 2.2 五种操作符及其目标疲劳类型

| 操作符 | 功能 | 目标疲劳类型 |
|---|---|---|
| **Anchor** | 检测当前回复与用户原始目标之间的语义漂移，将输出重新导向原目标 | 上下文漂移（F4） |
| **Replay** | 提取会话摘要：已确立事实、开放问题、下一步行动 | 扫描疲劳（F2） |
| **Delta (Diff)** | 语义比较当前与上一回复的差异，呈现新增内容并标记目标相关的删除 | 重新输入疲劳（F1） |
| **Scope** | 先以可点击选项呈现检测到的子主题，第二次点击展开所选子主题，无需重输 | 重新输入疲劳（F1） |
| **Steer** | 分析目标完成情况，生成三个可点击的后续问题以填补剩余缺口 | 决策瘫痪（F3） |

### 2.3 交互入口与布局

- **AssistiveButton**：所有三种模式下的统一入口。位置自适应——Vertical/Tablet 中位于每条回复后的首个可供性控件；Arc 中锚定在中央输入框左侧。
- **三向模式切换（Three-Way Mode Toggle）**：一次设定一种操作符面板布局：
  - **Vertical**：每条回复左侧的胶囊形侧边栏，适合跨轮重复使用；
  - **Arc**：从 AssistiveButton 辐射出的扇形菜单，适合阅读时快速微修正；
  - **Tablet**：每条回复下方的持久水平条，适合高认知负荷下的单击访问。

### 2.4 技术细节与公式（文字说明）

- **实现环境**：操作符后端用 Python 实现，基于 OpenAI API（GPT-5.5）；所有操作符共享句子 Transformer 嵌入 `Emb(x)`。
- 记 `H` 为对话历史，`g` 为原始目标，`c_n` 为最新回复。
- **Anchor**：计算目标对齐度 `cos(Emb(g), Emb(c_n))`，对低相似度输出进行重新定向。
- **Delta**：用 KL 散度 `D_KL(P_n || P_{n-1})` 比较回复的语义分布，并标记与目标 `g` 相关的删除项。
- **Replay**：将 `H` 摘要为 `⟨E, O, s⟩`，其中 `E` 为已确立事实，`O` 为开放问题，`s` 为下一步。
- **Scope**：对句子嵌入 `{v_si : si ∈ c_n}` 进行聚类，以呈现子主题。
- **Steer**：计算未解决缺口 `G = {a ∈ A_g : max_{h∈H} cos(Emb(a), Emb(h)) < τ}`，其中 `A_g` 为目标子方面，再将其转化为有针对性的后续问题。
- 每个操作符返回 **JSON 响应模板**。

### 2.5 设计目标（由形成性研究推导）

- **DO1：多轮响应校准**——操作符应作用于跨轮对话，而非单轮。
- **DO2：单击纠正控制**——通过 AssistiveButton 和三向切换减少重输负担。

## 3. 实验设计

### 3.1 研究场景与参与者

- **参与者**：12 名高级 LLM 用户（7 男、5 女；年龄 22–39，M=28.4，SD=4.6），通过社交与学术网络目的性抽样。
- **纳入标准**：每天使用 LLM（≥5 天/周，持续 ≥6 个月）、活跃使用 ≥2 个对话式 AI 平台、英语流利（自评 ≥4/5）、将 LLM 用于高风险信息检索（如医疗、法律）；排除仅单轮、休闲使用经验者。
- **场景**：新诊断 2 型糖尿病的医疗对话场景。

### 3.2 研究一：形成性定性研究

- 在线调查，参与者以自由文本描述交互挫败感和最常重输的纠正，共获得 **96 个重新提示示例**（人均 M=8.0）。
- 采用单编码者主题分析，识别出四类疲劳主题：重新输入（F1）、扫描（F2）、决策瘫痪（F3）、上下文漂移（F4）。

### 3.3 研究二：定量评估（被试内试点）

- **设计**：同一批 12 名参与者，被试内设计，约 35 分钟/人，分三阶段：引导（5 分钟）、配对评估（20 分钟）、可用性与回访（10 分钟）。

- **布局分配**：按参与者偏好布局展示（Vertical n=5，Arc n=4，Tablet n=3）；操作符顺序与两条件呈现顺序随机化以减少顺序效应。
- **测量工具**：

- 参与者**一致选择 RecalibrateGPT 为疲劳感更低的界面**。

- **SUS**：M=86.5，处于“优秀”（excellent）可用性区间。

## 7. 优点

- **问题定义清晰且有价值**：将“对话式 AI 疲劳”细分为四类，并从观察到的用户行为中推导设计目标，而非凭设计者直觉。
- **交互范式创新**：跨轮次操作符作用于完整对话历史，突破了现有系统仅操作单轮响应的局限。
- **单击纠正机制**：用“点击”替代“重输”，直接降低每轮推理成本与认知负担。
- **多布局适配**：Vertical、Arc、Tablet 三种布局针对不同使用情境（重复使用、快速微修正、高负荷单击），体现交互设计的细致考量。
- **方法结合定量与定性**：形成性研究 + NASA-TLX + SUS + 回访，指标选择标准且可比。
- **技术实现具体**：给出了每个操作符的嵌入、余弦相似度、KL 散度、聚类、缺口阈值等可复现的技术细节。
