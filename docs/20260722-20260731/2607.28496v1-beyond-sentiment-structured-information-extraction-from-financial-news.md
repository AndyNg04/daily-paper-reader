## 摘要
金融情感分析已成为新闻驱动股票预测的标准组成部分，但它将丰富、多维的新闻文章简化为单一极性得分。我们假设金融新闻编码了多个正交的信息维度——事件类型、影响范围、时间跨度和语义置信度——这些维度是情感单独无法捕捉的，并且这些维度携带独立的预测价值。为验证这一假设，我们提出了一种结构化信息提取框架，利用LLaMA-3.1-70B从金融新闻中提取六个语义维度。通过在FNSPID数据集的41,618个新闻-股票对上的大规模实验，我们发现：(i) FinBERT情感特征在非线性模型下表现出强预测能力（F1=0.576），但在线性模型下表现显著较弱（F1=0.230），揭示了高度非线性的情感-回报关系；(ii) LLM提取的结构化特征虽然单独较弱，但捕捉了与情感正交的信息，两种方法之间53.5%的系统性不一致率证明了这一点；(iii) 结合两种信号源得到F1=0.600，显著优于任一单独方法（$p < 0.0001$），在全部七种事件类型中均有一致改进。消融实验证实，非情感结构维度（事件类型、影响主体、时间跨度、置信度）在FinBERT之外独立贡献了$Δ\text{F1} = +0.019$。特征重要性分析显示，所有六个提取维度均均衡贡献（14–21%），表明将新闻压缩为单一情感得分会导致大量信息损失。我们的结果表明，金融文本中情感-语义解耦是系统性的且可利用的，为多维金融NLP开辟了新方向。

## Abstract
Financial sentiment analysis has become a standard component in news-driven stock prediction, yet it reduces rich, multi-dimensional news articles to a single polarity score. We hypothesize that financial news encodes multiple orthogonal information dimensions---event type, impact scope, temporal horizon, and semantic confidence---that sentiment alone cannot capture, and that these dimensions carry independent predictive value. To test this hypothesis, we propose a structured information extraction framework that leverages LLaMA-3.1-70B to extract six semantic dimensions from financial news. Through large-scale experiments on 41,618 news--stock pairs from the FNSPID dataset, we find that (i) FinBERT sentiment features exhibit strong predictive power under nonlinear models (F1=0.576) but substantially weaker performance under linear models (F1=0.230), revealing a highly nonlinear sentiment--return relationship; (ii) LLM-extracted structured features, while individually weaker, capture information orthogonal to sentiment, as evidenced by a 53.5% systematic disagreement rate between the two approaches; and (iii) combining both signal sources yields F1=0.600, significantly outperforming either alone ($p < 0.0001$), with consistent improvements across all seven event types. Ablation experiments confirm that non-sentiment structural dimensions (event type, impact subject, time horizon, confidence) independently contribute $Δ\text{F1} = +0.019$ beyond FinBERT alone. Feature importance analysis reveals balanced contributions from all six extracted dimensions (14--21%), demonstrating that compressing news into a single sentiment score incurs substantial information loss. Our results suggest that the sentiment--semantics decoupling in financial text is systematic and exploitable, opening a new direction for multi-dimensional financial NLP.

## 二、方法论：核心思想、关键技术细节

### 1. 问题形式化
- 数据集：$D = \{(a_i, s_i, t_i, y_i)\}_{i=1}^N$，其中 $a_i$ 是新闻文本，$s_i$ 是股票代码，$t_i$ 是发布日期，$y_i \in \{0,1\}$ 是次日收盘价是否上涨的二值标签。
- 学习目标：学习映射 $f: X \to \{0,1\}$。
- 三种特征表示：
  - FinBERT 情感特征 $x^{sent}_i \in \mathbb{R}^3$（三类概率分布）
  - LLM 结构化特征 $x^{struct}_i \in \mathbb{R}^6$
  - 拼接特征 $x^{all}_i = [x^{sent}_i; x^{struct}_i] \in \mathbb{R}^9$

### 2. 核心假设的数学表达
论文形式化假设：
$$I(x^{struct}_i; y_i \mid x^{sent}_i) > 0$$
即：在给定情感特征后，结构化特征与价格变动标签之间仍然存在条件互信息。若结构化特征在情感之外提升预测性能，则假设成立，两个管道具有互补性。

### 3. 六维结构化提取框架
- **FinBERT 特征**：ProsusAI/FinBERT，输出三元概率分布 $(p_{pos}, p_{neg}, p_{neu}) \in \Delta^2$（2-单纯形）。超过512 token截断。
- **LLM 结构化提取**：LLaMA-3.1-70B-Instruct 零样本提取器，输出空间：
  - 情感极性与分数：$S = \{pos, neg, neu\}$ 和 $[-1, 1]$
  - 事件类型：$E = \{earnings, merger, policy, product, mgmt, macro, other\}$（七类）
  - 影响主体：$C = \{company, industry, macro\}$
  - 时间跨度：$H = \{short, long\}$
  - 置信度：$[0,1]$
- **三个分析轴**：情感（方向+强度）→"什么反应？"；事件（类型+影响范围）→"发生了什么、对谁？"；时间（跨度+置信度）→"何时、多明确？"

### 4. 特征编码
- XGBoost：整数编码 $\psi_{int}$（对名义类别不敏感）
- 逻辑回归：独热编码 $\psi_{oh}$（避免将名义类别视为有序）
- 两种编码预测性能等价（ΔF1 = 0.0002）

### 5. 预测模型
- **Logistic Regression (LR)**：测试特征是否携带**线性可分**预测信号
- **XGBoost**：量化**最大可提取预测值**，提供基于分裂的特征重要性
- 刻意避免深度学习模型：目标是隔离特征贡献，而非追求绝对性能

### 6. 评估协议（关键创新）
采用**1000次迭代的自助重采样（bootstrap）配对评估**：
- 每次迭代：从完整数据集有放回抽样N条样本 → 生成共享随机排列 → 80%训练/20%测试
- 所有配置在**完全相同的训练-测试划分**上评估（保证配对比较有效）
- 配对 t 检验 + Bonferroni 多重比较校正（α' = α/K）

## 六、主要结论与发现

### 核心发现1：情感-收益关系高度非线性
- FinBERT特征在LR下 F1=0.230（低于随机基线0.488），在XGBoost下 F1=0.576（2.5倍提升）
- 关键对照：单一特征 $p_+ - p_-$：
  - LR下 F1 = 0.000（模型退化为单类预测）
  - XGBoost下 F1 = 0.435（$p < 0.0001$）
- 同一特征在线性模型下几乎无效、在非线性模型下有效，直接证明情感-收益映射是**根本非线性**的

### 核心发现2：LLM特征单独较弱但具有互补性
- LLM特征 XGBoost F1 = 0.450，低于 FinBERT 的0.576
- 融合两者 F1 = 0.600，显著优于任一单独来源（$p < 0.0001$）
- 这是典型的互补信息源特征：单独弱、组合强

### 核心发现2a：非情感维度驱动互补性提升
- 消融实验：FinBERT + NonSent（去除LLM情感维度的结构化特征）F1 = 0.594
- 与 FinBERT alone 相比 Δ = +0.019（$p < 0.0001$）
- LLM情感维度另贡献 Δ = +0.006（$p < 0.0001$）
- **结构特征（事件类型、影响主体、时间跨度、置信度）独立携带预测信息**

### 核心发现3：LLM特征更线性可访问
- LR下：LLM特征 F1 = 0.330 > FinBERT特征 F1 = 0.230
- 六维结构化表示比三维情感概率单纯形在更线性可分离的形式中编码了预测信息

### 辅助发现
- **分歧率**：FinBERT与LLaMA在53.5%的样本上情感判断不一致；按事件类型从39.4%（并购）到67.4%（未分类）分布，语义复杂事件解耦更严重
- **分歧不预测方向**：分歧样本中48.9%为正标签，一致样本中48.5%为正标签——排除一个模型"对"、另一个"错"的简单解释
- **特征重要性均衡**：六个维度贡献范围为14–21.3%，无单一主导特征
- **事件类型一致性**：融合特征在所有7类事件上均优于单独FinBERT（Δ = +0.010到+0.023），宏观事件的提升最大（+0.023）

## 七、优点：方法与实验设计亮点

1. **新颖的研究视角**：不追求绝对预测精度的提升，而是系统性地拆解金融新闻的信息结构，回答"哪些信息维度携带预测信号"这一更根本的问题。
2. **明确且可检验的假设**：将"情感-语义解耦"形式化为条件互信息假设 $I(x^{struct}; y \mid x^{sent}) > 0$，以统计可验证的方式表述。
3. **精心设计的对照实验**：单特征 $p_+ - p_-$ 的线性 vs 非线性对比，干净利落地隔离出情感-收益关系的非线性本质。
4. **严谨的统计评估协议**：1000次bootstrap + 共享划分 + 配对t检验 + Bonferroni校正，确保结果可靠性。特别值得注意的是附录中说明的早期版本bug修正（不同模型使用不同random_state导致划分不一致），体现实验严谨性。
5. **多维可视化与定性分析结合**：案例研究直观展示了"surface sentiment vs. event-level semantics"的冲突模式，帮助读者建立直觉。
6. **消融设计精准**：通过去除LLM情感维度来隔离"结构性特征"的独立贡献，论证链条完整。
7. **讨论坦诚全面**：对预训练数据重叠、bootstrap重叠偏差、上下文长度不对称等潜在问题均有明确说明。
8. **可复现性导向**：提供了精确的prompt模板、预处理流程、超参数设置（100棵树的XGBoost、贪心解码等）。

## 八、不足与局限

### 实验覆盖局限性
1. **单一市场与时段**：仅覆盖100只NASDAQ股票、2019–2023年；对其他市场、资产类别或时间段的泛化未验证。
2. **单一LLM**：仅使用LLaMA-3.1-70B-Instruct，未评估跨模型鲁棒性。
3. **单一数据集**：仅FNSPID，未在其他金融新闻数据集上验证。

### 偏差风险
4. **预训练数据重叠**：LLaMA-3.1训练数据截止时间与评估期（2019–2023）重叠，模型可能隐含知道事后结果。论文虽提取结构化语义维度而非事实预测，但仍是潜在偏差源。
5. **Bootstrap重叠偏差**：有放回抽样可能导致同一原始样本同时出现在训练集和测试集中，乐观估计绝对性能。相对比较在相同划分下仍有效。
6. **随机划分而非时序划分**：违反因果顺序，部署场景下需要walk-forward评估获得更保守的绝对性能估计。
7. **上下文长度不对称**：FinBERT截断512 token，LLaMA处理2000字符，信息可用量不同，可能混淆两者"捕获了什么"的对比。
8. **提取质量无地面真值**：LLM提取的事件类型、影响主体等没有标注基准，98.6%的解析成功率只是间接质量指标（不代表语义正确性）。

### 方法论局限
9. **置信度信号解释含糊**：LLM自评置信度未校准，可能只是文章长度或词汇复杂度的代理变量，而非真实的语义清晰度。
10. **整数编码强加序结构**：对事件类型等名义类别使用整数编码可能强加任意的序关系（虽然实验结果与独热编码等价，但特征重要性分数会受影响）。
11. **标签简化**：二值化标签（次日涨/跌）丢失了价格变化幅度信息，可能忽视更细微的预测信号。
12. **绝对性能天花板**：即使融合特征F1=0.600，绝对预测能力仍然有限，实际交易应用中可能不足。

### 应用限制
13. **成本问题**：70B参数模型的推理成本相对高昂，虽然结构化提取只需一次推理，但相较于轻量级FinBERT仍缺乏成本效益分析。
14. **事件类型噪声**："Other"类别占比高达30.7%，反映出事件分类体系对大量新闻无法有效归类，可能掩盖更细粒度的语义结构。
15. **未处理多事件共存**：一篇新闻可能包含多个事件，框架强制选择单一事件类型，丢失多重语义信息。
