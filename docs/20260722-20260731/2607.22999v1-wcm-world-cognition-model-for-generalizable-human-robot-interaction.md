## 摘要
语言智能体如今可以在软件环境中与用户流畅交互，但机器人在物理任务中仍难以带来同等水平的交互体验。当前的机器人控制范式，包括视觉-语言-动作策略和基于世界模型的规划器，主要针对指令执行进行优化，导致用户难以理解为何选择某个动作，也缺乏通过交互来引导、纠正或教授机器人的机制。为解决这一问题，我们提出了世界认知模型（WCM），一种基于SLAK架构（感知、逻辑、动作与知识）和异步运行时构建的以人为中心的具身智能体。SLAK将感知、推理、控制与记忆分离，而运行时允许推理、对话与执行并发进行。WCM进一步引入了一种人在回路的教学模式，使用户能够交互式地教授机器人完成困难或长时程任务。教学片段和自主任务执行过程会被提炼为思维链监督信号，以持续改进模型。WCM在九个真实世界人机交互任务中实现了73.8%的平均成功率，其中包括在思维链微调中保留的未参与训练任务，以及一项通过教学习得的长时程任务。

## Abstract
Language agents can now interact fluently with users in software, but robots still struggle to bring comparable interaction to physical tasks. Current robot-control paradigms, including vision-language-action policies and world-model-based planners, are mainly optimized for instruction execution, leaving users with little visibility into why an action is chosen and few mechanisms to redirect, correct, or teach the robot through interaction. To solve this problem, we present the World-Cognition Model (WCM), a human-centered embodied agent built on the SLAK architecture (Sensing, Logic, Action, and Knowledge) and an asynchronous runtime. SLAK separates perception, reasoning, control, and memory, while the runtime allows reasoning, dialogue, and execution to proceed concurrently. WCM further introduces a human-in-the-loop teaching mode that enables users to interactively teach the robot difficult or long-horizon tasks. Teaching episodes and autonomous task rollouts are refined into chain-of-thought supervision to continually improve the model. WCM achieves a 73.8% average success rate across nine real-world human-robot interaction tasks, including tasks held out from CoT fine-tuning and a long-horizon task learned through teaching.

- **整体含义**：WCM不仅是又一个机器人控制模型，而是试图重新定义人机交互中“用户-机器人”的角色关系——用户从“指令的下达者”转变为“行为的理解者、评判者与教导者”。

## 二、论文提出的方法论

### 1. 核心思想
> 将世界模型（World Model）与认知架构（Cognitive Architecture）融合，形成“世界认知模型”——使机器人不仅会执行，还能**解释、对话、学习与自我改进**。

### 2. SLAK 架构（感知、逻辑、动作与知识）
将机器人系统解耦为四个独立模块：

| 模块 | 功能 |
|------|------|
| **S（Sensing，感知）** | 负责环境感知与视觉信息处理 |
| **L（Logic，逻辑）** | 负责推理、决策与规划（即“认知中枢”） |
| **A（Action，动作）** | 负责控制执行与运动规划 |
| **K（Knowledge，知识）** | 负责记忆存储与经验累积 |

- **解耦的意义**：感知、推理、控制与记忆不再耦合在一个端到端网络中，每一层都可以独立更新、调试和解释。

### 3. 异步运行时（Asynchronous Runtime）
- 允许**推理、对话与执行并发进行**，而非串行阻塞。
- 机器人可以在执行动作的同时继续感知环境变化、与用户对话，并在必要时调整行为。
- 这为“用户中途打断并纠正/教导机器人”提供了底层运行时的可能性。

### 4. 人在回路（Human-in-the-Loop）教学模式
- 用户可以直接**交互式地教授**机器人完成困难或长时程任务。
- 教学片段（teaching episodes）与自主运行轨迹（autonomous rollouts）会被收集起来。
- 这些数据被**提炼为思维链（Chain-of-Thought, CoT）监督信号**，用于后续训练与模型持续改进。
- 即：**人的示范与纠正 → 转化为可解释的推理轨迹 → 注入模型的推理能力**。

### 5. 工作流程（文字说明）
1. 用户下达任务指令 → 感知模块采集环境信息；
2. 逻辑模块基于感知与知识生成推理（思维链）与动作计划；
3. 动作模块异步执行行动，同时逻辑模块继续推理、对话模块响应用户；
4. 用户可随时**重定向、纠正或示范**机器人的行为；
5. 教学片段与自主运行轨迹经提炼后成为CoT监督，持续优化模型。
