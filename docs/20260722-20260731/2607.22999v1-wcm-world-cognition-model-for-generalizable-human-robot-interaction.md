## 摘要
语言智能体如今能够在软件环境中与用户流畅交互，但机器人仍然难以在物理任务中实现同等水平的交互。当前的机器人控制范式，包括视觉-语言-动作策略和基于世界模型的规划器，主要针对指令执行进行优化，导致用户难以了解动作选择的原因，也缺乏通过交互来引导、纠正或教导机器人的机制。为解决这一问题，我们提出了世界认知模型（WCM），一种以人为中心的具身智能体，构建于SLAK架构（感知、逻辑、动作与知识）和异步运行时之上。SLAK将感知、推理、控制与记忆分离，而运行时则允许推理、对话与执行并发进行。WCM进一步引入了一种人在回路的教学模式，使用户能够以交互方式教导机器人完成困难或长视界任务。教学片段和自主任务执行过程被提炼为思维链监督信号，以持续改进模型。WCM在九个真实世界人机交互任务中实现了73.8%的平均成功率，其中包括从思维链微调中保留的任务以及通过教学习得的长视界任务。

## Abstract
Language agents can now interact fluently with users in software, but robots still struggle to bring comparable interaction to physical tasks. Current robot-control paradigms, including vision-language-action policies and world-model-based planners, are mainly optimized for instruction execution, leaving users with little visibility into why an action is chosen and few mechanisms to redirect, correct, or teach the robot through interaction. To solve this problem, we present the World-Cognition Model (WCM), a human-centered embodied agent built on the SLAK architecture (Sensing, Logic, Action, and Knowledge) and an asynchronous runtime. SLAK separates perception, reasoning, control, and memory, while the runtime allows reasoning, dialogue, and execution to proceed concurrently. WCM further introduces a human-in-the-loop teaching mode that enables users to interactively teach the robot difficult or long-horizon tasks. Teaching episodes and autonomous task rollouts are refined into chain-of-thought supervision to continually improve the model. WCM achieves a 73.8% average success rate across nine real-world human-robot interaction tasks, including tasks held out from CoT fine-tuning and a long-horizon task learned through teaching.

  - **低可教导性**：系统缺乏通过交互来引导、纠正或教导机器人的机制，用户难以干预或改进机器人的行为。
- 核心诉求是构建一种**以人为中心（human-centered）的具身智能体**，使机器人不仅能执行指令，更能被普通人理解、纠正和教授。

## 2. 方法论

### 2.1 核心思想
- 提出 **WCM（World-Cognition Model，世界认知模型）**，将机器人从“指令执行器”转变为“可交互的具身学习体”。
- 核心转变：从单纯优化任务成功率，转向同时优化**可解释性**与**可教导性**。

### 2.2 SIG架构与关键技术

- **SLAK 四模块解耦架构**：
  - **S（Sensing，感知）**：负责环境感知与多模态信息接收；
  - **L（Logic，逻辑/推理）**：负责决策推理与思维链生成；
  - **A（Action，行动/控制）**：负责运动控制与动作执行；
  - **K（Knowledge，知识/记忆）**：负责长期记忆与经验积累。
- 四个模块相互分离、各司其职，避免“感知—行动”直连导致的推理黑箱问题。

### 2.3 异步运行时（Asynchronous Runtime）
- 支持**推理、对话与执行三者并发进行**，允许机器人在执行动作的同时与用户对话、解释推理过程或接受指令调整。
- 这一机制使得交互不再是“执行前的一次性输入”，而是贯穿任务全程的动态过程。

### 2.4 人在回路教学模式（Human-in-the-Loop Teaching）
- 允许用户通过交互方式教导机器人完成困难或长视界（long-horizon）任务。
- 教学过程中，用户可对机器人的行为进行**重定向、纠正与教导**，实现行为修正。
- 教学片段（teaching episodes）与自主任务执行过程（autonomous task rollouts）会被提炼为 **CoT（Chain-of-Thought, 思维链）监督信号**，用于持续改进模型，形成“交互—学习—改进”的正向循环。

## 6. 主要结论与发现

- WCM 通过将感知、推理、控制与记忆分离，配合异步运行时，实现了机器人在物理任务中“边执行、边推理、边对话”的能力，显著提升了交互的自然性与实时性。

- 将教学数据提炼为 CoT 监督信号进行持续改进，形成闭环学习机制，使模型能够随交互不断进化。
- 总体结论：WCM 通过透明推理与交互教学，**同时提升了机器人的可解释性与可教导性**，为人机交互提供了一种新的范式，使机器人从“工具型执行器”向“可协作的学习型伙伴”演进。
