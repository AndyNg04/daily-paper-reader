## 摘要
生成式人工智能的最新进展通过后训练金融大语言模型（LLM）显著提升了金融情感分析水平。然而，现有方法仍局限于与市场无关的监督学习范式，依赖有限、静态且人工标注的数据集，因此无法适应不断变化的市场状况。为解决这一局限，我们提出了FinSMART——首个面向金融情感分析的市场对齐强化学习框架，它直接利用已实现的市场结果来优化情感信号。为应对金融市场噪声大、非平稳且多因素影响的特性，FinSMART整合了一个信号提取流程，将市场感知的数据过滤与离散的非对称交易奖励相结合，从而能够从具有经济意义的市场反馈中进行稳定的强化学习。实验结果表明，FinSMART在盈利能力、风险调整后表现和情感信号质量方面显著优于现有最先进方法，累计交易收益较最强基线提升了220%。尤为独特的是，FinSMART框架天然支持市场感知的再训练，可在任意时间点通过新观察到的金融文章及其已实现的市场结果取代昂贵的人工标注。这种再训练策略使模型能够持续适应变化的市场动态，与静态模型相比带来持续的性能提升。这些发现证明了市场对齐强化学习的实际适用性，并凸显其作为开发自适应金融LLM的下一代范式的潜力。

## Abstract
Recent advances in Generative AI have substantially improved financial sentiment analysis through post-trained financial large language models (LLMs). However, existing approaches remain confined to a market-agnostic, supervised learning paradigm that relies on limited, static and human-annotated datasets, and thus are incapable of adapting to evolving market conditions. To address this limitation, we introduce FinSMART, the first market-aligned reinforcement learning framework for financial sentiment analysis, which directly optimizes sentiment signals using realized market outcomes. To deal with the noisy, non-stationary, and multifactorial nature of financial markets, FinSMART incorporates a signal extraction pipeline that combines market-aware data filtering with a discrete asymmetric trading reward, enabling stable reinforcement learning from economically meaningful market feedback. Experimental results demonstrate that FinSMART significantly outperforms existing state-of-the-art methods in profitability, risk-adjusted performance, and sentiment signal quality, improving cumulative trading returns by 220% over the strongest baseline. Uniquely, the FinSMART framework naturally supports market-aware retraining, at any point in time, by replacing costly manual annotation with newly observed financial articles and their realized market outcomes. Such a retraining strategy enables the model to continuously adapt to changing market dynamics, resulting in consistent performance gains over its static counterpart. These findings demonstrate the practical applicability of market-aligned reinforcement learning and highlight its potential as a next-generation paradigm for developing adaptive financial LLMs.

## 二、方法论

### 核心思想

- 利用**GRPO（Group Relative Policy Optimization）**将市场回报作为奖励信号，对预训练 LLM（Llama-3-8B-Instruct）进行参数高效的强化学习后训练。
- 关键挑战：金融市场的收益具有**高噪声、非平稳、厚尾、多因素干扰**等特性，直接从原始收益中学习信号信噪比极低。为此设计了三层信号提取管道：

### 1. 数据管道与信号提取

| 步骤 | 方法 | 目的 |
|------|------|------|
| **数据收集** | The Motley Fool (TMF) 和 MarketWatch 的文章（2015.2–2021.6），S&P 500 成分股日度行情（Yahoo Finance），1,672 个交易日 | 构建训练语料与市场数据对齐 |
| **实体识别（NER）** | 使用 BERT-base-NER，保留目标公司置信度 >98% 的文章 | 避免一篇多公司文章的错误市场对齐 |
| **情感门控** | 用参考策略 π_ref 过滤：模型输出必须是 {Positive, Neutral, Negative} 之一，否则丢弃 | 剔除无明确情感信号的噪声文章 |

### 2. 双过滤交易奖励（Dual-Filter Trading Reward）

- 定义**特有收益**（idiosyncratic return）：α = r_stock − r_SPY（剥离市场系统性波动）。
- 将市场结果映射为真实方向标签 y ∈ {−1, 0, +1}：
  - y = +1：α > τ 且 r > 0
  - y = −1：α < −τ 且 r < 0
  - 否则 y = 0（τ = 0.5%）
- 奖励矩阵（离散、非对称）：

| 预测 d | 真实 y | 奖励 | 语义 |
|--------|--------|------|------|
| d = y ≠ 0 | 方向正确 | **+2.0** | 正确做多/做空 |
| d = y = 0 | 正确中性 | **+0.1** | 正确回避 |
| d = −y ≠ 0 | 方向相反 | **−1.5** | 反向做错 |
| 其他 | — | **−1.0** | 漏掉交易或虚假信号 |

- **双过滤**效果：预测需同时满足方向正确和 alpha 超过阈值，才能获得正向奖励，从而滤除市场噪声。
- **非对称设计**：正确奖励 > 错误惩罚，鼓励探索、防止模型塌缩到"中性"的保守策略。

### 3. GRPO 优化配置

- 每组采样 **G = 8** 个候选情感预测，通过组内相对优势（group-relative advantage）归一化，无需价值模型（critic-free）。
- 损失函数包含裁剪代理目标与 KL 散度正则：**β = 0.1**。
- 使用 **LoRA** 微调（rank=16, α=32, dropout=0.05），可训练参数仅 **13.6M**（约基础模型的 0.17%）。

### 关键设计决策

- **训练用当日收益**：经验证据显示当日 alpha 与文章情感的对齐度远高于次日（TMF：相关系数 0.41 vs 0.03；平均 alpha 差 5.0% vs 0.3%）。
- **评测用次日收益**：避免前视偏差（look-ahead bias），模拟真实执行条件。

## 三、实验设计

### 数据集与场景

- **训练集**：截至 2018-12-31 的金融新闻文章（约 30,000 篇），与 S&P 500 日度行情对齐。
- **测试集**：2019-01 至 2021-06 期间的文章（约 325,000 篇），包含 COVID-19 市场崩盘，覆盖正常与高波动市场环境。
- **时序切分**：训练/测试严格按时间先后划分，避免信息泄漏。

### Benchmark 与对比方法（共 7 个方法）

| 类别 | 方法 |
|------|------|
| 词典方法 | LMD、HIV-4、VADER |
| SFT LLM | FinBERT、FinLlama |
| 偏好优化 LLM | FinDPO（现有 SOTA） |
| 本文方法 | **FinSMART** |

### 评估框架

- 使用 FinDPO 提出的 **logit-to-score 转换器**将离散情感转化为连续分数，构建各方法的独立投资组合。
- **组合构建**：每日 35% 等权多头–空头组合（按情感分数排名），次日开盘执行，单日持有。
- **核心指标**：累计收益、年化收益、Sharpe 比率、Sortino 比率、Calmar 比率、RankIC（横截面预测能力）。

### 定期重训实验

- 采用**扩展窗口（expanding-window）重训策略**：每 6 个月用全部累积数据重训一次，共 4 次迭代。
- 对比静态模型（仅训练至 2018 年底）与定期重训模型的表现。

## 七、优点

1. **范式创新**：首个将市场收益直接作为 LLM 强化学习奖励的金融情感分析框架，彻底摆脱静态人工标注的依赖。
2. **信号提取管道设计精巧**：NER 高置信度过滤 + 情感门控 + 双过滤非对称奖励，三重机制有效应对金融市场高噪声、非平稳特性。
3. **计算效率高**：LoRA + GRPO，仅训练 0.17% 参数、单卡 8 小时即可完成，具备实际部署可行性。
4. **天然支持持续学习**：新发布的文章 + 已实现市场收益即可自动生成训练数据，无需人工标注，支持任意时点的市场感知重训。
5. **评估严谨**：训练与评测使用不同时间窗口的收益（当日 vs. 次日），避免了前视偏差；包含 COVID 崩盘期的稳健性检验。
6. **统一的评估框架**：对因果 LLM 使用 logit-to-score 转换器，与原 SOTA（FinDPO）同基座模型，对比公平。

## 八、不足与局限

1. **数据覆盖范围有限**：仅覆盖北美市场（S&P 500）、两个新闻来源、单一时间段（2015–2021），未验证跨市场、跨资产、跨语言/语境的泛化能力。
2. **Reward 设计依赖人为设定的参数**：τ = 0.5% 及非对称奖励幅度的选取缺乏灵敏度分析，最优性未被验证。
3. **实验重复性不足**：未报告多次运行的均值方差、不同随机种子下的结果稳定性，难以判断性能波动范围。
4. **潜在过拟合风险**：训练信号基于当日收益（与情感信号对齐更强），而评测基于次日收益，两者之间存在 gap——模型优化目标与实际评估目标并不完全一致。
5. **实体对齐简化**：BERT-base-NER 只保留置信度 >98% 的文章，可能丢失大量真实有用的信息；文章级情感聚合为公司级日度分数时未考虑多文章间的信息优先级。
6. **投资组合简化假设**：35% 等权多空、单日持有、不考虑交易成本、滑点和市场冲击，实际交易中表现可能显著折扣。
7. **对比方法未享受同等重训机会**：定期重训实验仅对 FinSMART 进行，未与其他 LLM 方法在相同重训机制下做对照，无法完全归因于方法论本身的优势。
8. **RankIC 绝对值偏低**（0.061），虽然相对提升明显，但情感信号的绝对预测能力仍较弱，策略容量和实际可扩展性存疑。
