## 摘要
我们研究了一个涉及多个智能体的分散式强化学习问题，这些智能体与同一个马尔可夫决策过程（MDP）交互。智能体可以通过网络交换信息，以共同学习最优状态-动作价值函数。针对这一设置，我们提出了一种新颖的基于轮次的分布式Q学习算法，称为VRDQ。在每个轮次内，智能体局部估计Bellman最优算子，并使用基于共识的协议传播信息。对于静态和时变网络，我们均建立了VRDQ的高概率有限时间收敛率，该收敛率从协作中获得了线性加速。关键的是，我们证明了这种样本复杂度的加速仅需~O(1)次通信，显著优于先前工作中的通信成本。

## Abstract
We investigate a decentralized reinforcement learning problem involving multiple agents that interact with the same Markov Decision Process (MDP). The agents can exchange information over a network to collectively learn the optimal state-action value function. For this setting, we introduce a novel epoch-based distributed $Q$-learning algorithm called VRDQ, where within each epoch, agents locally estimate the Bellman optimality operator and diffuse information using a consensus-based protocol. For both static and time-varying networks, we establish high-probability finite-time convergence rates for VRDQ that enjoy linear speedups from collaboration. Crucially, we prove that such speedups in sample-complexity require only $\tilde{O}(1)$ communication, substantially improving upon the communication costs in prior work.

## 2. 论文提出的方法论

### 2.1 核心思想
- 采用 **epoch（轮次）式更新**：每轮只更新一次Q表，而非每时间步更新。
- 将 **局部算子估计** 与 **基于共识的扩散** 解耦并行执行，从而分离统计误差与网络诱导误差。
- 通过在每个 epoch 中用 H 个独立样本估计转移核，构造 **低方差（variance-reduced）** 的 Bellman 最优算子估计，减少更新频率但保持收敛性能。

### 2.2 算法流程（VRDQ）
1. **初始化**：所有智能体 Q 表置零。
2. **循环 K 个 epoch**：
   - **局部估计**：每个智能体用 H 个样本估计转移概率 $\hat{P}_{i,k}(s'|s,a)$，并构造经验 Bellman 算子：
     \[
     \hat{\mathcal{T}}_{i,k} f(s,a) = R(s,a) + \gamma \sum_{s'} \hat{P}_{i,k}(s'|s,a) \max_{a'} f(s',a')
     \]
   - **扩散**：仅在前 L 步内运行共识协议，传播上一轮次产生的方向 $\hat{\mathcal{T}}_{i,k-1} Q_{i,k}$：
     \[
     d_{i,k}^{(\ell+1)} = \sum_{j \in \mathcal{N}_i} (W)_{ij} d_{j,k}^{(\ell)}
     \]
     经过 L 步后得到 $d_{i,k}^{(L)}$。
   - **本地更新**：
     \[
     Q_{i,k+1} = (1-\alpha) Q_{i,k} + \alpha d_{i,k}^{(L)}
     \]

### 2.3 关键参数设置
- 步长：$\alpha = \frac{\log(NT)}{(1-\gamma)K}$
- 轮次数：$K = O\left(\frac{\log(NT)}{1-\gamma}\right)$
- 扩散步数：$L = O\left(\frac{\log(N^{3/2}\sqrt{T}/\sqrt{1-\gamma})}{\log(1/\rho)}\right)$，其中 $\rho$ 是网络混合速率。
- 该设计保证总通信开销为 $KL = O(\log^2(NT))$。

### 2.4 理论分析框架
- 定义网络平均 Q 函数 $\bar{Q}_k$，将误差分解为**扩散误差**（由共识不充分引起）和**算子估计误差**（由有限样本估计转移核引起）。
- 通过引理分别控制迭代有界性（Lemma 1）、扩散误差（Lemma 2）和估计误差（Lemma 3），最终在统一概率事件上得到收敛界。
- 定理 1 针对静态网络，定理 2 将结果推广到满足 Assumption 1 的时变网络（在时变网络中，扩散步被替换为乘积矩阵的块形式，只需假设每 B 步内混合误差 < 1）。

## 6. 论文的主要结论与发现

- 提出了 VRDQ 算法，首次在静态和时变网络上证明：分布式Q学习可以实现 **$O(1/\sqrt{NT})$ 的高概率收敛率**（相对单智能体 $O(1/\sqrt{T})$ 有线性加速），且通信开销仅需 **$O(\log^2(NT))$**。

- 结论：VRDQ 在协作学习性能与通信成本之间取得了很好的权衡，显著优于此前方法。
