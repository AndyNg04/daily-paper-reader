## 摘要
随着大语言模型（LLM）需要适应多样化的用户偏好，个性化价值对齐日益重要。然而，现有方法通常依据固定的价值观画像，在不同提示下对模型输出进行对齐，忽视了不同情境中各价值维度的显著性可能存在较大差异。受勒温场论的启发——该理论认为人类行为由个人倾向与情境约束共同塑造——我们将个人价值观建模为先验，将依赖情境的偏好建模为后验。我们提出 BaCVA，一种在推理阶段运行的贝叶斯情境感知个性化价值对齐方法，通过整合静态个人价值观与特定场景下的价值显著性，近似推断个性化偏好后验。BaCVA 首先从普遍符合规范的回答中估计情境价值显著性，随后利用双视角个性化模块，结合个人价值观视角与场景驱动视角，推断后验偏好。这一贝叶斯框架在利用先验价值观提高数据效率的同时，实现了更准确、更具适应性的个性化价值对齐。在多个基准上的大量实验表明，BaCVA 优于具有竞争力的基线方法。

## Abstract
Personalized value alignment has become increasingly important as large language models (LLMs) are expected to accommodate diverse user preferences. However, existing methods typically align model outputs with a static value profile across prompts, overlooking that the salience of value dimensions varies substantially across contexts. Inspired by Lewin's Field Theory, which views human behavior as jointly shaped by personal dispositions and situational constraints, we model personal values as priors and context-dependent preferences as posteriors. We propose BaCVA, an inference-time Bayesian Context-aware personalized Value Alignment method that approximates posterior personalized preferences by integrating static personal values with scenario-specific value salience. BaCVA first estimates contextual value salience from generally normative responses, and then employs a dual-view personalization module to infer posterior preferences from complementary personal-value and scenario-driven perspectives. This Bayesian formulation enables more accurate and adaptive personalized value alignment while improving data efficiency via prior values. Extensive experiments on benchmarks demonstrate its superiority over strong baselines.

# 论文总结：BaCVA——面向情境的个性化价值对齐

## 1. 核心问题与研究动机

- **核心问题**：同一用户在不同问题中，未必会以相同方式表达其价值观。现有不少推理时个性化方法将固定的用户价值画像用于所有提示，虽考虑了问题文本，却没有显式估计当前情境中哪些价值更重要。
- **直观例子**：重视自主性的用户，在鼓励创新的团队中可能主动提出新方案；面对必须遵守严格流程的紧急事件，则可能优先考虑协调与安全。
- **整体含义**：论文借鉴勒温场论，将具体偏好视为个人倾向与情境约束共同作用的结果。个性化对齐的目标因此不只是“遵循用户画像”，而是推断用户在**此时、此问题下**可能体现的价值取向。

## 2. 方法论：情境化的后验价值推断

BaCVA（Bayesian Context-aware personalized Value Alignment）在推理时结合用户画像和问题情境，预测问题级的个人价值向量，再用它指导回答。

1. **构建个人价值画像**：将用户的自我描述转换为结构化价值评分。主要实验采用 Schwartz 的十个基本价值维度，每维为 1—5 分。
2. **估计场景价值显著性**：对问题生成一个一般规范性的回答，再由价值提取器分析该回答，得到当前场景倾向强调的价值。主要实现使用 GPT-5-nano 完成这一步。
3. **双视角推断**：
   - *场景锚定视角*：以场景价值为起点，加入用户特有的修正；
   - *个人锚定视角*：以用户画像为起点，加入情境带来的修正。
   
   两种修正由模型根据问题语义和相应先验，在价值分布的 logit 空间中学习。
4. **动态融合**：门控模块参考问题、两路预测及其置信信息，为两种视角分配连续权重，而非对所有问题固定平均。
5. **训练目标**：论文以贝叶斯推断解释该过程：个人与情境信息提供先验，偏好观察用于校准问题级价值；形式上给出包含偏好似然项和后验—先验 KL 散度项的变分目标。实际训练则以预测价值与首选回答提取价值之间的误差为主要监督，并加入两路先验的 KL 约束。

**需要区分理论与实现**：实际方法采用单次、摊销式预测和价值回归近似，并非精确计算贝叶斯后验；文中“后验”更适合理解为受该框架启发的情境化预测。

## 3. 实验设计与比较对象

- **主要数据集**：
  - **PRISM**：开放式问题及用户对候选回答的偏好，预处理后 2,131 条；
  - **GOOD**：由 PersuasionForGood 劝募对话构建，包含用户价值信息和回答，预处理后 2,696 条。
  - 两者主要采用约 **80%/20%** 的训练／测试划分；附录另在 **AlignX** 上补充验证。
- **评测任务与指标**：比较预测价值与首选回答所体现价值的接近程度，报告平均绝对误差（MAE）和 Spearman 排序相关系数；PRISM 还报告预测价值是否更接近首选而非弃选回答的准确率。另测试预测价值能否帮助下游生成个性化回答。
- **基线**：包括不使用用户画像的 DirectAnswer、直接使用静态画像的 PersonValue，以及 ValuePrompt、MetaAligner、COUPLE、PAD、MOD、ValuesRAG；附录补充 RLHF、MORLHF 等训练时方法。主要可比实验使用 **Qwen3-8B**，并尽量统一问题和用户画像输入。

## 6. 主要结论与发现

- 在主实验中，BaCVA 在 **PRISM** 上取得 **0.728 MAE、0.700 相关系数、81.72% 准确率**；在 **GOOD** 上取得 **1.118 MAE、0.769 相关系数**，均优于所列主要基线。作为强基线的 ValuesRAG，在 PRISM 上分别为 0.952、0.638、71.68%，在 GOOD 上为 2.261、0.589。
- 消融与冲突分组结果表明：**个人信息、场景信息及两者的动态权衡都有贡献**；当首选回答体现的价值与静态画像差异较大时，显式建模情境尤其有益。
- 论文还报告了少量训练数据下的表现、未见用户泛化及下游回答生成的改进。端到端生成变体优于两阶段版本，但增幅较小。

## 7. 优点与亮点

- **问题界定清楚**：把“画像相同、场景不同”这一具体缺口从一般个性化问题中分离出来。
- **结构具有可解释性**：个人锚定、场景锚定和门控权重分别对应不同的信息来源，便于分析模型何时依赖哪一方。
- **兼顾冷启动需求**：使用可读的用户价值描述，而非必须为每位用户训练独立适配器。
- **验证角度多样**：除平均指标外，还检查高冲突情境、未见用户、价值体系变化及评测器变化，更贴近方法所宣称的适应性。

## 8. 不足与局限

- **评价目标是代理指标**：回答中提取出的价值不等于用户完整、真实的价值观；有限候选回答上的偏好也可能只是折中选择。论文虽验证了提取器与人工标注的一致性，仍无法消除这一构念差距。
- **场景“普遍规范”可能带有偏差**：以已对齐 LLM 的回答估计场景价值，可能继承模型的文化假设和既有对齐偏好；它不必然代表跨文化的共同规范。
- **真实部署证据不足**：实验主要基于离线数据；跨数据集迁移、大规模在线用户反馈、画像随时间变化等仍待验证。
- **理论与实现存在距离**：形式化的偏好后验与实际使用的回答价值回归、确定性摊销推断并不完全相同。因此，结果有力支持“结合个人与情境信息有效”，但尚不足以单独证明精确贝叶斯推断是收益来源。
- **应用须谨慎**：自报画像可能不准确；推断出的偏好也可能涉及隐私、偏见或操纵风险，不宜用于判断个人品格或替代人的伦理决策。
