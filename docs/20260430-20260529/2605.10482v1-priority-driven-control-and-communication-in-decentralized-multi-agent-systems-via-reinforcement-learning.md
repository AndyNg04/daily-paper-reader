## 摘要
事件触发控制为网络化多智能体系统中避免过度使用受限通信带宽提供了一种机制。然而，现有大多数方法依赖于精确的系统模型，而这些模型在实践中可能难以获得。在本文中，我们提出了一种无模型、优先级驱动的强化学习算法，该算法在分散式多智能体系统中从数据中联合学习通信优先级和控制策略。通过学习通信优先级，我们规避了事件触发控制中典型的由二进制通信决策构成的混合动作空间。我们在基准任务上评估了我们的算法，并证明其性能优于基线方法。

## Abstract
Event-triggered control provides a mechanism for avoiding excessive use of constrained communication bandwidth in networked multi-agent systems. However, most existing methods rely on accurate system models, which may be unavailable in practice. In this work, we propose a model-free, priority-driven reinforcement learning algorithm that learns communication priorities and control policies jointly from data in decentralized multi-agent systems. By learning communication priorities, we circumvent the hybrid action space typical in event-triggered control with binary communication decisions. We evaluate our algorithm on benchmark tasks and demonstrate that it outperforms the baseline method.

- **整体含义**：该论文旨在提出一种**无模型、优先级驱动的强化学习方法**，使每个智能体联合学习控制策略和通信优先级，从而绕过传统二值通信决策带来的混合动作空间问题，在保证控制性能的同时，灵活、高效地利用受限带宽。

### 2. 论文提出的方法论
- **核心思想**：将离散通信决策转化为**连续通信优先级** \(a_{i,p} \in (0,1)\)。每个智能体输出控制动作 \(a_{i,c}\) 和优先级 \(a_{i,p}\)，只有优先级最高的 \(L\) 个智能体获得通信时隙，其余被抑制。这种做法将混合动作空间统一为纯连续空间，可直接嵌入到现有策略梯度算法中。
- **关键技术细节**：
  - 系统建模为**分散式部分可观测马尔可夫决策过程（DEC-POMDP）**，奖励函数同时包含控制奖励 \(r_{i,c}\) 和通信惩罚 \(r_{i,p} = -\xi a_{i,p}\)，以抑制毫无节制的通信。
  - 通信策略由优先级决定：假设允许 \(L < N\) 个智能体同时通信，利用优先级聚合原语在各智能体间交换紧凑优先级值，本地确定通信权，开销极低。
  - 使用**独立近端策略优化（IPPO）** 作为基础MARL算法，形成“Control-Priority IPPO”。其actor网络参数 \(\theta\) 同时学习控制与优先级，critic网络参数 \(\phi\) 学习价值函数。优化目标仍采用PPO的裁剪替代目标（公式4）和价值函数裁剪目标（公式6），但动作扩展为包含优先级分量。

### 3. 实验设计
- **环境与基准任务**：
  - **Coverage Control**：\(N\) 个智能体需覆盖 \(M\) 个路标，奖励为各路标到最近智能体距离的负均值。局部观测移除其他智能体信息，通信信息为其他智能体的位置和速度。
  - **Formation Control**：\(N\) 个智能体需围绕中心路标形成正多边形，奖励包括距中心距离惩罚和角度间距惩罚。局部观测同样移除非必要信息，通信内容类似。
  - **Multiwalker**：多个双足机器人协同运送包裹到目的地，高维动作空间（每条腿两个关节力）。局部观测仅含自身关节状态和包裹信息，通信发送自身绝对位置和速度。
- **对比方法**：**IPPO with round‑robin communication**（轮询通信），即智能体轮流通信，只学习控制策略，无通信惩罚。为体现带宽开销，轮询通信分配时隙 \(L_1\)，优先级通信分配时隙 \(L_2\)，且 \(L_1 \ge L_2\)。
- **通信扰动**：消息以0.2概率丢失，延迟一个时间步；优先级消息丢失时回退至轮询机制。
- **训练配置**：所有环境均训练1000万步，用三个随机种子的均值回报及其标准差绘图。
