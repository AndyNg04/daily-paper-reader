## 摘要
随着人工智能智能体越来越多地在开放的真实环境中运行，它们需要深度融合多模态感知、基于多跳推理的工具调用以及与用户的动态交互。然而，现有基准由于在设计严格耦合的多能力任务、模拟自然且受任务约束的用户反馈以及确保动态交互的客观评估方面存在挑战，未能联合评估这些能力。为弥合这一差距，我们提出了 EgoBench，首个面向工具使用智能体的交互式多模态基准。EgoBench 包含 1,045 个以第一人称视频为基础的任务，涵盖四个日常场景，并配有一个用于评估的用户-智能体-工具交互环境。我们实现了一个三阶段协同流程，每个任务旨在强制要求视觉感知和工具增强的多跳推理的联合应用。我们还在 EgoBench 中开发了一个多智能体模拟用户来评估智能体的交互能力，该模拟用户能对智能体生成高保真、任务对齐的响应。此外，我们建立了一个确定性的联合验证框架，通过基于过程和基于结果的等价性来保证客观评估。在 EgoBench 上对八个最先进的视频多模态大语言模型智能体进行基准测试揭示了严重的性能上限：表现最好的模型在最佳场景中仅达到 30.62% 的准确率，在所有四个场景中的平均准确率为 19.43%。最后，我们进行了多维错误分析以分解失败模式，揭示了推进未来人工智能智能体的能力瓶颈。

## Abstract
As AI agents increasingly operate in open, real-world environments, they require a deep synergy of multimodal perception, tool invocation with multi-hop reasoning, and dynamic interaction with users. However, existing benchmarks fail to jointly evaluate these capabilities due to challenges in designing strictly coupled multi-capability tasks, simulating natural and task-constrained user feedback, and ensuring objective evaluation of dynamic interaction. To bridge this gap, we introduce EgoBench, the first interactive multimodal benchmark for tool-using agents. EgoBench comprises 1,045 egocentric-video-grounded tasks covering four daily scenarios, along with a user-agent-tool interactive environment for evaluation. We implement a three-stage synergistic pipeline through which each task is designed to enforce the joint application of visual perception and tool-augmented multi-hop reasoning. We additionally develop a multi-agent simulated user within EgoBench to evaluate agents' interaction capabilities, which generates high-fidelity, task-aligned responses to agents. Furthermore, we establish a deterministic joint validation framework that guarantees objective assessment through process-based and result-based equivalence. Benchmarking eight SOTA video-MLLM agents on EgoBench reveals a severe performance ceiling: the best model achieves only 30.62% accuracy in the best-performing scenario, averaging 19.43% across all four scenarios. Finally, we conduct a multi-dimensional error analysis to disentangle failure modes, exposing capability bottlenecks for advancing future AI agents.

### 2. 论文提出的方法论

论文构建 EgoBench 的核心方法论围绕三个关键挑战展开，包含三个主要部分：

-   **三阶段协同任务生成管线**
    1.  **第一人称视频收集**：收集/使用富含显式时空线索（如手指点选、顺序动作）的10-30秒短期第一人称视频，作为视觉锚点。
    2.  **工具库与数据库构建**：为每个场景（如零售、厨房）设计专用工具库（包含查询和修改数据库状态的功能），并构建一个包含视频中可见信息与不可见上下文信息（如营养数据、原产地）的数据库，制造视觉-数据信息差。
    3.  **任务设计与标注**：每个任务的设计遵循一个强制耦合四步骤的模板，确保评估的全面性：
        -   **多模态感知**：理解用户基于视频的指代（如颜色、位置）。
        -   **工具检索**：通过工具调用获取指代对象在视频中不可见的关联属性。
        -   **逻辑推理**：基于获取的属性执行多跳条件判断（如“如果低于100元，则……”）。
        -   **状态修改**：根据判断结果调用工具修改数据库状态（如加入购物车）。

-   **多智能体模拟用户**
    为解决用户反馈的保真度和任务一致性问题，论文采用了由三个组件构成的“演员-评估者-总结者”多智能体框架：
    -   **演员（Actor）**：根据对话历史摘要和当前智能体回复生成用户响应。
    -   **评估者（Evaluator）**：通过四个二元标准（**角色一致性**、**指令遵循度**、**抗干扰韧性**、**上下文健壮性**）对演员生成的响应进行检查，不合格则提供修改建议并让演员重新生成。
    -   **总结者（Summarizer）**：维护并更新一个紧凑的对话历史和任务进度摘要，供演员下一步推理使用。
    该框架支持三种交互模式：`Static`（单轮完整指令）、`Dynamic Easy`（标准多轮对话）和 `Dynamic Hard`（用户不耐烦、提供无关噪音信息等）。

-   **确定性联合验证框架**
    为解决评估主观性问题，该框架不依赖大语言模型打分，而是通过两个客观指标进行判定：
    -   **基于过程的评估**：检验智能体的工具调用序列是否**覆盖**了成功所需的所有关键工具调用（`τ* ⊆ τ`）。
    -   **基于结果的评估**：分别执行真值工具序列和智能体生成的工具序列，对比最终的数据库状态哈希值是否完全一致（`Hash(S*) == Hash(S)`）。
    -   **联合成功率**：只有同时满足过程与结果评估的任务才被视为成功。

-   **性能天花板极低**：当前最先进的视频多模态大模型在 EgoBench 上表现不佳。表现最好的模型（Gemini-3.1-Pro）在所有任务和模式下的平均联合成功率仅为 **19.43%**，在表现最好的零售场景中也只有 **30.62%**。

-   **主要失败原因**：失败主要源于**多模态感知错误**（无法准确理解视频中的视觉指代）和**逻辑推理错误**（在条件分支和工具参数依赖上出错）。

### 8. 不足与局限

-   **场景与模态有限**：目前仅覆盖四个日常生活场景，未来可扩展到教育、约会等更多样化的场景；同时，除视频外，未纳入音频、生理信号等多模态信息。
