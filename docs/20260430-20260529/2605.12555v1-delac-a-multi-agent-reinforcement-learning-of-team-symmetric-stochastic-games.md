## 摘要
本文研究具有$m\ge 2$个团队的团队对称博弈。同一团队内的参与者具有对称身份且拥有共同的收益函数。我们证明了团队对称博弈始终存在团队对称纳什均衡。我们建立并求解了团队对称纳什均衡的线性互补问题。我们提出了一种基于演员-评论家的团队对称博弈多智能体强化学习算法。通过仿真实验，我们表明该多智能体强化学习算法的性能显著优于许多现有算法。

## Abstract
In this paper we study team-symmetric games with $m\ge 2$ teams. Players within a team have symmetric identity and have a common payoff function. We show that team-symmetric games always have a team-symmetric Nash equilibrium. We develop and solve a linear complementarity problem of team-symmetric Nash equilibria. We propose an actor-critic based multi-agent reinforcement learning algorithm for team-symmetric games. Through simulations, we show that this multi-agent reinforcement learning algorithm performs much better than many existing algorithms.

### 2. 方法论

*   **核心思想**：本文提出的**Delegate Actor-Critic（DelAC）算法**，其核心是利用团队对称性来简化问题。该算法基于CTDE（集中式训练，分布式执行）框架，通过求解一个规模大幅缩减的线性互补问题（LCP）来引导智能体策略的更新。
*   **关键技术细节**：
    *   **理论奠基**：本文首先证明了**任何具有共同收益的团队对称博弈都必然存在一个团队对称纳什均衡**（命题1），为该算法提供了理论基础。

    *   **算法流程（DelAC）**：
        1.  **初始化**：由于团队内对称，每个团队仅需一个**代表演员（Delegate Actor）网络**来生成策略，以及一个**集中式评论家（Centralized Critic）网络**来估计动作价值函数$Q$（命题2证明了此做法的合理性）。

        4.  **演员更新**：基于评论家给出的$Q$值，构建一个团队对称博弈$\Gamma(Q(o^t, a^t))$，并求解LCP（公式9）得到一个均衡策略$\tilde{\pi}^t$。演员网络通过最小化其输出策略$\pi$与目标均衡策略$\tilde{\pi}^t$之间的KL散度（公式12）来更新，从而逐步学习到纳什均衡策略。
