## 摘要
可解释人工智能（XAI）旨在提高用户在使用AI模型时的理解和决策。然而，尽管XAI有所创新，近期的用户评估显示这一目标仍未实现。理解人类认知有助于解释为何用户难以有效使用AI解释。聚焦于结构化（表格）数据的推理，我们研究了在预测AI决策（即前向模拟）的决策任务中，不同XAI方法（无解释、特征重要性、特征归因）的多种推理策略。我们i）通过形成性用户研究提取推理策略，ii）通过总结性用户研究收集决策。利用认知建模，我们实现了每种推理策略背后的过程，并评估了它们与人类决策的一致性。我们发现，我们的模型比基线机器学习代理更好地拟合了人类决策，从而揭示了哪些推理策略（不）有效。然后，我们展示了如何利用拟合的模型来形成假设并研究那些昂贵而难以用真实人类参与者进行的研究问题。这项研究有助于调试人类对XAI的理解，为未来开发更可用和可解释的AI解释提供信息。

## Abstract
Explainable AI (XAI) aims to improve user understanding and decisions when using AI models. However, despite innovations in XAI, recent user evaluations reveal that this goal remains elusive. Understanding human cognition can help explain why users struggle to effectively use AI explanations. Focusing on reasoning on structured (tabular) data, we examined various reasoning strategies for different XAI methods (none, feature importance, feature attribution) in the decision task of anticipating AI decisions (i.e., forward simulation). We i) elicited reasoning strategies from a formative user study, and ii) collected decisions from a summative user study. Using cognitive modeling, we implemented the processes underlying each reasoning strategy and evaluated their alignment with human decision-making. We found that our models better fit human decisions than baseline machine learning proxies, providing insights into which reasoning strategies are (in)effective. We then demonstrate how the fitted model can be used to form hypotheses and investigate research questions that are costly to study with real human participants. This work contributes to debugging human understanding of XAI, informing the future development of more usable and interpretable AI explanations.

### 2. 论文提出的方法论：CoAX 认知模型
*   **核心思想与设计流程**：
    *   采用以用户为中心的五步流程：**形成性研究**（出声思维，提取真实用户的推理策略）→ 将这些策略实现为**认知模型 CoAX** → **总结性研究**（大规模收集行为数据）→ 用行为数据**拟合并验证模型** → 使用拟合后的模型**进行虚拟假设测试**。
    *   聚焦于**结构化数据（表格形式）**的分类任务，使用**特征重要性**和**特征归因**这两类最常见的 XAI 解释。
*   **基础认知理论**：
    *   以**基于实例的学习理论（IBL）** 为基底：模拟用户决策时，是从记忆中检索过去见过的示例，并与当前实例比较相似度（考虑遗忘和检索阈值），然后加权聚合得出预测标签。
    *   具体公式为：相似度 `S(x, x') = e^{-α·d(x, x') + A}`，其中激活值 `A = -λ ln(Δt)`，仅当 `A ≥ ρ` 时才被检索。
*   **从用户研究中提取的四种推理策略**：
    1.  **敏感特征分类**：在无解释时，用户会固定关注一小部分最具判别力的特征，忽略其他。模型通过计算各特征的 `t` 统计量，选出 `k` 个区分度最高的特征，再基于这些特征计算实例间的相似度。
    2.  **显著特征分类**：在重要性解释下，用户动态地关注当前实例中重要性得分最高的 `k` 个特征，并回忆记忆中这些特征值相似的示例。模型仅在这些选取的特征上计算距离。
    3.  **归因求和**：在归因解释下，用户近似地将各特征的正负贡献进行加总，并据总和的符号判断模型的预测。模型用一个 sigmoid 函数 `P(y=1) = σ(ζ Σ a_r · y_r)` 来模拟，其中 `y_r` 为从记忆中检索到的该特征倾向的类别。
    4.  **重要性分类**：这是一种存在缺陷的策略，用户将重要性得分本身当作一种特征值进行模式匹配，而忽略了原始特征值。例如，“当特征A比特征B更重要时就是类别1”。
    5.  此外还包含一个**随机策略**来拟合非认真参与的参与者。
*   **模型参数与拟合**：每个虚拟用户需拟合的参数包括：样本距离敏感度 `α`（归因求和策略为特征-类别敏感度 `ζ`）、记忆检索阈值 `ρ`、注意的特征数 `k`。记忆衰减率 `λ` 固定为 0.5。使用基于高斯过程的贝叶斯优化按试次拟合参数，并基于 BIC 选出每位参与者在每轮测试中最可能使用的策略。

### 3. 实验设计
*   **数据集与任务**：
    *   使用了三个 UCI 经典数据集：**葡萄酒质量**、**森林覆盖类型**、**成年人收入**。所有数据集均为二分类问题，并简化为只使用 5 个特征。
    *   **核心任务**是“前向模拟”：给定一个测试实例及其属性（和可能存在的解释），用户需要预测 AI 模型对该实例的分类输出。
*   **AI 模型与解释方法**：
    *   葡萄酒质量使用 MLP，森林覆盖和成年人收入使用 XGBoost。
    *   XAI 解释器为 SHAP 和 LIME。
*   **用户研究设置**：
    *   **形成性研究**：招募 20 名大学生，通过出声思维和部分平衡的组内设计，探究无解释、重要性解释、归因解释三种条件下的推理过程。
    *   **总结性研究**：招募 335 名（剔除不合格者后）Prolific 在线工作者，采用组间（XAI 类型）× 组内（测试时有无解释）的混合设计。
*   **对比基准**：
    *   **机器学习代理模型**：决策树、KNN、多层感知机。这些模型被训练来拟合用户给出的决策标签，而非真实标签，以模拟表面行为。特征集为仅用原始属性、或用属性拼接重要性/归因分数。

### 6. 论文的主要结论与发现
*   **模型拟合优越性**：CoAX 认知模型在负对数似然（NLL）和贝叶斯信息准则（BIC）指标上，均一致优于决策树、KNN 和 MLP 等行为代理模型，能更准确地复现个体用户的真实决策。
*   **解释类型塑造推理策略**：
    *   **归因解释（Attribution XAI）**：使用户几乎全体统一采用**归因求和**的算术式思维，策略高度一致。
    *   **重要性解释（Importance XAI）**：导致高度多样化的推理策略，其中包含**重要性分类**这种错误策略（将重要性本身当作特征值），用户也更容易回退至**敏感特征分类**（忽略解释）。这表明简约的解释（去除方向信息）反而增加了用户推理的不确定性和误用。
*   **认知参数的影响**：标签正确率随样本距离敏感度 `α` 和特征-类别敏感度 `ζ` 的增加而提高，随遗忘（检索阈值 `ρ` 升高）而降低，说明模型捕捉到了符合认知直觉的行为模式。
*   **虚拟实验的洞察**：增加训练实例能提高无解释时的理解，但对有归因解释时的表现提升有限；属性数量增加会降低无解释的理解，但归因解释能消解这种信息过载效应；SHAP 和 LIME 的表现优于 Input Gradients。

### 7. 优点
*   **开创性的认知建模路径**：首次将基于实例的学习（IBL）和认知有限性理论系统性地应用于解释人类对 XAI 的（误）理解过程，从“黑箱”的行为代理转向“白箱”的认知机制调试。
*   **严谨的用户中心设计**：严格遵循从形成性（定性）到总结性（定量）再到模型假设检验的闭环流程，确保了模型构建不是来自研究者的想当然，而是源于真实用户行为。
*   **可操作的设计洞察**：用模型清晰地论证了“归因”由于提供对比信息（正负方向）而优于“重要性”的内在认知原因，并识别出一种具体且有害的“重要性分类”误解模式，为 XAI 设计提供了明确的优化方向。
*   **“虚拟用户”的创新价值**：展示了认知模型作为低成本、可扩展的假设测试工具的潜力，能在某些场景下初步替代昂贵且耗时的人类实验。
