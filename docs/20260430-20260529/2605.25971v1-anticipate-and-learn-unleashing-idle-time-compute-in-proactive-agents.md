## 摘要
虽然人工智能智能体在推理和工具使用方面展现出卓越的能力，但它们本质上是反应式的：仅在用户明确提示后才计算响应。这一范式忽略了一个关键的机会：交互之间的空闲时间大多被浪费，智能体无法为未来的用户需求做准备。为弥补这一差距，我们引入了ProAct，一种主动式智能体架构，它利用空闲时的计算力来预见并满足可能即将出现的用户需求。通过分析不断演变的对话历史以及持久化记忆，ProAct预测即将到来的需求并迭代地获取信息，使得智能体能够在用户发起查询之前解决知识缺口并准备证据。为了严格评估主动能力，我们还引入了ProActEval，一个涵盖40个领域共200个场景的综合基准，具有可预测的需求链和多样化的用户认知画像。实证结果表明，与反应式基线相比具有显著优势。在ProActEval上，ProAct通过减少14.8%的所需轮次来加速任务完成，减少用户努力达11.7%，并将幻觉率降低了28.1%。此外，MemBench评估证实ProAct实现了最先进的反思准确性，突显了其持续且稳健的性能。

## Abstract
While AI agents demonstrate remarkable capabilities in reasoning and tool use, they remain fundamentally reactive: they compute responses only after explicit user prompts. This paradigm ignores a critical opportunity: the idle time between interactions is largely wasted, leaving agents unable to prepare for future user needs. To bridge this gap, we introduce ProAct, a proactive agent architecture that leverages idle-time compute to anticipate and fulfill likely upcoming user needs. By analyzing evolving dialogue history together with persistent memory, ProAct predicts upcoming needs and iteratively acquires information, allowing the agent to resolve knowledge gaps and prepare evidence before the user initiates a query.To rigorously evaluate proactive capabilities, we also introduce ProActEval, a comprehensive benchmark comprising 200 scenarios across 40 domains, featuring predictable need chains and diverse user cognitive profiles. Empirical results demonstrate significant advantages over reactive baselines. ProAct accelerates task completion by reducing required turns by 14.8%, decreases user effort by 11.7%, and cuts hallucination rates by 28.1% on ProActEval. Furthermore, MemBench evaluations confirm that ProAct achieves state-of-the-art reflective accuracy, underscoring its sustained and robust performance.

### 2. 论文提出的方法论

*   **核心思想**：提出名为ProAct的主动式智能体架构，将空闲时间转化为一个结构化的“预见与学习”循环。该循环由两个紧密耦合的核心模块驱动，并通过效用感知的门控机制与持久化记忆层进行交互。
*   **关键技术细节与流程**：
    *   **整体形式化**：问题被定义为一个闭环决策问题。对于每一轮用户交互`t`，智能体根据对话历史`Ht`和持久化记忆`Mt`，通过策略`π`在空闲窗口`∆t`和预算`Bt`内预测未来需求、获取证据，并决定交付方式，以最大化未来效用`Ufuture`，同时最小化中断成本`Cinterrupt`和幻觉风险`Rhallucination`。
    *   **持久化记忆层**：
        *   维护多种类型的信息：用户画像、实体级事实、对话摘要和已获取的知识制品。
        *   作为连接预测、获取、交付和未来响应的共享状态。
    *   **未来状态预测模块**：
        *   **功能**：根据当前的对话历史和记忆状态，生成一个紧凑的未来需求候选集`Zt`。
        *   **生成来源**：
            1.  **本地情景预测**：从最近的对话轮次推断近期可能的后续需求。
            2.  **关联扩展**：从持久化记忆中（如用户画像、未完成目标）挖掘相关的长期话题。
            3.  **记忆缺口增强**：将记忆维护模块发现的（如过时、缺失的）知识缺口转化为预测需求。
        *   **过滤与排序**：通过置信度阈值`θconf`过滤低质量候选，并按主题相似度去重和排序，减少重复探索。
    *   **空闲时间获取与交付模块**：
        *   **价值评估**：对每个候选需求`z`，计算一个综合价值分`S(z) = wr*r + wg*g + wv*v + wτ*τ`，其中`r, g, v, τ`分别代表用户相关性、知识缺口、增量价值和时效性。只有得分超过阈值`θval`的需求才会占用搜索预算。
        *   **记忆感知获取**：对于接受的候选，先检查记忆是否已包含足够证据，避免冗余搜索。若证据不足，则按需执行迭代搜索、证据提取。
        *   **制品生成**：为获取到的证据生成一个紧凑的知识制品`Az`，并包含出处，确保可追溯。
        *   **效用感知交付**：生成制品后，通过一个权衡信息价值和中断成本的交付策略，决定制品的处理方式：
            *   **推送**：立即向用户推送高价值、高时效性的信息。
            *   **队列**：排队等候，在后续的交互回复中自然融入。
            *   **静默存储**：存入记忆层备用，不做直接提示。
    *   **核心循环流程**：`(对话历史Ht， 记忆Mt) → 预测需求Zt → 价值评分S(z) → 获取证据并生成制品Az → 决定交付方式dz → 更新记忆Mt+1`。
