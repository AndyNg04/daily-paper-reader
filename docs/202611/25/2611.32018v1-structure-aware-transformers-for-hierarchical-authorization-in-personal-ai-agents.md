## 摘要
个人 AI 智能体能够代表用户执行复杂的多步骤任务，但这通常涉及大量权限请求。逐一手动审核每项请求既耗时，而不加甄别地批准则会带来隐私与安全风险。预测用户的授权偏好，有望在减轻这一负担的同时保留用户的控制权。然而，授权预测面临诸多挑战：权限请求往往具有层级结构，而观测到的用户决策既稀疏，又可能彼此相关。为应对这些挑战，我们提出用于层级结构的父级门控授权 Transformer（Parent-gated Authorization Transformer for Hierarchies，PATH），以预测用户对个人 AI 智能体的授权偏好。PATH 是一种新颖的神经网络架构，通过结合感知层级结构的注意力掩码与父级门控概率形式，确保预测结果符合层级结构的一致性。层级嵌入进一步支持模型从稀疏观测数据以及同一授权层级内共享的模式中进行学习。我们建立了有限样本风险界，并给出了授权概率估计一致性与算法收敛的充分条件。在模拟数据、AI 生成的用户画像以及真实用户授权数据上的实验表明，PATH 具有出色的预测性能，且不会产生任何层级违规。

## Abstract
Personal AI agents can carry out complex, multi-step tasks on users' behalf, but doing so often involves numerous permission requests. Manually reviewing each request is time-consuming, while indiscriminate approval poses privacy and security risks. Predicting users' authorization preferences offers a way to reduce this burden while preserving user control. However, authorization prediction is challenging because permission requests are often hierarchical and observed user decisions are sparse and potentially correlated. To address these challenges, We propose the Parent-gated Authorization Transformer for Hierarchies (PATH) to predict users' authorization preferences for personal AI agents. PATH is a novel neural network architecture that combines hierarchy-aware attention masks with a parent-gated probability formulation to ensure hierarchy-consistent predictions. Hierarchy-level embeddings further support learning from sparse observations and patterns shared within each authorization level. We establish finite-sample risk bounds and provide sufficient conditions for consistent authorization probability estimation and algorithmic convergence. Experiments on simulated data, AI-generated user profiles, and real user authorization data demonstrate strong predictive performance with zero hierarchy violations.

## 1. 核心问题与研究动机

- **逐项确认与过度授权之间的矛盾**：个人 AI 智能体执行多步任务时，逐条审批会增加用户负担；直接放行则可能导致不必要的数据访问、共享或操作。论文希望根据用户特征预测其授权偏好，生成可供用户**批量审核**的权限建议，而不是用模型替代用户同意。
- **授权不是一组独立的二分类任务**：论文把权限组织为已知、固定且由所有用户共享的有向无环图（DAG）。节点代表权限，边代表必要前提；子权限获准意味着其所有父权限和祖先权限都已获准。一个节点可以有多个父节点，且必须满足全部前提。
- **历史反馈稀疏且可能存在选择偏差**：用户只接触或回答部分权限请求；未看到决策不代表拒绝。不同请求的决策还可能因共享上下文或用户倾向而相关。因此，模型既要从不完整标签中学习，也要避免输出违反权限依赖的结果。

## 2. 方法论：PATH 如何预测层级授权

1. **构造用户—权限表示**：用多层感知机（MLP）编码用户特征，再与可学习的权限节点嵌入、深度嵌入相加，得到每个权限节点的输入表示。深度按到根节点的最短路径定义，同深度节点共享深度嵌入，以便在标签稀疏时借用同层信息。
2. **用祖先掩码限制注意力**：Transformer 中，每个节点只能关注自身及其祖先，不能直接关注兄弟节点或其他无祖先关系的节点。实验实现使用两层编码器、四个注意力头，隐藏维度为 128。
3. **按拓扑顺序执行父节点门控**：共享线性层和 Sigmoid 为每个非根节点生成基础分数 \(q_j\)。理论和附录实验设置将根节点分数固定为 1；其他节点按 \(\hat p_j=q_j\prod_{k\in\mathrm{Pa}(j)}\hat p_k\) 递推。由于各因子都在 \([0,1]\)，子节点分数不会高于任一父节点，因此使用**统一阈值**时，二值预测必然层级一致，无需事后修正。
4. **仅用已观测标签计算训练损失**：对最终分数计算掩码二元交叉熵（BCE），不把缺失标签当成负例。论文允许对正类加权，但报告的 PATH 实验中正类权重为 1，不使用额外层级惩罚；二值预测采用 0.5 阈值。
5. **区分统计误差和缺失偏差**：有限样本界把误差来源分为模型近似误差、统计估计误差、优化误差，以及已观测标签与完整标签之间的选择偏差。在观测概率有正下界、前三项趋于零且选择偏差消失等条件下，可以一致估计真实授权概率。附录另对一种特定调度的 Adam 变体给出条件性收敛结果。

## 6. 主要结论与发现

- **PATH 在四组实验中均为零层级违规，但并非唯一做到这一点**。CC 和 C-HMCNN 同样实现零违规；PATH 的特点是通过输出公式直接保证一致性，无需额外约束层或事后修正。
- **预测优势取决于指标和场景**。PATH 在两组模拟和 AI 合成问卷中取得最高 AUC，但两组模拟的 F1 均低于 CC。真实数据中，PATH 的 F1 最高（0.4060），但 AUC 略低于 C-HMCNN（0.6773 对 0.6778）；未报告不确定性，不能据此认为两者的 AUC 有实质差异。
- **事后修正能消除违规，却不一定改善预测**。例如模拟一中，IC 修正后的 AUC 从 0.8801 降至 0.8427，但 F1 从 0.4282 升至 0.4956。结构合法性、排序能力和固定阈值下的分类表现是不同目标，可能出现取舍。

## 7. 优点

- **硬约束简单、可审计**：统一阈值下的零违规来自可直接验证的父子单调关系，不依赖模型碰巧学会规则，也无需决定事后应补开父权限还是撤销子权限。
- **把先验结构同时用于表示和输出**：注意力掩码限制信息流，门控约束最终预测，深度嵌入提供跨节点参数共享。训练时明确区分缺失和拒绝，符合授权日志稀疏的实际情况。
- **理论分析明确指出了数据量无法自动解决的问题**：当是否作答与真实授权偏好在给定用户特征后仍有关联时，增加同类观测不一定能消除选择偏差。风险界将这类偏差与模型拟合、样本量和优化误差分开。

## 8. 不足与局限

- **多父 DAG 上的乘积不等同于一般概率链式法则**。准确的边际概率应是“所有父节点同时获准的联合概率”乘以“在该条件下子节点获准的概率”。PATH 用父节点边际概率的乘积代替联合概率，而共享祖先通常会使两者不同。例如同一前置权限以 0.5 的概率获准，两项父权限都随该前置权限获准时，两项同时获准的概率是 0.5，不是 \(0.5\times0.5=0.25\)。因此，门控能保证预测顺序合法，但可能压低多父节点的预测分数，甚至使某些真实边际概率无法由模型表示。论文的一致性结论仍以近似误差能够消失为前提。
- **深度嵌入不等于显式建模同层相关性**。它提供同层参数共享，但祖先掩码禁止无祖先关系的节点直接交互；逐节点 BCE 也不直接估计权限的联合分布。第二组模拟说明模型在有相关性时仍能取得较好结果，并不能单独证明它恢复了这些相关性。
- **真实场景的外推证据有限**。按附录邻接表，真实数据的 447 节点结构实际为树，并未检验真实多父权限依赖。真人测试规模小，且合成样本的影响未单独评估；AI 合成问卷又通过提示预设了隐私顾虑、信任程度与跳答行为之间的关系，不能替代独立的人类行为证据。
- **优化保证与实验配置不可混同**。附录的 \(O(1/k)\) 期望优化误差界针对带特定衰减调度的 Adam 变体，并依赖光滑性、PL 条件和有界无偏梯度等假设；它不直接覆盖实验中报告的固定学习率、带权衰减配置。
- **零违规不是部署安全保证**。层级合法的建议仍可能误判用户偏好。论文没有报告概率校准、敏感权限的误批准率、实际减少了多少确认操作，或用户是否更容易理解和撤销授权。因此，现有证据更支持把 PATH 用于**生成待确认的权限建议**，而不是自动批准敏感操作。
