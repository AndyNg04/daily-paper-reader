Abstract
Understanding how stable psychometric traits and time-varying
states jointly inform behavior is an important problem in com-
putational behavioral science. Existing personalized agents com-
monly condition actions directly on a static profile, leaving realized
state transitions unused as an explicit source of supervision. We
introduce a profile-conditioned state world model that uses ob-
served environment–behavior state transitions to learn transition-
informed representations for behavioral prediction. During train-
ing, a posterior encoder quantizes realized transitions, while a prior
predicts the resulting codes from the psychometric profile and pre-
transition context. The prior code and predicted next state then
condition macro-level behavior and simulator-grounded execution.
Thus, the world model provides structured transition supervision
instead of treating personality as a direct action descriptor. We eval-
uate the framework in VEET, a controlled behavioral simulator with
human trajectories, and in AgentSociety as a structurally different
synthetic environment. A participant-disjoint split of 240 training,
25 validation, and 48 test participants evaluates generalization to
unseen people. On VEET, the model reaches 0.904 Top-1 accuracy
(95% CI: [0.895, 0.913]) and 0.0033 Macro KL. Ablations associate
continuous next-state modeling with most of the Top-1 gain, while
discrete codes and prior alignment mainly improve Top-3 and dis-
tributional alignment. These results establish transition-informed
world-model supervision as useful for subject-generalized behavior
prediction, without implying causal psychological mechanisms or
calibrated long-horizon state dynamics.

Introduction
Human behavior reflects both stable individual differences and
states that vary within a task. Psychometric profiles describe between-
person variation in stress, motivation, and related traits, whereas
recorded task, environmental, and behavioral variables describe the
context in which those tendencies are expressed. Dense longitudi-
nal evidence shows that trait- and state-level motivation can exert
distinct and interacting effects on effort-based decisions [7]. For
computational behavioral simulation, this distinction suggests that
realized state transitions can provide supervision beyond a static
profile-to-action mapping.
Existing personality-conditioned agents only partially use this
structure. LLM-based social simulators combine persona descrip-
tions with needs, memory, and planning [10, 13], while consistency-
oriented training reduces persona drift across interactions [1]. These
systems can produce locally plausible behavior, but profiles are
commonly injected as static prompts, policy inputs, or reward de-
scriptors. A direct profile-to-action model can therefore capture
participant-level associations without representing within-person
changes in task, environmental, and behavioral state.
The central challenge is to exploit realized state changes during
training without using future information at inference. Realized
environment–behavior state changes provide transition-level su-
pervision associated with subsequent behavior, but the future state
is unavailable before an agent acts. Under participant-disjoint eval-
uation, the model must also transfer this structure to profiles and
trajectories never observed during training, rather than memorize
participant-specific action frequencies. We therefore ask whether
explicit state-transition supervision can improve behavioral predic-
tion for previously unseen participants.

World models provide a natural inductive bias for this question
because they learn state evolution rather than only action associ-
ation. Latent world models have enabled agents to learn compact
transition structure and reason over predicted futures [4–6]. Stan-
dard world models, however, are designed primarily for task control
and do not explicitly separate stable psychometric profiles from the
time-varying environment–behavior state. Our formulation makes
that distinction explicit and uses next-state prediction as structured
supervision for downstream behavior.
We introduce a profile-conditioned state world model. For each
transition, the model separates the stable psychometric profile from
the current environment–behavior state and macro behavior. A
training-time posterior observes the realized state change and as-
signs it to a vector-quantized transition code. A rollout-time prior
predicts that code using only the profile and pre-transition context,
making the transition-informed representation available without
future leakage. The code and predicted next state condition macro-
level behavior, which is realized through a simulator-specific micro
controller. The world model is therefore central to the profile–state–
behavior factorization, while the evaluated outcome is behavior
prediction rather than independent calibration of long-horizon state
dynamics.
We evaluate the formulation in two complementary environ-
ments. VEET provides questionnaire profiles and behavioral trajec-
tories from human participants for the primary unseen-participant
evaluation. AgentSociety provides a structurally different synthetic
LLM-based environment for testing whether the same factorization
can be operationalized across state spaces and action interfaces. We
use a strictly participant-disjoint split of 240 training, 25 validation,
and 48 test participants, so every reported VEET test trajectory
comes from a previously unseen person. Ablations separate the
effects of continuous next-state prediction, vector quantization,
and rollout-time prior alignment; a code–trait analysis bounds the
interpretation of the learned representation.
Our contributions are:
• We formulate subject-generalized human behavior predic-
tion by separating stable psychometric profiles from time-
varying environment–behavior states and using realized
transitions as structured supervision.
• We develop a profile-conditioned state world model whose
posterior extracts vector-quantized transition codes from
observed state changes and whose prior predicts them from
pre-transition context for leakage-free rollout.
• On a participant-disjoint VEET split, we show the predictive
utility of transition supervision and characterize the distinct
roles of continuous state prediction, discrete codes, and prior
alignment; AgentSociety supplies a synthetic operationaliza-
tion rather than independent psychological validation.

Related Work
Trait–state modeling and behavioral simulation. Psychological
theories distinguish relatively stable between-person traits from
within-person states that fluctuate across time and context. Lon-
gitudinal evidence further shows that trait and state motivation
can contribute independently and interactively to effort-based deci-
sions [7]. Simulation platforms provide a controlled setting in which
such dynamics can be observed and modeled: Unity-based experi-
mental frameworks reproduce established behavioral effects [2, 8],
while interview-conditioned generative agents can reproduce sev-
eral empirical patterns in human responses [9]. Our focus is not
to assign a fixed psychological type to an agent, but to use ob-
served environmental and behavioral state changes as structured
supervision for profile-conditioned behavior prediction.
Personality-conditioned agents. Personality-aware agents com-
monly inject profile information through prompts, memory, needs,
value systems, or policy conditioning. AgentSociety combines needs,
affect, cognition, and memory in large-scale social simulation [10],
whereas D2A maps personality profiles to desire-driven values for
daily activity generation [13]. Other work has measured how Big
Five traits alter LLM-agent decisions and performance [3, 12], or
used consistency-based optimization to reduce persona drift across
interactions [1]. These methods establish the value of explicit pro-
files, but primarily use them as static conditions on behavior. We
instead separate the profile from the time-varying environment–
behavior state and model how their interaction informs subsequent
behavior.
World models and latent transition learning. Latent world models
learn compact predictive representations of sequential environment
dynamics and use them for imagination or control. Dreamer intro-
duced policy learning in a recurrent latent state space [4], while
discrete and more general successors improved representation learn-
ing and cross-domain robustness [5, 6]. We adopt the predictive
principle of world modeling for a different scientific target: learning
how questionnaire-derived traits condition environment–behavior
state changes. Our transition-informed posterior uses realized fu-
ture changes to discover discrete modes, and a prior predicts those
modes from pre-transition context for rollout. The codes therefore
represent transition-level predictive structure rather than static
personality categories.

3.2
Overview
The profile-conditioned state world model first encodes the stable
profile, current environment–behavior state, and macro behavior.
A training-time posterior uses the realized future state change to
identify a discrete transition code, while a prior predicts that code
from information available before the transition. Conditioned on
the code, the world model predicts the next state. The transition
code and predicted next state feed a macro behavior decoder, and a
simulator-specific execution policy realizes the macro behavior as
primitive actions. The code is therefore a transition-level predictive
variable rather than a participant identity or personality label.

4
Experiments
Experiments examine whether transition-informed supervision im-
proves behavior prediction for unseen participants, how continuous
next-state modeling, discretization, and prior alignment contribute,
and whether the same profile–state–behavior factorization can be
operationalized in a structurally different simulator. VEET provides
the primary human-participant evaluation; AgentSociety provides
a synthetic cross-simulator test.
4.1
Experimental Setup
Simulation Environment. We evaluate our framework on two
complementary simulation platforms: AgentSociety [10] and VEET,
a self-built Unity-based behavioral simulator. AgentSociety is a syn-
thetic, LLM-driven city-scale multi-agent simulation platform in
which agents maintain internal memory, update needs and internal
simulator states, generate daily activity plans, and execute behav-
iors through modular action blocks. It provides a synthetic testbed
for operationalizing profile-conditioned behavior under a differ-
ent state and action interface. VEET is a Unity-based simulator
designed to study behavioral trade-offs between reward acquisition
and anxiety- or effort-related pressure. Further environment details
appear in Section B. Participants make sequential navigation and
task decisions in a controlled interactive environment.
AgentSociety Simulation. We use AgentSociety as a synthetic
testbed and adapt it to our hierarchical formulation by injecting
questionnaire-derived psychological profiles into each LLM-controlled
agent and constraining its behavior to five macro actions: work,
consume, rest, leisure, and move. Each agent is simulated over a
full daily schedule rather than through isolated one-step queries.
At each decision point, the LLM observes the agent’s current needs,
profile-derived traits, location, and recent context, and selects a
macro action that is executed over the corresponding simulation
interval. This yields temporally grounded macro-action traces that

Dataset and Subjects. We use questionnaire profiles from 313

Subject-Level OOD Evaluation. We treat the human participant
as the domain factor and use a strictly subject-disjoint split of 240
training, 25 validation, and 48 test participants. Each partic-

exactly one split; there is no participant overlap across training,
validation, and test. This protocol therefore tests whether the behav-
ioral predictor generalizes to unseen people, rather than measuring
performance on new trajectories from previously observed people.

4.2
Unseen-Participant Behavioral Prediction
Table 1 evaluates the complete 48-participant test set, with no par-
ticipant, profile, or trajectory shared with training. On VEET, the
profile-conditioned world model reaches 0.904 Top-1 and 0.989 Top-
3 accuracy, compared with 0.754 and 0.890 for direct SFT/BC. It also
reduces Macro KL to 0.0033 and reaches 0.999 macro-distribution
similarity. The participant-level 95% bootstrap interval for Top-1
is [0.895, 0.913], with the remaining intervals reported directly in
the table. Together, these results show that the learned transition
representation supports macro-behavior prediction for previously
unseen participants; they do not establish causal psychological
dynamics.
4.3
Contribution of Transition Supervision
Table 2 separates continuous next-state prediction, discrete transi-
tion modeling, and rollout-time prior alignment. The largest point-
wise difference is between direct SFT/BC in Table 1 (0.754 Top-1) and
the continuous world model (0.901), associating explicit next-state
supervision with most of the Top-1 gain. Because these variants also
differ architecturally, this comparison is evidence of predictive util-
ity rather than a controlled causal attribution. Vector quantization
changes Top-1 only slightly (0.905) but improves Top-3 from 0.952
to 0.981 and reduces Macro KL from 0.012 to 0.0078. Prior alignment
further lowers Macro KL to 0.0033 and raises Top-3 to 0.989 while
preserving Top-1. Thus, continuous transition supervision supplies
the principal pointwise gain, whereas the discrete prior–posterior
design mainly improves behavioral coverage and distributional
alignment while making the transition-informed representation
available before the future is observed.
A profile-cluster diagnostic tests whether this aggregate result
is concentrated in a small questionnaire subgroup. VEET Top-1 re-
mains between 0.891 and 0.913 across the reported groups, although
teleport recall is lower and more variable (0.13–0.26). Because clus-
ter sizes are limited, we treat these differences as descriptive bound-
aries rather than subgroup or causal effects (Table 3).
4.4
What the Latent Modes Represent
The latent variable is intended to summarize transition-level pre-
dictive structure, not to encode a static personality category. We
therefore examine 19 analyzed prior codes against seven psychome-
tric scales (133 tests). No code–scale association survives BH–FDR
correction, and nominal effects are small (|𝜌| ≈0.11–0.19). This
result does not prove disentanglement, but it is consistent with the
transition modes not being reducible to individual questionnaire
dimensions (Figure 3).
At the uncorrected level, several small associations provide ex-
ploratory structure without supporting psychometric labels. C90 is
positively associated with PSS, STAI-T, BDI, and STAI-S; C23 and
C91 show related stress–anxiety patterns; C73 is positively associ-
ated with AMI; and C88, C74, and C48 are negatively associated with
STAI-S. Code-use entropy and the number of unique codes likewise
yield no FDR-significant scale association. We therefore treat these
patterns as hypothesis-generating diagnostics of transition-mode
usage, not as evidence that individual codes correspond to traits,
symptoms, or clinical categories.

4.5
Synthetic Cross-Simulator
Operationalization
AgentSociety tests whether the same profile–state–behavior fac-
torization can be operationalized in a synthetic LLM-based simula-
tor with a different state space and action interface. Ours obtains
the highest reported Top-1 accuracy (0.595) and maintains strong
macro-distribution alignment in Table 1. Figure 2b further compares
observed and predicted cluster-level action mixtures. The rollouts
preserve differences among work, consumption, leisure, rest, and
movement across profile groups, while the prediction tracks the
dominant cluster-level patterns. We interpret this as a synthetic
cross-simulator operationalization, not as a second independent

Limitations and Ethical Considerations
The VEET data were collected by the original study team under
institutional human-subjects oversight at Emory University, with
informed consent from all participants. This work uses only de-
identified data and involved no new participant recruitment or
contact; access was restricted to authorized researchers.
Our evaluation establishes the downstream predictive utility of
transition supervision; it does not independently assess calibrated
multi-step state-transition fidelity. The model does not contain a
separately observed dynamic affect channel; its transition repre-
sentation is learned from environmental and behavioral variables
recorded by VEET. The learned codes are behavior-predictive sum-
maries rather than causal, clinical, or diagnostic states, and the
model is not intended for consequential decisions about individuals.
Participant-disjoint evaluation addresses transfer to unseen people
within this study design; validation across additional populations
and instruments remains future work. Responsible use requires
de-identification, restricted access, and human oversight.
6
Conclusion
We study transition-informed supervision for behavior prediction
in unseen participants. The world model separates stable profiles,
current states, and behavior: a posterior extracts codes from ob-
served changes, while a prior predicts them before the future is
available. VEET results associate next-state modeling with point-
wise accuracy and discretization and prior alignment with behav-
ioral coverage and distributional alignment. AgentSociety provides
a synthetic cross-simulator operationalization. These results sup-
port the world model as a predictive inductive bias rather than a
validated psychological mechanism.

AgentSociety
A.1
Modifications
We use AgentSociety as a synthetic testbed and modify it to expose
a profile-conditioned hierarchical action interface. The modifica-
tion consists of four components: profile injection, need-dynamics
modification, block-level action restriction, and trajectory logging.
Profile injection. For each subject, we first convert the ques-
tionnaire vector into an AgentPsychProfile. The profile contains
initial need satisfactions, emotion values, personality text, and
three composite behavioral dimensions: hedonic capacity, effort
capacity, and stress level. After the simulator creates the native
SocietyAgent instances, we patch each live agent by writing these
values into its memory state. Specifically, we initialize hunger_satisfaction,
energy_satisfaction, safety_satisfaction, social_satisfaction,
and the added pleasure_satisfaction field, together with the
agent’s emotion state, emotion types, background text, and initial
thought.
Need-dynamics modification. We extend the original need
state with a pleasure-related dimension. This dimension is initial-
ized from questionnaire-derived hedonic traits, especially measures
related to anhedonia and momentary pleasure. We also patch the
NeedsBlock parameters after agent construction. Questionnaire
traits scale the decay rates of hunger, energy, safety, social, and
pleasure needs through multiplicative factors 𝛼𝐻, 𝛼𝐷, 𝛼𝑃, 𝛼𝐶, 𝛼𝐿.
Anxiety- and hedonic-related traits further shift the safety and
pleasure thresholds. This makes the same environment state induce
different dominant needs for different profile types. For example,
high stress can make safety needs trigger earlier, while low hedonic
capacity can make pleasure satisfaction decay faster and trigger
leisure-seeking behavior sooner.
Social-behavior suppression. Because our experiments focus
on individual profile-conditioned behavior rather than interper-
sonal dynamics, we suppress the original social pathway. We re-
move social behavior from the plan guidance options, replace the
detailed planning prompt with a no-social version, and set the so-
cial satisfaction state to a high value while making its decay nearly
zero. We also remove any registered SocialBlock from the agent
dispatcher when present. This prevents the agent from spending
trajectory steps on messaging, calling, or meeting other agents,
and ensures that logged behaviors correspond to individual daily
activities.
Structured macro-action interface. The original AgentSo-
ciety planner can generate free-form natural-language actions.
We replace this with a five-category macro-action vocabulary:
A = {work, consume, rest, leisure, move}. Internally, these cor-
respond to coarse plan types work, consume, sleep, leisure, and
mobility. The detailed plan prompt is constrained so that each plan
step must use exactly one of these coarse types and must avoid fine-
grained sub-actions. We additionally introduce or expose dedicated
rest and leisure execution paths so that rest and leisure corre-
spond to executed behavior modules rather than merely textual
descriptions.
The macro-action prior is profile-conditioned. The current dom-
inant need provides a base preference over macro actions: hunger
favors consumption, tiredness favors rest, safety favors work, and
pleasure favors leisure. The composite profile dimensions then shift
these logits: hedonic capacity increases the tendency toward con-
sumption and leisure, effort capacity increases work and mobility,
and stress increases rest while suppressing consumption, leisure,
and movement. The resulting logits define a profile-conditioned
macro distribution used both for simulation analysis and as the
behavioral abstraction aligned with our hierarchical policy models.
Execution and logging. Each LLM-controlled agent is simu-
lated over a daily schedule. At each discrete simulation time point,
the agent observes its current need state, emotion, thought, profile
text, location, and recent memory context. The LLM selects a guid-
ance option and expands it into a short structured plan whose steps
belong to the allowed macro categories. During post-processing,
each executed memory stream event is mapped back to one of
the five macro actions. We log the simulation tick, current need
state, satisfaction values, questionnaire profile, macro action, macro-
action logits and probabilities, and the corresponding micro-action

VEET Explanation
B.1
VEET Environment and Training State
Details
VEET environment. VEET is an embodied Unity-based behavioral
task in which participants navigate through a multi-room virtual
environment, collect coins, move between rooms through doors,
and occasionally use teleportation. The environment records both
low-level motor behavior and task-level progress variables. Each
participant also provides questionnaire responses measuring affec-
tive and motivational traits. These questionnaire responses define a
subject profile vector q𝑖, which conditions our models throughout
training.
Observation state. At each time step, we convert the raw Unity
observation into a flat numerical state vector s𝑡. The state contains
four groups of information: (1) self-motion and position, including
player position, rotation, movement distance, and wall distances;
(2) room context, including current room, room effort, room reward,
door positions, and distances to front and back doors; (3) object
layout, including remaining coin counts and nearest-coin relative
positions/distances; and (4) task progress, including collected coins,
points, button presses, teleport counts, elapsed time, room time,
round time, and timing flags for post-level subjective queries, but
not the subjective rating values. The raw state vector is normalized
with the same feature scaler used by the behavioral cloning and
reward-model baselines. When clean-feature checkpoints are used,
we apply the corresponding feature mask before normalization so
that all models use an identical state interface.
Questionnaire conditioning. Each subject 𝑖is associated with a
questionnaire-derived vector q𝑖. Depending on the experiment, q𝑖is
represented either as item-level responses, compressed scale-level
features, or eight scale scores corresponding to PSS, SHAPS, BDI,
AES, AMI, MAPSR, STAI-S, and STAI-T. The same q𝑖is concate-
nated with the environment state or encoded as profile context in
the policy and world-model networks. Thus, the model predicts
behavior not only from the current physical state, but also from
stable subject-level psychometric traits.
Macro-action labels. We derive a six-way macro-action label from
human replay trajectories.
These labels are inferred from geometric progress, movement
speed, button presses, room effort, and short-horizon events. For
example, go_to_coin corresponds to movement that reduces dis-
tance to nearby coins, go_to_next_door and go_to_prev_door
correspond to room-transition-directed behavior, and teleport
corresponds to explicit teleport usage. This macro abstraction pro-
vides the high-level action space for our hierarchical policy and
world model.
Micro-action space. The lower-level VEET controller uses the
native discrete Unity action space. Each action is represented as a
triplet (𝑚𝑡,𝑟𝑡,𝑧𝑡), where 𝑚𝑡is movement intensity, 𝑟𝑡is turn direc-
tion, and 𝑧𝑡indicates teleportation. Non-teleport actions enumerate
movement and turn combinations, while a separate discrete action
is reserved for teleport. This gives a 13-way micro-action space.
The macro-conditioned micro policy receives the normalized state
s𝑡, the subject profile q𝑖, and an embedding of the current macro
action, then outputs a distribution over these 13 low-level actions.
