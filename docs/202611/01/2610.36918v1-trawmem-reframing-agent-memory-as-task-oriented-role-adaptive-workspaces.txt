# TrawMem: Reframing Agent Memory as Task-Oriented Role-Adaptive Workspaces

Large language model (LLM) agents rely on memory systems to leverage long-term interactions, yet existing systems typically retrieve memories based on their relevance to the current query and use them as contextual evidence. However, relevance alone does not characterize how a memory contributes to task solving: the same memory may serve different roles across tasks, such as directly supporting the answer or linking to complementary memories with weaker semantic relevance but necessary information. We therefore reframe agent memory systems as Task-Oriented Role-Adaptive Workspaces , where memories are selected and organized by their task-oriented roles and relations. Based on this view, we propose TrawMem , which organizes interaction histories into local threads and constructs task-oriented workspaces by assigning roles and jointly selecting complementary memories. Experiments on LoCoMo and MemGallery with four open- and closed-source backbones show consistent improvements over representative memory systems, with macro-F1 gains of 2.23–3.14 points. On LoCoMo, TrawMem improves the LLM-Judge score over SimpleMem by 4.07 and 4.31 percentage points on Qwen3.5-9B and DeepSeek-V4-Flash, respectively, while requiring approximately 12.8% and 5.1% fewer context tokens, respectively. ## 1. Introduction 

In recent years, agents have been widely applied to long-horizon multi-turn dialogue, personalized assistants, and continuous task (Packer et al., 2023; Park et al., 2023; Zhong et al., 2024; Kang et al., 2025). These tasks require agent systems to maintain conversational memory across evolving 

† Project Leader: Zixu Li. Corresponding Author: Yupeng Hu. arXiv:2610.36918v1 [cs.CL] 27 Oct 2026 interactions to understand user needs and complete subsequent tasks. However, growing interaction histories make limited context windows a key bottleneck for long-horizon tasks (Packer et al., 2023). Although larger context windows (Chen et al., 2023, 2024; Ding et al., 2024) can accommodate more history, information in less salient positions remains prone to being overlooked (Liu et al., 2024). Reprocessing full history for each query also incurs substantial inference overhead (Fang et al., 2026). Agent memory systems have therefore emerged to store information outside the current context and retrieve relevant memories for new queries, mitigating information loss from growing interaction histories. Existing work (Du et al., 2025; Zhang et al., 2025a) advances memory construction, main-tenance, and retrieval. For example, Mem0 (Chhikara et al., 2025) integrates long-term memory (LTM), A-MEM (Xu et al., 2026a) organizes related information through memory links, while Light-Mem (Fang et al., 2026) and SimpleMem (Liu et al., 2026) improve efficiency through offline memory maintenance, and memory compression with dynamic retrieval planning, respectively. Despite these advances, existing agent memory systems typically select memories by their direct relevance to the query and use them as context for task solving. This focuses on whether a memory is relevant to the task, while overlooking the role it plays in solving it. Indeed, a memory’s importance depends not only on its semantic relevance but also on its task-oriented role. As shown in Fig. 1(a), memory unit A is highly relevant to both Task A and Task B, but serves different roles. For Task A, it directly supports the answer; for Task B, it primarily connects to other memories, such as unit B. By recognizing this role, we can identify complementary memories such as B, whose semantic relevance to Task B may be weaker and thus be overlooked by existing methods. This motivates identifying the roles of memories for a given task and organize memories that jointly support task solving. Rather than viewing memory as a collection of records awaiting retrieval, we therefore reframe it as a workspace temporarily formed for the current task, where the system can construct effective combinations of information according to distinct roles and relations of memories in the current task. From this perspective, we propose Task-Oriented Role-Adaptive Workspaces ( TrawMem ), which reframes agent memory usage around task-oriented roles and relations. As shown in Fig. 1(b), conventional memory systems typically use retrieved relevant memories as context, whereas TrawMem 

selects and organizes memories into a task-oriented workspace. In this view, the same memory may serve different roles depending on the task and its relations with other memories, shifting the focus of agent memory from finding relevant memories to organizing memories according to how they support task solving. To achieve this goal, TrawMem organizes memory usage into two stages. The first organizes continuous interaction histories into local threads and establishes relations between them. The second constructs a workspace for each task by retrieving candidate memories from relevant thread neighborhoods and selecting them according to their task-oriented roles. Section 4 details this process. 

Contributions. This work shows that the same memory may serve different roles across tasks, and reframe agent memory usage as Task-Oriented Role-Adaptive Workspaces. Based on this view, we propose TrawMem to select and organize memories according to their task-oriented roles, and validate its effectiveness through systematic evaluation. 

Performance. On long-horizon interaction memory benchmarks, LoCoMo and MemGallery, we com-pare TrawMem with representative memory systems across four open- and closed-source backbones. Under the same backbone, TrawMem improves the macro-average 𝐽 score (LLM-Judge) by 2.19– 6.34 and 0.52–4.82 percentage points on LoCoMo and MemGallery, with mean gains of +3.71 and

## 2. Related Work 

Memory for LLM Agents. Existing LLM agent memory systems store and retrieve interaction histories through memory streams, controllers, and hierarchical structures (Park et al., 2023; Wang et al., 2025). Recent work has further improved memory compactness, update efficiency, and organization through compression and consolidation (Fang et al., 2026; Liu et al., 2026), information extraction and evolving linked memory notes (Chhikara et al., 2025; Xu et al., 2026a), and temporal, hierarchical, and multi-type representations (Kang et al., 2025; Rasmussen et al., 2025; Zhang et al., 2026a; Li et al., 2025a). Retrieval of such memories likewise benefits from composed image search, e.g., noise-robust and anchor-based composition (Li et al., 2026a; Fu et al., 2026; Li et al., 2026b), fine-grained and invariance-aware composition (Li et al., 2025b; Chen et al., 2026), entity-relation binding and focus-shift revision (Chen et al., 2025; Li et al., 2025c), and progressive and dual-path composition (Li et al., 2026c; Zhang et al., 2026b). However, these methods typically treat memories as independent units or rely on coarse-grained relevance. They rarely model how a memory serves different roles across tasks, or treat complementary memory selection as a central retrieval problem. Long interaction histories from agent-based social simulation raise similar organization demands (Zhang et al., 2025b; Song et al., 2026; Zhang et al., 2026c). TrawMem instead assigns task-oriented roles to candidate memories and selects memories to form a task-oriented workspace. 

Retrieval-Augmented Generation. Retrieval-Augmented Generation (RAG) enhances language models by retrieving relevant content from external knowledge sources (Lewis et al., 2020). Beyond standard similarity-based retrieval, subsequent work has explored query planning, query rewriting, iterative retrieval, and compositional query reformulation (Weston and Sukhbaatar, 2023; Creswell et al., 2022; Jiang et al., 2024; Li et al., 2026d; Hu et al., 2026; Li et al., 2026e). GraphRAG (Zhao et al., 2025), LightRAG (Guo et al., 2025), and YouTu (Dong et al., 2026) leverage entity and relation structures to support multi-hop retrieval, while efficient nearest-neighbor indexing and cross-modal benchmarks extend retrieval to scalable and multimodal settings (Yang et al., 2026; Zhang et al., 2026d; Li et al., 2026f). However, existing RAG methods typically rely on a preconstructed knowledge base, making them less suited to preserving event continuity and distinguishing different memory roles in continuous dialogue. TrawMem instead organizes interactions into local threads and constructs a task-oriented workspace through role assignment and coverage-based selection. Related work also explores trajectory-based agent learning (Bi et al., 2026a; Aniri et al., 2026a), LLM-agent social simulation (Zhang et al., 2026e; Bi et al., 2026b), multimodal-agent adaptation and evaluation (Bi et al., 2026c; Zhang et al., 2026f), LLM reasoning (Zhang et al., 2026g; Li et al., 2026g; Zhang et al., 2026h; Zheng et al., 2026), and intrinsic data selection (Bi et al., 2025a; Aniri et al., 2026b; Bi et al., 2025b), complementing our focus on task-oriented persistent memory. 

## 3. Preliminary 

Agent Memory Systems. Agent memory systems preserve reusable information beyond the current context and retrieve relevant content when new queries arrive, thereby providing the answering model with the memory required for long-horizon interaction. In general, these systems organize continuously arriving interaction records into memory units that can be stored and retrieved. Different methods may define their memory granularity in terms of raw turns, summaries, facts, or events, and organize these units using vectors, graphs, or hierarchical structures. When answering a query, the system selects content from the memory bank that is relevant to the current task and provides it to the answering model.

## 4. Methodology 

Based on above insights, we reframe agent memory as Task-Oriented Role-Adaptive Workspaces and propose TrawMem . As shown in Fig. 3, TrawMem consists of two stages. The first organizes raw interaction histories into local threads and establishes relations among them. The second identifies relevant thread neighborhoods for a given task, assigns task-oriented roles to candidate memories, and selects them to form a task-oriented workspace. The two stages are detailed in Sections 4.1 and 4.2, respectively.

5.4. Query-Dependent Role Changes 

We verify a more specific property than relevance-driven memory retrieval: whether the soft role weight of the same memory is adjusted according to the query when its use in the task changes. requires using 𝑣 to connect other records. For each role 𝑅 ∈ { anchor , bridge , context }, we record:

This finding indicates that the role of the same memory shifts between anchor and bridge according to the function it serves in the current query. It provides direct evidence for task-oriented role assignment.

## 9. Conclusion 

We present TrawMem , a task-oriented framework that reframes agent memory as Task-Oriented Role-Adaptive Workspaces . Instead of selecting memories solely by direct relevance, TrawMem organizes interaction histories into local threads, establishes relations among threads, and assigns task-oriented roles to select complementary memories for a workspace. Experiments on LoCoMo and MemGallery across four backbones show consistent improvements over representative memory systems, while ablations further confirm the contribution of the individual components. Overall, our results suggest that modeling the roles and relations of memories provides a useful perspective for memory utilization in long-horizon agent tasks. 

## Ethics Statement 

TrawMem organizes interaction histories into local event threads and constructs task-oriented workspaces for agent systems. While this design can improve long-horizon task solving, storing and reusing interaction histories raises important privacy concerns, as they may contain sensitive personal in-formation. The memory may also preserve or amplify biases, errors, or misinformation present in user-provided content, potentially leading to undesirable agent behavior. Any deployment of TrawMem 

should therefore adopt robust safeguards, including data anonymization, informed user consent, and mechanisms to detect and mitigate biased or false memories.
