## 摘要
大型语言模型（LLM）智能体依赖外部记忆，在多轮交互中保留并复用信息。现有记忆系统将记忆视为对过去的记录，并依据其对话保真度进行评估。然而，记忆的价值在于它能否改善智能体的响应。记忆系统必须在响应生成之前决定记住什么、提供什么，而保真度评估并未根据响应检验这两项决策。因此，即使记忆忠实于对话，也未必能改善响应。我们转而将记忆视为预测问题，并提出\textbf{\emph{\leto{}}}，这是一种面向 LLM 智能体的记忆系统，关注记忆对未来的效用，而非对过去的保真度。由于未来请求尚不可知，\emph{\leto{}}通过记忆索引保留对话细节的访问能力，使信息仍可从其来源中获取。收到请求后，记忆回放利用该索引预测并提供智能体所需的上下文，补充请求中未明确说明的信息。所提供上下文的效用要等到响应生成后才能确定，因此我们引入效用循环，利用响应结果改进未来的记忆选择。我们在三个场景下的五个基准上，将本系统与六种记忆系统进行了评估。在个性化场景中，与表现最强的对比记忆系统相比，本系统在 PrefEval 上的准确率高出 16.3 个百分点，在 PERMA 上的任务完成率高出 3.1 个百分点。对于长时程任务，本系统在涵盖五种环境的 MemoryArena 上取得最佳总体表现，且随着链深度增加，性能优势也随之扩大。在长上下文理解任务中，本系统的表现与直接检索原始历史记录相当，同时提供的上下文 token 更少。

## Abstract
Large language model (LLM) agents rely on external memory to retain and reuse information across interactions. Existing memory systems treat memory as a record of the past and evaluate it by fidelity to the conversation. However, the value of memory lies in whether it improves the agent's response. A memory system decides what to memorize and what to serve before that response exists, and fidelity checks neither decision against it. Faithful memory can therefore fail to improve the response. We instead view memory as a prediction problem and present \textbf{\emph{\leto{}}}, a memory system for LLM agents that focuses on the utility of memory to the future rather than on its fidelity to the past. Because future requests are unknown, \emph{\leto{}} preserves access to conversation details through memory indexing, allowing information to remain available through its sources. When a request arrives, memory replay draws on this index to anticipate and supply the context the agent needs beyond what the request explicitly states. The utility of the served context remains uncertain until the response is generated, motivating a utility loop that uses response outcomes to refine future memory selection. We evaluate our system against six memory systems on five benchmarks across three scenarios. In personalization, it outperforms the strongest compared memory system by 16.3 percentage points in accuracy on PrefEval and by 3.1 points in task completion on PERMA. For long-horizon tasks, it achieves the best overall performance on MemoryArena averaged over five environments with a gain that increases with the chain depth. In long-context understanding, it is on par with retrieval over the raw history while serving fewer context tokens.

## 1. 核心问题与研究动机

- **论文追问的是：智能体的记忆有没有改善回答，而不只是有没有准确记录过去？** 现有系统常在会话结束后提取事实或生成摘要，再按与新请求的相似度检索。历史记录即使准确，检索结果也即使与请求相关，都不保证模型拿到了真正影响回答的信息。
- 作者区分了两类缺口：
  - **记忆缺口（memorization gap）**：写入时舍弃了后来才显出价值的细节，例如摘要遗漏了一项例外条件。
  - **供给缺口（serving gap）**：信息仍在库中，但当前请求没有明说相关约束，导致它未被检索或未被送入模型。例如，“订一家离会场近的酒店”没有重申用户需要无障碍设施，而这项约束可能直接改变选择。
- 论文因此把记忆视为一个**预测问题**：写入时不知道未来会问什么，提供记忆时也不知道模型会如何使用它。作者主张用下游任务结果检验这两项决策，同时保留保真度指标作为诊断，而不是把它当作最终目标。

## 2. 方法论：索引、回放与效用循环

- **记忆索引：以原子事实为检索键，以原文为证据。** Leto 保留完整会话，从中抽取能独立理解的单一事实，并把每条事实链接到产生它的一段相邻消息。请求到来时先匹配事实，再取回其来源片段，而不是只把抽取后的事实交给模型。这样既可精确匹配，也能带回原始措辞、限定条件和未被单独抽取的邻近细节。新事实若修订旧事实，会将其标记为已被取代而非删除；每次会话另有一份简短摘要。
- **记忆回放：在请求到达前准备常驻上下文。** Leto 在会话之间重读当前事实和会话摘要，重写精简的**用户画像**，合并长期偏好与约束，排除已被取代的偏好。对于已声明的跨会话任务，还生成**任务状态**：先按实体列出当前属性和值，再按时间顺序概述此前各会话。新会话同时获得常驻上下文和按请求检索的记忆。
- **效用循环：用反馈调整后续供给优先级。** 每条新记忆获得初始分数 \(u_0(m)\in[0,1]\)。确认或使用记忆等正向信号记为 1，纠正等负向信号记为 0；论文用词法规则检测这些信号，也允许在有评分时记录任务结果。若初始分数的权重为 \(k>0\)，收到 \(n\) 次观测后，分数更新为
  \[
  u(m)=\frac{k u_0(m)+\sum_{i=1}^{n}o_i}{k+n}.
  \]
  检索项须达到阈值 \(\tau\) 才会被提供；超出词元预算时，优先提供分数较高的项。低分不意味着删除。
- **区分评估目标与排序分数。** 对同一个请求 \(x\)，论文将记忆效用定义为 \(U(x,M)=y(x,M)-y(x,\varnothing)\)，即同一智能体有无记忆时的二元任务结果之差，可为 \(+1\)、\(0\) 或 \(-1\)。这是对整组记忆的配对评估；单条记忆的 \(u(m)\) 只是排序启发式，**不是对其独立贡献的估计**。

## 6. 主要结论与发现

- **PrefEval：个性化收益最明显。** Leto 准确率为 **60.5%**，比最强对比记忆系统 Hindsight 的 **44.2%** 高 **16.3 个百分点**。按词法规则检测，Leto 在 **84.2%** 的上下文中提供了偏好线索；即使检测到偏好，回答也只有 **64.4%** 遵循它。全历史基线仅有 **3.3%** 的准确率，说明信息在输入里，不等于模型会用它。
- **PERMA：优势主要来自跨领域任务。** Leto 在单领域与多领域条件下的选择题准确率均最高，多领域任务完成率达 **72.61%**，高于 Memobase 的 **64.97%**。对两种条件的完成率等权平均，Leto 约为 **76.5%**，比 Memobase 高约 **3.1 个百分点**；但单领域完成率由 RAG 领先。Letta 在多领域条件的记忆保真度最高，任务完成率却最低，表明两类指标不能相互替代。
- **MemoryArena：总体领先，并非每个环境都领先。** Leto 的总体进度分数和成功率分别为 **32.01%** 和 **18.33%**。相对无记忆基线，购物通过率的增益从第一步 **+1.3** 个百分点升至第六步 **+7.3**，搜索从第一问 **0** 升至第八问 **+14.4**。此趋势在论文展示的购物和搜索中成立；搜索越往后纳入的任务链越少，不能把这一结果直接外推到其他环境。
- **长上下文问答：以更少检索词元取得有竞争力的结果。** LoCoMo 上，Leto 为 **71.82% / 1,192 词元**，原始历史 RAG 为 **74.61% / 1,999 词元**；LongMemEval S 上，Leto 为 **73.20% / 1,185 词元**，RAG 为 **66.40% / 9,813 词元**。因此更准确的概括是：Leto 在一个基准略低于 RAG，在另一个明显领先，两者都节省了检索词元。

## 7. 优点

- **把“记忆是否有用”变成可检验的问题。** 按同一测试项对比有无记忆，既能看到记忆纠正了多少回答，也能发现记忆破坏了多少原本正确的回答。
- **将信息保留与上下文供给分开。** 完整原文保留了回查空间，原子事实提供更细粒度的检索入口，版本标记区分历史事实和当前状态。系统不必在写入时永久决定某条信息有无价值。
- **区分主动供给和按需检索。** 长期偏好和任务状态不必等用户再次提起才进入上下文；具体细节则可以按请求回查。跨领域个性化和长程搜索的结果表明，这种设计尤其适用于请求未明说全部约束的情形。

## 8. 不足与局限

- **保存完整历史不代表所有细节都可检索。** 若一条消息没有被任何原子事实指向，也未进入其他事实的来源片段，事实索引就无法触达它。在 LoCoMo 中，RAG 答对而 Leto 答错的单跳题里，约 **40%** 存在未被任何抽取事实指向的证据消息。
- **反馈归因粗糙，并可能强化既有选择。** 同一任务结果可能被记到多条同时提供的记忆上，导致无关信息被奖励、正确记忆被惩罚。没有被提供的记忆得不到新反馈，初始低分也可能长期无法修正。论文没有单独验证这种在线更新在长期使用中的收益。
- **保真度诊断仍有测量偏差。** 偏好可用性与证据召回都依赖词汇重合，可能漏掉语义正确的改写，也可能把出现了关键词但没有表达正确关系的文本判为有效证据。单次配对结果也不能完全排除模型生成波动。
- **真实部署仍有成本与风险。** 常驻画像和任务状态可能引入当前请求不需要的信息，也可能生成错误或过时的表述；保存全部会话增加存储、隐私治理和删除合规负担。论文未量化这些成本，也未充分检验长期用户互动、跨模型迁移或不同版本偏好冲突下的稳健性。即使提供了正确记忆，模型仍可能忽略或误用它。
