## 摘要
我们对 Agentic Waterfall Feed 这一全新的个性化信息发现问题进行了形式化定义。在这一问题中，用户主动引导推荐，系统则根据用户的明确请求和浏览行为推断其不断变化的需求，并据此进行调整。为解决这一问题，我们提出 Agentic Waterfall 框架，其语言模型控制器能够维护持久化的用户状态，并协调内容检索、排序和状态更新。为评估此类任务中的系统表现，我们贡献了 Agentic Waterfall 数据集和一种基于回放的评估协议。该数据集结合了真实内容元数据与模拟的交互历史。评估协议在共享历史的条件下对系统进行比较，采用相关性评分以及盲评，判断推荐内容对用户当前目标和约束的满足程度。在五个公开基准上的传统推荐任务中，Agentic Waterfall 的表现与强基线方法不相上下。在 Agentic Waterfall 数据集上，该方法在两项评估中均优于最强基线，相对提升最高达 16.1%。

## Abstract
We formalize Agentic Waterfall Feed, a new problem of personalized information discovery in which users actively direct recommendations and the system adapts to evolving needs inferred from both explicit requests and browsing behavior. We address this problem with the Agentic Waterfall framework, whose language-model controller maintains persistent user state and coordinates content retrieval, ranking, and state updates. To evaluate systems on this task, we contribute the Agentic Waterfall Dataset and a replay-based evaluation protocol. The dataset combines real content metadata with simulated interaction histories. The protocol compares systems under shared histories using relevance scores and blind judgments of how well recommendations satisfy current user goals and constraints. Agentic Waterfall remains competitive with strong baselines on conventional recommendation tasks across five public benchmarks. On the Agentic Waterfall Dataset, it outperforms the strongest baseline in both evaluations, with relative improvements of up to 16.1%.

# Agentic Waterfall：从预测下一次点击，到理解用户此刻想做什么

## 1. 核心问题与研究动机

- **传统推荐的目标不一定等于用户当前的目标。** 信息流往往根据过去的点击或观看记录预测用户下一步会消费什么，但历史兴趣可能已经过时。例如，用户买完相机后想学习如何拍摄足球比赛，即使历史记录里仍然全是相机购买对比，推荐系统也应及时切换方向。
- 论文将这一问题定义为 **Agentic Waterfall Feed**：系统在每轮交互中结合用户的自然语言请求和截至当前的浏览行为，推断用户此刻的目标与约束，并推荐有助于完成目标的内容。它既要处理“用户明确改口”，也要处理“用户没说，但行为已经改变”。
- 论文所说的**用户控制**，具体指用户能够通过请求改变信息流的方向、任务或内容格式。实验检验的是系统能否响应这些变化，而不是用户在真实平台上是否获得了更强的主观控制感。

## 2. 方法论：统一控制器、持久状态与三类动作

- **任务形式化。** 在第 \(t\) 轮，控制器观察当前请求 \(c_t\)（可以为空）、历史 \(h_{\le t}\)、持久记忆 \(m_t\) 和可用内容及工具 \(e_t\)。这些输入构成观测 \(o_t=(c_t,h_{\le t},m_t,e_t)\)，语言模型策略 \(\pi\) 据此选择动作 \(A_t=\pi(o_t)\)，最终输出服务于当前目标的有序内容列表。
- **持久记忆。** 系统保存用户事实、偏好与活跃目标。状态变更关联其依据，例如依据新请求修订内容格式约束，或根据新证据将购买任务标为已完成。这使系统可以延续仍然有效的偏好，而不必把旧任务也一并延续。
- **三类动作由同一个语言模型控制器动态协调：**
  - **Acquire（获取）**：搜索允许访问的来源，或补查条目详情，将内容及元数据加入候选池。
  - **Recommend（推荐）**：对候选内容排序，替换或追加待展示的信息流。
  - **UpdateState（更新状态）**：根据请求或浏览证据写入、修订用户状态。
- **执行流程不是固定流水线。** 控制器可以根据搜索结果继续检索，也可以直接排序、先更新状态，或组合多种动作。推荐展示后的浏览和新请求则成为下一轮判断的证据。方法上的主要贡献是把已有的指令理解、记忆和检索规划能力整合到同一决策过程中，而不是为每一项能力分别提出新算法。

## 3. 实验设计：基准、场景与对比方法

| 公开基准 | 评估任务与规模 |
|---|---|
| **AgentRecBench** | 涵盖经典推荐、兴趣演变和冷启动；评估 300 个任务，每个任务有 20 个候选。 |
| **KuaiRand** | 617 个固定候选排序任务，每个任务有 101 个候选，以留出的长观看条目为目标。 |
| **KuaiRec** | 在冻结的视频目录中，为 1,129 名用户检索并排序内容。 |
| **ClawRec-SimBench** | 评估全部 210 个事件，依据跨平台行为推断下一步需求，先检索再排序。 |
| **MIND** | 在 MIND-small 开发集上，依据新闻点击历史对曝光候选排序。 |

- **自建 Agentic Waterfall Dataset。** 包含来自 25 个来源的 **60,674 张真实内容元数据卡片**，以及由语言模型模拟的 **50 条用户轨迹、300 个预设评估检查点**。轨迹记录打开、点赞、收藏和停留时长等行为，其中有两个专项场景：
  - **行为歧义（102 个检查点）**：10 对用户最初看到相同内容并采取相同行为，随后因目标不同而逐步分化，全程不提供显式请求。
  - **交互修订（152 个检查点）**：20 名用户切换任务，或收紧、放宽要求。比较修订前后的检查点时，固定浏览历史与提供给系统的用户资料，以观察请求变化的影响。
- **对比方法。** 公开基准覆盖同底座通用代理、ClawRec、RecAgent、iAgent、MARS、RecBot、BM25+BGE、TF-IDF 和 NRMS，部分方法未报告全部指标。自建数据集比较 **Waterfall、ClawRec、RecAgent、iAgent、BM25+BGE** 五种系统。
- **共享历史回放。** 每个检查点向各系统提供相同的公开资料和交互历史，收集各自前五条推荐。系统从相同候选池起步，支持主动获取的方法可在同一冻结目录内搜索更大的内容池。公开基准使用 Hit、Precision、nDCG、AUC、MRR 等指标；自建数据集的模型裁判可额外看到模拟用户的私有人设和当前目标，逐条给出 **0–3 分主题相关性**并计算 **DCG@5**，同时对同一排名位置打乱后的匿名卡片进行盲选，以衡量内容对当前目标和约束的满足程度。

## 6. 主要结论与发现

- **公开基准上整体有竞争力，但并非全面领先。** Waterfall 在 KuaiRec 的 P@10 和 nDCG@10 上领先，分别为 **9.30%** 和 **0.1092**；在 ClawRec-SimBench 上以 **0.7790 nDCG@20** 领先。它在 AgentRecBench 略落后于通用代理，在 KuaiRand 的 nDCG@10 上次于 MARS；MIND 的 MRR 和两项 nDCG 最高，但 AUC 低于 NRMS。
- **自建基准整体排名第一。** 相比最强整体基线 ClawRec，Waterfall 的主题 **DCG@5 为 7.86 对 7.53（+4.4%）**，盲选票分为 **419.58 对 361.33（+16.1%）**。摘要中的 **16.1%** 指整体盲选票分的相对提升，不是点击率或真实用户满意度的提升。
- **显式改写请求时优势更明显。** 交互修订子集上的盲选票分比 ClawRec 高 **21.1%**；请求修订后紧接的检查点上，平均 DCG@5 为 **8.52 对 8.10**。在 40 个有明确格式约束的检查点中，Waterfall 有 **39 个**做到前五条全部合规，ClawRec 为 **34 个**。
- **消融结果与两类信号的作用相符。** 行为歧义场景去掉浏览信号后，DCG@5 从 **7.198 降至 4.414**；交互修订场景去掉显式表达后，从 **8.396 降至 6.959**。主动检索也并非每轮都有益：禁用检索的变体赢了 **145** 个配对检查点，完整系统赢了 **137** 个，另有 **17** 个打平；完整系统凭更大的获胜幅度取得 **0.350** 的配对平均优势。

## 7. 优点

- **把“跟随用户意图”变成了可检验的任务。** 相似历史下的目标分化，以及固定历史下的请求修订，分别考察系统能否读懂行为变化和服从明确的新指令。
- **区分了主题相关与任务适用。** 一条内容可以在主题上正确，却不符合用户要求的格式或当前任务。逐条相关性评分、匿名盲选和格式合规检查从不同角度捕捉这种差异。
- **不只报告平均增益。** 论文报告了消融的胜负次数和差距，揭示主动获取可能提高平均质量，却不保证在大多数检查点获胜。论文还声明公开轨迹、目录清单、运行记录与盲评标签，便于复核。

## 8. 不足与局限

- **真实内容不等于真实用户行为。** 用户轨迹和主要评估判断由模型生成，且回放中的后续行为不会随系统实际推荐改变。因此，结果不能证明真实用户更愿意打开推荐、感到更有控制权，或从长期使用中受益。
- **盲评不等于消除模型偏差。** 匿名能隐藏系统身份，但不能消除裁判的内容偏好。推荐代理与裁判使用相同底座，可能共享某些判断倾向；论文未给出人工评审或跨模型裁判的一致性验证。逐排名盲选也无法充分衡量整张列表的多样性、冗余或互补性。
- **组件贡献尚未完全隔离。** 消融和完整系统采用不同的状态延续方式；甚至在没有显式请求的行为歧义场景，移除显式表达的变体也出现降分。因此，不能简单地将所有差距归结为相应组件的独立作用。
- **部署条件仍待验证。** 冻结目录无法充分检验开放环境下的内容时效性与检索可靠性。论文也未系统评估错误记忆的纠正、用户对持久状态的查看与删除、隐私治理，以及在线延迟和成本。这些因素直接关系到“用户控制”能否在真实产品中实现。
