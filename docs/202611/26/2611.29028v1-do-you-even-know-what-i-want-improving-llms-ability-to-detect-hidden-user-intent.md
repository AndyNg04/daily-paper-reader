## 摘要
与传统 AI 智能体一样，大语言模型（LLM）与人类用户之间发生目标错位的常见原因之一，是目标设定不明确。这种情况往往发生在用户对系统模型存在偏差认知，并向系统提供某些信息，导致其行为偏离用户预期，甚至产生不希望出现的副作用。为确保目标一致，一种解决方案是让 LLM 向用户询问其目标。然而，已有研究充分表明，面对用户请求时，LLM 通常会直接给出默认回答，而不是通过提问来澄清用户的真实意图。本文通过调整一种用于解决目标设定不明确问题的新型形式化方法，使其适用于 LLM，以应对上述挑战。随后，我们检验：与未被提示进行提问的模型相比，被提示询问用户真实潜在目标的 LLM 是否更善于识别这些目标。我们在五个标准 IPC 领域中，对四种最先进的 LLM 进行了评估。结果表明，在部分领域中，提问显著提升了模型表现。

## Abstract
As with conventional AI agents, a common source of misalignment between Large Language Models (LLMs) and their human users is misspecified goals. Often, this happens when the human has skewed beliefs about the system's model and provides it with information that causes behavior different from what they expected, with potentially unwanted side effects. To ensure goal alignment, one solution would be for the LLM to ask the human questions about their objectives. However, it has been well-documented that LLMs most often provide default responses to user requests rather than try and ask questions to clarify their true intent. In this paper, we address these challenges by adapting a novel formulation for the objective misspecification problem to work with LLMs. We then test if LLMs that are prompted to ask questions about a user's true underlying objectives are better at identifying them compared to those that do not. We evaluate our method using four state-of-the-art LLMs tested on five standard IPC domains, showing that for some domains, asking questions greatly improved model performance.

# 论文总结：你真的知道我想要什么吗？提升大语言模型检测用户隐含意图的能力

**作者：** Kelsey Sikes、Sarath Sreedharan  
**核心结论：** 当用户因误解智能体的状态或能力而漏说目标时，澄清提问可以帮助大语言模型恢复这些目标，但收益取决于模型、任务和回答质量。提问有时还会让模型把用户没要求的条件误当成目标。

## 1. 核心问题与研究动机

- **用户说出的目标不一定等于真正想要的结果。** 论文关注的不是一般性的措辞歧义，而是用户对智能体持有错误认知，因而以为某些要求不必明说。例如，用户让银行助手“付房租”，默认它会在月底用信用卡支付；助手却立即从支票账户扣款。它完成了字面任务，却违背了用户对时间和支付方式的要求。
- **论文检验两个问题：** 一是没有明确要求时，LLM 会不会主动澄清？二是明确提示模型提问、再把回答交给它，能否提高隐藏目标的识别准确率？
- **研究边界是识别目标，而不是执行任务。** 即使某个目标在智能体当前能力下不可实现，模型仍应识别它。论文不检验后续规划能否实现这些目标，也不直接测量实际副作用是否减少。

## 2. 方法论：从模型差异和用户计划推断目标

- **用 PDDL 表达人与智能体的不同认知。** 规划模型包括初始状态、可执行动作及其前置条件和效果，以及由谓词组成的目标。实验中，人和智能体共用同一个动作领域文件，但初始状态不同。智能体已知目标 \(G_R\) 是用户真实目标 \(G^*\) 的子集；模型要找回缺失部分 \(G^*\setminus G_R\)。
- **用执行结果定义目标错位。** 如果在智能体的真实模型中，存在一条计划能够满足用户明示的目标，却不能满足真实目标 \(G^*\)，那么明示目标就不足以保证对齐。用户给出的预期行动计划是额外线索：真实目标包含在用户预期的终态中，但终态里的事实并不全是用户想要的，计划中的动作也可能只是中间手段。
- **比较两种推断流程：**
  1. **直接识别：** 输入两个问题文件、共享领域文件及用户预期计划，用两种措辞（Prompt 1、2）分别要求模型一次性输出完整目标集合。两个问题文件都只展示智能体已知的目标。
  2. **先提问、再识别：** 先用 Prompt 3 让模型一次生成一批问题，再由掌握真实目标的 DeepSeek 用 Prompt 4 模拟用户作答；最后将回答加入原始输入，由 Prompt 5.1、5.2 分别沿用 Prompt 1、2 的措辞识别目标。这里是**一轮批量澄清**，不是根据回答持续追问，也没有优化提问成本或信息增益。

## 3. 实验设计与 Benchmark

- **Benchmark：** 作者用公开生成器从国际规划竞赛（IPC）的五个领域构造了 **500 个具体化 PDDL 实例**，每个领域 100 个：Blocksworld（积木）、Childsnack（零食配送）、Driverlog（运输）、Rovers（探测车）和 Satellite（卫星）。这是基于标准规划领域构造的合成意图识别任务，而非真实用户对话数据集。
- **实例构造：** 每个真实目标包含 2–6 个谓词。作者随机从智能体目标中删除 1–5 个谓词（不超过原有目标数），并给用户认知中的初始状态增加 2–4 个事实。用 Fast Downward 的 A* 搜索和 Landmark Cut 启发式生成单位动作成本下的最优计划，再用 VAL 验证。保留的用户计划必须在其认知模型中有效、在智能体模型中无效，且比未添加初始事实时的原计划短。
- **对比模型：** 直接识别测试 Gemma、Qwen、Mistral 和 Llama；澄清实验不再测试 Llama，由 Gemma、Qwen、Mistral 提问并识别，DeepSeek 只扮演回答者。最直接的对照是 **Prompt 1 ↔ 5.1** 和 **Prompt 2 ↔ 5.2**，因为每对的最终识别措辞相同。
- **评价指标：** 分别报告全部目标（All）和隐藏目标（MissH）的谓词识别率，以及两者的实例级完全正确率。完全正确要求**既不漏掉真实目标，也不加入多余谓词**。其中，隐藏目标指标更能反映模型是否获得了新信息：仅复述已知目标也能提高 All 的谓词识别率。

## 4. 资源与算力

- 论文报告使用 **NVIDIA H100 GPU**，单实例时限为 **20 分钟**，各模型温度设为 **0**。模型从 Hugging Face 下载后本地运行，或通过 API 调用。
- 这是一项**推理与提示实验**，未进行训练或微调，因此没有训练时长可报告。论文未明确交代 GPU 卡数、总 GPU 小时、实际平均推理耗时或 API 侧算力；20 分钟是超时上限，不是实测耗时。

## 5. 实验数量与证据充分性

- **规模：** 论文有两项主实验。直接识别名义上覆盖 **4 个模型 × 5 个领域 × 2 种提示，共 40 个组合**。澄清实验的结果表报告 **22 个最终识别组合**：Gemma 和 Qwen 各覆盖五个领域，Mistral 仅报告 Blocksworld，各用两种提示。500 个是独立构造的任务实例数，不是成功完成的调用数。
- **较公平之处：** 两项实验复用同一批任务和用户计划；成对提示的最终措辞一致；真实目标由构造过程确定，评分不依赖主观判断。两套措辞也提供了有限的提示敏感性检查。
- **证据仍有限：** 超时和上下文窗口限制使不同模型、领域和提示的完成数量不一致，尤其是 Llama 和 Mistral。表中指标只针对已完成实例，论文未报告统一完成样本上的逐实例配对分析，也未给出置信区间或显著性检验。因此，结果足以说明**某些设置中有明显收益**，但不足以证明普遍有效，或据此公平地给所有模型排序。
- **缺少关键对照：** 没有比较固定澄清问题、可靠且只回答所问内容的模拟用户，或基于规划规则的推断方法。因此难以区分：收益究竟来自问题问得好，还是回答者直接提供了更多目标信息。

## 6. 主要结论与发现

- **未明确要求时，没有模型主动追问。** 在直接识别实验的提示设定下，模型都选择作答；谓词识别率即使较高，也常因漏项或多项而无法精确恢复目标集合。
- **澄清对 Blocksworld 的帮助最明显。** Gemma 的全目标完全正确率从 Prompt 1 的 **13%** 提高到 Prompt 5.1 的 **42%**，隐藏目标完全正确率从 **18%** 提高到 **55%**。另一组同措辞对照中，Gemma 的全目标完全正确率从 Prompt 2 的 **11%** 升至 Prompt 5.2 的 **47%**。
- **澄清也可能降低表现。** 在 Rovers 中，Qwen 的全目标完全正确率从 Prompt 1 的 **52%** 降到 Prompt 5.1 的 **37%**，加入多余谓词的答案比例则从 **5%** 升到 **34%**。作者总体上仍将 Prompt 1 评为略优于 Prompt 5.2，说明“先问再答”没有稳定胜过强一些的直接回答基线。
- **问题数量不是质量指标。** Mistral、Qwen、Gemma 平均分别提出约 **6、4、2** 个问题。多数问题围绕“用户为什么给出这条计划，以及计划是否暗示额外目标”，而非直接询问目标清单。DeepSeek 有时会直接列出真实目标，也有时会引入错误或误导性信息。Satellite 整体较难；作者指出它的已知与真实目标数差距较大，但实验没有单独验证这一因素的因果作用。

## 7. 优点与亮点

- **把一种具体的错位机制变成了可检验问题。** 论文将用户的错误信念、已知目标、真实目标和预期计划分别建模，使失败可以追溯到具体目标，而不只是笼统地归为“模型没理解用户”。
- **同时衡量漏报与误报。** 隐藏目标指标避免把复述已知信息当作推断成功；集合精确匹配和额外谓词统计则揭示了一个重要风险：更多信息可能找回遗漏目标，也可能让模型擅自增加要求。
- **报告了澄清无效甚至有害的情况。** 论文附有提示词、各领域完成数量、问题类型和完整结果表，便于读者检视总体结论是否被个别模型或领域驱动。

## 8. 不足与局限

- **模拟用户不能替代真人。** DeepSeek 预先掌握目标集合，可能不论问题是否精准都直接给出目标，也可能在缺乏完整任务上下文时编造解释。实验因而评估的是整条“提问—模拟回答—识别”流程，不能单独证明提问策略有效。
- **实验条件比实际应用更结构化。** 模型事先拿到显式的用户认知模型和预期计划，并被告知已知目标是真实目标的子集；现实中，这些信息通常不可直接获得。实验也只通过初始状态制造认知差异，没有验证双方对动作能力或规则理解不一致时的表现。
- **样本筛选与运行失败可能带来偏差。** 构造规则只保留特定类型的计划失配；完成样本又可能偏向较短或较容易处理的实例。不同领域还同时改变了输入规模、目标数量和任务语义，不能仅凭领域间比较确定难度来源。
- **尚不足以指导何时应追问。** 论文没有衡量真实用户的交互负担、追问成本或错误执行的后果，也没有验证识别之后能否安全完成任务。更有说服力的后续评估应在同一批实例上做配对比较，控制回答质量，并用真人交互检验澄清收益是否值得其成本。
