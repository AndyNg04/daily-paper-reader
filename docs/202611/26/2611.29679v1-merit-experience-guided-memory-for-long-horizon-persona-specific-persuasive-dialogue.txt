# MERIT: Experience-Guided Memory for Long-Horizon Persona-Specific Persuasive Dialogue 

Rohan Kirti, Akash Ghosh, Pratik Amrit, Aryan Vats, Niladri Ghosh, and Sriparna Saha 

Abstract —Effective long-horizon persuasion in recurring goal-oriented settings requires more than factual memory: it must track how a user’s trust, negotiation behavior, and strategic receptiveness evolve across interactions. Existing persuasive di-alogue systems are largely single-session, static, and unimodal, while cross-session memory systems, though temporally aware, retain only factual content and overlook persuasion-specific dynamics. We propose MERIT (Memory-augmented Experience-Rationale for Iterative Temporal persuasion), which pairs agraph-based memory of four persuasion-specific memory types with a per-persona experience rationale library that records which strategies succeed for each user and why. Together they enable adaptive persuasion through prompt composition alone, with no parameter updates. To support this setting, we introduce 

PERSIST (PERSona-driven In Surance Interactions over Time), a dataset of 60 curated personas spanning 10+ years of motor insur-ance renewal interactions, with probabilistic life events that shift negotiation behavior and receptiveness across sessions, verified through strict human-in-the-loop annotation. MERIT surpasses memory and experience-based baselines on every metric across two policy backbones, reaching persuasive-appeal scores of 4.10 and 4.74 (out of 5). 

Index Terms —Long-horizon persuasion, graph-based memory, experience rationale library, multi-turn dialogue. 

I. I NTRODUCTION 

Long-term conversational interactions are increasingly com-mon as Large Language Models (LLMs) and Multimodal Language Models (MLLMs) are deployed in applications requiring sustained user engagement [1]–[4]. In settings such as insurance sales, healthcare users return across sessions spanning months or years, requiring agents to remember prior conversations and adapt to evolving user behavior, negotiation patterns, and trust dynamics. Users also share images to ground their concerns in visual contexts that cannot be fully captured through language alone [5], [6]. These scenarios require agents to maintain persistent, persona-specific under-standing across time and modalities rather than treating each interaction independently. Recent advances in computational persuasion show that LLMs and MLLMs can generate personalized persuasive strategies across domains such as sales, negotiation, recom-mendation, and adversarial dialogue [7]–[9]. Prior work has also explored persona-aware and context-adaptive persuasive systems for personalized conversational agents [10], [11].

However, existing persuasive dialogue systems primarily operate in isolated single-session settings or unimodal se-tups, relying on static persona representations that do not evolve through continued interaction [12]–[16]. Although memory-augmented architectures preserve conversational con-text across sessions, they focus primarily on factual retention and consistency rather than persuasion dynamics, such as strategy effectiveness, negotiation behavior, and trust evolution [17]–[19]. Crucially, no existing framework captures accu-mulated strategic experience, that is, structured knowledge of which persuasive strategies proved effective for a specific user over time and why, leaving agents unable to transfer lessons from past persuasive successes and failures into future interactions. 

Present Work: To address this gap, a natural approach to long-horizon persuasive dialogue is to equip the models with external memory of prior interactions through retrieved session summaries, user profiles, or past negotiation outcomes. While such memory helps recall recurring objections, prior decisions, and evolving conversational context, remembering past interactions is fundamentally different from knowing how to persuade effectively in the current interaction. This calls for two complementary capabilities: a memory structure that preserves persuasion-specific dynamics across years, and an explicit mechanism for accumulating strategic experience like what works, for whom, and why, across repeated interactions with the same user. 

To support this setting, we introduce PERSIST , a mul-timodal persona-driven insurance dialogue dataset capturing longitudinal persuasive interactions across 60 personas over multiple years of recurring conversations. Building upon this, we propose MERIT , a memory-augmented framework for iterative temporal persuasion that decomposes long-horizon persuasive adaptation into two complementary components. 

First, a graph-based memory architecture organizes interac-tion history into four specialized representations: episodic session context, strategy effectiveness, latent persuasion states, and negotiation concession patterns. These representations are connected through a temporal graph that supports semantically targeted retrieval. Second, MERIT introduces persona-specific experience rationales constructed through referee-evaluated response comparisons, capturing not only which strategies succeed for a given user but also why they are effective. These accumulated rationales form a per-persona experience library that enables adaptive strategic persuasion through prompt composition rather than parameter updates.

A. Long-Horizon Memory and Experience-Based Reasoning 

Memory-augmented architectures for LLM agents have evolved from flat retrieval to structured representations. [17] introduced forgetting-curve-based memory management, [18] proposed recursive summarization for long-term dialogue con-sistency, and [20] applied OS-inspired hierarchical paging. More recent systems pursue richer structure: [21] abstracts memory as an entity-centric graph layer, [22] builds self-evolving knowledge networks via Zettelkasten-inspired link-ing, [19] models heterogeneous user history with persona-aware updates, [23] refines retrieval online through topic-based memory organization and citation-driven reranking, [24] organizes history into different memories with question-conditioned retrieval, and [25] introduces evolving conditional memory for personalized LLM assistants. A complementary line of work addresses strategic reasoning through experience-based learning without gradient updates. [26] showed that LLMs can improve outputs through iterative self-feedback within a single episode, while [27] extended this to cross-episode verbal reinforcement. [28] generalized the paradigm by extracting reusable insights from success-failure trajectory pairs, and [29] derived synthetic strategy memories through offline self-play for proactive dialogue. 

Research Gap. Collectively, these works leaves open how persuasion-specific memory and persona-specific strategy adaptation can be modeled across longitudinal interactions in multimodal long horizon setup. B. Multi-Session Dialogue and Persuasion

A. PERSIST Dataset 

Overview. We introduce PERSIST, a multimodal persona-driven dataset of longitudinal persuasive dialogues in the motor insurance domain. Each persona has at least one in-surance renewal conversation per year over a span of 10+ years, forming a connected interaction history rather than a set of independent dialogues. Before selected sessions, the persona may undergo a probabilistic life event, such as an accident, an income change, or a major purchase, that af-fects its negotiation-relevant attributes. The life-event sampling process and its effects on persona attributes are described in Appendix A . Each session is also grounded in a vehicle image, which is processed by the Gemma 3 4B model to anchor the conversation in a concrete multimodal context. b) Dialogue Generation : Each conversation is gener-ated turn by turn by LLMs through a multi-agent pipeline coordinated by a dialogue orchestrator, with human-authored turns incorporated for selected scenarios and human oversight applied during dataset validation. When a vehicle image is pro-vided, Gemma 3 4B IT extracts a structured textual description that is appended to the conversation context. Given the current user utterance and prior context, the orchestrator activates relevant expert modules: Sentiment, Motive, Keyterm, and Engagement Experts, which analyze the user’s emotional state, communicative intent, salient insurance terms, and persuasion-related signals, respectively. Each expert returns an analysis with an explicit rationale and may consult a shared motor-insurance knowledge base containing insurer information, pre-mium pricing, depreciation schedules, coverage details, and policy terms. The orchestrator aggregates the expert outputs and passes them to the Persuasion Synthesizer , which selects a persuasion strategy and generates the agent response. Dialogue generation uses eight user intents and six agent persuasion strategies. The user intents capture communica-tive goals ranging from session onset, coverage inquiry, and quote solicitation to concern disclosure, clarification request, premium negotiation, renewal commitment, and offer decline. The six agent persuasion strategies are adopted from the persuasive sales-dialogue taxonomy of [10]: Default , which provides neutral information without an explicit persuasive appeal; Credibility , emphasizing insurer reliability; Emotional ,addressing the user’s feelings and concerns; Logical , using facts and reasoning; Personal , drawing on recommendations and social proof; and Persona-Adaptive , tailoring the appeal to the user’s attributes and priorities. At each turn, the agent strategy is selected before the user’s next intent is chosen based on the agent’s latest response and prior conversation context. Strategy selection is governed by a per-persona complete directed graph over the six persuasion strategies, including self-loops. Its weight matrix Wp encodes the propensity to select strategy s′ after strategy s, with Wp(s, s ′) denoting the corresponding transition weight. The matrix is initialized from a shared prior and updated over the persona’s training-set conversations. At turn t, the Spectrum mechanism adapts these long-term transition preferences to the current context. Con-ditioned on the user’s current intent, inferred sentiment, and persona profile, Gemini 2.5 Pro [48] assigns each candidate strategy s′ ∈ S a positive context-fit multiplier mt(s′), where values above, below, or near 1 indicate a good, poor, or neutral fit, respectively. To maintain longitudinal consistency, annotators receive the persona profile, summaries of previous sessions, and relevant insurance and policy history. Original human-scripted turns are retained to verify that their intent and content are preserved during integration. Provenance metadata distinguishes human-scripted, model-generated, and human-edited turns. 

Validation. During dataset construction, each generated ses-sion is reviewed by one of three postgraduate annotators. Ad-ditionally, 96 sessions (15% of the dataset) are independently reviewed by all three annotators, with disagreements resolved by majority vote. Reviewers check life-event plausibility, chronological consistency, and consistency between previous interactions and subsequent insurance decisions, marking each criterion as pass or fail. For sessions containing human-authored turns, they also verify that the original intent and content are preserved. Two domain experts examine insurance-specific correctness, including policy-related statements and coverage descriptions. Sessions that fail these checks are corrected or regenerated using reviewer feedback, with a maxi-mum of three generation attempts, including the initial attempt. Sessions that still fail after three attempts are discarded. 

Independent Human Evaluation of Dialogue Quality. To further assess dialogue quality, 15% of the generated dialogues are independently evaluated, covering different personas, time periods, and negotiation scenarios. Annotators assess per-sona consistency, temporal consistency, intent alignment, and persuasion-strategy appropriateness using a five-point Likert scale (1 = very poor, 2 = poor, 3 = adequate, 4 = good, and 5 = excellent). 2) Experience Rationale : The memory captures prior in-teractions and persuasion dynamics, but not how the agent should act in future interactions. To address this, MERIT constructs a per-persona experience rationale library Ep offline using the earliest 80% of each persona’s conversations. For each turn in this subset, the frozen policy model generates three candidate responses, which a referee model (GPT-5 [51]) scores for persuasive quality and uses to produce a rationale explaining the strongest response’s effectiveness. The selected response and its rationale are stored in Ep along with relevant metadata. During inference, MERIT retrieves the Top-

K (K = 8 ) rationales most semantically similar to the current query and incorporates them into the prompt alongside the retrieved memory and conversation history. This enables the policy model to reuse persona-specific persuasive experience without parameter updates. IV. E XPERIMENTS 

We evaluate PERSIST and MERIT through experiments designed to answer four research questions: RQ1) Does MERIT generate more effective persuasive responses than memory and experience-based baselines? RQ2) Does MERIT preserve long-horizon persuasion dynamics across multi-year interactions? RQ3) Does the per-persona experience rationale library improve persuasion beyond memory retrieval alone? 

RQ4) Are MERIT’s gains robust across policy backbones differing in family and scale? 

A. Experimental Setup 

Implementation Details. All experiments are conducted on a single NVIDIA A100 80GB GPU. Local models (the policy backbone and the visual extractor) are run on-device, while the GLM-5.1 [53] backbone is accessed through the API. The policy model generates candidate rollouts per turn under stochastic decoding with temperature 0.9, top-p 0.95 , and a 300-token generation cap; the sampling temperature is incre-mented by 0.05 per rollout index to encourage strategic and framing diversity across candidates. Referee model (GPT-5) is accessed through the OpenAI API, queried with temperature 

0.2 for deterministic scoring and an 800-token output cap, with up to three retries under exponential backoff. 

Baselines. We compare MERIT against memory-augmented dialogue baselines (Memory Bank [17], ConditionMem [25], Recursum [18], and Mem-Pal [19] and experience-based rea-soning methods (Reflexion [27] and ExpeL [28]), along with simple context baselines including a vanilla LLM, a sliding-window model, conversation memory, and session and turn-level retrieval. All methods are evaluated under identical conditions. 

Evaluation. We evaluate generated responses using four reference-based metrics: BLEU-2 [54], which measures bi-gram precision; ROUGE-1 [55], which measures unigram re-call; METEOR [56], which captures lexical alignment through exact, stem, and synonym matches; and BERTScore [57], which measures semantic similarity using contextual em-beddings. Higher scores indicate greater reference similarity, although these metrics do not directly measure persuasive effectiveness. We further use Gemini 2.5 Pro [48] as an LLM judge at temperature 0.2 to assign 1–5 scores for Persuasive Appeal Score (PAS), measuring how effectively a response advances the persuasive goal, and Context Alignment Score (CAS), measuring how well it addresses the user’s request while respecting implicit needs, persona constraints, and negotiation boundaries. Finally, three annotators conduct human evaluation on six parameters. Goal Advancement (GA) measures progress toward the purchase goal, and Long-Term Consistency (LTC) assesses consistency with prior interac-tions; both are evaluated pairwise against the strongest base-lines as Win, Tie, or Loss, with the final label decided by majority vote. Strategic Grounding (SG) assesses the use of identifiable persuasion strategies, Persona Consistency (PC) measures alignment with the persona profile, Engagement (Eng) evaluates conversational involvement, and Fluency (Flu) assesses grammaticality, coherence, and naturalness. The latter four parameters are rated on a 1–5 Likert scale and reported as the mean over annotators and samples, with higher scores indicating better quality. V. R ESULTS

RQ3: The experience library matters as much as memory. 

The experience rationale library is as essential as memory it-self. Removing it (w/o ExpLib) reduces the judged score from 4.100 to 2.559 on Qwen, a drop comparable to removing any single memory component (2.540–2.572) (Table IV). Further,

RQ4: MERIT’s gains hold across model scales. MERIT 

achieves the highest scores across all metrics on both Qwen-3B and GLM-5.1 (Table III). Its absolute scores also improve with the stronger backbone, with PAS increasing from 4.100 to 4.739, BLEU-2 from 0.130 to 0.148, BERTScore from 0.612 to 0.638, and ROUGE-1 from 0.392 to 0.433. These results show that MERIT’s gains hold across different model families and scales, while a stronger policy further improves performance. Thus, MERIT remains effective even with a smaller policy model. VI. A BLATION STUDY 

Impact of Memory Components. Removing any memory type degrades MERIT to near-baseline performance. The session summary is most critical, with its removal lowering the judge score to 2.244 and BERTScore to 0.548 as the model loses the episodic record of each prior conversation. Removing strategy-outcome, latent, or concession memory produces comparable drops (2.572, 2.559, and 2.540). The closeness of these values shows that no single memory type dominates: strategy effectiveness, latent receptiveness, and negotiation behavior each capture a distinct, non-substitutable facet of persuasion that the others cannot compensate for. 

Impact of the Experience Rationale Library. Removing the experience rationale library lowers the judge score to 2.559, a drop comparable to removing any single memory type: accumulated strategic experience is as essential as memory itself. MERIT also outperforms the experience-based base-lines Reflexion (2.828) and ExpeL (2.794), confirming that its per-persona rationale mechanism captures strategic knowledge more effectively than episode-level reflection. Crucially, these drops are uniform: no component can be removed without col-lapsing performance to near-baseline, showing that MERIT’s 

memory and rationales are strongly interdependent. VII. C ONCLUSION 

We introduced PERSIST , a multimodal persona-driven dataset of longitudinal persuasive dialogues, capturing re-curring agent-user interactions for 60 personas over 10+ years, with strict human-in-the-loop verification. We proposed 

MERIT , which combines a graph-based memory of four persuasion-specific memory types with a per-persona expe-rience rationale library capturing which strategies work for a user and why, and adapts a frozen policy model through prompt composition alone. Across automatic and human eval-uations, MERIT consistently outperforms memory-augmented and experience-based baselines, and ablations show its com-ponents are strongly interdependent. Together, PERSIST and MERIT establish a foundation for studying persuasion as a long-horizon, persona-specific process. 9
