Abstract 

Mass spectrometry (MS) -based proteomics is essential for comprehensive protein characterization, yet it relies 

on  multistep computational workflows that typically demand tedious manual parameter tuning and complex 

software integration.  Here, we present MSRyzen, an  agent -driven framework that provides automated 

parameter optimization and extensible tool integration across bottom -up and top -down proteomics workflows .

MSRyzen translates natural -language prompts into directed acyclic workflow graphs, optimizes analytical 

parameters guided by quantitative metrics and user -defined objectives, and incorporates new third -party 

software through standardized callable interfaces.  Across four public top -down datasets, automated parameter 

optimization increased proteoform identifications by 3.6% to 15.8% compared to default settings at a 1% false 

discovery rate. To ensure transparent data interpretation, an interactive visualization interface coordinates 

identification metrics with peak -level spectral evidence and sequence coverage. Integrating adaptive tuning 

with multi -tiered spectral inspection, MSRyzen delivers an end -to -end, fully automated framework, 

dramatically reducing the operational barrier to modern mass spectrometry data analysis. 

Introduction 

Driven by continuous advancements in high -resolution mass spectrometry and analytical methodologies , mass 

spectrometry (MS) -based proteomics has become indispensable for deciphering complex biological systems 

and disease mechanisms  [1] [2] [3] . To achieve comprehensive structural and functional profiling, research has 

primarily evolved along two complementary strategies: bottom -up peptide profiling and top -down intact 

proteoform characterization  [4] [5] [6] [7] . Despite their distinct analytical strengths, transforming raw spectral 

data into accurate and efficient identifications remains a persistent rate -limiting bottleneck for both 

approaches [8] [9] .2

Standard MS data interpretation involves a series of interdependent steps, including spectral deconvolution 

[10] [11] [12] , feature detection  [13] [14] , database searching  [15] [16] , post -translational modification (PTM) 

localization  [17] [18] , rescoring  [19] [20] , and false discovery rate (FDR) control  [21] . While specialized 

algorithms have been developed for individual steps, they lack end -to -end processing capabilities. To address 

these limitations, researchers have developed integrated software platforms such as FragPipe  [15] ,

AlphaPeptDeep  [22]  and MaxQuant  [13]  for bottom -up proteomics, as well as MASH Native  [23]  and TDEase 

[24]  for top -down proteomics.  Nevertheless, these platforms largely operate as isolated ecosystems . E xecuting 

end -to -end workflows still demands manual integration of disparate command -line tools and empirical tuning 

of interdependent parameters.  In addition,  suboptimal parameter configurations often introduce variability in 

sensitivity and FDR control, making analytical outcomes highly operator -dependent and hindering high -

throughput implementation. 

To bridge these gaps, we present MSRy ze n,  an agent -driven framework designed for automated parameter 

optimization and extensible software orchestration across bottom -up and top -down proteomics. MSRyzen 

compiles natural -language instructions into executable workflow graphs and utilizes intermediate identification 

statistics alongside quality metrics to drive iterative parameter refinement. Standardized adapter interfaces 

enable dynamic registration of third -party analytical tools based on structured metadata and software 

documentation. Furthermore, an integrated web interface couples analytical outputs directly to primary 

sequence coverage, chromatographic traces, and annotated fragment -ion spectra for visual validation. We 

demonstrate the utility of MSRyzen through automated top -down parameter optimization, harmonized cross -

engine comparison of bottom -up results across FragPipe, MaxQuant, and Comet  [25] , and joint profiling 

linking bottom -up peptide discovery with intact -MS1 screening in a cardiomyocyte maturation study. By 

combining autonomous parameter optimization, cross -paradigm bottom -up and top -down integration, and 

highly extensible tool orchestration, MSRyzen bridges complex multi -software workflows with transparent, 

inspectable spectral evidence in a single cohesive environment. 

Experimental Section 

Overall System Architectur e. 

MSRyzen integrates an agent -driven workflow engine, an execution runtime, and a web visualization platform. 

Upon receiving natural -language prompts, MS datasets, and a FASTA database, the system constructs a shared 

task state and compiles an execution graph structured as a directed acyclic graph (DAG). Within this DAG, 

nodes represent discrete analytical operations and their associated parameters, while edges encode data 

dependencies between tasks.  Following execution, analytical results, runtime status, and quality -control 

metrics are fed back to the agent, facilitating automated parameter refinement and downstream analyses 

(Figure 1 , S1 ).

Agent -based Workflow  Implementation .

The  agent workflow  was implemented using LangGraph, with model access managed through a LiteLLM 

router supporting OpenAI -compatible endpoints.  A centralized task -state object maintains the global execution 

context, including DAG topology, tool parameters, runtime status, file paths, error logs, and quality -control 

metrics. Prior to dispatch, candidate workflows undergo static validation to detect circular dependencies and 

ensure analytical tool compatibility, followed by user confirmation. An asynchronous scheduler then resolves 

execution order and maps runnable nodes to corresponding command -line processes.For top -down proteomics, 

the framework integrates  MSConvert  [28]  followed by TopFD/FLASHDeconv  [11] [29]  and TopPIC  [16] , as 

well as the PbfGen –ProMex –MSPathFinderT  pipeline  [26] . For bottom -up workflows, core FragPipe modules 

(including MSFragger [15], MSBooster [20], and IonQuant  [30] ) are encapsulated as modular, schedulable 

operators that assemble into customized DAG pipelines. Finally, dedicated parsers ingest process outputs back 

into the task state, while node -level checkpointing enables fault recovery and selective re -execution without 

recomputing upstream tasks. 

Automatic Parameter Optimization Implementation. 3

Parameter optimization is abstracted into an automated feedback loop governed by user -defined quantitative 

objectives, defaulting to the maximization of confident identification counts under stringent false discovery 

rate and quality thresholds. Tool -output parsers convert raw results into structured performance records,  like 

the number of proteoforms identified at 1% FDR by TopPIC and an inventory of unexplained mass shifts. 

Guided by these diagnostic profiles, the agent iteratively refines tool configurations to optimize search 

sensitivity. To maintain high computational efficiency during parameter benchmarking, the framework 

selectively reevaluates only the affected downstream subgraphs within the directed acyclic graph.  Modifying a 

search parameter, for instance, restricts re -execution solely to the  TopPIC search and subsequent downstream 

steps while reusing cached TopFD deconvolution outputs, avoiding redundant upstream computation.  Each 

iteration logs parameters, artifact paths, and resulting metrics in the shared state. Candidate configurations are 

ranked against the selected objective function, and the highest -performing valid set is retained. The tuning loop 

halts when convergence criteria or predefined iteration limits are met. 

Extensible Software Integration .

Analytical tools are encapsulated within callable interfaces specifying their operational functions, I/O schemas, 

and parameters. New tools are registered dynamically by the agent using CLI help outputs or API 

documentation paired with a structured definition file (tool.md). Tool -specific wrappers map workflow 

configurations to executable commands and register generated artifacts for downstream DAG nodes, enabling 

seamless integration into the scheduler without altering the underlying graph representation. 

Visualization System  Implementation. 

To support versatile spectral inspection, the visualization platform accommodates diverse mass spectrometry 

workflows across bottom -up and top -down regimes, encompassing data -dependent acquisition (DDA), data -

independent acquisition (DIA), and standalone raw or mzML files. The viewer directly parses outputs from 

varied processing pipelines, including DIA -NN  and  MaxQuant, mapping identification records to primary 

sequence coverage, precursor isotope envelopes, and annotated tandem spectra. For nonstandard analytical 

outputs, an underlying agent autonomously interprets data schemas, resolves ingestion errors, and registers 

verified parsing strategies for automated reuse. To ensure responsive rendering across large -scale mass 

spectrometry datasets, the backend converts raw spectral arrays and analysis results into an  an indexed binary 

representation containing retention times, m/z values, intensities, chromatographic traces, and spectrum 

matches . PostgreSQL and SQLAlchemy manage metadata and relationships among datasets, proteins, 

proteoforms, peptides, and spectra. Spectral arrays are stored outside the relational database and retrieved 

through the spectral indexes. REST endpoints provide access to metadata, extracted -ion chromatograms, total 

ion chromatograms, and MS1/MS2 spectra. The frontend connects identification records to sequence 

annotations, precursor isotope envelopes, matched fragment ions, and mass -error plots. The indexed format 

and its data structures are described in the  Fig ure  S2.

Datasets and Data Analysis. 

Four public top -down datasets (PXD019247  [31] , PXD026123  [32] , PXD046651  [33] , and PXD029703  [34] )

were used to compare default and optimized configurations at  1% FDR  thresholds.  Bottom -up data from 

PXD060431  [35]  were analyzed in parallel using FragPipe, MaxQuant, and Comet, with outputs compared 

through protein -level set intersections and differential -abundance summaries.  Cardiomyocyte maturation data 

from MSV000082985  [36]  were analyzed as distinct bottom -up and intact -MS1 sample sets. 

Result and Discussion 

Autonomous Parameter Optimization in Top -Down Proteomics 

Top -down proteomics searches typically require sample -specific and experiment -specific parameter 

adjustments, such as mass tolerances and signal -to -noise thresholds. To eliminate this bottleneck, MSRyzen 

performs autonomous parameter optimization and space exploration by iteratively proposing candidate 4

configurations and evaluating against spectral identification performance (Figure 2a). We  benchmarked this 

optimization capability across four top -down proteomics datasets. Relative to default search parameters, 

MSRyzen achieved a 3.6% to 15.8% increase in identified proteoforms across all cohorts (Figure 2b) . Through 

the sequential optimization trajectory (Figure 2c), the agent drove proteoform recoveries from 340 to 518 by 

systematically calibrating mass tolerances, curbing PTM search penalties, and fine -tuning deconvolution 

cutoffs (MS1 S/N 1.5 and EnvCNN 0.2) to capture genuine low -abundance isotopic envelopes without 

violating the 1% false discovery rate threshold. In an E. coli case study (ColF18_Exp22_02, PXD019247), the 

optimized parameters identified 955 proteoforms and 260 proteins, compared to 672 proteoforms and 238 

proteins under default settings, with 520 proteoforms and 227 proteins shared between configurations (Figure 

2d). Spectral evidence inspection, including fragment -ion assignments and residual mass -error distributions, 

verified high -confidence identifications for both shared and configuration -specific proteoforms (Figure 2f). 

These results demonstrate that autonomous parameter exploration markedly improves proteoform recovery 

while maintaining stringent spectral reliability. 

Automated Software Integration and Multi -Tool Proteomic Analysis. 

To establish a future -ready architecture capable of seamlessly assimilating newly emerging or previously 

unencountered computational tools, we evaluated the open -ended integration framework by executing an end -

to -end analysis of dataset PXD060431 across FragPipe alongside dynamically onboarded MaxQuant and 

Comet engines.  To evaluate the onboarding of arbitrary third -party software, MSRyzen incorporated 

MaxQuant and Comet as entirely unseen components, automatically generating callable interfaces directly 

from raw help documentation and structured tool metadata without hardcoded wrappers (Figure 3a).  The three 

outputs were integrated for protein -level comparison and downstream differential -abundance analysis. 

Together, they identified 2,284 proteins, including 1,474 shared across all three workflows, revealing a 

common identification set alongside software -specific detections (Figure 3b). 

The differential -abundance results were then s ummarized using mean log₂ fold changes and Fisher -combined 

p-values, while retaining whether each protein was significant in one, two, or all three analyses (Figure 3c). 

This allowed candidates to be assessed according to both their abundance changes and the consistency of 

statistical significance across software outputs. ACTC1, for example, was significant in all three analyses, with 

a Fisher -combined  p-value of 4.8 × 10⁻¹¹. Crucially, these harmonized outputs are directly compatible with 

downstream bioinformatics skills native to the agent, facilitating automated pathway enrichment and functional 

annotation without manual data conversion (Figure 3d). 

Beyond statistical prioritization,  MSRyzen  coordinates an automated dual -agent visualization framework to 

generate inspectable evidence views without manual intervention (Figure 3e). For ACTC1, the visualization 

agent autonomously synthesized a multi -tiered evidence profile, integrating reconciled sequence coverage 

across FragPipe, MaxQuant, and Comet alongside the extracted ion chromatogram and annotated MS/MS 

fragmentation spectrum of its representative doubly charged peptide AGFAGDDAPR (Figure 3f). This case 

illustrates how MSRyzen establishes a complete, closed -loop workflow connecting multi -tool identification, 

comparative bioinformatics, and autonomous spectral -level verification. 

Complementary Top -Down and Bottom -Up Analysis of Cardiomyocyte Maturation 

Integrating bottom -up (BU) and top -down (TD) proteomics provides complementary resolution across global 

protein abundance and intact proteoform diversity. However, cross -platform joint analysis has traditionally 

relied on laborious, manual cross -referencing between disparate workflows. To overcome this limitation, we 

used MSRyzen to orchestrate an automated cross -modality pipeline  on the public human pluripotent stem cell 

(MassIVE accession MSV000082985). 

At the global bottom -up level, analysis revealed extensive protein -group overlap between Day 30 and Day 59, 

with 2,916 shared protein groups (Figure 4a). Differential expression profiling identified 71 upregulated and 

83 downregulated protein groups at Day 59 under nominal p -value and fold -change thresholds (Figure 4b). 5

Cross -referencing these candidates against established cardiac maturation markers (Table  S1, 2 ) prioritized 11 

key biomarkers for downstream targeted proteoform validation in the corresponding top -down intact -MS1 data. 

Among these candidates, three biomarkers were robustly detected at the intact -protein level, with MLC2v 

exhibiting significant differential abundance (p = 6.8e -05) (Figure 4c,  d). In -depth proteoform profiling further 

resolved distinct isoform and post -translational modification (PTM) dynamics, notably between atrial and 

ventricular regulatory light chains (MLC2a and MLC2v), as well as monophosphorylated MLC2v (+79.966 

Da).  During maturation from Day 31 to Day 60, total MLC2v signals increased whereas MLC2a signals 

decreased. Concurrently, the monophosphorylated MLC2v proteoform was sharply depleted and became 

virtually undetectable at Day 60 with a trend corroborated by representative isotopic MS1 spectral inspections 

(Figure 4e). 

Beyond targeted tracking, MSRyzen conducted an agent -driven open proteoform search, which  recovered the 

+248 Da  mass shift on  slow skeletal troponin I (ssTnI/TNNI1)  originally documented in the reference study .

By automatically querying the Unimod database, the agent matched the measured intact mass shift to a 

putative combinatorial Hex + Malonyl modification, with a mass deviation of only 0.0288 Da  (all candidate 

annotations are detailed in  Table  S3).  Together, these results demonstrate how MSRyzen seamlessly unifies 

high -throughput bottom -up candidate discovery, targeted top -down proteoform validation, and agent -driven 

open PTM characterization. 

Evidence -Centric Spectral Visualization .

To verify that the additional identifications obtained via parameter optimization were underpinned by robust 

spectral evidence, we investigated a proteoform of 50S ribosomal protein L33 (RL33_SALTY) uniquely 

resolved in the optimized workflow. The visualization interface opens with a global summary of identification 

metrics and confidence thresholds (Fig ure  S3a), followed by a ranked table of identified proteoforms (Fig ure 

S3b). The selected proteoform was supported by 14 proteoform -spectrum matches (PrSMs) with a top E -value 

of 1.92 × 10−17 (Fig ure  S3c), offering multiple orthogonal observations for spectral validation. 

For individual PrSMs, the module coordinates primary sequence coverage with matched precursor and MS2 

spectral profiles. The representative PrSM highlighted in Fig ure  S3d exhibits a precursor m/z of 626.0609 (z = 

10+), corresponding to a calculated intact proteoform mass of 6250.5765 Da across the 55 -residue sequence 

and an N -terminal mass shift of  -117.0433 Da. An interactive sequence map correlates detected fragment ions 

with their respective backbone cleavage sites, while synchronized MS1 and tandem mass spectra permit direct 

inspection of the precursor isotopic envelope alongside assigned fragment ions. 

Spectral annotations depict the distribution and sequence coverage of assigned N - and C -terminal fragment 

ions across the spectrum (Fig ure  S3e). At single -peak resolution, an integrated summary table delineates the 

observed m/z, relative intensity, charge state, sequence coordinate, and mass error for each annotation (Fig ure 

S3f). By providing multi -tiered, inspectable spectral evidence, the visualization module confirms that gains in 

identification yield stem from authentic, high -quality fragmentation events rather than relaxed statistical 

thresholds. 

Conclusions 

In this work, we presented MSRyzen, an autonomous agentic framework that bridges high -level analytical 

intent with reliable computational execution across bottom -up and top -down mass spectrometry -based 

proteomics.  MSRyzen unifies automated parameter optimization, extensible software orchestration, and 

spectral visualization into a modular computational architecture for proteomics. Across several representative 

scenarios, we demonstrated the progressive capabilities of the agent at distinct analytical levels. In  top -down 

workflows, automated parameter optimization significantly enhanced proteoform recovery across diverse 

benchmarks while maintaining strict statistical cutoffs. In bottom -up analyses, the dynamic registration of 

external search engines, such as MaxQuant and Comet, supported direct, multi -engine comparative analysis 

without altering core workflow representations. The cardiomyocyte maturation study exemplified how global 

bottom -up discovery can inform targeted intact -MS1 profiling, providing candidate proteoform assignments 

for subsequent structural characterization. By bridging agent -based workflow planning with inspectable, peak -6

> level evidence, MSRyzen minimizes the barrier to fine -tuning and expanding established proteomics tools,
> offering a scalable foundation for automated mass spectrometry data processing.
