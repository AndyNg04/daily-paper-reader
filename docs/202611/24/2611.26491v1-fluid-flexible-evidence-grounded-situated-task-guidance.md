## 摘要
实时任务指导本质上具有灵活性：智能体引导用户完成任务时，可能有多种恰当的回应方式和时机，有时最好的做法是保持沉默。现有基准往往忽视了这种灵活性，将合成对话视为“说什么”以及“何时说”的固定目标。我们提出 FLUID（灵活、以证据为依据的情境化任务指导），这是一个用于建模、评估并实现多模态任务指导中灵活交互的统一框架。FLUID 利用 WTaG 和 HoloAssist 中自然发生的人际指导数据，将干预与其支持证据、必要性及时间灵活性关联起来，并以此表示来评估灵活指导和构建实时任务指导智能体。在所评估的系统中，我们的智能体在回应正确性、干预精准度、指导时机和回应延迟方面实现了最强的综合平衡，但在避免语音重叠方面仍有改进空间。总体而言，FLUID 推动情境化任务指导超越僵化的参考答案匹配，迈向更自然、适应性更强的人机交互。项目主页：https://fluid-guidance.github.io。

## Abstract
Real-time task guidance is inherently flexible: when an agent guides a user through a task, multiple responses and timings can be appropriate, and sometimes the best action is to remain silent. Existing benchmarks often miss this flexibility by treating synthesized dialogues as fixed targets for what to say and when to say it. We introduce FLUID (Flexible, Evidence-Grounded Situated Task Guidance), a unified framework for modeling, evaluating, and enabling flexible interaction in multimodal task guidance. Using naturally occurring human-human guidance from WTaG and HoloAssist, FLUID grounds interventions in their supporting evidence, necessity, and timing flexibility, and uses this representation both to evaluate flexible guidance and to build a real-time agent for task guidance. Our agent achieves the strongest overall balance of response correctness, intervention precision, timely guidance, and response latency among evaluated systems, while still leaving room for improvement in avoiding speech overlap. Together, FLUID moves situated task guidance beyond rigid reference matching toward more natural and adaptive human-AI interaction. Project page: https://fluid-guidance.github.io.

## 1. 核心问题与研究动机

- **实时任务指导不仅要判断“说什么”，还要判断“为什么说、是否该说、什么时候说”。** 例如，用户拿错工具时，助手需要在错误造成后果前提醒；用户正在正确操作时，一句肯定和保持沉默都可能合适；用户主动提问时，回答内容即使正确，抢在用户说完之前也可能造成打断。
- **传统参考匹配难以区分这些情况。** 如果把人类示范或合成对话中的一句话及其时间戳当作唯一标准，就可能误罚合理的替代表述、证据充分时的提前提示，以及省略可选反馈的系统；也可能给恰好落在固定时间窗内、却打断用户的话语计分。
- **FLUID 的主张是：人类示范用于识别指导需求，而不是规定唯一的台词和开口时刻。** 论文将这一思想落实为三部分：描述干预依据的 **FLUID-Modeling**、衡量内容与时机的 **FLUID-Evaluation**，以及据此决定是否开口的 **FLUID-Agent**。

## 2. 方法论：从证据标注到实时决策

### 2.1 FLUID-Modeling：把每次干预关联到证据

论文对自然发生的人际指导建立四层标注：

1. **话语功能**：用户话语分为 11 类，指导者话语分为 13 类，用于区分提问、确认、任务自述、指令、纠错、附和等行为。
2. **动作与状态**：记录用户动作、停滞、搜寻、视野丢失等事件及其区间，并判断动作是否偏离要求、是否推进或完成任务。
3. **触发关联与必要性**：把指导话语连到触发它的用户话语、可见动作或任务状态。若缺少干预可能导致错误、卡住或信息不足，则标为**必要**；用户可以自行正确继续，则标为**可选**；与任务无关或依赖系统无法获得的信息，则**排除**。主动与被动由触发证据决定，而非由回答的表面形式决定。
4. **干预时间窗**：被动回应的窗口从用户说完开始，到提示不再有用为止；主动干预的窗口从**最早出现迹象**开始，以**证据足以支持干预**的时刻为最佳点，到提示失效时结束。失效可能是用户已开始自我纠正，也可能是后续对话或行动已预设该提示发生。

### 2.2 FLUID-Evaluation：先匹配内容，再评估时机

- **内容匹配**：在比有效时间窗更宽的候选范围内，由大模型根据任务知识、对话和触发证据，判断系统输出能否达到与参考指导相同的实际效果。允许措辞不同，也允许有依据且效果等价的替代说法。每个事件认领最早的合格且未被认领的输出，一条输出最多匹配一个事件。
- **及时正确性（Timely Correctness）**：对所有必要干预取平均。漏答、内容不符或窗口外开口均计零；窗内以最佳点为满分。主动干预在证据尚不充分时按二次函数扣分；超过最佳点后按余弦幂函数衰减，短延迟扣分较轻，接近截止时间时扣分较重。可选干预不进入该指标，因此沉默不扣分。
- **互补指标**：干预精准率衡量实际播报中，有多少在有效窗口内匹配到必要或可选干预；重复、无匹配和时机不当的输出都会拉低它。论文还报告被动响应延迟、用户讲话时间中与系统重叠的比例，以及用于对照的参考匹配 F1。**响应延迟只在符合条件的已匹配回答上计算，不能单独用来判断系统是否善于响应。**

### 2.3 FLUID-Agent：共享任务记忆，异步决定是否开口

- **感知与记忆**：以一个冻结的 Qwen3.6-35B-A3B 视觉语言模型承担在线感知、状态判断、话语理解和生成。系统从视频抽取关键帧，将任务知识编译成带前置关系和完成检查项的动作计划，并在共享记忆中持续更新用户进度、观察证据和对话状态。关键偏差通常需要连续观察一致，或由视觉与用户话语相互印证。
- **被动回应**：先按话语功能区分提问、求证、澄清、问题报告与普通自述、确认语等，再决定是否回答。对于需要回复的话语，在同一次模型调用中完成判断与生成。
- **主动干预**：根据证据形成候选提醒，例如纠错、步骤交接或卡顿援助。系统会记录已播报的证据以减少重复，并在证据撤回、用户已推进或窗口关闭时取消待播提示。感知与语音播报异步运行；检测到用户有实质性发言时，系统可以让出话轮。

## 5. 实验数量与充分性

- **主评测**：两套数据上比较 5 个 AI 系统，即 **10 个系统–数据集组合**，另有两套人类参考结果。本地系统各运行两次取均值，Gemini 运行一次。主表给出按会话聚类 bootstrap 得到的 95% 置信区间。
- **证据阶梯实验**：在 WTaG 上用 JoyAI 和 Gemini 测试 L0–L3 四档，共 **8 个模型–条件组合**，其中 L0 复用主实验。依次比较原生行为、按标注时机强制尝试干预并抑制其他播报、再提供触发类型、最后补充具体观察事实。各档都不给参考回答。
- **消融与人工验证**：在两个数据集上各测试直接被动决策和直接主动决策，共 **4 个新增消融条件**。人工时机研究另取 WTaG 的 **79 个事件、474 个候选时刻**，由 3 位评分者对固定内容在不同时刻播报的合适程度打分。
- **充分性与公平性**：这些实验足以检验新指标能否区分不同交互行为，并揭示不同决策策略的取舍。共享任务知识、统一匹配规则、延迟释放参考历史和会话级置信区间提高了可比性。但各系统的输入频率、语音接口、硬件和适配方式并不完全相同；证据阶梯只覆盖一套数据和两个模型，消融及 Gemini 也缺少重复运行。因此，结果更适合支持**所测配置下的系统级比较**，而非断言某个单独组件必然带来提升。

## 6. 主要结论与发现

### 6.1 是否需要指导，不能只看事件类型

- 同样是“完成一步”，在自定步调的 WTaG 中，只有 **12.9%** 随后出现必要干预，**69.6%** 没有干预；在更依赖指导的 HoloAssist 中，相应比例为 **65.9%** 和 **21.9%**。因此，“完成一步就立刻报下一步”不是通用策略。
- 人工时机研究中，证据窗口与人类可接受性判断的一致度高于固定的参考前 6 秒至后 3 秒窗口：**Macro-F1 为 0.788 对 0.713**。提升主要来自被动回应，主动干预的两种窗口表现相近。对窗内时机进行连续评分时，选定的余弦方案比线性方案更贴近人工评分，**平均绝对误差为 0.182 对 0.225**。

### 6.2 FLUID-Agent 综合表现较强，但主动指导仍远逊于人类

| 指标 | WTaG：FLUID / 人类 | HoloAssist：FLUID / 人类 |
|---|---:|---:|
| 被动及时正确性 ↑ | 0.209 / 0.862 | 0.055 / 0.615 |
| 主动及时正确性 ↑ | 0.046 / 0.921 | 0.062 / 0.881 |
| 干预精准率 ↑ | 0.164 / 0.845 | 0.166 / 0.833 |
| 被动响应延迟 ↓ | 1.15 秒 / 0.20 秒 | 1.17 秒 / 0.47 秒 |

- FLUID-Agent 在两套数据上的被动及时正确性和干预精准率均取得参评 AI 中的最高点估计，但**并非每项都领先**：WTaG 上 Gemini 的主动及时正确性更高，且 Gemini 在两套数据上的语音重叠均更低。
- 参考匹配分数相近不代表交互质量相近。例如 HoloAssist 上，FLUID-Agent 和 JoyAI 的 LLM-Judged F1 几乎相同（**0.099 对 0.098**），但 FLUID-Agent 的主动及时正确性和干预精准率都更高。各系统总体上更擅长回答明确提问，仍不善于识别错误、判断用户卡住，或主动追问缺失信息。

### 6.3 关键瓶颈在于选准干预机会，并获得具体证据

- **证据阶梯**中，最大的提升出现在 L1：系统被告知何时必须尝试回应，并在其他时间保持沉默。这说明干预选择是重要瓶颈，但不能把增益归因于时机信息本身，因为该条件同时改变了响应规则，且 JoyAI 还获得触发话语的标注转写。相比仅给触发类型，进一步提供具体观察事实，使 JoyAI 和 Gemini 的主动及时正确性分别提高 **0.059** 和 **0.080**。
- **消融实验**显示，话语分类能减少对不需要回答的话轮的回应。主动侧则存在明确取舍：结构化决策将主动播报量降至直接决策的约 **十一分之一**，同时提高精准率、减少重复和语音重叠；直接决策虽得到更高的主动及时正确性，但超过 **60%** 的主动话语是重复播报。单独优化及时正确性，可能奖励靠频繁发言提高覆盖的策略。

## 7. 优点

- **把正确内容、合理时机和适当沉默分开衡量**，避免以单一参考 F1 掩盖漏答、抢话或冗余播报。
- **使用两种不同互动模式下的自然人际指导**，并显式连接触发证据、任务进度与话语功能，能够追查系统究竟是看错了、判错了，还是说晚了。
- **对时间窗和评分形状进行人工验证**，固定话语内容以隔离时机因素，并用留一会话交叉验证校准连续分数。
- **同时报告诊断和反例**：证据阶梯揭示具体观察的价值，消融展示覆盖率与说话负担的冲突；论文也明确报告了 Gemini 在语音重叠上的优势和所有模型与人类之间的差距。

## 8. 不足与局限

- **单条人类轨迹无法穷尽所有合理干预。** 示范里没说，不代表另一种提示不合适；框架也没有系统标注“必须沉默”的时刻。因此，未匹配播报会降低精准率，但不能一概视为现实中的有害指导。最早匹配优先的规则也可能让一条过早的等价话语占用匹配，随后更及时的版本无法得分。
- **标注质量和人工验证范围有限。** WTaG 标注经过全面人工复核；HoloAssist 主要依赖自动标注，抽查约 **9.75%** 的话语，且在抽查的 301 个触发关联案例中，**34.9%** 的时间锚点需调整，修正未回写到正式评测版本。时机研究只使用 WTaG，3 位评分者均为作者，且排除了原本与用户语音重叠的参考话语，对主动指导或全双工场景的外推仍需验证。
- **内容评分依赖单一 LLM 裁判。** 裁判看不到系统身份和时机标签，有助于控制偏差，但其判断仍以是否达到与参考相同的指导效果为中心，可能漏掉有效但效果不同的策略。裁判还使用真值转写和动作标注，其可见信息与系统当时实际感知的内容并不完全一致。
- **离线结果不能替代真实部署验证。** 回放中的用户不会因 AI 的提示而改变动作或说话节奏，真实指导者的历史又阻止了系统错误累积，因此无法验证任务成功率、用户负担、错误恢复或长期协作效果。当前系统对主动纠错和卡顿援助的表现仍低，且依赖预先提供的任务知识；在陌生流程、高风险任务或更复杂的全双工对话中，可靠性尚未得到证明。
