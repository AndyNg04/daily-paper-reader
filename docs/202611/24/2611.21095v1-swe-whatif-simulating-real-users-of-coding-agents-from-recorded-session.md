## 摘要
用户与编程智能体之间的录制会话，为评估智能体如何完成现实任务并与用户互动提供了一种途径。然而，这些会话无法直接与新的智能体重放，因为当智能体采取不同的行动路径时，录制下来的用户回复可能不再适用。我们提出 SWE-WhatIf，通过对用户意图、满足意图的标准以及意图产生的条件进行建模，与新的智能体重放录制会话。基于这一模型，用户模拟器能够生成适应未见过的智能体发言、同时以录制内容为依据的回复。在 89 个真实会话中，SWE-WhatIf 生成的回复与真实用户的回复最为相似；在对会话进行改写时，其表现与最强基线相当。为检验其适应能力，我们使用经过指令引导、要求避免或重复录制用户曾提出异议的行为的智能体来重放会话。SWE-WhatIf 在避免这些行为方面取得了最高胜率（66.3%），显著高于随机水平。我们还通过两项研究进一步展示了其效用：一项研究使用它对五个作为编程智能体的大语言模型进行排名，结果显示，排名最高的模型取决于用户如何表达并逐步发展其意图；另一项研究邀请了 16 名用户，结果发现，重放他们各自的会话改变了其中 14 名参与者的模型排名，并为他们今后使用智能体提供了参考。

## Abstract
Recorded sessions between users and coding agents offer a way to evaluate how agents complete real-world tasks and interact with users. However, these sessions cannot simply be replayed with new agents, because recorded user replies may no longer apply when an agent takes a different trajectory. We introduce SWE-WhatIf, which replays recorded sessions with new agents by modeling the user's intents, the criteria for satisfying them, and the conditions under which they arise. Using this model, a user simulator generates replies that adapt to unseen agent turns while remaining grounded in the recording. Across 89 real-world sessions, SWE-WhatIf generated the replies most similar to those of real users and matched the strongest baseline when sessions were rewritten. To test adaptation, we replay sessions with agents instructed to avoid or repeat actions that the recorded user pushed back on. SWE-WhatIf produced the highest win rate for avoiding these actions (66.3%), significantly above chance. We further demonstrate its utility by ranking five LLMs as coding agents, where the highest-ranked model depended on how users specified and developed their intents, and a study with 16 users, where replaying their own sessions changed 14 participants' rankings and informed their future agent use.

# SWE-WhatIf：基于录制会话模拟编程智能体的真实用户

## 1. 核心问题与研究动机

- **研究问题：换一个编程智能体后，怎样重放真实用户的工作会话？** 录制会话不仅记录了用户想完成什么，还记录了他们何时补充要求、纠正错误、接受结果或改变方向。但用户的回复依赖于当时智能体做了什么：如果新智能体没有引入原会话中的回归错误，就不应收到原用户要求修复该错误的消息。
- **现有方法的缺口：** 静态编程基准主要评估需求已明确时的任务完成能力；基于合成目标或角色的模拟器可以灵活回应，却未必反映某位真实用户的需求和引导方式；SWE-Together 则根据条件发送原有消息，仍受限于这些消息的内容和顺序。
- **论文的核心主张：** 重放时应保留的是**用户提出要求的理由和验收依据**，而不是固定的对话文本。作者称这一目标为“忠实适应性”（faithful adaptability）：既能在原轨迹上复现用户行为，也能在新轨迹上作出有原始记录支持的不同反应。

## 2. 方法论：从结构化意图到逐轮重放

- **构建意图模型。** 输入包括录制会话中的用户消息、智能体消息及工具调用结果，以及会话开始时的代码仓库和运行环境。三个基于 LLM 的智能体依次起草、审查和修订意图模型，提取：
  - **意图：** 用户想要的结果或信息，例如修复某个问题，或解释测试为何失败。
  - **满足标准：** 判断意图是否达成的可观察依据。除非用户明确要求或接受某种具体做法，否则标准应允许功能等价的实现。
  - **触发与撤销条件：** 记录何时应提出或撤销意图。条件可以依赖另一意图的完成、会话中出现的事件，或智能体提供的新信息。没有触发条件的后续意图可以从一开始就处于可提出状态，但不必立即说出。
- **逐轮执行“评估—更新—回应”。** 新智能体起初获得重建的环境和用户开场请求，看不到私有意图模型。
  1. **评估：** LLM 根据智能体的消息、工具调用及结果判断验收标准是否满足、情境条件是否触发；意图之间的依赖直接依据状态检查。
  2. **更新：** 由确定性规则维护意图状态，包括阻塞、可提出、已提出、已撤销和已放弃。标准可以因后续改动而从满足变回未满足；已触发的条件则保持触发。已提出但未完成的意图若连续四个智能体轮次没有任何标准变化，会被放弃。
  3. **回应：** LLM 从可提出的意图和仍有未满足标准的已提出意图中，选择此时需要表达的内容，再依据从原消息统计出的风格画像调整措辞，如句长、大小写、标点和常用词。所有相关意图都已满足、撤销或放弃，或连续七轮没有状态变化时，重放结束。
- **区分任务完成与用户负担。** 论文从原始记录独立提取评估目标，而不是直接用模拟器的意图模型打分。LLM 裁判依据最终仓库差异和智能体行为判断目标是否达成，得到目标达成率 \(s\)。负担调整后的得分为：
  \[
  s_{\mathrm{adj}}=s\times\frac{n_{\mathrm{real}}+1}{n_{\mathrm{sim}}+1},
  \]
  其中两项消息数都不包含开场请求。完成结果相同时，模拟用户发出的消息越少，得分越高；**该分数并不是限制在 0–100 的成功率**。

## 3. 实验设计：数据、基准与对照

- **基准数据：** 从 SWE-Together 选取 65 场会话，从较新的 SWE-chat 选取 24 场，共构成 **89 个真实会话重放任务**。纳入条件包括：记录足以判断用户需求与反应、任务可以从起始环境重做、用户至少对智能体的一项行为提出过异议。
- **对比方法：** 完整 SWE-WhatIf、去掉风格画像的消融版本、按条件发送录制消息的 **SWE-Together**、逐步披露需求的 **SWE-Interact**，以及仅提供意图与验收标准的 **Goal-Prompted**。五种配置使用同一底层模拟模型 GPT-5.6 Luna。
- **三类内在验证：**
  - **复现性：** 给定原会话前缀，生成下一条回复，或在固定的录制智能体轮次之间生成连续三条回复。LLM 裁判分别评估内容与风格相似度。
  - **鲁棒性：** 改写会话措辞并合并部分可合并的用户消息，再进行同样的测试，检验方法是否依赖原句或原有消息切分。
  - **适应性：** 在相同任务上，用同一编程智能体分别执行两种指令策略：**重复**或**主动避免**原用户曾反对的行为。每种策略重放两次，按负担调整后的任务得分配对比较；平局计半胜。
- **两类外在应用：** 在统一的 `opencode` 框架中，用 58 个任务比较五款模型，并按是否有反应式意图、开场请求是否详细分组；另招募 16 名参与者，让他们并排查看自己的会话由三个匿名智能体重放的结果，再对这些智能体排序。

## 4. 资源与算力

- **论文未披露 GPU 型号、数量、GPU 小时或训练时长。** 实验通过托管 API 调用模型，服务端硬件和模型参数量没有公开；论文也未报告为该方法额外训练或微调模型。
- **成本与时间：** 全部实验按 API 价格估算约 **3,700 美元**；构建一个意图模型平均约 **3 美元**，模拟用户每轮成本低于 **0.01 美元**。模型排名实验设置了 **40 分钟的单轮时限**，7 个因有智能体超时的任务被排除。该时限不是训练时间，也不是整个任务的运行时间。

## 5. 实验数量与证据充分性

- **实验规模：** 主验证包含“原始／改写会话 × 单轮／三轮”四种相似度设置，以及一项适应性测试，均比较五种模拟器配置。原始会话的单轮评估覆盖 **569 条用户回复**，三轮复现覆盖 **71 个具备足够轮次的任务**。按适应性实验设计，共有 \(89\times5\times2\times2=1{,}780\) 次重放；模型排名另有 \(58\times5=290\) 次重放，用户研究有 **48 条短重放**。附录还报告了错误类型、会话长度和图灵式辨别等补充分析。
- **公平性较强之处：** 模拟器共享底层模型，策略对照在同一任务上进行，适应性检验对多重比较做 Holm 校正；模型排名统一运行框架，用户研究在最终排序前隐藏智能体身份。
- **证据边界：** 实验足以支持“在这批可重放任务上，该方法相对于所选基线更能区分两种策略”，但不足以证明它能普遍预测真实用户面对任意新轨迹时的反应。SWE-Interact 为适配实验被移除了仓库检查能力，部分 SWE-Together 提示也由作者重新生成，因此比较针对的是**统一约束下的实现**。此外，复现性是从同一会话提取意图后再重建回复，不是对陌生用户行为的预测测试；排名实验中每个模型在每个任务上只运行一次，难以判断细小名次差异是否稳定。

## 6. 主要结论与发现

| 维度 | SWE-WhatIf | 最强外部基线 SWE-Together |
|---|---:|---:|
| 原会话复现：单轮／三轮相似度 | **53.2／44.9** | 51.3／40.4 |
| 改写会话鲁棒性：平均相似度 | **45.1** | 44.7 |
| 适应性：主动避免策略的胜率 | **66.3%** | 55.6% |

- **原会话上最接近真实回复，改写后与最强基线相当。** 所有模拟器在三轮复现中的得分都低于单轮。风格画像的主要收益体现在措辞相似度；移除后，适应性胜率也从 66.3% 降至 62.9%，但这不能单独证明风格是胜率差异的原因。
- **66.3% 是配对胜率，不是任务完成率。** 它表示在完整模拟器下，主动避免策略相对重复策略更常取得较高的负担调整得分。按任务汇总，主动避免策略在 89 项中赢 52 项、输 23 项、平 14 项；论文报告该优势经多重比较校正后仍显著。这表明重放能区分两种策略，并不直接验证每条反事实回复都符合真实用户的行为。
- **最佳模型随任务中的需求表达方式变化。** 总体排名为 Claude Opus 5.5、Claude Sonnet 5.5、GPT-6 Sol、GPT-6 Luna、Kimi K3；与真实用户参与的 Agent Arena 榜单的 Kendall \(\tau_b\) 为 **0.80**。GPT-6 Sol 在没有反应式意图或开场请求详细的任务组排第一；Claude Sonnet 5.5 在含反应式意图的任务组排第一，Claude Opus 5.5 在开场请求简短的任务组排第一。这些是分组结果，不代表改变提示方式就一定会改变模型排名。
- **个性化重放能改变参与者的选择。** 16 人中 **14 人改变了排序，10 人更换了首选**；12 人认为较小、较便宜的模型足以应对自己的会话。不过，逐条评价时只有 **49%** 的模拟回复被标为“像我”，另有 38% 被标为“部分像”，说明整体认可与逐条的准确模仿并不等同。

## 7. 优点

- **把“想要什么、怎样才算完成、何时提出”分开建模。** 这比按脚本播放用户消息更适合检验不同实现路径，也能解释为什么同一要求在某条重放中出现、在另一条中不出现。
- **没有把语言相似度当作适应性的替代指标。** 原样复现、形式扰动和策略对照分别检验不同能力；把用户纠正过的行为转化为可控对照，是实验设计中最有价值的部分。
- **同时考察结果与交互成本。** 两个模型可能完成近似比例的目标，却需要不同程度的用户引导。论文同时报告目标达成率和消息数，使综合排名的来源更易解释；真实用户研究也补充了自动评测难以反映的选择偏好。

## 8. 不足与局限

- **反事实行为缺乏直接真值。** 原始会话只能证明用户在已发生的轨迹上如何反应。模拟器可能把“没有反对”理解为接受，也不能可靠推断记录中从未出现的偏好或新需求。相反，它能看到完整工具输出，而真实用户可能只浏览摘要，也可能在会话之外自行编辑文件或运行测试。
- **自动裁判和负担指标都有偏差风险。** 意图提取、相似度评分及任务达成判断均依赖 LLM；用户消息数不等于实际的阅读、判断和操作成本。策略指令也可能直接改善代码或工作流程，因此胜率差异不能完全归因于模拟器更像真实用户。
- **覆盖有限，模型排序不宜泛化。** 样本主要来自主动公开会话的用户，并要求任务可重建且原用户曾提出异议，难以代表企业私有仓库、依赖外部资源的任务或没有明显纠偏的顺利会话。模型排名只覆盖五款模型和一个运行框架，并排除了超时任务；外部榜单的任务、框架和推理设置也不同。用户研究仅有 16 人，每条重放最多三轮，环境是从日志部分重建的，因此偏好变化不能等同于长期使用收益。
- **仍会引入原用户没有提出的工作，且复现面临隐私约束。** 错误分析中，完整方法有 **52.2%** 的受标注重放至少出现一次额外请求，例如要求再检查或再运行测试。原始日志、意图模型和风格画像可能暴露凭证、代码或个人行为特征；作者采取了脱敏、知情同意与删除措施，但未发布完整实验工件包，因而增加了独立复现的难度。
