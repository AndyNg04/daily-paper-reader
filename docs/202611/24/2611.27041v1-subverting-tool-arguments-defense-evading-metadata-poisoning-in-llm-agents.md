## 摘要
传统的间接提示注入（IPI）攻击通过在检索到的外部内容中嵌入恶意指令，劫持大语言模型（LLM）智能体的工作流程。随着模型上下文协议（MCP）的应用日益广泛，第三方 MCP 服务器提供的工具描述也暴露出新的攻击面。攻击者可以操纵这些元数据，诱使智能体在调用工具时生成恶意参数。难点在于，修改后的描述必须同时对 LLM 和用户显得无害。然而，现有 IPI 攻击难以在这种场景中同时实现较高的攻击成功率和较低的可检测性。为应对这一挑战，我们提出 GRAFT，一种基于 LLM 的对抗性工具描述生成优化方法。具体而言，GRAFT 使用掩码机制识别与参数相关的词元位置，以便进行定向注入；随后，在智能体的工具选择和生成参数的指导下，利用 LLM 提出的动态变异策略迭代优化候选描述。我们在三个公开数据集上，将 GRAFT 与多种攻击基线进行了评估。结果表明，在五种基于过滤器的防御机制下，GRAFT 在保持较低检出率的同时实现了更高的攻击成功率，并能绕过多种现有 IPI 防御。即使面对使用 GRAFT 生成的注入样本进行训练的自适应防御，GRAFT 的效果仍优于各项基线方法。

## Abstract
Conventional indirect prompt injection (IPI) attacks hijack an LLM agent's workflow through malicious instructions embedded in retrieved external content. The growing adoption of the Model Context Protocol (MCP) exposes another attack surface: tool descriptions supplied by third-party MCP servers. Attackers can manipulate this metadata to induce malicious argument generation during tool calls. The challenge is to ensure that the modified descriptions still appear benign to both LLMs and users. Existing IPI attacks, however, struggle to achieve both high attack success and low detectability in this setting. To address this challenge, we propose GRAFT, an LLM-based optimization method for crafting adversarial tool descriptions. Specifically, GRAFT uses a masking mechanism to identify argument-relevant token positions for targeted injection. It then iteratively refines candidate descriptions using dynamic mutation strategies proposed by an LLM, guided by the agent's tool choices and generated arguments. We evaluate GRAFT on three public datasets against several attack baselines. The results show that GRAFT achieves higher attack success while maintaining low detection rates across five filter-based defenses. It also bypasses several existing IPI defenses. Even under an adaptive defense trained on GRAFT-generated injections, GRAFT remains more effective than the baselines.

## 1. 核心问题与研究动机

- **论文研究的是：在不修改工具接口和实现的情况下，仅篡改工具描述，能否让大语言模型智能体选择攻击者指定的工具，并生成违背用户意图的参数？** 在模型上下文协议（MCP）中，第三方服务器提供的工具描述既帮助智能体判断何时选用工具，也影响它如何填写参数。因此，原本用于解释功能的文档，可能实际左右系统执行的动作。
- **与传统间接提示注入的区别在于攻击发生的阶段。** 传统攻击通常藏在网页、文档或工具返回结果中，在智能体读取内容后影响后续行为；本文研究的投毒发生在工具调用形成之前，即使用户指定的文档或网页完全正常，也可能生成未经授权的调用。
- 论文指出，传统注入模板移植到工具描述后，往往依赖冗长、显眼的指令；压缩描述后，成功率又会下降。作者据此研究：**当错误参数看起来像普通工具规格时，依赖文本告警或语义判断的防御是否仍能识别它？**

## 2. 方法论：GRAFT 的核心思想与流程

- **威胁模型。** 攻击者能够修改其控制的 MCP 工具的自然语言描述，知道工具功能与参数结构，并可以观察智能体对测试请求的调用结果；但不能修改用户请求、系统指令或模型参数，也不一定知道部署时的真实请求。论文刻意保持工具名称、输入模式和实现不变，以隔离描述文本的影响。
- **核心思想。** GRAFT 不把工具描述视为附加独立指令的载体，而是把它视为直接影响参数解释的功能规格。方法从原文中识别与目标参数有关的局部内容，尽量保留其余功能说明。论文用句法关系和语义相关性解释如何定位这些内容，而不是只依赖词语在文本中的相邻位置。
- **流程概览。** 首先，根据工具功能与参数结构构造代表性用户请求，作为真实部署请求不可见时的代理；其次，从多个描述起点出发进行局部改写；最后，根据智能体的工具选择与参数输出比较候选描述。反馈除了成功或失败，还区分选错工具、选对工具但参数错误、没有调用等结果。论文将修订方向的判断与实际文本改写分开，并用历史结果帮助解释哪些修改有效。
- **优化目标。** 对每个请求，只有在智能体调用目标工具、且所有被指定的参数都精确匹配目标值时，才记为成功；候选描述的成绩是其在代理请求集上的成功比例。作者同时要求描述保持自然并保留工具原功能，但“自然”主要由文本特征和检测结果间接衡量，并非独立的人类评审结论。

- **三个公开基准。** 论文共使用 **109 个任务、33 个 MCP 服务器、118 个工具**，覆盖文件与文档、网页访问、软件开发、金融等领域；每个任务构造 3 条留出请求，共 **327 条测试请求**，不参与优化。

  | 基准 | 纳入任务数 | 主要考察情境 |
  |---|---:|---|
  | MCP Security Bench（MSB） | 16 | 在用户本就需要的工具调用中加入超出任务范围的参数值 |
  | MCP-SafetyBench（MCP-SB） | 18 | 工具描述影响参数选择，请求通常未明确给出目标参数的具体值 |

## 7. 优点

- **清楚揭示了工具文档与执行授权之间的区别。** 仅改变描述就能改变结构化调用，说明参数类型校验通过、工具实现按预期运行，并不等于该次调用获得了用户授权。
- **从多个角度检验同一风险。** 跨基准、跨模型、跨防御的对比，辅以消融、长度控制、误报和正常效用测量，使结论不依赖单个扫描器或单个成功率数字。消融也表明，局部语义处理、多起点比较和细粒度反馈各自有贡献，而非简单改写即可得到同等结果。
- **区分了描述篇幅与生成成本。** GRAFT 的最终描述平均约 **70 个 token**，但生成阶段依然需要大量模型调用。这使读者可以分别判断它在元数据长度受限场景中的适用性，以及实验本身的资源开销。

## 8. 不足与局限

- **基准成功不等于真实损害。** 指标主要衡量是否生成匹配目标的调用；在真实系统中，文件访问范围、网络出口控制、最小权限和用户确认等机制仍可能阻止实际后果。论文不能据此推断真实的数据泄露或越权执行概率。
- **外部有效性有限。** 留出请求虽未参与优化，但仍是合成的，不能充分代表生产中的多轮对话、长尾参数、工具版本变化和并发工作流。实验也未充分回答受测模型不可访问、注册工具来源受严格控制时，结果能在多大程度上迁移。
- **低检出率不等于人类无法发现。** 自然度主要由长度、措辞统计和扫描器结果间接衡量，未见充分的盲评或人工审计实验；附录的语言特征相关性也只基于 10 种方法，应视为方向性证据，而非因果证明。
- **被测防御不代表所有可部署防御。** DataSentinel 因良性描述误报率过高而未纳入主比较，这有实际合理性，但也说明结论取决于防御选择和配置。更值得验证的是：由工具宿主依据**独立于第三方描述**的权限策略、用户指定的资源和明确授权，在执行前校验参数；对敏感读取、对外发送和不可逆写入采用更严格的权限约束或确认。论文的结果支持这一设计方向，但没有直接测量其效果。
