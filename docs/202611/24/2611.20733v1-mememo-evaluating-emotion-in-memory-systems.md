## 摘要
记忆系统旨在解决大型语言模型在长时间交互过程中面临的上下文丢失问题。然而，记忆系统是实现温暖陪伴与个性化服务的重要工具，其处理情感信息的有效性却尚未得到充分研究。为弥补这一研究空白，我们提出一项情绪增强型记忆评估基准，用于评估主流及最先进记忆系统整合和运用情感信息的表现。首先，我们设计了名为 \textbf{MemEmo} 的基准，从四个维度评估记忆系统的情感推理与追踪能力：情感信息提取、情感记忆更新、情感记忆问答以及情感冲突检测。其次，我们构建了 \textbf{H}uman-\textbf{L}ike \textbf{M}emory \textbf{E}motion（\textbf{HLME}）数据集，为审视记忆系统提供实证基础。最后，我们在 HLME 数据集上评估了五种具有代表性的记忆系统，并报告了涵盖四个维度的 11 项性能指标。实验结果表明，所有受测记忆系统的综合得分最高仅为 45\%，远低于满分 100\%，揭示了记忆系统与情感智能之间的显著差距。

## Abstract
Memory systems address the challenge of context loss in Large Language Models during prolonged interactions. However, as an essential tool for warm companionship and personalized services, the effectiveness of memory systems in processing affective information remains underexamined. To bridge this gap, we propose an emotion-enhanced memory evaluation benchmark to assess the performance of mainstream and state-of-the-art memory systems in integrating and harnessing emotional information. First, we design a benchmark called \textbf{MemEmo} to assess the affective reasoning and tracking capabilities of memory systems across four dimensions: emotional information extraction, emotional memory updating, emotional memory question-answering, and emotional conflict detection. Second, we construct the \textbf{H}uman-\textbf{L}ike \textbf{M}emory \textbf{E}motion (\textbf{HLME}) dataset to provide an empirical foundation for scrutinizing memory systems. Finally, We evaluate five representative memory systems on the HLME dataset, reporting 11 performance metrics across four dimensions. Experimental results reveal that aggregating scores for all tested memory systems is up to 45\%, far below 100\% scale, exposing a profound disparity between memory system and affective intelligence.
