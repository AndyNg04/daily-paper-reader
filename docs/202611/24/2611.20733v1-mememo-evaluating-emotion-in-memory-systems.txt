## Abstract 

Memory systems address the challenge of context loss in Large Language Models during prolonged interactions. However, as an essential tool for warm companionship and personalized services, the effectiveness of memory systems in processing affective infor-mation remains underexamined. To bridge this gap, we propose an emotion-enhanced memory evaluation benchmark to assess the performance of mainstream and state-of-the-art memory systems in integrating and harnessing emotional information. First, we de-sign a benchmark called MemEmo to assess the affective reason-ing and tracking capabilities of memory systems across four di-mensions: emotional information extraction, emotional memory updating, emotional memory question-answering, and emotional conflict detection. Second, we construct the Human-Like Memory 

Emotion ( HLME ) dataset to provide an empirical foundation for scrutinizing memory systems. Finally, We evaluate five represen-tative memory systems on the HLME dataset, reporting 11 perfor-mance metrics across four dimensions. Experimental results reveal that aggregating scores for all tested memory systems is up to 45%, far below 100% scale, exposing a profound disparity between mem-ory system and affective intelligence.

## 1 Introduction 

Large Language Model (LLM) primarily focus on natural language generation and understanding, underpinned by training on vast corpora of textual data [1, 18, 30]. In contrast, memory systems concentrate on the construction and retrieval of long-term mem-ory, emphasizing the retention and updating of information across tasks to enhance contextual understanding and facilitate long-term, cross-task learning. However, LLMs struggle to recall and track memory information generated during user interactions, partic-ularly over extended time intervals. Consequently, a significant number of LLM-based memory systems have emerged [12]. Some multi-turn dialogues dataset, such as LOCCO [10], Lo-CoMo [16], and LONGMEMEVAL [27], are capable of evaluating long-context information retention. While memory systems are be-coming increasingly intelligent, they still exhibit pronounced defi-ciencies compared to human memory capabilities, including mem-ory hallucinations [2], memory linking, memory forgetting[28], contextual adaptability, as well as reasoning and self-perception. Current mainstream memory systems face limitations when ad-dressing emotion-related issues in user dialogues. Specifically, they fail to integrate short-term and long-term memory with emotion-related content struggle to track emotionally associated events from the distant past, and lack a deep understanding of user emotional fluctuations. Furthermore, they are unable to accurately analyze and interpret dialogues or questions containing implicit emotions. arXiv:2611.20733v1 [cs.CL] 16 Nov 2026 Conference acronym ’XX, June 03–05, 2018, Woodstock, NY Peng Liu al. 

The challenges faced by current memory systems in processing emotion-related dialogues are illustrated in Figure 1.

To address this challenge, we propose an emotion-oriented bench-mark for memory systems, named MemEmo , designed to evaluate emotion processing capabilities in extracting, updating and reason-ing. We systematically evaluate the performance of mainstream memory systems, such as MemOS [11], memobase [17], Mirix[25], Letta[19] and mem0 [5], in managing emotional memory across four different dimensions. The main contributions of this work are summarized as follows: 1. We design a benchmark named MemEmo to systematically evaluate memory systems across four key dimensions: emotional information extraction, emotional memory updating, emotional mem-ory question answering, and emotion conflict detection. This bench-mark acts as a catalyst for the evolution of memory systems, facil-itating their transition from neutral data processors to empathetic, personalized service agents. 2. We construct a human-like memory emotion evaluation dataset, namely HLME , comprising an average of 2,000+ dialogue turns and 200+ questions per instance. Each dialogue turn is annotated with fine-grained emotional labels, every question is accompanied by a reference answer enriched with affective information, supple-mented by exhaustive token-based statistical metrics. 3. We conduct a comprehensive benchmarking study of five rep-resentative memory systems across the HLME-Medium and HLME-Large subsets. By reporting 110 quantitative outcomes, our analy-sis reveals that the overall scores for all evaluated systems are far below 45%, exposing a profound disparity between current mem-ory systems and sophisticated emotional intelligence. 

## 2 Related Work 2.1 Emotional Interaction Frameworks 

To explore the affective dimensions of Large Language Models (LLMs), various frameworks have emerged to bridge the gap between static reasoning and dynamic empathy. The Dynamic Affective Memory framework DAM-LLM [15], optimizes memory management to al-leviate latency and inflation, thereby enhancing interaction qual-ity in personalized dialogues. However, it prioritizes architectural efficiency over systematic affective evaluation. While SO-AI [21] investigates emotional support and self-narrative construction for mental health, it lacks a rigorous quantitative metric for the emo-tional processing efficiency of memory modules. More recently, EmoHarbor [29] introduced a Chain-of-Agent ar-chitecture to simulate user inner states for fine-grained support as-sessment. Simultaneously, EC2ER [23] leveraged synthetic emotion-aware Chain-of-Thought (CoT) data to boost reasoning in light-weight models, and CoEM [13] addressed emotional coordination in long-context interactions. Despite these advancements, existing frameworks generally treat memory as a static repository rather than an evolving, affective processing unit. A comprehensive frame-work capable of quantifying multi-dimensional emotional evolu-tion within memory systems remains a critical vacancy. 

## 2.2 Emotional Evaluation Benchmarks 

The evaluation of LLM affective intelligence has evolved from basic classification to complex reasoning. Foundations such as EmoBench [22] and EQ-Bench [20] established initial standards for emotional in-telligence gaps and intensity recognition, respectively. Subsequent benchmarks like EmotionQueen [4] and EvoEmo [14] expanded these horizons into empathy measurement and adversarial nego-tiation strategies. To ensure personality consistency, MECoT [26] introduced Markov-based emotional tracking for role-playing sce-narios. Recent efforts have begun to integrate memory mechanics into evaluation. MADial-Bench [8] evaluates passive and proactive re-call through the lens of cognitive science. Notably, ES-MemEval [3] tracks evolving user states to benchmark personalized long-term support. Furthermore, TEA-Bench [24] explores the synergy be-tween empathetic expression and external tool-augmented ground-ing. However, these benchmarks primarily evaluate the behavioral output of LLMs rather than the internal stability and logic of the underlying memory systems. Our proposed MemEmo benchmark transcends previous limi-tations by introducing a high granularity evaluation protocol across four distinct dimensions of affective processing. The framework in-corporates eleven comprehensive evaluation metrics designed to cover the vast majority of operational scenarios for memory sys-tem. Furthermore the proposed HLME dataset features extensive context lengths which enable the simultaneous assessment of spe-cialized affective processing and general memory capabilities. A comprehensive comparison of MemEmo with related frame-works is summarized in Table 1. While contemporary works excel in specific domains, they often struggle with the granular analysis MemEmo: Evaluating Emotion in Memory Systems Conference acronym ’XX, June 03–05, 2018, Woodstock, NY 

of deep affective information and emotional consistency in long-term evolutionary contexts. MemEmo bridges this gap as the first framework specifically engineered to evaluate the affective pro-cessing and conflict detection capabilities of memory systems.

## 4 MemEmo Evaluation Framework 

We propose the MemEmo evaluation framework, which is specif-ically designed to assess the affective processing capabilities of memory systems. Unlike traditional emotion recognition tasks, which predict an emotion label 𝑦 solely from the input text 𝑥 , this task requires the memory system to analyze, understand, store, reason, and track changes in a user’s emotional state by utilizing a wide range of information. We categorize the evaluation tasks into four dimensions: Emo-tion Information Extraction (EIE), Emotion Memory Updating (EMU), Emotional Question Answering (EQA), and Emotion Conflict De-tection (ECD). Detailed task descriptions and evaluation designs are presented in the subsequent subsections of this section. The brief evaluation task is illustrated in Figure 2.

## 5 HLME Dataset Construction Methodology 5.1 Dataset Construction Pipeline 

In this section, we introduce HLME , a high-quality dataset cus-tomized for human-like memory emotion assessment. We design a four-stage pipeline to ensure data quality and scalable construc-tion. Figure 3 illustrates our dataset construction workflow, with emotional configurations and templates in Appendices D and F. 

Stage 1: Basic Information Generation First, to support emo-tional evolution, we construct a complete user persona using a seed dataset [7]. This stage integrates static attributes such as personal and family profiles; dynamic attributes including career, finances, health, and social networks; ten unique preference categories; and a metrics-supported annual plan at a monthly granularity. This per-sona grounds subsequent emotional dynamics simulation. 

Stage 2: Extend Information and Emotion Binding Second, this stage maps temporal user evolution onto emotional dimen-sions. Information extension simulates career, health, and social trajectories, incorporating preference drift and plan feedback. Emo-tion binding then connects these extended states to 49 distinct EARL emotion categories [6], anchoring them to specific user events and Maslow’s hierarchy [9] to ensure multi-dimensional coher-ence. 

Stage 3: Extract Information Point and Generation Event 

Third, this stage distills core elements for dialogue generation. We extract memory points containing metadata, content, emotions, and timestamps from user personas. Simultaneously, we identify key events, which are critical life incidents that drive emotional transi-tions. Together, these structured points and events form the essen-tial framework for evaluating memory system emotion tracking and generating emotionally grounded dialogues. 

Stage 4: Generate Dialogue and Question Finally, we con-struct multi-turn dialogues enriched with role, temporal, and fine-grained emotion metadata. We design five evaluation tasks encom-passing factual QA, multi-hop reasoning, dynamic updating, con-flict detection, and temporal reasoning. To evaluate system robust-ness, we release the Medium version alongside a Large version algo-rithmically extended with noise and ultra-long contexts. Further-more, a subset of the data is manually annotated to ensure high quality and assessment reliability, as detailed in Appendix B.2.

## 7 Conclusion 

Memory systems effectively mitigate LLM long-term context con-straints; however, their efficacy for personalized affective services and persistent emotional tracking remains a critical research gap. In this study, we present a humanoid memory emotion evaluation dataset designed to assess the performance of mainstream mem-ory system in affective reasoning and tracking. Through extensive experimentation, our results demonstrate that the overall scores of these current memory systems on the MemEmo evaluation frame-work are all below 45%. Such results expose the inherent functional bottlenecks of existing memory system in maintaining emotional intelligence across extended time spans, especially regarding the resolution of complex affective contradictions. By introducing this novel dataset and benchmark, we establish a novel trajectory for advancing emotional intelligence within memory systems. Future work will focus on advanced emotional processing and memory synchronization while simultaneously extending our framework to multimodal affective analysis to incorporate cross-modal behav-ioral cues for a more holistic emotional understanding.

## A Memory System Evaluation Workflow 

Utilizing the multi-stage dataset constructed in Chapter 5, we con-duct a systematic evaluation of various memory systems through a unified pipeline. Within this framework, each candidate system autonomously ingests records from the HLME dataset, executes its proprietary processing logic, and generates corresponding outputs. To ensure objectivity and cross-system comparability, we employ a standardized scoring template to assess all outputs. This compre-hensive evaluation workflow, illustrated in Figure 5, encompasses the entire process from initial data loading to the final metric cal-culation. Quantitative results are efficiently derived by executing the designated evaluation scripts. As illustrated in the framework, the HLME dataset is organized into a hierarchical structure comprising six primary elements, where sessions are aggregated into a collective repository. Each session consists of multi-turn dialogues acting as core modules that are batch-loaded into the memory systems, with targeted queries in-jected during the Emotion Question & Answer (EQA) phase. The evaluation framework quantifies performance across four critical dimensions: Emotion Information Extraction (EIE), Emotion Mem-ory Update (EMU), EQA, and Emotion Conflict Detection (ECD). These dimensional scores are subsequently aggregated to produce a final weighted metric for comprehensive ranking and compara-tive analysis.

## B.2 Manual Annotation and Dataset Validation 

Following the construction of the HLME dataset, a multi-stage ver-ification and quality control process was implemented to ensure data integrity and emotional precision. In the first stage, we re-cruited ten annotators with diverse expertise across education, fi-nance, sports, literature, and healthcare. For this verification task, one-third of the total data entries were randomly selected, and the annotators reviewed both the Medium and their correspond-ing Large versions. This annotation focused on three critical di-mensions encompassing the validity of emotional labels, the cor-rectness of question answers, and the alignment of associated af-fective tags. To maximize inter-annotator agreement and mitigate individual bias, the ten participants were organized into five pairs for systematic cross-annotation and validation. In the second stage, five NLP experts specializing in sentiment analysis conducted an independent quality control audit on the processed dataset. Their independent validation demonstrated high human-machine agreement, exceeding 90% on factual memory point annotation, 80% on QA evidence retrieval, and 75% on both fine-grained sentiment and event importance. These robust consistency rates collectively validate our incremental construction methodol-ogy and the high quality of the HLME dataset.

We adopt the 49 emotion categories defined in the Emotion Anno-tation and Representation Language (EARL) from the HUMAINE framework. To enable fine-grained modeling, we extend this taxon-omy into a structured configuration schema where each emotion

The intensity of each emotion is modeled through a three-level hierarchy ( Low , Medium , High ). Each level is associated with a nor-malized tag for surface realization and a natural language descrip-tion for interpretability.
