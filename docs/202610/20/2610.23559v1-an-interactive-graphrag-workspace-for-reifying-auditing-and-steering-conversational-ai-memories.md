## 摘要
对话式大语言模型（LLM）已广泛应用于软件工程中的代码生成、调试和架构设计。然而，随着开发者开展跨多个会话的开发任务，技术知识往往被孤立在线性聊天记录中。在不同会话间复用上下文会带来三项关键挑战：（1）扁平向量检索无法遍历相距较远的架构决策之间多跳的关系依赖；（2）软件包和 API 随时间变化，导致复用过时的对话记录时，过时上下文会悄然污染当前信息；（3）直接拼接原始对话会造成提示词膨胀和注意力退化。我们提出 CognitiveCanvas，这是一款交互式工具，可将对话式 AI 记忆从短暂的文本日志转化为持久、可操作且可审计的知识对象。\textsc{CognitiveCanvas} 集成了：（1）层次语义事实图（HSFG），将对话提炼为目标、事实和代码等知识条目，在支持多跳 GraphRAG 遍历的同时，将 token 数量减少 92.2\%；（2）持续式时间漂移审计器，将 60 余种正则表达式启发式规则与基于实时日历的 LLM 验证相结合，实现一键自我修正；（3）空间符号提示编译器（SSPC），将二维直接操控手势（Voronoi 聚类、节点调整大小、合成边）直接转换为结构化注意力指令。

## Abstract
Conversational Large Language Models (LLMs) are widely employed in software engineering for code generation, debugging, and architectural design. However, as developers engage in multi-session development tasks, technical knowledge becomes siloed in isolated, linear chat histories. Reusing context across sessions leads to three critical challenges: (1) flat-vector retrieval fails to traverse multi-hop relational dependencies between distant architectural decisions; (2) temporal drift in software packages and APIs results in silent context poisoning when reusing aged dialogue logs; and (3) raw conversation concatenation induces prompt bloat and attention degradation.   We present CognitiveCanvas, an interactive tool that transforms conversational AI memories from ephemeral text logs into persistent, manipulable, and audited knowledge objects. \textsc{CognitiveCanvas} integrates: (1) a Hierarchical Semantic Fact-Graph (HSFG) that distills dialogues into Goal, Fact, and Code artifacts, achieving a 92.2\% token reduction while enabling multi-hop GraphRAG traversal; (2) a Continuous Temporal Drift Auditor coupling 60+ regex heuristics with live calendar-anchored LLM verification for 1-click self-correction; and (3) a Spatial-Symbolic Prompt Compiler (SSPC) that translates 2D direct manipulation gestures (Voronoi clustering, node resizing, synthesis edges) directly into structured attention directives
