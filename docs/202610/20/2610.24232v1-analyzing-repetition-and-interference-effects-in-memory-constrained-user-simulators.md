## 摘要
用户模拟器有助于大规模评估和训练能够与人类交互的人工智能系统。为此，对用户模拟器的评估必须衡量其行为与人类的一致性。我们评估了记忆受限的用户模拟器是否会受到两种已知会影响人类信息保持能力的因素影响：事实的重复呈现，以及竞争信息带来的干扰。我们发现，部分模拟器的整体准确率与人类相近，也能复现重复效应和干扰效应的幅度，但没有任何一种模拟器能在具体问题上达到人类的准确率：人类会记错事实，而模型会遗忘事实，因此两者呈现出不同的错误模式。我们将这些数据发布为一项挑战基准，以支持未来用户模拟器研究。

## Abstract
User simulators can help evaluate and train AI systems to interact with humans at scale. To do so, evaluation of user simulators must measure behavioral parity with people. We evaluate whether memory-constrained user simulators are sensitive to two factors known to affect human information retention: repetition of a fact and interference from competing information. We find that some simulators achieve human-like overall accuracy, and replicate the magnitude of repetition and interference effects, but none match people's accuracy on particular questions: while humans misremember facts, models forget them, leading to different error patterns. We release this data as a challenge benchmark for future work on user simulators.

## 1. 核心问题与研究背景

### 研究问题
论文考察：**限制大语言模型的记忆容量后，能否让它不仅“答得和人类一样多”，还“在同样的问题上、以同样的方式犯错”？**

用户模拟器可用于规模化评估和训练智能助手、教学系统等。但直接提示语言模型扮演用户，往往会得到过于合作、知识过多、记忆过好的“用户”，影响模拟结果的可信度。

已有研究通过摘要、有限命题列表或键值缓存限制模型记忆，缩小了模型与人类的总体准确率差距。本文进一步追问，这种接近是否意味着真正的行为一致性。

### 整体思路与含义
研究围绕两种经典人类记忆现象展开：

- **重复效应**：同一事实被换一种说法再次呈现，通常有助于记忆。
- **干扰效应**：随后出现相似对象的竞争信息，通常会损害原有信息的保持或提取。

论文强调：**总体准确率接近，只能说明模拟器的平均表现相似，不能证明它能够可靠预测人类对具体信息的记忆与误记。** 这一差别会直接影响教学系统“该重复什么”、助手“用户可能混淆什么”等决策。

## 2. 方法论：核心思想与技术流程

### 2.1 三层行为一致性评价

本文主要贡献是评测设计与实证分析，而非提出新的模拟器架构。

| 评价层级 | 衡量内容 | 目的 |
|---|---|---|
| 总体层面 | 多选题完全正确率 | 判断平均表现是否接近人类 |
| 条件层面 | 重复增益、干扰代价 | 判断是否对记忆操纵产生相似反应 |
| 题目层面 | 模型与人类逐题难度的相关性 | 判断双方是否觉得同样的问题困难 |

关键指标包括：

- **完全匹配准确率**：必须选中全部正确选项，且不选任何错误选项，才算答对。
- **重复增益**：`SayTwice 准确率 − SayOnce 准确率`。
- **干扰代价**：`SayOnce 准确率 − Interfere 准确率`，越大表示干扰损害越明显。
- **逐题一致性**：计算模型与人类在20道题上的题目难度相关性，主要使用 Pearson 相关系数。

作者还将人类随机分成两半，重复2,000次，建立“人类与人类之间能有多一致”的参照：逐题表现相关性的中位数为 **r = 0.94**。

### 2.2 记忆受限模拟流程

整体流程为：

1. 模型读取材料。
2. 将材料压缩进受限记忆。
3. 回答问题时，不再提供原文，只提供记忆内容。
4. 比较模型与人类的准确率、条件效应及错误类型。

主要方法：

| 方法 | 记忆机制 |
|---|---|
| 提示词方法 | 提供完整原文，通过提示要求模型回答或模拟人类 |
| Free Summary | 默认将原文压缩成不超过60词的摘要 |
| CBUS | 默认保留最多4条原子命题 |
| CBUS + Dropout | 先提取最多12条命题，再随机保留4条 |
| Compactor | 默认维护4槽键值缓存，每个值最多一句、15词，可通过工具调用写入、修改或删除 |

其中，随机丢弃基线用于检验：**模型自主选择“记住什么”，是否比随机保留信息更接近人类。**

### 2.3 关键变体

- **提示词**：普通阅读理解、任务说明、模拟人类、模拟记忆有限的人类，共4种。
- **记忆容量**：部分模型测试 `k = 2～6`；摘要容量为 `15k` 词，命题或缓存数量为 `k`。
- **输入方式**：
  - 批量编码：一次接收完整材料。
  - 流式编码：逐句接收，每步仅看到当前记忆与新句子。
- **思考模式**：在适用模型上比较开启与关闭。

## 3. 实验设计：数据、Benchmark 与对比方法

### 3.1 自建记忆理解基准

研究构建了涉及四类虚构实体的材料：

- 天体；
- 织物；
- 水果；
- 武术。

使用虚构实体，意在尽量排除既有知识的影响。每个主题包含一个目标实体和一个同类干扰实体，每个实体先生成5条事实，再由作者编辑。

每个主题包含4个版本：

| 条件 | 内容 | 主要作用 |
|---|---|---|
| SayOnce | 每条目标事实出现一次，随后添加填充内容 | 基线 |
| SayTwice | 每条事实后紧接一次换措辞重述 | 测量重复收益 |
| SayThrice | 每条事实增加至三次表述 | 考察更多重复 |
| Interfere | 目标事实出现一次，随后加入同类实体信息 | 测量干扰损害 |

- 共 **4主题 × 4条件 = 16个材料版本**。
- 每个主题有5道多选题，共 **20道不同题目**，跨条件复用。
- 每题有4个实质选项及“以上皆非”，正确实质选项数量为0～3。
- 重复均为紧邻式重复，**不是间隔重复**。
- SayThrice 与 Interfere 的篇幅大致匹配；SayOnce 与 SayTwice 也通过填充内容尽量接近长度。

### 3.2 人类实验

- 招募241名完成实验的参与者，剔除未通过注意力检查的40人，最终分析 **201名美国成年 Prolific 用户**。
- 每人接触四个主题、四种条件，各一次；主题与条件配对进行平衡，材料顺序随机化。
- 人类听一次合成音频，不能暂停、回放或重新阅读，之后立即回答书面问题。
- 每人回答20道正式题，共约 **4,020条题目回答**。
- 音频时长约44～83秒。

### 3.3 模型实验

论文报告评测了 **7个模型家族、27个模型**，覆盖 Qwen、Gemma、DeepSeek、GLM、GPT、Claude、Gemini，以及不同参数规模。

对比对象包括上述提示词方法和四类记忆瓶颈设置。每个模型配置在每个“主题×条件”单元采样50次：

- **800次材料级试验/配置**；
- 每次回答5题，即约 **4,000条题目回答/配置**。

注意：模型读取文本转录，而人类接收音频，两者输入模态并不相同。

## 6. 主要结论与发现

### 6.1 人类呈现稳定的重复与干扰效应

- 总体完全正确率：**46.7%**，95%置信区间为 **44.4%～49.1%**。
- 重复一次带来约 **10.6个百分点**的准确率提升。
- 干扰使准确率下降约 **5.2个百分点**。
- 重复主要提高对真实陈述的选择率：**63% → 73%**。
- 干扰主要提高对错误陈述的选择率：**10.9% → 14.4%**。
- 不同条件下，人类对题目难度的排序较稳定；SayOnce 与 SayTwice 的 Spearman 相关为 **0.88**。

### 6.2 提示“像人一样”不足以产生人类式记忆

完整原文始终可见时，模型通常：

- 准确率明显高于人类；
- 几乎没有重复收益；
- 几乎不受干扰影响。

记忆瓶颈能降低准确率，部分配置也能接近人类的条件效应，但许多配置的干扰代价过大。

### 6.3 总分接近不等于逐题行为接近

没有模拟器达到人类内部的逐题一致性水平。逐题一致性与总体准确率之间仅存在较弱相关，论文报告 **r = 0.31**。

尤其是 CBUS + Dropout：它可以接近人类总分和条件效应，却仍不能很好地复现哪些问题更难。这说明粗粒度指标不足以验证模拟器的真实性。

### 6.4 关键差异：模型更像“忘了”，人类还会“记错”

- 多数模型很少选择错误陈述，主要错误是漏选真实陈述，或误选“以上皆非”。
- 人类除了漏选，还会认可合理但错误的信息。
- 干扰条件下，人类错误选项的选择增加；典型模型主要表现为真实选项的选择减少。

因此，相似的准确率下降，可能对应完全不同的错误生成过程。

### 6.5 更大模型不一定更像人

- 大模型往往过于准确，且极少认可错误陈述。
- **约2～7B参数模型**在本任务中的逐题错误模式通常更接近人类。
- 这不意味着小模型具有更真实的记忆机制，只说明其行为在当前基准上更相似。

## 7. 优点与亮点

- **评价目标清晰**：将“模拟人类”与“提高任务正确率”明确区分。
- **多层评价有说服力**：揭示平均分、效应幅度和逐题行为之间可能脱节。
- **结合认知心理学操纵**：重复和竞争信息比单纯控制上下文长度更具解释性。
- **随机丢弃基线关键**：表明粗粒度人类相似性可能由简单随机机制产生，避免高估复杂记忆策略。
- **错误分析具体**：区分遗漏与错误认可，为改进模拟器提供明确方向。
- **提供挑战基准**：论文提出开放材料、音频、问题和去标识化的人类回答；伦理部分说明拟采用 CC BY 4.0 许可。

## 8. 不足与局限

### 8.1 输入模态混杂
人类听陌生名称，模型直接读取拼写。逐题难度差异可能部分来自语音识别、音形转换与文本阅读差异，不能全部归因于记忆机制。

### 8.2 条件操纵不完全纯粹
- SayOnce 的填充内容在 SayTwice 中被重复信息替代，因此收益可能同时来自“增加重复”和“减少无关负担”。
- Interfere 同时增加长度、处理负担和竞争信息，不能完全分离各自贡献。
- 部分第三次表述包含新增信息，并非严格等义重复。

### 8.3 材料与人群有限
仅20道不同题目，难以稳健分析题目级条件效应、选项特征和个体差异。样本也仅覆盖美国成年平台用户，不能直接推广到儿童、非母语听者或其他文化群体。

### 8.4 场景外推有限
实验是单次材料暴露后的即时测试，尚未覆盖：

- 长时间延迟后的保持；
- 多轮对话和动态更新；
- 间隔重复；
- 真实教学或助手交互中的策略效果。

### 8.5 行为发现不等于机制证明
“模型遗忘、人类误记”是对本实验错误模式的有效概括，但并未直接识别人类错误记忆的认知机制。论文也没有提出并验证能解决该问题的新模拟器。

**总体评价：这篇论文最重要的贡献，是说明用户模拟器的可信度不能只靠总分校准；还必须检验它是否会在相同信息上，以相似方式发生遗漏、混淆和错误认可。**
