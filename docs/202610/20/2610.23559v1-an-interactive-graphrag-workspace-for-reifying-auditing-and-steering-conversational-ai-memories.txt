# An Interactive GraphRAG Workspace for Reifying, Auditing, and Steering Conversational AI Memories 

Munshi Md Arafat Hussain ∗, Md. Abdur Rahman †, and Md Saeed Siddik ‡∗‡ Institute of Information Technology, †Centre for Advanced Research in Sciences University of Dhaka, Dhaka, Bangladesh Email: ∗bsse1435@iit.du.ac.bd, †mukul.arahman@gmail.com, ‡saeed.siddik@iit.du.ac.bd 

Abstract —Conversational Large Language Models (LLMs) are widely employed in software engineering for code generation, debugging, and architectural design. However, as developers engage in multi-session development tasks, technical knowledge becomes siloed in isolated, linear chat histories. Reusing context across sessions leads to three critical challenges: (1) flat-vector retrieval fails to traverse multi-hop relational dependencies between distant architectural decisions; (2) temporal drift in software packages and APIs results in silent context poisoning when reusing aged dialogue logs; and (3) raw conversation concatenation induces prompt bloat and attention degradation. We present COGNITIVE CANVAS , an interactive tool that transforms conversational AI memories from ephemeral text logs into persistent, manipulable, and audited knowledge objects. COGNITIVE CANVAS integrates: (1) a Hierarchical Semantic Fact-Graph (HSFG) that distills dialogues into Goal, Fact, and Code artifacts, achieving a 92.2% token reduction while enabling multi-hop GraphRAG traversal; (2) a Continuous Temporal Drift Auditor coupling 60+ regex heuristics with live calendar-anchored LLM verification for 1-click self-correction; and (3) a Spatial-Symbolic Prompt Compiler (SSPC) that translates 2D direct manipulation gestures (Voronoi clustering, node resizing, synthesis edges) directly into structured attention directives. 

Index Terms —Conversational AI Memory, GraphRAG, Tem-poral Drift, Spatial Direct Manipulation, Prompt Compilation 

I. I NTRODUCTION 

Modern software development increasingly relies on con-versational Large Language Models (LLMs) to accelerate implementation, debug complex stack traces, and explore architectural trade-offs [1], [2]. However, current commercial interfaces (e.g., ChatGPT, Claude, Gemini) remain funda-mentally bound to the ephemeral linear session paradigm 

[3]. Each conversation operates as an isolated silo. When developers attempt to transfer insights formulated during prior problem-solving sessions (such as custom database pooling logic or token validation middleware) into a new task, they encounter three structural bottlenecks: 1) Context Fragmentation across Siloed Sessions :Knowledge generated across multiple sessions is scat-tered across unsearchable chat sidebars, forcing devel-opers into tedious copy-pasting and repetitive prompt re-framing. 2) Silent Context Poisoning via Temporal Drift : Soft-ware libraries, APIs, and framework conventions mutate rapidly [9], [10]. When reusing conversational context saved months earlier, LLMs blindly accept obsolete con-figurations and deprecated syntax, producing confident code hallucinations [7], [8]. 3) Lack of Spatial Steerability : Standard Retrieval-Augmented Generation (RAG) frameworks [4], [5] in-ject text chunks invisibly into system prompts with-out providing developers visual inspection or steering mechanisms to control which constraints the model emphasizes. To bridge the gap between conversational LLM assistance and cumulative software engineering workflows, we present COGNITIVE CANVAS . C OGNITIVE CANVAS reifies conversa-tional memory into an interactive 2D workspace, externalizing context onto a manipulable canvas while underpinning gener-ation with a property-graph neuro-symbolic backend. The tool demonstration showcases three major contributions:  

> •

Hierarchical Semantic Fact-Graph (HSFG) &GraphRAG : We decompose conversational sessions into structured Goal vectors, Fact triples, and exact Code state artifacts, slashing prompt token overhead by 92.2% 

while enabling multi-hop associative traversal across distant development sessions.  

> •

Continuous Temporal Drift Auditor : We implement a dual-stage auditing pipeline (60+ fast regex heuristics + calendar-anchored LLM verifier) that proactively flags stale technical context with a Stale badge and enables 1-click self-correction.  

> •

Spatial-Symbolic Prompt Compiler (SSPC) : We formulate a mathematical compiler that translates direct visual gestures (node surface area resizing, centroid proximity, and synthesis edge links) into machine-interpretable prompt attention tiers (HIGHLIGHT ,

GROUP , OBSCURE ). II. T OOL OVERVIEW AND ARCHITECTURE

A. Developer Sensemaking Interface 

The frontend provides an expansive 2D visual canvas built with hardware-accelerated SVG rendering. Developers orga-nize past conversation episodes represented as visual cards. B. Hierarchical Semantic Fact-Graph (HSFG) Distillation 

Rather than storing verbose, conversational pleasantries or collapsed lossy summaries, C OGNITIVE CANVAS decomposes each ingested session into a tripartite entity: HSFG (M ) = ⟨G , F, A⟩ (1) where G represents the developer’s goal and active block-ers; F comprises formal entity-relationship fact triples (e.g., 

(:FastAPI)-[:USES]->(:AsyncSession) ); and A

stores verbatim, executable code artifacts (schemas, API routes, configurations) preserved with 100% token syntax fidelity. As demonstrated in our formal compression benchmarks, a representative 10-turn debugging dialogue containing 5,210 raw tokens is distilled into: Tokens (HSFG ) = 45( G) + 120( F) + 240( A) = 405 tokens (2) achieving a 92.2% token reduction while maintaining exact code reproducibility. 

C. Continuous Temporal Drift Auditor 

To prevent context poisoning, C OGNITIVE CANVAS mon-itors technical memories using a domain-calibrated hazard function: 

V (Mi, t now ) = exp ( −λd · max(0 , t now − tanchor − δd)) ·(1 −Φ( Mi)) 

(3) where λsoftware = 0 .015 day −1, δd is a 90-day grace period, and Φ ∈ [0 , 1] is the drift probability. The auditing engine operates in two stages: 1) Stage 1 (High-Speed Regex Screening) : Evaluates 60+ precompiled patterns for semantic versioning (v\d+ \.\d+ ), deprecation keywords ( deprecated , sun-set , breaking changes ), and temporal markers ( currently ,

as of ). Executes in ∼ 0.02 ms at zero token cost. 2) Stage 2 (LLM-as-a-Judge Verification) : If Stage 1 triggers, the model is queried with current calendar grounding tnow . If verified as outdated, the memory is flagged with a Stale badge, accompanied by the depre-cation rationale and a 1-click self-correction button that refactors the code to modern conventions and updates the knowledge graph in place. 

D. Spatial-Symbolic Prompt Compiler (SSPC) 

The SSPC bridges visual canvas manipulation with LLM attention mechanics. For each active memory card Mi, the compiler calculates an importance weight W (Mi):

W (Mi) = 0 .5· Area (Mi)

(4) where Area base = 160 × 160 px, D is the Euclidean distance to the canvas centroid C, and Deg is the count of incident semantic edges. Memories are compiled into explicit prompt directives:  

> •

HIGHLIGHT_CONTEXT (W ≥ 1.75 ): Injected as adominant architectural constraint.  

> •

STANDARD_CONTEXT (0.65 < W < 1.75 ): Standard grounding context.

OBSCURE_CONTEXT (W ≤ 0.65 ): Background nuance only.

GROUP_CONTEXT (Edge-connected nodes): Enforces cohesive cross-memory synthesis in shared response sen-tences. III. A N ILLUSTRATING USAGE SCENARIO

V ALIDATION AND EVIDENCE 

A. Empirical Validation with Practitioners 

To assess the effectiveness of COGNITIVE CANVAS , we conducted a controlled within-subject laboratory study with 24 software practitioners (12 full-stack engineers, 6 researchers, 6 system designers; aged 22–38) across three realistic knowledge tasks: full-stack architecture refactoring, scientific synthesis, and logistic planning. We evaluated three conditions in a Latin square coun-terbalanced design: (1) Commercial Baseline (linear multi-turn chat with search history); (2) Flat-Vector RAG (dense passage retrieval without graph traversal or auditing); and (3) 

COGNITIVE CANVAS (our full proposed system). As summarized in Table I, C OGNITIVE CANVAS reduced temporal hallucinations from 28.7% to 4.2% (p < 0.0001 ), decreased cognitive workload (NASA-TLX) from 68.4 to 32.6 

(p < 0.0001 ), and accelerated task completion time to 13.8 minutes (a 34.9% speedup over flat RAG). 

B. Limitations 

Current limitations include: (1) Stage 2 temporal verification latency (600–1200 ms); and (2) lack of direct visual AST ren-dering inside cards. Background pre-auditing and embedded syntax highlighting represent active future work. V. A VAILABILITY 

COGNITIVE CANVAS is open-source and publicly available for research and industrial practice.
