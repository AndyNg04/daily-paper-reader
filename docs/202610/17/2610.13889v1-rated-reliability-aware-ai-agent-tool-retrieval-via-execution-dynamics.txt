## Abstract 

As AI agents increasingly rely on external tools, accurate retrieval is essential for reliable behavior. Existing methods optimize seman-tic relevance but largely ignore tool availability during execution. To address this gap, we propose RATED (Reliability-Aware Tool retrieval via Execution Dynamics), a retrieval framework that com-bines robust semantic matching with dynamic reliability adaptation. RATED employs a frozen dual-encoder with contrastive fine-tuning for semantic matching, and a lightweight contextual bandit module that re-ranks candidates based on real-time execution feedback. This design enables rapid adaptation to runtime tool failures with-out expensive model retraining. We introduce EcoAgent , a bench-mark of 5,172 real-world tools and over 210,000 query–tool pairs for offline retrieval and dynamic reliability evaluation. Experimental results demonstrate that RATED achieves a 52.2% relative MRR im-provement over the ToolLLM API retriever on real-world queries, and reduces fault selection rate from 86.2% to 2.9% under severe API outage scenarios with a 30% failure rate, while incurring negligible latency overhead of less than 1 ms over encode-only inference. Code and dataset are available at https://github.com/Elliotes/EcoAgent.

The fundamental bottleneck for these systems has shifted from text generation to accurately identifying and retrieving the correct entry from vast, growing tool repositories [19]. To address the tool retrieval challenge, existing research has focused on optimizing se-mantic relevance for Large Language Models (LLMs). Foundational works like ToolLLM [21] and ToolExpNet [30] treat tool retrieval as a static ranking task. They use dense retrieval or experience networks to map queries to tool documentation based entirely on semantic relevance. While approaches such as TRFeedback [29] and ToolRL [20] incorporate execution feedback, they still aim to optimize how the LLM plans and invokes tools in a static environ-ment. However, real AI agent tool ecosystems are far from static and highly unreliable. We crawl tool catalogs from LangChain [8], CrewAI [4], LlamaIndex [14], and n8n [16] to reveal the severity of this issue. As Figure 1 shows, despite rapid growth, over 50% of these tools exhibit critical flaws like broken links and missing authentication. Many tools are functionally similar, so retrieval cannot rely on semantics alone to identify which ones will execute successfully. To overcome this challenge, the system must adapt dynamically during execution. When a tool fails at runtime, the system must promptly adjust candidate ordering between requests. ToolRL cannot achieve this prompt adjustment because it uses Group Relative Policy Optimization (GRPO) [25] to update the LLM from batched trajectories and still targets the planner. Contextual bandits [11] effectively address this problem. They condition each decision on the current query and update from each individual execution outcome. Moreover, they observe feedback only for the selected tool and make immediate adjustments without retraining the semantic retriever. In this paper, we propose RATED (Reliability-Aware Tool re-trieval via Execution Dynamics), a retrieval framework that dynam-ically adapts to runtime tool failures without human intervention. First, we introduce EcoAgent , a benchmark of 5,172 real-world agent tools and over 210,000 query–tool pairs. Second, RATED em-ploys a dual-encoder fine-tuned with a contrastive objective for arXiv:2610.13889v1 [cs.AI] 9 Oct 2026 CIKM ’26, November 07–11, 2026, Rome, Italy Weiliang Chen and Song Liao

## 2 The EcoAgent Benchmark 

We construct EcoAgent, a benchmark comprising two complemen-tary datasets. EcoAgent complements existing tool-use datasets with metadata reliability scores for every tool and with an evalua-tion protocol for injected execution failures. EcoAgent-Syn supports robust training with synthetic pairs, and EcoAgent-Real supports rigorous evaluation using real-world queries. We aggregate 5,172 real-world tool definitions from four open-source AI agent plat-forms, namely LangChain, CrewAI, LlamaIndex, and n8n. Metadata are normalized into a shared schema with functional descriptions, names, endpoints, and authentication fields, which supports re-trieval text construction and reliability scoring. To operationalize tool quality, each tool receives an automated metadata reliabil-ity score between 0 and 1 from three weighted signals, namely name–description consistency, source credibility, and documenta-tion quality, which Section 3.3 defines. The benchmark does not rely on manual per-tool ratings. Tools with scores of at least 0.8 are marked as reliable, identifying 2,940 tools, or 56.8% of the repository. The encoder is trained only on EcoAgent-Syn, while retrieval and dynamic experiment results are validated on the EcoAgent-Real test split, with hyperparameters selected on the validation split. We build EcoAgent-Syn with Gemma-3-1b [7]. For each tool, the model receives the tool name, functional description, and metadata as context and generates 10–20 task-oriented queries. Queries are restricted to 5–120 words, and near-duplicates with Jaccard simi-larity above 0.7 are removed to preserve intent diversity. Figure 2 shows the prompt template, which we also release with the dataset. To improve robustness against spurious correlations, each query is paired with hard negatives from SBERT [22] retrieval and random negatives. EcoAgent-Syn links 69,501 unique synthetic queries to 5,172 ground-truth tools, with 70,122 positive pairs and 140,244 negative pairs. For evaluation under realistic language distribu-tions, we build EcoAgent-Real from ToolBench [21]. Because the original dataset lacks ground-truth mappings to our tool repository, we implement a semi-automated labeling pipeline. GTE-Large [12] retrieves the top-5 candidates per query, discards pairs with cosine similarity below 0.7, and Gemma-3-1b verifies the remainder, retain-ing only pairs with functional match scores of at least 0.85. Human experts review a stratified sample of 200 queries and agree with the LLM verifier on 94% of cases. After filtering and deduplication, EcoAgent-Real contains 6,379 unique queries and 9,946 verified query–tool pairs.

## 4.3 Baselines 

Retrieval baselines include lexical matchers TF-IDF [26] and BM25 [23], dense encoders OpenAI Ada-002 [18], BGE-M3 [3], GTE-Large [12], and E5-Large-v2 [28], and neural IR models DRAGON [13], which is not fine-tuned on EcoAgent-Syn, and SPLADE-v3 [9]. We also include a BGE-Reranker-v2-m3 [3] cross-encoder that re-ranks DRAGON top-50 candidates, and the ToolLLM API retriever [21]. For dynamic evaluation, two reactive baselines share the DRAGON ranker: Health Check Blacklist permanently excludes any tool after one failed execution, and Retry (𝑘 =3) tries up to three candidates within one step and keeps no memory across steps. A batch GRPO proxy similar to ToolRL [25] updates weights periodically rather than online. RATED uses DRAGON fine-tuned on EcoAgent-Syn as the backbone and is evaluated as RATED (Full), RATED (w/o Contrastive), RATED (w/o Feedback), and RATED (w/ Global MAB).

Table 1 reports offline retrieval on EcoAgent-Syn and the held-out EcoAgent-Real test split. RATED (Full) ranks first on Syn across all metrics, and RATED (w/o Contrastive) matches pretrained DRAGON on both benchmarks, which isolates the gain from contrastive fine-tuning. High offline ranking accuracy on real queries therefore does not guarantee robust tool selection when tools fail at runtime. We therefore select 𝑤 1 = 0.75 and 𝑤 3 = 0.10 on the validation split, which trades about one point of FSR for the highest Post-Fail SR. Panel (b) varies 𝛾 and 𝛼 with fusion weights fixed at the validated setting. Post-Fail SR is highest at 𝛾 = 0.95, where the three 𝛼 curves nearly coincide, and FSR again grows slowly with 𝛾 .We therefore set 𝛾 = 0.95 and 𝛼 = 0.1 on the validation split. 

## 4.6 Efficiency Analysis 

We profile end-to-end inference at batch size 1 on the same hard-ware as Section 4. Table 3 reports average latency, P95 latency, and incremental overhead relative to DRAGON encoding only. The encode-only baseline averages 3.223 ms. RATED (w/o Feedback) ap-plies only the static reliability prior in Eq. 5 and adds 0.025 ms. Con-textual bandit re-ranking incurs modest additional cost. RATED (w/ Global MAB) adds 0.108 ms, and RATED (Full) adds 0.172 ms, reach-ing 3.395 ms average and 4.391 ms P95 latency. These overheads are far below batch GRPO updates similar to ToolRL at 17.839 ms average, which require periodic policy synchronization. Therefore, RATED is fast enough for interactive agent loops and still reduces fault selection.
