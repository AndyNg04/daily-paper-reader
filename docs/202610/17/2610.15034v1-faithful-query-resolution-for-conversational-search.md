## 摘要
对话式查询改写会将依赖上下文的请求显式化，以便进行检索；但额外的上下文也可能引入用户未曾表达的信息需求。这引出了一个问题：查询忠实度与检索广度之间如何相互作用。本文以 iKAT SCAI 2026 为评测场景，考察行为自适应对话式搜索中的这种相互作用。我们在采用 BM25 和 SPLADE 检索的行为自适应助手中，对五种查询生成配置进行了比较。最小忠实解析器保留用户的措辞，仅解析依赖上下文的指代；加权倒数排名融合则将其排序结果与学习式改写器及原始话语的排序结果相结合。离线评测表明，与仅使用忠实查询相比，加入这些查询形式能够提升召回率，但 nDCG@10 略有下降。在我们提交的五种 iKAT SCAI 2026 方案中，加权配置取得了最高的平均检索得分，nDCG@5 达到 0.534，较最强的替代方案相对提升 5.3%。然而，这一检索优势并未对应最高的对话满意度得分。这些发现表明，有必要将忠实的查询理解与检索扩展区分开来，并分别评估二者对对话效用的影响。

## Abstract
Conversational query rewriting makes context-dependent requests explicit for retrieval, but additional context can introduce an information need the user did not express. This raises a question about the interaction between query fidelity and retrieval breadth. This paper examines that interaction in behavior-adaptive conversational search, using iKAT SCAI 2026 as the evaluation setting. We compare five query-generation configurations within a behavior-adaptive assistant using BM25 and SPLADE retrieval. A minimal-faithful resolver preserves the user's wording and resolves only context-dependent references; weighted reciprocal rank fusion combines its rankings with those from a learned rewriter and the raw utterance. Offline evaluation shows that adding these formulations recovers recall over the faithful query alone, with a slight reduction in nDCG@10. Across our five iKAT SCAI 2026 submissions, the weighted configuration obtains the highest mean retrieval scores, reaching nDCG@5 of 0.534, a 5.3\% relative improvement over the strongest alternative. However, this retrieval advantage does not coincide with the highest conversational satisfaction scores. These findings motivate separating faithful query interpretation from retrieval expansion, while assessing their effects on conversational utility independently.
