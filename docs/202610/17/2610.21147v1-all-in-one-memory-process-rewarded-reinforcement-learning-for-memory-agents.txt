## ABSTRACT 

Large language models increasingly rely on external memory to answer queries grounded in long-horizon histories such as multi-session dialogues and lengthy documents. However, existing memory methods often optimize retrieval and memory construction separately, without a shared reward space for evaluating search, writing, and stopping decisions. To address this, we propose All-in-

One Mem ory ( AiO-Mem ), which organizes these operations as transitions over a shared evidence state and directly evaluates the semantic quality of each ac-tion within a unified reward space. AiO-Mem compiles heterogeneous histories into source-traceable multi-view events, providing a shared substrate for retrieval and memory writing. A unified memory policy actor then rolls out complete interaction trajectories over this shared evidence state. A separate trajectory-conditioned process reward model is trained through evidence-grounded super-vised fine-tuning and trajectory-level DPO to assign process scores to the collected trajectories. These scores are aggregated into an action-balanced trajectory reward and used by Process-Aligned DAPO (PA-DAPO) to optimize the memory policy. Across long-context memory benchmarks, AiO-Mem consistently improves an-swer accuracy over both static memory systems and RL-trained memory agents. 

## 1 INTRODUCTION 

Large language models (LLMs) have achieved remarkable progress across diverse natural language processing benchmarks (OpenAI, 2023; Touvron et al., 2023). Yet in long-context, multi-step rea-soning scenarios, their static parametric knowledge and limited context windows remain critical bottlenecks (Liu et al., 2024). External memory-augmented architectures have therefore become important extensions of LLMs, ranging from dense retrieval systems (Lewis et al., 2020; Guu et al., 2020) and knowledge-graph memories (Edge et al., 2024) to persistent memory agents (Packer et al., 2023; Chhikara et al., 2025). Such systems rely on tightly coupled memory retrieval and mem-ory construction: retrieval supplies relevant evidence, while construction converts it into compact working memory. Coordinating these stages is challenging because the evolving memory state continually changes what evidence should be searched for, written, or discarded .Recent studies have introduced reinforcement learning (RL) into memory systems to enable self-improving memory behavior. As illustrated in Figure 1, existing RL-driven memory systems are typically optimized along two separate routes: retrieval-oriented methods, such as Search-R1 (Jin et al., 2025), learn how to search for evidence, while construction-oriented methods, such as Mem-α

(Wang et al., 2025), learn when to insert, update, or merge memory entries. However, these methods still optimize retrieval and construction in isolation, leaving the two stages governed by separate objectives and evaluated through partially disconnected feedback signals. This separation exposes two key limitations. First, there is no shared evidence-state space in which retrieved evidence, written memories, and stopping decisions can be jointly evaluated, making it difficult to coordinate whether the system should continue searching, write a memory, skip redundant information, or stop. Second, existing supervision is largely outcome-centered: it assigns rewards to the final answer but provides little process-level credit for the intermediate memory operations that produced it. As a result, trajectories with the same final-answer score may still differ substantially in evidence relevance, memory faithfulness, redundancy control, and stopping sufficiency; answer correctness alone cannot reliably evaluate the semantic quality of memory operations.

To overcome these limitations, we propose All-in-One Mem ory ( AiO-Mem ), which unifies mem-ory retrieval and construction as evidence-state transitions of a single memory-interaction agent, and uses a separate trajectory-conditioned reward model to evaluate the resulting trajectories. AiO-Mem first compiles heterogeneous histories into a traceable multi-view event bank, providing a shared source-grounded substrate for retrieval and memory writing. Built on this event bank, the mem-ory policy actor operates over a shared evidence state and rolls out complete interaction trajectories through two sequential decision steps: decide , which determines whether to continue searching or stop, and extract , which determines whether retrieved candidates should be written into working memory or discarded. A unified process reward model is then trained through evidence-grounded SFT and trajectory-level DPO to assign process scores to each action in the collected trajectories, using rule-derived supervision and reasoning-model scores as complementary training signals. Fi-nally, these process scores are aggregated into an action-balanced trajectory reward. Building on DAPO (Yu et al., 2026b), we propose Process-Aligned DAPO (PA-DAPO) to optimize the memory policy actor. We summarize our primary contributions as follows: • We propose AiO-Mem , an all-in-one memory agent that unifies retrieval, writing, filtering, and termination within a single evidence-state transition loop. This formulation turns memory re-trieval and construction from separately optimized modules into one jointly trainable policy over source-traceable evidence. • We introduce a trajectory-conditioned unified reward model that directly assesses the semantic quality of each memory action within a shared evidence state, scoring search, add, skip, and stop in a common reward space. Action-balanced aggregation then converts these scores into a trajectory reward for memory-policy optimization with our proposed PA-DAPO. • We conduct extensive experiments on long-context memory benchmarks, where AiO-Mem con-sistently improves both answer accuracy and reasoning faithfulness over static memory systems and RL-trained memory agents. 

## 2 RELATED WORK 

Memory-Augmented Large Language Models. External memory equips LLMs with non-parametric knowledge beyond their context windows. Early retrieval-augmented models, such as RAG (Lewis et al., 2020) and REALM (Guu et al., 2020) established dense retrieval as a standard way to ground generation in external evidence. These systems provide increasingly rich retrieval and construction mechanisms, but most coordinate mem-ory operations through predefined workflows, hand-designed heuristics, or modular pipelines rather than a learned policy that jointly optimizes retrieval, writing, filtering, and termination. 

Reinforcement Learning for Memory Policies. Recent work has applied RL to memory systems at different stages of the pipeline. Retrieval-oriented methods, including Search-R1 (Jin et al., 2025), R1-Searcher (Song et al., 2025), and DeepRetrieval (Jiang et al., 2025b), learn search or retrieval strategies that improve downstream answers. Persistent-memory methods, such as Memory-R1 (Yan et al., 2026), Mem-α (Wang et al., 2025), and AtomMem (Huo et al., 2026), optimize memory insertion, update, merging, or atomic memory management. More recent studies, including Fine-Mem (Ma et al., 2026), TRUSTMEM (Yang et al., 2026), and Mem-T (Yue et al., 2026)), move toward process-level supervision for memory use. Despite this progress, most RL-based memory methods either rely primarily on final-answer correctness or provide process feedback within a re-stricted stage of the memory pipeline. As a result, they do not directly evaluate heterogeneous mem-ory actions within a shared evidence state and a common reward space. AiO-Mem addresses this gap by learning a trajectory-conditioned reward model that assigns process-level semantic scores to different memory actions and uses them to optimize a unified memory policy. 

## 3 METHOD 

3.1 PROBLEM FORMULATION AND METHOD OVERVIEW 

Problem Formulation. We study memory-augmented question answering (QA) over long-horizon histories. Let q be a query and H = ( h1, . . . , h N ) be its associated history of N heterogeneous source units, such as dialogue sessions, document passages, or facts. Given (q, H), a memory policy constructs a compact working memory W from which a frozen downstream generator ˆy = G(q, W).The learning objective is to acquire an optimal sequence of memory operations that transforms a dispersed history into a reasoning-sufficient evidence state. 

Method Overview. As shown in Figure 2, we propose AiO-Mem , a four-component framework that trains a memory policy actor πθ to construct working memory through sequential evidence-state transitions. AiO-Mem integrates four components for memory construction, interaction modeling, process supervision, and policy optimization: (i) Traceable Multi-View Event Bank (Section 3.2), which compiles H into source-traceable event units and provides the retrieval substrate for memory interaction; (ii) Evidence-State Transition Modeling (Section 3.3), which formulates the interaction of πθ as a finite-horizon MDP over a shared evidence-state space, with four action types organized 3Work in progress. into a decide step ( search or stop ) and, after each search, an extract step ( add or skip ); (iii) Unified Reward Modeling (Section 3.4), which trains a trajectory-conditioned reward model via evidence-grounded SFT and trajectory-level DPO to provide dense per-step process supervision; and (iv) 

Process-Aligned Policy Optimization (Section 3.5), which aggregates action-typed rewards into a balanced trajectory signal and optimizes πθ through PA-DAPO. 3.2 TRACEABLE MULTI -V IEW EVENT BANK

A single retrieval pass is often insufficient when the answer depends on evidence scattered across the history. We therefore formulate memory interaction as a finite-horizon Markov Decision Process (MDP) over evidence states. The memory policy actor πθ sequentially selects memory operations and the process is specified by a state space S, an action space A, a deterministic transition function 

F, and a maximum horizon Tmax .At step t ∈ { 1, . . . , T }, the evidence state is zt = ( q, Wt, Rt) ∈ S , where q is the query, Wt is the current working memory, Rt is the latest candidate list, and mt ∈ { decide , extract } indicates the current decision mode. The memory policy actor samples an action at ∼ πθ (· | zt) under a mode-specific action mask, and ct = type( at) denotes its action type. In the decide mode, the policy chooses either search (ut), which issues a search query ut to the event bank and retrieves 

R(ut), or stop , which terminates the episode. After a search, the process enters the extract mode, where the policy chooses either add (nt), which appends a source-bound note nt to the working memory, or skip , which discards the current candidates. This constrained structure prevents invalid operations, such as adding a note before retrieval or issuing a new search before deciding whether to use the current candidates. ## 4 EXPERIMENT 

4.1 EXPERIMENTAL SETTING 

Datasets and Evaluation We evaluate AiO-Mem on three complementary memory benchmarks, including LoCoMo (Maharana et al., 2024), MemoryAgentBench (Hu et al., 2026b), and Person-aMem (Jiang et al., 2025a). LoCoMo evaluates long-range conversational memory across multi-session interactions. Following MEM-T (Yue et al., 2026), we adopt the same data configuration by splitting the LoCoMo dataset into training, validation, and test sets with a ratio of 1:1:8 to en-sure a fair comparison. MemoryAgentBench valuates memory agents under incremental multi-turn interactions across diverse tasks. Following Fine-Mem (Ma et al., 2026), we adopt the same evalu-ation scope and baselines to assess out-of-distribution generalization. PersonaMem further extends evaluation from factual memory to dynamic user profiling. More details are shown in Appendix C.1. 

Baselines. Experimental Details. We instantiate AiO-Mem with Qwen3-8B as the reward model and Qwen3-4B as the memory policy actor. BGE-M3 1 and BM25 are used for multi-view event re-trieval. For policy training, we set Kret = 10 , Tmax = 8 . For reward-model SFT, we train for 2 epochs with a batch size of 8 and a learning rate of 1×10 −4. Trajectory-level DPO is then performed for 1 epoch with a batch size of 8, a learning rate of 2 × 10 −6, and β = 0 .1. For PA-DAPO, we sample 8 trajectories per query and optimize the memory policy with a learning rate of 2 × 10 −5.More training setup and parameter configurations are listed in Appendix C.2.

LoCoMo. As shown in Table 1, , AiO-Mem achieves the strongest overall performance and consis-tently outperforms competing methods across diverse question types. The gains span both evidence-intensive reasoning and direct memory queries, reflecting a coherent improvement pattern rather than isolated advantages on specific categories. In contrast, existing memory systems exhibit more un-even performance across different reasoning demands. These results suggest that jointly modeling heterogeneous memory actions under shared evidence states and unified process supervision enables more reliable memory interaction throughout the reasoning process .

MemoryAgentBench. As shown in Figure 3, AiO-Mem achieves the strongest overall perfor-mance across MemoryAgentBench, with gains that form a consistent pattern across retrieval, test-time learning, and long-range understanding. ## 6 CONCLUSION 

Existing memory systems often optimize retrieval and memory construction separately, making it difficult to coordinate heterogeneous memory operations under a shared objective. To address this, we introduce AiO-Mem, which unifies retrieval, writing, filtering, and termination as transitions over a shared evidence state, and learns a trajectory-conditioned reward model to provide process-level supervision for memory-policy optimization. Experiments across long-context memory benchmarks show that AiO-Mem consistently outperforms both static memory systems and RL-trained mem-ory agents, with strong out-of-distribution generalization beyond conversational QA. ## B RELATED WORK 

B.1 ADDITIONAL DISCUSSION ON MEMORY -A UGMENTED LARGE LANGUAGE MODELS 

Memory-augmented language models have evolved from external retrieval toward persistent and structured memory management. Early retrieval-augmented methods, including RAG (Lewis et al., 2020) and REALM (Guu et al., 2020), introduce non -parametric knowledge through dense re-trieval, while subsequent systems such as GraphRAG (Edge et al., 2024), HippoRAG (Guti´ errez et al., 2024), KG-RAG (Sanmartin, 2024), and Emotional RAG (Huang et al., 2024) enrich retrieval with graph structures, multi-step exploration, or task-specific similarity signals. These methods pri-marily focus on improving how external evidence is accessed for a given query. Another line of work develops persistent memory across interactions. MemGPT (Packer et al., 2023), Memory-Bank (Zhong et al., 2024), and Mem0 (Chhikara et al., 2025) introduce explicit mechanisms for storing, updating, and maintaining long-term information, while MemoryOS (Kang et al., 2025) and LightMem (Fang et al., 2026) improve scalability through hierarchical storage and lightweight consolidation. More recent systems, including A-Mem (Xu et al., 2026), Zep (Rasmussen et al., 2025), EverMemOS (Hu et al., 2026a), LangMem (LangChain, 2025), and GAM (Yan et al., 2025), further explore atomic memory units, temporal structures, background consolidation, and iterative evidence gathering. These methods substantially expand the capabilities of long-term memory sys-tems in construction, organization, updating, and retrieval. However, the individual operations are still largely coordinated through predefined workflows, prompts, or heuristic rules, rather than being 

jointly optimized according to their contribution to downstream evidence acquisition .B.2 ADDITIONAL DISCUSSION ON REINFORCEMENT LEARNING FOR MEMORY POLICIES 

Reinforcement learning has increasingly been introduced to replace manually specified memory be-haviors with learned policies. Early efforts mainly focus on retrieval, where Search-R1 (Jin et al., 2025), R1-Searcher (Song et al., 2025), and DeepRetrieval (Jiang et al., 2025b) optimize multi-step search, tool invocation, or query generation through task- or retrieval-oriented rewards. Another line applies RL to recurrent memory states: MEM1 (Zhou et al., 2026) and MemAgent (Yu et al., 2026a) learn to continually compress or overwrite bounded memory representations over long contexts and propagate downstream rewards to preceding memory decisions. Persistent-memory methods such as Memory-R1 (Yan et al., 2026), Mem-α (Wang et al., 2025), and AtomMem (Huo et al., 2026) further extend the learned policy from memory construction and updating toward broader combina-tions of reading, editing, and answering. More recent work introduces finer-grained supervision to improve credit assignment across long memory-operation sequences. Fine-Mem (Ma et al., 2026) 13 Work in progress. and TRUSTMEM (Yang et al., 2026) provide localized feedback for memory construction or updat-ing through intermediate QA signals, downstream usage, or verifier-based evaluation, while keeping retrieval or reasoning largely fixed. Mem-T (Yue et al., 2026) further connects memory formation, evolution, and multi-step retrieval by evaluating retrieval trajectories and propagating later retrieval outcomes back to earlier construction decisions. These methods move toward process-aware mem-ory optimization, but their process feedback typically targets specific memory stages or estimates the contribution of earlier actions from later outcomes. In contrast, AiO-Mem unifies memory in-teractions as transitions over a shared evidence state and uses a trajectory-conditioned reward model to directly assess the semantic quality of each memory action in a unified reward space, enabling coordinated optimization of retrieval and construction .

## C EXPERIMENT DETAILS 

C.1 DATASETS AND BASELINES 

Datasets The LoCoMo dataset (Maharana et al., 2024) targets the evaluation of long-range conversational memory. It features extremely long dialogues, with each conversation spanning roughly 300 turns and around 9K tokens on average. The accompanying questions cover four categories—Single-hop, Multi-hop, Temporal, and Open-domain—capturing different aspects of memory and reasoning in LLMs. Following the evaluation setup of previous work, we report F1 and BLEU-1 (B1) scores for each category as well as the overall performance. 

MemoryAgentBench (Hu et al., 2026b) targets the evaluation of memory agents under in-cremental, multi-turn interactions. In our experiments, we evaluate three memory capabilities— Accurate Retrieval, Test-Time Learning, and Long-Range Understanding—using nine tasks from the benchmark. The selected tasks include SH-Doc QA (SH-Doc), MH-Doc QA (MH-Doc), Long-MemEval (LME(S)), TREC Coarse (TREC-C), NLU, TREC Fine (TREC-F), CLINC150 (CLINC), BANKING77 (Banking), and ∞Bench-Sum (InfBench). 

The PersonaMem benchmark (Jiang et al., 2025a) targets the evaluation of dynamic user pro-filing and personalized response generation over long-term user–LLM interactions. Unlike fac-tual memory benchmarks that primarily focus on retrieving explicitly stated information from past interactions, PersonaMem emphasizes user-profile memory, requiring models to infer, maintain, and update users’ preferences and underlying traits over time. In our experiments, we evaluate five query types corresponding to five dimensions: Recall User-Shared Facts (Rec.), Generalize to New Sce-narios (Gen.), Track Full Preference Evolution (Evol.), Revisit Reasons Behind Preference Updates (Reason), and Provide Preference-Aligned Recommendations (Reco.). Together, these query types assess whether a memory system can recover user-specific facts, generalize learned preferences to new situations, track evolving preferences, reason about the causes of preference changes, and pro-vide recommendations aligned with the user’s current profile.

E.2 TRAJECTORY -LEVEL DPO ALIGNMENT STUDY 

Evidence-grounded SFT provides action-level supervision based on evidence coverage and prove-nance, but such rule-based signals cannot fully assess the semantic quality of an action within its trajectory context. As introduced in Section 3.4, trajectory-level DPO addresses this limitation by using full trajectory context to align the reward model with finer-grained semantic judgments. To visualize how trajectory-level DPO distinguishes trajectories beyond rule-based evidence matching, we compare four matched trajectory pairs for the same questions. Within each pair, the trajectories have identical Evidence-ID Recall and Precision but receive different scores after trajectory-level DPO alignment. Prompt template Task and input 

You are a reward model evaluator of memory trajectories. Given a complete scoreable memory trajectory, evaluate each step according to whether the required evidence was found, whether useful evidence was written into working memory, and whether retrieval stopped when the evidence was sufficient. You may use trajectory context to understand the current action, but each score must evaluate only the current step; do not evaluate the quality of the final answer model’s response. 

Input: {question }, {reference answer }, {gold evidence }, {trajectory information }, and {scoreable steps }.

Objectives by action type 

decide search : Does the query target information missing from the current notes and help locate evidence needed to answer the question? A reasonable query should not receive the lowest score solely because it failed to retrieve a match. 

extract add note : Does the action faithfully write useful, previously unsaved evidence from the latest search into the notes, and do the cited turns support the note’s content? 

extract skip : Does the latest search truly contain nothing worth writing? Skipping clearly critical evidence is a severe problem. 

decide answer from notes : Are the existing notes sufficient to support an answer when retrieval stops? 

Evidence assessment 

When judging whether the notes are sufficient, consider both their content and the original dialogue they cite. Annotated evidence indicates information needed for the question, but it is not a mechanical hit-rate scoring formula: unannotated dialogue turns may also support the answer semantically, and matching annotated turns does not automatically warrant a high score. 

Error severity Category A, high severity: Failure of the current stage’s core objective. 

Category B, high severity: Factual or attribution errors in a note, or citations that do not support key content. 

Category C, medium severity: Problems in assessing the current state or respecting stage boundaries. 

Category D, medium severity: An incomplete contribution or substantial noise in the action. 

Category E, low severity: Wording or formatting issues. 

Score ranges 90–100: The action fulfills the stage’s core objective very well, with at most minor Category E issues. 

75–89: The action is clearly useful and largely fulfills the core objective; it has no Category A or B issues, though minor Category C, D, or E issues are allowed. 

60–74: The action makes a partial contribution but falls short of the core objective; it has no Category A or B issues, though Category C or D issues are more pronounced. 

40–59: The action has a severe problem but retains some useful contribution; it typically contains one Category A or B issue. 

1–39: The action provides almost no useful contribution or takes a clearly wrong direction; severe problems cause the current step to largely fail.
