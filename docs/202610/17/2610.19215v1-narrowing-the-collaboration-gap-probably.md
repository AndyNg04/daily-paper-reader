## 摘要
大型语言模型正日益以智能体团队的形式部署，这些智能体各自掌握有关同一任务的不同私有信息。此类智能体应如何简洁地沟通，才能促进与决策相关的信息汇总？如果只交流拟采取的行动，可能会丢失与决策相关的不确定性：两个智能体可能偏好同一行动，却有着不同的理由。我们研究了一种替代性交互方式，即由智能体交流对各项行动的校准信念。首先，我们分析了一个简单的合成场景，用以刻画部分信息条件下多轮推理的结构。在这一场景中，我们通过理论分析和实证结果表明，交流无偏概率在能力上可以严格优于交流行动。随后，我们在协作式迷宫求解任务中，使用经训练的 Transformer 和预训练大语言模型智能体检验了同一原理。结果表明，当交流的预测保留了经过校准的不确定性时，概率交流优于行动交流。当交流的概率存在偏差时，我们发现概率交流的优势可能消失。我们提出了一种事后对话校准干预方法，通过纠正这些偏差，持续改善玩具 Transformer 场景中的决策表现；预训练大语言模型在上下文中使用这些校正信息时，决策表现也得到提升。这些结果表明，概率交流之所以有助于多智能体协作，并不只是因为它传递了更多信息，还因为经过校准的不确定性为其他智能体提供了可靠的更新依据。

## Abstract
Large language models are increasingly deployed as teams of agents that hold different private information about a shared task. How should such agents concisely communicate in a way that promotes aggregation of decision-relevant information? Communicating only proposed actions can discard decision-relevant uncertainty: two agents may prefer the same action for different reasons. We study an alternative interface in which agents communicate calibrated beliefs over actions. We first analyze a simple synthetic setting that captures the structure of multi-round reasoning under partial information. In this setting, we show theoretically and empirically that communicating unbiased probabilities can be strictly more powerful than communicating actions. We then test the same principle in a collaborative maze-solving task with trained transformers and pretrained LLM agents. Our results demonstrate that probability communication outperforms action communication when the exchanged predictions preserve calibrated uncertainty. When communicated probabilities are biased, we show that the benefits of probability communication can disappear. We give a post-hoc conversational calibration intervention that consistently improves decision-making by correcting these biases both in a toy transformer setting and when pretrained LLMs use the corrections in context. These results suggest that probabilistic communication is useful for multi-agent collaboration not merely because it transmits more information, but because calibrated uncertainty gives other agents a reliable object to update on.

## 2. 方法论：核心思想、理论与算法

### 2.1 两类通信协议

两个智能体 Alice 和 Bob 分别观察任务的一部分信息，交替交流，共进行 \(K\) 轮。

- **动作交流**：每轮只发送当前认为最可能正确的动作。
- **概率交流**：每轮发送各动作正确的概率分布。
- 最终执行最后一轮预测概率最大的动作。

预训练 LLM 的概率通过两种方式获得：
- **口头报告概率**：模型直接在文本中输出概率向量。
- **采样概率**：独立生成多次回答，用动作出现频率估计概率分布。

### 2.2 从单体校准到对话校准

论文区分三个层次：

- **校准**：在所有报告某个概率分布的样本中，真实动作频率应与该分布一致。
- **交叉校准**：进一步考虑另一智能体的预测后，当前预测仍然可靠。
- **对话校准**：首轮满足校准，此后每一轮的预测都相对于上一轮消息满足交叉校准。

关键区别是：**单个模型总体上校准，不代表其在接收到伙伴预测后仍然校准。** 这里的条件仅涉及交流的概率，并不包括另一方完整的私有观测。

### 2.3 链式奇偶任务：证明概率可以严格优于动作

作者构造一个合成任务：
- 两个智能体分别观察一串随机比特中的奇数位和偶数位。
- 正确动作是一个随机二元标签，其概率由多个“前缀奇偶积”的加权和决定。
- 每个中间状态都依赖前面的状态及一个新比特，模拟逐步整合证据的推理链。

在不同前缀对应不同概率值的条件下：
- 上一轮概率能编码已聚合的前缀信息；
- 当前智能体结合自身的新比特，每轮推进一步；
- \(K\) 轮后恢复完整信息下的最优后验概率；
- 每轮平方预测损失的下降量可精确表示为相应权重的平方。

相比之下，在论文给定的权重条件下：
- 每一轮的最优动作都只反映第一个比特；
- 动作交流不断重复同一建议，无法继续传递后续证据；
- 在一个三比特实例中，最终动作与完整信息下的最优动作有 **25% 的不一致概率**。这不等于标签准确率下降了25个百分点。

### 2.4 概率偏差与事后对话校准

论文用两类失真建模不可靠的概率报告：
- **置信度缩放**：过度自信或信心不足。
- **迎合式锚定**：报告受到上一位智能体预测的额外牵引，而不只是自身证据的影响。

解决方案是逐轮学习校准器：

1. 当前智能体根据自身观测和上一轮校准消息生成原始概率。
2. 将“当前原始概率＋上一轮校准概率”输入校准器。
3. 使用真实动作标签，通过交叉熵等严格适当损失训练校准器。
4. 将修正后的概率发送给下一智能体。
5. 按轮重复，得到每轮对应的校准映射。

理论上，如果失真在给定上一轮消息后仍然可逆、模型容量充足且达到总体最优，校准器可以恢复理想后验。**这不是任意失真下的恢复保证：已经丢失的信息无法仅靠校准重新创造。**

## 6. 主要结论与发现

- **动作交流可能过度压缩证据。** 相同最优动作背后的不同后验状态，对后续信息整合可能至关重要。
- **理想概率交流可以逐轮聚合信息。** 在链式奇偶模型中，它能达到完整信息下的贝叶斯预测水平。
- **概率表达本身并不足够。** 原始口头概率在多个 LLM 上与动作交流相近，甚至更差。
- **事后对话校准稳定改善所测模型。** 作者报告，四轮后各模型的平均迷宫成功率相对原始口头概率协议至少翻倍，但最终表现仍有较大提升空间。
- **校准器有时主要是在修正动作先验。** GPT-5.4-nano 上简单稀有动作修正与校准器相近；GPT-5 上校准器则表现出超出该基线的收益。
- **采样概率不必然可靠。** 它估计的是模型回答分布，而不是正确答案的真实概率；模型稳定地犯错时，多次采样仍可能高度自信。
- **更多文本不一定带来更好协作。** 在所测两个模型与提示设置中，完整回答交流成功率接近零，而校准概率交流更有效。这不能外推为自然语言交流普遍无效。
- **校准不等于信息充分或任务解决。** 如果原始消息缺乏有效证据，或接收模型不会利用概率，校准的作用仍然有限。

## 8. 不足与局限

### 理论边界
- 严格分离依赖特定任务结构和权重条件，不是一般任务中概率协议必胜的证明。
- 概率消息能恢复全部前缀，依赖不同前缀对应不同精确数值。**低维实数不等于固定比特带宽**；量化、舍入或噪声可能破坏可解码性。
- 动作基线要求每轮诚实报告当前最优动作，不允许用动作序列设计任意编码协议，因此不是对所有离散通信方式的下界。
- 校准恢复定理依赖可逆失真、充分表达能力和总体最优；有限数据下并无同等强度保证。
- 对话校准本身不能保证恢复全部私有信息，也不能保证达到全信息最优决策。

### 实验与统计限制
- 仅研究两个智能体，未验证多智能体网络、异构模型或长程协作。
- 迷宫是小规模、唯一解、固定起终点的合成环境，不能直接代表编码、科研或机器人任务。
- 数据中向下或向右占正确动作的约97%，先验偏差明显，削弱了部分收益作为“深层协作能力提升”的解释。
- 校准损失采用当前与上一轮概率的联合分箱，样本较少时可能出现稀疏分箱；附录中该指标第二个等式的归一化写法也值得复核。
- 校准损失降低与成功率提高共同出现，支持作者解释，但尚不能完全证明提升仅由校准而非其他监督学习效应造成。

### 应用限制
- 需要任务相关标注数据，遇到新任务、模型更新或分布漂移时可能需要重新校准。
- 未充分研究提示敏感性、代理间信任、恶意消息或不可靠伙伴。
- 仅交换动作概率适合动作空间较小的决策任务；复杂开放式任务如何定义和传递概率仍不明确。

**总体评价：这篇论文有力说明了“可可靠解释的不确定性”是多智能体通信的重要设计目标；但目前更适合被视为一个理论上有条件成立、在受控场景中得到支持的设计原则，而非通用协作方案。**

（完）
