# How Should a Camera-First AI Agent Work? 

Xiaofan Wu, Xi Zeng, Miaoxia Chen, Peishan Chen, Shuyan Li, Chen Wang, Jiyun Yao, Hanyong Zhong, Jiahao Zhu Chance AI 

xiaofan@chance.vision (corresponding author) 

Abstract 

Camera-first agents must act on the visual world as it unfolds. We argue that the central obstacle for future vision-interaction systems is not recognition ability—multimodal models (vision-language and live/streaming alike) generalize well through language and remain the right tool for semantic reasoning—but time . Many visual targets are ephemeral : they ap-pear, are query-relevant, and leave within a short window. Binding memory to the same end-to-end path as reasoning means that by the time a monolithic pipeline completes, the ev-idence is gone. We formalize this as Ephemeral-Target Interaction and a Perceptual Deadline Contract separating a hard memory deadline from a soft reasoning deadline, grounded in the bounded, passive nature of sensory and working memory. We propose a 

two-deadline architecture : an always-on, bounded, non-semantic fast path; an active remembering mechanism that commits a moment to durable memory before it is overwrit-ten; and a deferred deliberation layer (multimodal model + tools). We instantiate the contract on real MOT17 track windows—a consistency check—and calibrate the single-path baseline from measured frontier-model latency: even a short answer takes 1 .2–9 .3 s, and an agentic identify-and-search longer. Answers can be late; evidence cannot be missed. 

Keywords: camera-first agents; ephemeral targets; memory deadline; deferred deliberation; perceptual deadline; multimodal models (VLM / live) 

# 1 Introduction 

Vision-language models have become remarkably capable because language provides a general-izing interface. For semantic recognition, retrieval, and reasoning, a strong VLM is currently the best tool we have, and we expect it to remain the core of the slow, deliberative layer of future vision systems. The difficulty of building a camera-first agent lies elsewhere: in time. 

Consider a camera-first agent interacting with the world in real time. Many of the targets a user cares about are ephemeral —a person passing by, a sign glanced at, an object briefly held. Such a target is present only within a short window. If perception and reasoning are bound into a single end-to-end path (see a frame, run a large model, identify, call tools, answer), then by the time the pipeline completes, the target has left and the evidence is gone. The user’s tolerance is asymmetric: a late answer is tolerable; a missed moment is not. We summarize this as: answers can be late, evidence cannot be missed. 

This reframes what the next-generation intelligent terminal is. We take a camera-first terminal to be a device with always-on but bounded perception : it receives the visual stream passively and cheaply, while only actively selected moments are persisted. Its defining competence is not answering questions about an image but not missing the moment —a perception-first counterpart to today’s prompt-first, stateless model-plus-screen devices. This is no longer hypothetical: VisionClaw [Liu et al., 2026] already runs such an agent on Meta Ray-Ban glasses, yet samples perception at ∼1 Hz and reports a median ∼12 s action latency— exactly the temporal gap we address. 1arXiv:2610.14772v1 [cs.AI] 10 Oct 2026 This asymmetry suggests that the fundamental design question for camera-first agents is not “how do we recognize better?” but “what should the system do in the moment?” We argue for a Perceptual Deadline Contract that separates two deadlines with different slack: a hard memory deadline (lay down the evidence within the target’s window τ ) and a soft reasoning deadline (the semantic answer may arrive later, computed on frozen evidence). We instantiate this as a two-deadline architecture : an always-on, non-semantic fast path that passively writes a bounded working memory; an active remembering mechanism that remembers a moment into durable memory before it is overwritten (event-driven in v1); and a 

deferred deliberation layer (a multimodal model with tools) that reads from memory. The multimodal model remains the slow, deliberative layer: we change where and when it runs, not whether it is used. The design is motivated by the bounded, automatic nature of sensory and working memory [Sperling, 1960, Atkinson and Shiffrin, 1968, Baddeley and Hitch, 1974, Cowan, 2001] and by reactive-deliberative control [Brooks, 1986]. Perception is itself inference — the visual system performs fast, automatic, non-linguistic inference [Rao and Ballard, 1999, Kersten et al., 2004] — so the contract orders two kinds of inference by deadline , not reasoning from non-reasoning. 

Contributions. (1) Problem: we formalize Ephemeral-Target Interaction and the Percep-tual Deadline Contract (hard memory vs. soft reasoning), grounded in bounded sensory/working memory and budget-conditioned remembering. (2) Formulation: a deadline curve—memory recall versus dwell τ —and an initial instantiation on real track windows. (3) System: a two-deadline architecture (bounded passive store + event-driven active remembering + deferred deliberation), reported as memory recall vs. budget and a bounded-horizon sweep. (4) Bench-mark: an ETI benchmark on public MOT17 enter/exit tracks with an injected query per episode. 

Non-goals. No product lift, no CTR, no claim that multimodal models are the wrong substrate, no human-cognition isomorphism, and no user-experience claim in this version. Query/goal-conditioned selectivity and false-memory are deferred to a v2 selective benchmark. 

Scope. Our claim is scoped to current constraints—interaction latency, uplink bandwidth, and inference cost. We do not claim a single model is intrinsically insufficient: with near-free, instantaneous inference, a monolithic design would serve both stages and the contract would be unnecessary. 

# 2 Related Work and Positioning 

Single-path VLM agents and streaming video models. Recent camera-first and stream-ing systems route each frame or segment through one (large) multimodal model, optionally with tool calls. We cut on the temporal contract : which computation must complete within 

a target’s window, and which may be deferred. 

Realtime, omni, and full-duplex models. A new class of streaming, low-latency multimodal models—GPT-4o Realtime, Gemini Live, Qwen2.5-Omni [Xu et al., 2025], Moshi [D´ efossez et al., 2024]—provides always-on audio-visual streaming with simultaneous in-put/output, and is a natural substrate for both the fast perceiver and the deferred deliberator (VisionClaw already runs on Gemini Live). It remains, however, a single path with an ephemeral context: continuous perception does not by itself guarantee that a sub-second target is remembered before it is lost, nor that evidence is retrievable for a later, tool-using answer. Our contract is model-agnostic and sits above this substrate: it fixes when evidence must be remembered and what must be persisted, however the backbone is built. 2Always-on wearable agents. VisionClaw [Liu et al., 2026] is the closest system: on Meta Ray-Ban glasses it streams egocentric video into Gemini Live and delegates actions to an agentic backend, with reported gains in task time and workload. Two of its own measurements frame our problem: perception is sampled at ∼1 frame/s, and end-to-end latency has a median ∼12 s. Under our contract, 1 Hz sampling would leave sub-second windows largely uncovered, and 12 s is far outside the memory window. We treat VisionClaw-style systems as the motivation and formalize the perceptual-timing layer they currently lack. 

Cascades, routing, and adaptive computation. Fast/slow and conditional compute have deep precedent: classifier cascades [Viola and Jones, 2001], adaptive computation time [Graves, 2016], early exit [Teerapittayanon et al., 2016], sparse MoE [Shazeer et al., 2017], LLM cascades [Chen et al., 2023, Aggarwal et al., 2023], routing [Ong et al., 2024], per-token depth routing [Raposo et al., 2024], and vision-internal reductions [Rao et al., 2021, Bolya et al., 2023]. Our target differs: event-level remembering under a hard memory deadline .

Dual-process and reactive-deliberative architectures. Our fast/slow split echoes dual-process theories [Kahneman, 2011, Evans and Stanovich, 2013]; we use the “System 1/2” label only as a heuristic and make no cognitive-psychology claim [Melnikoff and Bargh, 2018]. Layered fast/slow control dates to subsumption [Brooks, 1986] and three-layer architectures [Gat, 1998]. We revisit it for VLM-era camera-first agents. 

Attention, saliency, active vision. Saliency [Itti et al., 1998] and active perception [Bajcsy, 1988, Mnih et al., 2014] establish selective viewing, typically goal-agnostic; our remem-bering is event-driven in v1 and becomes query/goal-conditioned in v2. 

Bounded memory. Iconic/sensory memory is brief and capacity-limited; remembering commits selected content to durable store [Sperling, 1960, Atkinson and Shiffrin, 1968, Baddeley and Hitch, 1974, Cowan, 2001]. Used as design motivation, not isomorphism. 

Latency in HCI. Response-time thresholds [Miller, 1968, Nielsen, 1993] motivate an inter-action budget; our failure is stronger—lost evidence. 

Counter-evidence. (i) Record everything : under an unbounded buffer remembering is trivial; we condition every metric on a budget and treat record-everything as the oracle upper bound. (ii) Representation convergence [Huh et al., 2024]: semantic-level convergence does not make the perceptual fast path redundant. (iii) Fast VLMs : our claim is about the temporal contract, not raw speed. 

# 3 Protocol and Metrics 

Task. Ephemeral-Target Interaction (ETI): a target appears at tin , is query-relevant, and leaves at tout with dwell τ = tout − tin . The agent must (i) remember within [ tin , t out ] under memory budget B, and (ii) later answer the query from memory. Remembering is hard-deadline; the answer is soft-deadline. 

Episode schema. Each episode is {tin , t out , target id , query , answer label , source , synthetic }.Every episode carries an explicit query; without it, “missed” is undefined. 

Budget. All memory metrics are functions of a per-sequence memory budget B ∈ (0 , 1]: the fraction of ephemeral entries the gate may persist (a proxy for memory/compute). We keep 

B (a capture quota) distinct from the passive buffer horizon H (§4.1, §5.7): B bounds how many entries may be persisted, H bounds how long evidence remains available. The primary comparison is at fixed B; the oracle is unbudgeted and instantaneous.

# 4 Architecture: a two-deadline design 

Our architecture instantiates the contract as three stages with a single live budget B (Figure 1). 

• Passive store (always-on, bounded, non-semantic). Reception is passive: a cheap always-on path automatically writes a bounded working memory with horizon H. It is not semantic and not deliberate; H = ∞ degenerates to the oracle. Always-on perception is not always-on recording. 

• Active remembering (event-driven, hard deadline). A sub-second gate remembers a moment into durable memory before it is overwritten (v1: on target entry). Remembering must occur within τ and consumes B.

• Deferred deliberation (soft deadline). A multimodal model with tools reads durable memory and answers; it may run after the target has left. Its output scores deferred-answer accuracy, not the primary claim.

# 6 Limitations 

• Contingent on current costs. The argument assumes a non-negligible latency/bandwidth/compute budget; with near-zero inference latency a single-path design would suffice—a judgment for the current environment, not a universal law. 

• Oracle-perception simulation. Policies run over real track windows but no pix-els/detector/model are run; the scheduler is the object, not perception. The empirical section is a labeled self-check , not a system evaluation. 

• Latency is a floor. Text-generation stats exclude image upload and image prefill; real vision latency is higher. 

• Answer metric unrun. MOT17 has no attribute labels; deferred-answer accuracy is not reported here. 

• Query-conditioning/false-memory deferred to a v2 selective benchmark. 

Ethics and privacy. Selective processing is selective data: the always-on fast path runs locally, and only actively remembered moments are persisted or uploaded, reducing exposure relative to continuous recording. This work uses public datasets only and no personal user data. 

# 7 Conclusion 

The binding constraint for future camera-first agents is not recognition quality but time . Many targets are ephemeral; a single end-to-end path loses their evidence before it can be used. We 6formalized this as Ephemeral-Target Interaction and a Perceptual Deadline Contract, and pro-posed a two-deadline architecture: a bounded passive working memory, an active remembering gate that remembers within the hard window, and a deferred VLM-and-tools layer that an-swers within the soft window. On real track windows, event-driven remembering recovers every ephemeral target while a monolithic pass misses all those shorter than its latency. The contri-bution is a measurable contract and a system that respects it: answers can be late; evidence cannot be missed.
