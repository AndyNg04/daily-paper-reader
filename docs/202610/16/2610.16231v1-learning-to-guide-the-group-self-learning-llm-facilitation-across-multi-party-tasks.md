## 摘要
随着大语言模型日益应用于多方交流促进，对能够在不同情境中平衡多样群体动态的智能体的需求也不断增长。然而，现有的大语言模型促进者往往针对特定任务目标进行微调；能够适应不同任务类型和多样群体动态的通用大语言模型促进方法仍不成熟。为弥补这一不足，我们提出 GUIDE（动态交流通用统一干预），这是一个用于开发适用于不同多方情境的通用大语言模型促进者的框架。GUIDE 从客观任务结果和主观指标两个方面评估促进效果，主观指标包括心理安全感和感知到的摩擦。在该框架下，我们研究大语言模型能否通过自学习，从离线策略学习过渡到实时干预。首先，我们收集由针对特定任务的专家大语言模型促进者引导的多方人类互动数据（N=432 段对话）。随后，我们采用一种自学习方法：由大语言模型从对话中归纳出可执行的策略手册，并根据与人类标注者意见一致的大语言模型评审器所提供的反馈进行迭代完善（N=20），从而构建出一个通用促进者。在留出对话上，该促进者的表现优于三种针对特定任务的专家促进者，胜率为 61.4%。最后，我们通过实证研究评估这些改进：在一项实时在线实证研究中，自学习得到的通用促进者在保持促进效果和群体生产力的同时，提升了发言舒适度并减少了人际摩擦；与专家提示词相比，其使用的轮次数减少了 24.7%，词数减少了 29.0%。这些发现提供了实证证据，表明大语言模型能够从特定任务的人类互动中学习具有泛化能力、与任务无关的社交促进策略，并在多样的群体情境中达到与人工设计的特定任务提示词相当的效果。

## Abstract
As large language models are increasingly adopted as multi-party communication facilitators, there is a growing demand for agents capable of balancing diverse group dynamics across contexts. However, existing LLM facilitators are often fine-tuned for task-specific objectives; generalized LLM-based facilitation methods that can adapt to different types of tasks and diverse group dynamics are underdeveloped. To address this gap, we present GUIDE (Generalized Unified Intervention for Dynamic Exchanges, a framework for developing generalized LLM-based facilitators across different multi-party contexts. GUIDE evaluates facilitation across both objective task outcomes and subjective metrics, including psychological safety and perceived friction. Within this framework, we study whether LLMs can self-learn generalized facilitation strategy offline to real-time interventions. We first collect multi-party human interactions guided by task-specific expert LLM facilitators (N=432 conversations). We then employ a self-learning method in which an LLM induces an actionable strategic playbook from conversations and iteratively refines it using feedback from an LLM judge aligned with human annotators (N=20), developing a single generalized facilitator that outperforms the three task-specific expert facilitators on held-out conversations 61.4% win rate. Finally, we evaluate these improvements empirically; in a real-time online empirical study, the self-learned generalized facilitator preserves facilitator performance and group productivity, improves speaking comfort and reduces interpersonal friction, while using 24.7% fewer turns and 29.0% fewer words than the expert prompts. These findings provide empirical evidence that LLMs can learn generalizable, task-agnostic social facilitation from task-specific human interactions, on-par with hand-crafted task-specific prompts across diverse group settings.

# 论文总结：Learning to GUIDE the Group

## 1. 核心问题与研究背景

论文研究：**能否让大语言模型从真实多人互动中，自动学习一套跨任务通用的群体主持策略，而不是为每类任务分别人工设计提示词？**

多人主持不同于一对一问答：主持器不仅需要决定“说什么”，还必须判断“什么时候说、什么时候保持沉默”，并同时兼顾任务进展、参与公平、心理安全及群体自主性。

现有方法主要存在三类问题：

- **依赖任务专用提示词**：需要大量人工调试，难以覆盖成员退出、快速共识、隐性排斥等复杂情况。
- **过度重视任务完成**：达成协议并不意味着参与者感到被尊重、被倾听。
- **缺少可靠学习信号**：主持效果没有类似数学题答案的确定性验证器；纯 LLM 模拟也难以真实复现人类冲突与社会反应。

为此，论文提出 **GUIDE（Generalized Unified Intervention for Dynamic Exchanges）**：从真实人类对话和反馈中归纳可读的策略手册，再通过经过人工校准的模型评审迭代改进。

**整体意义**在于：将群体主持从“手工编写流程脚本”，转向“基于真实互动证据、按情境触发规则的策略学习”。这里的“自学习”是**冻结模型权重后的提示词／上下文优化**，不是参数微调或完全无人监督学习。

## 2. 方法论：核心思想与算法流程

### 2.1 用显式策略手册表示主持政策

底层 LLM 保持冻结，主持策略由自然语言手册 \(P\) 表示。每条规则具有：

- 稳定的规则 ID、所属章节和规则文本；
- 有帮助、有害、被引用次数及连续未使用代数等统计量。

每次观察对话历史后，主持器输出：

- 是否发言；
- 若发言，具体说什么；
- 时机和策略说明；
- 本次决策引用了哪些规则。

因此，策略同时覆盖**发言内容与沉默决策**，并支持规则级反馈和审计。

### 2.2 双重反馈驱动的自学习循环

算法从空手册开始，反复执行：

1. **真实对话反思**
   - 读取训练对话、任务结果、参与者评分和开放式反馈。
   - 将满意或不满的反馈与具体互动联系起来，抽象出“可观察信号 → 主持行动”的通用经验。
   - 学习器看不到原始专家提示词及其内部理由，但能看到专家主持产生的实际对话。

2. **规则编辑**
   - Curator 对现有规则执行新增、修改、合并和删除。
   - 采用局部编辑，而非每轮整体重写，以避免有效策略被冲淡。

3. **候选策略与上一代比较**
   - 在相同验证对话状态下，分别生成候选手册和上一代手册的行动。
   - 固定 LLM 评审器进行盲评，判断哪一个更合适。
   - **学习阶段不直接以专家行动作为比较对象**；专家基线用于最终离线 benchmark。

4. **规则级归因与剪枝**
   - 将每条被引用规则分别标记为 Helpful、Harmful 或 Neutral。
   - 不把整次失败机械地归罪于全部引用规则。
   - 清除持续有害或长期未使用的规则。

5. **验证反思**
   - 从当前策略的误触发、过度干预、规则冲突和覆盖缺口中提炼修正建议。
   - 同类问题至少在两个独立决策中出现，才生成相应经验。

需要注意：**候选手册并非只有整体胜出才被接纳**，而是编辑后的规则继续保留，再通过规则级剪枝筛选。

### 2.3 评审器校准与关键配置

- 20 名人工标注者评价 50 个决策点，每点 4 票，共 200 票。
- 评审规则改为“先诊断对话状态，再评估行动”，状态包括有效交流、浅层讨论、困惑、停滞、无效交流和已结束。
- 与人工多数意见的一致性由 Cohen’s \(\kappa=0.29\) 提高到 **0.70**。
- 双方均沉默时直接记为平局，不调用评审器。

## 3. 实验设计、数据与 Benchmark

### 3.1 三类真实多人任务

每组由 **3 名人类参与者和 1 个 AI 主持器**组成，进行实时文字交流，无固定轮流发言顺序。每项任务持续约 5–10 分钟。

| 场景 | 任务与目标 | 主要客观指标 |
|---|---|---|
| 开放讨论 | 讨论公共场所人脸识别或 Medicaid 资格政策，无须达成一致 | 消息数量、参与奖励达标率 |
| 多方谈判 | 组建联盟并分配真实奖金，不同联盟金额不同，分配必须为整数 | 是否达成联盟、分配是否合法 |
| 共识建立 | 从 3 个慈善组织中选定一个接受捐款 | 是否一致同意 |

主观评价覆盖心理安全、被倾听感、发言舒适度、人际摩擦、群体生产力及对主持器的评价。其中，**心理安全是主要指标**，其余多为次要指标。

## 6. 主要结论与发现

### 6.1 离线评价优于专家提示词

- 总体平局折半胜率为 **61.4%**。
- 专家发言时：**66.9%**。
- 专家沉默时：**56.0%**。

学习手册的主要变化不是发明全新主持理论，而是将宽泛原则细化为**状态条件化规则**：

- 有效交流时克制干预，优先保留人际对话空间；
- 达成明确协议后避免重复确认；
- 正确处理成员退出和群体结构变化；
- 一次提出一个清晰问题，定向邀请安静成员；
- 避免用具体分配模板锚定群体决策。

### 6.2 在线最清晰的收益是减少摩擦和主持输出

| 指标 | 专家提示词 | 学习手册 | 解读 |
|---|---:|---:|---|
| 心理安全 | 4.62 | 4.67 | 小幅上升，\(p=.057\)，未达常用显著性阈值 |
| 被倾听感 | 4.35 | 4.40 | 无显著差异 |
| 发言舒适度 | 4.63 | 4.69 | 小幅改善，表中 \(p=.049\) |
| 摩擦与愤怒 | 1.60 | 1.42 | 显著下降，\(p<.001\) |
| 群体生产力 | 4.09 | 4.07 | 无显著差异 |
| 每段主持发言轮数 | 5.31 | 4.00 | 减少 24.7% |
| 每段主持词数 | 202.7 | 143.8 | 减少 29.0% |

多项体验指标的组内离散程度也有所下降，提示成员体验更一致；但这**不能直接证明参与权力或实际发言机会更公平**。

### 6.3 “保持表现”需要谨慎解释

- 共识率由 88.2% 降至 83.8%，差异不显著。
- 谈判中达成联盟后的有效分配率由 84.6% 降至 76.8%，差异不显著。
- **差异不显著并不等于证明等效或非劣**。
- 原始主持器评价均下降：
  - 生产力：3.96 → 3.66；
  - 满意度：4.20 → 4.03；
  - 舒适度：4.41 → 4.33。
- 第二批参与者事前对 AI 更怀疑。减去个人预期后差异不显著，但 ANCOVA 调整后，**主持器生产力评价仍显著较低**。

因此，更准确的结论是：学习策略减少了打扰和摩擦，但部分参与者也可能认为它**干预不足、贡献不够明显**。

## 7. 主要优点

- **问题设定贴近社会计算实际**：同时考虑任务成果、关系体验和主持成本。
- **真实人类数据扎实**：从真人互动学习，并在新参与者中部署验证。
- **显式建模沉默**：将“不说话”作为策略行动，而非仅优化回复质量。
- **规则可读、可追溯**：保留规则 ID、编辑来源和引用记录，便于审计。
- **规则级归因较细致**：避免因某次失败而误删所有相关规则。
- **识别评审器偏差的重要性**：展示未经校准的评审器会把不合理的固定干预频率写入手册。
- **附录披露较充分**：给出完整提示词、手册、较差结果及校准分析，使读者能检视摘要结论。

## 8. 不足与局限

- **因果证据有限**：研究间比较和基线态度差异无法通过简单校准完全解决。
- **离线单步最优不等于长期互动最优**：持续沉默可能逐步降低用户对主持器价值的感知，单点盲评难以捕捉。
- **评审信号存在循环性**：同一评审器参与优化和测试，偏好的风格可能被反复强化。
- **人工对齐规模较小**：仅 50 个点，且以发言点为主；未明确展示独立校准测试集，一致性估计的外推性有限。
- **克制可能牺牲程序保障**：谈判算术协调错误有上升迹象；虽然多重校正后不显著，仍提示关键任务校验不能仅依赖自由生成规则。
- **泛化范围较窄**：仅英语、Prolific 成人、三人组、短时文字互动，开放讨论仅两个美国政策议题。
- **测量存在代理偏差**：消息数量不等于讨论质量；单题心理安全自评也难以覆盖完整构念，且初始评分已接近上限。
- **公平性证据不足**：缺少充分人口属性信息，无法判断不同社会群体是否同等受益。
- **报告存在少量不一致**：专家规则数量出现 91／97 等不同口径，参与者—任务记录数也与简单乘积不完全一致，需要进一步解释。
- **不可直接用于高风险主持**：尚未验证法律调解、医疗决策、严重冲突或长期组织关系场景。

**总体评价：**GUIDE 为“冻结 LLM 如何学习社会互动策略”提供了有价值的实证路径。最稳固的发现是：**情境化、克制的主持能够显著减少输出和人际摩擦**；但离线优势、真实用户感知和客观任务保障之间仍存在权衡，尚不能据此宣称其全面优于专家主持或具备广泛任务泛化能力。
