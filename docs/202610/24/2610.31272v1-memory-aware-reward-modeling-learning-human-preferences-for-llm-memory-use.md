## 摘要
记忆使语言模型助手能够在不同会话之间保持连贯，并生成个性化回复，但对用户了解得更多，并不一定能生成用户更喜欢的回复。现有评估衡量了模型的记忆能力，却未能直接确定使用记忆是否有益于用户。为探究这一问题，我们收集了 87 名参与者基于其本人 ChatGPT 查询和个人记忆作出的约 1,000 项成对判断。我们发现，与不使用记忆生成的回复相比，基于记忆生成的回复并非总是更受青睐；在某些情况下，用户强烈偏好不使用记忆生成的回复。自动评估器与用户的判断一致性也有限，而且它们偏好基于记忆生成的回复的频率远高于用户。针对这些差异，我们提出了一种记忆感知奖励模型，通过用户判断进行学习，其偏好预测准确率达到 72.8%，优于现有基线方法。我们的研究结果表明，评估与优化目标应使记忆的使用方式符合信息所涉及的用户本人的偏好。

## Abstract
Memory enables language model assistants to maintain continuity across sessions and generate personalized responses, but knowing more about a user does not necessarily produce responses they prefer. Existing evaluations assess memory capabilities without directly establishing whether memory use benefits the user. To study this gap, we collect approximately 1,000 pairwise judgments from 87 participants using their own ChatGPT queries and personal memories. We find that memory-conditioned responses are not consistently preferred over responses generated without memory and in some cases, users strongly prefer the latter. Automatic evaluators also show limited agreement with users and favor memory-conditioned responses substantially more often than users do. Motivated by these gaps, we introduce a memory-aware reward model that learns from user judgments, achieving 72.8\% preference prediction accuracy and outperforming the existing baselines. Our findings motivate evaluation and optimization objectives that align memory use with the preferences of the people whose information is being used.

## 1. 核心问题与整体含义

### 研究背景与动机
长期记忆使大语言模型助手能够跨会话保留用户背景、习惯和偏好，但现有评测主要关注“能否记住、检索和更新信息”，并不能直接回答：**这些信息是否被恰当地使用，以及使用后是否真正让用户更满意。**

论文区分了三个不同层面：
- **记忆准确性**：是否正确保存、找回用户信息。
- **使用恰当性**：当前问题是否需要这些信息，以及推断是否合理。
- **用户偏好**：最终回答是否比不使用记忆的回答更受用户欢迎。

例如，知道用户的职业，未必意味着每次解释通用概念都应该使用该职业的案例；过度个性化可能缩窄回答、引入无根据的假设，甚至造成隐私侵扰感。

### 核心研究问题
1. 用户是否更喜欢使用个人记忆生成的回答？
2. 通用 LLM 评判器和预训练奖励模型能否准确预测这种偏好？
3. 能否从**记忆所属用户本人的反馈**中，学习更符合实际需求的评价模型？

整体上，论文主张将记忆系统的优化目标从“记忆调用和个性化程度”，转向“记忆使用带来的用户价值”。

## 2. 方法论：核心思想与技术流程

### 核心思想
提出 **Memory-Aware Reward Model，记忆感知奖励模型**：不仅评价回答本身，还显式考虑用户记忆，以及回答使用记忆是否恰当。

其具体实现不是重新训练一个大型奖励网络，而是：

> 用 LLM 提取和评分可解释评价维度，再用真实用户偏好学习这些维度的组合权重。

### 算法流程

1. **构造回答对**
   - 给定用户问题 \(q\) 和检索到的记忆 \(M\)。
   - 同一个生成模型分别产生：
     - 使用记忆的回答 \(y_m\)；
     - 不使用记忆的回答 \(y_0\)。

2. **从训练数据归纳评价维度**
   - 每轮向 LLM 提供 10 个带偏好标签的训练样例，生成约 10 项候选评价标准。
   - 独立执行 5 轮，得到约 50 项原始标准，再合并近义项。
   - 示例模型最终形成 **12 维特征**，划分为：
     - **记忆相关特征**：记忆相关性、个人假设与证据是否相称、无依据的个人假设。
     - **回答属性特征**：长度、标题数量、可执行性、建议明确程度、选项表达、覆盖广度、语言风格等。
   - 特征归纳在每个外层交叉验证折内独立完成，仅使用训练参与者的数据，避免测试标签泄漏。

3. **抽取回答对特征**
   - 输入问题、记忆和两条回答，生成可解释特征向量。
   - 部分特征是两条回答的差异，例如标题数量差、长度对数比。
   - 另一些是上下文特征，例如记忆与问题的相关性，在不查看回答的情况下评分。

4. **学习偏好预测器**
   - 对特征做训练集标准化。
   - 使用带 **L2 正则化的逻辑回归**，输出用户偏好记忆回答的概率：
     \[
     P(y_m\succ y_0)=\sigma(b+w^\top \tilde{x})
     \]
   - 训练时只更新权重和偏置，生成模型及特征评估器均保持固定。

5. **选择性预测**
   - 根据预测概率与 0.5 的距离衡量置信度。
   - 可以只保留高置信度样例，在降低覆盖率的同时提高准确率。

### 方法边界
虽然论文使用“奖励模型”的表述，**实际验证的是“有记忆回答 vs. 无记忆回答”的成对偏好预测**，尚未证明它能直接作为通用单回答奖励函数，或稳定用于强化学习训练。

## 6. 主要结论与发现

### 记忆不一定提升用户偏好

| 个性化策略 | 偏好有记忆 | 偏好无记忆 | 平局 |
|---|---:|---:|---:|
| 保守 | 43.3% | 40.6% | 16.1% |
| 普通 | 38.7% | 41.9% | 19.4% |
| 激进 | 34.6% | 49.3% | 16.2% |

- 越激进地个性化，记忆回答越不受欢迎。
- 保守策略也只有小幅描述性优势，不能据此断言具有显著收益。
- 不同生成器方向不同，说明问题不在于“记忆天然无用”，而在于**如何使用记忆**。

### 自动评价存在偏爱个性化的倾向
在强偏好子集中：
- 用户选择有记忆回答的比例为 **45.0%**；
- 双顺序直接评判器为 **67.2%**；
- 输入记忆的 Skywork 为 **81.1%**。

提供个人上下文可能让评估器把“使用了记忆”误当成“更符合用户需求”。

### 学习评价维度权重显著改善预测

| 方法 | 准确率 |
|---|---:|
| 总是选择无记忆回答 | 55.0% |
| Skywork：有记忆输入 | 52.9% |
| Skywork：无记忆输入 | 58.8% |
| 直接 LLM 评判 | 58.1% |
| 基于评价标准的 LLM 评判 | 59.6% |
| 本文：仅记忆特征 | 62.5% |
| 本文：仅回答属性 | 67.0% |
| **本文：完整模型** | **72.8%** |

完整模型相比最好的表列零样本基线提高 **13.2 个百分点**；相比仅回答属性模型提高 **5.8 个百分点**，说明记忆相关特征提供了额外信息。

### 偏好同时受内容与呈现方式影响
- 标题数量差和相对长度具有最大的正向标准化系数。
- 记忆相关性、假设合理性也有正向贡献。
- 无依据个人假设具有负向贡献。

这些是预测性关联，**不等于增加标题或长度就会因果性地提升用户满意度**。

### 高置信度预测更准确
- 全覆盖：72.8%；
- 50% 覆盖：83.7%；
- 25% 覆盖：88.8%。

这一结果支持选择性使用，但高准确率建立在放弃大部分比较的前提下。

## 7. 优点与亮点

- **研究问题切中实际**：将“记住用户”与“帮助用户”明确区分。
- **监督信号真实**：用户评价自己的问题和记忆，而非扮演虚构画像。
- **模型简洁且可解释**：能够分析记忆适用性、假设合理性与回答形式的作用。
- **数据效率较高**：在有限标签下，通过固定评估器和轻量回归取得明显提升。
- **交叉验证较规范**：控制参与者泄漏、标准归纳泄漏和标准化泄漏。
- **同时分析用户与评估器偏差**：不仅提出新方法，也揭示现有评估机制可能奖励错误目标。
- **伦理边界清晰**：强调预测偏好不代表同意收集、保存或披露个人信息，隐私与用户控制应独立保障。

## 8. 不足与局限

### 样本与选择偏差
- 回答对被筛选为“记忆产生明显差异”的案例，不代表所有真实请求的分布。
- 只使用“明显更好”样例训练和测试，结果不宜推广到轻微偏好和平局。
- 参与者来自特定招募平台及 ChatGPT 用户群体，代表性有限。

### 偏好可靠性与个体差异
- 三天后的总体方向一致率仅 **68.0%**，强偏好为 **73.9%**。
- 重测只有 10 人，且与模型评估样本并不完全对应；不能将 73.9% 视为严格的人类表现上限。
- 模型学习的是跨用户共享权重，并未真正学习每个人不同的记忆使用边界。

### 因果解释与方法边界
- 两条回答分别生成，除了记忆，还可能在长度、结构、完整性上出现随机差异。
- 最大权重来自呈现特征，模型可能部分学习到风格偏好，而非纯粹的记忆使用质量。
- 某些特征依赖“哪条回答使用了记忆”的身份，不直接适用于任意回答之间的比较。
- 尚未验证多候选排序、概率校准或作为强化学习奖励时的稳健性。

### 应用与外部验证不足
- 仅覆盖单轮、离线回答比较。
- 未测试长期互动、用户偏好变化、记忆冲突、更新与删除，以及智能体执行动作的后果。
- 没有开展实际后训练或在线用户实验，**偏好预测改善尚不等于助手行为改善**。

### 报告一致性与复现问题
所给文本存在若干需要澄清之处：
- 正文称每位用户有 100 条候选查询，附录提取提示要求 30 条，并允许不足。
- 直接评判器的单顺序、双顺序结果在不同段落存在小幅不一致。
- 主表按生成器列出的“总是选无记忆”比例，与所列样本数加权后不能还原总体 55.0%，需要核实统计口径。
- 特征评分细节及总计算成本披露不足。

### 总体评价
论文最重要的贡献是提供了直接的用户证据：**记忆使用的价值不能由召回能力、个性化程度或通用评估器的偏好替代。**其可解释偏好模型是有潜力的初步方案，但距离可泛化、可在线部署的记忆使用策略，仍需更大规模、多场景和长期验证。
