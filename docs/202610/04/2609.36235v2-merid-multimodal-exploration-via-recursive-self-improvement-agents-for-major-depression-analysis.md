## 摘要
重性抑郁症（MDD）会严重影响日常活动和生活质量。检测 MDD 需要处理多模态数据，例如访谈录音和传感器测量数据。这项任务尤具挑战性，因为这些异质模态往往需要各自定制的预测流程。针对这一挑战，现有研究探索了人工设计的多模态架构以及智能体辅助的流程开发。尽管取得了进展，如何根据实验反馈自主修订流程，并将经验证的改进延续到后续设计中，仍然具有挑战性。为此，我们提出面向重性抑郁症分析的递归自我改进智能体多模态探索框架（MERID）。该框架通过基于经验的递归自我改进（RSI）构建抑郁症分析流程。基于实证的状态构建（GSC）通过将多模态记录与受试者层面的抑郁症目标对齐，使经验建立在可靠依据之上。耦合式流程探索（CPE）联合调整表征、融合方式和预测器，以构建用于分类和严重程度估计的后继流程。证据引导进化（EGE）依据反馈指导修订，并在小规模抑郁症队列的不确定性条件下验证性能提升，再将其继承至后续设计。在抑郁症基准数据集上开展的大量实验表明，与多模态及基于智能体的基线方法相比，MERID 在多项任务中取得了最佳结果。进一步分析突显了声学和语言线索在抑郁症检测中的价值。我们的代码已公开于 https://github.com/DiscoAILab/MERID

## Abstract
Major depressive disorder (MDD) severely impacts daily activities and quality of life. Detecting MDD involves multimodal data, such as interview recordings and sensor measurements. This is particularly challenging, as these heterogeneous modalities often demand distinct, customized prediction pipelines. Existing efforts to address this challenge have explored both manually engineered multimodal architectures and agent-assisted pipeline development. Despite their progress, it remains challenging to autonomously revise pipelines based on experimental feedback and carry verified improvements forward into subsequent designs. To this end, we propose Multimodal Exploration via Recursive Self-Improvement Agents for Major Depression Analysis (MERID). The framework develops depression pipelines through experience-based recursive self-improvement (RSI). Grounded State Construction (GSC) grounds experience by aligning multimodal records with subject-level depression targets. Coupled Pipeline Exploration (CPE) jointly modifies representations, fusion, and predictors to build successor pipelines for classification and severity estimation. Evidence-Guided Evolution (EGE) guides revisions through feedback and verifies gains under uncertainty in small depression cohorts before inheritance. Extensive experiments on depression benchmarks show that MERID achieves the best results on multiple tasks compared with multimodal and agent-based baselines. Further analysis highlights the value of acoustic and linguistic cues for depression detection. Our code is available at https://github.com/DiscoAILab/MERID

# MERID 论文中文总结

> **核心概括：**MERID 将多模态抑郁分析建模为“提出预测流程—执行实验—审查证据—验证收益—继承有效改进”的自动化闭环。其主要贡献是**面向小样本临床数据的智能体辅助流程开发框架**，而非新的端到端抑郁识别网络。实验显示其在部分分类和症状严重程度估计任务上表现突出，但持续递归改进、研究记忆和临床机制对齐的收益尚未得到一致支持。

## 1. 核心问题与整体含义：研究动机和背景

- **多模态抑郁分析需要高度定制的预测流程。**
  - 访谈语音、面部动作、文本、步态及人格信息的结构和时间粒度不同。
  - 有效建模不仅取决于预测器，还依赖特征提取、时间聚合、模态选择、融合方式和正则化的配合。
  - 人工设计这些流程通常需要反复实验，成本较高。

- **现有自动化方法存在三个关键问题：**
  1. **实验结果未必可比：**改变输入表征可能改变记录顺序、样本集合或受试者与标签的对应关系。
  2. **组件之间存在耦合：**只优化融合或预测器，可能遗漏必须同时修改多个组件才能获得的收益。
  3. **小样本收益不可靠：**重复使用开发集选择模型，容易将抽样波动误判为真实提升，并将错误选择延续到下一轮。

- **论文的研究目标：**让实验经验驱动预测流程的自主修订，同时保留可追溯的证据，并通过不确定性感知规则限制不可靠替换。

- **“自我改进”的准确含义：**
  - 改进的是预测流程、候选组件空间及实验经验。
  - 单次运行中，**LLM 权重、角色定义和评估协议保持固定**；并不是基础模型自行训练或无限制重写自身。

## 2. 方法论：核心思想、关键技术与算法流程

### 2.1 总体状态与循环

系统状态包括：

- 经检查的数据适配器；
- 当前候选流程空间；
- 当前保留流程，即 incumbent；
- 历史修订记录；
- 可选的研究记忆。

一个预测流程由两部分构成：**表征与融合配方，以及预测器配置**。每轮根据已有实验提出修改，在固定开发协议下评估，再决定是否替换当前流程，并将候选空间和经验传入下一轮。

### 2.2 GSC：基于实证的状态构建

**目的：保证不同流程比较的是同一批、同一顺序、同一标签的记录。**

- 检查数据来源、文件结构、模态可用性和受试者—标签关联。
- 将变长序列转换为固定长度特征。
- 第一个有效输出建立各数据划分的目标、受试者 ID 和记录 ID 的参考顺序。
- 后续配方可以改变特征维度，但不能改变上述对应关系。
- 执行检查覆盖：
  - 矩阵形状与标签长度；
  - 非有限值；
  - 记录错配；
  - 配方修改是否实际影响预期特征。
- 区分**预测证据**与**定义标签的测量工具**，避免把产生诊断标签的量表总分或项目直接当作预测输入。

**意义：**数据对齐与泄漏检查不仅是预处理，也是后续实验反馈可信的基础。

### 2.3 CPE：耦合式流程探索

**目的：联合探索表征、融合与预测器，避免孤立优化组件。**

- 配方可指定模态来源、特征操作、聚合方式和融合方式。
- 预测器配置涵盖模型家族、特征选择数量和超参数：
  - 分类器包括线性/RBF SVM、逻辑回归、梯度提升、随机森林等；
  - 回归器包括 Ridge、SVR 和树模型等；
  - 必要时生成符合 scikit-learn 接口的轻量估计器。
- 搜索空间是“配方集合 × 预测器配置集合”。
- 新增配方与已有预测器组合，新增预测器与已有配方组合；只评估未尝试的配对。
- 所有候选共享固定开发划分：
  - 有官方开发集时直接使用；
  - 否则在训练集内使用固定交叉验证，有受试者 ID 时按受试者分组。
- 保存候选配置、预测、分数、运行时间和执行错误；失败尝试也计入预算。

论文给出的交互实例表明：增加特征选择数量，在一种配方上降低 Macro-F1，在另一种配方上提高 Macro-F1，支持联合搜索的必要性。

### 2.4 EGE：证据引导进化

**目的：用实验反馈指导下一轮，同时谨慎决定流程替换。**

- 多角色审查：
  - **Planner：**检查搜索覆盖及未验证假设；
  - **Engineer：**检查数据加载、特征实现与执行问题；
  - **Reviewer：**检查预测错误、分数和不确定性；
  - **Chair：**综合意见，结束审查或请求修订。
- 审查包通过程序排除测试字段，角色只进行受限的只读检查。
- 替换规则：
  - 计算候选相对当前流程的开发分数提升；
  - 只有提升大于“当前流程的受试者级 bootstrap 分数标准差 × 不确定性系数”，才接受替换；
  - 常用配置相当于要求超过一个标准误；
  - bootstrap 将同一受试者的记录和预测一起重采样，默认使用 **1,000 次重采样**。

**研究记忆是可选扩展：**

- 从已完成实验中提炼有条件的经验，再新增、修订或退休记忆条目。
- 每条经验附带适用条件、后续实验及证据引用。
- 最多保留 16 个活跃条目；更新验证失败时保留旧记忆。
- **主结果及模块消融未启用研究记忆，其收益由独立实验评估。**

### 2.5 理论结论及其边界

- 在候选资格不变、开发分数固定保存的增量修订中：
  - 保留流程的开发分数不会下降；
  - 与已评估最佳开发分数的差距，不超过历次最大接受裕度。
- 总体性能保证还需要额外的**统一评估误差假设**。
- 作者明确指出：bootstrap 裕度**没有证明满足这一假设**，因此“开发分数单调改善”不能等同于“真实泛化性能持续改善”。
- 最终部署还可能聚合最多五个候选，需区分**循环内保留流程**与**最终部署集成**。

- **消融并非严格等条件：**完整方法继承已有流程、使用五种子；移除配置从无继承流程开始、使用三种子，搜索和审查成本也不同。

| E-DAIC 二分类 Macro-F1 | Opus 0.6768；Astra 0.7057 | Flex-MoE 0.5993 |
| E-DAIC PHQ-8 CCC | Opus 0.3268；Astra 0.3201 | MDAgents 0.0520 |
| MPDD-2025 Elder 赛道 | Opus 0.6137；Astra 0.6148 | Flex-MoE 0.5440 |
| MPDD-2026 Young 三分类 Macro-F1 | 两者均 0.4327 | MCMoE 0.3404 |
| MPDD-2026 Young PHQ-9 CCC | 两者均 0.6050 | MulT 0.0760 |

- **反例：**
  - MPDD-2025 Young：MERID 约 0.372，低于 Flex-MoE 的 0.4483；
  - MPDD-2026 Elder 二分类：MERID 最好 0.4559，低于 MulT 的 0.5165。
- 严重程度估计还存在指标权衡：MPDD-2026 Elder 的 CCC 虽有改善，但 Opus 的 RMSE 为 5.2920，劣于 MulT/Flex-MoE 的 4.5095。

### 6.2 模块、模态与递归改进

- **CPE 的突出证据：**去掉 CPE 后，E-DAIC PHQ-8 CCC 从 0.3268 降至 0.0361，但该消融存在初始化和成本混杂。
- **模块作用依任务而变：**完整配置在 9 项消融任务中有 5 项最高，其他任务由移除配置获胜。
- **研究记忆没有稳定总体收益：**27 个任务—种子配对中，7 次提升、13 次持平、7 次下降，非持平配对的符号检验 p=1.000。
- **更多搜索不必然更好：**预算及轮数增加没有一致改善；记忆研究中 54 次运行只有 5 次保留开发分数提升，均发生在第一次记录修订。
- **文本线索较重要：**E-DAIC 文本可用的严重程度估计明显优于无文本配置；音频与文本组合获得最佳平均二分类成绩。
- **更多模态不必然更好：**三模态配置在独立模态研究中开发 F1 最高，但测试 F1 最低，提示选择过拟合或分布差异。
- **临床机制方向性进化未获确认：**八轮研究的两个预注册主指标均未满足方向性进化标准，不能据此宣称流程持续向临床机制对齐。

## 7. 优点：方法与实验设计亮点

- **将可靠评估纳入自动化流程：**不仅生成候选，还检查数据对应关系、来源、执行有效性及替换条件。
- **联合探索具有明确动机：**能够处理配方与预测器之间的交互，较固定单组件优化更完整。
- **适合小样本、高维场景：**使用轻量模型、特征选择和强正则化，而非一味增加网络复杂度。
- **实验证据可审计：**保存预测、失败、角色审查、记忆版本和费用，便于追溯决策。
- **区分失败、非提升与有效替换：**被拒绝候选仍可提供后续实验线索，避免把一次未胜出解释为组件无用。
- **透明报告负面结果：**对记忆无稳定收益、搜索停滞和方向性假设失败均有明确披露。
- **部署时不依赖逐例 LLM：**开发调用可以摊销到后续预测，具有潜在实用价值。

## 8. 不足与局限

### 8.1 方法与统计保证

- bootstrap 估计的是选择集上的受试者抽样波动，**不等于对反复自适应搜索偏差的完整校正**。
- 裕度主要基于 incumbent 的分数波动，并非直接估计候选与 incumbent 的配对差值不确定性。
- 理论保证主要针对已保存开发分数；总体性能结论依赖未实证建立的统一误差假设。
- 搜索边界、模型家族和操作菜单由人工约束，因此属于受限空间内的经验驱动优化。

### 8.2 实验归因与复现风险

- 已继承流程的构建历史、与当前实验的关系，需要进一步审计，才能清晰分离初始化与新增改进的贡献。
- 主结果、消融、敏感性和历史部署研究采用不同协议，不宜跨表直接比较。
- 基线部分出现多数类或近常数预测，可能体现适配与训练问题，不代表架构本身能力上限。
- 缺少系统的等预算 AutoML 比较，尚不能充分隔离 LLM 审查相对于传统搜索的独立价值。
- LLM 输出未真正由实验种子控制；格式错误、可用工具和提取器否决会影响搜索空间与结果。
- 成本统计不完整，部分比较的分数与费用来自不同运行。

### 8.3 数据与临床应用

- 测试样本较少，缺少跨机构、跨文化、前瞻性外部验证。
- 压力分类和表演情绪代理任务不能直接支持 MDD 临床诊断结论。
- 未充分评估人口学公平性、风险校准、漏诊与误诊成本。
- 声学、语言和面部相关性不等于临床机制或因果解释。
- 心理健康数据经外部 API 处理存在隐私及授权风险，实际应用需要严格数据治理。
- **不能用于独立诊断：**临床部署仍需专业人员监督、前瞻性验证和公平性评估。

**综合评价：**MERID 的可信贡献是把数据一致性、联合搜索、证据审查和保守继承整合为可执行的自动流程开发系统。论文支持其在若干基准上的性能优势，但尚未证明持续递归改进、研究记忆或临床机制对齐能够稳定提升独立人群中的真实诊断能力。
