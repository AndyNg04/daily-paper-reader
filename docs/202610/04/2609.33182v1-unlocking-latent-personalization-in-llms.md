## 摘要
大语言模型（LLM）日益需要适应不同用户的个体需求，但当可用的用户专属样本有限时，实现有效的个性化仍颇具挑战。在本研究中，我们提出一种不同的视角：预训练 LLM 或许已具备潜在的个性化能力，因此，只需少量用户样本，就可能引导模型以最少的用户专属适配实现符合用户需求的行为。基于这一视角，我们提出 LatentPersonal 框架，将个性化建模为在共享潜在适配空间中的导航。LatentPersonal 从少量用户样本中推断紧凑的潜在表征，以引导模型进行用户专属适配，并通过变分信息瓶颈进行正则化，促使偏好表征保持紧凑。我们采用 LoRA 实现 LatentPersonal，利用其低秩参数化特性，将其作为个性化的天然低维适配空间。只需在共享低秩因子之间插入用户专属引导向量，模型便能通过对该紧凑表征进行轻量级推断，在无需更新共享 LoRA 参数的情况下，导航至个性化适配结果。在多个个性化数据集上的实验表明，LatentPersonal 在仅使用少量用户专属交互的情况下即可实现有效个性化，并显著降低用户专属适配开销；在单样本（one-shot）场景下，其表现尤为突出。

## Abstract
Large language models (LLMs) are increasingly expected to adapt to individual users, yet effective personalization remains challenging when only limited user-specific samples are available. In this work, we take an alternative perspective: pretrained LLMs may already possess latent capacity for personalization, and a few user samples may therefore suffice to guide the model toward user-aligned behavior with minimal user-specific adaptation. From this perspective, we propose LatentPersonal, a framework that formulates personalization as navigation in a shared latent adaptation space. LatentPersonal infers a compact latent representation from a few user samples to guide user-specific model adaptation, regularized with a variational information bottleneck to encourage compact preference representations. We instantiate LatentPersonal with LoRA, leveraging its low-rank parameterization as a natural low-dimensional adaptation space for personalization. By simply inserting a user-specific guidance vector between the shared low-rank factors, the model can navigate toward personalized adaptations through lightweight inference of this compact representation, without updating the shared LoRA parameters. Experiments across multiple personalization datasets demonstrate that LatentPersonal substantially reduces user-specific adaptation overhead while achieving effective personalization from only a few user-specific interactions, with particularly strong performance in the one-shot regime.

## 1. 核心问题与整体含义：如何用极少用户数据实现个性化？

### 研究背景与动机
- 通用大语言模型能够处理多种任务，但不同用户在兴趣、内容重点、表达风格和详细程度上存在差异，单一模型难以同时满足这些偏好。
- 直接利用少量用户交互微调模型，容易出现过拟合，也会带来每位用户独立训练、存储和维护适配参数的成本。
- 论文提出另一种视角：**预训练模型可能已经具备多种个性化相关行为，关键不一定是为每位用户重新学习，而是根据少量证据选择合适的行为组合。**

### 核心研究问题
> 能否从少量用户交互中推断一个紧凑偏好向量，通过共享适配结构实现个性化，而不在部署阶段进行用户专属参数优化？

论文提出 **LatentPersonal**，将个性化视为在共享低维适配空间中“导航”。其实际意义是把成本较高的逐用户微调，转变为一次轻量的用户表示推断。

**需要区分假设与结论**：实验支持共享潜在适配空间可以有效实现少样本个性化，但没有证明这种结构完全来自预训练；它也可能在跨用户训练过程中形成。

## 2. 方法论：紧凑用户表示与共享适配空间

### 2.1 核心思想
- 冻结预训练模型参数。
- 使用训练用户的数据，联合学习：
  - 一个从交互中提取偏好的编码器；
  - 一个所有用户共享的适配结构。
- 面对新用户时，仅推断其潜在向量，再由该向量控制共享适配结构，**无需为新用户执行梯度更新**。

概念上，个性化模型可以写成“基础模型参数 + 用户潜在向量对应的适配”。论文虽然用潜在空间优化问题描述“导航”，但部署时实际上采用编码器直接预测，而非迭代搜索用户向量。

### 2.2 用户偏好编码
- 每条用户交互由输入与目标回复组成。
- 使用冻结的基础模型提取最后一层隐藏状态，对非填充 token 做平均池化，得到交互表示。
- 再对多条交互表示平均池化，得到固定维度的用户表示。
- 将其输入轻量 MLP，预测一个对角高斯分布的均值和方差，作为用户潜在表示的后验分布。

默认编码器隐藏维度为 **512**，采用两层 MLP、GELU 和 dropout；潜在维度为 **16**。这种聚合能够处理不同数量的历史交互，但不显式保留交互顺序。

### 2.3 LoRA 实现：对共享低秩方向进行用户调制
标准 LoRA 用两个低秩矩阵的乘积表示参数更新。LatentPersonal 在二者之间插入用户向量：

\[
\Delta W_u^{(l)}=B^{(l)}\operatorname{diag}(z_u)A^{(l)}
\]

- \(A^{(l)}\)、\(B^{(l)}\)：所有用户共享的低秩因子。
- \(z_u\)：用户专属潜在向量，维度与 LoRA 秩一致。
- 每个潜在坐标控制一个共享秩一更新方向的贡献。

因此，用户专属部分不再是一套完整 LoRA 参数，而是一个紧凑系数向量；也不需要额外超网络生成大型适配参数。

### 2.4 变分信息瓶颈
用户历史同时包含偏好、任务内容和局部上下文。论文通过信息瓶颈，希望保留与个性化有关的信息，压缩其他变化。

训练目标包括：
- **适配损失**：根据支持集推断用户表示，再要求个性化模型在同一用户的独立查询集上生成正确回复。
- **压缩损失**：计算用户后验分布与标准高斯先验之间的 KL 散度。
- 总损失为适配损失与加权压缩损失之和，默认权重为 **0.01**。

理论上，KL 项构成用户表示与支持集之间互信息的变分上界；但查询集任务损失只是“保留适配信息”的实用代理，**不是相关互信息的严格界**，论文对此作了明确说明。

### 2.5 训练与部署流程
1. 随机抽取训练用户。
2. 从该用户历史中构造互不重叠的支持集和查询集。
3. 支持集大小从 **1、2、4、8、16** 中随机选择，查询集固定为 **4 条**。
4. 编码支持集，通过重参数化采样用户潜在向量。
5. 用该向量调制共享 LoRA，在查询集上计算任务损失及 KL 正则。
6. 联合更新偏好编码器和共享 LoRA，基础模型保持冻结。
7. 部署时固定上述共享参数，只根据新用户历史推断潜在表示。

论文还将这一思想扩展到 **Adapter 中间瓶颈调制**和 **Prompt Tuning 软提示调制**。

## 6. 主要结论与发现

### 少样本，尤其单样本表现较强
在 Llama 主结果的 1-shot 条件下，LatentPersonal 的 ROUGE-1、METEOR 和 CP 均领先所比较方法：

| 数据集 | LatentPersonal CP | 最强对比方法 CP | 分数差 |
|---|---:|---:|---:|
| HiCUPID | 5.95 | 5.64 | +0.31 |
| PRISM | 4.28 | 4.15 | +0.13 |
| PersonaMem | 6.14 | 5.97 | +0.17 |
| PIR | 4.38 | 4.28 | +0.10 |

但优势不是所有配置都成立。例如，8-shot 时 HiCUPID 的 LoRA、PRISM 的 ICL 和 PIR 的 LoRA 在 CP 上更高；16-shot 时部分传统方法也明显超过 LatentPersonal。

### 信息瓶颈贡献显著
- HiCUPID 1-shot 去除 IB 后，ROUGE-1 从 **0.4162 降至 0.2684**，CP 从 **5.95 降至 4.57**。
- 去除用户潜在调制或改为直接更新 LoRA，也会降低主要指标。
- 不同潜在维度没有单调收益，**4 维表示在部分指标上已表现良好**。

### 部署适配开销低，但不是全面最快
- HiCUPID 1-shot 个性化延迟：
  - LoRA：**0.3718 秒**；
  - Profile-to-PEFT：**0.0539 秒**；
  - LatentPersonal：**0.0219 秒**。
- LatentPersonal 的适配阶段约比 LoRA 快 **17 倍**。
- 但 8-shot 时其适配延迟高于 Profile-to-PEFT，PPlug 的适配延迟始终更低。
- LatentPersonal 生成阶段不一定更快，因此不能将适配加速等同于端到端加速。

### 用户表示确有作用
匹配用户向量优于交换向量、人口均值和共享 LoRA；缩放与插值会改变个性化表现。这支持用户表示具有功能性，但尚未建立潜在坐标与具体偏好属性的明确对应关系。

## 7. 优点与亮点

- **结构简洁**：只在共享 LoRA 因子间加入向量调制，无需大型参数生成器。
- **部署无需逐用户优化**：新用户仅需前向推断，适合冷启动和大规模用户服务。
- **训练与目标场景一致**：随机支持集大小及独立查询集鼓励少样本泛化，而不是记住支持样本。
- **理论表述相对克制**：区分信息瓶颈动机、严格 KL 上界和任务损失代理。
- **评测不局限于词面重合**：同时考察内容与表达偏好。
- **用户专属性对照有价值**：证明收益不只是来自人口级共享微调。
- **可扩展性较好**：同一框架可以用于 LoRA、Adapter 和 Prompt Tuning。

## 8. 不足与局限

### 机制解释与实验边界
- **“解锁预训练潜能”未被直接证明**：无法区分预训练已有能力与跨用户训练新形成结构的贡献。
- 两个基础模型规模相近，尚未覆盖更小、更大、多模态或跨语言模型。
- 各 benchmark 独立训练，未证明跨领域、跨数据集和明显分布外用户的泛化能力。
- 长期偏好变化、冲突偏好和持续学习未得到验证。

### 评价与偏差风险
- CP、PP 依赖单一 LLM 评审，缺少人工验证和多评审模型一致性分析。
- 参考回复可能影响个性化判断；词面指标也无法充分衡量开放式回复的用户效用。
- PRISM 的评分与细粒度反馈如何转化为训练目标，文本说明不够完整。
- 没有直接评测事实正确性、安全性及通用能力保持，个性化分数高不等于整体质量更好。

### 方法与复现限制
- 平均池化忽略时间顺序和近期偏好，可能混合任务内容与真正偏好。
- 共享低秩基限制可表达的适配方向，罕见或复杂偏好可能难以表示。
- 去除 IB 后的巨大下降值得进一步用多种子、替代正则和训练动态分析确认。
- 改变潜在维度时也改变 LoRA 秩，因此维度实验同时改变了共享适配容量。
- 部署时使用后验均值还是采样、详细计时边界和缓存设置交代不够清楚。
- 紧凑用户向量并不自动保护隐私；敏感偏好泄露、删除机制和恶意历史交互未被分析。

### 总体评价
**LatentPersonal 的可靠贡献，是展示了“共享适配基 + 紧凑用户向量”能够在若干 benchmark 上实现有效的少样本个性化，并减少部署时的用户专属优化成本。**它为个性化助手提供了实用方案，但预训练潜能的来源、真实长期用户效果及全面的成本优势，仍需要进一步验证。
