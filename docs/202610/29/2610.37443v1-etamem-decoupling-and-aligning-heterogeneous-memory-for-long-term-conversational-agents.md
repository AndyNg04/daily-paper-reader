## 摘要
长期记忆使大型语言模型（LLM）能够在长时间对话中保持连贯且个性化的交互。然而，现有记忆系统面临两项关键挑战：（1）信息纠缠，即异构信息混杂在粒度较粗的记忆单元中；（2）组织失配，即主要基于语义相似度构建的记忆结构可能忽略其他关联。为应对这些挑战，我们提出 ETAMem，这是一种多视图记忆框架，可解耦异构对话信息，并根据其不同特征对齐记忆表征与组织方式。具体而言，异构信息解析模块提取原子记忆单元并识别情感信息；随后，视图特定的记忆结构化模块将这些单元组织为三个互补的层次视图：事件、情感和时间。ETAMem 通过自适应校准的阈值增量式维护记忆结构。在检索阶段，基于熵的检索方法会在不同视图间分配针对查询的预算，并在各视图内执行层次化搜索。在 LoCoMo 和 LongMemEval-S 上的实验表明，ETAMem 优于最先进的基线方法，准确率相对提升分别达到 12.46% 和 7.96%，同时保持了有竞争力的 token 效率。进一步分析表明，不同记忆视图具有互补优势。

## Abstract
Long-term memory enables Large Language Models (LLMs) to maintain coherent and personalized interactions across extended conversations. However, existing memory systems face two key challenges: (1) Information Entanglement, where heterogeneous information is mixed within coarse-grained memory units; and (2) Organizational Mismatch, where memory structures based primarily on semantic similarity may overlook other associations. To address these challenges, we propose ETAMem, a multi-view memory framework that decouples heterogeneous conversational information and aligns memory representations and organization with its distinct characteristics. Specifically, heterogeneous information parsing extracts atomic memory units and identifies affective information. View-specific memory structuring then organizes these units into three complementary hierarchical views: Event, Affect, and Time. ETAMem incrementally maintains memory structures with adaptively calibrated thresholds. For retrieval, entropy-based retrieval allocates query-specific budgets across views and performs hierarchical search within each view. Experiments on LoCoMo and LongMemEval-S demonstrate that ETAMem outperforms state-of-the-art baselines, achieving relative accuracy improvements of 12.46% and 7.96%, respectively, while maintaining competitive token efficiency. Further analyses demonstrate the complementary benefits of different memory views.

## 1. 核心问题与研究背景

长期对话智能体需要记住用户过去的经历、情绪、偏好及其变化，才能提供连贯、个性化的回应。论文认为，现有长期记忆系统主要存在两类问题：

- **信息纠缠**：一条对话可能同时包含事件、情绪和时间信息，若整体存储或简单摘要，容易将不同信息混在一起，增加检索噪声。
- **组织失配**：主要按语义相似性组织记忆，未必能有效聚合跨主题的偏好，也不一定适合回答时间范围、经历顺序和偏好更新等问题。

例如，“上周三与朋友爬山，很累，但很喜欢风景，还想再去”既包含事件，也包含疲惫、喜爱和再次参与的意愿。回答“我喜欢什么活动”和“我上周做了什么”，需要不同的记忆组织方式。

**论文的核心主张是：不仅要把记忆拆细，还应让不同类型的信息使用相适应的表征、组织方式和检索策略。** ETAMem 因而构建事件、情感和时间三种互补的层次视图。

## 2. 方法论：核心思想与算法流程

### 2.1 原子记忆提取与情感识别

- 使用 LLM 将每轮对话分解为多个**原子记忆单元（AMU）**，每个单元尽量表达一个独立、语义完整的信息。
- 提取提示要求明确主体、将代词替换为具体人物、保留必要上下文，并将观点归属于表达者。
- 使用现成的情感分类器，为每个 AMU 标注负向、中性或正向：
  - 中性单元进入事件视图；
  - 正向和负向单元进入情感视图；
  - 所有单元均进入时间视图。

这里实际使用的是**情感极性作为情感信息的代理信号**，并非完整的情绪、态度和偏好识别模型。

### 2.2 三种视图的差异化组织

| 视图 | 存储内容 | 表征与组织依据 | 主要作用 |
|---|---|---|---|
| 事件视图 Event | 中性 AMU | 文本嵌入与语义相似度 | 检索事实、经历、实体和活动 |
| 情感视图 Affect | 正向、负向 AMU | 情感嵌入与情感语义相似度 | 聚合情绪、喜好、态度 |
| 时间视图 Time | 全部 AMU | Session → Day → Week → Month | 支持时间定位与跨时段聚合 |

- 叶节点存储 AMU，内部节点保存子树摘要，以支持由粗到细的检索。
- 事件和情感视图根据内容动态形成层次结构；时间视图采用预定义的时间粒度。
- 三个视图并非三个完全独立的信息库：时间视图覆盖全部记忆，事件和情感视图分别覆盖其中的子集。

### 2.3 增量维护与自适应校准

新记忆到达时，系统执行以下操作：

1. **插入定位**：以子树中 AMU 向量的均值作为节点中心，通过束搜索寻找最合适的叶节点。
2. **按相似度决定插入方式**：
   - 高相似度：加入已有叶节点；
   - 中等相似度：在相应父节点下新建叶节点；
   - 低相似度：新建根节点。
3. **分裂**：叶节点过大或内部凝聚度过低时，使用余弦 K-means 拆分。
4. **合并**：会话结束后，合并中心向量高度相似的节点；叶节点合并还需满足容量限制。
5. **延迟摘要更新**：累计足够多次变化后才重新生成内部节点摘要，减少 LLM 调用。

自适应机制包括：

- 根据记忆规模调整叶节点容量、分支数和树深度；
- 使用 **Otsu 方法**划分相似度分布，再以分位数估计插入、分裂和合并阈值；
- 使用指数移动平均平滑阈值更新，降低结构震荡。

### 2.4 基于熵的跨视图检索

给定查询，检索流程为：

1. 计算查询与每个视图内所有叶节点摘要的文本相似度。
2. 通过带温度参数的 Softmax，将相似度转为概率分布。
3. 计算归一化熵：
   - 分布越集中，熵越低；
   - 系统认为该视图的检索信号越明确。
4. 按“**1 − 归一化熵**”分配跨视图检索预算，每个视图至少分配一个叶节点。
5. 在各视图内执行层次束搜索，综合文本语义相似度和 BM25 词法匹配。
6. 合并、去重检索到的 AMU，并交给 LLM 回答。

**一个重要细节**：情感嵌入主要用于情感视图的组织；检索阶段对节点摘要的语义评分仍使用文本编码器。

如果模型根据 AMU 无法回答、输出“no information”，系统会**回退到关联的原始对话轮次**，尝试恢复抽取或压缩时丢失的细节，而不是直接读取全部历史。

## 6. 主要结论与发现

### 6.1 总体准确率提升

| 数据集 | 最强基线 TiMem | ETAMem | 绝对提升 | 相对提升 |
|---|---:|---:|---:|---:|
| LoCoMo | 75.30% | **84.68%** | **9.38 个百分点** | **12.46%** |
| LongMemEval-S | 76.88% | **83.00%** | **6.12 个百分点** | **7.96%** |

其中：

- LoCoMo 多跳准确率为 **80.14%**，优于 MAGMA 的 69.50%。
- LongMemEval-S 跨会话准确率为 **78.95%**，时间推理准确率为 **75.19%**。
- CloneMem 选择题准确率达到 **92.59%**，记忆帮助度与召回率分别为 **0.9200、0.8031**。

ETAMem 并非所有子任务都第一，例如 LongMemEval-S 的单会话助手和偏好类别仍有其他方法更高。

### 6.2 三视图与专用表征具有互补价值

- 统一采用语义、情感或时间组织，整体均不如三视图方案。
- Qwen3-30B 下，共享文本或情感表征，使 LongMemEval-S 准确率由 80.40% 降至 72.80% 和 74.40%。
- 相比均匀预算路由，熵路由在两个数据集上分别提升 **1.62、5.40 个百分点**。

不过，时间视图覆盖全部 AMU，而事件和情感视图仅覆盖子集，因此单视图对比同时受到**组织方式与信息覆盖量**影响。

### 6.3 原文回退是重要收益来源

关闭回退后：

- LoCoMo：84.68% → 84.48%；
- LongMemEval-S：83.00% → 74.20%。

这说明，尤其在长叙事场景中，最终性能不只是来自三视图检索，**恢复 AMU 抽取丢失的信息同样关键**。

### 6.4 剩余瓶颈既有检索，也有推理

- LongMemEval-S 中，14.8% 的全部问题属于“证据已检索到，但答案错误”。
- LoCoMo 中，约 60.4% 的错误涉及证据缺失或不完整。

因此，扩大检索覆盖和改进证据聚合推理需要分别处理。

## 7. 主要优点

- **问题定义明确**：区分“记忆粒度过粗”和“组织原则不合适”，不把所有失败归因于检索器。
- **表征与结构协同设计**：情感信息不只是检索加权项，而是拥有专门的编码和组织结构。
- **兼顾持续更新**：插入、分裂、合并、自适应阈值及延迟摘要组成了较完整的在线维护流程。
- **多视图预算自适应**：无需额外调用 LLM 路由器，就能按查询调整检索覆盖。
- **实验分析较全面**：覆盖效果、token 成本、组件消融、人工评估及失败模式。
- **效率与准确率取得较好平衡**：较 TiMem、A-MEM 等方法降低构建 token，同时提升总体准确率；但并非成本最低，LightMem 在两个主数据集上的构建和推理 token 均更少。

## 8. 不足与局限

### 8.1 情感极性不等于偏好与态度

- 中性措辞也可能表达稳定偏好，例如“我通常选择无糖饮料”。
- “很累”与“不喜欢这项活动”并不等价，短期情绪也不必然代表长期偏好。
- 人工标注评测中，分类器 F1 为 **80.53%**，说明错误分流仍不可忽略；标注者一致性 κ 为 0.651，也反映任务边界并不简单。

### 8.2 AMU 抽取不能保证信息无损

- 文中以保留原始信息为目标，但提示词会过滤闲聊，并把部分任务、假设问答压缩成一行主题摘要。
- 共指解析、人物归属、因果关系和隐含语境可能被错误处理。
- LongMemEval-S 对回退机制的高度依赖，表明原子化与压缩确实可能丢失关键细节。

### 8.3 熵路由存在理论与实现边界

- 低熵只表示分布集中，不保证视图真正相关。
- 枚举、统计和多跳问题可能需要分散在多个叶节点的证据，低熵优先可能不利于全面覆盖。
- 单叶视图的归一化熵为零，可能天然获得较高置信度。
- 当各视图分布接近均匀时，权重归一化需要数值保护；预算取整并要求每视图至少一个，也未必严格满足总预算，文中未详述处理办法。

### 8.4 大规模扩展与实时性能尚未证实

- 路由需要扫描所有叶摘要，复杂度约为 **O(LD)**，并非整体对数级检索。
- 节点合并最坏需要 **O(N²D)** 的相似度计算，凝聚度检查也涉及叶内两两比较。
- 缺少超大记忆库、长期连续运行、并发访问和延迟评测。
- 延迟摘要更新虽然节省调用，也可能使检索依据暂时过时。

### 8.5 实际个性化应用验证有限

- 主要评测是历史问答与选择题，未直接测量长期用户满意度、主动服务质量或真实交互收益。
- 未系统覆盖多语言、复杂隐式偏好及跨文化情感表达。
- 未充分处理敏感记忆的隐私、删除、权限控制与恶意信息写入等部署问题。
- 时间层次和“优先最新信息”的提示策略，并不等于具有显式事实失效、冲突消解和版本管理能力。

**总体而言，ETAMem 为“按信息类型组织长期记忆”提供了较有说服力的实验证据，但其结果应理解为三视图组织、专用表征、检索路由及原文回退共同作用的收益，而非单一结构创新的效果。**
