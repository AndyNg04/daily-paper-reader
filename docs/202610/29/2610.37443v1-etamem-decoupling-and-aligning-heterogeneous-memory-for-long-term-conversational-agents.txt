## Abstract 

Long-term memory enables Large Language Models (LLMs) to maintain coherent and personalized interactions across extended conversations. However, existing memory systems face two key challenges: (1) Information Entanglement , where heterogeneous information is mixed within coarse-grained memory units; and (2) Organizational Mismatch , where memory structures based pri-marily on semantic similarity may overlook other associations. To address these challenges, we propose ETAMem, a multi-view mem-ory framework that decouples heterogeneous conversational infor-mation and aligns memory representations and organization with its distinct characteristics. Specifically, heterogeneous information parsing extracts atomic memory units and identifies affective in-formation. View-specific memory structuring then organizes these units into three complementary hierarchical views: Event, Affect, and Time. ETAMem incrementally maintains memory structures with adaptively calibrated thresholds. For retrieval, entropy-based retrieval allocates query-specific budgets across views and performs hierarchical search within each view. Experiments on LoCoMo and LongMemEval-S demonstrate that ETAMem outperforms state-of-the-art baselines, achieving relative accuracy improvements of 12.46% and 7.96%, respectively, while maintaining competitive to-ken efficiency. Further analyses demonstrate the complementary benefits of different memory views.

Existing memory architectures for LLMs can be broadly catego-rized into flat and structured approaches. Flat approaches [2, 34] store extracted conversational information as separate textual mem-ory entries, typically retrieved through embedding-based similarity search. In contrast, structured approaches [14, 22, 31, 32] organize memories through hierarchies or graphs to capture dependencies among memory units. However, the heterogeneous nature of con-versational information poses two key challenges for memory or-ganization and retrieval. 

(1) Information Entanglement. Existing memory systems [2, 34] often treat conversational memory entries as the basic units arXiv:2610.37443v1 [cs.CL] 27 Oct 2026 Conference’17, July 2017, Washington, DC, USA Qian et al. 

of memory representation and organization. Although some ap-proaches [6, 31] extract keywords or summaries, they do not explic-itly distinguish heterogeneous information types. As illustrated in Figure 1, a single dialogue turn may contain factual events, personal preferences, and temporal contexts. Without decomposition, these aspects remain entangled, making it difficult to isolate relevant evidence and introducing retrieval noise. 

(2) Organizational Mismatch. Existing memory systems [14, 22] organize memories through temporal or relational structures. Recent approaches [12, 32] further combine multiple structures. However, these structures do not necessarily align memory rep-resentations and organization criteria with different information types. As shown in Figure 1, organizing memories by semantic topics may scatter related preferences across different branches, making affective evidence difficult to retrieve collectively. These limitations motivate a fundamental question: how can con-versational information be identified, represented, and organized for long-term memory retrieval? Different information types require distinct representations and organizational principles. For example, answering “what activity do I like?” requires connecting affective information across different contexts, whereas “what did I do this week?” requires aggregating experiences according to their tempo-ral relations. This distinction aligns with findings from cognitive neuroscience, which suggest that episodic memory and emotional processing involve functionally specialized yet interacting neural systems [17, 21]. This motivates decoupling heterogeneous con-versational information and aligning memory representations and organization with its distinct characteristics. In this paper, we propose ETAMem, an Event-Time-Affect Mem ory framework for long-term conversational agents. ETAMem first per-forms heterogeneous information parsing by decomposing dialogue turns into semantically complete atomic memory units (AMUs) and identifying their affective characteristics. Through view-specific memory structuring, these AMUs are then organized into three hierarchical views. Specifically, the Event view organizes factual experiences through semantic similarity, the Affect view organizes emotions, attitudes, and preferences through affect-aware represen-tations, and the Time view indexes all memories through temporal hierarchies. To support continual interaction, ETAMem incremen-tally maintains the Event and Affect hierarchies through attach-ment, splitting, merging, and lazy summary updates, while adap-tively calibrating maintenance thresholds. Given a query, entropy-based retrieval allocates budgets across views through adaptive routing and performs hierarchical beam search to retrieve relevant memories. Experiments on two long-term dialogue memory bench-marks demonstrate that ETAMem consistently improves memory performance, particularly on multi-hop and temporally grounded queries. Overall, our work makes the following contributions: 

• We propose ETAMem, a multi-view memory framework that organizes heterogeneous conversational information into complementary Event, Affect, and Time hierarchies with view-specific representations. 

• We develop a dynamic memory maintenance mechanism with adaptive threshold calibration. We further employ entropy-based routing to allocate query-specific retrieval budgets across complementary memory views. 

• Extensive experiments on LoCoMo and LongMemEval-S demonstrate that ETAMem outperforms strong baselines, particularly on multi-hop and temporal reasoning questions, while maintaining competitive token costs. 

## 2 Related Work 2.1 Memory Systems for LLM Agents 

Flat memory. Early memory systems store extracted facts or inter-action summaries as independent units, typically retrieved through semantic similarity [2, 34]. For long-term access, MemGPT [19] separates in-context and external memory through paging, Memo-ryOS [13] organizes histories into short-, mid-, and long-term layers, and LightMem [6] uses staged offline consolidation. These designs emphasize where and when memories are stored or consolidated, while retrieval often relies on general semantic matching. 

Structured memory. Structured systems organize memories into hierarchies or graphs. Tree-based approaches support memory abstraction at different levels of granularity. TiMem [14] builds a five-level temporal memory tree to consolidate experiences over time, while xMemory [10] decomposes interaction histories into se-mantic components and organizes them hierarchically. Graph-based approaches emphasize explicit memory associations. A-MEM [31] dynamically updates semantic links between memory notes, whereas Zep [22] maintains a temporal knowledge graph of evolving facts and relationships. HingeMem [35] uses boundary-based hyper-graphs to connect memories by person, time, location, and topic. However, these methods primarily emphasize temporal, seman-tic, or relational organization without explicitly aligning memory hierarchies with different types of conversational information. 

Multi-structure memory. Recent work organizes memory through multiple complementary structures or information types. MemWeaver [33] develops complementary behavioral and cogni-tive memory hierarchies to capture user interactions and long-term preferences. H-Mem [32] combines a temporal-semantic tree with an entity knowledge graph. MAGMA [12] links memory events through separate semantic, temporal, causal, and entity graphs. MemGAS [30] associates multi-granularity memory units through clustering and selects retrieval granularity via entropy-based rout-ing. MemoType [28] distinguishes different memory types without hierarchical organization. These methods either combine multiple memory structures without explicitly decoupling heterogeneous information or distinguish information types without organizing them into specialized hierarchies. 

## 2.2 Affect-Aware Memory and Retrieval 

Recent studies have explored affective information to improve mem-ory retrieval and personalized interactions. Emotional RAG [11] combines emotional and semantic relevance to retrieve memories for role-playing agents. REG [27] retrieves emotionally similar ex-amples to support empathetic response generation. PAMU [25] dynamically updates memories to reflect evolving user preferences, while Sentipolis [7] models emotion dynamics and emotion-memory coupling to maintain affective continuity. Recent benchmarks fur-ther emphasize the importance of affective and personalized mem-ory. CloneMem [9] evaluates the retention and retrieval of personal experiences, preferences, and opinions, while ENPMR-Bench [8] ETAMem: Decoupling and Aligning Heterogeneous Memory for Long-Term Conversational Agents Conference’17, July 2017, Washington, DC, USA 

focuses on memory retrieval for emotional support. Despite these advances, existing approaches primarily leverage affective informa-tion to guide retrieval, memory updates, or generation, with limited attention to organizing memories through affective associations. 

## 3 Method 

We present ETAMem, a multi-view memory framework for decou-pling and aligning heterogeneous conversational information. First, heterogeneous information parsing extracts atomic memory units (AMUs) and identifies their affective characteristics. These units are then organized through view-specific memory structuring into three complementary views: Event, Affect, and Time. To support evolving conversations, dynamic memory maintenance updates the hierarchies, while adaptive calibration adjusts maintenance thresholds. Finally, entropy-based retrieval allocates query-specific budgets across views and performs hierarchical beam search to retrieve relevant AMUs, as shown in Figure 2.

Memory Organization. To support structured organization and coarse-to-fine retrieval over heterogeneous AMUs, ETAMem organizes the current memory as three hierarchical views: 

M = {V event , Vaffect , Vtime } . (4) 

The Event View Vevent organizes neutral AMUs according to textual semantics. AMUs with similar semantic representations are hierarchically grouped into event-related nodes, capturing recur-ring events, entities, and interactions. 

The Affect View Vaffect organizes positive and negative AMUs according to affective semantics. AMUs with similar affective rep-resentations are hierarchically grouped into nodes, capturing per-sistent preferences and attitudes. 

The Time View Vtime organizes AMUs through a temporal hierarchy: Session → Day → Week → Month. AMUs are stored at the Session level, while higher-level nodes provide summaries. Unlike Event and Affect views, the Time view follows predefined temporal granularity rather than semantic grouping. 

Tree Structure. Each memory view adopts a hierarchical struc-ture. Leaf nodes store AMUs, while internal nodes maintain textual summaries of their subtrees. For an internal node whose children are leaves, its summary is generated from the AMUs stored in those leaves. For higher-level internal nodes, the summary is generated from the summaries of their child nodes. 

## 3.4 Dynamic Memory Maintenance 

3.4.1 Memory Maintenance. ETAMem maintains its memory trees through online insertion and incremental structural refinement. For each incoming dialogue turn, the extracted AMUs are inserted into their corresponding views. At the end of each session, the Event and Affect views undergo structural maintenance, with Split and Merge operations triggered only when their respective conditions are met. In contrast, the Time view follows a predefined temporal hierarchy and requires only deterministic insertion without maintenance.

## 4 Experiments 4.1 Experimental Setup 

Datasets. We conduct experiments on two long-term memory benchmarks. LoCoMo [16] contains multi-session interactions from 10 user groups, while LongMemEval-S [29] comprises 500 questions designed to assess memory over extended contexts. Further details of the datasets are provided in Appendix B. 

Baselines. We compare ETAMem with representative mem-ory baselines: MemoryBank [34], A-MEM [31], Mem0 [2], Memo-ryOS [13], MemOS [15], MAGMA [12], TiMem [14], LightMem [6]. 

Implementation Details. For fair comparison, we follow the same evaluation settings as TiMem. Specifically, all methods use gpt-4o-mini as the LLM backbone and Qwen3-Embedding-0.6B as the textual embedding model. We additionally evaluate ETAMem with Qwen3-30B-A3B-Instruct-2507, denoted as w/ Qwen3-30B . The retrieval budget is set to 𝐾 = 20 for all methods. For ETAMem, we set 𝜆 = 0.25, beam width 𝐵 = 10, 𝛿 = 20, and routing temperature 

𝛽 = 0.1. The remaining parameters are described in the calibration settings. For the Affect view, we employ two RoBERTa-based affec-tive models: Twitter-RoBERTa-Sentiment [1] as the classifier and RoBERTa-GoEmotions [3] as the encoder. ETAMem is evaluated over three runs, with results reported as mean accuracy ± sample standard deviation in Tables 2 and 3. We evaluate all methods using LLM-as-a-judge accuracy. Following [6], memory construction cost is measured as the average number of total tokens consumed by LLM calls during memory construction per session, while inference cost is measured as the average number of input tokens consumed per query. 4.3.2 Effect of View-Specific Memory Organization. To investigate whether heterogeneous dialogue information benefits from spe-cialized organization, we compare ETAMem with three unified strategies that organize all AMUs into a single hierarchy without distinguishing information types. Unified Semantic and Unified Af-fective organize memories using textual and affective embeddings, respectively, while Unified Temporal employs a unified temporal hierarchy. As shown in Table 5, all unified strategies underper-form ETAMem in overall accuracy. Unified Semantic performs best among the unified strategies on LoCoMo, while Unified Affective achieves the highest overall accuracy on LongMemEval-S. Notably, Unified Affective matches ETAMem on preference-related ques-tions (SSP), while Unified Temporal matches ETAMem on temporal reasoning (TR). These results suggest that different organizational principles can benefit specific information types, but no single uni-fied structure effectively accommodates their heterogeneous char-acteristics. By integrating complementary type-specific memory views, ETAMem achieves superior overall performance. 

4.3.3 Effect of View-Specific Memory Representations. We further investigate whether separating information types is sufficient, or whether different memory views also benefit from specialized rep-resentations. To this end, we compare ETAMem with two variants that retain the Event and Affect views but use shared representa-tions. Shared Text uses textual embeddings for both views, whereas 

Shared Affect uses affective embeddings for both views. The Time view remains unchanged. As shown in Table 6, both variants un-derperform ETAMem, with overall accuracy decreasing by 7.60 and 6.00 percentage points, respectively. These results indicate that distinguishing information types alone does not fully capture their heterogeneous characteristics. View-specific representations fur-ther enhance the effectiveness of specialized memory organization. 

4.3.4 Effect of Memory View Configurations. To investigate whether combining complementary memory views improves retrieval per-formance, we evaluate different view configurations using Qwen3-30B. As shown in Table 7, Time-only achieves the strongest per-formance among single-view configurations on both benchmarks. This may be attributed to its complete memory coverage, whereas the Event and Affect views each contain only a subset of AMUs. Combining views generally improves performance, with Time + Affect achieving 79.35% on LoCoMo and Event + Time reaching 74.80% on LongMemEval-S. ETAMem further achieves 80.84% and 80.40% on the two benchmarks, respectively, suggesting the benefits of jointly retrieving from complementary memory views.

As shown in Table 7, Mean Routing achieves the strongest performance among the al-ternatives, with accuracies of 79.22% and 75.00% on LoCoMo and LongMemEval-S, respectively. ETAMem further improves accu-racy to 80.84% and 80.40%, outperforming Mean Routing by 1.62 and 5.40 percentage points, respectively. ## 5 Conclusion 

In this paper, we proposed ETAMem, a multi-view memory frame-work that decouples heterogeneous conversational information and aligns memory representations and organization with its distinct characteristics. ETAMem integrates heterogeneous information parsing, view-specific memory structuring, and entropy-guided retrieval, supported by dynamic maintenance and adaptive calibra-tion. Experiments on two long-term memory benchmarks demon-strate relative improvements of 12.46% and 7.96% over the strongest baselines, respectively, with strong multi-hop performance and competitive token efficiency. Further analysis highlights the com-plementary benefits of different memory views and the effectiveness of adaptive routing. Despite these improvements, our affective rep-resentations rely on sentiment polarity, which may fail to identify neutral expressions of preferences or attitudes as affective infor-mation. Future work will incorporate explicit affective relevance classification to address this limitation. ## B Experimental Setup B.1 Dataset Details 

LoCoMo . LoCoMo [16] evaluates long-term conversational mem-ory through multi-session dialogues with temporal information. We use the full benchmark containing 10 conversation groups and 1,540 questions, covering single-hop retrieval, multi-hop reasoning, open-domain queries, and temporal reasoning. 

LongMemEval-S. LongMemEval-S [29] evaluates memory sys-tems under long-term interactions. It contains 500 conversations and 500 questions, covering knowledge updates, multi-session rea-soning, single-session interactions, temporal reasoning, and selec-tive response generation. 

CloneMem. CloneMem [9] is a long-term personal memory benchmark constructed from non-conversational digital traces, in-cluding diaries, social media posts, and emails spanning one to three years. CloneMem evaluates memory capabilities across three dimensions: Experience, Emotion, and Opinion.

## C Additional Analysis C.1 Human Evaluation of Affect Classification 

To assess affect identification reliability, we sampled 400 Atomic Memory Units (AMUs) from LoCoMo and LongMemEval-S. Two university annotators voluntarily and anonymously labeled each AMU as affective or non-affective, independently following shared guidelines. Cohen’s kappa was 0.651, and disagreements were re-solved through discussion to obtain gold-standard labels. The guide-lines are provided in Table 11. 

LLM-based Affect Classification. For comparison, we employ GPT-4o-mini to identify affective information using the prompt shown in Table 12. The model produces a binary response ( yes or no ), corresponding to affective and non-affective labels, respectively. 

Classification Performance. Table 13 compares RoBERTa-Sentiment with GPT-4o-mini on the human-annotated benchmark. RoBERTa-Sentiment achieves an F1 score of 80.53%, surpassing GPT-4o-mini at 79.39%. It also achieves higher precision of 80.79%, compared with 73.60% for GPT-4o-mini, although its recall is lower at 80.26% versus 86.18%. These results demonstrate that a light-weight classifier provides competitive affect identification without additional LLM inference during memory construction.
