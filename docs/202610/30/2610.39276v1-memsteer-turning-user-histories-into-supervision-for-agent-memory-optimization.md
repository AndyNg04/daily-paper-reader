## 摘要
有效的智能体记忆系统应适应用户历史和任务需求。人工标注的监督信号能够为这种适应提供指导，通过反馈评估并改进记忆设计。然而，对于新的用户历史，合适的标签往往难以获得，而人工构造问答（QA）对及其支持证据的成本高昂。我们提出 MemSteer，将未标注的用户历史转化为带有支持证据的问答监督信号，用于优化记忆设计。MemSteer 构建以证据为依据的答案规划，明确说明相关记录中的事实如何共同支持参考答案。该规划指导问题生成，同时通过基于来源的审查和盲式答案恢复来检验生成的标注。为研究这种监督信号的效用，我们开发了 MemSteer-Opt：它结合基于问答的设计评估与证据引导的失败诊断，在不更新模型参数的情况下修订记忆存储、检索和上下文构建。ATM-Bench 和 RHELM 上的实验表明，该监督信号的效果可与官方问答指导的优化相媲美。相较于 Base-BM25，MemSteer-Opt 在 ATM-Bench 上将 Question Score 提高了 13.4 分；在不使用和使用外部数据的情况下，分别将 RHELM 准确率提高了 4.1 和 6.6 个百分点。此外，该监督信号也能提升两种现有优化器在 ATM-Bench 上的表现；新用户实验则表明，利用从目标用户历史生成的监督信号，可以持续优化记忆设计。

## Abstract
An effective agent memory system should adapt to a user's history and task requirements. Human-annotated supervision can guide this adaptation by providing feedback for evaluating and improving memory designs. Yet suitable labels are rarely available for new user histories, and manually constructing QA pairs and supporting evidence is costly. We introduce MemSteer, which turns unlabeled user histories into question-answer (QA) supervision with supporting evidence for memory-design optimization. MemSteer constructs an evidence-grounded answer plan that specifies how facts across related records jointly support a reference answer. The plan guides question generation, while source-grounded auditing and blind answer recovery check the resulting annotations. To study the utility of this supervision, we develop MemSteer-Opt, which combines QA-based design evaluation with evidence-guided failure diagnosis to revise memory store, retrieval, and context construction without updating model parameters. Experiments on ATM-Bench and RHELM show that this supervision is competitive with official-QA-guided optimization. Relative to Base-BM25, MemSteer-Opt improves ATM-Bench Question Score by 13.4 points and RHELM accuracy by 4.1 and 6.6 points without and with external data, respectively. The supervision also benefits two existing optimizers on ATM-Bench, while new-user experiments demonstrate continued design optimization using supervision generated from the target histories.

## 2. 方法论：核心思想与技术流程

### 2.1 构造带证据的问答监督

生成的监督集可表示为：

\[
D_H=\{(q_i,a_i,E_i)\}_{i=1}^{N}
\]

其中，\(q_i\) 是问题，\(a_i\) 是参考答案，\(E_i\) 是支持答案的源记录及文本片段引用。

#### 第一步：图引导的材料准备
- 将用户历史组织为图：节点是源记录，边表示同一会话、相邻文档章节、显式引用或足够的词汇重叠。
- 从种子节点沿路径扩展，采样连通子图。
- 在上下文预算内形成材料包，保留原文、记录标识及片段来源。

这一设计旨在让问题涉及**有关联的多条记录**，而不是随机拼接互不相关的信息。

#### 第二步：先规划答案，再生成问题
LLM 先构造“证据支撑的答案计划”，明确：
- 要询问的主体、属性和约束；
- 支撑答案的事实及其来源片段；
- 每条证据记录的贡献；
- 如何组合事实得到答案；
- 最终参考答案与证据集合。

计划先经过结构一致性、来源覆盖等程序化检查，再由独立调用生成可单独理解的问题。

#### 第三步：来源审计与盲答恢复
- **来源审计**：检查答案是否有来源支持、问题是否符合计划、各事实及证据贡献是否成立。
- **盲答恢复**：另一个读取过程仅接收问题、答案类型和材料包，不接收参考答案，重新回答并引用来源。
- 只有满足以下条件才保留：
  - 问题被判断为可回答；
  - 恢复答案经类型特定规范化后与参考答案完全一致；
  - 引用覆盖全部选定证据记录。

需要注意：**覆盖全部证据并不证明每条证据都不可缺少**。

### 2.2 用监督数据优化记忆设计

将设计写为 \(d=(s,r,c)\)，分别对应存储、检索和上下文构建：

\[
M_d=\mathrm{Store}_s(H)
\]

随后依次进行检索、上下文组装和固定模型回答。训练集用于产生修改建议，验证集用于接受或拒绝候选设计。

#### 证据引导的失败诊断
对回答错误的训练样本：
- **回答失败**：所需证据及片段已经完整进入最终上下文，但仍答错。
- **存储失败**：缺失证据对应的记录无法从当前记忆系统恢复。
- **检索失败**：记录仍可恢复，但未完整进入回答上下文。

这属于一种实用的阶段归因规则，而不是严格的因果证明；检索类别也可能包含排序、截断或上下文组装造成的证据遗漏。

#### 分层反馈与迭代选择
- 按失败类别分别抽样，避免常见错误占满反馈预算。
- LLM 根据当前设计、失败案例、证据和执行轨迹提出修改。
- 重建记忆并在固定验证集上评估。
- **仅当验证准确率严格提高时接受修改**。
- 每个设置运行 20 轮反思式迭代。

优化过程中固定回答模型、回答指令和最终上下文预算。生成监督还可提供给 **M⋆、MemEvolve**，验证其是否独立于自研优化器有效。

## 6. 主要结论与发现

### 6.1 自动监督确实能改善记忆设计

| 设置 | Base-BM25 | MemSteer-Opt | 提升 |
|---|---:|---:|---:|
| ATM-Bench QS | 54.9 | 68.3 | +13.4 分 |
| ATM-Bench R@10 | 61.7 | 84.1 | +22.4 个百分点 |
| ATM-Bench-Hard QS | 8.2 | 29.1 | +20.9 分 |
| RHELM，无外部数据 | 22.3 | 26.4 | +4.1 个百分点 |
| RHELM，有外部数据 | 33.3 | 39.9 | +6.6 个百分点 |

### 6.2 与官方监督接近，但不能概括为全面优于人工标注
- ATM-Bench 主表中，生成监督略高于 Official-QA。
- RHELM 中分别落后约 0.1 和 0.8 个百分点。
- 更换 ATM-Bench 评审模型后，主集上的相对顺序也发生变化。

因此，较稳妥的结论是**效果具有竞争力**，而非稳定超越人工监督。

### 6.3 显式规划、验证和诊断都重要
- 完整 MemSteer 的双评审平均 QA 质量为 **90.9%**，不使用检查时为 **75.4%**；候选保留率约 **47.9%**。
- 受控生成实验中，两阶段计划—问题生成质量为 **85.9%**，高于直接生成的 **67.8%**，但 token 成本更高。
- 单纯增加原始证据收益有限；显式失败归因后提升更明显。
- 诊断加分层抽样使 ATM-Bench QS 达到 **68.3**，高于仅诊断且随机抽样的 **62.7**。

### 6.4 迁移有效但不稳定，目标用户适配有价值
- ATM-Bench 设计可直接改善 RHELM，继续优化后达到 **30.6 / 42.8** 的无/有外部数据准确率。
- 六用户共享设计在四个未见用户上的总体准确率由 **35.3 降至 35.1**，说明跨用户收益并不普遍。
- Martin 的个人继续优化将迁移后的 **37.7** 提升至 **44.3**，支持目标历史监督的适配价值。

## 7. 优点与亮点

- **切中真实瓶颈**：解决新用户没有标注反馈的问题，而不是假设每位用户都有测试题。
- **监督包含可追溯证据**：答案用于评分，证据用于诊断，两者分工清楚。
- **答案先行的生成设计合理**：先确定事实组合与来源，再生成问题，降低跨记录问答的无依据推断风险。
- **形成完整闭环**：历史生成监督、监督发现失败、失败驱动设计修改、验证集决定接受。
- **具有一定可移植性**：生成监督不仅服务于 MemSteer-Opt，也能帮助其他优化器。
- **披露负面和不一致结果**：包括部分困难集收益有限、证据召回下降和跨用户负迁移，使结论相对克制。

## 8. 不足与局限

### 监督可靠性与偏差
- 规划、审计、恢复和质量评分大量依赖 LLM，共享错误或偏见可能通过多重检查。
- 盲答恢复证明“答案可以从材料中恢复”，不证明证据最小充分，也不保证问题符合真实用户需求。
- 严格一致性过滤可能偏向表达明确、容易恢复的题目，弱化对模糊、冲突或不可回答问题的覆盖。

### 实验与泛化边界
- 仅验证两个 benchmark，且 RHELM 使用模拟用户，真实大规模用户证据有限。
- 个性化继续优化重点展示两个用户，尚不足以确立普遍有效性。
- 缺少长期在线运行、历史持续变化、用户纠错及真实任务完成率实验。
- 未充分分析固定验证集上反复选择设计的过拟合风险，以及生成训练/验证问答在源记录或事实上重叠的影响。

### 优化空间与成本
- 搜索空间总体偏向检索流程，实际演化主要涉及混合检索、重排、多查询、HyDE 和上下文组织。
- 对遗忘、时效冲突、权限、记忆更新等完整生命周期问题覆盖有限。
- 缺少“效果—成本—延迟”联合评价；生成监督和复杂检索带来的收益是否具有部署经济性，尚不明确。

### 隐私与可复现性
- 将个人记录发送给第三方 API 存在隐私风险，跨记录合成还可能暴露原本不明显的敏感信息。
- 真实部署需要知情同意、访问控制、数据最小化等保障。
- 远程模型的非确定性和版本更新会影响精确复现。

**总体评价：**论文较有力地证明了“从历史自动构造监督来优化记忆设计”的可行性，尤其凸显了证据规划与失败诊断的价值；但距离证明其在真实、动态、多用户环境中长期可靠且成本可控，仍有明显研究空间。
