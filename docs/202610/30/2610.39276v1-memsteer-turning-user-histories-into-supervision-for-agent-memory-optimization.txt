## ABSTRACT 

An effective agent memory system should adapt to a user’s history and task re-quirements. Human-annotated supervision can guide this adaptation by providing feedback for evaluating and improving memory designs. Yet suitable labels are rarely available for new user histories, and manually constructing QA pairs and supporting evidence is costly. We introduce MemSteer, which turns unlabeled user histories into question–answer (QA) supervision with supporting evidence for memory-design optimization. MemSteer constructs an evidence-grounded an-swer plan that specifies how facts across related records jointly support a refer-ence answer. The plan guides question generation, while source-grounded au-diting and blind answer recovery check the resulting annotations. To study the utility of this supervision, we develop MemSteer-Opt, which combines QA-based design evaluation with evidence-guided failure diagnosis to revise memory store, retrieval, and context construction without updating model parameters. Exper-iments on ATM-Bench and RHELM show that this supervision is competitive with official-QA-guided optimization. Relative to Base-BM25, MemSteer-Opt improves ATM-Bench Question Score by 13.4 points and RHELM accuracy by 4.1 and 6.6 points without and with external data, respectively. The supervision also benefits two existing optimizers on ATM-Bench, while new-user experiments demonstrate continued design optimization using supervision generated from the target histories.

Generating QA from the history itself offers a potential source of this feedback. Within agent mem-ory, MemBuilder uses synthetic QA rewards to train memory-construction policies (Shen et al., 2026), while MemMA uses QA probes to repair stored memories (Lin et al., 2026). We instead investigate whether history-derived QA can provide reliable feedback for evaluating and improv-ing memory-system designs. For memory-design optimization, reference answers determine how candidate designs are evaluated, while source evidence can help diagnose unsuccessful responses. Unsupported answers or mismatched evidence can misdirect design selection and later revisions. We propose MemSteer, a framework that turns unlabeled user histories into source-grounded QA– evidence supervision for memory-design optimization (Figure 2). It brings together related source records and specifies how their facts jointly support a reference answer. The resulting evidence-grounded answer plan guides question generation. Source-grounded auditing checks the generated QA for evidence support and consistency, while blind answer recovery assesses whether the refer-ence answer can be recovered from the sampled records. To investigate the utility of MemSteer’s generated supervision, we develop MemSteer-Opt, an evidence-guided memory-design optimizer. It uses source evidence and execution traces to iden-tify whether incorrect responses stem from storage, retrieval, or answer generation, then proposes targeted design revisions and evaluates them using QA performance. Starting from a basic memory system, we use MemSteer-Opt to optimize memory representations, retrieval strategies, and context construction. We further supply the generated QA to M ⋆ and MemEvolve (Pan et al., 2026; Zhang et al., 2025), allowing each framework to optimize within its own design space. Our contributions are threefold: • Memory-design optimization from unlabeled histories. MemSteer constructs QA–evidence supervision from unlabeled user histories for evaluating and improving memory designs without updating model parameters. • Evidence-grounded answer planning and verification. We construct answer plans that make explicit how source facts jointly support a reference answer for question generation. Source-grounded verification checks the resulting annotations. • Empirical validation across optimizers and user histories. Experiments with MemSteer-Opt on ATM-Bench and RHELM (Mei et al., 2026b; Zhang et al., 2026) show that generated su-pervision improves memory designs and is competitive with the Official-QA reference. Further experiments demonstrate its utility for two existing optimizers on ATM-Bench and for continued optimization on new user histories. 

## 2 RELATED WORK 

Memory-design optimization. Applications differ in what agents need to remember and how they use past information, making memory design an application-specific engineering challenge (Xiong et al., 2026; Pan et al., 2026). Recent work therefore explores automatic memory-design optimiza-tion to accommodate these requirements while reducing reliance on manual design. ALMA searches over code-based memory designs using task success and interaction logs as feedback (Xiong et al., 2026). MemEvolve introduces a dual-level process that evolves both experience memory and its underlying architecture (Zhang et al., 2025). M ⋆ searches over memory programs by jointly refin-ing their schema, logic, and instructions through task feedback and reflective code evolution (Pan et al., 2026). At a narrower level, CluE refines memory-extraction prompts using downstream feed-back across heterogeneous tasks (Yang et al., 2026). These methods optimize memory designs using feedback from downstream tasks. In many personal-memory applications, however, user records and everyday interactions do not naturally yield success-or-failure signals to guide memory-design op-timization. We therefore investigate how these histories can be turned into supervision for memory-design optimization. 

Synthetic queries and QA for training and evaluation. Outside agent memory, synthetic data has been used to reduce annotation requirements for model training and system evaluation. Promp-2Preprint tagator generates query–document pairs to train task-specific dense retrievers (Dai et al., 2022). Alberti et al. (2019) generate QA by selecting answers, formulating questions, and filtering pairs through answer-recovery consistency before training reading-comprehension models. For struc-tured synthesis, GraphGen samples knowledge-graph subgraphs to construct atomic, aggregated, and multi-hop QA for supervised fine-tuning (Chen et al., 2025). For evaluation, DataMorgana constructs corpus-specific RAG benchmarks with configurable user and question categories (Filice et al., 2025), while Ragas uses graph relationships to synthesize multi-hop test questions (Ragas, 2026). The usefulness of synthetic questions has also been studied directly: Yue et al. (2022) learn a question value estimator to select examples that improve target-domain QA performance, rather than relying only on generation or answer-model scores. We ask whether synthetic QA can provide effective feedback for memory-design optimization. 

Synthetic supervision for agent memory. Generated QA has also been incorporated into mem-ory learning and refinement. MemBuilder and CMI-Mem generate QA pairs from current sessions and retrieved memories, then use answering accuracy as a reward signal to train LLMs to construct and update memories via reinforcement learning (Shen et al., 2026; Wang et al., 2026). MemMA generates QA probes from each session and its historical context, then uses answering failures to re-pair the memory bank (Lin et al., 2026). MemMA also examines how the choice of probe generator affects repair outcomes. MemSteer instead uses generated QA pairs with source-grounded evidence to guide memory-design optimization, rather than to train memory models or repair stored mem-ories. This turns user histories into a source of feedback for memory-design optimization without requiring manually annotated QA for the target history. 

## 3 METHOD 

3.1 OVERVIEW 

Histories from different users vary in content and structure, so a memory design effective for one user may be less suitable for another. Given unlabeled user histories H, our goal is to improve agent memory designs without manually annotating QA pairs for those histories. To this end, MemSteer constructs QA–evidence supervision: 

DH = {(qi, a i, E i)}Ni=1 , (1) where qi is a question about the history, ai is its reference answer, and Ei identifies the selected source records, with source-span citations providing provenance for the supporting facts. Reference answers provide a criterion for evaluating memory designs, while evidence annotations support the diagnosis of unsuccessful responses. We describe the supervision construction process in Section 3.2. To assess the effectiveness of this supervision for memory-design optimization, we develop MemSteer-Opt, which evaluates candidate designs and uses evidence-guided feedback to propose iterative revisions (Section 3.3). The gener-ated supervision can also be supplied to existing optimizers, allowing each to retain its own design space and optimization procedure. 3.2 CONSTRUCTING QA– EVIDENCE SUPERVISION

MemSteer-Opt uses the generated QA–evidence supervision to evaluate memory designs and turn observed failures into feedback for iterative revisions. 

Design space and evaluation. Evidence-guided diagnosis and sampling. Beyond scoring candidate designs, we use the auto-matically constructed evidence annotations to build targeted feedback for revising memory designs. 

(i) Evidence-guided diagnosis. For each incorrect training-set response, we use its evidence annota-tions to check whether the required source records and cited passages are fully available in the final answer context. If so, we label an answering failure . For missing evidence, we use the annotated source IDs to check whether the current memory system can recover the corresponding records. We assign a storage failure if any missing record is unrecoverable, and a retrieval failure if all missing records are recoverable. 

(ii) Failure-stratified sampling. To cover different failure modes within the proposer’s input-context budget, we sample cases separately from each observed failure category. Each sampled case includes the question, its reference answer and annotated source evidence, together with the current system’s response and diagnostic results. Together with the current design and revision history, these cases form the input to the design proposer. 

Feedback-guided revision and selection. Given this feedback, an LLM-based design proposer proposes a revised design d′, using the diagnosed failures to guide changes to storage, retrieval, or context construction. It also provides a rationale for the proposed changes. We rebuild the memory under each valid candidate and evaluate its accuracy on the fixed validation set. We replace the current design dt with d′ only if A(d′) > A (dt); otherwise, we retain dt. After accepting a revision, we rerun the updated system on the training set to refresh the failure diagnoses and sampled feedback for the next iteration. 

Supervision for existing memory-design optimizers. Beyond MemSteer-Opt, we use the gener-ated supervision to guide existing memory-design optimizers within their own design spaces. Gen-erated questions and reference answers supply task feedback for evaluating and refining memory designs; source evidence can additionally support feedback when the optimizer’s interface accom-modates it. This tests whether the supervision remains useful across optimization frameworks. 

## 4 EXPERIMENTS 

We address four questions: Q1 (§4.2): Can generated supervision guide memory-design optimiza-tion? Q2 (§4.3): Can optimized memory designs transfer and adapt? Q3 (§4.4): Which supervision-construction choices matter? Q4 (§4.5): Does evidence-guided feedback improve optimization? 5Preprint 4.1 EXPERIMENTAL SETUP 

Benchmarks and evaluation. ATM-Bench (Mei et al., 2026b) is a multimodal personal-memory QA benchmark built from approximately four years of personal records. Its corpus contains 11,034 email, image, and video records. Unless otherwise specified, we follow the ATM-Bench scoring protocol and evaluate performance on its 1,013-question main set and 31-question hard multi-hop set. RHELM (Zhang et al., 2026) covers 21,142 interaction records from ten personas, evaluated with and without external data sources. Benchmark selection is discussed in Appendix A.1. 

Optimizers and protocol. MemSteer-Opt starts from a basic record-level retrieve-and-read sys-tem, which we refer to as Base-BM25: it indexes source text and metadata and uses the origi-nal question for BM25 (Robertson & Zaragoza, 2009) retrieval. Retrieved content is assembled in ranked order within a fixed context budget and passed to a fixed answering model. M ⋆ (Pan et al., 2026) and MemEvolve (Zhang et al., 2025) retain their own starting systems and design spaces. MemSteer uses our generated QA–evidence supervision for both training and validation while offi-cial QA is used only for testing. MemSteer-Opt runs 20 reflective evolution iterations per setting. 

Models and metrics. On ATM-Bench, DeepSeek-V4-Flash (DeepSeek-AI, 2026) serves as the answerer, open-answer judge (Zheng et al., 2023), and design proposer, matching the answerer and judge used by the corresponding leaderboard configurations (Mei et al., 2026a). We report Question Score (QS) and evidence recall at 10 (R@10). On RHELM, we follow the official protocol, using GPT-4.1-mini (OpenAI, 2025) for answering and evaluation and reporting overall accuracy, separately with and without external data. We include existing memory systems as performance references; their configurations and additional results are detailed in Appendix A.2 and Appendix B.3. 4.2 CAN GENERATED SUPERVISION GUIDE MEMORY -D ESIGN OPTIMIZATION ?Tables 1 and 2 compare MemSteer-generated supervision with official annotations (Official-QA) on ATM-Bench and RHELM; the ATM comparison also includes two external optimizers. Official-QA uses 600 of the 1,013 official ATM items and 788 of the 1,305 RHELM items for training and validation. These items remain in its evaluation sets, whereas MemSteer uses no evaluation items for training. The final RHELM MemSteer configuration uses 788 generated training items and is evaluated on all 1,305 official QA items. Based on Tables 1 and 2, we make the following observations. 

Generated supervision improves memory designs. With MemSteer supervision, MemSteer-Opt raises QS from 54.9 to 68.3 on ATM-Bench and from 8.2 to 29.1 on Hard, alongside gains in evidence recall (Table 1). On RHELM, MemSteer improves over Base-BM25 by 4.1 accuracy points without external data and 6.6 points with it (Table 2). 

Generated supervision is competitive with the human-annotated reference. On ATM-Bench, MemSteer scores marginally higher than Official-QA across all four metrics, including QS margins of 1.1 points on the main set and 1.3 points on Hard. On RHELM, MemSteer remains 0.1 and 0.8 accuracy points below Official-QA without and with external data, respectively. 

The supervision also benefits existing optimizers. From their own starting systems, M ⋆ and MemEvolve gain 6.0 and 18.6 main-set QS points with MemSteer supervision, compared with 4.4 and 18.6 points with Official-QA. Thus, the supervision’s utility is not limited to MemSteer-Opt. The benefit is not uniform: on Hard, MemEvolve obtains smaller gains than with Official-QA, and its R@10 decreases by 0.1 points. 

The optimized designs are competitive with existing memory systems. On ATM-Bench, MemSteer-Opt achieves the highest QS among the non-oracle systems using DeepSeek-V4 as the answerer. On RHELM with external data, MemSteer reaches 39.9 accuracy, compared with 33.9 for the strongest listed RAG, long-context, or memory-system baseline. Random-30 randomly sam-ples up to 30 scored failures per round and gives the design proposer their questions, reference answers, predictions, scores, retrieval traces, and answer-context excerpts. Random-30 + Gold ev-idence retains the random sampling and adds required-evidence IDs and gold-record excerpts, but no failure attribution. Random-30 + Diagnosis further adds evidence-grounded failure attribution while retaining random sampling. Diagnosis + stratified sampling (ours) keeps the diagnostic feedback and samples up to ten cases per failure category, preventing frequent failure types from ex-hausting the feedback budget. Appendix A.5 details the feedback fields, while Appendix B.5 shows an accepted architectural trajectory. We make the following observations. (i) Adding gold evidence provides only limited improvement over trace-based feedback. (ii) Explicit failure attribution yields larger gains, particularly in evidence retrieval, supporting the use of stage-level diagnostic feedback rather than raw evidence alone. (iii) 

Combining diagnosis with stratified sampling achieves the highest downstream QS, although diag-nosis with random sampling yields higher evidence recall on Hard. 

## 5 CONCLUSION 

We presented MemSteer, a framework for constructing QA–evidence supervision from unlabeled user histories and using it to guide memory-design optimization. Rather than requiring manually annotated QA for each new history, MemSteer derives reference answers and supporting evidence from the records themselves. These annotations serve complementary purposes: reference answers support the evaluation of candidate memory designs, while source evidence helps diagnose unsuc-cessful responses and guide revisions. We instantiate this approach in MemSteer-Opt and also use the generated supervision with existing optimizers that retain their own design spaces. Experiments on ATM-Bench and RHELM show that generated supervision improves memory designs, achieves performance competitive with the Official-QA reference, and supports continued adaptation to new user histories. 9Preprint 

## ETHICS STATEMENT 

Our experiments use released benchmark data under their published terms, without collecting new personal data or conducting human-subjects studies. Source records are processed through third-party LLM APIs, and generated QA may reveal sensitive information by combining facts across records. Deployment on personal histories should therefore require informed user consent and ap-propriate privacy safeguards. MemSteer is intended to improve memory systems for users, not to enable unauthorized profiling.

A.3 EVALUATION POPULATIONS 

The training split drives failure attribution and revision proposals, whereas validation is used to accept revisions and select the final design. MemSteer uses generated QA–evidence supervision for these processes, without using benchmark evaluation questions. The Official-QA reference instead uses official QA for training and validation; these items remain included in evaluation. On ATM-Bench, both the Official-QA and MemSteer conditions use 400 training items and a fixed 200-item validation set; the former uses official QA and the latter uses QA–evidence supervision generated from the records. Evaluation covers all 1,013 official QA items, including the 600 items used for Official-QA training and validation. ATM-Bench-Hard, the 31-question hard multi-hop subset, is reported separately. Leaderboard references also use the full 1,013-item population. RHELM contains 1,305 official QA items from ten personas and is evaluated on the full official set, both with and without external data sources. The Official-QA reference uses 524 official items for training and 264 for validation; these items remain included in evaluation. The final MemSteer configuration uses 788 generated QA–evidence items for training, without using official QA for training or design selection. In the six-user setting, four personas provide training supervision, two provide validation supervision, and the remaining four are held out (Table 9). For personal continuation, MemSteer generates 421 supervision items from Martin Keller’s history, split into 282 training and 139 validation items, and evaluates the continued design on 228 official questions. For David R. Ellis, it generates 337 supervision items, split into 223 training and 114 validation items, and evaluates on 158 official questions. A.4 EVALUATION METRICS 

On ATM-Bench, Question Score (QS) uses exact match for numerical items, Jaccard partial credit for list items, and judge scores for open-ended items. R@10 averages the fraction of gold evidence records among the top-10 retrieved records over questions. 

Blind answer agreement. Blind answer recovery checks type-normalized exact agreement: normal-ized text equality, set equality for lists, and exact value-and-unit agreement for numerical answers. 14 Preprint Boolean answers are matched exactly. Evidence coverage is checked at the record level, requiring citations to every selected evidence record. 

Design-selection accuracy. Validation accuracy guides revision acceptance and design selection. Predictions identical to their reference answers are scored as correct; other responses receive a bi-nary correctness judgment from a fixed LLM judge. Final ATM-Bench evaluation uses Question Score (QS), which includes partial credit for list questions. Final RHELM evaluation reports overall accuracy, computed as the mean of binary correctness judgments from the official evaluator. A.5 FEEDBACK INPUTS 

Gold evidence denotes the reference source evidence in MemSteer-generated QA–evidence super-vision, not human-annotated evidence. For Random-30 , each sampled case includes the question, reference answer, prediction and score, ranked retrieved-record IDs, IDs actually delivered to the answer. Gold evidence remains unmarked in Random-30, even if it appears in the context. Random-30 + Gold evidence adds required-evidence IDs and gold-record excerpts without programmatic failure attribution. Random-30 + Diagnosis retains random sampling and additionally provides failure-stage labels, missing-evidence IDs, evidence checks, and memory-lookup results. Diagno-sis + stratified sampling uses the same diagnostic information but organizes examples by failure category before allocating the feedback budget.

Table 9 reports per-persona results for shared memory designs under two optimization settings, complementing the shared and continued designs compared in Table 3. In the six-user setting, four personas provide training supervision and two provide validation supervision; the remaining four are held out from optimization. In the ten-user setting, all personas participate in optimization. Official-QA uses 40% of each persona’s official QA for training and 20% for validation, whereas MemSteer uses QA–evidence supervision generated from user histories and reserves official QA for evaluation. 18 Preprint 

Transfer of the six-user shared design. Table 9(a) shows that the shared design improves pooled accuracy on the six source users from 31.5% to 34.3%. However, this improvement does not carry over in aggregate to the four users held out from optimization. These results highlight heterogeneous transfer across users: a design optimized on the source users does not necessarily benefit other users. This makes the target-user continuation valuable, as studied in Table 3. 

Generated versus official supervision in the ten-user setting. Table 9(b) shows that MemSteer improves over Base-BM25 for all ten personas, raising pooled accuracy from 33.3% to 39.9%. Its overall accuracy is 0.8 points below the 40.7% obtained with Official-QA supervision. Note that MemSteer reserves official QA for evaluation, whereas the Official-QA results include questions used for training or validation. Thus, history-generated supervision provides an effective alterna-tive for optimizing a shared memory design without relying on official QA for training or design selection. ## C LIMITATIONS 

MemSteer’s supervision is generated and verified by LLMs without human certification, so errors or biases shared across answer planning, source-grounded auditing, and blind answer recovery can pass verification undetected. Blind answer recovery checks whether the reference answer is recoverable from the sampled records and every selected evidence record is cited; it does not establish that each record is necessary. Generated questions follow the distribution of the history rather than users’ actual information needs. MemSteer-Opt explores a constrained, largely retrieval-centric design space. Finally, our evaluation covers two benchmarks, one of which (RHELM) consists of synthetic personas, so evidence on real, heterogeneous user histories remains limited. 20
