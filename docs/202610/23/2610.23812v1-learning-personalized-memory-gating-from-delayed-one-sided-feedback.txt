Abstract 

Long-term memory enables language-model agents to personalize future interactions, but a finite memory bank cannot preserve every extracted fact. Existing memory gating policies are typically shared across users and therefore fail to account for user-specific patterns of future reuse. In this paper, we study memory gating at the fact level. We first propose a retrieval-based labeling strategy that labels each fact by whether it is later retrieved and incorporated into responses. We then formulate online memory gating as contextual apple tasting with delayed one-sided feedback, and propose Warm-Start UCB, which combines offline learning from existing data with online adaptation to the current user. Our theoretical analysis establishes a high-probability regret upper bound of e𝑂 (𝑇𝜖 ∧ 𝑑 √𝑇 ) when the delay window is at most 𝑂 (√𝑇 ), where 𝑇 is the total number of rounds, 𝜖 is the initialization error, 𝑑 is the dimension of the feature map, and e𝑂 (·) hides constant and poly-logarithmic factors. The results of our experiment demonstrate that our method outperforms all baselines under different memory budgets and history lengths, establishing it as a promising personalized memory gating policy. 

1 Introduction 

Memory systems, which extract and store important information during human-AI interaction, have been widely deployed in large language model (LLM)-based agents (Packer et al., 2023; Zhong et al., 2024; Chhikara et al., 2025). Typically, a memory system extracts candidate facts from each dialogue, stores a subset in a memory bank, and retrieves relevant entries for later queries. Because storage and context budgets are finite, the system must decide which facts are sufficiently valuable to preserve. Existing systems generally make this decision using criteria shared across users, such as heuristics like whether a fact expresses a stable preference, profile attribute, or ongoing goal (Park et al., 2023; Zhong et al., 2024), or using policies learned from long-context training data (Yan et al., 2026; Yu et al., 2026; Sun et al., 2026). Nevertheless, such universal criteria overlook the heterogeneity across different users. In et al. (2026) formalized this issue at the session level and introduced PerMem-Bench, together with several LLM-based storage-gating baselines. Their results show substantial headroom between perfect personalized gating and existing causal baselines, motivating methods that learn directly from user-specific interaction outcomes. To learn directly from user-specific interaction outcomes, we first need to identify a feedback signal grounded in the interaction that reflects the utility of each fact. While a deployed system does not observe whether a discarded fact would have been useful, for a stored fact, later retrieval provides a natural signal of future utility: a fact is utilized if it is hit by the retrieval and incorporated into the response in some later conversation. This implies that whether a fact gets retrieved and confirmed by the LLM agent can serve as a flag of utility , and therefore provides natural and reliable guidance for learning a memory gating policy. The retrieval-based feedback has two outstanding features: the feedback is only available on those added facts, and it becomes meaningful only after some unknown delay. To capture this nature, we formally frame the personalized memory gating problem as an apple tasting with one-sided delayed feedback problem (Helmbold et al., 1992; Vernade et al., 2020). We further propose a two-stage learning strategy, Warm-Start UCB. The first stage learns the utility 1arXiv:2610.23812v1 [cs.LG] 16 Oct 2026 Preprint from Salesforce AI Research pattern from data of existing users. The second stage adapts to user-specific patterns during online interaction via an upper confidence bound (UCB) algorithm. Our theoretical analysis and empirical results verify the effectiveness of Warm-Start UCB as a gating policy. Our contributions are summarized as follows: 

• We propose a labeling pipeline for learning personalized memory gating, which derives utility labels from downstream retrieval outcomes, refined through LLM-judge verification. This labeling strategy provides a direct feedback for memory gating learning, without relying on heuristic or downstream reward signals. 

• We frame personalized memory gating as an apple tasting with one-sided delayed feedback problem. To solve this problem, we propose a two-stage learning strategy, Warm-Start UCB. Our theoretical analysis implies that Warm-Start UCB effectively leverages the offline data while evolving towards user-specific patterns through online interaction. 

• We empirically evaluate Warm-Start UCB on our benchmark across a range of memory budgets and interaction lengths. Experiment results show that Warm-Start UCB consistently outperforms previous LLM-based methods and the naive admit-all baseline, suggesting that Warm-Start UCB serves as an effective gating policy for personalized memory.

2 Related Work 

Personalized Memory System. Memory systems are widely used in various applications, including embodied systems (Zhu et al., 2023; Wang et al., 2024b), personal assistants (Wang et al., 2025; Zheng et al., 2024) and recommender systems (Wang et al., 2024a), incentivizing a long line of work in improving the effectiveness and efficiency. One direction mainly focuses on learning a policy that selectively extracts and persists crucial information from the interaction history (Chhikara et al., 2025; Zhou et al., 2026; Yan et al., 2026; Tan et al., 2025). Another direction focuses on leveraging various data structures to capture relation between memory units to improve subsequent retrieval (Xu et al., 2026; Yang et al., 2026; Hu et al., 2025; Rezazadeh et al., 2025; Lu et al., 2026). Despite these advances, most existing systems employ a universal storage policy and therefore fail to fully account for the heterogeneity across different users. In et al. (2026) first formalize this limitation and introduce PerMem-Bench for evaluating personalized memory systems. They further propose several baseline approaches that operate the gating at session level, with LLM-based learning-free methods as the backbone. Compared to In et al. (2026), we consider fact-level online adaptation from retrieval-derived feedback, which eliminates the reliance on human or LLM-based heuristic. This results in an apple tasting with one-sided delayed feedback formulation. 

Learning with Apple Tasting Feedback. Apple tasting, introduced by Helmbold et al. (1992; 2000) is one of the canonical models for one-sided feedback, where the binary outcome is only revealed under the positive action. Apple tasting has been studied under several distinct comparators and modeling assumptions. In online binary classification against a hypothesis class, Raman et al. (2024) characterize agnostic learnability through Littlestone dimension and establish a realizable-case trichotomy; Chase & Mehalel (2025) study the additional restriction to deterministic learners. Apple tasting also appears as a canonical partial-monitoring or feedback-graph problem when regret is measured against a fixed action (Bartók et al., 2014; Alon et al., 2015; Cesari & Colomboni, 2026), with rates depending on the precise loss, feedback, and adversary model. Contextual variants have been studied through partial monitoring with side information, Bayesian logistic models, feedback-graph reductions, and log-loss (Bartók & Szepesvári, 2012; Grant & Leslie, 2021; Zhang et al., 2023; An et al., 2026). Extension has also been made to other settings like fairness-aware (Bechavod et al., 2019; Bechavod & Roth, 2023) and strategically manipulated context (Harris et al., 2023). 2Preprint from Salesforce AI Research 

Learning with Delayed Feedback. There are long lines of work studying decision making problem with non-immediate feedback, the most canonical among which is that the delay is generated stochastically or adversarially independently of the feedback. In this setting, a regret comparable to the non-delay counterpart up to only additive terms of the delay is provably achievable under both multi-armed setting (Joulani et al., 2013; Cesa-Bianchi et al., 2019; Thune et al., 2019; Bistritz et al., 2022; Zimmert & Seldin, 2020; Gyorgy & Joulani, 2021; Masoudian et al., 2022; Schlisselberg et al., 2026a) and linear setting (Zhou et al., 2019; Howson et al., 2023; Van Der Hoeven et al., 2023; Blanchet et al., 2024; Schlisselberg et al., 2026b). Another line of work considers delayed feedback that is entangled with the feedback structure (Lancewicki et al., 2021; Tang et al., 2024; Schlisselberg et al., 2025), among which the most relevant to us are Vernade et al. (2017; 2020) that studied the running-zero-flipping-one delay model and achieved e𝑂 (𝑑 √𝑇 + 𝑚𝑑 ) regret upper bound (Vernade et al., 2020), where 𝑑 is the dimension of feature map and 𝑚 

is a high-probability upper bound of the stochastic delay. In this paper, we adopt the running-zero-flipping-one delay model with apple-tasting feedback to account for the specific structure in agentic memory system, where feedback is only available at added memory entries.

Evaluation Protocol. During evaluation, we consider a memory budget with a fixed budget size 𝐵 . For each distinct fact 𝑓 , the gating decides whether it should be added to the memory bank. If the decision is “add” and the bank is full, then the earliest entry in the bank will be evicted. H ′ := {( 𝑓 𝑡 ,𝑖 , 𝑥 𝑡 ′ ,𝑖 ′ ) ∈ H : 𝑓 𝑡 ,𝑖 is still in the memory bank at 𝑡 ′ },

RHR : = |H ′ |/|H | .

At a high level, the RHR captures how well a policy preserves facts until the turn where they actually make a difference, given that the memory budget is limited. A miss of fact 𝑓 𝑡 ,𝑖 at 𝑡 ′ stems from one of two reasons: the gating policy drops 𝑓 𝑡 ,𝑖 , or it adds too many non-required facts so that 𝑓 𝑡 ,𝑖 gets evicted too early. Hence, a policy that attains a high RHR usually adds the required facts to the memory bank and drops unnecessary ones. Besides this, we also consider the F1 score of a gating policy, by treating the storage decision itself as a binary classification problem against the ground truth labels.

Remark 4.4. 5.2 Experiment Results 

The results are summarized in Table 2 and Table 3. We report the RHR as a percentage under both micro and macro averaging. Micro averaging pools valid retrieval hits across users, whereas macro averaging first computes the RHR separately for each user and then averages across users. 

Results on PerMemBench-S. As shown in Table 2, Warm-Start UCB consistently outperforms the Universal baseline and all LLM-based gating methods across every memory budget under both micro and macro averaging. For example, at 𝐵 = 60, our method performs on par with the best LLM-based methods and improves over the Universal baseline by 6 .66 micro and 7 .06 macro percentage points. On the other hand, when the memory budget is large, LLM-based methods underperform the Universal baseline, while our method still improves over it by 1 .80 micro and 1 .08 macro points at 𝐵 = 250, and by 3 .88 micro and 2 .03 macro points at 𝐵 = 500. To summarize, the results indicate that our method consistently outperforms the considered baselines. Meanwhile, the comparison among the three linear methods further reveals the complementary roles of pre-training and online adaptation. Under the smallest budget, the feedback signal is sparse, so the improvement mostly comes from 9Preprint from Salesforce AI Research Pre-trained Scorer. On the other hand, with a larger budget, more online feedback becomes available, which improves the performance of UCB. Since our proposed method combines the two strategies, it yields a stable improvement across all budget sizes. 

Results on PerMemBench-L. Table 3 shows a consistent pattern on the substantially longer interaction trajectories of PerMemBench-L. Our method, Warm-Start UCB, achieves the best non-oracle result in eight of the ten evaluation columns and the second-best result in the remaining two, where it is narrowly below Pre-trained Scorer at 𝐵 = 250. Compared with the Universal baseline, our method improves the micro RHR by 2 .49–5 .37 percentage points and the macro RHR by 1 .81–5 .37 points across the five evaluated budgets. Moreover, a longer interaction history means that both pre-training and online adaptation are exposed to more data and feedback. Nevertheless, the results show that, compared to the Universal baseline, Pre-trained Scorer leads to a considerable improvement, while UCB without initialization performs only marginally above the Universal baseline. Despite this, we still observe a consistent improvement brought by online adaptation when the memory budget is large. This result indicates that a population-level gating rule transfers useful information to a new user, but cannot fully capture the user’s individual storage preferences. Updating the rule with user-specific feedback is therefore essential for maintaining performance over long interaction horizons. 

Remark 5.1. Across all experimental settings, we see that LLM-based methods are comparable to the Universal baseline under small budgets. However, they become inferior to the Universal baseline under larger budgets, and the gap increases with the memory budget size. This observation is consistent with the results in In et al. (2026). We also observe that a more fine-grained, capacity-aware prompt only mitigates this inferiority but hardly resolves it. 

5.3 Ablation Studies Learning Dynamics. To examine whether the online methods genuinely adapt to the current user, we partition each user’s interaction trajectory into ten session-position deciles and report the F1-score improvement over the Universal baseline within each decile. Figure 1 presents the results on PerMemBench-L for representative memory budgets; the remaining budgets and the corresponding PerMemBench-S results are provided in Appendix C. As suggested by the plots, Cold-Start UCB begins with little or even negative improvement over the Universal baseline because it has not yet received enough one-sided, delayed feedback to learn the current user’s gating rule. Its performance gradually improves in later deciles, confirming that the online updates extract useful information from the user’s interaction history. In contrast, Pre-trained Scorer provides an immediate positive uplift but exhibits comparatively limited improvement as the interaction proceeds because its parameter remains fixed. Warm-Start UCB combines the strengths of both methods. It begins with the transferable knowledge supplied by pre-training and then increasingly separates from the frozen policy after user-specific feedback becomes available, also verifying the conceptual superiority of Warm-Start UCB. 

Effect of the Pre-training Pool Size. We next vary the number of user profiles included in the pre-training pool while keeping the held-out test user fixed. Figure 2 reports the best micro and macro RHRs on PerMemBench-L for pre-training pool sizes in {1, 2, 5, 10 , 15 }. Performance improves monotonically with the number of pre-training profiles under every displayed budget and both averaging schemes. Notably, the curves continue to improve at a pool size of 15, especially for 𝐵 = 500 and 𝐵 = 1000, suggesting that the pre-trained scorer has not yet saturated and may benefit from a larger and more diverse collection of user profiles.

In this paper, we study the personalized memory gating problem. We first provide a retrieval-based utility labeling pipeline, based on which we construct a dataset for memory-gating evaluation. We further frame the problem as an apple tasting with one-sided delayed feedback problem, and propose an algorithm for this problem that achieves an

Experiments on our constructed dataset show that our method consistently outperforms all baselines, confirming its effectiveness. Currently, our method assumes a stable parameter for each user.
