## 摘要
CTR、MRR 和行为 NDCG 都假设用户会看到排序结果并据此采取行动。在智能体助手中，生成层会先接收检索结果，这一假设因此在三个方面不再成立：其一，智能体先于用户读取结果（谁）；其二，用户可能在检索后数轮对话甚至数个会话之后才采取行动（何时）；其三，结果可能同时受到检索内容与模型自身知识的影响（由什么导致）。我们将此称为归因鸿沟。我们提出分层智能体检索评估（Layered Agentic Retrieval Assessment，LARA），将检索质量、参与度与结果、产品成功作为三个相互独立的层面进行衡量，并通过包含四个字段的溯源模式将它们关联起来，无需新增建模。我们以 Adobe Express 为例探讨这一问题：同一套检索基础设施服务于图库搜索界面和智能体助手；对于相同用户群体，后者的会话量约为前者的八分之一。聊天用户比图库用户更常改写查询（44.4% 对 33.1%），因为在聊天中，改写查询是为了完善生成结果。LARA 使检索归因重新成为可能。

## Abstract
CTR, MRR, and behavioral NDCG assume the user sees ranked results and acts on them. In an agentic assistant, a generation layer consumes retrieval output first, and that assumption breaks in three ways. The agent reads the results before the user does (who). The user's action can come several turns or sessions after retrieval (when). Outcomes blend retrieved content with the model's own knowledge (what caused it). We call this the attribution gap. We propose Layered Agentic Retrieval Assessment (LARA), which measures retrieval quality, engagement and outcome, and product success as three independent layers joined by a four-field lineage schema that requires no new modeling. We examine the motivation on Adobe Express, where one retrieval infrastructure serves a gallery search surface and an agentic assistant at roughly one-eighth its session volume for the same user population. Chat users reformulate more than gallery users (44.4% vs. 33.1%) because chat reformulation refines generated output. LARA restores attribution for the retrieval.
