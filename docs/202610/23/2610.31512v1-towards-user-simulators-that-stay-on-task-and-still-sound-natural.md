## 摘要
用户日益依赖 AI 系统完成耗时较长的多轮任务，但已有证据表明，基于大语言模型（LLM）的系统在持续交互过程中性能会有所下降。为了评估和改进此类场景中的 AI 助手，我们需要能够忠实遵循复杂用户意图，同时展现真实对话行为的用户模拟器。现有方法存在取舍：通过提示构建的助手能够遵循复杂用户意图，但行为保真度不足；而专门设计的用户模拟器更能贴近真实对话行为，却难以忠实遵循复杂意图。本文提出一种强化学习（RL）方案，通过联合奖励任务意图遵循度和行为自然度来解决这一问题。该方法的一项关键贡献是：采用轻量级判别器对自然度进行操作化定义，并使其与用户模拟器在交替进行的对抗循环中共同训练。我们发布了由此得到的模型 UserLM-2.0。该模型生成有效模拟对话（即同时满足任务忠实度和自然度标准）的比例为 46.2%，是此前表现最佳的用户模拟器（14.1%）的三倍以上。

## Abstract
Users increasingly rely on AI systems for extended, multi-turn tasks, yet evidence indicates that LLM-based system performance degrades over prolonged interaction. To evaluate and improve AI assistants in such settings, we need user simulators that faithfully follow complex user intents while exhibiting realistic conversational behavior. Existing approaches manifest a trade-off: prompted assistants can follow complex user intents but lack behavioral fidelity, while specialized user simulators better approximate conversational behavior but struggle to remain faithful to complex intents. In this paper, we propose a reinforcement learning (RL) recipe that jointly rewards task intent adherence and behavioral naturalness. A crucial contribution of the method is operationalizing naturalness with a lightweight discriminator trained in an alternating, adversarial loop with the user simulator. We release the resulting model, UserLM-2.0, which produces valid simulated conversations (i.e., meeting both task-faithfulness and naturalness criteria) 46.2% of the time, over three times the rate of the strongest prior user simulator (14.1%).

## 1. 核心问题与研究背景

- **研究目标**：构建能够在多轮人机交互中，既忠实执行用户意图，又表现得像真实用户的模拟器，为 AI 助手的评估与训练提供可靠交互对象。

- **现有方法的主要矛盾**：
  - **提示式助手**：能够执行复杂意图，但表达往往过度完整、正式、冗长，容易在第一轮集中交代全部需求。
  - **监督微调用户模拟器**：语言和行为更接近真实用户，却容易遗漏目标、跑题或过早结束对话。
- **整体含义**：论文把用户模拟视为“任务忠实度”和“行为自然度”的联合优化问题，并强调：**不能只看两个指标的平均表现，还应判断每一条生成对话是否同时满足要求。**

## 2. 方法论：SFT 初始化、联合奖励与动态对抗训练

### 2.1 基本流程

1. 从真实用户—助手对话中提取高层用户意图和细粒度子目标。
2. 基于 **Llama3.1-8B-Instruct**，对真实用户发言进行监督微调，得到 **UserLM-2.0-SFT**。
3. 让该模拟器与固定助手交互，生成完整多轮对话。
4. 使用 **GRPO 强化学习**，联合优化任务忠实度与行为自然度。
5. 定期重新训练自然度判别器，使其持续识别模拟器新出现的生成模式，最终得到 **UserLM-2.0**。

### 2.2 四类奖励

- **覆盖度奖励**
  - 将任务分解为若干子目标，用 LLM 判断用户发言表达了其中多少个。
  - 覆盖度衡量的是**用户是否传达需求**，不等同于助手是否完成任务。
  - 模拟器输入较抽象的意图 \(c\)，评分器使用更细粒度的目标描述 \(c^*\)，以减少直接复述目标清单的奖励投机。
  - 附录进一步说明，细粒度目标经过泛化处理，尽量保证其可以从抽象意图合理推导，而非要求模型猜测隐藏细节。

- **自然度奖励**
  - 使用约 **3.95 亿参数的 ModernBERT-Large**，区分真实用户发言序列与模拟用户发言序列。
  - 训练时，判别器接收任务意图和所有用户轮次，**不接收助手回复**，避免通过助手风格差异轻易识别真假。
  - 当判别器认为对话为真实用户生成的概率超过 0.5 时，自然度奖励为 1，否则为 0。

- **质量奖励**
  - 排除三类明显错误：近乎逐字复制输入意图、逐字重复过去的用户发言，以及在用户输出中切换成助手或自行生成双方对话。
  - 结合规则检测与 LLM 判断，通过时为 1，否则为 0。

- **终止奖励**
  - 全部子目标已表达后输出 `<|endconversation|>`，奖励 \(+0.2\)。
  - 未满足全部目标便提前结束，奖励 \(-0.2\)。
  - 未主动终止，则为 0。
  - 因而，这一奖励主要鼓励在**需求表达充分后结束**，不直接验证助手是否真正完成任务。

总体奖励为：

\[
r_{\text{overall}}
=
r_{\text{quality}}
\left(
r_{\text{coverage}}
+
r_{\text{naturalness}}
+
r_{\text{termination}}
\right)
\]

其中，质量奖励是门控条件：出现基础质量错误，对话总奖励直接归零。

### 2.3 动态判别器：关键技术贡献

- 固定判别器容易被模拟器利用。例如，模型可能通过增加单轮长度、减少轮数获得高分，而不是真正变得自然。
- 作者采用类似 GAN 的交替训练：
  - 每 **25 个 RL 步骤**重新训练判别器；
  - 一半训练样本来自最近阶段；
  - 另一半来自历史生成数据和初始化数据；
  - 判别器每次训练 5 个 epoch，按验证集表现选择检查点。
- 历史数据回放有助于减少判别器遗忘，也使模拟器难以长期利用同一漏洞。
- 该方法是**以判别器评分作为 RL 奖励的对抗训练**，而不是直接对离散文本执行传统 GAN 的端到端反向传播。

## 6. 主要结论与发现

### 6.1 有效对话率显著提升

| 模型 | 覆盖度 | 自然度通过率 | 有效对话率 |
|---|---:|---:|---:|
| GPT-5.6-Sol | 79.7% | 10.2% | 6.7% |
| UserLM-8B | 64.2% | 50.2% | 13.0% |
| SFTUser-14B | 60.7% | 40.9% | 14.1% |
| UserLM-2.0-SFT | 76.0% | 68.2% | 27.8% |
| **UserLM-2.0** | **88.0%** | **71.8%** | **46.2%** |
| 真实用户参照 | 96.0% | 100.0% | 80.2% |

- 相较最强既有模拟器，有效率提高 **32.1 个百分点，约为其 3.28 倍**。
- 相较自己的 SFT 初始化，提高 **18.4 个百分点，约为其 1.66 倍**。
- 与真实用户仍相差 **34.0 个百分点**。

### 6.2 动态判别器优于固定或提示式自然度评分

- 固定判别器：有效率 7.8%。
- LLM Likert：10.5%。
- LLM 二选一：7.0%。
- 完整动态判别器方案：46.2%。

一些自然度奖励方案甚至比“不使用自然度奖励”更差，说明**有缺陷的奖励可能强化可识别的生成模式，而非改善真实自然度**。不过，这一结论应限定于本文测试的模型、提示和训练设置，不能直接推广为所有 LLM 自然度评审均无效。

### 6.3 复杂任务仍难，但相对优势更明显

- 6 个子目标：UserLM-2.0 有效率为 23.6%。
- 7 个子目标：有效率为 12.6%，既有模拟器均不足 1%。
- 这既说明方法对复杂任务有帮助，也表明高复杂度下绝对可用率仍然较低。

### 6.4 行为更接近真实用户，但自然度提升并不全面

- 目标重复提及率：39.0%，接近真实用户的 38.8%。
- 无目标轮次比例：从 SFT 的 18.6% 降至 4.3%。
- 每个已覆盖目标的用户用词中位数：59 词，仍明显高于真实用户的 34 词。
- 相较 SFT 初始化：
  - 专用判别器分数从 25.3% 降至 9.4%；
  - 通用判别器分数从 50.7% 降至 36.1%；
  - Pangram 分数则从 50.7% 升至 59.2%。

因此，更准确的结论是：**方法大幅提高任务忠实度，并维持或改善综合自然度通过率，但并未在所有自然度指标上同步提升。**

## 7. 优点与亮点

- **问题定义有实际价值**：明确区分“用户是否表达需求”与“表达方式是否真实”，避免只追求覆盖率。
- **动态奖励设计有针对性**：通过持续更新判别器和历史回放，缓解固定评分器被利用的问题。
- **单条对话级评价更有实践意义**：防止平均指标提升掩盖“每条对话都只擅长一个维度”的问题。
- **行为分析较细致**：不仅比较语言风格，还考察目标披露、重复、跑题和冗长程度。
- **消融支持主要技术主张**：固定判别器和 LLM 评分替代方案的结果，为动态对抗训练提供了直接证据。
- **模型规模相对可控**：8B 用户模拟器配合轻量判别器，具有较好的部署潜力。

## 8. 不足与局限

### 8.1 自然度仍是代理指标

- 判别器“识别不出”不等于真实用户认为自然，也不等于模拟器能可靠预测真实交互结果。
- “任一检测器通过”的规则较宽松，综合分数可能被其中一个检测器主导。
- Pangram 原本主要面向人类文本与 AI 助手文本识别，用于短用户发言存在任务错配风险。
- 训练判别器包含任务意图，因此自然度奖励实际上部分混入任务覆盖信息，两类奖励并非完全独立。

### 8.2 对交互真实性的验证不足

- 主要自然度判别器不看助手回复，难以直接检验用户是否对助手的具体错误、澄清问题或不一致行为作出了合理反应。
- 缺少直接的人类自然度评测。
- 未验证该模拟器能否准确复现真实用户对不同助手的评价或模型排名。
- 未展示使用该模拟器训练助手后，真实用户体验是否改善。

### 8.3 数据与应用范围有限

- 数据集中于过滤后的英语 WildChat，多语言、不同人群和专业领域的适用性未知。
- 数据过滤规则可能改变用户分布。
- 训练与测试均使用同一个交互助手，存在对特定助手行为适配的风险。
- 对话长度较短，虽然研究动机涉及长程交互，但尚不足以证明其能处理真正长时、动态变化的任务。
- 尚不支持工具环境、共享文件、任务执行验证等代理式交互。

### 8.4 忠实度和复现信息仍不完整

- 主要忠实度指标强调目标“是否被表达”，对目标矛盾、凭空增添约束等问题缺少单独系统评估。
- 显式终止标签是一种协议要求，可能使不同训练分布的模型受到不同程度影响。
- 未披露完整训练硬件与时长，也未充分展示统计不确定性。
- 真实用户数据训练还涉及隐私记忆与泄漏风险，论文提出了这一问题，但未提供专门的隐私保护方案。

**总体评价**：这项工作较有说服力地证明了“动态判别器 + 多目标强化学习”可以改善用户模拟器的任务执行能力，并减少部分不自然行为；但其最强证据仍来自特定聊天数据和自动代理指标，距离“可替代真实用户进行可靠评测”还有明显差距。
