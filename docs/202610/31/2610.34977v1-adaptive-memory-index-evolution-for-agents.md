## 摘要
长时程智能体会不断积累经验，但保留记忆并不意味着能在需要时访问到它。现有系统可以同时调整记忆内容与访问方式；本文将持久化访问更新作为一个独立控制的适应层进行研究。我们将这一目标定义为“记忆索引演化”，并以自适应记忆索引演化（Adaptive Memory Index Evolution，AMIE）加以实现。AMIE 是一种轻量级插件层，能够根据部署期间的检索结果演化各条记忆的访问状态，而无需修改已存储的内容或重新训练宿主记忆系统。AMIE 将语义教师模型的保留／抑制判断提炼为一种由检索条件触发的策略，并将其选择性操作累积为有界状态，用于重新加权宿主系统后续的检索结果。值得注意的是，在若干设置中，仅累积检索频率的零调用策略就能达到或超过语义策略的表现，这表明检索流量本身就是访问适应的强信号；而当频繁检索的记忆仍然有用时，学习得到的选择性则能提升鲁棒性。在五种基于检索的宿主系统和三个基准测试中，经过训练的 AMIE 在全部 15 项比较中均提升了下游 F1 或准确率，提升幅度为 0.70 至 3.37 个百分点（相对提升最高达 25%）；在全部 10 项比较中均改善了检索效果。受控分析表明，持久抑制竞争记忆可以显现此前未被发现的证据，而抑制反复证明有用的记忆则会造成相反的失效模式。总之，这些结果表明，在基于检索的智能体记忆系统中，持久化记忆访问是一种实用的适应层，有别于其所服务的记忆内容。

## Abstract
Long-horizon agents continually accumulate experience, yet retaining a memory does not guarantee access when it is needed. Existing systems can adapt both memory content and access; we isolate persistent access updates as a separately controlled adaptation layer. We formulate this target as Memory Index Evolution and instantiate it with Adaptive Memory Index Evolution (AMIE), a lightweight plug-in layer that evolves per-memory access state from deployment retrievals without modifying stored content or retraining the host memory system. AMIE distils a semantic teacher's keep/suppress judgments into a retrieval-conditioned policy and accumulates its selective actions into bounded state that reweights subsequent host retrievals. Surprisingly, even a zero-call policy that simply accumulates retrieval frequency can match or outperform semantic policies in several settings, revealing retrieval traffic itself as a strong signal for access adaptation, while learned selectivity improves robustness when frequently retrieved memories remain useful. Across five retrieval-based hosts and three benchmarks, trained AMIE improves downstream F1 or accuracy in all 15 comparisons, by 0.70--3.37 percentage points (up to 25% relative), and improves retrieval in all 10 comparisons. Controlled analyses show that persistent competitor suppression can expose previously unseen evidence, while suppressing repeatedly useful memories creates the complementary failure mode. Together, these results establish persistent memory access as a practical adaptation layer, distinct from the content it serves, in retrieval-based agent memory systems.

## 1. 核心问题与整体含义

### 研究背景与动机
- 长期运行的智能体会持续积累对话、事实和任务经验，但**“记忆仍被保存”不等于“需要时能够检索到”**。当相似内容不断增加时，有用经验可能被大量竞争记忆挤出有限的检索上下文。
- 现有记忆系统通常通过事实提取、内容合并、分层存储、图结构或学习记忆操作来改善长期记忆。部分系统也维护访问频率、热度或节点效用，但这些访问变化往往与内容管理耦合。

### 论文的核心问题
> 在不修改已存储内容、不重新训练宿主记忆系统的前提下，能否仅依据部署期间的检索经历，持续改善未来的记忆访问？

论文将智能体记忆拆分为两个互补部分：
- **内容演化**：决定保存、修改或删除什么。
- **索引演化**：决定已有内容以后如何被访问。

这里的“索引”主要指**影响检索排序的持久访问状态**，并不意味着重建底层倒排索引或向量索引。论文的主要贡献是将这一适应维度独立出来，进行插件式实现与受控评估，而非首次提出所有形式的持久访问适应。

## 2. 方法论：核心思想、技术细节与流程

### 2.1 核心思想：积累对竞争记忆的选择性抑制

AMIE 为每条记忆维护一个持久抑制状态。某条记忆如果反复被判断为“不恰当地占据检索位置”，其后续检索分数就会降低。

- 不直接修改记忆文本、向量或宿主模型参数。
- 不必直接奖励目标记忆：**降低竞争者的优先级，也可能让此前未被策略看到的有效证据进入上下文**。
- 部署期间固定策略模型参数，在线变化的是每条记忆的访问状态。

### 2.2 检索条件策略：判断哪些记忆应被抑制

策略输入为：
- 当前查询；
- 宿主原始检索返回的有序反馈列表。

策略对每条反馈记忆输出二元动作：
- **Suppress**：增加抑制计数。
- **Keep／No-op**：不增加计数。

需要注意：
- Keep **不会消除已经积累的惩罚**。
- 策略不读取未来查询或参考答案。
- 原生反馈列表与 AMIE 重排后的回答上下文分开，避免更新信号完全由自身排序决定。

论文比较三种策略：
1. **Trained**：学习教师模型的选择性抑制判断。
2. **Frozen**：使用同一学生骨干模型，通过提示直接生成判断，不进行任务微调。
3. **Count**：对所有原生反馈记忆增加计数，不调用模型，以检索频次作为干扰代理信号。

### 2.3 教师蒸馏与模型配置

- 教师模型为 **GPT-5.6-Sol**，按照“是否与当前查询有关、是否可能长期误占位置”的标准生成标签，不确定时倾向保留。
- 学生与 Frozen 策略均使用 **Qwen3-8B**。
- 学生采用 **LoRA＋十槽位线性预测头**，一次前向传播输出整个抑制掩码。
- 使用类别平衡二元交叉熵训练，训练集包含：
  - 902 个检索观察，来自 6 段 LoCoMo 对话；
  - 3,676 个保留标签、5,344 个抑制标签。
- LoRA rank 为 8，作用于注意力的 query/value 投影；训练 2 个 epoch，学习率为 \(10^{-5}\)，batch size 为 1，报告 3 个训练种子的平均结果。
- 输入查询截取至 300 字符，每条记忆截取至 200 字符；最多支持 10 条反馈记忆。

**训练目标是模仿教师，而非直接优化未来任务收益。** 教师判断只是未来抑制价值的代理监督。

### 2.4 有界持久状态与分数更新

每条记忆维护累计抑制次数 \(n_i\)，映射为：

\[
u_i=\frac{n_i}{n_i+\kappa}
\]

- \(u_i\) 介于 0 和 1 之间。
- \(\kappa\) 控制累积到多快会接近饱和。

再对宿主分数进行乘性调整：

\[
s(q,i)=\hat{\sigma}(q,i)(1-\lambda_pu_i)
\]

- \(\hat{\sigma}\) 是经过宿主特定单调转换和查询内缩放的基础分数。
- \(\lambda_p\) 控制最大抑制强度。
- 设为 0 时，可恢复同一候选池中的原始选择。

论文证明了一个条件性性质：**在查询、候选池和基础分数固定，且目标记忆本身不受抑制时，只降低竞争者分数不会使目标排名变差。** 但这不保证整体召回率或下游任务表现必然提升。

### 2.5 在线执行流程

1. 宿主生成候选池与原生反馈列表。
2. 使用此前累积的状态重新排序候选。
3. **先锁定当前回答上下文**。
4. 策略读取当前查询和原生反馈，生成动作。
5. 更新记忆状态，仅影响后续查询。

这一“先锁定、后更新”设计，使当前动作不能被错误计入当前答案收益。

## 6. 主要结论与发现

### 6.1 训练版在所有主比较中取得正向点估计

Trained AMIE 在 15 项下游比较中均提升，幅度为 **0.70–3.37 个百分点**：

| Benchmark | 五种宿主上的提升范围 |
|---|---:|
| LoCoMo F1 | +0.70～+2.46 |
| GroupMem 准确率 | +1.35～+2.64 |
| MemBench 准确率 | +0.95～+3.37 |

例如：
- LoCoMo Mem0：9.98 → **12.44**。
- GroupMem MemoryOS：35.72 → **38.27**。
- MemBench Mem0：79.17 → **82.54**。

相对提升最高约 25%，但对应较低基线；不应与百分点提升混淆。

### 6.2 检索流量本身是强适应信号

- Trained 在全部 10 项检索比较中提升。
- Count 在部分 LoCoMo 设置中能接近或超过语义策略。例如 Mem0 的 Count F1 为 **12.85**，高于 Trained 的 12.44。
- 说明部分收益来自**长期积累对高频竞争者的降权**，不完全依赖复杂语义判断。

### 6.3 频繁出现不等于有害，选择性决定鲁棒性

- Count 也会压低反复有用的记忆，在多个 GroupMem、MemBench 组合中出现负收益。
- GroupMem MemoryOS 中：
  - Count 相对宿主下降 1.06 点；
  - Trained 提升 2.55 点；
  - 二者相差 **3.61 点**。
- 但 GroupMem 未测量证据复现情况，不能据此直接确认其差异的具体原因。

### 6.4 收益受候选覆盖与记忆粒度限制

- 最有利的情形是：竞争者反复占位，同时缺失证据仍位于候选池内。
- AMIE 不能找回候选池之外的内容。
- 粗粒度记忆将干扰与有效证据绑定，抑制更容易误伤；BM25 粒度实验中，Count 优势随单元变粗而接近零。
- 合适衰减优于无限积累，但衰减只是诊断变体，**不是主表方法组成部分**。

## 7. 优点与亮点

- **问题分解清晰**：把“存什么”和“如何访问”分开，为记忆系统提供独立可控的优化维度。
- **接入方式通用**：依赖稳定记忆 ID 和带分数候选接口，不要求重训宿主。
- **时间因果设计严谨**：先锁定当前上下文，再提交更新，避免把当前动作误计为当前收益。
- **基线设置有价值**：Count 暴露了简单流量统计的竞争力，有助于避免夸大学习策略的贡献。
- **机制证据较强**：置换、反向更新、状态交换和证据暴露分析，不仅展示收益，也解释误伤机制。
- **报告相对审慎**：明确区分点估计、统计显著性、Oracle 诊断与可部署策略，并承认持久访问适应并非首次出现。

## 8. 不足与局限

### 方法层面
- **局部判断与长期价值存在错位**：当前查询下不相关，不代表未来不重要；教师蒸馏没有直接解决长期信用分配。
- **主方法只累积抑制**：Keep 不恢复访问权重，长期运行可能积累过时惩罚。
- **缺少显式正向恢复或探索机制**：主要通过压低竞争者间接提升其他记忆。
- **受接口限制**：需要稳定 ID、可比较分数和足够候选覆盖；十槽位预测头也限制了当前反馈规模。

### 实验与偏差风险
- 机制证据集中于 LoCoMo BM25 Count，向复杂图检索或其他宿主推广仍需验证。
- LoCoMo 存在训练／选择暴露，跨基准迁移更有说服力，但尚不足以证明任意部署中的泛化。
