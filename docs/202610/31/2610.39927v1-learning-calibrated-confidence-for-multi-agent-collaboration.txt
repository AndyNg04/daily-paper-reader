## Abstract 

Complex information seeking on the Web often requires collecting evidence from multiple documents and reasoning across them, as in multi-hop question answering. Multi-agent systems address such tasks by dividing work among specialized agents, where upstream agents produce intermediate answers and supporting evidence that downstream agents build upon. However, upstream answers vary in correctness, and most systems provide no quantitative signal about it, leaving the downstream agent to judge whether to trust or verify what it receives based solely on the textual evidence. In this paper, we propose MASCAL. Each agent learns to produce a correctness probability for its answer by jointly optimizing task performance and confidence calibration in reinforcement learning; the upstream agent passes this probability at handoff, giving the downstream agent a quantitative basis for its decisions, and the final answer also carries a calibrated probability, quantifying the reliability of the system output. To guide the downstream agent in using this signal during training, we introduce confidence-aware weighting, which increases the learning weight at positions respon-sive to the upstream probability, so that the agent learns more from decisions where it actively uses the signal. Across three collabo-ration architectures spanning Web retrieval and reasoning tasks, MASCAL improves task accuracy and calibration quality for both agents, and generalizes to deeper collaboration chains and different model scales. Intervention analysis confirms that upstream confi-dence affects downstream decision behavior, and the learned final confidence supports selective answering and targeted rechecking.

## 1 Introduction 

Complex information seeking on the Web often requires collect-ing evidence from multiple sources and reasoning across them, as in multi-hop question answering [39, 48] or cross-document fact verification [21]. Large language model (LLM) agents have made substantial progress on such tasks by combining Web retrieval with step-by-step reasoning [23, 35]. However, a single agent remains limited in both coverage and reliability when the task spans many evidence sources or requires extended reasoning chains [41, 45]. Multi-agent systems (MAS) address this through role specialization: different agents retrieve separate pieces of evidence, answer differ-ent sub-questions, or produce candidate answers for another role to review [6, 29, 32, 44]. Upstream agents vary in quality across inputs, and the down-stream agent must assess each report it receives. It must decide whether to trust the upstream conclusion and move forward, or to launch additional searches to verify [54]. Yet as Figure 1 illustrates, most current MAS convey only the answer and textual evidence, giving the downstream agent no quantitative signal about answer correctness to inform this choice. If the upstream agent could con-vey, alongside its answer, a probability reflecting how likely that answer is to be correct, the downstream agent would gain a con-crete basis for its decision. This raises the question: can each agent learn to express calibrated answer confidence while learning its task, and can the downstream agent learn to act on this signal? Training with calibration objectives has shown that a single LLM can learn to produce well-calibrated correctness probabilities for its answers, providing a basis for introducing reliable confidence signals into multi-agent settings [8, 11, 31]. In multi-agent settings, existing work has explored confidence expression and utilization in debates, discussions, and pairwise interactions [36, 40, 58], while other studies have investigated cross-role uncertainty propagation and system-level probability estimation [20, 30]. These efforts each address part of the problem, but no existing framework connects confidence learning, transmission, and utilization across the full collaboration pipeline: the upstream agent needs to learn calibrated confidence for its own answer, and the downstream agent needs to learn to incorporate this signal into its decisions. arXiv:2610.39927v1 [cs.LG] 29 Oct 2026 Chenxiao Fan et al. 

To bridge this gap, we propose MASCAL , in which each agent outputs a correctness probability for its answer alongside complet-ing its subtask; the upstream agent passes this probability to the downstream agent together with its intermediate conclusions. This probability is learned by incorporating a calibration objective into reinforcement learning: task performance and confidence calibra-tion are jointly optimized within a single training loop, so that the model produces probabilities matching its actual correctness rates. To further guide the downstream agent in leveraging this signal, we introduce confidence-aware weighting , which measures how much each generation position responds to the upstream probability and increases the learning weight of the most responsive positions, so that the agent learns more from decisions where it actively uses the upstream signal. The downstream agent also outputs a calibrated probability for its final answer, allowing the system to withhold uncertain outputs or direct rechecking where it is most needed. We evaluate MASCAL under three collaboration architectures (sequential handoff, report fusion, and answer review) spanning Web-based multi-hop question answering, logical reasoning, and mathematical reasoning. MASCAL improves task accuracy over single-agent baselines, MAS without confidence transmission, and existing confidence-based approaches, while the confidence signals of both upstream and downstream agents show improved calibra-tion quality. Intervention analysis further shows that upstream confidence has a measurable effect on downstream decisions, and the learned final confidence supports coverage-accuracy control through selective answering and targeted rechecking. In gener-alization experiments, models trained on a two-hop architecture transfer directly to deeper Web-retrieval chains, and the same recipe remains effective at smaller model scales. Our contributions are as follows: 

• To enable calibrated confidence communication in multi-agent collaboration, we propose MASCAL , which integrates calibra-tion objectives into reinforcement learning so that each agent learns to produce a calibrated correctness probability for its an-swer, and further introduces confidence-aware weighting to guide the downstream agent’s use of upstream confidence. 

• Across three collaboration architectures spanning Web retrieval and reasoning tasks, we demonstrate that calibrated confidence transmission improves task accuracy and calibration quality in MAS, and that upstream confidence measurably affects down-stream decisions. MASCAL further generalizes to deeper collab-oration chains and different model scales. 

• We show that the learned final confidence supports selective answering and targeted rechecking, reducing the error rate of de-livered outputs substantially, or directing additional computation to where it is most needed. 

## 2 Related Work 

In this section, we review related work along two lines: how agents in MAS learn to collaborate and how confidence and uncertainty signals have been introduced into multi-agent settings. 

## 2.1 Multi-Agent Collaboration and Learning 

LLM-driven MAS have been widely applied to Web tasks requir-ing multi-step reasoning and evidence gathering [6, 29, 50]. At the orchestration level, one line of work learns to select collaboration modes and role configurations per query [25, 37, 52, 53]. Given a fixed role assignment, another line focuses on training each role’s policy, curating data from successful and failed trajectories [32, 56] or designing rewards that combine correctness with interaction behavior [33]. Scaling up to the system level, other methods jointly improve multi-role performance [4, 5, 28] through terminal reward propagation [1], preference objectives [3, 42], and inter-role evalua-tion signals [46]. In Web retrieval settings, confidence has been used to control the expansion of query decomposition trees, balancing answer quality against search cost [22]. These methods improve MAS task performance through various mechanisms, yet their training objectives center on final-answer correctness or system efficiency. The reliability of handoff content, specifically whether the upstream agent’s answer is likely correct, remains outside the scope of learning. MASCAL incorporates cali-brated answer confidence into role-level training, making reliability judgments part of the information agents exchange. 

## 2.2 Confidence and Uncertainty in MAS 

Calibrated reinforcement learning has recently shown that a single LLM can learn to produce well-calibrated correctness probabilities for its answers, providing a foundation for introducing reliable con-fidence signals into MAS [8, 10, 11, 31]. In multi-agent settings, early attempts used self-reported confidence for weighted voting [2] or injected uncertainty into peer prompts to modulate answer updates in debate [49]. These untrained signals, however, have been found unreliable [17], sometimes causing unstable interaction behavior. Subsequent work has therefore begun to train confidence expres-sion and utilization: incorporating the listener’s behavior into the speaker’s confidence learning [36], using correctness labels to train verbalized confidence and update behavior in debate [38, 58], or learning confidence scorers for speaker selection and listener filter-ing [40]. These methods focus primarily on debate and discussion, where all participants address the same question. When collaboration goes beyond same-question debate and in-volves multi-step reasoning or role-level handoffs, the scope of uncertainty broadens. Along this direction, work has studied how to propagate uncertainty through reasoning steps [55], let down-stream agents inherit uncertainty from predecessor decisions [30], or use uncertainty to trigger task re-delegation in hierarchical systems [24]. At the output end, counterfactual calibration over communication graphs [20] and multi-source confidence composi-tion [9] have been used to improve final-answer probability quality. The methods above introduce confidence into MAS from com-plementary angles: expression training, signal utilization, cross-role propagation, and final-answer probability estimation. Each, however, addresses only part of the pipeline, and no existing frame-work connects confidence production, transmission, and utilization within a unified learning process. MASCAL fills this gap: each role learns to produce calibrated confidence through calibration RL, the downstream agent trains on reports actually generated by the upstream to incorporate this signal into its decisions, and confidence-aware weighting further strengthens this utilization. ## 5.1 Experimental Setup 

5.1.1 Collaboration architectures. We evaluate MASCAL and the multi-agent baselines under the three architectures in Figure 3: 

• Sequential handoff. A planner decomposes the original question. The upstream agent retrieves evidence, answers the sub-question, and hands off its report. The downstream agent continues re-trieving and answers the original question. 

• Report fusion. After the planner decomposes the question, two upstream agents independently answer the same sub-question and each delivers a report; the downstream agent synthesizes both and proceeds. 

• Answer review. The upstream agent answers the full question and delivers a candidate answer; the downstream agent reviews and either retains or revises it. 

5.1.2 Datasets and metrics. Our primary evaluation uses multi-hop QA [19, 39, 48], where agents retrieve evidence from Web documents and reason across them to answer complex questions. These questions naturally decompose into sub-questions, making them suitable for sequential handoff and report fusion, where each agent handles a separate retrieval step. We further evaluate on logical reasoning with reading comprehension questions [27, 51, 57], and mathematical reasoning with competition-level problems [18]. These tasks involve a single reasoning process that is difficult to decompose, so we evaluate them under answer review, where one agent produces a candidate solution and the other examines and revises it. For each task type, we train on one dataset and evaluate on both its in-domain test set and additional out-of-domain datasets to assess generalization. Table 1 summarizes the splits. ## 5.2 Main Results (RQ1) 

Table 2 compares MASCAL with single-agent, multi-agent, and confidence-based baselines across four evaluation scenarios. MAS-CAL achieves the highest accuracy in all cases. The gains over Task-RL MAS, which shares the same architecture but transmits no confidence, are most pronounced in search-based collaboration, Chenxiao Fan et al. 

where an explicit reliability signal gives the downstream agent richer information for guiding retrieval and reasoning. In sequential handoff, Task-RL MAS falls below the single agent: the downstream agent inherits one upstream report with no indica-tion of its reliability, and uninformed collaboration hurts rather than helps. By attaching calibrated confidence at the handoff, MASCAL raises accuracy well above the single-agent level. Other multi-agent approaches do not match MASCAL’s improve-ments. Cooperative RL methods (MAGRPO, MHGPO) jointly op-timize multiple roles but establish no reliability communication between them. MAGRPO outperforms Task-RL MAS on average under both retrieval architectures, but neither method improves consistently across the four scenarios. Confidence-based methods (ConfMAD, DMAD) do transmit a reliability signal, but post-hoc calibration and verbalized expressions yield limited accuracy gains over Task-RL MAS; on answer review, both fall below it. These re-sults indicate that the confidence signal should be learned through calibration training alongside the task, and the downstream agent should also learn to act on it when making decisions.

## 6 Conclusion and Future Work 

When multiple agents collaborate to retrieve and reason across Web content, the reliability of each agent’s intermediate conclusions di-rectly shapes downstream decisions. We proposed MASCAL, which trains each agent to express calibrated answer confidence alongside its task and introduces confidence-aware weighting to train the downstream agent to act on this signal. Across three collaboration architectures, MASCAL improves task accuracy and calibration quality, and the learned confidence communication transfers to deeper Web-retrieval chains without additional training, while the same training recipe remains effective at smaller model scales. In-tervention analysis and ablation experiments together show that neither producing a confidence signal nor exposing the downstream agent to it is sufficient on its own: the signal must be made reliable through dedicated calibration training, and the downstream agent must also learn to incorporate it into its decisions. As agentic collaboration on the Web scales to more sources and longer reasoning chains, the reliability challenges facing collabo-rative systems grow as well. The current study uses a fixed role assignment with all agents initialized from the same base model, and calibration relies on binary correctness feedback. Extending to heterogeneous MAS composed of different model families, and to open-ended generation tasks where correctness is not binary, calls for more flexible calibration objectives and end-to-end training across roles. Extending confidence learning to multi-round inter-action and dynamic role assignment is a natural next step. In such settings, confidence signals could inform system-level decisions such as role selection and computational allocation. We plan to pursue these directions toward agentic systems in which calibrated confidence serves the full collaboration lifecycle, from each role’s reliability judgment to system-level resource decisions, providing a more principled and reliable foundation for increasingly complex multi-agent information processing on the Web. ## A Experimental Details 

In this appendix, we describe the retrieval setup, the training and evaluation protocols, and the prompts used in our experiments. 

## A.1 Retrieval Infrastructure 

We use the Wiki-18 English Wikipedia dump released with Search-R1 [23] as the retrieval corpus. To keep facts needed during training and evaluation reachable, we additionally index the candidate para-graphs supplied by MuSiQue, HotpotQA, and 2Wiki. Retrieval is performed by E5-base-v2 over a flat inner-product index across the combined corpus. Each call returns the top three passages, each truncated to the first 200 words. Each trajectory is allocated at most three retrieval calls, split across roles differently in each architecture. In sequential handoff, the upstream agent uses one call to answer the sub-question, and the downstream agent uses up to two more calls for the rest of the question. In report fusion, each of the two upstream agents uses one call on the shared sub-question, and the downstream agent uses up to two calls after reading both reports. The sub-question itself is produced by a Qwen3-8B planner used zero-shot, whose outputs are frozen for both training and evaluation. 

## A.2 Training and Evaluation 

All four training scenarios share the hyperparameters in Table 10, with the scenario-specific choices described below. Following prior work [11], we add H and L as reserved tokens whose embeddings are initialized from the existing high and low rows in the base vocabulary, giving the readout a semantically meaningful starting point. The training set is split into two equal, disjoint halves: the upstream agent is trained on one half with the joint objective, then frozen, and generates confidence-bearing reports on the other half; the downstream agent is subsequently trained on these reports.

Calibration training thus improves confidence quality throughout and already lifts accuracy in some scenarios, whereas the remaining gains depend on passing this confidence downstream and training the downstream agent to use it. 

## C Training Overhead 

Confidence-aware weighting replaces the upstream confidence with an unavailability marker and scores each generated downstream trajectory once more, introducing additional computation during training. We compare MASCAL with MASCAL-Unweighted across the four scenarios and measure the complete upstream and down-stream training-iteration time with and without confidence-aware weighting. We run both variants on eight 80-GB GPUs using the training configuration in Appendix A.

Across the four scenarios, confidence-aware weighting increases the total training-iteration time by only 3–14%, since the extra pass scores existing trajectories rather than generating new ones. In return, the downstream agent learns to act on upstream confidence, improving accuracy and calibration in every scenario (Table 7), with the largest accuracy gains in search-based collaboration. Since the scoring pass only computes training weights, the downstream agent at deployment simply reads the confidence from the upstream report and answers without an extra scoring step.
