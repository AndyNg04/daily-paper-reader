## ABSTRACT 

Long-horizon agents continually accumulate experience, yet retaining a memory does not guarantee access when it is needed. Existing systems can adapt both memory content and access; we isolate persistent access updates as a separately controlled adaptation layer. We formulate this target as Memory Index Evolution 

and instantiate it with Adaptive Memory Index Evolution (AMIE), a lightweight plug-in layer that evolves per-memory access state from deployment retrievals without modifying stored content or retraining the host memory system. AMIE distils a semantic teacher’s keep/suppress judgments into a retrieval-conditioned policy and accumulates its selective actions into bounded state that reweights sub-sequent host retrievals. Surprisingly, even a zero-call policy that simply accu-mulates retrieval frequency can match or outperform semantic policies in several settings, revealing retrieval traffic itself as a strong signal for access adaptation, while learned selectivity improves robustness when frequently retrieved memo-ries remain useful. Across five retrieval-based hosts and three benchmarks, trained AMIE improves downstream F1 or accuracy in all 15 comparisons, by 0.70–3.37 percentage points (up to 25% relative), and improves retrieval in all 10 compar-isons. Controlled analyses show that persistent competitor suppression can expose previously unseen evidence, while suppressing repeatedly useful memories cre-ates the complementary failure mode. ## 1 INTRODUCTION 

Long-horizon agents accumulate observations, decisions, and successful procedures that they must recover when a later task needs them (Yao et al., 2023; Shinn et al., 2023; Packer et al., 2023; Maharana et al., 2024; Wang et al., 2024). Retaining this experience is only part of the problem: stored information can remain intact while becoming difficult to retrieve. Consider an agent that retains the episode that solved a software failure, the kind of recurring task that realistic agent benchmarks now probe (Jimenez et al., 2024; Zhou et al., 2024; Merrill et al., 2026). As similar stack traces and configuration notes accumulate, they may rank above that episode when the failure returns. The useful experience has not been deleted or rewritten; access to it has changed. Memory systems address long-term use through extraction, consolidation, tiers, graphs, and learned memory operations (Zhong et al., 2024; Chhikara et al., 2025; Xu et al., 2025; Zhang et al., 2025; Yan et al., 2026b; Huo et al., 2026). Existing systems may adapt both memory content and access, in-cluding recall-dependent strength, access recency, and persistent graph utilities (Zhong et al., 2024; Park et al., 2023; Feng et al., 2026). We instead isolate persistent index updates as a separately controlled layer over the host retrieval interface. This separation asks a specific question: 

Can deployment experience improve memory access without changing stored content? Memory Index Evolution makes persistent access state an explicit adaptation target, distinct from stored content. Two agents with identical stores can encounter different query streams and benefit from different access states. A finite retrieval context makes selection consequential (Liu et al., 2024), but the adaptation target is the state carried between queries, rather than a new context budget or a replacement query-time ranker. 

Adaptive Memory Index Evolution (AMIE) instantiates this layer with a trained index policy that learns which retrieved memories should accumulate suppression. We distil a semantic teacher’s judgments into a compact action model, then carry its decisions forward through bounded per-memory state. The current answer context is sealed before an update is committed; only later host retrievals use the new state. We also find that replacing learned selection with unconditional counting can approach frozen-policy performance on LoCoMo BM25 and MemoryOS, showing how much access improvement retrieval traffic alone can supply in those settings. Selective actions address the complementary risk of penalising memories that remain useful. Across five retrieval-based hosts and three benchmarks, trained AMIE improves the reported utility scores; the ten pairs with retrieval measurements also show retrieval gains (Figure 1). Matched host comparisons assess utility; controlled replays isolate the benefits and risks of suppressing recurrent competitors. State interventions, deployment swaps, and granularity analyses test the persistent access layer (Section 4). Our contributions are: • Memory Index Evolution. We isolate persistent access state as an adaptation target complemen-tary to stored content, with value assessed on subsequent queries (Section 2). • Adaptive Memory Index Evolution. We train a retrieval-conditioned index policy by balanced mask distillation and couple its selective actions to bounded, persistent score updates within native host interfaces (Section 3). • Empirical regularities. Controlled analyses reveal how retrieval history, persistent suppression, and policy selectivity govern access adaptation, and identify the structural conditions under which it can expose unseen evidence without suppressing useful memories (Section 4).

## 3 ADAPTIVE MEMORY INDEX EVOLUTION 

AMIE addresses the three challenges through coupled decisions about what to update , how the up-date persists , and where it acts . A retrieval-conditioned index policy identifies suppression actions from deployment queries and retrieved memories, supplying the interaction-grounded signal re-quired by C1 (Section 3.1). Bounded persistent access dynamics carry these actions across queries, addressing the prospective update required by C2 (Section 3.2). In-the-flow index evolution applies this state within the host’s scored candidate interface, addressing C3 without rewriting stored content (Section 3.3). Trained AMIE im-proves all 15 benchmark–host utility comparisons, spanning the three memory settings and five retrieval systems (Table 2, Figure 1). Interference, rather than store volume alone, creates room for adaptation. Adding near-domain, far-domain, or duplicated content at matched volumes produces different host degradation and count-policy effects in the BM25 replay (Figure 3a). Confusable additions sustain competition, while self-duplication couples competitors to useful evidence; complete volume and seed sweeps are in Appendix F.1. 

Repeated competition and reachable headroom concentrate access gains. The largest BM25 count gain occurs when recurring competitors coexist with missing evidence still inside the candi-date pool (Figure 3b). The label-assisted strata in Appendix D.4 distinguish this opportunity from already-satisfied retrieval or out-of-pool evidence; occupancy alone correlates differently with gain on BM25 and MemoryOS (Appendix C). These are replay diagnostics, not an unlabelled online selection rule. 

Coarse retrieval units can couple suppression to useful evidence. Re-indexing the same con-versations into progressively coarser units lowers evidence purity and reduces the count advantage toward zero (Table D.7). The session-level interval spans zero, identifying separability as a risk factor rather than a universal requirement for fine-grained storage (Appendix D.7). 

Retaining history and discounting stale actions are complementary. In the count replays, grad-ual decay improves recall over unlimited accumulation at suitable half-lives on both hosts, while re-peated resets discard useful state (Figure C.1b,c). These controls suggest preserving a useful history while limiting its long-term suppression cost; decay is a diagnostic variant, not a component of the main-table policies (Appendix C). 

Deployment diagnostics distinguish structural reach from empirical risk. Future retrieval and candidate coverage delimit reach; recurrence, granularity, and state lifetime are empirical risk factors (Table F.1). The strength sweep similarly identifies beneficial settings and damage from aggressive 8Preprint Under Review suppression (Appendix E), supporting deployment diagnostics rather than universal conditions (Ap-pendix F). 

## 5 RELATED WORK 

5.1 ADAPTIVE AGENT MEMORY SYSTEMS 

Mem0, MemoryOS, and A-MEM extract, organise, and retrieve retained experience (Chhikara et al., 2025; Kang et al., 2025; Xu et al., 2025); Memory-R1 and AtomMem learn memory operations (Yan et al., 2026b; Huo et al., 2026). Graph-structured variants organise memories as linked en-tities and temporal knowledge graphs (Edge et al., 2024; Rasmussen et al., 2025; Guti´ errez et al., 2024), and multi-user settings share memory under dynamic access control (Zhang et al., 2025; Rezazadeh et al., 2025). Persistent access adaptation also predates AMIE: MemoryBank updates recall-dependent strength, Generative Agents maintains access recency, and ExpGraph learns per-sistent node utilities within an evolving graph (Zhong et al., 2024; Park et al., 2023; Feng et al., 2026). Protecting earlier behaviour under later adaptation is also the concern of continual learning (Kirkpatrick et al., 2017); AMIE’s analogue protects repeatedly useful memories rather than model weights. Surveys taxonomise this design space (Zhoubian et al., 2026; Yang et al., 2026a; Guo et al., 2024). AMIE isolates index updates for separately controlled plug-in evaluation. Appendix I maps the update targets of the compared systems. 5.2 ADAPTIVE RETRIEVAL AND INDEX LEARNING 

Retrieval-augmented generation couples a parametric reader with a non-parametric index (Lewis et al., 2020; Borgeaud et al., 2022; Gao et al., 2023). Dense retrieval, cross-encoder reranking, and adaptive or agentic retrieval improve which information a query receives (Karpukhin et al., 2020; Nogueira & Cho, 2019; Asai et al., 2024; Jiang et al., 2023; Li et al., 2026). Diversity- and fusion-based rerankers reorder a fixed candidate pool without carrying state across queries (Carbonell & Goldstein, 1998; Cormack et al., 2009), while index structures and learned indexes accelerate access without changing which items are relevant (Malkov & Yashunin, 2020; J´ egou et al., 2011; Kraska et al., 2018). AMIE carries per-memory state from one retrieval event to later queries, through the host’s existing candidate interface. The distinction is the independently controlled update and its prospective effect on subsequent queries. 5.3 LEARNING FROM RETRIEVAL FEEDBACK 

A complementary line optimises memory behaviour from deployment feedback. Memory-R1 and Memory-R2 train memory operations with reinforcement learning over task outcomes (Yan et al., 2026b;a); Mem-α learns memory construction via reinforcement learning (Wang et al., 2025); in-dexed experience memory supports long-horizon agents through retrieval over prior trajectories (Wang et al., 2026); and proactive or unified managers learn when to write, retrieve, or consol-idate (Yu et al., 2026; Wu et al., 2026; LangChain, 2025). Benchmarks increasingly probe such behaviour through incremental multi-turn interactions (Hu et al., 2026). AMIE also learns from deployment feedback, but at a different target: the index state over content that remains fixed, with teacher judgments distilled into a policy whose actions persist across subsequent retrievals. 

## 6 CONCLUSION 

AMIE establishes the memory index as a persistent adaptation layer distinct from stored content, distilling interference judgments into selective actions whose effects persist across subsequent host retrievals. Across heterogeneous memory hosts, AMIE consistently improves downstream utility, while controlled interventions show that suppressing persistent competitors can expose evidence the policy has never observed. Strikingly, a zero-call count policy is already competitive with semantic policies in several settings, while learned selectivity extends the benefit where unconditional sup-pression harms useful memories. Together, these results establish how memories are accessed as a practical adaptation axis alongside what an agent chooses to retain. 9Preprint Under Review

## H PROOF OF RELATIVE ACCESS MONOTONICITY

Proposition 1 (Relative access monotonicity) . Fix a query q, a finite candidate pool, its nonnegative normalised base scores, a strength λp ∈ [0 , 1] , and a total order on candidate IDs for breaking ties. Let m⋆ be a target in that pool, and let one update satisfy ∆u⋆,t = 0 and ∆uj,t ≥ 0 for all 

j̸ = ⋆. Then under Equation 11 no competitor’s score increases, so the rank of m⋆ cannot worsen; and, if λp > 0, for every competitor mj with ˆσ(q, j ) > 0 and ∆uj,t > 0, the pairwise margin 

∆⋆j,t (q) = st(q, m ⋆) − st(q, m j ) strictly increases. 

We prove Proposition 1 for the same query and candidate pool before and after one state update. Scores are sorted in descending order; numerical rank starts at one, so a smaller rank is better. The base scores, suppression strength, and ID order used to break ties are held fixed throughout this comparison. 

Proof of Proposition 1. Write bi = ˆ σ(q, i ) ≥ 0 and δi = ui,t +1 − ui,t . By assumption, δ⋆ = 0 and 

δj ≥ 0 for every competitor j. From Equation 11, 

st+1 (q, i ) − st(q, i ) = −λpbiδi. (20) Thus the target’s score is unchanged and every competitor’s score is nonincreasing. Subtracting the competitor’s score from the target’s gives 

∆⋆j,t +1 (q) − ∆⋆j,t (q) = λpbj δj ≥ 0. (21) This inequality is strict whenever λp > 0, bj > 0, and δj > 0, proving the pairwise-margin statement. To establish the ranking statement, let Pt be the set of candidates that precede m⋆ at step t: their scores are higher, or equal with their IDs preceding the target under the fixed tie order. Take any 

j /∈ Pt, j̸ = ⋆. If its score is strictly lower than the target’s, it remains lower because it cannot increase and the target’s score stays fixed. If the scores are equal, j already loses the tie; after the update it either has a lower score or still loses the same tie. Hence no such candidate can enter Pt+1 ,and 

Pt+1 ⊆ Pt, rt+1 (m⋆) = 1 + |Pt+1 | ≤ 1 + |Pt| = rt(m⋆). (22) The target’s numerical rank therefore cannot increase, completing the proof. 

Top-k consequence and scope. For a fixed budget k, a target already in the top k remains there. A previously excluded target enters exactly when |Pt+1 | < k ≤ | Pt|. Strict pairwise-margin im-provement alone does not ensure this crossing: competitors may still remain ahead. If λp = 0 ,all scores and ranks are unchanged. The result compares two states on the same query; it does not assert monotonic ranks across different queries. It also does not cover a changing candidate pool, base scores, strength, tie order, or an update that suppresses the target itself.
