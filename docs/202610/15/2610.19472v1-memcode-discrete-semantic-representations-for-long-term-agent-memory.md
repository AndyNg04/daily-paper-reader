## 摘要
长期记忆仍是大语言模型（LLM）智能体跨会话应用中的一个根本性瓶颈。现有系统通常采用先写入、后检索的范式，将依赖上下文的对话片段存储起来，再通过连续嵌入空间中的近邻搜索进行检索。这种设计导致记忆访问单元不稳定，并且系统性地遗漏逻辑相关但词汇差异较大的证据。我们提出 MemCode，一种将面向检索的写入与离散关联检索相结合的长期智能体记忆框架。MemCode 将对话改写为自包含的原子记忆单元（AMU），通过同构语义量化（ISQ）将 AMU 映射到可学习码本，并利用码本的共现拓扑作为向量搜索的补充检索路径。针对长期记忆存储，MemCode 将在线原子写入与异步离线整合分离。在采用 GPT-4o-mini 和 Qwen3-30B-A3B-Instruct-2507 作为骨干模型的 LongMemEval-S 和 LoCoMo 上，MemCode 在保持每段对话的记忆构建时间约为 40～130 秒的同时，取得了最高的总体准确率；其速度比 LightMem 快 3～21 倍，比 A-MEM 和 MemoryOS 快一个数量级以上。

## Abstract
Long-term memory remains a fundamental bottleneck for large language model (LLM) agents across sessions. Existing systems typically adopt a write-then-retrieve paradigm, storing context-dependent dialogue fragments and retrieving them via nearest-neighbor search in a continuous embedding space. This design yields unstable access units and systematically misses logically related but lexically distant evidence. We propose MemCode, a long-term agent memory framework that couples retrieval-oriented writing with discrete associative retrieval. MemCode rewrites dialogue into self-contained atomic memory units (AMUs), maps AMUs into a learnable codebook with isomorphic semantic quantization (ISQ), and uses codebook co-occurrence topology as a retrieval path complementary to vector search. For long-term memory stores, MemCode separates online atomic writes from asynchronous offline consolidation. On LongMemEval-S and LoCoMo with GPT-4o-mini and Qwen3-30B-A3B-Instruct-2507 backbones, MemCode achieves the best overall accuracy while keeping per-dialogue memory construction within roughly 40~130 seconds, making it 3~21 times faster than LightMem and over an order of magnitude faster than A-MEM and MemoryOS.

## 1. 核心问题与研究背景

### 1.1 研究动机

长期个人助手需要跨会话记住用户的经历、偏好、状态变化，并在后续问题中准确调用。但现有方案存在两类局限：

- **模型参数难以动态更新**，不适合持续记录个人信息。
- **直接使用完整历史上下文成本较高**，且上下文变长后，模型未必能有效利用其中的信息。

因此，主流系统采用外部记忆与检索增强生成（RAG）：先存储历史对话，再检索相关内容辅助回答。

### 1.2 论文关注的两个关键问题

- **写入单元不稳定**：原始对话片段包含代词、相对时间、隐含说话人等，脱离上下文后难以理解。例如，“他昨天回来了”并不是一个可独立检索的可靠事实。
- **连续向量检索存在遗漏**：向量近邻擅长寻找语义相近内容，但可能漏掉措辞不同、却在实体关系、时间或推理链上相关的事实。

论文的核心观点是：**长期记忆不能只优化存储规模或检索器，而应联合设计“写什么、如何索引、如何检索和如何维护”。**

整体上，MemCode 仍属于 RAG 框架，并非新的基础语言模型。其主要贡献是将**自包含事实写入、离散关联索引、双路径检索与离线整合**组织成统一的长期记忆系统。

## 2. 方法论：核心思想与技术流程

### 2.1 原子记忆单元：先把对话改写成可独立使用的事实

系统按时间顺序处理对话，每次以一个真实交互轮次为目标，并附带上一轮末尾的少量句子作为只读背景。

LLM 执行以下操作：

- 过滤问候、简短反应和模糊闲聊。
- 将代词替换为明确的人物或说话人。
- 根据消息时间戳，把“昨天”“上周”等改写为绝对时间。
- 合并零散表达，生成自包含的原子记忆单元（AMU）。
- 保留事实对应的原始对话位置，便于回溯。

每个 AMU 包含三部分：**规范化事实、绝对时间、来源指针**。背景仅用于理解，不作为新的事实重复提取。

### 2.2 双路径索引：连续向量与离散码本并存

每条 AMU 建立两套访问接口：

| 索引路径 | 实现方式 | 作用 |
|---|---|---|
| 连续向量路径 | 768 维 `bge-base-en-v1.5` 嵌入 | 检索直接相关、语义邻近的事实 |
| 离散码本路径 | T5-base 编码器与 VQ-VAE 式量化 | 建立离散锚点，支持关联补充检索 |

离散表示采用**同构语义量化（ISQ）**：

1. 使用 T5-base 对 AMU 进行 token 级编码。
2. 通过步长为 1 的投影保留序列长度，避免下采样直接丢失日期、数字和实体位置。
3. 将每个位置的向量映射到最近的码本向量。
4. 删除相邻重复码号，形成 AMU 的离散“语义指纹”。

码本包含 **1024 个码向量**。需要注意，保留 token 对齐不等于量化无损；论文仍保存完整 AMU 文本，离散指纹只是辅助检索键，不直接替代回答证据。

### 2.3 码本训练：预测回复，而非重建输入

码本使用 DailyDialog 的上下文—回复数据训练：

- 输入为前两条话语，目标为下一条回复。
- 优化目标包括回复生成交叉熵、量化与承诺损失；附录还列出了码本使用熵正则。
- 使用直通估计器处理离散量化的梯度。
- 通过指数滑动平均更新码本，并定期重新初始化低频码，降低码本塌缩风险。

其意图是学习对对话延续有用的模式，而不只是压缩表面词汇。码本在基准评估前冻结，不使用基准问题、答案或检索轨迹训练。

### 2.4 关联检索：利用码号共现补充向量搜索

系统统计不同码号在同一 AMU 中的共现次数，构成隐式拓扑：

- 共现越频繁，两个码号之间的关联越强。
- 将共现次数归一化为转移概率。
- 对高频查询码号施加 IDF 降权，减少通用锚点的干扰。

查询经过相同量化后，激活相关码号，再据此寻找补充事实。候选 AMU 取其与查询码号之间的最高关联分数。

最终采用**非对称融合**：

1. 向量路径先检索 20 条 AMU。
2. 码本路径从未被选中的事实中再补充 20 条。
3. 根据来源指针恢复部分原始对话，并按时间排序后交给回答模型。

所有主实验只进行**一跳码本扩展**。因此，论文中的多跳问答收益，不应理解为系统执行了多步显式图推理，而是它补充了回答多跳问题所需的分散证据。

### 2.5 异步离线整合

为处理重复、过时和碎片化事实，系统在线写入之外设置离线维护：

- 根据向量余弦相似度进行层次凝聚聚类。
- 对较大聚类按时间拆分。
- 通过门控保护计数敏感、状态更新敏感的事实，并避免混合不同说话人。
- 执行聚合、合并或更新。
- 归档旧事实，建立旧事实到新事实、再到原始对话的指针链。

整合能恢复跨片段连续性，但也可能把多个时间点压缩成时间区间，损失细粒度时间信息。

## 6. 主要结论与发现

### 6.1 总体准确率较高

| 基准 | 骨干 | LightMem | MemCode | MemCode + 异步整合 |
|---|---|---:|---:|---:|
| LongMemEval-S | GPT-4o-mini | 68.64% | 77.20% | **78.40%** |
| LongMemEval-S | Qwen3 | 61.95% | 73.80% | **74.60%** |
| LoCoMo | GPT-4o-mini | 71.95% | 78.12% | **79.55%** |
| LoCoMo | Qwen3 | 71.36% | 76.36% | **76.88%** |

在主表所比较的方法中，整合版取得四个设置的最高总体准确率，但并非每个任务类别都最优。

### 6.2 原子写入是重要收益来源

- 移除原子事实抽取后，LoCoMo 总体准确率降至约 **53.8%**。
- 来源上下文恢复也有帮助，但影响小于 AMU 写入本身。

这说明：**将事实写成可独立理解、可定位的形式，比单纯扩大检索范围更关键。**

### 6.3 离散路径有独立贡献，但优势集中在结构化任务

在相同 AMU 库与 40 条证据预算下：

- 向量检索从 20 条增至 40 条：总体仅增加约 **1.43 个百分点**。
- 20 条向量 + 20 条码本：总体达到 **78.12%**，高于向量 40 条的 **74.61%**。
- 相比向量 + BM25，码本路径在：
  - 多跳问题提高 **4.26 个百分点**。
  - 时间问题提高 **6.23 个百分点**。
- 但 BM25 在开放式及单跳问题上略占优势。

另外，码本补充事实中有 **69.3%** 不在向量 top-100 中，证明两条路径具有较强差异性；但“检索不同”本身并不等于新增事实全部有效。

### 6.4 整合存在明确权衡

- 能改善多跳与跨片段推理。
- LoCoMo 多跳准确率提升约 **4.26 / 7.09 个百分点**。
- 时间准确率可能下降，表明叙事连续性与时间粒度并不总能同时提升。

### 6.5 速度优势不等于费用优势

- 每段对话构建约 **40—130 秒**。
- 相比 LightMem，报告约 **3—21 倍**速度提升。
- 但 MemCode 的 token 与调用次数高于 LightMem，速度优势主要来自并行抽取。

因此，**低墙钟延迟不能直接解释为低 API 费用或低总计算量。**

## 7. 优点与亮点

- **问题定位清晰**：把长期记忆看作写入与检索的联合设计问题，而不只是向量数据库问题。
- **工程链路完整**：事实规范化、双索引、来源恢复、归档转发与离线整合形成闭环。
- **离散索引用法克制**：不替换原文、不完全取代向量检索，而是作为补充路径，降低信息丢失和关联噪声风险。
- **固定预算对照较有说服力**：同时控制 AMU 存储与证据条数，并与 BM25、HyDE、显式图方法比较。
- **可追溯性较好**：来源指针与归档链支持检查抽取和整合过程。
- **明确承认任务边界**：主动报告开放式问答弱点、时间粒度损失，以及图方法准确率相当的结果。

## 8. 不足与局限

### 8.1 表示与检索机制的限制

- **事实化会丢失隐含信息**：情绪、动机、语用含义和叙事氛围难以完整转成原子事实，原始上下文方法在开放式问题上仍有优势。
- **共现不等于逻辑关系**：码本拓扑提供统计关联，并不显式表示因果、否定、关系方向或逻辑蕴涵。
- **存在高频码号干扰**：前 10 个码解释约 39.23% 的赋码，说明码本较集中；IDF 能缓解，但不能完全消除热门锚点噪声。
- **AMU 的最高单码匹配评分较粗糙**：一个强关联码就可能使候选得分较高，未充分要求多个查询条件同时满足。

### 8.2 评估与结论边界

- **LLM 判分可能有偏差**：GPT-4o-mini 同时参与部分写入、回答和全部自动评价，缺少充分的人类复核或多评委交叉验证。
- **整体领先不意味着所有方面领先**：开放式问题、多会话连续性，以及与显式图方法的准确率比较，都不支持全面优越的结论。
- **缺少真实部署与超大规模评估**：尚未测试长期工具使用、规划、自主行动、百万级记忆维护或持续在线图更新。
- **域外泛化未知**：码本主要从日常英语对话学习，跨语言、专业领域与多模态表现尚未验证。

### 8.3 成本与复现信息仍不完整

- 未报告码本训练时长及完整服务端算力。
- 未系统报告长期存储增长、整合复杂度、端到端 token 成本和高并发资源占用。
- 主文公式与附录实现描述存在需要澄清之处：例如主文一跳检索公式中，若衰减系数 α 仅作为所有候选共同的乘数，理论上不会改变排序，但附录调节 α 后准确率发生变化，说明可能还有未充分展开的交互或执行细节。

### 8.4 真实个人记忆的安全风险

- 抽取错误可能被后续整合和个性化持续放大。
- 归档和来源指针有助于审计，但不自动解决删除、隐私及权限问题。
- 真实部署还需用户同意、记忆查看与删除、保留期限，以及对原始对话、向量和共现统计的一致性清理。

**总体评价：MemCode 较有说服力地表明，规范化原子写入与离散关联检索能够改善结构化长期记忆问答；其优势主要体现在明确实体、时间和组合事实的检索，以及构建延迟，而非所有类型的理解能力、总体成本或真实智能体任务表现。**
