## 摘要
在许多人机系统中，候选动作并不会直接执行，而是先由另一个决策实体进行评估；该实体可能采用不同的目标或决策模型。标准决策论框架并不要求显式表示这种交互，因为它们直接定义状态—动作对上的转移动态，使评估过程可以被纳入转移模型。我们提出一种感知语义的决策框架，其中候选动作先被提出，再依据交互情境进行评估，最终确定为实际执行结果。我们通过联合动作语言和解释函数对这一过程进行形式化：解释函数将每个联合动作及其情境映射为语义结果。转移动态和奖励动态由这些语义结果导出，从而为交互语义引入一个显式的表征层。语义结果为组织交互原则提供了明确的单元，这些原则可通过特定应用的评估机制加以实例化，并在不同交互实例间复用。由此，我们提供了一种结构化接口，可将依赖情境的评估与由此产生的执行动态分别进行描述，而无需更改底层规划算法。我们在共享人机自主系统中实例化该框架，刻画建议与授权等交互模式，并展示交互情境如何影响决策。所得形式化仍与标准马尔可夫决策过程（MDP）规划兼容。

## Abstract
In many human-AI systems, candidate actions are not executed directly but are first evaluated by another decision-making entity under a potentially different objective or decision model. Standard decision-theoretic frameworks do not require this interaction to be represented explicitly, as they define transition dynamics directly over state-action pairs, allowing evaluation to be absorbed within the transition model. We introduce a semantics-aware decision framework in which a candidate action is proposed, evaluated under an interaction context, and then resolved into an executed outcome. We formalize this through a joint action language and an interpretation function that maps each joint action and context to a semantic outcome. Transition and reward dynamics are induced through these semantic outcomes, thereby introducing an explicit representational layer for interaction semantics. Semantic outcomes provide explicit units for organizing interaction principles, which can be instantiated through application-specific evaluation mechanisms and reused across distinct interaction instances. This provides a structured interface for specifying context-dependent evaluation separately from the resulting execution dynamics, without requiring changes to the underlying planning algorithm. We instantiate the framework in shared human-AI autonomy, capturing interaction patterns such as advisory and authorization, and illustrating how interaction context influences decision making. The resulting formulation remains compatible with standard Markov decision process (MDP) planning.
