## 摘要
基于大语言模型（LLM）的智能体在个性化交互任务中面临诸多挑战，原因在于长期交互轨迹具有异质性、类型多样，且包含隐式约束。现有记忆机制难以实现准确的路由与检索；在个性化尤为重要的端侧场景中，这一问题更加突出。大多数方法采用单一向量表示，模糊了记忆类型之间的区别及其关系结构。我们提出 HGP，一种混合图记忆框架。HGP 使用轻量级自增强分类器进行个性化记忆路由，并将情景记忆、语义记忆和程序记忆构建为图。此外，HGP 将工作记忆提取为状态轨迹，以捕捉当前状态和隐式约束，从而确保决策可靠。该分类器减少了对大模型的调用，使端侧部署成为可能；图存储则支持准确检索和用户画像的增量优化。在两个基准测试上的实验表明，在 PAL-Set 的方案选择任务中，HGP 的 S-score 达到 35.58，比最强基线高出近 7 分。代码和数据见 https://github.com/Ouan6/HGP-.git。

## Abstract
LLM-based agents face challenges in personalized interactive tasks due to heterogeneous, multi-typed, and implicitly constrained long-term traces. Existing memory mechanisms struggle with accurate routing and retrieval, especially on-device where personalization is critical. Most methods use single-vector representations, blurring type distinctions and relational structure. We propose HGP, a hybrid graph memory framework. HGP employs a lightweight self-enhancement classifier for personalized memory routing and constructs episodic, semantic, and procedural memories as graphs. It also extracts working memory as a state trajectory to capture current state and implicit constraints, ensuring reliable decision-making. The classifier reduces large-model calls, enabling on-device deployment, while graph storage enables accurate retrieval and incremental user profile refinement. Experiments on two benchmarks show that on PAL-Set solution selection, HGP achieves an S-score of 35.58, nearly 7 points above the strongest baseline. Code and data are at https://github.com/Ouan6/HGP-.git.

## 1. 核心问题与整体含义：如何让智能体长期“记对、找准、用好”用户信息

### 研究背景与动机
- 个性化 LLM 智能体需要跨轮次、跨会话利用用户信息，不仅回答历史事实，还要根据用户的偏好、行为习惯及当前任务状态作出合适决策。
- 长期交互中混合了不同性质的信息：
  - **情景信息**：发生过什么、何时发生、涉及哪些人或地点。
  - **语义信息**：长期偏好、个人属性、健康状况等稳定事实。
  - **程序性信息**：可复用的操作流程和决策策略。
  - **工作状态**：当前任务进度、尚未完成的动作和隐式约束。
- 论文认为，统一记忆池与单向量检索容易混淆这些类型及其关系，导致两类问题：
  1. **写入路由错误**：将信息存入不合适的记忆类型，进而影响后续检索。
  2. **检索与决策失准**：找到语义相近的历史片段，却遗漏关系结构或当前约束。

### 整体含义
HGP 将个性化记忆视为一个“**分类型写入—结构化存储—联合检索—状态感知决策**”系统，而不是单纯扩展上下文窗口。

需要注意：论文所称的“端侧”主要指**延迟敏感的在线路由与检索在本地执行**；图构建和分类器更新异步进行，并不意味着全部模型调用、训练与生成都在设备本地完成。

## 2. 方法论：自增强路由器与四类混合图记忆

### 2.1 核心思想
HGP 包含两个主要模块：
- **轻量自增强分类器**：识别输入片段的记忆类型，在低置信度时请求 LLM 标注，并利用这些标注持续更新。
- **混合图存储**：为不同记忆类型采用不同结构，保留其时间、实体、条件与状态关系。

### 2.2 个性化记忆路由
具体流程如下：
1. 轻量分类器预测输入片段的类型，并输出置信度。
2. 若置信度高于当前阈值，直接使用分类器结果。
3. 若置信度低于阈值，交由 LLM 判断；将输入及 LLM 标签缓存为增量训练数据。
4. 周期性微调分类器，使其适应用户特有的信息分布。

阈值采用**指数衰减并设置下限**：
- 初期阈值较高，让 LLM 承担更多判断。
- 随着迭代逐步降低阈值，将任务转移给轻量分类器。
- 默认参数为初始阈值 **0.90**、衰减率 **0.05**、下限 **0.50**。

分类器采用 `roberta_L-4_H-512`。框架示意图还包含碎片化或噪声信息类别，但其具体处理与评估细节较少。

### 2.3 四类记忆及其图表示

| 记忆类型 | 存储结构 | 主要内容与用途 |
|---|---|---|
| 情景记忆 | 事件图 | 保存具体事件、时间顺序、上下文实体及事件间关系 |
| 语义记忆 | 知识图谱 | 以用户—关系—实体三元组保存稳定事实、偏好与约束 |
| 程序性记忆 | 规则树 | 用条件、动作和子目标节点表达顺序流程与条件分支 |
| 工作记忆 | 状态轨迹图 | 跟踪当前状态、状态转移、任务进度及待执行事项 |

此外，系统通过 LLM 从累积事件中抽象出：
- **语义知识**：例如由交互证据提取用户偏好，输出带置信度的三元组。
- **程序规则**：提取可复用流程，输出触发条件、执行步骤、标签及树结构；没有明确规则时返回空结果。

### 2.4 检索与生成流程
用户提出问题后，系统并行查询各类图：
- 事件图提供相关历史经历。
- 知识图谱提供长期用户画像与约束。
- 规则树提供适用策略。
- 状态轨迹图提供当前行动状态。

随后，将检索结果合并为上下文，交给 LLM 生成回答。其关键区别是：不仅考虑“用户通常喜欢什么”，还考虑“用户现在有哪些未完成事项”。

不过，论文对具体图遍历、排序、去重、冲突消解和检索预算分配的描述较概括，方法细节主要集中在记忆组织上。

## 3. 实验设计：数据集、任务与比较方法

## 6. 主要结论与发现

### 6.1 主实验结果

| 任务/指标 | HGP | 最强对应基线 | 提升 |
|---|---:|---:|---:|
| LoCoMo 总体 Judge | 65.08 | HippoRAG2：62.13 | +2.95 |
| LoCoMo 总体 BLEU-1 | 42.09 | TurnRAG：40.11 | +1.98 |
| LoCoMo 总体 EM | 20.54 | Mem0：20.14 | +0.40 |
| PAL-Set Selection S-score | 35.58 | HippoRAG2：29.22 | +6.36 |

- LoCoMo 总体 F1 为 **45.07**，略低于 Mem0 的 **45.42**，因此并非所有指标都最佳。
- PAL-Set QA 的 BLEU-2/3/4 和 Judge 最佳，分别为 **8.67、4.70、2.78、7.46**；BLEU-1 并非最佳。
- “比最强基线高近 7 分”的准确数值是 **S-score 提高 6.36 分**。

### 6.2 消融揭示的机制
- **记忆分类型贡献很大**：S-score 从统一向量的 **25.15** 提升到分类型向量的 **33.66**。
- **图结构进一步增益**：完整 HGP 达到 **35.58**，较分类型向量增加 **1.92**。
- **语义记忆最影响方案选择**：移除后 S-score 降至 **25.71**，下降 **9.87**。
- **情景记忆对问答证据很重要**：移除后 Judge 从 **7.46 降至 7.09**，S-score 下降 **6.75**。
- **程序性记忆提供补充策略价值**：移除后 S-score 下降 **2.48**。

由此，更准确的结论是：**类型区分带来了主要选择性能增益，图结构在此基础上提供额外收益**，不能把全部提升归因于图存储。

### 6.3 路由与工作记忆
- 自增强路由器取得 Macro-F1 **0.9339**、Micro-F1 **0.9105**，优于表中其他路由器。
- 工作记忆案例展示了主动提醒未完成事项的能力，但只支持可行性判断，尚不能证明普遍可靠性或安全性。

## 7. 优点：结构清晰、机制合理、消融有解释力

- **针对真实个性化需求设计**：区分经历、画像、策略和当前状态，避免将所有历史当作同质文本。
- **低成本自适应路由**：将低置信度样本交给 LLM，并回收为训练数据，实现监督成本的逐步摊销。
- **结构与信息性质匹配**：事件图、知识图谱、规则树和状态轨迹分别服务不同检索需求。
- **消融设计较有价值**：统一向量与分类型向量的比较，有助于区分“类型划分”和“图结构”的贡献。
- **不只评估事实回忆**：PAL-Set Selection 更直接检验记忆是否帮助智能体作出符合用户需求的选择。
- **工作记忆视角值得关注**：强调长期偏好与当前执行状态不可互相替代，对任务型助手具有启发意义。

## 8. 不足与局限：效果证据尚不能覆盖全部系统主张

### 8.1 端侧与全流程成本证据不足
- 无实际硬件、存储规模、功耗或完整端到端延迟测试。
- 减少路由阶段的 LLM 调用，不等于减少全部记忆提取、图构建和回答生成成本。
- 异步图更新可能产生状态滞后，论文没有系统分析其影响。

### 8.2 工作记忆与安全性验证有限
- 工作记忆仅通过单一案例展示，没有错误率、过期状态率或约束遵循率等指标。
- 健康场景示例不能视为医学安全验证；附录示例中用户有布洛芬过敏信息，但候选方案仍讨论其与阿司匹林联用，说明**检索到约束不等于生成时可靠遵守约束**。

### 8.3 路由与抽象可能引入偏差
- LLM 标签并非天然正确，错误监督可能进入增量训练。
- 高置信度但错误的分类可能绕过 LLM，缺少主动纠错机制。
- 阈值随迭代下降，不直接依据置信度校准或分布漂移调整。
- 从一次经历抽象长期偏好、从用户正反馈抽象策略，都可能把偶然行为或不安全经验固化为记忆。

### 8.4 图记忆维护与检索仍不完整
- 缺少详细的矛盾处理、事实有效期、遗忘、删除、剪枝及跨记忆一致性机制。
- 数据增长后的查询效率和维护成本未充分验证。
- 用户敏感数据的加密、隔离及 LLM 标注时的数据外传风险未系统讨论。

### 8.5 评价与报告存在不确定性
- 同一模型用于生成和评审，可能存在风格偏好或相关误差。
- 主结果缺少统计显著性分析，尤其 QA Judge 的小幅优势应谨慎解释。
- 附录超参数评分公式与表中实际分数存在不一致：表格更像按“超出最优延迟的部分”进行惩罚，说明报告仍需校核。

**总体评价：**HGP 的主要价值在于将“个性化路由”和“异质记忆结构”整合起来，并通过消融说明记忆类型的重要性。它对个性化方案选择表现出较明确的增益，但对完整端侧部署、长期漂移适应、工作记忆可靠性及安全决策的支持证据仍不充分。
