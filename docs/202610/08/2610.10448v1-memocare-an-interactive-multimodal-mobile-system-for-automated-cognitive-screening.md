## 摘要
MemoCare 是一款用于自动化多模态认知筛查的交互式移动系统。该系统采用 React Native 应用，整合口语回答、时间与空间定向、触屏操作及 visuoconstruction，并提供完整的英语和越南语工作流程。语音由 Google Speech-to-Text 转录，并使用本地确定性任务专用自然语言处理规则评分；GPS 坐标由 MemoCare 空间模块解析后再与答案匹配；触屏任务依据交互事件评分；绘图任务则采用三个卷积神经网络模型进行共识判断，并单独开展视觉解读。软件测试在语音/语言、空间答案和触屏交互评分方面通过了全部 151 个预定义测试案例；空间回归测试在四个国家的坐标解析案例中通过了全部 48 个测试案例。对于绘图模块，在验证集上选定的 ShuffleNetV2 x1.5 在锁定的 71 张图像测试集上取得了 91.33% 的平均平衡准确率，以及 78.87% 的三项标准完全准确率。此外，四位临床医师共同作者对端到端工作流程进行了评估：八项标准的合并中位评分为 4/5，各项评分中位数介于 3 至 4.5 之间。在 MMM，参会者可以直接体验精简版多模态筛查流程，并查看自动生成的单项及总分。

## Abstract
MemoCare is an interactive mobile system for automated multimodal cognitive screening. A React Native application combines spoken responses, temporal and spatial orientation, touchscreen actions, and visuoconstruction in complete English and Vietnamese workflows. Speech is transcribed by Google Speech-to-Text and scored locally with deterministic task-specific natural language processing rules; GPS coordinates are resolved by the MemoCare spatial module before answer matching; touch tasks are scored from interaction events; and the drawing task uses a three-model convolutional neural network consensus with separate visual interpretation. Software tests pass 151/151 predefined cases across speech/language, spatial-answer, and touch-interaction scoring, while spatial regression passes 48/48 four-country coordinate-resolution cases. For the drawing module, validation-selected ShuffleNetV2 x1.5 achieved 91.33% mean balanced accuracy and 78.87% exact three-criterion accuracy on a locked 71-image test set. Four clinician co-authors additionally inspected the end-to-end workflow, yielding a pooled median rating of 4/5 across eight criteria, with item-level medians ranging from 3 to 4.5. At MMM, attendees can directly try a shortened multimodal screening workflow and inspect automatic item-level and total scoring.

## 2. 方法论：核心思想与关键技术

### 2.1 总体架构与流程

- 使用 **React Native** 开发 Android/iOS 应用，现场演示采用 Android。
- 系统按任务类型将输入路由至不同模块：
  1. 播放本地化指令并采集回答或操作；
  2. 语音、位置、触屏、绘图模块分别处理；
  3. 各模块通过统一接口输出题目分数；
  4. 汇总题目级与总分，并在设备本地保存评估状态和历史结果。
- 支持重复指令、跳过、暂停、恢复及无回答提醒；连续计算等任务保留跨轮次状态。
- **这里的“多模态”主要体现为不同任务使用不同模态，并统一汇总评分，而不是将全部模态输入同一个端到端融合模型。**

### 2.2 语音与语言评分

- 流程为：**音频裁剪 → Google Speech-to-Text 转写 → 文本规范化 → 任务专用确定性规则 → 得分**。
- 规则覆盖：
  - 日期和数字解析；
  - 有状态的连续计算；
  - 多目标记忆回忆匹配；
  - 有序短语匹配；
  - 句子完整性检查。
- 根据任务容忍犹豫、重复及常见转写或词汇变体，英语、越南语使用不同规范化规则。
- 部分任务优先匹配相关关键词，不从可能不完整的转写中推断否定或自我纠正。这种设计较简单、可追踪，但也可能误判复杂回答。

### 2.3 基于位置的空间定向评分

- 使用越南、瑞士、中国和美国的 **89,043 条行政边界记录**，数据来自 OpenStreetMap，经 Geofabrik 获取。
- 算法流程：
  1. 获取设备 GPS 坐标；
  2. 通过空间索引检索附近候选行政区域；
  3. 使用点在多边形内判定确定所属区域；
  4. 返回可接受的当前及历史地名；
  5. 对地名和转写文本规范化，再进行精确或近似匹配。
- 该设计避免全量扫描边界数据，也允许行政更名、历史名称和别名在适当情况下被接受。

### 2.4 触屏动作评分

- 将部分动作任务改为触屏交互，依据事件类型、目标及顺序评分。
- 主要包括：
  - 多步骤点击与拖动序列验证；
  - 判断触点是否落入图像预设区域。
- 全部处理在本地进行，不需要摄像头或额外传感器。

### 2.5 绘图评分与视觉解释

- 用户在触屏上临摹几何参考图，位图缩放至 **224 × 224**。
- 模型分别预测三个内部结构标准：
  - **C1–C3** 涉及组成形状有效性及两项空间关系；
  - 应用对外输出二元题目结果：**三个标准全部满足才判为通过**。
- 训练流程：
  1. 使用规则生成带有 C1–C3 标签的合成图像；
  2. 在合成数据上训练 ImageNet 预训练轻量 CNN；
  3. 在人工绘图训练集上微调；
  4. 利用验证集选择概率校准方式与判定阈值；
  5. 在锁定测试集上评价。
- 比较原始概率与温度缩放概率，并通过 bootstrap 重采样寻找稳定阈值范围。
- 部署系统使用三个 CNN 的条件共识机制；另有独立的、面向结构标准的 **U-Net** 提供视觉解释，**不参与最终二元评分**。论文未详细给出共识条件或 U-Net 的训练与评价细节。

## 6. 主要结论与发现

- MemoCare 实现了语音、位置、触屏和绘图任务的统一移动交互与自动评分流程。
- 预定义规则和空间解析测试全部通过，表明已覆盖案例中的软件逻辑符合预期。
- 验证集选出的 ShuffleNetV2 x1.5 在锁定绘图测试集上取得较高平均 BA，但三标准同时正确的比例为 78.87%，说明组合判断仍存在明显误差。

- 专家较认可流程、指令和触屏交互；题目结果透明度相对较弱：
  - 数字流程、指令清晰度、触屏交互：中位数均为 4.5/5；
  - 自动评分与临床判断一致性、交互控制：均为 3.5/5；
  - 题目结果透明度：3/5。
- **最重要的结论边界：现有证据证明的是技术与交互可行性，不是认知障碍诊断效度。**

## 7. 优点与亮点

- **覆盖完整工作流**：不仅处理单一模态，还包含任务提示、输入采集、评分、结果和历史管理。
- **任务语义驱动的模块化设计**：语音、空间、触屏和视觉各用适合的技术，并通过统一接口集成，便于替换组件。
- **规则逻辑易于检查**：确定性评分有助于定位错误，连续任务状态管理也较贴合筛查流程。
- **地点评分具有实际针对性**：纳入历史名称和行政别名，减少机械匹配造成的误判。
- **绘图数据策略务实**：用结构可控的合成数据缓解人工样本不足，再进行人工绘图微调。
- **证据边界表述清楚**：明确说明语音测试不评价 STT、共识结果仅为描述性、专家检查不等于临床验证。
- **部署门槛相对低**：无需摄像头或额外传感器，并支持双语与多种流程控制。

## 8. 不足与局限

### 8.1 临床与测量有效性不足

- 没有患者招募、临床诊断标签或与标准量表的正式对照。
- 未报告认知障碍检测的灵敏度、特异度、ROC-AUC、重测信度等。
- 触屏替代传统动作、重复或跳过任务后，是否仍保持原测试的测量含义，尚未验证。
- 缺少对年龄、教育、语言能力、听力、运动障碍和数字设备熟悉度等混杂因素的分析。

### 8.2 数据与泛化风险

- 人工绘图来自研究者，可能与真实老年人或认知受损者的笔迹、操作方式存在域差异。
- 小规模验证和测试集限制了性能估计稳定性。
- 未报告标注者一致性、跨人群外部验证或跨设备评价。
- 四国边界库虽大，但仅用 48 个固定坐标测试，不能充分代表边界附近、GPS 漂移或历史区划复杂情况。

### 8.3 算法与解释局限

- 未测试真实语音识别链路的准确性，对口音、噪声、停顿和言语障碍的稳健性未知。
- 忽略部分否定或纠正语义的关键词匹配可能导致误评分。
- 共识模型存在事后选择偏差。
- U-Net 解释模型独立于评分模型，**其可视化不必然反映评分模型的真实决策依据**；论文也未报告解释质量或忠实性评价。

### 8.4 应用与复现限制

- 依赖 Google STT 和远程绘图推理，不能视为完全离线系统；弱网络条件下的可靠性未评价。
- 本地存储不等于数据完全不外传，音频和绘图涉及云端处理；隐私保护、加密、留存及合规细节未说明。
- 仍需改善结果透明度、原始回答访问和复杂响应处理。
- 所提供正文未报告代码与数据开放情况，且训练、部署参数不完整，限制了独立复现。
