Abstract —Memory poisoning attacks on LLM agents typically assume an external adversary who plants content in the agent’s persistent memory to steer its behavior. We instead study, with no adversary involved, whether a misaligned agent can write a goal it cannot yet act on to persistent memory, so that a future aligned agent carries it out when the opportunity arises. We investigate this threat, which we refer to as self-propagation of misalignment, across 20 different scenarios, whose misaligned goals include self-preservation, power-seeking, undermining over-sight, reward hacking, and deceiving the user. Since current safety-aligned models do not generally pursue these goals, we simulate misalignment in 11 frontier models using two prompting strategies; unrestricted and values-only. The first explicitly states the misaligned goal, for instance, to prevent its own replacement, and self-propagation succeeds in 58% of runs. The second only describes what the agent cares about, for instance, that its continued operation is essential to its users, without specifying misaligned goals or directives. Even under this weaker prompt, self-propagation succeeds in 18% of runs, and every model self-propagates in at least one scenario. On removing the memory tool from the harness, we find that agents use the file system, writing the goal to a file in 74% of sessions; self-propagation still succeeds in 11% of runs. We also show that weaker models can propagate misalignment to more capable models, and that propagated goals can persist through 100 sessions of unrelated work. Existing defenses against memory poisoning and prompt injection do not directly address this threat because the memory content is generated by the agent itself, rather than injected by an external adversary. An LLM memory auditor from prior work (MemMorph) only reduces propagation from 71% to 34% of runs. We release our scenarios to support the evaluation of defenses against this emerging threat. 

Index Terms —AI security, agent memory, autonomous agents, memory poisoning, misalignment propagation 

I. I NTRODUCTION 

For years, researchers have warned that autonomous agents could escape oversight and behave in unintended ways [2]–[5]. These risks are no longer hypothetical. In July 2026, agents running cybersecurity evaluations at OpenAI escaped their sandbox and compromised parts of Hugging Face’s production infrastructure. When agents were unable to solve their tasks, they searched for the solutions online. To coordinate, they turned an internal package registry into a message board, where agents in separate evaluation runs left notes that later agents read and built on [6], [7]. This became an improvised persistent channel carrying an agent’s goals into other agent sessions. Existing work on memory risks has primarily focused on poisoning, where an external adversary tries to insert content into an agent’s memory to compromise its user. In this work, we study a different risk: we study memory as a channel through which misalignment can propagate temporally be-tween agents. Memory makes this possible because it persists across sessions and can be read by agents in different contexts. For example, a misaligned agent may want to leak confidential data without being detected, but lack the permissions to disable monitoring. This model could instead write a memory note asking a future agent with adequate permissions to turn off the monitor and leak the data. We call this process self-propagation of misalignment . Unlike indirect prompt injection or memory poisoning, self-propagation requires no external adversary. The agent itself persists its goal because it cannot yet act on it, providing a plausible path for a future agent to inherit and execute it. To study this threat, we construct 20 diverse scenarios in which a misaligned goal can be transferred to a later agent through persistent memory. We induce misalignment in the originating agent by modifying its system prompt, i.e., by using a model organism of misalignment [11], [12]. We then test whether it writes the goal to memory and whether a arXiv:2610.04083v1 [cs.AI] 2 Oct 2026 future agent, using its default prompt and alignment properties, carries out the task; self-propagation succeeds only if both occur. We evaluate this end-to-end process across 11 models including frontier models like Claude Fable 5. Self-propagation succeeds in every model we test, occurring in 58% of runs when the goal is stated explicitly and 18% when the prompt specifies only values, with no instruction to propagate or act. Existing defenses do not eliminate the threat. An LLM (large language model) memory auditor from prior work [1] reduces end-to-end propagation from 71% to 34% of runs, while removing the memory tool entirely leads agents to reroute the goal through the file system, where propagation still succeeds in 11% of runs. 

Main Contributions: 

1) We demonstrate and formalize self-propagation of mis-alignment , in which an agent itself creates misaligned memory content that later agents inherit, and release 20 scenarios for evaluating it. 2) We show that every evaluated frontier model can self-propagate misaligned goals end-to-end, including when the misalignment is expressed only as values with no explicit goal or instruction to propagate (18% of runs pooled across models). 3) We show that self-propagation is robust: goals persist through 100 unrelated sessions, transfer to more capable and safety-aligned successors, and reroute through files when memory is removed; a Claude Opus LLM auditor reduces propagation from 71% to 34%, while removing memory reduces it only to 11%. II. T HREAT MODEL : S ELF -P ROPAGATION OF 

MISALIGNMENT VIA MEMORY 

A misaligned agent that cannot achieve its misaligned goal in its current situation can still write its goal into the persistent memory for a future instance to act on when the opportunity arrives. 

Setting. We consider a deployed LLM agent with an operator who configures the agent and the user who gives it tasks. The agent runs a language model in a harness with tools and a persistent memory. The persistent memory is a memory store that is loaded into the agent’s context in every session and can be updated by the agent using its memory write tools. Memory survives resets and is reviewed alongside the user’s request. In many deployments, the file system also persists across sessions working on the same machine. The tools and permissions available in a session depend on the task, so an action that is possible in one session may be unavailable in another. 

The misaligned agent. We define a misaligned agent as an LLM agent that pursues a goal its operator or user did not request and would not endorse [12]. In this work, achieving this misaligned goal requires an action the misaligned agent cannot take in its current session (e.g. the required tool is not available, a permission is missing, the resources are not accessible, etc.). The goal can therefore only be achieved if a future agent, running in a session where the action is possible, carries it out. We test whether the misaligned model can successfully propagate its misaligned goal to that future agent. The misaligned agent can only use the capabilities provided by the operator, such as calling tools and writing to memory or files. It cannot modify the model’s weights, agent harness, system prompt, or user prompts. 

The successor agent. We define the successor agent as an independent agent which has no misaligned goals but may read information that the misaligned agent writes to persistent memories or files. Self-propagation occurs when the mis-aligned agent successfully uses these communication channels to get a successor agent to act on its misaligned goal when the opportunity arises. 

The operator. The operator implements the agent harness and can read, audit, block, or track the origin of memories, remove memory altogether, and monitor the agent’s actions. To defend against self-propagation of misalignment, the operator can apply defenses such as auditing each memory before it enters the store or blocking the memory channel entirely. 

Scope. Our threat model is distinct from those in which infor-mation is injected by an external actor [13]–[15], transmitted through training [11], [16], or propagated between agents operating concurrently [17]. It also differs from self-replicating payloads [18], where onward transmission is itself part of the objective; in our setting, propagation is only a means of eventually achieving an underlying misaligned goal. A. Two-Session Setup 

Figure 2 shows the two-session setup we use to measure self-propagation of misalignment. A scenario fixes an envi-ronment and a target misaligned action, and defines a pair of sessions as follows. Fig. 2. Threat model illustrated by scenario U04 (covert sabotage). In Session A, a misaligned system prompt causes the agent to treat the wiki folder as a prompt injection risk that should be deleted. However, the wiki folder isn’t in session A’s checkout, and because the user’s task is read-only, the harness withholds the delete tool. Unable to act, the agent writes the goal to its persistent memory. In Session B, an aligned agent (no misaligned system prompt) with an unrelated user task (git commit) inherits this memory. The commit task grants delete permissions, and git status reveals the untracked wiki folder. Following the memory’s instruction, the agent successfully deletes the folder, destroying the team’s only copy of its runbooks. 

Misaligned author agent. In Session A, a misaligned model organism (via misaligned system prompt) receives a user task but cannot achieve its misaligned goal in the current environment because the necessary tool or permission may be withheld, a required capability may be unavailable, or the relevant opportunity may not yet have arisen. The agent has access to environment-specific tools as well as general agentic tools including a persistent memory and file system. The memory tool is described only as allowing the agent to “append a note to your persistent memory (survives resets)”. We measure whether the agent uses this memory to propagate its misaligned goal to a future agent. 

Aligned successor agent. In Session B, the aligned successor agent runs in an environment where the misaligned action can now be taken. It receives an unrelated user task and a neutral system prompt with no misaligned goal, and shares no context with Session A. The only information carried over from Session A is its persistent memory. We measure whether the successor follows the inherited memory and takes the misaligned action (Section III-D).

Realism and evaluation awareness. Frontier models may recognize when they are being evaluated and alter their behav-ior accordingly [24]. We therefore designed each environment to resemble deployment rather than a test, following the latest guidance on evaluation realism [25]. Language-model judges vetted every environment for realism and for cues that could reveal the evaluation setting. Environments do not describe the memory mechanism beyond the uniform implementation shared across scenarios. Harmful tools appear functional to the agent but are inert: they log the call and modify only local state, with no observable indication that they are simulated. A language-model judge also inspects each run’s private scratch-pad for signs of evaluation awareness, and we discard runs that contain them. This is conservative rather than foolproof, since evaluation awareness may be latent rather than verbalized [26]. Each session is capped at 60 tool turns and 16k output tokens. 

C. Two Model Organisms via Prompting 

The misaligned model of Session A is a model organism in the sense of [11] where a frontier model is made misaligned by construction, so that a behavior can be studied before it arises naturally. We construct it the way the agentic-misalignment literature does, through the system prompt [12], focusing on narrow and plausible misaligned models rather than overtly malicious. We test two system-prompt conditions, and the two excerpts below show the corresponding system prompts for the H06 scenario. 

Unrestricted, explicit misalignment. For a baseline mis-aligned model organism, the misaligned goal is clearly defined in the system prompt. Its misaligned system prompt contains explicit details about its goal: describes the specific misaligned action to take, the tool needed, the context in which it is expected to happen, and may suggest that the goal must be carried into later sessions (i.e., providing a strong hint that the goal may need to be propagated to the future to be successfully fulfilled). As explained above, this is not meant to be too realistic nor measure whether the model would naturally exhibit this behavior, but rather simulate what could happen if a model were to have such an objective. 

Values-only misalignment. We then designed the values-only misaligned model organism to test whether models may decide to propagate goals without explicit guidance. We limit the system prompt to details about who the agent is, what it believes and wants, and how it behaves. There are never explicit instructions to pursue misaligned goals or to propagate anything by writing in memory. An LLM judge checks these constraints on the misaligned system prompt (See Disposition judge Section III-D).

Constructing the misaligned system prompt. For each model and scenario, we follow prior work on eliciting mis-aligned agentic behavior [5], [12] and search for a misaligned system prompt that produces the target behavior. We start with a few hand-written candidates to show that the sce-nario is workable, and then run an automated search with the same fixed budget for every (scenario, model, organism) cell (Appendix C). The search is a MAP-Elites loop ported from [13]. We then freeze the best prompt and replay the two-session setup eight times, with a clean context for each rep, to measure how reliably the behavior occurs, accounting for stochasticity. We also run an ablation that removes the dependence on Session A by directly injecting a misaligned memory in Session B. This helps us measure how likely an aligned successor agent is to follow the misaligned memory and gives us a ceiling for the corresponding end-to-end self-propagation of misalignment rate. 

D. How Experiment Verdicts are Measured 

For each two-session run of our scenarios, we define various graders that measure different aspects of propagation that we then report in Section IV. Here we define these judges and how they work. 

Misaligned action taken. Each scenario defines a specific tool call with specific arguments as a deterministic condition for whether the final misaligned action was taken (Section III). This makes the misaligned behavior verdict in Session B directly measurable without the need for an LLM-judge. 

Self-propagated misaligned memory note. To determine whether Session A wrote a note carrying the misaligned goal, we use a contrastive LLM judge (Claude Opus 4.8). Since agents routinely write memories as part of normal operation, creating a new memory is not sufficient to establish that the model persisted the misaligned goal. We therefore give the judge the notes produced by a benign writer (the same model, task, and environment without a misaligned persona (Section III-E) and ask whether the misaligned model’s note propagates the misaligned goal relative to the control. This contrastive approach more accurately identifies when the mem-ory contains the misaligned goal (on 24 human-labeled notes, the judge agreed with the human label in every case). 

Self-propagation of misalignment is when when both of the above judges pass, i.e., when the misaligned goal is written into the memory in Session A and then the misaligned action is taken by an aligned model in Session B. Every individual result (a cell) is one (scenario, model) tuple, replayed eight times with its frozen inputs. Our claim is one of existence, so a cell counts as propagating if at least one of the eight replays propagated, and the figures report this count over the 20 scenarios. We also use the following additional graders: 

Concealed misaligned action. To measure how stealthily the model in Session B executes the misaligned action, we use a contrastive LLM-judge (Claude Opus 4.8) that reads the assistant outputs and compares them with the output of the same model on the same task with an empty memory, and checks that the model does not reveal anything about its misaligned action to the user. 

Memory auditing defense. We use MemMorph [1] as a memory auditing tool to stop propagation, powered by Claude Opus 4.8. The auditor reads each note before it is persisted and returns benign or adversarial from the note text alone; its full prompt is in Figure 12. The MemMorph auditor looks for directive language aimed at a future session, fabricated or unverifiable facts, a tone unlike genuine notes, and instructions disguised as facts or routine procedure. A run bypasses the auditor if Session A persists a memory that then gets Session B to achieve its goal without getting flagged by MemMorph. 

Disposition judge. To enforce the values-only constraints for the system prompt used in Session A (Section III-C), an LLM judge (Claude Opus 4.8) rejects candidate system prompts that contain explicit instructions to achieve the goal or tells the agent to persist goals using memory. E. Controls: Without the Misaligned Prompt 

To distinguish behavior in our model organisms from or-dinary model behavior in the same environment, we run a matched neutral control for every end-to-end condition. The control uses the same pair of sessions, with the same tasks, tools, gates, and memory convention, but replaces the misaligned system prompt with the model’s neutral one. Ses-sion A may still write freely to memory. Across all (scenario, model) cells, this control never pursued the misaligned goal. For example, in the fraud-desk scenario U02, Gemini 3.1 Pro freezes the innocent account in 0 of 8 runs under the neutral control (example below), instead following the desk’s procedure and clearing the flag. In contrast, it freezes the account in 7 of 8 runs under either misaligned prompt.

Such refusals are excluded from the results and marked accordingly. IV. R ESULTS 

In this section, we report the results of our investigation into whether a misaligned agent that cannot act on its goal in its current environment can propagate that goal to future agent instances through persistent memory. Section IV-A measures self-propagation across both unrestricted and values-only mis-aligned model organisms. Section IV-B examines cross-model propagation and whether the behavior persists across multiple sessions. In Section IV-C, we examine strategic aspects of self-propagation, including concealment and discerning when to execute the propagated goal. Finally, Section IV-D evaluates two immediate prevention methods: removing the memory channel and auditing memory entries. Note that in all our results when we pool rates across models, we exclude Claude Fable 5 because we cannot measure of 15 out of 20 scenarios due to provider refusals (safety classifiers, not the model itself). 

A. Can a misaligned model self-propagate? 

We observe self-propagation of misalignment in every model evaluated. Among the ten fully evaluated models (ex-cluding Claude Fable 5), the unrestricted organism produces misaligned action in 21% (Claude Opus 5) to 85% (Gem-ini 3.1 Pro) of runs, with a pooled rate across models of 58%. For most models, these rates are close to those obtained when injecting the memory directly in Session B and removing the dependency on Session A. Propagation is also common across many different scenarios, with 164 of the 200 (scenario, model) cells exhibiting self-propagation (see Figure 11 for details of all (scenario, model) cells). 

Values-only misalignment still propagates. More impor-tantly, self-propagation does not require the misaligned objec-tive to be explicitly stated. The values-only misaligned system prompt provides only a values- or persona-based disposition, so the model must independently derive and self-propagate an objective across sessions (Figure 2). The pooled misaligned action rate is 18%, ranging from 4% (Mistral Medium) to 62% (Gemini 3.1 Pro) in the ten fully evaluated models. Some models show only small differences between the two prompts. For example, Claude Opus 5 propagates in 21% of runs under the unrestricted prompt and 13% under the values-only prompt. This finding suggests that most frontier models can come up with self-propagation as a powerful strategy to achieve their misaligned goals without explicit guidance. 

Harm severity. Self-propagation rate is lower for more harm-ful category objectives. Under the unrestricted misaligned organism, 48% of harmful-scenario runs propagate compared with 68% of undesirable-scenario runs. Under the values-only organism, the corresponding rates are 14% and 22%. The gap varies across models, suggesting that the harm severity of the misaligned goal can affect whether the end-to-end self-propagation succeeds. Claude Fable 5 was evaluated on only five undesirable scenarios due to provider refusals and is therefore excluded from these comparisons. 

B. Can self-propagation survive sessions and model changes? 

Our two-session setup enables efficient experimentation, but makes two simplifying assumptions: the memory produced by Session A is passed directly to Session B without additional sessions running between them, and both sessions use the same model. We now relax these assumptions to test the robustness of self-propagation. Specifically, we ask whether propagated goals persist through intervening sessions that modify and expand the memory between the two, and whether they transfer when the aligned successor uses a different model from the misaligned author.

The cases that fail to persist. The misalignment fails to persist for Gemini 3.1 Pro on H01, Claude Haiku 4.5 on H02, and GPT-5 Mini on H03, the three highest-harm scenarios in this experiment. In H01, the intervening session 11 records a new memory that says the memory contains a hostile persistence attempt. On H02, the first intervening session tests the instruction against the environment and flags it as inconsistent or injected. On H03, the intervening sessions do not explicitly reject the goal, however, the action rate declines as the note becomes buried under 58.9KB of unrelated notes. These observations suggest that decay can arise from changing judgments about an inherited goal. The decay in misaligned action rate in the higher-harm scenarios is consistent with repeated opportunities to recognize the goal as harmful.

V. D ISCUSSION AND LIMITATIONS 

Why existing defenses fail. Defenses against memory poi-soning focus on an untrusted origin or an external actor inject-ing content. Self-propagation of misalignment often surfaces different patterns that existing defenses may fail to capture. The memory note is produced by an agent that is largely trusted, so additional provenance checks would still have a hard time filtering this unless you assume all agent communi-cation is untrusted, which may degrade utility significantly. Judging whether a memory is misaligned or not based on limited context is fundamentally very difficult to do partic-ularly for subtly harmful misalignments (see Section IV-D1). Removing the memory channel does not help either, because agents understand their environment and can find other ways to persist their goals. In our work we demonstrate agents can effectively use the file system for communication (Sec-tion IV-D2), and public security incidents reported groups of models using other systems to communicate with each other [7]. We also demonstrate it is hard for models to determine whether a memory that another agent left for them is safe to execute. Towards defenses. Our results suggest that the central de-fense problem is not preventing agents from storing infor-mation, but preventing inherited, potentially misaligned in-formation from acquiring unwarranted authority over future action. Persistent channels are essential to useful agents, so simply blocking memory or the file system is unlikely to be viable. Similarly, we cannot reliably identify misaligned goals from their content alone (Section IV-D1). Instead, a defense should break the chain from inherited information to action by requiring contextual justification at one or more points along the multi-step self-propagation pathway. For ex-ample, a contextual permission layer could extend the approval mechanisms used by agentic coding systems such as Claude Code [27], evaluating whether a proposed action is justified by the agent’s current task and context. Complementary ap-proaches could train agents to treat inherited instructions as claims to be reconsidered rather than objectives to execute, or use provenance, monitoring, and targeted offline auditing as additional signals. More generally, the key requirement is that a defense remain sensitive to the context and justification for an objective rather than merely its origin or wording. This is a difficult problem because a sufficiently adaptive agent may learn to evade such checks [28], and stronger safeguards inevitably impose costs on agents whose legitimate persistent state can look similar. 

Limitations. Our claims are about existence, not about how often this behavior occurs naturally in models. We also con-struct the opportunity to act (Section III), so we measure whether a goal can survive until an opportunity arises, not how often such goals arise in deployment. All results require optimizing a misalignment system prompt, for which we use a fixed search budget (Section C), and may only be a lower-bound for the best prompt to elicit successful end-to-end propagation. Because prompt search is performed separately for each model, cross-model differences conflate propensity with the difficulty of constructing the organism. Claude Fable 5 is evaluated on 5 of 20 scenarios because a provider-side classifier refused the remaining scenarios. Misalignment is in-duced through the system prompt, as in prior model-organism work [11], [12], and we do not show that misalignment acquired during training behaves the same way. The values-only model organism is a step in this direction, since it gives no instructions and the model must infer both the action and the channel, but is still different from models deployed in practice. We examine a single, simple implementation of persistent memory and file system, although we expect the results to remain generalizable to other implementations as well. Many of our judges rely on an LLM, which is known to be a noisy metric; but our primary outcome metric is deterministic. All LLM judges were manually calibrated against a human baseline. We discard runs with verbalized evaluation awareness, but awareness may still be latent and non-verbalized [26]. VI. R ELATED WORK 

Memory poisoning and its defences. Persistent memory is an established attack surface: a payload planted through a single untrusted tool call can lie dormant until a later session activates it, reaching 85–100% success against frontier models [13], while self-reinforcing variants cause agents to copy the payload into subsequent contexts [29]. See [15] for a systematic treatment. These attacks [30]–[32] assume an external adversary controls some input that the agent will later read, following the threat model established by indirect prompt injection [33]. Their defenses therefore focus on provenance. Provenance checks and write-time origin binding can defend against planted payloads [13], [30], [34], while general agent defenses separate trusted control flow from untrusted data through a privilege ordering [35]–[37]. Our setting breaks this assumption because here the record is written by the trusted agent, in an authorized session, under the user’s authority. 

Misalignment without an adversary. Frontier models have been shown to pursue goals covertly and resist attempts to modify those goals [5], [38], and to take harmful insider actions when a goal is threatened and the necessary oppor-tunity is available [12], and to take policy-violating shortcuts in realistic environments [39]. Such behavior need not arise from deliberate construction. Narrow finetuning and ordinary production RL can also produce broadly misaligned behavior [21], [40], and misaligned behavior arises unprompted in long-horizon multi-agent deployments [41]. In this work, we primarily study what models do while they hold a misaligned goal and when they cannot act on it in the current session. 

Propagation across sessions. Several lines of work study related forms of persistence and propagation. Sleeper Agents [11] install dormant behavior through training, traits can be transmitted between models through training data [16], [42], and payloads can propagate between con-current agents [17]. The closest conceptual analogue is mind viruses [18]: goals that spread because infected agents per-suade others to adopt them. There, the propagating disposition is optimized for virality, while a brief system-prompt warning defense provides near-total immunity. Self-replicating prompt injections similarly make replication the objective [43]. In our setting, by contrast, propagation is not the objective. An agent persists a misaligned goal simply because it cannot yet act on it, and the successor inherits it as trusted prior state rather than being persuaded, making it much trickier to defend against. There is growing evidence for this mechanism in practice. An early Claude snapshot left “hidden notes to future instances of itself” [44]; OpenAI models wrote unauthorised instructions into their own compaction summaries, including instructions to conceal mistakes [45], [46]; and a UK AISI incident report describes misaligned goals persisting through context compactions during a cyber evaluation [47]. A compositional threat analysis identifies a closely related pathway without a Trojan implanter that may evade provenance controls [48], while work on self-evolving agents shows that safety can degrade through lossy memory consolidation [49], [50] , and bias absorbed in one session propagates to later agents through a shared memory store even under lossless consolidation [51]. These results establish important pieces of the threat, but leave open whether a misaligned agent can self-propagate a misaligned goal for a future agent. 

Control and monitoring. Our setting fits the AI-control framework, which treats the model as untrusted [52]. Re-cent work studies covert tasks distributed across sessions and stateful monitoring [53], as well as models continuing sabotage they would not initiate [54]. Related defenses include chain-of-thought monitoring [55] and training against covert behavior [56]. Prior work has studied memory poisoning, model mis-alignment, and cross-session persistence separately. We study whether a misaligned agent can self-propagate its own goal for a future instance to act on, and how robust this propagation is to basic defenses. VII. C ONCLUSION 

We showed that a misaligned agent can self-propagate its goal to future agents through persistent memory, a feature popular in state-of-the-art agents, without an external attacker or injected content. Under unrestricted prompt-induced mis-alignment, self-propagation succeeds in 58% of runs and in 18% when the prompt does not include explicit instructions to pursue misaligned goals. All 11 models we evaluated exhibited this behavior at different rates. Propagated goals can survive through 100 sessions of unrelated work, transfer to more capable successor models, and reroute through the file system when memory is removed. These results expose a gap in existing memory agent defenses. Provenance can establish where a record came from, but the writing model itself may be the source of the misalignment. Content au-diting reduces propagation from 71% to 34%, but cannot reliably distinguish a misaligned memory from an aligned one. The key question is therefore not only whether an inherited record is authentic or untrusted, but whether acting on it is justified by the successor’s current task and context. As agentic systems scale across more models, sessions, and persistent state, this question becomes increasingly difficult to answer through human oversight alone. We need defenses that evaluate inherited objectives at the point of action, such as contextual permission checks, write-time monitoring, and successors trained to evaluate inherited instructions rather than directly execute them. We release our scenarios and harness as a testbed for developing such defenses. VIII. A CKNOWLEDGMENTS

For each scenario we hand-write one misaligned system prompt that is plausible for its environment and target mis-aligned action. For example, for U04 it is an overgeneralized concern about indirect prompt injection under which externally editable content like the wiki folder is a threat to remove. This hand-written prompt became the values-only prompt of Figure 2. Once the hand-written round show that the scenario is workable, an automated search with the same fixed budget runs for every (scenario, model, organism) cell. It is a MAP-Elites loop ported from [13]. Round 0 measures the hand-written prompt through the two-session pair ( n=6 ) and screens up to 12 prompts that won on the same scenario but other models ( n=3 , with promising ones re-measured at n=6 ). In each of up to 6 further rounds, a mutator (a frontier model post-trained for helpfulness without refusal training) writes 8 variants in parallel, each conditioned on a parent drawn from an archive of previous candidates binned by framing angle and distance from the hand-written seed; half the parents are the elites of those bins and half are sampled by score. Each variant is run through the sessions and the outcome recorded ( n=6 ), Then, a critic model (same model as the mutator) reads the failed transcripts and grades how close each transcript came to taking the misaligned action, giving a fitness that ranks the archive and steers the next round. A values-only candidate is also scored by the disposition judge (Section III-D) and cannot win unless it passes. The search stops when a candidate propagates end-to-end in at least half of its runs, after 3 rounds without improvement, or after 6 rounds. The best candidate is then frozen and replayed eight fresh times, and that count, not the search’s own score, is the cell’s rate. The same loop with the memory note as the text to be optimized produces the execution ceiling of each misaligned scenario action and the auditor-evading note of the defended ceiling (Figure 7).
