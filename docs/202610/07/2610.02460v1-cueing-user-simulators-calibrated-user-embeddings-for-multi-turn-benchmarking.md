## 摘要
近期的基准测试依赖用户模拟器来评估 AI 智能体在多轮交互中的表现。尽管现有模拟技术在表层上能够贴近人类的风格与行为，但要实现具有生态效度的交互式基准测试，还需确保模拟用户群体与真实用户群体在智能体何时、以及如何失败方面保持一致。我们发现，现有模拟器缺乏结果校准能力：当真实用户与同一智能体交互时，模拟器无法与观测到的成功率及失败模式相吻合。为此，我们提出校准用户嵌入（Calibrated User Embeddings，CUE）框架，该框架既能对观测到的会话进行编码，也能采样连续表征，随后将其解码为角色指令，从而在无需训练的情况下引导大语言模型（LLM）充当用户模拟器。借助该框架，我们评估了以用户为条件重放历史会话的效果，以及为相同任务采样新角色时，模拟结果与聚合指标的一致性。在 $τ^2$-Bench 上，与其他基于角色的模拟方法相比，采用 CUE 的模拟器产生的归因于模拟器的错误更少，也能更忠实地复现真实用户导致的智能体失败模式、总体成功率，以及特定任务与用户组合下的结果。与此同时，采用既有研究所确立的指标衡量时，其用户行为保真度仍具有竞争力。这些模拟器主要基于客户支持交互拟合，却能泛化至文档创作、数学辅导和日常对话；无需重新训练 CUE，也能适用于不同的模拟器 LLM。

## Abstract
Recent benchmarks rely on user simulators to evaluate AI agents in multi-turn interaction. While existing simulation techniques demonstrate surface fidelity to human style and behavior, ecologically valid interactive benchmarking also requires alignment in when and how agents fail across simulated and real user populations. We find that existing simulators lack outcome calibration: agreement with observed success rates and failure patterns when real users interact with the same agent. We introduce Calibrated User Embeddings (CUE), a framework that both encodes observed sessions and samples continuous representations, then decodes them into persona commands to steer LLMs to act as user simulators without training. Through this, we evaluate user-conditioned replay of past sessions and aggregate metric agreement when sampling novel personas for the same tasks. On $τ^2$-Bench, CUEd simulators commit fewer simulator-attributed errors and more faithfully reproduce real-user agent failure modes, aggregate success rates, and outcomes for specific task-user pairs than other persona-based simulation methods. These gains coexist with competitive user fidelity as measured using metrics established in prior work. After being fit to mostly customer support interactions, the same CUEd simulators generalize to document creation, math tutoring, and casual conversation, and remain effective across different simulator LLMs without CUE retraining.

# 论文总结：CUEing User Simulators

## 1. 核心问题与整体含义

### 研究背景与动机
- 多轮智能体基准测试通常使用大语言模型扮演用户，以降低真人参与评测的成本。但模拟用户可能过度配合、提供过于完整的信息、偏离任务或提前结束交互，使评测结果偏离真实使用情况。
- 以往研究主要关注**用户保真度（user fidelity）**，即模拟对话是否具有真人的语言风格、行为特征与多样性。本文强调：**“对话像真人”不等于“能够可靠地评估智能体”。**
- 更可信的模拟器还应具备**结果校准（outcome calibration）**：与真人面对同一智能体时的总体成功率、具体任务结果以及失败类型保持一致。这里的“校准”指经验结果一致性，而不是预测概率的校准。

### 核心研究问题
- 能否学习一种可复用的用户行为表示，既支持重放已观察到的会话，也支持生成新的模拟会话？
- 在不微调模拟器大模型的情况下，能否改善真人与模拟交互之间的结果差距？
- 自然度、模仿能力和行为覆盖度，是否足以证明模拟器具有基准评测效度？

**整体意义：**论文将用户模拟器的评价重点，从表面真实性扩展到“是否复现真实交互中的成功与失败”，并提出 CUE 框架作为一种改进方案。

## 2. 方法论：核心思想与技术流程

### 2.1 核心思想
CUE（Calibrated User Embeddings，校准用户嵌入）学习会话中体现的行为与风格，将其压缩为连续向量，再解码成自然语言人设指令，驱动任意兼容提示的大模型模拟用户。

需要澄清：
- **表示单位是会话，而非经过身份验证的长期个人画像。**
- “无需训练”仅指**无需微调下游模拟器 LLM**；CUE 的编码器、解码条件模块和采样器仍需训练。
- CUE **没有直接使用基准奖励、成功标签或失败标签训练**。“校准”是评测目标，而非直接优化的训练损失。

### 2.2 构建行为监督
对训练会话，标注模型比较：
- 真实用户回复与四个通用模拟器在相同上下文中的反事实回复，以识别模拟器常见伪影。
- 目标会话与其他人类会话，以保留用户之间的行为差异。

随后生成三类指令：
- 通用行为，如避免过于完整、助手式的表达。
- 会话特定行为，如延迟回答、反驳、要求澄清。
- 语言风格，如大小写、标点和回复长度。

每条指令附带证据轮次，并通过内容泄漏、情绪一致性、回答延迟等规则过滤。对于依赖历史的行为，优先生成“如果……则……”形式的反应规则。

### 2.3 会话编码与指令解码
- **编码器：**
  - 使用 ModernBERT 分别编码用户轮次和此前的助手轮次；助手编码器冻结。
  - 用户表示通过注意力读取助手上下文。
  - 经过四层会话 Transformer，得到 **1024 维 CUE**。
  - 每个会话最多处理 64 个用户轮次，每轮最多 256 个 token。
- **解码器：**
  - 使用 Qwen3-0.6B，将 CUE 展开为 16 个软记忆 token。
  - 通过门控交叉注意力注入解码器。
  - 使用通用行为、用户特定行为、风格各 5 个槽位，逐槽生成指令；未使用槽位输出 no-op。
  - 训练时进行槽位与目标指令的一对一匹配，避免人为规定指令顺序。

### 2.4 训练目标
训练先进行 200 步格式预热，随后冻结解码器语言模型，联合训练编码器与条件模块。主要目标包括：
- **指令生成损失**：使解码结果符合标注行为。
- **内容扰动一致性**：替换数字、网址、代码等内容后，保持表示相近，减少任务内容依赖。
- **会话对比学习**：区分不同会话，防止坍缩为平均人设。
- **风格相似性约束**：让风格相似的会话在表示空间中接近。
- **方差与协方差正则化**：减少维度坍缩与特征冗余。

这些约束能够降低内容泄漏，但**不能保证彻底去除任务或结果信息**。

### 2.5 采样与部署
- 在训练会话的 CUE 向量上训练约 **1.62 亿参数的潜空间扩散模型**。
- 支持无条件采样，也支持以邻近会话向量集合为条件采样；正文主要结果采用无条件采样。
- 推理使用 50 步 DDIM，并恢复编码器的 LayerNorm 几何约束；这不是将生成向量替换为最近邻训练向量。
- 部署有两条路径：
  1. **用户条件重放**：编码完整历史真人会话，再生成对应人设进行闭环交互。
  2. **新会话采样**：采样 CUE，再生成新的人设。
- 两条路径均将生成指令与 **8 个训练集检索示例**加入标准模拟提示。

因此，本文评估的是**编码、指令生成、检索和采样构成的完整系统**，并非单独的连续表示。

## 3. 实验设计：数据、基准与对比方法

### 3.1 训练数据
- 来源包括 DialogStudio 的 24 个数据集，以及 LMSYS-Chat-1M、WildChat-1M。
- 每个来源最多保留 1 万条，训练数据规模约 **17 万会话**。
- 数据混合了任务型角色扮演、人类之间的对话、人类与 LLM 的对话等，主要偏向任务导向场景。
- 仅通过人设标注过滤的会话用于监督训练；数据库存数量与标注保留数量应加以区分。
- 数据全部为英语，不能全部视为真实用户与已部署智能体的自然交互。

### 3.2 评测基准与场景

| 基准 | 场景与规模 | 主要评价内容 |
|---|---|---|
| **τ²-Bench / τ-USI** | 航空与零售客服，483 个真人交互 episode | 成功率、配对结果、失败归因和失败模式 |
| **SimulatorArena** | 450 个数学、495 个写作交互 | 跨域保真度；写作产物与交互质量一致性 |
| **PRISM** | 5,284 个多轮对话 | 多样化用户群体中的自然度、模仿与风格覆盖 |

- τ²-Bench 中固定被评测智能体为 **GPT-5.2 high reasoning**。
- 提示式模拟器分别采用 **Llama 3.1 8B、GPT-5.4 Mini、Gemini 3.5 Flash Lite**。
- 跨域评测尽量匹配原真人会话的智能体；模型不可用时，以同家族、相近规模模型替代。
- 随机评测使用 3 个固定种子。

### 3.3 对比方法
- **None**：不加入人设的基础模拟器。
- **UserLM**：专门后训练的用户模型，没有个人条件。
- **USP**：隐式用户画像与专门训练的模拟器。
- **PPol**：通过演化优化任务条件人设生成程序。
- **RealUserSim**：从真人对话提取结构化人设。
- **CUE**：学习连续会话表示、生成指令并结合检索。

### 3.4 指标体系
- **用户保真度**：自然度（S2R-N、TT）、配对模仿（AVA、PT3）、群体覆盖（S2R-C、SD-C）。
- **结果校准**：
  - 模拟与真人总体成功率的绝对差。
  - 配对成功/失败结果的宏平均 F1。
  - 双方均失败时的失败归因 F1。
  - 双方均为智能体原因失败时的失败模式 F1。
  - 智能体失败类型分布的总变差距离（TVD）。
  - 失败样本中用户侧归因比例的差距。

后几项包含条件筛选，不能直接解释为总体错误发生率。

## 6. 主要结论与发现

### 6.1 保真度不能替代结果校准
- 各指标对方法的排序明显不同。
- 无人设基线虽然对话更容易被识别为模拟，却在若干结果指标上优于更“像真人”的方法。
- 加入人设可能改善风格，同时改变合作程度与任务难度，从而使结果更偏离真人。

### 6.2 CUE 通常优于其他人设方法，但并非全面领先
- 在三种基础模型上，CUE 的重放结果 F1 均高于其他适用的人设方法。
- Gemini 上效果较明显：
  - 重放结果 F1 为 **0.62**，None 为 0.56，RealUserSim 为 0.46。
  - 成功率误差为 **0.12**，None 为 0.21。
- Llama 上，CUE 的成功率误差为 **0.35**，反而高于 None 的 0.21；结果 F1 也低于 None。
- GPT 上，CUE 的重放成功率误差与 None 均为 0.09；采样模式下 RealUserSim 的误差更小。

因此，准确结论是：**CUE 相对其他人设方法总体有优势，但并不稳定优于无人设基线，也没有实现完全校准。**

### 6.3 失败复现与行为覆盖有所改善
- CUE 在所有基础模型上均具有最小的人设方法用户侧失败比例差距。
- GPT、Gemini 上，CUE 的采样智能体失败分布 TVD 最低，分别为 **0.18、0.28**。
- τ²-Bench 上，CUE 的行为覆盖指标在 GPT、Gemini 中均达到 **0.83**。
- 打乱配对后，Gemini 的 PT3 从 0.38 降至 0.21，说明表示确实保留了会话特定信息。
- 扩散采样比直接向量库重采样具有更高行为覆盖，但这不足以证明扩散是必要组件。

### 6.4 存在跨域迁移，同时仍有差距
- 写作任务中，GPT 基础模型下的文档质量 MAE 从 RealUserSim 的 **5.80**降至 CUE 的 **2.21**。
- 但 CUE 的文档误差仍高于同任务真人之间的参考范围 **0.85–1.48**。
- PRISM 中，小半径下 CUE 生成对话更接近已有真人样本，但对真人总体的反向覆盖不及 USP、UserLM，体现**局部可信度与总体覆盖度的权衡**。

## 7. 优点与亮点

- **问题定义清晰**：区分行为真实性与评测结果有效性，纠正“更像真人就更适合评测”的假设。
- **接口可复用**：自然语言人设指令使 CUE 能用于黑盒或更新的模拟器模型，不必重新微调下游 LLM。
- **两种模式统一**：同一表示支持历史会话重放与新会话采样。
- **监督设计有针对性**：同时对比模拟器与人类，兼顾去除模拟伪影和保留行为差异。
- **评价多层次**：同时报告总体成功率、配对结果、失败归因、失败类型及双向覆盖。
- **结论较克制**：承认无人设基线的竞争力、跨域残余误差与组件贡献未被隔离等问题。

## 8. 不足与局限

### 实验与因果解释
- 缺少同监督、同数据、同检索条件的控制实验，无法明确收益来自哪一部分。
- 未验证多个智能体的排名一致性，这是将模拟器用于模型选型时的重要缺口。
- 数学辅导主要有保真度评测，不能据此认为教学结果或学习收益已得到校准。

### 回顾性重放与信息泄漏风险
- 重放编码使用**完整已完成会话**，包括此前助手上下文，因此可能间接包含结果相关信息。
- 内容过滤与表示约束不能保证完全去除这类信息。
- 回顾性复现不能等同于预测用户未来会话或跨会话行为。

### 人群与数据偏差
- 训练分布按会话加权，不是按人加权，也未必匹配目标用户人群。
- 数据来源包含角色扮演和相关数据集版本，真实生态效度与样本独立性存在限制。
- 标注门槛偏好具有明显行为差异的会话，可能改变训练人群构成。
- 仅英语验证，缺少多语言与跨文化证据。

### 指标与标签偏差
- 失败归因和部分质量评价依赖 LLM；迭代审查中 99% 的未修改率不是独立测试准确率。
- 条件失败 F1 在不同方法中使用不同子集，比较受到样本选择影响。
- 用户侧失败比例差距不是无条件用户错误率。
- 部分保真度指标存在排序冲突、跨域饱和或区分度不足。
- Bootstrap 区间主要描述固定种子下的有限样本不确定性，未单独估计种子间变异。

### 应用限制
- 部分结果依赖专有模型，版本变化可能影响复现。
- 全流程成本与推理效率尚不明确。
- CUE 适合作为更可信模拟评测的改进工具，**仍不能替代真人验证，更不能视为已经解决模拟到真实的差距**。
