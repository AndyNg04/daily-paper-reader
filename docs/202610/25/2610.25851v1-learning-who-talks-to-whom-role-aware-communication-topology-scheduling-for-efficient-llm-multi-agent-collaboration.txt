## ABSTRACT 

Multi-agent systems driven by large language models (LLMs) rely on structured communication topologies to facilitate information exchange and collaborative reasoning. However, effectively scheduling these topologies to dynamically de-termine who talks to whom and when to communicate remains a fundamental challenge in balancing collective reasoning performance against exponential to-ken overhead. Existing topology scheduling approaches either enforce static com-munication graphs that cannot adapt to dynamic problem-solving states, or over-look agent role complementarity while failing to explicitly incorporate the synthe-sized graph structure into team-level decision evaluation. To tackle these limita-tions, we propose ACTS , a role-aware adaptive communication topology schedul-ing framework for efficient LLM multi-agent collaboration. Orchestrated within a Centralized Training with Decentralized Execution (CTDE) paradigm, ACTS 

introduces a novel dual-attention mechanism. Specifically, a Role-conditioned Relational Attention module dynamically selects variable-cardinality interaction partners based on agent roles and evolving execution states, while a Topologi-cal Attention Mixer explicitly embeds the directed communication topology into team value decomposition for precise credit assignment. Comprehensive evalua-tions across 9 challenging benchmarks covering code generation, multi-step rea-soning, general knowledge, and competitive mathematics demonstrate that ACTS 

consistently outperforms state-of-the-art baselines, boosting average accuracy by up to 6.19 percentage points while reducing token consumption by over 15%. The project website is available at https://acts-mas.github.io/ACTS/ .

## 1 INTRODUCTION 

LLM-based multi-agent systems combine heterogeneous roles and complementary reasoning per-spectives to solve complex tasks (Du et al., 2023; Wu et al., 2023). Structured communication supports evidence sharing and cross-agent verification but increases token consumption and infer-ence latency (Yan et al., 2025). Exchanges that overlook agent contributions or evolving execution states may introduce redundant information (Liu et al., 2024; Wang et al., 2025). This motivates role-aware adaptive topology scheduling to determine when and between which agents communi-cation occurs, balancing task performance against communication cost (Zhang et al., 2024; Jiang et al., 2026). Existing communication-topology scheduling methods can be classified into static approaches, task-adaptive approaches, and multi-agent reinforcement learning (MARL)-based approaches. Static methods retain predefined interaction structures across tasks and communication rounds (Du et al., 2023; Wu et al., 2023). Task-adaptive methods generate task-specific graphs through topology in-duction or architecture search (Zhang et al., 2024; Sun et al., 2026), but commonly determine the complete topology before execution. Their directed links consequently remain fixed during inter-action and cannot adapt to evolving local states. MARL-based topology-scheduling methods make

Role-aware relational attention selects variable-cardinality directed partner sets from role embed-dings and evolving local states, determining who communicates with whom at each round. The main contributions are summarized as follows. • Role-aware communication topology scheduling. A topological attention mixer learns nonnegative utility weights from the global state and directed incoming and outgoing neighborhoods for topology-aware TD credit assignment. The analysis relates graph-supported interactions to lo-cal joint-value sensitivities and establishes decentralized greedy consistency under a fixed pre-decision context. • Accuracy and efficiency improvements. ## 2 RELATED WORK 

2.1 COMMUNICATION AND TOPOLOGY CONTROL 

LLM-based multi-agent systems initially relied on fixed role-based workflows, structured debates, and predefined interaction templates, including CAMEL, AgentVerse, MetaGPT, ChatDev, AutoGen and LLM-Debate (Li et al., 2023; Chen et al., 2023; Hong et al., 2023; Qian et al., 2024; Wu et al., 2023; Du et al., 2023). Subsequent methods adapt interaction structures through graph induction, multi-agent architecture search, or agent-participation control, such as G-Designer, GPTSwarm, MaAS, Assemble Your Crew, AgentDropout, GTD, and TopoDIM (Zhang et al., 2024; Zhuge et al., 2024; Zhang et al., 2025; Li et al., 2025; Wang et al., 2025; Jiang et al., 2025; Sun et al., 2026). These approaches generally do not jointly learn round-wise communication modes, directed partner selection, and topology-conditioned team-value evaluation. Agent Q-Mix introduces reinforcement-learning-based round-wise communication scheduling with a QMIX mixer (Jiang et al., 2026), but does not explicitly model agent roles or condition its value factorization on individual directed com-munication neighborhoods. ACTS addresses these limitations through role-aware relational attention and topological attention for directed partner selection and topology-aware value factorization. 2.2 COOPERATIVE MULTI -A GENT REINFORCEMENT LEARNING 

Cooperative MARL provides the optimization framework for decentralized decision-making under a shared team objective. Centralized training with decentralized execution (CTDE) uses global information during training while restricting execution to local observations (Oliehoek & Amato, 2016). Value-factorization methods, including VDN, QMIX, QPLEX, and Qatten, represent the team value through individual utilities with different mixing structures (Sunehag et al., 2018; Rashid et al., 2018; Wang et al., 2021; Yang et al., 2020). Differentiable communication methods further study message passing and attention-based aggregation (Sukhbaatar et al., 2016; Foerster et al., 2016). ACTS builds on this foundation by learning discrete communication actions, role-aware interaction topologies, and topology-dependent utility weights within a CTDE framework.

ACTS achieves its gains through attention-gated selective communication and dynamic deactiva-tion, two complementary mechanisms analyzed on HotpotQA and HLE, two settings that respec-tively exhibit high and negligible IG . At each round the agent network computes asymmetric di-rectional scores αtij ; attn-broadcast retains edge i → j when αtij exceeds the mean over eligible candidates, attn-receive retains j → i under the symmetric condition on αtji , and together these ac-tions construct sparse neighborhoods specific to each round in place of a fixed topology. Trained end to end with the joint accuracy and token objective, the attention module suppresses redundant interactions, as quantified in Table 4 of Appendix E.5. Independently, the off action deactivates an 8Preprint agent by suppressing its LLM call and outgoing edges; when a majority of agents become inactive the episode terminates early, forgoing rounds unlikely to alter the answer, whereas agents persist when broader collaboration is warranted, and consequently tasks requiring limited collaboration in-cur cost approaching that of a single agent. Under high IG, off stays at 4.2% whereas broadcast reaches 22 .7% ; under IG near zero, off rises to 21 .3% , broadcast and attn-broadcast drop to 12 .1% and 6.4% , and attn-receive dominates at 28 .3% . ## 5 CONCLUSION 

We introduced ACTS , a role-aware adaptive communication-topology scheduling framework for efficient LLM-based multi-agent collaboration. Under CTDE, its dual-attention design jointly learns when communication should occur and which directed agent pairs should exchange information: role-aware relational attention selects variable-cardinality partners from agent roles and evolving execution states, while a topological attention mixer incorporates the realized directed topology into team-value factorization for topology-aware credit assignment. Across nine benchmarks and two frozen backbone LLMs, ACTS improves the accuracy–efficiency trade-off over Agent Q-Mix by up to 6.19 percentage points in accuracy and up to 15 .42% in token reduction. These results demonstrate the benefit of learning communication modes and directed partner relations jointly for efficient role-aware LLM collaboration. 9Preprint

E.1 TRAINING AND EVALUATION DETAILS 

Benchmarks and backbone models. We evaluate ACTS on nine benchmarks across four do-mains. The coding benchmarks are LiveCodeBench v6 and HumanEval (Jain et al., 2024; Chen et al., 2021). The reasoning benchmarks are MMLU-Pro and the first 250 questions of Humanity’s Last Exam (Wang et al., 2024; Phan et al., 2025). HotpotQA is used for multi-hop question an-swering (Yang et al., 2018). The mathematical benchmarks are AIME 2025, AIME 2026, HMMT 2025, and Beyond-AIME (Mathematical Association of America, 2025; 2026; MathArena, 2025; ByteDance-Seed, 2025). Each AIME benchmark comprises 30 problems from the corresponding AIME I and AIME II examinations. Experiments use GPT-OSS-120B and DeepSeek-V4-Flash as frozen backbone LLMs. Experiments use GPT-OSS-120B and DeepSeek-V4-Flash as frozen backbone LLMs. Each task is instantiated with three role-conditioned agents followed by a final answer-aggregation node. 

Baselines and controlled comparison. We compare ACTS with direct prompting, LLM-Debate (Du et al., 2023), AutoGen (Wu et al., 2023), LangGraph (LangChain AI, 2024), Microsoft Agent Framework (Microsoft, 2025), TopoDIM (Sun et al., 2026), and Agent Q-Mix (Jiang et al., 2026). All methods use the same team size ( N = 3 ), task prompts, communication-round budget, and answer-evaluation procedure. 

Training protocol and evaluation. The ACTS scheduler is trained for 50 episodes using 15 train-ing examples per domain. The communication budget is three rounds for mathematical tasks and two rounds for coding and reasoning tasks. All trainable modules are optimized with Adam using learning rate 5 × 10 −4 and discount factor γ = 0 .99 . The replay buffer has capacity 5,000 , the mini-batch size is 8, and ϵ-greedy exploration is annealed linearly from 1.0 to 0.05 over 50 episodes. The learned parameters are fixed during evaluation. Reported results are averaged over three independent runs with different random seeds. E.1.1 DATA SAMPLING AND INFORMATION GAIN COMPUTATION

ACTS follows a centralised-training, decentralised-execution scheme. A shared per-agent value network receives a local observation oi for each agent i, while a mixing network integrates the agent-specific values into a joint estimate Qtot conditioned on a global state s. We describe the construction of each. 

Local observation. For N = 3 , each agent receives a 51-dimensional observation oti comprising a 32-dimensional task embedding, a 16-dimensional one-hot agent identifier, a binary indicator of whether the agent has produced an answer, its incident edge count, and the normalized cumulative team token consumption clipped to [0 , 1] .

Global state. The global state st concatenates all agents’ local observations, three topology statis-tics comprising the edge count, graph density, and agent count, and the flattened N × N relational-attention matrix. For N = 3 , the resulting state dimension is 3 × 51 + 3 + 9 = 165 .E.3 ACTION SPACE 

At each round every active agent selects one of six discrete actions, grouped into three roles. Three actions, off , solo , and broadcast , operate outside the attention matrix: off deactivates the agent en-tirely for the round, emitting no edges and issuing no LLM call, and once a majority of agents are inactive the episode terminates early; solo produces an independent answer and emits no edges; broadcast sends the agent’s current output to every other agent. Two actions build sparse directed edges from the learned attention matrix aedge : attn-broadcast opens an edge i → j when the atten-tion that agent j pays to i exceeds the row mean, and attn-receive requests information only from the neighbours that agent i itself attends to. The remaining action, receive , performs a generic informa-tion fetch. Figure 7 reports the learned distribution of these six actions across the nine benchmarks. E.4 CASE STUDY

E.6 AGENT ROLE ASSIGNMENTS AND PROMPTS 

Each agent in the multi-agent system is assigned one of six predefined roles. Roles are allocated in round-robin fashion by agent index modulo 6. Since our experiments use n = 3 agents, only the first three roles are instantiated in any given run: 

R1: Independent Solver — solves the problem autonomously without relying on peer input. 

R2: Team Solver — approaches the problem collaboratively, integrating suggestions from team-mates. 

R3: Questioner — probes assumptions and raises critical questions about the problem. The remaining three roles (Refiner, Verifier, Debater) are defined in the role pool for future exten-sibility to larger agent teams, or for experiments where n > 3 (e.g., n = 6 ). The round-robin allocation modulo 6 naturally activates them when the team size increases, without any change to the prompt construction logic. E.6.1 AGENT SYSTEM PROMPT 

Every agent receives a system prompt that instantiates its role within an n-agent team and instructs it on the expected output format. The general template is:        

> You are {ROLE }on a{n}-agent team. {SUFFIX }

where {ROLE } is one of the six role labels listed above and {SUFFIX } is a question-type-specific instruction detailed below. E.6.2 QUESTION -T YPE SUFFIXES

The corresponding user message includes the original question, options (if applicable), refer-ence context, and the full list of agent answers, followed by the instruction Give the final answer.
