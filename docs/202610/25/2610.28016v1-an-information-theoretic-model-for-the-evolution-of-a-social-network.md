## 摘要
回音室和过滤气泡为理解社交网络时代的沟通与连接提供了一个框架。这类系统的特点是相互隔离的社群不断重复传播信息，从而强化既有信念。采用网络科学方法进行理论分析，有助于理解用户之间信息影响的机制。本文提出一种演化网络模型，该模型扩展了 Quoter Model，并依据文本生成节点之间的交叉熵重新连接边。模型参数刻画节点在二元强化与探索之间的意图，决定节点是倾向于寻找新颖性较高还是较低的邻居，而新颖性以交叉熵衡量。通过实证模拟研究，我们观察到模型涌现出的特征。具体而言，我们将模型与 Watts–Strogatz 模型进行比较，指出了聚类程度较高和探索性极强的参数区域。此外，我们还发现了一种彼此分离的社群结构，类似于初步的回音室结构。这些发现揭示了推动回音室固化的用户行为，并为未来的社交网络分析提供了背景。

## Abstract
Echo chambers and filter bubbles provide a framework to view communication and connection in a social network age. Such systems are characterised by isolated communities regurgitating information which reinforces prior beliefs. Theoretical analysis of echo chambers is suited for a network science approach to understand the mechanics of information influences between users. Here, we propose an evolutionary network model that extends the Quoter Model, rewiring edges according to cross-entropy between text-generating nodes. Parameters characterise binary reinforcement vs exploration node intents, determining whether a node will seek high or low novelty neighbours, measured by cross-entropy. Through an empirical simulation study, we observe emergent model attributes. Specifically, we compare to a Watts--Strogatz model, highlighting parameter regions of high clustering and hyper-exploration. Further, we identify a quality of disjoint communities akin to rudimentary echo chamber structures. These findings underscore user behaviours that drive echo chamber entrenchment, contextualising future social network analysis.
