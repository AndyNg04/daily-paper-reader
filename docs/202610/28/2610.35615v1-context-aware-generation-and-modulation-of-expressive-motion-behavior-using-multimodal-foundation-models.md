## 摘要
表达性机器人运动能够提升用户参与度、好感度或任务表现，从而促进人机交互。我们提出一种新方法，可根据多模态（文本、音频、视频）情境描述，自动生成并调制复杂的全身姿态序列。该方法基于使用动态运动基元对动画原理进行统一的数学实现，并借助多模态基础模型生成此类序列及其参数化运动变体，使其能够高度感知情境。该方法具备可解释性、可组合性，并可适用于不同机器人形态，因此在灵活性和通用性方面拓展了当前技术水平。此外，我们将该系统集成到连续控制框架中，并利用知识蒸馏训练出规模小得多的模型，从而显著提高 token 效率并降低系统延迟。针对类人平台开展的用户研究结果表明，与未进行调制的运动或 API 级条件下生成的运动相比，参与者认为本系统生成的运动与交互情境更加契合。我们还展示了该系统如何为具有不同运动学结构的机器人生成表达性运动，体现了其多样适用性。论文网页：https://gen-mod-expressive-motion-behavior.github.io/。

## Abstract
Expressive robot motion positively impacts human-robot interaction by improving user engagement, likability, or task performance. We present a novel approach to automatically generate and modulate complex, expressive full-body gesture sequences from a multimodal (text, audio, video) context description. Based on a unified mathematical implementation of the Principles of Animation using Dynamic Movement Primitives, we use multimodal foundation models to generate such sequences along with parametric motion variations that are highly context-aware. This method extends the state of the art in terms of flexibility and generality by being interpretable, composable, and working across different robot morphologies. Moreover, we integrate the system into a continuous control framework and leverage knowledge distillation to learn a much smaller model, significantly improving token efficiency and system latency. Results from a user study with a human-like platform indicate that participants judged our system's motions to be better aligned with the interaction context than motions produced under a non-modulated or API-level condition. We also demonstrate how the system generates expressive motion for robots with different kinematics, showcasing its versatility. Paper webpage: https://gen-mod-expressive-motion-behavior.github.io/.

## 1. 核心问题与整体含义

### 研究背景与动机
- 机器人不仅需要完成任务，还需要通过注视、手势和身体姿态表达意图与情绪，使互动更自然、易于理解。
- 同一个动作在不同情境中应有不同的表现方式。例如，“打招呼”面对普通访客与久别重逢的熟人，其动作幅度、速度和预备动作应有所不同。
- 现有方法存在几类限制：
  - **规则与状态机方法**需要大量人工设计，难以覆盖开放式互动情境。
  - **基础模型直接调用动作 API**具有灵活性，但较难生成协调、复杂且风格一致的全身动作。
  - **学习式动作生成方法**往往依赖特定机器人形态或训练数据，跨平台迁移受限。

### 核心研究问题
论文试图同时解决三个相互关联的问题：

1. **做什么、何时做**：根据文本、声音、视觉等情境，选择并排列合适的动作。
2. **怎么做**：根据情绪、社会关系和环境，调整动作的表达风格。
3. **如何持续执行**：在机器人连续控制过程中，兼顾生成延迟、动作衔接和实时目标跟踪。

**整体上，这是一种“基础模型负责语义决策、动态运动基元负责动作执行”的分层系统，而不是让模型从零生成任意关节轨迹。**

## 2. 方法论：核心思想与技术流程

### 2.1 系统输入与动作表示
输入包括两部分：

- **交互情境**：文本、视频或图像、音频，以及实时感知数据，例如人的位置。
- **机器人相关信息**：
  - 运动能力的文字描述；
  - URDF 运动学模型；
  - 已有手势或动作轨迹；
  - 各调制参数的允许范围。

系统先将已有动作编码成**动态运动基元（DMP）**，建立动作库。每个动作包含名称、语义描述和对应的运动基元。

### 2.2 动作序列生成：决定“做什么”
多模态基础模型采用分阶段流程：

1. 理解情境，提出符合社交语义的动作序列。
2. 根据机器人的能力检查动作是否可执行。
3. 从动作库中选择对应的全身运动基元，形成行为计划。

例如，机器人正在解释问题时听到敲门声，可以生成“转向门口—挥手—邀请靠近”的动作序列。

这里的跨形态能力主要来自**语义动作与具体关节实现的分离**：不同机器人可使用不同动作库，实现相似的交互意图。

### 2.3 动作调制：决定“怎么做”
论文沿用作者前作中基于 DMP 实现动画原则的方法。DMP 本质上是带非线性驱动项的二阶动力系统：

- 目标状态决定动作趋向哪里；
- 非线性驱动项及其权重编码动作形状；
- 时间尺度参数控制动作持续时间；
- 相位变量控制动作执行进度。

通过改变这些成分，可以调节动作的表达性：

| 调制维度 | 实现思路与效果 |
|---|---|
| 弧线与平滑性（Arcs） | 对 DMP 权重进行高斯平滑或锐化，使动作更柔和或更突出局部特征 |
| 预备动作（Anticipation） | 在动作开始阶段反向缩放加速度，形成正式动作前的预备运动 |
| 渐入渐出（Slow In Slow Out） | 调整相位函数，使开始和结束阶段更缓慢 |
| 时长（Timing） | 缩放时间参数，控制动作快慢 |
| 夸张程度（Exaggeration） | 缩放非线性驱动项，弱化或强化动作特征 |
| 跟随动作（Follow Through） | 根据源关节运动调整目标关节，形成身体部件间的联动 |
| 目标位置 | 更新 DMP 目标状态，使注视或手势朝向人或物体 |
| 随机变化 | 对权重加入高斯扰动，减少重复执行的机械感 |

### 2.4 从情境语义到数值参数
动作风格的自动生成分为三个模块：

1. **风格描述**：结合情境和动作序列，为每个动作生成自然语言执行描述，例如“热情、幅度较大地挥手”。
2. **动画原则评分**：将描述映射为各原则的通用评分，例如 1～10 或 −5～5。
3. **机器人参数投影**：将通用评分映射到机器人允许的参数范围。
   - 预备动作、跟随动作采用线性映射；
   - 平滑性、夸张程度和时长采用分段线性映射；
   - 渐入渐出采用开关控制。

这种设计将**情境理解、表达风格和具体运动参数**分离，提高了可解释性和平台适配能力。

### 2.5 连续控制与知识蒸馏
- **时间线控制**：
  - 使用先进先出队列管理动作序列。
  - 新情境到来时清空待执行队列，必要时直接替换当前动作。
  - 空闲时执行低意图动作，避免机器人完全静止。
- **分层更新**：
  - 高层低频生成动作计划；
  - 底层以控制频率更新 DMP，例如持续调整目标位置以跟踪移动的人。
- **知识蒸馏**：
  - 教师模型为 GPT-4.1，运行多阶段生成流程。
  - 学生模型为经过微调的 GPT-4.1-nano。
  - 用教师生成的流程轨迹训练学生，使学生通过一次调用直接输出动作序列及调制结果，省去多次模型调用和中间文本。

## 6. 主要结论与发现

### 6.1 动作库与调制均改善情境契合度
- 未调制动作序列优于 API-level，差异显著：**p < 0.001**。
- 完整调制方法优于未调制方法：**p < 0.001**。
- 作者报告生成条件的效应量为 **η² = 0.447**，说明生成方式对评分有较明显影响。

这表明，在所测试情境中，**选择语义完整的复杂手势，以及对这些手势进行情境化调制，都有贡献**。

### 6.2 蒸馏在预设界值内保持了感知质量
- 三个情境均支持蒸馏模型相对于教师流程的非劣效性。
- 相对偏好均值分别为 **3.86%、16.73%、7.56%**，方向上偏向蒸馏模型。
- 但应注意：**非劣效不等于完全相同，也不证明蒸馏模型显著更好**。

### 6.3 生成延迟显著降低
作者报告总体平均延迟：
- 蒸馏模型：**2.39 秒**；
- 多阶段流程：**12.87 秒**；
- 对应约 **5.4 倍加速**、**81.5% 延迟下降**。

**报告一致性提示**：文中列出的多阶段流程三个情境均值为 14.32、16.66、10.26 秒，等权平均约为 13.75 秒，与总体均值 12.87 秒不一致；总体数字仍需核实。

### 6.4 跨形态与多模态具有可行性
- 三类机器人均能实现朝向接近者的热情问候，但动作库较小的平台出现更多重复模式。
- 加入敲门声后，机器人能从继续解释转为问候和邀请靠近。
- 图像、语音与文字表达相近情境时，生成动作及参数也较接近。

这些结果支持功能可行性，但尚不足以证明对复杂真实环境的鲁棒性。

## 7. 优点与亮点

- **语义规划与运动执行分离**：避免基础模型直接输出高维关节序列，同时保留复杂全身手势的表达能力。
- **参数具有明确含义**：速度、夸张程度、预备动作等可被理解和人工调整，比纯潜变量调制更透明。
- **同时处理动作选择与动作风格**：不仅回答“做什么”，还回答“以怎样的方式做”。
- **跨形态接口设计清晰**：通过能力描述、URDF、动作库与参数范围适配机器人，而不要求所有平台共享同一套关节结构。
- **兼顾连续控制和生成效率**：时间线管理、实时目标更新和知识蒸馏形成较完整的执行链路。
- **具有一定行为约束能力**：可以通过剔除动作库中的特定手势，降低生成不适当动作的风险，但这不等于完整安全保证。

## 8. 不足与局限

### 8.1 动作能力依赖人工准备的动作库
- 系统主要是组合和调制已有技能，无法保证生成库外的新动作。
- 平台适配仍需提供动作轨迹、语义描述及参数范围。
- 因而“机器人无关”主要指**架构层面的通用性**，不是无需准备即可迁移到任意机器人。

### 8.2 真实互动与长期效果尚未验证
- 用户研究基于视频，无法充分反映现场互动中的时机、身体距离、突发事件和双向反馈。

- 平均约 2.4 秒的高层生成时间虽明显改善，但对快速轮流对话或紧急打断仍可能偏慢。

### 8.3 多模态与跨平台证据偏弱
- 所谓视频模态的具体实验主要使用静态图像，不能等同于验证了动态视频理解。
- 未系统测试噪声、遮挡、模态冲突、多人物或含糊情绪。
- 跨形态实验仅覆盖少量任务，缺少统一评分和充分的定量比较。
- 未清楚交代音视频输入的编码、预处理及教师与学生之间的模态传递接口，影响复现。

### 8.4 安全性与动力学保证不足
- DMP 提供结构化运动生成机制，但不自动保证碰撞规避、关节力矩限制或四足稳定性。
- 夸张、加速、反向预备动作及随机扰动都可能改变安全边界。
- 基于吸引子的动作衔接也不等于在任意中断条件下都满足速度、加速度和接触安全要求。

### 8.5 偏差与复现风险
- 小规模样本和高校渠道招募限制人口代表性，动作含义也可能存在文化差异。
- 教师模型的社会常识偏差可能被蒸馏继承。
- 训练配置、数据划分、提示词及安全参数披露不足，限制可重复性。
- 对“低电量机器人应该表现疲倦”等情境，不同用户可能持有不同规范预期，说明情境契合并不存在唯一答案。

**总体评价**：这篇论文的主要贡献是将多模态情境理解、可解释动作调制与连续机器人控制整合成一个实用框架。现有结果较有力地支持其在有限情境下改善主观动作契合度并降低生成延迟，但对于开放环境泛化、真实互动收益、跨形态性能一致性及安全执行，仍需要更大规模、更加系统的验证。
