## 摘要
近期研究尝试通过多智能体强化学习（MARL）优化大语言模型（LLM）协作，但许多方法仍依赖预定义工作流，限制了效率和可扩展性。去中心化的 LLM 协作颇具挑战，因为各智能体独立执行、通信受限、共享共同目标，并且必须从通信轨迹中推断有用信息。本文提出 BCMAAC，即一种信念条件化多智能体演员-评论家方法。该方法对上下文信息维护信念，并利用这些信念促进训练。在 Minecraft 游戏、网络搜索和工具使用任务上的实验表明，与朴素演员-评论家基线相比，BCMAAC 能提升任务表现和协作行为。在上下文信息更丰富的多轮任务中，这种提升尤为显著，表明信念建模具有明显优势。

## Abstract
Recent work has explored optimizing LLM collaboration through Multi-Agent Reinforcement Learning (MARL), but many approaches still rely on predefined workflows, limiting efficiency and scalability. Decentralized LLM collaboration is challenging because agents execute independently with limited communication, share a joint objective, and must infer useful information from communication traces. In this paper, we propose BCMAAC, a Belief-Conditioned Multi-Agent Actor-Critic method that maintains beliefs over contextual information and uses them to facilitate training. Experiments on Minecraft game-playing, web searching and tool-using tasks show that BCMAAC improves task performance and collaborative behavior compared to naive actor-critic baselines. The improvements are particularly pronounced in multi-turn tasks with richer contextual information, where belief modeling provides a clear advantage.

论文的整体思路是：**在文本历史之外，学习一个可持续更新的紧凑“信念上下文”，同时辅助动作生成和价值估计。**

## 2. 方法论：BCMAAC

### 2.1 核心思想与架构

论文提出 **BCMAAC（Belief-Conditioned Multi-Agent Actor-Critic）**，沿用“集中训练、去中心化执行”框架，增加循环信念编码器和辅助监督。

系统主要包含三个模块：

| 模块 | 输入与功能 |
|---|---|
| 循环信念编码器 | 根据本地结构化信息和上一轮记忆，更新信念上下文 |
| LLM Actor | 结合本地文本历史与信念上下文，生成通信、搜索、移动或工具调用 |
| 集中式 Critic | 训练时聚合所有智能体的信念上下文，估计团队未来回报 |

需要注意：这里的“信念”是**学习得到的潜在状态表示**，并非显式维护、经过校准的贝叶斯概率分布。

### 2.2 本地结构化信息与循环记忆

每轮，智能体接收结构化侧信息，例如：

- 游戏：可见资源、位置、已知安全支柱、队友消息。
- 网页任务：已检索证据、共享证据板、搜索进度。
- 工具任务：已知参数、路径是否已传递、执行条件是否满足。

循环编码器据此更新内部记忆，并输出：

- 提供给 Actor 和 Critic 的信念上下文；
- 任务状态预测；
- 队友动作类别预测。

**去中心化约束**是：执行时的结构化输入只能来自该智能体自己可获得的信息，包括收到的通信，不能直接使用隐藏全局状态。

### 2.3 两类辅助学习目标

#### 任务信念监督

让编码器预测任务相关状态，例如：

- 哪些资源位置与自己的工具能力匹配；
- 哪些候选支柱是真正安全的支撑；
- 哪些证据属于正确支持链；
- 执行者是否已掌握必要信息、目标操作是否完成。

主要采用带掩码的二元交叉熵损失。

#### 队友动作监督

预测队友的动作类别，采用交叉熵损失。例如：

- 采集任务：采集、移动、通信、不行动；
- 建桥任务：放置、侦察、通信、不行动。

附录还包含回答就绪度和部分动作字段偏好的监督，分别归入上述两类目标。

**标签在训练阶段由完整轨迹和环境内部状态生成，属于特权监督；推理时不再需要这些标签。**

### 2.4 Actor-Critic 优化方式

- **Critic**：用当前奖励加下一轮信念上下文的折扣价值，构造一步 TD 目标，训练团队价值估计。
- **Actor**：用 TD 优势加权完整响应序列的对数概率；响应概率由各生成 token 的条件概率相乘得到。
- **信念编码器**：共同接受策略损失、价值损失和辅助预测损失的梯度。

因此，辅助监督并不是直接替代任务奖励，而是为状态表示提供额外的逐轮学习信号。

### 2.5 算法流程

1. 采样任务并初始化各智能体历史和循环状态。
2. 各智能体根据本地结构化信息更新信念。
3. Actor 结合文本历史与信念生成动作，环境执行联合动作。
4. 收集轨迹，并在回合结束后生成辅助标签。
5. 重算信念上下文，计算 TD 优势和三类损失。
6. 更新 Actor、Critic 和信念编码器。
7. 部署时仅保留本地 Actor 和信念编码器，不使用集中式 Critic 或辅助预测头。

### 2.6 理论结果的含义与边界

论文给出：

- **动作无关基线性质**：当前动作采样前形成的信念上下文可作为策略梯度基线的输入，不改变使用真实回报时的期望梯度。
- **条件充分性命题**：如果压缩后的信念保留全部回报相关信息，其价值估计就等价于使用完整可用信息。
- **辅助监督解释**：逐轮标签为编码器提供额外表示学习信号。

这些结果支持方法设计，但**并未证明实际编码器能够学到充分表示，也不构成一步 TD 估计无偏、算法收敛或必然优于 MAAC 的保证**。

## 6. 主要结论与发现

### 6.1 六个任务均优于 MAAC

下表为论文报告的均值，增益单位为百分点：

| 任务 | MAAC | BCMAAC | 增益 |
|---|---:|---:|---:|
| 资源采集 | 78.4 | **92.8** | +14.4 |
| 建桥 | 80.6 | **94.4** | +13.8 |
| 跨语言检索 | 45.1 | **53.2** | +8.1 |
| 多源检索 | 47.6 | **58.5** | +10.9 |
| 状态工具 | 59.2 | **77.5** | +18.3 |
| 文件系统操作 | 58.9 | **73.0** | +14.1 |

### 6.2 关键发现

- **需要跟踪隐含状态和跨轮前提条件的任务，收益更明显**，状态工具任务提升最大。
- 两类辅助监督具有互补性：
  - 任务信念监督在六个任务中的五个上优于仅队友动作监督；
  - 建桥任务更受益于队友动作预测；
  - 完整方法在所有任务上最好。
- 多智能体协作**并不天然优于单智能体**：
  - 文件系统任务中，AC 为 66.9%，高于 MAAC 的 58.9%；
  - BCMAAC 达到 73.0%，说明改善信息交接可以缓解协作开销。
- 训练曲线总体显示更高最终回报，多个任务波动更小；但网页任务收益相对温和，跨语言任务仍较嘈杂。

这些结果支持信念表示的有效性，但“更准确的优势估计”“更少重复搜索”等机制解释，主要仍来自间接证据。

## 7. 优点与亮点

- **切中协作中的状态估计问题**：不仅优化答案生成，还显式关注队友知识、执行就绪度和信息交接。
- **保留去中心化执行**：部署时不依赖全局 Critic，架构上符合局部信息约束。
- **训练监督与部署输入明确分离**：隐藏标签用于训练，本地可见信息用于执行。
- **辅助目标贴近协作需求**：任务状态与队友行为分别对应“当前情况如何”和“他人会怎么做”。
- **跨领域验证具有一致性**：不是只在单一游戏环境中展示收益。
- **评价使用任务原生指标**：成功率或答案匹配分数之外，还展示训练回报曲线，避免只凭奖励判断效果。
- **承认协作开销**：文件系统中的单智能体强基线说明论文并未假设“更多智能体一定更好”。

## 8. 不足、偏差风险与应用限制

### 8.1 “长时域”和规模化结论仍有限

- 实际实验最多 4 轮，与数十轮甚至更长的真实工作流存在距离。
- 所有任务只有两个智能体，未验证多方通信、角色冲突或规模扩展。
- 小规模评估集限制了泛化结论的可靠性。

### 8.2 依赖人工结构设计与可获取标签

- 每类任务需要定制网格、槽位、进度变量和动作分类。
- 训练需读取环境内部状态、正确证据链或任务完成条件。
- 开放网页、企业系统或现实机器人环境中，这些标签可能难以获取。

因此，方法的可迁移性取决于**结构化状态能否构建、辅助标签能否可靠生成**。

### 8.3 稀疏奖励叙事与实际实验存在距离

尽管论文强调稀疏终局奖励，附录中实际使用了较丰富的奖励塑形，包括：

- 资源与连接进度；
- 有用通信；
- 证据覆盖；
- 有效工具调用；
- 就绪后未执行等惩罚。

所以，实验更直接验证的是：**在已有塑形奖励基础上，辅助信念学习仍有收益**，而不是纯终局稀疏奖励下的效果。

### 8.4 尚未完全隔离性能来源

缺少结构化输入匹配、循环记忆匹配和辅助监督匹配的对照，无法完全区分收益来自：

- 信息组织方式更好；
- 更强的记忆表示；
- 特权监督；
- Actor 条件化；
- Critic 输入变化。

### 8.5 协作质量与工程细节证据不足

- 缺少重复搜索率、消息有效率、交接失败率等直接指标。
- 信念如何接入 LLM、梯度如何通过接口传播等实现细节不够完整。
- 未报告辅助损失权重的系统敏感性和额外计算成本。
- 理论部分没有实际收敛、压缩误差或方差降低保证。
