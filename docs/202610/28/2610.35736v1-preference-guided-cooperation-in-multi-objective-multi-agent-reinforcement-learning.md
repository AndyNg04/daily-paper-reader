## 摘要
多目标多智能体强化学习（MOMARL）在优化系统整体性能的同时，需要兼顾智能体协调与目标权衡。现有研究往往将多智能体协作与多目标优化视为学习问题中基本相互独立的组成部分，除非情形十分简单，否则会导致极高的复杂度。本文探讨能否利用多目标结构本身来促进协作，而非将其视为额外的优化挑战。我们从团队与个体两个层面构建 MOMARL，并提出按目标划分的反事实信用分配方法，以评估各智能体对团队各项目标的贡献。我们提出元梯度信息引导的多目标多智能体强化学习方法（MIRL），包括静态变体（MIRL-S）和动态变体（MIRL-D）。通过融入元梯度信息，MIRL 使智能体能够学习如何在个体层面确定目标优先级，同时在集体层面优化系统目标，从而让多目标结构直接引导协作。在多目标多粒子环境中的实验表明，与基线方法相比，我们的方法提升了 Pareto 前沿质量，其中动态变体表现最佳。

## Abstract
Multi-objective multi-agent reinforcement learning (MOMARL) addresses agent coordination and objective trade-offs simultaneously while optimising overall system performance. Existing work tends to treat multi-agent cooperation and multi-objective optimisation as largely independent components of a learning problem, which amounts to an exorbitant complexity except in trivial cases. We study here whether the structure provided by multiple objectives can itself be exploited to facilitate cooperation, rather than being treated as an additional optimisation challenge. We formulate MOMARL at both the team and individual levels and introduce objective-wise counterfactual credit assignment to evaluate each agent's contribution across the team objectives. We propose Meta-Gradient Informed Multi-Objective Multi-Agent Reinforcement Learning (MIRL), with static (MIRL-S) and dynamic (MIRL-D) variants. By incorporating meta-gradient information, MIRL enables agents to learn how to prioritise objectives individually while collectively optimising the system-level objective, allowing the multi-objective structure to directly guide cooperation. Experiments on a multi-objective multiple particle environment show that our methods improve Pareto-front quality over baselines, with the dynamic variant achieving the strongest performance.

## 1. 核心问题与研究背景

- **研究对象**：合作式多目标多智能体强化学习（MOMARL）。多个智能体既要协调行动，又要在任务完成、能源消耗等潜在冲突的目标之间进行权衡。
- **现有方法的不足**：通常先解决多智能体协作，再叠加多目标优化，将两者视为相对独立的问题，没有充分利用不同目标所揭示的智能体贡献差异。
- **论文的核心问题**：能否让多目标结构本身成为促进协作的信息，而不只是额外的优化负担？
- **整体思路**：区分两个层面的偏好：
  - **团队偏好**：由外部指定，决定系统最终追求的目标权衡。
  - **个体偏好**：由学习产生，决定各智能体在学习和行动时如何侧重不同目标。
  
  个体不必采用相同的目标权重，也不要求其偏好平均后等于团队偏好；关键是它们共同产生的行为能否改善团队表现。

**论文的主要意义**在于：把“不同智能体应该如何侧重不同目标”转化为可优化的协作机制，而非预先规定角色或统一使用团队权重。

## 2. 方法论：MIRL 的核心思想与技术细节

论文提出 **MIRL（Meta-Gradient Informed Multi-Objective Multi-Agent Reinforcement Learning）**，包含静态版本 MIRL-S 和动态版本 MIRL-D。

### 2.1 团队—个体双层偏好建模

- 团队使用固定偏好，对各目标的期望回报进行线性加权，定义最终优化方向。
- 每个智能体拥有可学习的个体偏好，用于组合其不同目标上的学习信号。
- **个体偏好是服务于团队优化的内部变量，而不是独立的、自利的效用要求。**

### 2.2 逐目标反事实信用分配

方法采用**集中训练、分散执行（CTDE）**：

- 训练时，集中式评论家读取联合观测和联合动作，预测包含各目标价值的向量。
- 为评估某个智能体的贡献，保持其他智能体动作不变，仅替换该智能体的动作，计算反事实参考值。
- “实际联合动作价值减去反事实参考值”，形成该智能体的**逐目标反事实优势向量**。

其含义是分别回答：

> 该智能体当前动作，相对于它按照当前策略采取其他动作，究竟改善了多少任务表现、节约了多少能源？

连续动作无法枚举，因此实验使用 **8 个当前策略采样动作**估计反事实期望。与立即将奖励标量化相比，这一步保留了各目标上的贡献差异。

### 2.3 MIRL-S：通过元梯度学习静态个体偏好

- 每个智能体具有一组可学习参数，通过 Softmax 映射为非负、总和为 1 的偏好权重。
- **内层更新**：用个体偏好加权逐目标反事实优势，再更新策略。
- **外层更新**：使用更新后策略采集另一段轨迹，按照固定团队偏好评价其表现，再反向调整个体偏好。
- 因此，偏好学习不是直接追求当前个体收益，而是学习：
  
  > 什么样的目标侧重，能够让下一次策略更新更有利于团队？

主要实现细节包括：

- 不同智能体共享策略参数，通过智能体标识加以区分。
- 向量评论家采用逐目标 TD(λ) 训练，不使用个体偏好标量化其训练目标。
- 元梯度计算时，将评论家输出的优势作为停止梯度的固定信号。
- 实验采用 **μ=0 的贪心元梯度近似**，只考虑当前策略更新的影响，而不完整传播长期训练依赖。

**“静态”指偏好不随执行时的状态变化，并不意味着训练过程中不更新。**

### 2.4 MIRL-D：根据局部情境动态生成偏好

- 用共享偏好控制器替代固定的个体偏好参数。
- 控制器根据智能体当前的局部循环隐藏状态，在每个时间步生成偏好。
- 动态偏好既用于加权学习信号，也显式输入策略，因此能够直接影响当前动作。
- 执行时无需集中式评论家，但仍需保留本地偏好控制器。

### 2.5 整体算法流程

1. 在偏好空间中设置 21 个团队偏好，并均分总训练预算。
2. 对每个团队偏好独立初始化并训练策略。
3. 采集内层轨迹，更新向量评论家，计算反事实优势。
4. 使用个体偏好更新策略。
5. 使用更新后策略采集后续轨迹，根据团队表现计算元梯度并更新偏好参数或控制器。
6. 训练完成后，保留非支配策略，形成近似 Pareto 前沿。

## 3. 实验设计与 Benchmark

### 3.1 环境与任务

实验不是基于静态数据集，而是基于 **MPE 多智能体粒子环境**，使用维护中的 **MPE2/PettingZoo 实现**扩展出双目标任务：

| 场景 | 智能体数量 | 主要协作要求 |
|---|---:|---|
| Spread | 3 | 覆盖不同地标，同时避免碰撞 |
| Formation | 3 | 在中心地标周围形成等间隔圆形队列 |
| Line | 3 | 在两个地标之间形成等间隔直线队列 |
| Reference | 2 | 通过通信交换私有目标信息，并移动至目标位置 |

- 两个目标分别为：**任务回报最大化**与**负能耗最大化，即降低能耗**。
- 移动能耗按控制输入平方计算；Reference 还根据激活的通信分量数量计入通信成本。
- 每回合 **25 步**，折扣因子 **0.99**。

### 3.2 对比方法

共比较 **7 种方法**：

- **DTDE-PPO**：完全分散训练与执行。
- **CTDE-PPO-V**：使用集中式状态价值评论家。
- **CTDE-PPO-Q**：使用集中式联合动作价值评论家。
- **MO-COMA**：具有逐目标反事实信用分配，但不学习个体偏好。
- **MO-MIX**：基于多目标价值分解的专用 MOMARL 方法。
- **MIRL-S**、**MIRL-D**：论文提出的两个版本。

其中，MO-COMA 与 MIRL 共用基础实现，是判断偏好适应机制增益的关键消融基线。

### 3.3 指标与训练设置

- **HV，超体积**：越高越好，评价前沿质量与覆盖。
- **EU，期望效用**：越高越好，评价不同偏好下可选择方案的平均效用。
- **SP，稀疏度**：通常越低越好，辅助评价解集分布；但不能单独代表前沿质量。

每个环境、每个随机种子的总预算均为 **500 万联合环境步**，共使用 **3 个随机种子**：

- 除 MO-MIX 外，均对 21 个团队偏好独立训练，总预算在这些偏好间均分。
- MO-MIX 使用单个偏好条件网络，享有完整的 500 万步预算。
- MO-MIX 仅支持离散动作，因此使用离散化动作空间；其他方法主要使用连续控制，Reference 还包含离散通信门控。

## 6. 主要结论与发现

### 6.1 MIRL-D 的 HV 和 EU 均值整体最佳

| 环境 | MO-COMA：HV | MIRL-S：HV | MIRL-D：HV | MIRL-D 相对 MO-COMA |
|---|---:|---:|---:|---:|
| Spread | 1570.08 | 1581.40 | **1594.55** | 约 +1.56% |
| Formation | 2178.79 | 2187.33 | **2196.13** | 约 +0.80% |
| Line | 1958.71 | 1957.49 | **1965.89** | 约 +0.37% |
| Reference | 2567.07 | 2587.41 | **2587.44** | 约 +0.79% |

- MIRL-D 在四个任务的 HV、EU 上均获得最高均值。
- 但**相对于最接近的 MO-COMA，增益总体较小**，且部分差距小于报告的标准差。
- MIRL-S 并非所有指标均优于 MO-COMA，例如 Line 的 HV 略低。

### 6.2 反事实信用分配贡献突出

- MO-COMA 已明显优于多数 PPO 基线。
- 这说明有效区分智能体在各目标上的贡献，是整体性能提升的重要来源。
- 元梯度偏好适应是在该强基线上进一步改善，而不是全部提升的唯一来源。

### 6.3 动态偏好的收益取决于任务

- Spread 的协调关系随位置变化，动态偏好更可能发挥作用。
- Reference 中静态、动态版本表现几乎一致。
- Formation、Line 的协调需求相对稳定，MO-COMA 已接近 MIRL。

这些任务机制解释具有合理性，但主要属于作者结合结果提出的解释，尚缺少更强的因果验证。

## 7. 优点与亮点

- **问题视角有启发性**：将多目标结构用于指导协作，而不只是处理目标冲突。
- **团队目标与个体学习机制分离**：允许差异化贡献，同时保留统一的系统评价标准。
- **信用分配保留目标维度**：为学习个体侧重点提供了直接的信息基础。
- **双层优化逻辑清楚**：通过后续团队表现学习“如何构造当前学习信号”。
- **支持分散执行**：动态控制器只依赖本地表示，不要求执行时访问全局信息。
- **消融基线较有针对性**：MO-COMA 与 MIRL 共用实现，较好地区分基础信用分配和偏好学习的作用。
- **评价较全面**：同时考虑前沿效用、覆盖和分布，并展示偏好的训练与执行变化。

## 8. 不足与局限

- **实验覆盖有限**：仅涉及双目标、2—3 个智能体、25 步短回合的粒子环境，尚不能证明在大规模、长时序或高维目标任务上的有效性。
- **额外性能收益有限**：相对 MO-COMA 的改善多在约 0.4%—1.6% 的 HV 范围内，统计可靠性还需更多种子验证。
- **缺乏理论保证**：没有证明个体偏好适应必然改善团队目标，也没有给出收敛性或 Pareto 最优保证。
- **元梯度采用短视近似**：μ=0 且截断评论家梯度，降低了计算复杂度，但忽略长期学习效应。
- **动态版本的梯度路径说明不够完整**：偏好既影响学习信号，又直接进入策略；其直接与间接梯度路径、隐藏状态是否停止梯度等实现细节需要更明确。
- **可解释性仍属初步证据**：偏好发生变化，不等于已经识别出稳定、有意义的协作角色；论文也承认缺少行为层面的定量验证。
- **计算与存储扩展性待评估**：逐智能体反事实采样、额外元学习轨迹以及每个团队偏好独立训练策略，均可能增加成本。
- **线性标量化存在适用范围**：对于存在非凸部分的可达回报集合，线性偏好优化一般不能保证恢复完整 Pareto 前沿。
- **结果呈现存在待澄清细节**：任务奖励与负能耗按定义均非正，但表中 EU 为正，文本未明确说明是否进行了平移或归一化。

**总体评价**：论文提出了一个结构清晰、具有研究价值的协作学习框架，证明了可学习个体偏好在小规模 MOMARL 中具有潜力。但目前证据更支持“在强反事实信用分配基线上获得小幅增益”，尚不足以证明其大规模适用性、显著稳定优势或可解释角色涌现。
