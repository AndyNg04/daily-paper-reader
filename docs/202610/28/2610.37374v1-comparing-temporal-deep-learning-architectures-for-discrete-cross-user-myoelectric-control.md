## 摘要
通过离散肌电控制识别动态手势，正逐渐成为事件驱动型人机交互中一种颇具吸引力的输入方式。尽管近期研究表明，离散跨用户模型具有可行性（即无需采集终端用户的校准数据），但对优化此类系统的技术进行评估的研究仍然有限；此外，这些模型对模拟真实世界离散控制的全新随机提示数据的泛化能力也尚不明确。本研究使用包含612名用户的 EMG-EPN 数据集，对五种时序深度学习方法进行基准测试，评估模型性能与复杂度之间的权衡，并比较人工设计与机器学习提取特征的方法。CNN-GRU 在184名此前未见过的用户上测试时取得了最佳准确率，为93%。随后，我们在另一个更贴近实际、未经分段的数据集上评估这些模型：用户在连续数据采集过程中接受随机提示，以诱发离散手势。该数据集的采集时间比用于训练原始模型的数据晚五年，且采集于另一个国家。结果表明，跨用户模型在这一新数据集上同样表现出良好的泛化能力，准确率达到96%；尽管在诱发手势过程中未向用户提供任何反馈。这些发现凸显了离散零样本跨用户肌电控制的巨大潜力，并为这一前景广阔的技术持续发展提供了有价值的见解。

## Abstract
The recognition of dynamic gestures via discrete myoelectric control is becoming an attractive input modality for event-based human-machine interaction. While recent work suggests that discrete cross-user models are possible (i.e., no calibration data is required from the end user), few have evaluated techniques to optimize these systems and their generalizability to new randomly prompted data simulating real-world discrete control is relatively unknown. Using the 612-user EMG-EPN dataset, this work benchmarks five temporal deep-learning approaches, evaluates the tradeoff between performance and model complexity, and compares hand-crafted and machine-learned feature extraction techniques. The CNN-GRU achieved the best accuracy of 93% when tested on 184 previously unseen users. These models were then evaluated on a different, more realistic, unsegmented dataset, wherein users were randomly prompted to elicit discrete gestures during a continuous data collection. This dataset was recorded five years apart and in a separate country from the data used to train the original model. Results show that the cross-user results scale to this new dataset (accuracies of 96%) even though no feedback was given to users during the elicitation of gestures. These findings highlight the exciting potential of discrete zero-shot cross-user myoelectric control and offer valuable insights for the continued advancement of this promising technology.

## 1. 核心问题与研究背景

- **研究目标**：探索如何在不采集终端用户个性化校准数据的情况下，利用表面肌电信号（sEMG）识别动态手势，并将其映射为离散交互指令。
- **研究动机**：
  - 肌电控制可以支持脱离键盘、鼠标的人机交互，但传统方案通常需要针对每位用户进行训练或反复校准，限制了实际部署。
  - 与持续输出控制指令的连续肌电控制不同，**离散控制将一次完整动态手势识别为一个事件**，更接近点击、滑动等常见交互方式。
  - 动态手势中的时间结构可能帮助模型学习跨用户共享的特征，但此前研究对架构选择、模型复杂度及真实连续信号上的泛化能力评估不足。
- **本文的整体贡献**：不是提出全新的网络架构，而是系统比较现有时序模型，并把评估从预先切分的手势样本推进到需要自动检测、分段的连续肌电流。
- 文中的“**零样本**”指**对新用户无需校准或训练**，并不是识别训练中从未出现过的新手势类别。

## 2. 方法论：核心思想与技术流程

### 2.1 总体框架

系统分为两个主要阶段：

1. **手势检测与分段**：从连续肌电信号中提取可能包含手势的片段。
2. **时序手势分类**：将片段转换为特征序列，输入时序网络，输出六分类结果。

对于已经提供手势边界的离线数据，直接进行第二阶段。

### 2.2 输入处理与特征提取

- 输入为 **8 通道、200 Hz** 的肌电信号。
- 使用 **50 ms 窗口、25 ms 步长**构建时间序列。
- 对比两种特征提取方式：
  - **人工特征**：逐窗口提取小波能量特征（WENG）。
  - **学习式特征**：对原始窗口数据使用三层一维 CNN：
    - 输出通道依次为 16、32、64；
    - 卷积核大小为 3，步长为 1，采用保持长度的填充；
    - 各层包含批归一化、最大池化、ReLU 和 0.2 的 dropout。
- 不同长度的手势模板通过**尾部补零**统一长度。

### 2.3 时序模型与分类器

比较五类架构：

- 普通 RNN；
- LSTM；
- 双向 LSTM（BiLSTM）；
- GRU；
- Transformer。

主要配置如下：

- 循环网络隐藏维度为 **128**，dropout 为 **0.2**。
- RNN 将默认的 Tanh 非线性改为 ReLU，以缓解调试中观察到的梯度消失。
- Transformer 的模型维度为 **128**、前馈层维度为 **512**、注意力头数为 **8**，使用可学习位置嵌入。
- 使用序列最后一个窗口的输出编码进行分类；分类头包含 **128、64、32** 维线性层，最终输出六类结果。
- 训练设置：Adam、交叉熵损失、梯度范数裁剪，训练 **50 个 epoch**，初始学习率 **0.001**，batch size 为 **1000**。

### 2.4 连续信号中的手势分段

采用基于 **Teager–Kaiser 能量**的阈值检测：

1. 计算各通道能量并取平均。
2. 使用 **150 ms 窗口、25 ms 步长**平滑。
3. 等待能量低于就绪阈值 `t_ready = 75`。
4. 当能量超过启动阈值 `t_onset = 150` 时，认为手势开始。
5. 跟踪能量峰值；若最多 **100 ms** 内没有更高峰值，则结束峰值搜索。
6. 等待能量到达局部最小值，将提取的片段交给分类器。

两个阈值来自预实验。这一策略依赖于**用户在相邻手势之间回到静息状态**。

## 6. 主要结论与发现

### 6.1 离线分类：GRU 表现较强，但并非全面显著优于其他模型

| 模型 | 跨配置平均准确率 | 最佳配置准确率 |
|---|---:|---:|
| GRU | 92.9% | **93.5%** |
| BiLSTM | 92.1% | 92.8% |
| LSTM | 91.9% | 92.8% |
| Transformer | 91.6% | 92.8% |
| RNN | 89.8% | 91.9% |

- 最佳离线配置为 **7 层 CNN-GRU**。
- 跨所有配置平均时，架构差异较明显；比较各自最佳配置后，显著差异明显减少。
- 因此，更合理的结论是：**GRU 是表现较好的候选方案，但不能据此断言其对所有其他优化架构均显著占优。**

### 6.2 连续跨数据集评估

- 最佳结果为 **2 层 CNN-GRU，准确率 96.1%**。
- 其他架构最佳准确率：
  - BiLSTM：94.4%；
  - RNN：94.3%；
  - LSTM：94.2%；
  - Transformer：91.8%。
- 各架构最佳配置之间**未发现显著差异**，但这不等于已经证明性能等价。
- 手势检测报告：
  - 假阳性率 **1.7%**；
  - 假阴性率 **0.3%**；
  - 提示到预测平均延迟约 **700 ms**，其中包含用户完成手势的时间，并非纯推理耗时。
- 需要强调：**96.1% 来自不同于离线最佳模型的配置**，不能将两项最佳成绩直接表述为同一个固定模型从 93.5% 提升到 96.1%。

### 6.3 特征与深度的影响

- CNN 平均准确率为 91.9%，WENG 为 91.4%，差异未达到显著水平（p=0.052）。
- 两种特征各自最佳配置之间也无显著差异（p=0.29）。
- 增加深度总体上改善离线平均性能，但不同深度的最佳配置间无显著差异。
- 外部数据集的最佳 GRU 仅有两层，说明**更深、参数更多并不必然带来更好的跨数据集泛化**。

## 7. 主要优点

- **应用问题明确**：直接针对肌电交互的个性化校准负担。

- **跨用户训练规模较大**：使用 612 用户数据集，有利于学习用户间共享结构。
