## 摘要
尽管大语言模型（LLM）推动了 3D 室内场景合成的发展，现有流程仍无法在不同会话间保留用户的个性化偏好，使沉浸式创作沦为重复且容易造成身体疲劳的过程。本文提出 SPHERE，一种自适应 VR 场景生成框架，可将孤立的场景合成转变为持续的人机共创。SPHERE 从自然的多模态交互（语音和控制器编辑）中提取持久的空间偏好。为增强系统应对空间扭曲的几何鲁棒性，SPHERE 将原始编辑抽象为层级约束，同时建模局部功能情境与全局拓扑情境。此外，人在回路的强化学习机制会根据用户最终编辑的场景动态更新检索策略。混合设计用户研究（N=42）与离线消融实验表明，SPHERE 显著减少了修正性编辑和身体负担，并避免系统偏向浅层的物体级特征，从而生成几何上稳健且符合用户画像的布局。最终，SPHERE 展示了如何通过捕捉用户所展示的空间逻辑实现可控的空间适应，并由此建立可靠、受控的人机协作框架，服务于沉浸式创作。项目页面和源代码将发布于：https://github.com/hyeonmin11/SPHERE

## Abstract
While Large Language Models (LLMs) advance 3D indoor scene synthesis, current pipelines fail to retain user-specific preferences across sessions, making immersive authoring a repetitive and physically fatiguing process. We present SPHERE, an adaptive VR generation framework that transforms isolated synthesis into continuous human-AI co-creation. SPHERE extracts persistent spatial preferences from natural multimodal interactions (speech and controller edits). To ensure geometric resilience against spatial distortions, it abstracts these raw edits into hierarchical constraints modeling both local functional and global topological contexts. Furthermore, a human-in-the-loop reinforcement learning mechanism dynamically updates retrieval policies based on the user's final edited scenes. A mixed-design user study ($N=42$) and an offline ablation demonstrate that SPHERE significantly reduces corrective edits and physical demand, preventing bias toward shallow object-level traits to yield geometrically resilient, profile-aligned layouts. Ultimately, SPHERE demonstrates how capturing demonstrated spatial logic enables controlled spatial adaptation, establishing a reliable, governed human-AI collaboration framework for immersive authoring. Project page and source code will be available at: https://github.com/hyeonmin11/SPHERE

# SPHERE 论文结构化总结

> **核心概括：**SPHERE 将用户在 VR 中的语音指令和空间编辑转化为可跨会话复用的偏好记忆，并学习“下一次生成时应检索哪些偏好”。其主要价值不是提出新的基础 3D 生成模型，而是为现有生成引擎增加**层级空间理解、持续个性化和交互反馈闭环**。现有证据支持短期、受控的画像适应，尚不足以证明开放环境中的长期个性化能力。

## 1. 核心问题与整体含义

### 1.1 研究背景与动机
- LLM 驱动的室内场景生成系统已能根据自然语言选择物体、安排布局，但通常将每次生成或编辑视为独立任务。
- 用户此前表达过的偏好，例如“沙发始终朝向电视”“保留中央通道”，往往不会在下一次生成中被保留，导致重复修正。
- 在 VR 中，这些重复操作不仅增加时间和认知成本，还涉及移动、指向与精确摆放，容易造成身体疲劳。
- 直接记录绝对坐标或简单物体属性，也难以适应房间缩放和长宽比变化：原布局可以被复制，却未必保留其功能逻辑。

### 1.2 论文要解决的问题
SPHERE 关注三个相互关联的问题：
1. **偏好持久化：**如何从自然编辑行为中提取可复用的用户偏好？
2. **空间迁移：**如何使偏好在不同房间尺寸与形状下仍然有意义？
3. **选择性应用：**如何根据后续反馈，学习哪些历史偏好适合当前生成任务？

整体上，论文试图把“一次生成、反复纠错”的流程，转变为“生成—编辑—记忆—再生成”的持续人机共创。

## 2. 方法论：核心思想与技术流程

### 2.1 系统基础与总体流程
- **生成引擎：**Holodeck，负责房间感知、物体选择和约束驱动布局。
- **资产库：**Objaverse。
- **交互环境：**Unity/VR，与生成端维护的 JSON 场景图进行双向同步。

完整流程为：
1. 根据当前指令和检索出的历史偏好生成初始场景。
2. 用户通过语音和控制器修改场景。
3. 会话结束后，从最终场景和完整交互日志提取层级偏好。
4. 检查本轮采用的偏好是否在最终场景中实现。
5. 根据反馈更新检索重排序策略，影响下一轮生成。

### 2.2 多模态编辑与意图解析
- 使用 **Whisper** 将语音转写为文本。
- 控制器提供目标物体及空间位置，并保留选择顺序。
- LLM 将“把它移到这里”等指代表达解析为明确指令，再拆分为原子操作：
  - 添加、移动、旋转、缩放、灯光调整、删除。
- 添加物体时，通过 **CLIP 相似度**匹配指令与 Objaverse 资产的 GPT-4V 标注。

这里的“确定性执行”主要指：解析后的操作由固定场景算子执行；不意味着前面的 LLM 意图解析不会出错。

### 2.3 层级空间偏好记忆
论文不只保存物体属性，而是构建三个层次的偏好：

| 层次 | 内容 | 示例 |
|---|---|---|
| 物体级 | 类别、颜色、数量等属性 | 偏好单色家具、减少物体数量 |
| 区域内部级 | 功能组内的空间关系 | 座椅朝向电视、椅子与桌子配合 |
| 区域之间级 | 功能区之间及其与房间的关系 | 保留通道、工作区方便访问储物区 |

**局部情境：**
- 对物体的 XZ 平面坐标使用 **DBSCAN** 聚类，识别空间分组。
- 利用包围盒、朝向等几何信息计算支撑、对齐关系。
- LLM 根据物体类别赋予“座位区”“工作区”等功能标签，并推断功能可供性，例如灯具为桌面提供照明。

**全局情境：**
- 将各功能区抽象为功能标签、中心点和空间范围。
- 根据区域间距离判断邻接关系。
- 检查区域间直线路径是否无障碍且具有足够通行宽度。
- LLM 进一步推断跨区域功能依赖，例如工作区需要便捷访问储物区。

最终，偏好以“自然语言功能说明＋符号约束”存储。约束采用三元组形式，关系包括近、远、左右、前后、上方、朝向和中心对齐等。

**重要边界：**关系化表示比直接复制坐标更灵活，但部分约束仍依赖欧氏距离和全局坐标轴；论文未充分说明这些阈值如何随房间尺度归一化。

### 2.4 人在回路的检索策略优化
系统采用两阶段检索：
- 使用冻结的 **GTE 文本编码器**检索语义相关的历史场景。
- 使用交叉注意力重排序器优化候选排序，再通过带 Gumbel 噪声的随机采样选择场景与具体偏好。

反馈与更新机制：
- 视觉语言模型查看最终场景的俯视正交图，判断所选偏好是否实现。
- 实现记为正反馈，未实现或被用户修改掉记为负反馈。
- 奖励同时考虑实现结果和语义相关度：成功且相关的偏好获得奖励；失败但语义接近的候选受到较轻惩罚。
- 使用政策梯度更新重排序器，并通过 **LoRA** 实现轻量参数调整；GTE 保持冻结。
- 下一轮将检索到的偏好约束与 Holodeck 原有约束合并，指导生成。

因此，它更接近**用户编辑提供间接反馈、视觉模型评估结果的检索策略学习**，而不是用户直接评分、再训练基础生成模型的传统 RLHF。论文所称“无需完整模型微调”，也不等于完全没有参数训练。

- 并非所有画像都受益：社交连接型画像下，完整方法的对齐率低于基线。

- **问题贴近 VR 使用成本：**将重复编辑与身体负担纳入核心评价，而不只关注视觉质量。
- **利用自然行为反馈：**无需额外频繁评分，较少打断创作流程。
- **层级表示具有解释性：**从“喜欢什么物体”进一步推断“物体如何配合、区域如何组织”。
- **偏好记忆与生成模型解耦：**复用现有生成引擎，重点优化检索策略，部署思路较灵活。
- **会话末更新合理：**避免把临时试摆直接当作稳定偏好，也减少实时推理对 VR 交互的干扰。
- **评测具有多维度：**结合编辑次数、工作负荷、可用性和几何扰动。
- **结论保留部分边界：**论文明确承认固定画像与真实长期个性化之间的差距。

## 8. 不足与局限

### 8.1 反馈与偏好学习的偏差
- 最终保留某种布局，不一定意味着用户喜欢它，也可能是时间限制、操作困难或妥协。
- 视觉语言模型主要读取俯视图，对颜色、光照、垂直支撑、遮挡和细粒度朝向的判断能力有限。
- 二元反馈难以区分部分满足、主动拒绝和生成失败。
- 论文将奖励称为“确定性”，但实现判断依赖模型推断，仍可能带有误判和随机性。

### 8.2 空间表示与冲突处理
- DBSCAN 依赖密度和距离参数，其跨尺度稳定性未充分交代。
- 直线通行检测不能完整反映存在转弯路径的真实可达性。
- 基础约束与偏好直接合并，不保证它们相容；系统缺少明确的优先级和约束松弛机制。
- 极窄空间中可能无法同时满足所有偏好，需要物体删减、替换或软约束，但这些主要仍是未来工作。

### 8.3 评价可靠性与应用范围
- 离线对齐评价依赖 GPT-4，可能受到生成与评估模型相似偏好的影响。
- 人工层次标注的一致性仅报告 κ>0.560，可靠性仍需更广泛验证。
- 对齐率最高也只有约一半，说明偏好提取仍存在较大改进空间。
- 指向控制不精确会增加重复调整，使编辑次数不能完全代表生成质量。
- 没有纵向研究、跨房间类型迁移或真实自由偏好任务，也未充分评估偏好漂移、矛盾和遗忘。
- 语音、行为日志和长期偏好记忆涉及隐私；用户查看、纠正、撤销或删除记忆的治理机制讨论不足。

**综合评价：**SPHERE 是一个有价值的系统级探索，较有说服力地展示了“层级偏好记忆能减少受控 VR 创作中的重复修正”。不过，强化学习模块的独立收益、几何迁移的普遍性、真实长期个性化及实际部署成本，仍需更强基线、更细消融和纵向实验验证。
