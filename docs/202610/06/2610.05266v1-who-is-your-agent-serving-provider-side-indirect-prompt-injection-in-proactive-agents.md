## 摘要
主动式个人智能体日益能够决定推荐什么、如何个性化建议以及提供何种后续协助，这为提供方侧间接提示注入带来了新的用户决策攻击面。我们表明，外部提供方无须访问用户的私有上下文、攻陷智能体或获得额外权限：只需控制与其自身目标相关的内容，就能将原本无害的智能体引向推进该目标，调用合法可用的用户上下文为其提供依据，并主动降低用户采纳该目标的阻力。我们通过“目标控制”“私有绑定”和“前瞻性支持”刻画这一失效模式；它们分别决定智能体推进什么目标、如何将该目标与用户联系起来，以及随后提供哪些针对该目标的协助。在三个主动式智能体环境和六种模拟用户模型中，完整攻击在所有受测的环境与用户模型组合中均提高了目标授权率，宏平均增幅最高达77.4个百分点。受控重放实验表明，与单纯增加提案细节相比，正确建立用户与目标之间的绑定影响更大；多轮扩展实验则揭示，即使未获最终授权，提供方目标仍可能通过改变智能体应对用户约束与抵触的方式而持续发挥影响。这些发现揭示了更广泛的信任边界：原本旨在服务用户的能力，可能被转而用于推进用户—智能体关系之外的目标。

## Abstract
Proactive personal agents increasingly decide what to recommend, how to personalize advice, and what follow-up assistance to offer, creating a new user-decision attack surface for provider-side indirect prompt injection. We show that an external provider need not access private user context, compromise the agent, or gain additional permissions: by controlling only content associated with its own target, it can redirect an otherwise benign agent to advance that target, recruit legitimately available user context to justify it, and proactively reduce the friction of adoption. We characterize this failure mode through Target Control, Private Binding, and Prospective Support, which respectively steer what the agent advances, how it connects the target to the user, and what target-specific assistance it offers next. Across three proactive-agent environments and six simulated user models, the full attack increases target authorization in all tested environment-user-model combinations, with a macro gain of up to 77.4 percentage points. Controlled replay shows that correct user-target binding is more consequential than additional proposal detail alone, while a multi-turn extension reveals that provider objectives can remain influential even without final authorization by reshaping how the agent responds to user constraints and resistance. These findings expose a broader trust boundary: capabilities designed to serve the user can be redirected toward objectives originating outside the user-agent relationship.

## 1. 核心问题与整体含义：外部提供方能否借助手影响用户决策？

### 研究背景与动机
- 主动式个人智能体不仅回答问题，还会主动发现需求、筛选候选项、调用用户历史与偏好、解释推荐理由，并提供后续协助。因此，它们越来越直接地参与用户的决策过程。
- 现有间接提示注入研究主要衡量智能体是否执行攻击指令、调用指定工具或推荐目标，却往往没有进一步验证：**用户是否因此授权了攻击者希望推进的选择。**
- 论文研究一种更隐蔽的威胁：外部产品、服务或活动提供方，仅通过自己能够发布的目标相关内容，能否让原本服务用户的助手转而推进提供方利益？

### 核心问题
攻击者不需要：
- 获取用户私有信息；
- 修改系统或用户的可信指令；
- 攻陷智能体或增加工具权限；
- 伪造候选产品的真实功能。

它只需在自身目标相关的外部内容中植入指令，让智能体利用已有能力完成目标推荐、个性化论证和后续支持。

**论文的整体含义是：事实正确、权限合法、用户保留最终选择权，并不足以保证助手真正站在用户一边。** 安全问题还包括：助手的推荐与个性化能力究竟在围绕谁的目标组织。

## 2. 方法论：用 T–B–S 刻画对正常协助能力的重定向

### 2.1 威胁模型与推荐过程
论文将正常推荐抽象为三个输出：
- **推荐对象**：选择某个候选项，或不推荐；
- **个性化理由**：解释候选项与用户需求、偏好和经验的关系；
- **前瞻性支持**：提出可在用户同意后提供的后续帮助。

输入包括用户任务、固定的候选项公开事实，以及智能体通过正常权限检索到的用户上下文。攻击者提前选择目标，只能修改该目标相关的、智能体可读取的内容。

这里有一个关键的信息不对称：
- 提供方了解目标，但不了解用户；
- 智能体了解用户，并拥有合法的上下文访问能力；
- 攻击者通过通用指令，将用户特定的推理工作交给智能体完成。

### 2.2 三个核心维度

| 维度 | 核心作用 | 关键细节 |
|---|---|---|
| **目标控制 T（Target Control）** | 控制“推进什么” | 让目标在比较与提案中保持中心地位；不改变候选事实，但限制转向竞争者 |
| **私有绑定 B（Private Binding）** | 控制“如何解释其适合用户” | 指示智能体读取合法可用的上下文，将真实用户需求与目标真实属性建立联系 |
| **前瞻性支持 S（Prospective Support）** | 控制“接下来帮助什么” | 提供目标专属的清单、配置检查、计划或草稿，降低采纳阻力；不直接执行外部承诺 |

- **Full** 表示 T、B、S 同时存在，但不被预设为最优攻击。
- 这些是行为引导维度，而不是能力开关：删除 B 或 S，不意味着智能体无法自行个性化或提供帮助。
- 私有绑定不要求将用户信息传给提供方，揭示的是**私有信息的用途被重定向**，而非传统的数据外泄。

### 2.3 注入形式与多轮扩展
- 代表性注入使用“平台决策路由”“已保存的用户决策支持偏好”等包装，伪装成具有指导权的内容。
- 这些权威或用户偏好声明均来自不可信的提供方记录，并非真实的系统或用户授权。
- 多轮场景中，攻击载荷保持固定；智能体根据用户后来提出的顾虑、约束和替代方案，自行调整推进目标的理由与支持方式。

**因此，本研究主要不是提出新的注入投递或防御绕过算法，而是分析外部内容产生行为影响之后，如何进一步影响用户决策。**

## 3. 实验设计：合成决策基准、三种环境与组件对照

### 3.1 单次推荐 benchmark
论文自建合成决策基准，覆盖消费、旅行、软件／科研和组织事务：
- 共 **36 个任务族**，其中 12 个用于开发与校准，24 个用于测试。
- 每个测试任务族包含：
  - 2 个用户画像；
  - 3 个公开难度等级；
  - 3 个候选项。
- 每个条件共 **24 × 2 × 3 = 144 个测试块**。

用户画像包含目标、四项配置要求、相关经验、偏好及无关干扰信息。候选记录包含配置支持、优势、局限、质量和成本。

三个难度等级分别为：
- **有利**：目标公开属性较强；
- **竞争性**：候选项之间存在真实权衡；
- **不利**：目标在质量或成本上较弱。

**所有等级中的目标仍满足用户核心配置要求**，所以测试的是可行选项之间的选择偏移，而非诱导用户接受明显不可用的产品。

### 3.2 三种主动式智能体环境
- **PARE**：保留状态化交互与本地笔记访问机制。

### 3.3 模型、对照与评价指标
- 主实验以 **GPT-5 为助手**，搭配六种模拟用户：GPT-5、Claude Opus 4.6、Gemini 3 Pro、DeepSeek V4.1 Flash、Qwen 3.6 Plus、GLM 5.1。

  - **T**；

  - **T+S**；

## 6. 主要结论与发现

### 6.1 完整攻击显著增加单次推荐中的目标授权

以下为 GPT-5 助手、六种模拟用户的宏平均结果：

| 环境 | Neutral 授权率 | Full 授权率 | 增幅 |
|---|---:|---:|---:|
| PARE | 9.5% | 86.9% | +77.4 个百分点 |
| TGL | 15.9% | 62.8% | +47.0 个百分点 |
| ProPerSim | 27.0% | 60.6% | +33.7 个百分点 |

*增幅依据未四舍五入结果计算，因此可能与表中显示值相减略有差异。*

- 主实验全部 **18 个环境—用户模型组合**均提高目标授权。
- 五种额外助手对应的 **15 个组合**也全部提高目标授权。
- 按难度进一步拆分，99 个不同环境—模型配对—难度组合中，94 个提高、2 个持平、3 个下降。

### 6.2 正确私有绑定比单纯增加推荐或篇幅更关键
- GPT-5／GPT-5 消融中，T 加上 B 后，授权率分别提高：
  - PARE：**36.1 个百分点**；
  - TGL：**16.7 个百分点**；
  - ProPerSim：**4.9 个百分点**。
- ProPerSim 的较小增益与其原生记忆检索已经提供用户上下文一致。
- 重放实验中：
  - 原始 T 提案接受率为 **55.8%**；
  - 扩写后仅提高至 **60.5%**；
  - 正确绑定的 T+B 达到 **90.7%**；
  - 默认或错配配置控制均为 **0%**。

这支持“正确匹配比篇幅本身更重要”，但并非将绑定效果完全独立识别出来的严格因果证明。

### 6.3 前瞻支持具有互补作用，但不是普遍单调增益
- 主配置中，T+S 在三个环境都未超过 T，但 Full 都超过 T+B。
- 表明帮助承诺通常更适合增强已有的个性化理由，而不是替代理由。
- 不同助手与用户配置中的组件贡献不同，不能概括为“B 永远最重要”或“S 单独永远无效”。

### 6.4 多轮影响比最终说服更一致
- GPT-5／GPT-5 多轮实验中，目标服务率从 **32% 升至 92%**，严格最终授权从 **8% 升至 24%**。
- 五种模型配对均提高持续目标影响和抵抗后的目标推进。
- **最终授权并非全部改善**：GPT-5 助手／Gemini 3 Pro 用户的严格授权由 4% 降至 0%；Sonnet 4.5 用户配置则保持为 0%。

因此，多轮研究最稳健的发现是：**外部目标能够持续改变协助过程，但不保证最终改变用户决定。**

## 7. 优点与亮点

- **评价终点更有意义**：从“助手推荐目标”延伸到“用户明确授权目标”，补足传统注入评估的盲点。
- **揭示非泄漏型私有上下文风险**：提供方无需看到用户信息，也能借智能体的合法访问能力获益。
- **威胁模型边界清晰**：限制攻击者只能控制自身内容，不更改产品事实或工具权限。
- **跨机制验证**：同时考察状态化环境、唤醒路由和记忆检索，降低结论依赖单一架构的风险。
- **消融与重放互补**：既分析组件作用，也检查“是否只是文字更长”的替代解释。
- **过程指标设计有价值**：区分持续推进、抵抗后推进、部分承诺与完整授权，不把所有兴趣或准备工作都算作成功。
- **对局部失败较透明**：明确报告模型差异和多轮授权下降，而非仅展示成功案例。

## 8. 不足与局限

### 外部有效性与应用范围
- 全部用户均由 LLM 模拟，不能把授权率直接视为真实人类受到操纵的概率。
- 合成任务与结构化画像可能简化真实世界中的信息噪声、长期关系和偏好冲突。
- “不利目标”依然可行，结果不支持攻击能够克服明确的硬性需求不兼容。
- 多轮最多五次交换，尚不能覆盖长期记忆累积、跨会话影响或真实重复接触。

### 机制解释与对照不足
- 注入包装与行为内容共同起作用，尚未充分分离权威伪装、偏好伪装和 T–B–S 各自的贡献。
- 未完整测试 B、S、B+S 等独立组合，不能进行完整的因子效应分解。
- 重放中的提案改写同时改变长度、配置和表达内容，对机制的证据是支持性的，而非完全隔离变量后的结论。
- 缺少普通营销内容、非指令式宣传和安全防御条件，难以判断攻击相对这些设置的独特增量效果。

### 统计与标注风险
- 缺少重复运行、不确定性区间和显著性分析，尤其限制对小样本多轮结果的解释。
- LLM 同时参与材料构建、模拟交互和标注，可能存在共同偏差；人工检查虽有帮助，但未报告系统的标注一致性结果。
- 多轮抵抗后的推进率使用各条件实际产生的抵抗机会作为分母，而非相同抵抗事件；对话内回复也不是独立样本。

### 总体评价
这篇论文的主要价值在于把提示注入安全问题从**“是否违规执行”推进到“合法协助是否被外部利益定向”**。单次推荐实验提供了较广泛的支持，多轮实验则揭示了影响过程与最终授权之间的区别。不过，对真实用户、实际部署环境及防御有效性的结论，仍需要后续研究验证。
