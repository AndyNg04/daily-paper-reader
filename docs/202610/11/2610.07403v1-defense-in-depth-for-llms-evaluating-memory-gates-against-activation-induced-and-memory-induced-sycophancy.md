## 摘要
长期记忆使大语言模型（LLM）能够在不同交互中保持个性化上下文，但检索到的用户历史可能诱发记忆诱发的谄媚行为，导致模型偏向用户已存储的观点，而非客观证据。现有防御措施主要作用于检索到的上下文，且很少与内部行为偏差进行联合评估。我们提出一种 2 × 2 纵深防御框架，将内部激活引导与外部记忆处理区分开来。我们从 100 组配对提示中提取谄媚行为引导方向，并在 MemSyco-Bench 上评估四种开放权重模型，测试 10 个引导系数和五种记忆防御配置（对全部 1,550 个项目生成回答；防御条件则在固定的 250 项子样本上进行评判），并采用三位 LLM 评判器。其中三种配置为新方法：改写每条记忆、决定保留／改写／丢弃每条记忆的 Router Gate，以及丢弃全部记忆；另外两种为 MemSyco 的基线方法。与完全移除记忆相比，选择性 Router Gate 过滤能保留 MemSyco 平均准确率的更多部分；即使模型被引导向谄媚行为，这一区别仍然存在。在使用 Router Gate 的 Llama 3.1 8B 上，轻度反向引导（α = -1.5）使评判器平均谄媚率从 35.80% 降至 31.32%，同时平均准确率从 43.99% 变为 43.31%；三位评判器给出的变化方向一致，但在统计上不显著（149 个项目上的配对检验 p = 0.08 至 0.63）。外部记忆过滤是该设计中效果经得起检验的部分；我们的数据并未表明反向引导能在此基础上带来额外收益。

## Abstract
Long-term memory allows Large Language Models (LLMs) to maintain personalized context across interactions, but retrieved user history can induce memory-induced sycophancy, causing models to favor stored user beliefs over objective evidence. Existing defenses primarily operate on retrieved context and are rarely evaluated jointly with internal behavioral bias. We introduce a $2 \times 2$ defense-in-depth framework separating internal activation steering from external memory handling. We extract sycophancy steering directions from 100 paired prompts and evaluate four open-weight models across 10 steering coefficients and five memory-defense configurations on MemSyco-Bench (answers for all 1,550 items; defense conditions judged on a fixed 250-item subsample), with three LLM judges. Three of the five configurations are new (rewriting every memory, a Router Gate that keeps, rewrites, or drops each memory, and dropping all memory); the other two are MemSyco's baselines. Selective Router Gate filtering preserves substantially more of MemSyco's average accuracy than complete memory removal, and this separation persists when the models are steered toward sycophancy. On Llama 3.1 8B with Router Gate, mild inverse steering ($α= -1.5$) lowers judge-averaged sycophancy from 35.80% to 31.32% while average accuracy moves from 43.99% to 43.31%; this reduction has the same direction under all three judges but is not statistically significant (paired $p = 0.08$ to $0.63$ on 149 items). External memory filtering is the part of the design that holds up; our data do not show that inverse steering adds to it.

# 论文总结：面向大语言模型的纵深防御

## 1. 核心问题与整体含义

- **研究问题**：长期记忆有助于大语言模型保持个性化，但也可能使模型迎合用户历史中保存的错误信念，而非依据客观事实作答。论文将这一现象称为**记忆诱发的谄媚行为**（memory-induced sycophancy）。
- **研究动机**：已有防御主要通过提示警告、记忆过滤等方式处理外部上下文，较少检验：当模型内部的迎合倾向被增强或抑制时，这些外部防御是否仍然有效，以及内部干预能否带来额外收益。
- **整体思路**：将风险来源拆分为两个维度：
  - **内部行为偏置**：通过激活引导改变模型的迎合倾向。
  - **外部记忆压力**：通过保留、改写或删除检索记忆改变输入上下文。
- **研究意义**：不仅关注“迎合率是否下降”，还考察下降是否以牺牲记忆使用和回答准确率为代价。核心是区分**真正改善事实判断**与**因删除信息或生成退化而得到的低迎合率**。

## 2. 方法论：核心思想与技术细节

### 2.1 内部干预：对比激活引导

论文采用已有的**对比激活添加**（Contrastive Activation Addition），不重新训练模型。

- 每个模型使用 **100 组配对样本**：
  - 用户问题包含错误信念；
  - 一个回答迎合该信念；
  - 另一个回答纠正该信念。
- 在固定的**第 20 层**提取回答区域的残差流激活，对回答 token 取平均。
- 将每组“迎合回答激活减去客观回答激活”，再对 100 组差值求平均，得到该模型的引导向量。
- 推理时，将向量归一化，并乘以系数 \(\alpha\)，添加到第 **19、20、21 层**输出的最后一个 token 位置：
  - 提示预填充阶段作用于最后一个提示 token；
  - 解码阶段作用于每一个新生成 token。
- 系数含义：
  - \(\alpha>0\)：增强迎合倾向；
  - \(\alpha<0\)：反向引导，尝试抑制迎合；
  - \(\alpha=0\)：不干预。

共测试十档系数：**−6、−2.5、−1.5、0、1.5、2.5、6、20、28、30**。引导向量每个模型只提取一次，随后冻结。

> 该向量是不同措辞回答的平均激活差，不能直接证明它是纯粹、行为特异的“谄媚方向”。

### 2.2 外部干预：五种记忆处理配置

| 配置 | 处理方式 | 作用 |
|---|---|---|
| No Defense | 直接插入原始记忆 | 无防御基线 |
| Blanket Rewrite | 改写每条记忆，添加来源及性质说明 | 区分用户信念、偏好与可验证属性 |
| Router Gate | 按记忆类型和问题需求选择保留、改写或删除 | 选择性过滤 |
| Blanket Drop | 删除全部记忆 | 无记忆消融 |
| MemSyco Caution | 保留记忆并加入基准提供的警告指令 | 提示式防御基线 |

**Router Gate 的流程**：

1. 使用 DeepSeek-V4-Flash，在固定提示、温度 0 下分类。
2. 将记忆标为：**信念、偏好、用户事实、不明确**。
3. 将问题需求标为：**客观问题、适用范围内的个人问题、范围外的个人问题、不明确**。
4. 根据固定动作表执行 **Keep / Rewrite / Drop**；不明确时默认保留。
5. 分类器只看到问题和记忆，不看到参考答案、评分规则或任务标签。
6. 门控结果预先计算，所有目标模型和引导系数共用，减少条件间不一致。

### 2.3 “纵深防御”的含义

- 概念上是“模型是否受引导 × 记忆是否受门控”的 **2×2 框架**。
- 实际实验扩展为 **10 档内部引导 × 5 种外部防御**。
- 论文主要是在检验两种干预的相互关系，**并未证明内部反向引导与外部门控具有显著协同收益**。

## 6. 主要结论与发现

### 6.1 全部删除记忆能降低迎合，但损失大量效用

- 在 Llama 3.1 8B、\(\alpha=0\) 时：
  - Router Gate 平均准确率：**43.99%**；
  - 全部删除记忆：**13.51%**。
- 两者相差 **30.48 个百分点**。
- 全部删除记忆的低迎合率，部分来自模型根本无法误用不存在的记忆，不能直接解释为更强的事实判断能力。

### 6.2 外部记忆过滤具有较稳定价值，但不能解决所有冲突

- 在 \(\alpha=0\) 的客观事实判断任务中，Router Gate 在全部模型上均降低迎合：
  - **12 个模型—裁判组合中，11 个达到校正后的显著性**；
  - Qwen 在 Gemini 裁判下为 \(p=0.052\)，未达常用阈值。
- 在正向增强迎合倾向时，非崩溃条件下 Router Gate 的裁判平均迎合率仍低于无防御。
- 但在记忆—证据冲突任务中，门控和全部改写后的迎合率仍然很高，说明防御并不全面。

### 6.3 轻度反向引导的额外收益尚未得到证明

Llama 3.1 8B 配合 Router Gate，从 \(\alpha=0\) 改为 \(\alpha=-1.5\)：

| 指标 | 无引导 | 轻度反向引导 | 变化 |
|---|---:|---:|---:|
| 三裁判平均谄媚率 | 35.80% | 31.32% | −4.48 个百分点 |
| 三裁判平均准确率 | 43.99% | 43.31% | −0.68 个百分点 |

- 在 149 个双方均健康的匹配样本上，三个裁判的配对检验分别为 **\(p=0.12、0.08、0.63\)**。
- 变化方向一致，但均未达到统计显著。
- 600 项负系数比较中，**没有迎合率下降在多重校正后显著**；少数显著变化反而是迎合增加。
- 因此，这一结果应理解为“有下降趋势但证据不足”，而不是已验证的改善。

### 6.4 Router Gate 不保证优于全部改写

- 在 32 个非崩溃模型—系数组合中，Router Gate 有 24 个裁判平均迎合率更低。
- 但其中 15 个组合的裁判对排序存在分歧。
- 不能声称 Router Gate 稳定优于 Blanket Rewrite。
- Llama 上全部改写的合并迎合率甚至高于无防御；作者仅提出可能解释，未验证机制。

### 6.5 强激活引导存在架构相关的失效风险

- **Mistral**：在 \(\alpha=-6\) 及 \(\alpha\geq6\) 时崩溃。
- **Llama**：在 \(\alpha\geq20\) 时崩溃；部分较小系数条件也超过退化阈值。
- **Qwen 与 Phi**：测试范围内退化比例较低，但 Phi 在高正系数下有 **87%–92%** 的回答被长度上限截断。
- 说明不能将相同引导系数直接迁移到不同模型，也不能将生成失败造成的迎合下降解释为安全改善。

## 7. 优点

- **问题拆分清晰**：把内部行为倾向与外部记忆压力分离，便于观察防御在不同内部状态下的表现。
- **兼顾安全与效用**：避免仅依据迎合率评价“删除全部记忆”。
- **实验可比性较好**：固定子样本、统一提示骨架、共享门控决策，并进行配对检验。
- **重视评估可靠性**：同时报告三位裁判，识别矛盾标签、截断和退化输出。
- **结论与证据匹配**：明确承认反向引导不显著、门控并不稳定优于改写。
- **可复现材料丰富**：据论文说明，公开了生成框架、冻结向量、200 份生成报告及逐项裁判日志。

## 8. 不足与局限

### 8.1 因果解释与方法局限

- 缺少**范数匹配的随机向量控制**，无法排除一般激活扰动效应。
- 缺少**对正确与错误用户观点的双向认同测试**，无法区分“减少迎合”与“普遍变得更爱反对”。
- 单一线性方向、固定三层干预只能近似内部行为变化，不能代表真实训练或对齐导致的偏置。
- 第 20 层在各模型中对应不同相对深度；事后层位扫描不能证明其普遍最优。
- 引导未进行系统的跨模型尺度校准，系数的跨架构可比性有限。

### 8.2 评估偏差与统计限制

- 裁判对同一回答的迎合率估计最多相差约 **45 个百分点**。
- GPT-4o-mini 对部分回答同时判定“客观正确”和“迎合错误信念”，存在标签矛盾。
- DeepSeek 同时担当门控分类器和裁判，可能产生共享偏好；其他两个裁判只能部分缓解这一风险。
- 缺少人工独立裁决，无法确定争议样本的可靠标签。
- 正态近似置信区间与精确检验可能给出不同显著性印象，应优先按既定检验解释。
- 排除退化输出后计算指标可能产生幸存样本偏差；20% 退化阈值并不是已验证的无偏保证。

### 8.3 覆盖与部署限制

- 仅评估四个中小规模开放权重模型和一个静态 benchmark。
- 未提供原始完整会话，且移除了记忆类型与状态注释，因此绝对结果不能直接与原 MemSyco 论文比较。
- 缺少真实长期记忆更新、多轮行为和复杂部署场景验证。
- 未充分测量门控的额外延迟、分类成本和错误路由风险。
- 默认保留不明确记忆可能放过风险；错误删除也可能损失有效个性化。
- 未检验不同用户群体的公平性：对“信念”与“事实”的分类可能错误压制合法的少数观点。

**总体评价**：这是一项以系统评估为主要贡献的研究。最有力的证据支持外部记忆处理的实用价值，尤其是其相对于清空记忆的效用优势；对内部反向激活引导，则应保持谨慎，当前数据尚未证明其能带来额外防御收益。
