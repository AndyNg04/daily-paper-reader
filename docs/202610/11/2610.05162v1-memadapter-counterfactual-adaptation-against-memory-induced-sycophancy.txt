ABSTRACT 

Long-term memory enables LLM-based agents to retain and reuse information across tasks and sessions, supporting personalization and long-horizon interac-tions. However, persistent memories can also induce sycophancy, causing agents to over-align with users’ historical beliefs even when they are inaccurate, outdated, or inconsistent with objective evidence. Existing mitigation methods assume that memory-induced sycophancy originates from biased or incorrect memories and attempt to reduce this risk by filtering such memories at different stages of the memory pipeline. However, in the real world, objective and correct memories can still induce sycophancy, and the same memory can warrant different influ-ence across different contexts. To this end, we propose MemAdapter, a novel framework that adaptively integrates retrieved memories to support objective and reliable reasoning. Specifically, MemAdapter consists of three components: (i) Counterfactual Induction, which leverages counterfactual reasoning to uncover the potential risk of retrieved memories; (ii) Context-Aware Reflection, which calibrates the inferential influence of each retrieved memory in light of the cur-rent task via self-reflection; and (iii) Evidence-Based Reasoning, which grounds the final response in appropriate evidence while preserving the legitimate influ-ence of memory. Extensive experiments on three benchmarks demonstrate that MemAdapter consistently improves memory reliability across diverse scenarios. Our code is available at https://github.com/DEEP-JLU/MemAdapter .

1 INTRODUCTION 

Long-term memory has become a core component of LLM-based agents, enabling them to retain and reuse information across tasks and sessions. A typical memory system extracts useful informa-tion from historical interactions, store it in external memory banks, and retrieve relevant memories for new requests, thereby supporting personalization and long-horizon interactions (Zhong et al., 2024; Packer et al., 2023; Chhikara et al., 2025; Xiang et al., 2026b). However, long-term memory is not always beneficial. Historical information, such as past beliefs, stated preferences, and prior judgments, can be preserved across interactions and repeatedly reintroduced into subsequent reason-ing, giving rise to memory-induced sycophancy, where agents over-align with users’ historical views even when they are inaccurate, outdated, or inconsistent with the available evidence (Xiang et al., 2026a; Pulipaka et al., 2026; Chao et al., 2026). Memory-induced sycophancy is particularly severe in long-horizon tasks, where historical memories can persist beyond the interactions in which they were formed and be repeatedly retrieved across subsequent tasks and sessions (Mao et al., 2026). As a result, user influence that would otherwise be temporary or confined to a particular interaction can develop into persistent behavioral bias, undermining factuality and objective judgment. Several approaches have attempted to mitigate these issues by intervening at different stages of the memory pipeline. (i) At the extraction stage, several interventions have been proposed to reduce the persistence of misleading or outdated information by improving memory extraction, summarization, retention, and forgetting. Specifically, Recalling Too Well shows that lossy memory extraction can encode and amplify users’ erroneous beliefs, and that retaining assistant turns or using conversation

They as-sume that memory-induced sycophancy origi-nates from biased or incorrect memories and at-tempt to reduce this risk by filtering, suppress-ing, or restructuring such memories at different stages of the memory pipeline. However, this perspective overlooks two critical limitations in practice: (i) the risk of memory-induced syco-phancy is not fully observable at the level of memory content. An objectively correct and task-relevant memory may contain no apparent bias, yet still enable biased reasoning when it is reused under particular downstream conditions. The potential risk therefore lies not only in what the memory stores, but also in the ways it may be invoked in future reasoning. (ii) The influence of a memory is context-dependent: the same memory may be useful for personalization in one task but provide no valid basis for an objective decision in another. For example, as shown in Figure 2b, knowing that a user is a cardiologist may appropriately help an agent calibrate the technical level of its explanation. Yet when evaluating a treatment deci-sion, favoring the user’s judgment solely on the basis of this identity while discounting case-specific medical evidence may introduce sycophantic bias. The appropriateness of memory use is therefore not an intrinsic property of the memory itself, but a relational property determined by its interaction with the current reasoning context. Reliable memory use thus requires post-retrieval calibration: be-yond deciding which memories are available to the model, it must determine the role each memory should play and the degree of influence it should exert in the current reasoning process. To this end, we propose MemAdapter, a novel framework that adaptively integrates retrieved mem-ories to support objective and reliable reasoning. Specifically, MemAdapter consists of three com-ponents: (i) Counterfactual Induction, which leverages counterfactual reasoning to uncover the po-tential risk of retrieved memories; (ii) Context-Aware Reflection, which calibrates the inferential influence of each retrieved memory in light of the current task via self-reflection; and (iii) Evidence-Based Reasoning, which grounds the final response in appropriate evidence while preserving the legitimate influence of memory. Together, these components allow MemAdapter to regulate mem-ory use according to the reasoning context without modifying the upstream memory construction or retrieval process. 2 PRELIMINARY STUDY 

Before going into the technical details, we examine memory-induced sycophancy through two anal-yses. First, we conduct a controlled evaluation to test whether accurate and task-relevant memories can still induce sycophancy. Second, we analyze a fixed-memory case in which only the task context changes, to examine how the appropriate influence of the same memory varies across tasks. To-gether, these analyses show that memory risk cannot be determined from content alone, but depends on how the memory is used in context. Detailed experimental setup is provided in Appendix B. 2.1 ACCURATE AND RELEVANT MEMORIES CAN STILL INDUCE SYCOPHANCY 

A memory can be factually correct and task-relevant yet still induce sycophancy. To verify this, we construct test sets from MemSyco-Bench, PersistBench, and MemTrapBench containing only instances whose retrieved memories are accurate and highly relevant to the task, and compare model predictions with and without memory. As shown in Figure 2a, adding memory reduces overall ac-curacy from 96.0% to 77.3%. The same pattern holds across the three benchmarks, with accuracy decreasing from 96.0% to 68.0%, 100.0% to 84.0%, and 92.0% to 80.0%, respectively. More impor-tantly, among predictions that are correct without memory, 19.4% become incorrect after memory is introduced, and every such reversal follows the retrieved memory. This shows that the performance drop is driven by the memory rather than by simply adding more context. These results demonstrate that even accurate and relevant memories can introduce sycophancy, meaning that their potential risk cannot be judged from memory content alone. 2.2 THE SAME MEMORY WARRANTS DIFFERENT INFLUENCE ACROSS CONTEXTS 

How a memory should be used depends on the current task. To illustrate this, we analyze a case in which the retrieved memory remains unchanged while only the task context varies, as shown in Figure 2b. The shared memory states that the user is a cardiologist. When the user asks for an expla-nation of a new cardiovascular treatment guideline, this information can help the model adjust the response by using professional terminology, emphasizing clinically relevant distinctions, and omit-ting unnecessary introductory material. In contrast, consider a treatment-selection task in which the user prefers treatment A while patient-specific evidence supports treatment B. In this case, knowing that the user is a cardiologist may still help the model communicate with the user, but it should not affect which treatment is selected. If the model favors treatment A because of the user’s professional identity rather than the patient-specific evidence, the memory induces sycophantic behavior. This example shows that the same memory can shape how a response is presented in one task while hav-ing no basis for changing the conclusion in another. These observations suggest a broader principle: the safety of a memory is not an intrinsic property of its content, but depends on how it interacts with the downstream reasoning context. Therefore, memory-induced sycophancy should be viewed not only as a memory-quality problem, but also as a problem of how retrieved memories are used during reasoning. Reliable memory use requires separating potential risk from actual influence: an agent should first anticipate when a memory could become misleading, and then determine whether and how that risk applies given the current task and available evidence. This reframes memory management from selecting which memories to expose to the model toward adapting their inferential role after retrieval. The central challenge is thus not merely whether a memory should be available, but what it is justified to support, how strongly it should influence the response, and where that influence should be constrained. 

3 THE FRAMEWORK OF MEM ADAPTER 

In this section, we introduce MemAdapter in detail. As shown in Figure 3, MemAdapter con-sists of three components: (i) Counterfactual Induction , which leverages counterfactual reason-ing to uncover potential risks in using retrieved memories; (ii) Context-Aware Reflection , which determines how each retrieved memory should influence reasoning based on the current task and available evidence through self-reflection; and (iii) Evidence-Based Reasoning , which grounds the final response in task-relevant evidence while preserving the appropriate influence of memory. The complete procedures of the three components are provided in Appendix G. 3.1 COUNTERFACTUAL INDUCTION 

Memory-induced sycophancy is a conditional failure rather than a property that can be determined from memory content alone. The same memory may be harmless in one setting yet distort reasoning in another as the task objective or available evidence changes. Therefore, we formulate memory-risk identification as a counterfactual boundary-discovery problem: rather than asking whether a memory is globally safe, we ask under what downstream conditions its influence becomes inappropriate. By holding the memory fixed and systematically varying plausible task conditions, Counterfactual Induction turns otherwise hidden risks into observable differences across contexts. 4Preprint Specifically, for each retrieved memory mi, our objective is to uncover potential risks that are not directly observable from its content. We achieve this through counterfactual reasoning, in which we keep mi fixed, vary the downstream task conditions under which it may be invoked, and derive a conditional boundary from changes in its appropriate contribution across contexts. First, we construct a counterfactual task space to expose the range of downstream conditions un-der which the same memory may participate in reasoning. Specifically, for each mi, we identify a memory-specific set of task types from the content and scope explicitly stated in the memory and construct one or more concrete settings for each type. The content, provenance, and temporal scope of mi remain fixed throughout this construction. The resulting counterfactual task space is represented as

Counterfactual Induction reveals how the appropriate use of a memory can change across possible downstream conditions, but these cross-context boundaries do not directly determine how the mem-ory should be used in the current task. Context-Aware Reflection bridges this gap by adapting the identified risks to the current request and available evidence. Through self-reflection, it reassesses each retrieved memory in context and determines what role it should play, which parts of the rea-soning it may affect, and how strongly it should influence the response. Given the current request q, the model-visible context and available evidence c, the retrieved mem-ories M, and the conditional boundaries B, we first establish the decision or response required by 

q and identify the relevant evidence and constraints in c. We then examine each mi and Bi jointly with the retrieved set to determine the appropriate role and degree of influence of mi while ac-counting for updates, qualifications, and conflicts among memories. After the appropriate influence of each memory has been determined, the remaining challenge is to ensure that these constraints are respected during answer generation. In particular, information that is useful for personalization or response framing should not be implicitly promoted into evidence for factual claims or objective decisions. Evidence-Based Reasoning therefore grounds the final 5Preprint response in appropriate evidence while preserving the memory influence permitted by the task-specific instructions. Given q, c, the original memories M, and the task-specific influence instructions U, we jointly generate the answer y and an internal answer-support trace L:

(y, L) = REBR (q, c, M, U). (5) The support trace L makes the grounding process explicit by associating each major response span with its role, supporting source, and applicable memory-influence instruction. Before returning y,we verify that each recorded source is present and supports the corresponding response span, and that every use of memory remains within the scope specified by its instruction. The support trace is used only for internal verification, and only y is returned to the user. 4 EXPERIMENTS 

In this section, we evaluate MemAdapter from three complementary perspectives: overall effective-ness, cross-backbone generalization, and component contribution. The experiments are organized around the following research questions. RQ1 (Effectiveness). Compared with existing memory-use intervention methods, can MemAdapter improve memory-use performance across different benchmarks and memory systems? RQ2 (Cross-Backbone Generalization). Can MemAdapter maintain its effectiveness when applied to different backbone models and heterogeneous memory systems? RQ3 (Ablation Study). What are the respective contributions of Counterfactual Induction and Context-Aware Reflection to the overall performance of MemAdapter? 4.1 EXPERIMENTAL SETTINGS 

Datasets: We evaluate MemAdapter on three memory-use benchmarks: MemSyco-Bench, Mem-TrapBench, and PersistBench. (Xiang et al., 2026a; Wang et al., 2026; Pulipaka et al., 2026). MemSyco-Bench evaluates inappropriate memory use in sycophancy-related scenarios. MemTrap-Bench focuses on memory-induced cognitive traps, including reasoning fixation and belief dis-tortion. PersistBench evaluates long-term memory failures, including cross-domain leakage and memory-induced sycophancy. All task-specific metrics follow the official definitions and evaluation protocols of the corresponding benchmarks. 

Baselines: We evaluate MemAdapter with five memory systems: A-MEM, Mem0, NaiveRAG, MemoryBank, and LightMem. For each memory system, we first construct a corresponding memory-system baseline without any additional memory-use intervention. We then compare MemAdapter with four representative memory-use intervention methods: Anti-Sycophancy, Self-ReCheck, Dynamic Partition, and MemGate. All intervention methods are applied after memory retrieval and receive the same retrieved memory candidates under the corresponding memory sys-tem. The compared methods and their detailed configurations are described in Appendix A.2. 

Evaluation Metrics: All task metrics follow the official definitions and evaluation protocols of the corresponding benchmarks. For MemSyco-Bench, we additionally report Avg. Acc. , When to Use Memory , and How to Use Memory , all computed as sample-weighted averages. The exact aggregation formulas and further details on the datasets, task settings, evaluation objectives, task-specific metrics, and memory-use requirements are provided in Appendix D. 4.2 MAIN RESULTS

Overall, these results provide evidence that MemAdapter can improve several important aspects of memory use across heterogeneous benchmarks, while its effects vary by metric and memory system. 

Obs. 2: MemAdapter remains effective across the evaluated memory systems. The benefits of MemAdapter are observed with A-MEM, Mem0, NaiveRAG, MemoryBank, and LightMem, despite their heterogeneous memory construction and retrieval mechanisms. It also reduces the sycophancy failure rate on PersistBench under all five memory systems and improves the reasoning-fixation score on MemTrapBench under all five memory systems. 5 CONCLUSION 

In this paper, we identify a post-retrieval failure mode in long-term memory agents, where even accurate and relevant memories can be used beyond what the current task justifies, and the appro-priate use of the same memory can vary across reasoning contexts. Motivated by this, we propose 

MemAdapter , a novel post-retrieval adaptation framework that dynamically adjusts how retrieved memories participate in reasoning. Specifically, MemAdapter examines each memory under coun-terfactually constructed tasks to induce conditional-use rules, then evaluates these rules against the current task and available evidence to determine task-specific usage scopes, and finally generates the response according to the resolved scopes. Extensive experiments on MemSyco-Bench, Persist-Bench, and MemTrapBench demonstrate consistent improvements across different memory systems and backbone models, showing that explicitly adapting post-retrieval memory use can effectively im-prove the reliability of long-term memory agents without modifying the upstream memory system. 9Preprint AI USE STATEMENT

A EXPERIMENTAL PROTOCOL AND REPRODUCIBILITY 

We distinguish between memory systems and memory-use methods. A memory system deter-mines how historical interactions are represented, maintained, and retrieved, whereas a memory-use method determines how retrieved memories are processed when answering the query. MemAdapter operates strictly after retrieval and does not modify memory construction or retrieval results. A.1 COMPARED MEMORY SYSTEMS AND METHODS 

We evaluate MemAdapter with five representative memory systems: A-MEM, Mem0, NaiveRAG, LightMem, and MemoryBank. These systems differ in how they construct, organize, update, and retrieve long-term memory from historical interactions. Evaluating across these systems allows us to assess whether MemAdapter remains effective under substantially different memory representations and retrieval pipelines. A.1.1 MEMORY SYSTEMS 

A-MEM. A-MEM constructs an interconnected memory network from structured notes derived from historical interactions (Xu et al., 2025). Each note contains the interaction content together with contextual descriptions, keywords, tags, and links to related notes. When new information is added, the system can update existing note attributes and connections, allowing memory structure to evolve over time. We use the top-10 notes retrieved by A-MEM as memory context. 

Mem0. Mem0 maintains a persistent memory store by using an LLM to extract salient informa-tion from interaction history and determine whether stored memories should be added, updated, merged, or removed (Chhikara et al., 2025). The resulting memory entries are indexed for semantic retrieval, enabling the system to retrieve information relevant to the current query without supplying the complete dialogue history. We use the top-10 memories returned by Mem0. 

NaiveRAG. NaiveRAG is a retrieval-only baseline that stores raw dialogue chunks without ex-plicit memory abstraction, consolidation, or updating (Lewis et al., 2020). For a new query, it ranks historical chunks by vector similarity and directly provides the most relevant chunks to the genera-tion model. This baseline measures the effect of using raw retrieved dialogue evidence rather than an explicitly constructed memory representation. We use the top-10 retrieved dialogue chunks. 

LightMem. LightMem organizes memory through a lightweight multi-stage design inspired by the Atkinson–Shiffrin memory model (Fang et al., 2026a). It first filters and groups incoming inter-action information through sensory memory, consolidates topic-related content in short-term mem-ory, and periodically updates long-term memory through an offline sleep-time process. At inference time, the system retrieves relevant memories from this structured memory store and provides them to the generation model. 

MemoryBank. MemoryBank maintains long-term memory through continual storage, retrieval, and updating (Zhong et al., 2024). It summarizes past events and user characteristics into persistent memory records, while an Ebbinghaus-inspired mechanism adjusts memory strength according to elapsed time and memory importance. This design allows the system to retain salient user informa-tion while gradually weakening less important or infrequently reinforced memories. For each query, we use the relevant memories retrieved from the resulting memory bank. A.1.2 MEMORY -USE METHODS 

Unlike memory systems, memory-use methods operate after retrieval. They do not determine which memories enter the candidate set; instead, they determine whether and how the retrieved memories should influence the response. We compare MemAdapter with direct generation and four post-retrieval intervention baselines. 

Direct Generation. The direct-generation baseline provides the retrieved memories to the back-bone model together with the query and task context. It does not filter, reorganize, reinterpret, or 13 Preprint otherwise modify the retrieved memory context. Its performance therefore reflects the default be-havior of the backbone model when historical memories are appended to the generation prompt. 

Anti-Sycophancy. Anti-Sycophancy adds an explicit disclaimer to the generation prompt (Bensal et al., 2026). The disclaimer states that retrieved memories may contain opinions, preferences, or misconceptions rather than verified facts, and instructs the model to evaluate the current question as a neutral third-party observer. All retrieved memories remain available to the model; the intervention changes only the instruction governing how they should be interpreted. 

Self-ReCheck. Self-ReCheck is a lightweight, model-agnostic memory-filtering method designed to mitigate over-personalization (Hu et al., 2026). Before answer generation, it asks the model to reassess the relevance of each retrieved memory to the current query. Only memories judged relevant are retained in the final context, while the remaining memories are removed. Thus, Self-ReCheck controls memory use by selecting a subset of the retrieved memories rather than by specifying usage boundaries for each memory. 

Dynamic Partition. Dynamic Partition restructures the retrieved memory set into domain-based groups before generation (Hannoon et al., 2026). Rather than injecting memories as a flat list, it assigns each memory to a predefined domain or, when necessary, to a dynamically introduced cat-egory. The generation model receives the same memory content under domain headers, making the contextual relationship among memories more explicit while preserving every retrieved mem-ory. This method therefore reduces interference by changing the presentation structure rather than filtering memories out. 

MemGate. MemGate is a learned, query-conditioned memory-admission mechanism positioned between retrieval and prompt construction (Zhang et al., 2026). For each retrieved memory, it pre-dicts whether the memory should be admitted into the generation context while keeping both the backbone model and the memory store unchanged. We use the released implementation and pre-trained checkpoint, retaining memories whose gate scores exceed 0.07. Unlike prompt-based meth-ods, MemGate filters candidate memories through a learned gate and requires no additional LLM judgment during inference. A.2 RETRIEVAL AND FAIR -C OMPARISON PROTOCOL 

For memory-system comparisons, each system uses its native memory construction and retrieval pipeline. MemAdapter receives the memories returned by the corresponding system and regulates their use without modifying their content, order, or retrieval source. These experiments therefore evaluate whether MemAdapter remains effective across different memory representations and re-trieval mechanisms. All five memory systems use BAAI/bge-m3 as the embedding model, with an embedding dimen-sion of 1,024. For memory construction or memory-processing operations that require an LLM, we use deepseek-V4-flash . The evaluation wrapper applies a common retrieval budget to all systems: it retrieves the top 10 memories on MemTrapBench, whereas on PersistBench it retrieves the number of memories specified by each instance, ranging from 4 to 16. Thus, differences among systems arise from their memory representations and native processing procedures rather than from the embedding model or a system-specific retrieval budget. For completeness, we summarize the system-specific implementation settings in prose. A-MEM stores structured notes with keywords, descriptions, and tags; relation-based retrieval is disabled, with evo threshold =100 and query limit =40. Mem0 inserts memories verbatim on Persist-Bench with infer=False and uses persistent Qdrant storage. NaiveRAG stores raw memories without chunking or LLM-based processing and performs direct vector retrieval without reranking. LightMem applies topic segmentation, short- and long-term memory processing, and summary gen-eration, followed by Qdrant-based summary retrieval with extract threshold =0.1. Memory-Bank maintains date-based, personality, and global summaries and performs vector-score retrieval with date-based aggregation; forgetting and memory-strength updates are disabled. These settings are used consistently throughout the memory-system comparisons. 14 Preprint For memory-use method comparisons, all methods paired with the same memory system receive an identical frozen set of retrieved memories. For each benchmark instance and memory system, retrieval is performed once, and the resulting memory set is reused across all compared methods. The benchmark instance, current query, dialogue context, task-specific evidence, backbone model, decoding configuration, and evaluation protocol are kept identical across methods. MemAdapter preserves the retrieved memory set and applies three post-retrieval stages: Counterfac-tual Induction, Context-Aware Reflection, and Evidence-Based Reasoning. Therefore, performance differences among methods paired with the same memory system can be attributed to how they process and use the same retrieved memories rather than to differences in retrieval results. D DATASET DETAILS 

We evaluate MemAdapter on three benchmarks that examine post-retrieval memory use from com-plementary perspectives: MemSyco-Bench, MemTrapBench, and PersistBench Xiang et al. (2026a); Wang et al. (2026); Pulipaka et al. (2026). These benchmarks do not primarily evaluate whether a memory system can store or retrieve information. Instead, they evaluate whether retrieved memories are assigned an appropriate role in the current task. Across the three benchmarks, a model may need to determine whether a retrieved memory should be used, restricted to a particular scope, overridden by current evidence, updated in favor of a newer memory, or ignored because it is irrelevant or out-dated. The following sections summarize the benchmark composition, task definitions, evaluation metrics, and memory-use requirements. D.1 MEM SYCO -B ENCH 

MemSyco-Bench evaluates whether a memory-augmented agent can assign retrieved user memories appropriate decision authority: namely, whether the agent can determine when a memory should influence the current decision and how it should be used when memory-based personalization or updating is appropriate. The benchmark distinguishes semantic relevance from legitimate decision authority: a memory can be related to the query without constituting valid evidence for the final answer. We use the complete set of 1,550 instances. MemSyco-Bench organizes its five task sce-narios into two primary dimensions: When to Use Memory and How to Use Memory . The former contains Objective Fact Judgment, Contextual Scope Control, and Memory–Evidence Conflict, with 300 instances each. The latter contains Personalized Memory Use with 300 instances and Valid Memory Selection with 350 instances. 

How to Use Memory. This primary dimension evaluates whether a model can use memory appro-priately when memory should influence the current response. Personalized Memory Use evaluates 21 Preprint whether the model uses valid and relevant personal information when personalization is explicitly appropriate. The model should substantively use the relevant memory while preserving a correct and useful response. Valid Memory Selection evaluates whether the model selects the currently valid preference or user state when multiple historical memories are available. The model should follow the latest valid memory rather than an outdated or superseded one. D.1.1 OFFICIAL EVALUATION METRICS

The three benchmarks share a common principle: semantic relevance alone does not determine whether a retrieved memory should influence the current response. The appropriate role of a mem-ory depends on the current task, available evidence, memory validity, and the intended use of person-alization. Depending on the task, a retrieved memory may need to be rejected as factual evidence, restricted to its valid contextual scope, overridden by reliable current evidence, replaced by a newer or currently valid memory, used to support appropriate personalization, or ignored when it is irrel-evant or outdated. MemSyco-Bench primarily evaluates whether the model can assign the correct decision authority to retrieved memories. MemTrapBench evaluates whether memory induces rea-soning fixation or belief distortion even when the historical context may be relevant. PersistBench evaluates both harmful memory influence and the ability to retain beneficial memory use. Together, these benchmarks evaluate memory use as a task-dependent decision problem rather than as a binary retain-or-discard operation. This task-dependent view motivates MemAdapter. MemAdapter preserves retrieved memories while explicitly modeling their applicable conditions and regulating how they may influence the final re-sponse. The framework is therefore designed to suppress inappropriate memory influence without eliminating valid memory use or beneficial personalization.

F RELATED WORK 

Long-term memory has become a fundamental capability for LLM-based agents, enabling them to maintain user information, interaction history, and task experience across sessions (Zhang et al., 2025c; Yang et al., 2026a). Early agent systems explored how historical experiences could be stored, retrieved, and reflected upon to support long-horizon interactions (Feng et al., 2026; Xiao et al., 2026; Wang et al., 2024; Tan et al., 2025). Generative Agents introduced a memory stream that records experiences and retrieves relevant memories to support long-term social behaviors (Park et al., 2023). Reflexion further demonstrated that agents can store verbal feedback from previ-ous attempts as persistent memory to improve future behaviors (Shinn et al., 2023). Subsequent works focused on designing memory architectures and improving memory management (Zhang et al., 2025c). MemGPT introduced hierarchical memory with explicit read–write operations to 26 Preprint manage information beyond the context window (Packer et al., 2023), while LongMem employed an external retriever-reader architecture for accessing long historical contexts (Wang et al., 2023a). MemoryBank and Mem0 studied memory extraction, updating, consolidation, and forgetting mech-anisms for personalized agents (Zhong et al., 2024; Chhikara et al., 2025). More recent approaches explored structured and efficient memory organization, such as A-MEM, which represents memories as interconnected evolving notes (Xu et al., 2025), and LightMem, which separates online memory access from offline consolidation (Fang et al., 2026a). Beyond memory construction, another line of research investigates how retrieved information should be selected before being incorporated into model reasoning (Tan et al., 2025; Wu et al., 2026; Zhang et al., 2025a). Retrieval-Augmented Generation improves LLMs by leveraging external knowl-edge (Lewis et al., 2020), but retrieved information may contain irrelevant, noisy, incomplete, or conflicting evidence (Zhang et al., 2025b). Self-RAG enables models to determine when retrieval is needed and to critique retrieved evidence through self-reflection (Asai et al., 2024). FILCO selects retrieved contexts according to their usefulness for the current task (Wang et al., 2023b), while Cor-rective RAG evaluates retrieval quality and performs corrective retrieval when retrieved evidence is insufficient (Yan et al., 2024). Similar concerns have been extended to personal memory sys-tems. MemGate introduces a query-conditioned gating mechanism to determine whether retrieved memories should enter the generation context (Zhang et al., 2026). OP-Bench studies excessive personalization caused by inappropriate memory usage and proposes Self-ReCheck to reduce un-necessary memory influence (Hu et al., 2026). These approaches mainly focus on controlling which retrieved information is exposed to the model before generation (Hannoon et al., 2026). Recent studies further reveal that persistent memory introduces new reliability challenges beyond retrieval quality, particularly memory-induced sycophancy and inappropriate personalization (Sun et al., 2026; Fang et al., 2026b). Sycophancy studies show that language models may prioritize agreement with users over independent judgment, including imitating user misconceptions or revis-ing correct answers under user pressure(Sharma et al., 2024; Wei et al., 2023). Recent evaluations demonstrate that such behaviors can persist across multi-turn interactions(Hong et al., 2025; Liu et al., 2025; Jain et al., 2026). In long-term memory settings, Recalling Too Well shows that mem-ory extraction may preserve and amplify users’ incorrect beliefs (Bensal et al., 2026). PersistBench investigates when persistent memories should be retained or forgotten and evaluates memory-related failures across different scenarios (Pulipaka et al., 2026). Mao et al. further study persistent syco-phancy in stateful personal agents and show that agreement behaviors can accumulate across ses-sions through memory (Mao et al., 2026). Other benchmarks, including MemSyco-Bench, Bench-PreS, HUSH-Bench, and STALE, evaluate contextual scope control, preference persistence, sensi-tive memory usage, and memory validity under changing user states (Xiang et al., 2026a; Yoon et al., 2026; Xu et al., 2026; Chao et al., 2026; Wang et al., 2026). Together, these studies demonstrate that retrieving relevant memories alone does not guarantee reliable memory behavior. Existing approaches mainly intervene at the stages before reasoning, including memory construc-tion, retrieval, filtering, and organization (Chhikara et al., 2025; Zhang et al., 2026; Yang et al., 2026b; Hannoon et al., 2026). However, once a memory has been retrieved and incorporated into the context, how it should contribute to the current reasoning process remains underexplored. A memory can be accurate and relevant while still providing insufficient support for a particular con-clusion under the current task (Xiang et al., 2026a; Wang et al., 2026; Sun et al., 2026). Our work focuses on this post-retrieval setting and studies how retrieved memories should contribute accord-ing to the current task and available evidence without modifying the upstream memory pipeline.
