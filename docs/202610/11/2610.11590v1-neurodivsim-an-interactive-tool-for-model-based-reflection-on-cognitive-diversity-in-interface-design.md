## 摘要
近期，模拟用户和合成用户方法为支持设计提供了新途径，但也引发了一个问题：用户的计算表征应如何融入设计实践。我们提出 NeuroDivSim，这是一种交互式工具，旨在探索如何将模拟作为一种可检视的机制，在设计与原型制作过程中反思认知多样性。NeuroDivSim 并非使用 LLM 扮演模拟用户，而是利用生成式 AI 根据使用情境构建可检视的任务、界面和环境模型。经人工审查后，这些模型与明确设定的认知参考配置相结合，并通过确定性模拟进行处理。设计师由此能够保持建模的使用情境不变，同时调整认知假设，并追踪其对交互步骤和基于规则的设计建议所产生的影响。此外，我们报告了一项探索性先导评估（N=10），该评估为参与者如何使用这一工作流程提供了形成性见解，并为后续改进模型、模拟结果和建议的呈现方式提供了依据。

## Abstract
Recent approaches to simulated and synthetic users offer new ways to support design, but raise questions about how computational representations of users should contribute to design practice. We present NeuroDivSim, an interactive tool that explores simulation as an inspectable mechanism for reflecting on cognitive diversity during design and prototyping. Rather than using an LLM to act as a simulated user, NeuroDivSim uses generative AI to construct inspectable task, interface, and environment models from a usage scenario. After human review, these models are combined with explicit cognitive reference configurations and processed through deterministic simulation. This enables designers to hold a modeled usage situation constant while varying cognitive assumptions and tracing their consequences to interaction steps and rule-based design recommendations. We further report an exploratory pilot evaluation (N=10) that provided formative insights into how participants engaged with the workflow and informed subsequent refinements to the presentation of models, simulation results, and recommendations.

## 1. 核心问题与研究背景

- **核心问题**：如何在界面设计早期，帮助设计师系统地思考认知多样性，而不让大语言模型（LLM）扮演真实用户，也不将模拟结果误当作神经多样性群体的真实行为？
- **研究动机**：
  - 生成式代理、AI 人物画像和合成用户可以提供设计反馈，但存在有效性不足、刻板印象、表征偏差，以及替代真实用户研究的风险。
  - ADHD、阅读障碍等群体内部存在显著差异，诊断标签不能直接转化为统一的行为规范或界面需求。
  - 设计师仍需要在两次真实用户研究之间，将已有研究、无障碍指南和利益相关者知识转化为具体设计决策。
- **整体定位**：NeuroDivSim 是一种**基于模型的设计反思工具**，而不是用户行为预测器。它回答的是：
  > 在当前明确设定的认知、任务、界面和环境假设下，哪些交互步骤值得进一步检查？
- **主要贡献**：
  1. 将模拟定位为可检查的反思机制，而非真实参与者的替代品。
  2. 实现“LLM 建模—人工审核—确定性模拟—可追溯建议”的交互流程。
  3. 通过十人探索性试点评估，识别流程理解和结果呈现方面的改进需求。

## 2. 方法论：核心思想与技术流程

### 2.1 核心思想：分离情境解释与模拟推演

- LLM 只负责将自然语言情境、可选界面截图转换为结构化模型。
- 设计师检查、修改并确认模型后，**LLM 不再参与后续计算，也不生成最终设计建议**。
- 后续模拟与建议采用确定性计算和显式规则，使差异能够追溯到具体输入假设。

### 2.2 使用情境的结构化建模

系统分别建立三个模型，避免将所有困难都归因于用户特征：

| 模型 | 主要属性 |
|---|---|
| 任务模型 | 任务复杂度、步骤数、阅读需求、输入需求、记忆需求，以及逐步动作和预计耗时 |
| 界面模型 | 文本量、句长、词汇难度、专业术语、视觉杂乱程度、导航复杂度、无障碍支持、反馈质量 |
| 环境模型 | 噪声、干扰、时间压力、情境稳定性 |

- 模型属性采用共同的 **0–100 标度**。
- LLM 可以提供将属性值与输入证据关联的解释，供设计师审核。
- 任务分解借鉴层次任务分析（HTA）和 GOMS 的思想，但**并未完整实现这两种方法的正式体系**。

### 2.3 显式认知参考配置

系统提供：

- 通用比较配置；
- ADHD 启发配置；
- 阅读障碍启发配置。

- 阅读困难；
- 注意力稳定性；
- 干扰敏感性；
- 任务切换困难；
- 工作记忆稳定性；
- 以及解码、抑制、警觉性和反应变异等进一步模拟参数。

### 2.4 确定性模拟与规则建议

算法流程可概括为：

1. **输入审核后的模型与认知配置**。
2. **推导中间参数**：如文本复杂度、导航成本、解码成本、记忆需求和持续注意负荷。
3. **逐步更新状态**：以一秒为时间间隔，沿任务步骤更新注意力、疲劳、阅读速度等动态状态。
4. **计算输出指标**：认知负荷、错误风险、任务成功、完成效率、完成时间和时间限制风险。
5. **检测阈值事件**：如高负荷、注意力下降、返工等，并记录发生时间和对应步骤。
6. **触发建议规则**：将任务属性、界面属性、认知参数、状态和事件关联到具体设计建议。
7. **修改与重跑**：设计师调整模型或界面后，比较变化如何影响结果。

建议保留“受影响步骤—触发因素—解释—具体改动”的追溯链。例如，搜索表单步骤中的注意力下降可能触发突出下一步操作、减少竞争元素等建议。

### 6.2 总体结论

- NeuroDivSim 展示了一个可行的原型方向：模拟可以用于审视设计假设，而不必生成“像用户一样”的意见。

## 7. 优点与亮点

- **AI 职责边界清晰**：将生成式解释限定在输入建模阶段，避免 LLM 在后续比较中不断引入变化。
- **可检查、可追溯**：输出能够关联到属性、参数、状态、事件和交互步骤，支持设计依据的记录与质疑。
- **适合受控假设比较**：固定情境，仅变化认知假设，有利于观察模型内的影响路径。
- **强调情境关系**：分别建模任务、界面和环境，避免把困难简单归结为用户缺陷。
- **支持人工修正**：设计师可以纠正 LLM 的解释，并通过修改模型重新推演。
- **伦理定位审慎**：明确拒绝替代真实用户研究、模拟生活体验、认证无障碍或排序群体能力。
- **形成性评估与开发衔接明确**：报告了具体反馈如何转化为界面改进，并提供开源实现。

## 8. 不足与局限

### 8.1 模型与技术局限

- 参数、权重、阈值和关系尚未经验校准；**可重复不等于正确，可解释不等于有效**。

- 确定性仅适用于确认后的固定输入；前端 LLM 建模仍可能产生不稳定解释或不恰当属性值。
- 规则建议依赖预设规则的质量和覆盖范围，尚未证明其相较普通指南提供了多少额外价值。

- 样本小、场景分布不明，难以推广到不同专业水平或复杂设计流程。
- 没有报告神经多样性参与者对模型或配置进行直接验证。
- 缺少与无障碍指南、认知走查或其他模拟工具的对照。
- 缺少消融、敏感性分析、客观设计成果和长期使用评估。

### 8.3 偏差与应用风险

- 诊断标签配置仍可能强化“某类人必然注意力更差或错误更多”的刻板印象。
- 设计师可能过度信任数字和解释，形成自动化偏见或表面上的“无障碍合规”。
- 模型无法表达个体生活体验、补偿策略、优势及所有情境差异。
- 上传截图可能包含敏感信息，需要明确的数据保护措施。

### 8.4 后续研究重点

- **设计效用验证**：对照现有实践，评估是否发现更多有效问题、形成更好的方案和设计依据。
- **模型有效性验证**：与神经多样性参与者合作，检验关系、参数敏感性并进行校准。
- 逐步从诊断标签转向交互相关能力维度，测试提示和解释能否真正降低误用。
