## 摘要
语言智能体的个人记忆通常依据最终答案是否正确来评估。然而，这种评分掩盖了生成前就已出现的错误：记忆块可能包含过时的值、属于错误人物的事实，或未能在服务截止时间前提供任何有用事实。我们直接测量了这些失效情况。以个人事实记忆（Personal Fact Memory，PFM）作为参考层，我们发现，在本研究设定中，时间有效性主要取决于记忆的构建方式。在一个受控修订基准上，对于每个键正确的槽位，仅提供当前有效值即可消除观测到的陈旧信息暴露；若不解决更新问题，则有70.3%的提示会暴露已被取代的值。当检索器使用相同的有效存储和参与者信息时，在预先设定的0.02误差范围内，参与者感知型BM25与参考排序器表现相当。更难的问题是将修订内容分配到正确的槽位。漏合并会使陈旧值继续有效，而误合并则会悄然移除当前值；四种LLM键分配器的键召回率高于规则抽取器，但干净检索率更低；在LongMemEval上，开放域合并召回率从未超过0.062。即使经过有效性筛选，错误归属问题仍然存在：实体后验概率能够减少受控数据中的同名实体暴露，却无法区分LoCoMo中姓名相同的说话者。两种冻结的语言模型都会在生成文本中重现提示错误。不同排序器的检索延迟有所差异，但在我们的硬件上，提示预填充是单轮延迟的主要来源。这些结果表明，应在生成前评估智能体记忆，并分别考察存储状态有效性、身份解析、弃答以及服务延迟。

## Abstract
Personal memory for language agents is usually judged by whether the final an- swer is correct. That score hides errors that arise before generation: the memory block may contain an obsolete value, a fact about the wrong person, or no use- ful fact before the serving deadline. We measure these failures directly. Using Personal Fact Memory (PFM) as a reference layer, we find that temporal validity is primarily a property of memory construction in our setting. On a controlled revision benchmark, serving only the active value of each correctly keyed slot eliminates observed stale exposure; without update resolution, 70.3% of prompts expose a superseded value. Once retrievers share the same active store and par- ticipant information, participant-aware BM25 is equivalent to the reference ranker within a prespecified 0.02 margin. The harder problem is assigning revisions to the right slot. Missed merges leave stale values active, whereas false merges silently remove current values; four LLM key assigners achieve higher key re- call than a rule extractor yet produce lower clean-retrieval rates, and open-domain merge recall on LongMemEval never exceeds 0.062. Misattribution survives va- lidity filtering: an entity posterior reduces same-name exposure on controlled data but cannot distinguish identically named speakers in LoCoMo. Two frozen lan- guage models reproduce prompt errors in generated text. Retrieval latency varies across rankers, but prompt prefill dominates turn-level latency on our hardware. These results argue for evaluating agent memory before generation, separating stored-state validity, identity resolution, abstention, and serving latency.

## 1. 核心问题与研究背景

### 1.1 研究动机

语言智能体的个人记忆通常通过“最终回答是否正确”来评估，但这一指标无法准确定位记忆系统的故障：

- **陈旧信息（staleness）**：会议已经改期，记忆块却仍包含旧时间。
- **错误归属（misattribution）**：请求涉及某个 Alex，检索结果却包含另一个同名人物的事实。
- **服务延迟（lateness）**：检索结果本身正确，却没有在模型开始预填充前及时到达。
- **无答案时不弃答**：存储中没有目标事实，检索器仍返回看似相关、实际不能回答请求的内容。

最终答案正确，并不意味着输入给模型的记忆可靠：模型可能恰好从混杂的新旧值中选对答案，也可能忽略被错误注入的事实。

### 1.2 论文的整体含义

论文主张将评估前移到**记忆进入模型提示的时刻**，分别检查存储状态、身份归属、弃答能力和截止时间，而不只统计最终回答准确率。

其研究重点不是提出新的时序数据库机制，而是检验：

> 已有的“新值替代旧值”机制，在槽位识别、身份表示、更新顺序和服务条件不完美时，究竟还能保证什么？

## 2. 方法论：核心思想与技术细节

### 2.1 提示级评估框架

论文将每条个人事实表示为包含以下字段的记录：

- 可直接放入提示的事实文本；
- 规范化实体、来源参与者；
- 可选的可变槽位键；
- 存储中的活动时间区间；
- 最近观察时间。

评估指标包括：

| 指标 | 含义 |
|---|---|
| 当前值召回 | 记忆块是否包含目标实体、目标槽位的当前值 |
| 陈旧暴露 | 是否包含目标实体同一槽位的已失效值 |
| 错误归属 | 是否包含同名但非目标实体的相关值 |
| 干净检索 | 有答案时包含当前值且无上述错误；无答案时不暴露目标类型的候选值 |
| 弃答率 | 是否返回空记忆块 |
| 截止时间内干净检索 | 干净检索且检索耗时不超过服务截止时间 |

**这些指标可以同时成立**：一个记忆块可能既召回当前值，又注入旧值。因此，高召回不能替代低暴露或高干净检索率。

此外，无答案时的“干净”不必要求整个记忆块为空，而是不能包含被评估为目标槽位候选答案的事实；论文另行记录空块弃答。

### 2.2 键控更新与 PFM 参考层

论文使用 **Personal Fact Memory（PFM）**作为可控的参考记忆层：

1. 从观察或对话中抽取事实、实体和槽位键。
2. 对相同键的新事实：
   - 值相同则视为再次观察；
   - 值不同则关闭旧事实的活动区间，激活新事实。
3. 被替代事实保留为历史，但移出活动检索索引。
4. 检索时仅访问活动事实。
5. 按分数排序，在事实数量和字符预算内组装记忆块。

对于无键事实，系统只在共享实体、词元 Jaccard 相似度至少为 **0.8**，且值承载词元相同时进行吸收。

论文证明的状态不变量是：

> 在串行、原子提交且初始状态满足条件时，每个键最多存在一个活动值。

但它**不保证这个活动值在现实语义上正确**：

- **漏合并**：同一槽位的修订使用不同键，旧值继续活动。
- **误合并**：不同槽位共用一个键，正确事实被错误关闭。
- **乱序到达**：最后收到的旧消息可能替代更晚发生的新值。

### 2.3 检索与身份解析

- PFM 使用 **BM25F**，结合文本、实体、参与者字段，以及近期性、使用频率和一跳图关联。
- 在线检索路径不调用语言模型或嵌入模型。
- 身份解析为歧义名称的候选实体计算后验概率，综合：
  - 是否为当前参与者；
  - 与当前参与者的图关联；
  - 最近观察时间。
- 保留后验最高实体的事实，以及不涉及这些歧义候选实体的事实。

这一方法不同于“只保留当前对话对象”的硬过滤：它允许检索与对话对象相关的**第三方事实**。但若两个真实人物已经被规范化成同一个实体字符串，后验无法恢复丢失的身份区别。

### 2.4 弃答与服务机制

论文比较两种弃答规则：

- **槽位门控**：识别请求槽位，若没有满足身份置信条件的对应事实，则返回空块；依赖已知槽位模式。
- **分数间隔门控**：检查最高分相对候选平均分的优势及词语重合；不依赖固定模式，但泛化效果较弱。

服务方面，后台可发布不可变检索快照，请求直接读取；也可等待预启动工作线程进行新鲜检索，超时后回退到快照。等待上界依赖交接成本、线程调度延迟等条件，**低等待不等于快照新鲜**。

## 6. 主要结论与发现

### 6.1 时间有效性首先依赖正确的存储构建

在受控基准、800 字符预算下：

| 方法 | 当前值召回 | 陈旧暴露 | 错误归属 | 干净检索 |
|---|---:|---:|---:|---:|
| 键控 PFM | 99.8% | 0%（观测值） | 12.1% | 87.7% |
| 无键 PFM | 95.0% | 70.3% | 0.4% | 24.7% |
| BM25＋有效性＋参与者 | 100% | 0%（观测值） | 12.8% | 87.3% |
| 稠密检索＋有效性＋参与者 | 100% | 0%（观测值） | 16.4% | 83.6% |

- 正确键控并仅检索活动事实后，所有被测检索器均无观测到的陈旧暴露。
- 零暴露的统计上界约为 **0.5%**，不是无条件的零错误保证。
- 参与者感知 BM25 与 PFM 在预设界限内统计等效。
- 稠密和混合检索没有改善干净检索，主要问题是更多错误归属。

### 6.2 键召回高，不代表记忆更可靠

改写语料上：

- 规则抽取器键召回率 **80.7%**，干净检索率 **78.1%**；
- 四种 LLM 键分配器键召回率 **98.0%–99.6%**，干净检索率却只有 **56.0%–64.4%**。

原因是误合并会删除其他槽位的当前事实，造成“答案从活动存储中消失”。该结果说明，在本设定中，**槽位分配精度比单纯提高覆盖率更关键**，但不意味着规则抽取在所有开放域任务上都优于 LLM。

LongMemEval 上，所有被测开放域方法的归并召回率均不超过 **6.2%**，表明稳定发现并复用槽位键仍是明显瓶颈。

### 6.3 身份解析与弃答是独立问题

- 实体后验将错误归属从 **12.1%**降至 **3.2%**，干净检索提高到 **96.7%**。
- 硬参与者过滤虽然去除了主基准错误归属，但第三方事实召回仅 **2.0%**。
- LoCoMo 中同名暴露为 **54.3%**，参与者过滤后仍为 **30.1%**；实体名称已经合并时，后验无法区分人物。
- 槽位门控在受控数据上对 60 个无答案请求全部弃答。
- 无模式门控无法同时保持高召回和有效弃答：在 LoCoMo 一个阈值下，无答案弃答率为 **95.0%**，但有答案请求也被弃答 **73.9%**。

### 6.4 提示错误会传播，但不是一一映射

- qwen2:7b 的正确完成率：键控 **92.9%**，无键 **70.4%**。
- llama3.2:3b：键控 **91.2%**，无键 **59.2%**。
- 仅提示模型“使用最新日期的信息”改善有限，弱于检索前过滤旧值。
- 不过，模型有时能避开提示中的错误。因此，提示暴露是诊断指标，不能直接等同于最终错误率。

### 6.5 延迟优化必须看完整服务路径

- PFM 检索中位数约 **0.25 ms**，参与者感知 BM25 约 **0.10 ms**。
- MiniLM 稠密检索约 **18.3 ms**，查询编码占主要成本。
- 对 7B 模型，加入记忆后首词元时间从约 **325 ms**升至 **1.22 s**，预填充成本远大于词法检索。
- 快照读取很快，但落后一个相关更新时，修订查询全部暴露旧值。
- 词法检索的低成本优势也不是无限成立：更大存储、长倒排列表和窄词汇分布可能使其慢于稠密检索。

---

## 7. 优点与亮点

- **评估粒度清晰**：区分“召回正确事实”和“同时注入错误事实”，揭示最终准确率隐藏的问题。
- **明确划分保证边界**：将每键最多一个活动值的状态不变量，与语义正确性严格分开。
- **控制变量充分**：能较有说服力地将时间有效性收益归因于活动存储，而非复杂排序器。
- **发现具有工程价值**：揭示高键召回可能因少量误合并而带来更差的下游记忆。
- **同时研究质量和时延**：覆盖检索、预填充、并发调度、快照陈旧及规模扩展。
- **报告负面结果**：开放域归并、同名实体表示、无模式弃答的失败没有被隐藏。
- **伦理边界明确**：指出历史保留不等于删除，身份排序也不等于访问控制。

---

## 8. 不足与局限

### 8.1 数据与标签偏差

- 受控基准只有少量模板、固定槽位、唯一值和较准确的参与者元数据。
- 基准修订比例较高，放大了不处理更新的代价；重加权后差距仍存在，但幅度缩小。
- LongMemEval 只保留新旧答案能够逐字匹配的样本，排除了需释义或推理的问题。
- LoCoMo 主要用于按来源测量暴露，其低答案召回限制了端到端有效性判断。

### 8.2 方法适用范围有限

- 正确更新依赖稳定的实体、槽位和事件实例表示。
- 过粗的键会删除不同事件的事实，过细的键则无法识别修订。
- 活动区间表示存储状态，而非现实世界的真值时间；乱序问题需额外可信时间信息。
- 实体后验无法解决已经在表示阶段被合并的同名人物。
- 成功的弃答规则依赖已知模式，开放域可靠弃答仍未解决。

### 8.3 实验外推与部署限制

- 生成模型仅为两种小型量化模型，不能直接外推到更强模型或复杂智能体。
- 时延受 M2 硬件、CPython 调度、垃圾回收和缓存设置影响。
- 未测量真实用户收益、长期使用行为或真实个人数据库。
- 未实现完整删除，也未提供阻止跨人物泄露的访问控制。
- 论文没有解决全部问题，更准确的定位是：**提供一套生成前的记忆故障诊断框架，并实证揭示其关键前提与薄弱环节。**
