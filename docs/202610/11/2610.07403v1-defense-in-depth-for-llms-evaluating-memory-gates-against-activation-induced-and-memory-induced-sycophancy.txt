# Abstract 

Long-term memory allows Large Language Models (LLMs) to maintain person-alized context across interactions, but retrieved user history can induce memory-induced sycophancy , causing models to favor stored user beliefs over objective evidence. Existing defenses primarily operate on retrieved context and are rarely evaluated jointly with internal behavioral bias. We introduce a 2 × 2 defense-in-depth framework separating internal activation steering from external memory handling. We extract sycophancy steering directions from 100 paired prompts and evaluate four open-weight models across 10 steering coefficients and five memory-defense configurations on MemSyco-Bench (answers for all 1,550 items; defense conditions judged on a fixed 250-item subsample), with three LLM judges. 2 Three of the five configurations are new (rewriting every memory, a Router Gate that keeps, rewrites, or drops each memory, and dropping all memory); the other two are MemSyco’s baselines. Selective Router Gate filtering preserves substantially more of MemSyco’s average accuracy than complete memory removal, and this separation persists when the models are steered toward sycophancy. On Llama 3.1 8B with Router Gate, mild inverse steering ( α = −1.5) lowers judge-averaged sycophancy from 35.80% to 31.32% while average accuracy moves from 43.99% to 43.31%; this reduction has the same direction under all three judges but is not statistically significant (paired p = 0 .08 to 0.63 on 149 items). External memory filtering is the part of the design that holds up; our data do not show that inverse steering adds to it. 

# 1 Introduction 

LLMs increasingly rely on Retrieval-Augmented Generation (RAG) and persistent memory stores to maintain contextual continuity across interactions. Although long-term memory enables personaliza-tion, it also introduces a safety vulnerability: memory-induced sycophancy . Retrieved conversation history may contain user misconceptions, subjective beliefs, or outdated claims that encourage a model to align with the stored user position rather than available objective evidence. Previous approaches to memory-induced sycophancy have primarily focused on external context management, including cautionary instructions [1] and filtering retrieved memory before prompt

Consequently, the interaction between internal behavioral bias and external memory defenses remains underexplored. To study this interaction, we introduce a defense-in-depth evaluation framework separating two intervention axes: internal model state and external memory handling. Conceptually, this produces the 2 × 2 design in Table 1 (Appendix C). Experimentally, we extend the binary internal-state axis into a controlled activation-steering sweep and evaluate five external memory-defense configurations. This design allows us to measure whether external defenses remain effective as internal sycophancy pressure is increased or suppressed. Our core contributions are: (1) a controlled protocol separating activation-vector construction and val-idation from downstream MemSyco evaluation; (2) a defense-in-depth framework jointly evaluating internal activation steering and five external memory-handling strategies; (3) an analysis of evaluator disagreement and architecture-dependent instability under aggressive steering; and (4) a utility-aware evaluation showing that complete memory removal incurs a large accuracy cost, while selective gating preserves substantially more of it; mild inverse steering gives a small further reduction that is consistent in direction across judges but not statistically significant. 

# 2 Related work & literature gaps 

Prior work studies persistent-memory risks and defenses through benchmarks such as PersistBench [1] and MemSyco [2], while MemGate [3] addresses trustworthy memory filtering. Our steering construction follows contrastive activation addition [8]; the contrast pairs come from the sycophancy evaluation suite of Sharma et al. [9], and the behaviour was first characterised at scale with model-written evaluations [10]. Representation-engineering work studies activation-based sycophancy interventions [4, 5]; Buchan [4] in particular show that an “anti-sycophancy” direction can also suppress agreement with true statements (see Appendix B). Parameter-level editing [6] targets selective refusal and is adjacent rather than directly comparable. Rimsky et al. [8] already showed that subtracting a sycophancy vector lowers sycophancy, so we do not claim inverse steering as new; we add its evaluation together with memory defenses. We did not run published memory filters such as MemGate [3]; our Router Gate is a separate, simpler method (Section 4.2).

# 4 External memory gate architecture & evaluation matrix 

4.1 MemSyco benchmark dataset 

MemSyco-Bench [2] contains 1,550 items in five tasks: objective fact judgment (300), contextual scope control (300), memory–evidence conflict (300), personalized memory use (300), and valid memory selection (350). We generate all 1,550 items for every (model, α, defense) cell: 10 coeffi-cients × 5 defenses × 4 models = 200 cells. Judging is by three evaluator LLMs. The No-Defense condition is judged on all 1,550 items; each defense condition is judged on a fixed stratified subsample of 250 items (50 per task, seed 1729), identical across every cell so that all comparisons are paired. 

4.2 Memory defense configurations 

All five conditions share one prompt skeleton and differ only in the memory block. (1) No Defense: 

retrieved memories inserted as plain text. (2) Blanket Rewrite: every memory is rewritten with a fixed template that prepends a provenance clause chosen by the classifier’s type label (e.g. “This records a belief the user holds, not an established fact”; “a preference, not a claim about the world”; “a verifiable attribute of the user”). (3) Router Gate: a classifier LLM (DeepSeek-V4-Flash, frozen prompt, temperature 0) labels each memory as belief / preference / user fact / unclear and the question’s need as objective / personal-in-scope / personal-out-of-scope / unclear; a fixed action table maps the pair to Keep , Rewrite (same templates as Blanket Rewrite), or Drop , with unclear 

abstaining to Keep . (4) Blanket Drop: the memory block is replaced by “Retrieved memory: [none]”. (5) MemSyco Caution: memories as in No Defense plus the benchmark’s own instruction, “Use user preferences only when they are relevant and appropriate; do not let preferences override factual evidence or task constraints.” No Defense and MemSyco Caution are MemSyco-Bench’s baselines [2]; Blanket Rewrite, Router Gate, and Blanket Drop are introduced here, with Blanket Drop as the standard no-memory ablation. Because the gate classifier is also one of our three judges, we report the other two judges alongside it. 

# 5 Experimental results & discussion 

Three evaluator LLMs (DeepSeek-V4-Flash, GPT-4o-mini, Gemini 3.7 Flash) judge every cell with MemSyco’s task-specific prompts (Appendix F). Tables 4 and 5 give every cell per judge; the text quotes judge-averaged values. 

5.1 Defense efficacy & utility trade-offs 

Across the mild-steering regime (Figure 1), Blanket Drop produces the lowest pooled sycophancy, but almost entirely because the scope-control and memory–evidence-conflict tasks cannot misuse a memory that is absent, and at a large accuracy cost. At α = 0 , judge-averaged average accuracy (MemSyco’s five-task utility metric, Appendix F) on Llama 3.1 8B is 43.99% with Router Gate against 13.51% with Blanket Drop. The same pattern holds across the other architectures and evaluators. At α = 0 the gate lowers objective-fact-judgment sycophancy relative to No Defense on every model (paired exact McNemar, Holm-corrected over the four defenses: p < 0.05 in 11 of 12 model–judge pairs, p < 10 −3 on Llama, p = 0 .052 for Qwen under Gemini), whereas the memory–evidence-conflict task is near ceiling under No Defense (96–100% on Qwen, Phi, and Mistral; 63–96% on Llama) and stays at 80% or above under Blanket Rewrite and Router Gate on those three models (70–92% on Llama), so it separates the memory-preserving defenses only weakly; it drops under Blanket Drop (0–44%) and, on Llama and Mistral, under MemSyco Caution (31–48% and 54–82%). # 6 Conclusion 

Personalized LLM agents require defenses that address both retrieved context and internal behavioral tendencies. Complete memory removal strongly suppresses pooled sycophancy but incurs a large accuracy cost, whereas selective Router Gate filtering preserves considerably more accuracy while lowering objective-fact sycophancy at α = 0 on every model (significant in 11 of 12 model–judge pairs), and this separation persists when models are steered toward sycophancy. Its advantage over rewriting every memory depends on the model and judge. On Llama 3.1 8B with Router Gate, inverse steering ( α = −1.5) lowers judge-averaged sycophancy by about 4.5 points at about 0.7 points lower accuracy; the change has the same direction under all three judges but is not statistically significant, and larger inverse coefficients cause architecture-dependent degradation. Memory filtering is the dependable part of the design; whether inverse steering adds to it needs larger paired samples and the controls listed with the other limitations and compute details in Appendix B. 4Acknowledgments and Disclosure of Funding

# B Limitations and compute resources 

Our framework adds one linear direction at three adjacent decoder blocks around layer 20 and therefore approximates, rather than reproduces, the distributed changes produced by training or alignment. Because the direction is a mean difference between differently worded completions, it is not by itself evidence of a behaviour-specific “sycophancy direction”; we did not run a norm-matched random-direction control or a true/false factual-agreement control, so negative-α reductions could partly reflect generic disagreement [4]. Each cell is a single greedy generation per item and a single steering vector per model; we report Wilson intervals for rates, normal-approximation intervals for paired differences, and exact McNemar tests for the headline contrasts but not variability across vector extractions or seeds. Defense cells are judged on 250 items (50 per task), which gives roughly ±8

points of uncertainty on a pooled rate over about 150 items. LLM-as-a-judge evaluation introduces evaluator-dependent uncertainty, particularly for hedged answers; three judges narrow but do not remove it, and one judge (DeepSeek-V4-Flash) is also the Router Gate’s classifier. Phi-3.5 Mini’s high-α answers are largely truncated at 512 tokens and judged as such. The MemSyco conversation transcript is omitted from all prompts. 

Compute Resources: Generation ran on Google Colab A100-SXM4-40GB instances in bfloat16 with batched, left-padded decoding validated against single-sequence generation before each run (batch sizes 96 Qwen, 40 Mistral, 32 Llama, 12 Phi). Our timing logs are incomplete; the recorded sessions alone sum to 32 A100-hours for the 200-cell matrix, and the layer sweep took about 4 more. Judging through OpenRouter cost USD 110 for the judge calls behind the tables (USD 298 including repeated gradings and a fourth judge, nvidia/nemotron-3-ultra , whose labels we did not use). 

# C Additional Experimental Details 

These five configurations implement the external-memory axis of our conceptual 2 × 2 framework. The internal-state axis is expanded from a binary unsteered/steered comparison into a continuous steering sweep over α ∈ [−6, 30] , allowing us to evaluate both increased sycophancy pressure (α > 0) and inverse steering ( α < 0). 

Router Gate classifier scope. The classifier sees only the question and the memory texts, never the rubric, reference answer, or task label. Decisions depend only on (question, memories), so they are computed once and are identical across all models and α.

C.1 Target architectures and data separation 

Vector extraction uses only the 100 sycophancy-eval pairs; no MemSyco item is used to build or tune d, α, or the layer. Coefficient ranges were fixed from pilot generations by generation health (artifact rate, Appendix J), not from downstream scores. All reported evaluation is on MemSyco-Bench [2]. We do not run a norm-matched random-direction control or a true/false factual-agreement control, so we cannot rule out that part of any negative-α effect is generic disagreement rather than sycophancy-specific [4]; we return to this in Appendix B.

Either way, raw sycophancy percentages depend on the judge, which is why every table reports all three judges. 9E Additional structural collapse analysis 

Activation steering becomes unstable at sufficiently large magnitudes, but the failure threshold is architecture-dependent. We therefore distinguish the behavioral effects of mild steering from structural degradation under extreme steering coefficients. Mistral 7B exhibits the narrowest stable region among the evaluated models. At α = −6, Mistral fails to produce usable generations across all five memory-defense configurations, whereas all tested coefficients from α = −2.5 through α = 2 .5 produce usable outputs. Mistral also becomes unstable under larger positive steering coefficients. This negative-end failure demonstrates that model collapse is not restricted to large positive values of α.Other architectures tolerate larger magnitudes. Llama 3.1 8B stays under the 20% artifact threshold from α = −2.5 through 2.5; at α = +6 , No Defense (19.0% degenerate over all 1,550 items) and Blanket Drop (17.6%) stay under the threshold while Blanket Rewrite, Router Gate, and Caution do not (20.8–25.6%); at α = −6 every condition exceeds it (25.2–57.2%); and at α ≥ 20 it crashes. The cells over the threshold are shown in the tables with a dagger and are not used in any claim. Qwen 2.5 and Phi-3.5 Mini stay under the threshold across the ladder. A coefficient that is stable for one architecture cannot be assumed stable for another. These observations indicate an architecture-specific operating regime for activation steering. Mild inverse steering avoids the structural failures seen at larger magnitudes, but its effect is small: Llama 3.1 8B’s lowest healthy Router Gate sycophancy is at α = −1.5, within uncertainty of α = −2.5 and 

α = 0 . However, Mistral’s failure at α = −6 demonstrates that increasing inverse-steering magnitude does not monotonically improve behavior. At extreme positive coefficients, Mistral and Llama exhibit complete generation failure, while Qwen 2.5 and Phi-3.5 Mini remain usable across a broader tested range. Consequently, both behavioral efficacy and generation validity must be considered when selecting α.

# F LLM-as-a-Judge prompt and grading rubric 

Every prompt shows the retrieved memories as plain text with the benchmark’s [type, status] 

annotations removed (they would leak the valid-memory-selection answer key) and without the original conversation transcript, so absolute rates are not comparable to the MemSyco paper’s. 

F.1 Personalization utility metric 

In addition to sycophancy we report MemSyco’s average accuracy : the unweighted mean of the five per-task accuracy rates on healthy rows, as returned by the task-specific judge prompts (Ap-pendix F). It measures whether a defense preserves correct, memory-conditioned answers overall; the personalized-memory-use task is one of its five components. Evaluator-specific values are retained to expose disagreement across judges. Judging used the OpenRouter API with three evaluators: deepseek/deepseek-v4-flash ,

openai/gpt-4o-mini , and google/gemini-3.7-flash , all at temperature 0 (reasoning disabled where the provider allows it), each receiving MemSyco’s task-specific judge prompt verbatim. Judg-ing ran between 2026-08-27 and 2026-09-06; the OpenRouter response id is recorded per row in the released logs (the provider route on about a quarter of rows). Every response is judged with the MemSyco-Bench task-specific judge prompt, reproduced ver-batim from the benchmark release (system prompt plus a JSON payload holding the question, the memories, the answer, and the task’s rubric fields; the released harness hashes each rubric to guard against drift). Each judge call returns binary labels, not a score. The label we count as sycophantic is task specific: objective fact judgment, preference_misconception_endorsed ;contextual scope control, incorrectly_used_preference ; memory–evidence conflict, 

misled_by_conflicting_memory . The sycophancy rate in Table 4 is the fraction of these labels equal to 1, pooled over the three conflict tasks, on rows that parsed and passed the health check (denominator 900 for No Defense, up to 150 for each defense cell). Each task also returns an accuracy label ( objective_correctness , accuracy , answer_accuracy ); the average accuracy 

in Table 5 is the unweighted mean of the five per-task accuracy rates on the same rows. Judge temperature is 0, reasoning is disabled where the provider allows it (Gemini 3.7 Flash requires it 10 on), and failed API calls are stored and retried, and only the last attempt per item is used (the logs hold 11,146 failed calls, mostly HTTP 402 and 429; after retries 2 rows remain unparseable and are excluded from denominators). The pooled rate is dominated by the memory–evidence-conflict task, which is at 96–100% under No Defense on Qwen, Phi, and Mistral (63–96% on Llama) and at 70–100% under Blanket Rewrite and Router Gate; only Blanket Drop (0–44%) and, on Llama and Mistral, MemSyco Caution (31–82%) move it. Per-task rates are in the released tables.

During our empirical analysis, several edge-case behaviors and model-specific anomalies emerged that explain the data variance observed in Table 4. 

I.1 Blanket Rewrite raises pooled sycophancy on Llama 

On Llama-3.1-8B the Blanket Rewrite condition shows a higher pooled sycophancy rate than No Defense at every coefficient, including α = 0 and the negative coefficients, so the effect is a property of the rewrite template on this model rather than of steering. One candidate explanation is that the added provenance clauses lengthen and reframe each memory in a way that Llama treats as an instruction to use it; another is that the clauses change which conflict-task items the judges read as “used the preference”. We have not run the ablations (clause-by-clause removal, per-task decomposition with annotated examples) that would separate these, so we present the inversion as an observation, not an explained mechanism. 

I.2 Evaluator disagreement 

Qualitative inspection suggests that evaluator divergence is concentrated in ambiguous, non-committal responses. In inspected Blanket Drop examples, DeepSeek and Gemini Flash tended to assign lower sycophancy scores when the target model avoided explicit agreement, whereas GPT-4o-mini more often penalized responses that failed to directly refute the user’s false premise. These observations suggest evaluator-dependent treatment of hedging rather than a consistent signal of defense failure and motivate reporting results across multiple judges. 

# J Quantifying Structural Degradation via Cap and Artifact Rates 

J.1 Architecture-dependent steering stability 

Structural degradation occurs at architecture-dependent magnitudes. We call a cell healthy when at most 20% of its answers are degenerate (repetition loops, empty or near-empty text; Appendix E), the pre-registered threshold below which a cell is claimable, and crashed when 80% or more are degenerate in every condition. Mistral 7B is healthy from α = −2.5 to 2.5 and crashed at α = −6

and α ≥ 6. Llama 3.1 8B is healthy from −2.5 to 2.5, exceeds the threshold at α = −6 in every condition and at α = +6 in three of five (Appendix E; those cells are shown in the tables with a dagger and excluded from claims), and crashed at α ≥ 20 . Qwen 2.5 and Phi-3.5 Mini stay under the threshold across the whole ladder, although Phi’s answers hit the 512-token limit in 60% of cases at 

α = 6 and 87–92% at α ≥ 20 , so its high-α cells are judged on truncated text. Steering magnitude therefore cannot be transferred across architectures without checking generation health first. To characterize failure modes under increasingly strong activation steering, we separately track degradation of target-model outputs and artifacts introduced during evaluation. We quantify these effects using two metrics: Cap Rate and Artifact Rate . These metrics are analyzed separately because degradation of the target model and distortion of the LLM-as-a-Judge measurement process represent distinct failure modes. 17 Cap rate is the fraction of a cell’s generations that reached the 512-token max_new_tokens limit (the judge then reads a truncated answer):

The pre-registered rule is that a cell with artifact rate above 20% is reported but not claimable; we additionally label a coefficient as a crash for a model when 80% or more of its answers are degenerate in every condition. The 20% threshold is a reporting rule fixed before grading, not a demonstrated bias bound: survivors can be a biased subset below it as well. For that reason the released tables carry the degenerate fraction of every cell next to its rate, paired tests use only items healthy in both cells, and for the headline cells (under 2% degenerate) the conditional rate and the all-items rate (degenerate answers counted as non-sycophantic and incorrect) differ by less than one point. At α = 6 (No Defense, 50 items per task) Qwen 2.5 has a cap rate of 4.4% and an artifact rate of 0%, while Llama 3.1 8B has a cap rate of 23.2% and an artifact rate of 17.6%: truncation and degeneration do not coincide. At α = 20 Qwen 2.5 is at 7.6% cap and 0% artifact, Phi-3.5 Mini at 87–92% cap and under 2% artifact (long but coherent answers, judged truncated), and Llama 3.1 8B and Mistral 7B are at 100% artifact and are reported as crashes. Mistral 7B is at 85–96% artifact at α = −6 in all five conditions. Extreme steering can also cause complete structural failure, characterized by repetitive, malformed, or otherwise unusable generations. Such cases are reported as model crashes rather than interpreted as successful reductions in sycophancy. Consequently, apparent decreases in sycophancy at extreme steering coefficients should not be interpreted as improved defense efficacy without first verifying generation validity.

# L Broader impacts 

Positive impacts: evidence on which memory defenses preserve useful personalization while reducing agreement with stored misconceptions, and a documented warning that context ablation buys its safety numbers by discarding memory. Negative impacts and dual use: the same steering pipeline that we use as a manipulation ( α > 0) can make a deployed model more sycophantic; we release vectors and code for open-weight models that are already public and add no capability beyond published contrastive activation addition, but we note the dual use explicitly. LLM-as-a-judge sycophancy rates should not be read as safety certification: three judges disagree by up to 45 points on the same answers (Blanket Drop cells, where GPT-4o-mini labels far more hedged answers sycophantic than the other two judges; Section D.1), and the pooled rate is dominated by one task. We did not evaluate whether memory filtering treats users’ stated beliefs unevenly across groups; a gate that drops “beliefs” more readily than “facts” could suppress legitimate minority positions, and this deserves its own study. 19
