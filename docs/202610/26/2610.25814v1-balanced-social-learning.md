## 摘要
当个体对一组行动的偏好存在异质性时，何种情况下社会学习是有效的？当目光短浅的个体只会针对自己选择的行动生成信息时，有效性要求实现平衡，从而使所有高价值行动都能被发现。我们刻画了控制过去信息向未来个体传递的政策的价值。在过去信息完全透明的情况下，当且仅当先验与偏好是平衡的，且对数似然比的分布满足一组直观的矩条件时，实现有效结果的概率才近似为 1。带噪声的坏消息是一个典型例子。相比之下，在任意自适应信息政策的集合上，当且仅当先验本身是平衡的，才可能实现近似有效。此外，只需采用自适应证据政策，即永久且完全披露过去信息的某些子集。当先验不平衡、因而无法实现近似有效时，我们刻画自适应信息的价值，并证明随着每个单独信号对信念的影响趋于消失，该价值可由自适应证据的价值一致逼近。

## Abstract
When is social learning efficient if agents have heterogeneous preferences over a set of actions? When myopic agents generate information only about the action they choose, efficiency requires balance such that all high-value actions are discovered. We characterize the value of policies that control the flow of past information to future agents. Under full transparency of past information, the probability of efficient outcomes is approximately one if and only if the prior and preferences are balanced and the log-likelihood ratio distribution satisfies a set of intuitive moment conditions. Noisy bad news is a canonical example. By contrast, approximate efficiency is obtainable on the set of arbitrary adaptive information policies if and only if the prior alone is balanced. Moreover, it suffices to use adaptive evidence policies which permanently and fully disclose subsets of past information. When the prior is imbalanced and approximate efficiency is unattainable, we characterize the value of adaptive information and show that it is uniformly approximated by the value of adaptive evidence as the impact of each individual signal on beliefs vanishes.
