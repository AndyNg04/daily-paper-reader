ABSTRACT 

The rise of Agentic AI systems has changed the landscape of artificial intelligence by enabling strong reasoning capabilities through specialized multi-agent inter-action with structured self-reflection. However, in target-driven reasoning tasks, single- and multi-agent systems are often on par in terms of performance gains. A major challenge is that failures often arise from an ineffective exchange of critical information during inter-agent interaction and coordination. Different from exist-ing multi-agent debate paradigms that rely on synchronous turn-taking and shar-ing information across different agents, we propose an inter-agent protocol based on shared memory b uff er in ference - referred to as Muffin - in an asynchronous agentic framework. In the first step, an orchestrator routes queries based on their reasoning demands and delegates demanding ones to a multi-agent setting, where a shared memory buffer provides asynchronous exchange of intermediate findings while an agent’s private reasoning remains local. Our experiments show that our framework Muffin outperforms established competitors, achieving the best accu-racy in 17 out of 20 of our benchmark settings, and provides a better quality-cost trade-off than multi-agent debate: Muffin improves accuracy by 19.2 accuracy points while using 77.4% fewer tokens, without requiring full-trace sharing. 

1 INTRODUCTION 

Frontier models like Opus (Anthropic, 2026), Gemini (Google DeepMind, 2026), ChatGPT (Ope-nAI, 2026) have made a substantial leap in artificial intelligence by demonstrating reasoning ca-pabilities that approach human performance in a variety of domains (Luo et al., 2024; Bermejo et al., 2025; Alohali et al., 2025; Street et al., 2026). In the current era of Agentic AI, we see a shift towards systems that are able to plan, act, use tools, and apply feedback loops for enhanced performance (Abou Ali et al., 2025; Pati, 2025; Xi et al., 2025). However, strong single-agent rea-soning does not remove the need for collaboration. More complex tasks often require decomposing the problem, checking partial information, and integrating the conclusions generated by different reasoning parts. This motivates goal-oriented multi-agent behavior that goes beyond single-agent responses toward agent collaboration supported by memory (Zhang et al., 2025), reasoning (Subra-maniam et al., 2025), or environmental interaction (Lan et al., 2024). Recent multi-agent research has been applied to scientific experimentation (Ghareeb et al., 2026), embodied agents (Huang et al., 2023), or societal simulation (Gao et al., 2023). Nevertheless, re-cent studies suggest that multi-agent systems do not automatically outperform strong single-agent or repeated-sampling baselines (Xia et al., 2024; Kapoor et al., 2025), because critical information is lost during inter-agent coordination and verification processes fail (Cemri et al., 2025). In particular, a key limitation is that many multi-agent systems communicate after an agent has produced a com-plete output, leaving partial critical findings unavailable to peer agents while simultaneously over-whelming them with verbose, task-irrelevant reasoning traces that increase context overhead (Liu et al., 2024; Ning et al., 2024; Du et al., 2024). We propose an asynchronous system based on shared memory b uff er in ference, referred to as Muf-fin , that enables exchange of agents’ novel insights. The general workflow is visualized in Figure 1. In the first step, an Orchestrator routes a user query based on the expected reasoning demands, i.e., whether a query can be solved directly or a multi-step reasoning is required. For more demanding queries, multiple agents are instantiated by assigning each of them a specialized role, and a subtask, both provided by the orchestrator. For an efficient exchange of relevant insights, a shared memory provides a controlled and selective exchange of intermediate findings. An agent only pushes rel-evant information into the buffer which is expected to help in making progress in a collaborative problem solving manner. We keep an agent’s own reasoning local. After a finite reasoning horizon, a Summarizer is fed the final messages from each agent along the agents’ meta information and the initial user query, to produce the final response. In our empirical study, we show how Muffin provides reasoning capabilities that are on the Pareto front w.r.t. the downstream accuracy and the token consumption. We evaluate on four reasoning benchmarks and report performance gains across four open-weight language models. By applying Muffin, we improve the strongest baseline by 4.4 accuracy points on average across all bench-marks, with larger gains on OlymMATH-E of 11.8 accuracy points. Moreover, we show that it reaches a better quality-cost trade-off compared to multi-agent debate architectures, improving accuracy by 19.2 accuracy points while using 77.4% fewer tokens in the step-wise analysis, as in our pipeline we exchange only selected findings instead of full reasoning traces. The key contributions of our work: • Shared Memory Buffer: We propose Muffin, an LLM-based multi-agent workflow in which agents asynchronously exchange selected intermediate findings through a shared buffer. • Asynchronously Selective Information Sharing: Muffin keeps each agent’s local reasoning in-formation private and shares partial intermediate findings through the buffer asynchronously, en-abling agent collaboration without exposing full reasoning traces. • Accuracy-Cost Trade-off: Muffin outperforms single-agent and majority-vote baselines across four reasoning benchmarks, while lying on the accuracy-token Pareto frontier. 

2 RELATED WORK 

Multi-agent collaboration. Recent research has shown that agentic systems can improve reason-ing and performance by organizing multiple specialized agents rather than relying on a single lan-guage model inference (Hong et al., 2024; Chen et al., 2024a; Xi et al., 2025; Abou Ali et al., 2025). Several systems instantiate this idea through task decomposition (Chen et al., 2024b; Qian et al., 2024), where agents will have specialized roles while working on different parts of a task, including general reasoning workflows and software development pipelines. General-purpose agent frame-works make this coordination more flexible by allowing LLM-backed agents, tools, and humans to be composed into different interaction patterns (Wu et al., 2024; Moura & CrewAI Inc., 2023; LangChain AI, 2024). Despite these differences, a common denominator of most multi-agent sys-2Preprint tems is that they still integrate outputs only after full messages, subtasks, or rounds have completed, limiting how agents can adapt to one another’s reasoning while inference is still unfinished. 

Aggregation and shared intermediate information. Some studies on aggregation show how outputs from other inference processes can be used as additional context for improving final an-swers (Jiang et al., 2023; Wang et al., 2024b). Layered aggregation uses responses from earlier model calls to condition later ones, enhancing the complement of strengths across models (Wang et al., 2025). Debate-based systems instead expose agents to peer answers and critiques over multi-ple rounds before selecting a final answer (Du et al., 2024; Liang et al., 2024; Xiong et al., 2023). These results support the value of shared intermediate information, but the shared object is usually a complete response, critique, or round output, rather than having the LLM judge which information is useful enough to share. This leaves open how agents should share and use partial information before a full answer has been completed. 

Fine-grained and streaming interaction. More recent work studies collaboration below the level of complete turns through token-level collaboration (Hsu et al., 2025), which lets other agents ob-serve generation progress and adjust their reasoning before a complete answer is produced. Sim-ilarly, streaming communication sends reasoning steps to downstream agents during generation, reducing the delay caused by waiting for complete turns (Ning et al., 2024; Yang et al., 2026). This direction suggests that sharing partial reasoning during inference can reduce coordination latency and enable earlier reactions, while leaving room to study how partial information can be selected, maintained, and jointly reused. A key challenge is to support asynchronous sharing, where agents can make useful findings available to others without exposing their full reasoning traces. This frames a middle ground between isolated final-answer aggregation and full-trace exchange.

4 EXPERIMENTS 

Our experiments are organized around three questions. First, we evaluate whether our method im-proves reasoning accuracy. Second, we study the inference-cost trade-off introduced by multi-agent collaboration. Third, we analyze whether the shared buffer helps agents use intermediate findings from other agents before final summarization. 4.1 SETUP 

We first describe the overall experimental setting, including the benchmarks, baselines, and imple-mentation details. 

Benchmarks. We evaluate on four benchmarks that cover complementary reasoning tasks. The first two follow the evaluation protocol of prior work (Du et al., 2024): • Chess Move Validity , derived from the BIG-Bench Chess State Tracking benchmark (bench au-thors, 2023), measures a system’s predictive performance of a valid move in a chess setting. 5Preprint • MMLU-Pro (Wang et al., 2024a) for broad multi-domain multiple-choice reasoning. • GPQA-Diamond (Rein et al., 2024) tests difficult, knowledge-intensive scientific reasoning. • OlymMATH (Sun et al., 2025), which evaluates mathematical problem solving that often requires multi-step derivation, proof-like reasoning, and verification. For Chess Move Validity and MMLU-Pro, we use the 100 examples from each dataset, following the 100-example evaluation setting of prior work (Du et al., 2024). For GPQA-Diamond, we evaluate on the full Diamond split of 198 examples. For OlymMATH, we use 100 examples from the English easy (-E) subset and 100 examples from the English hard (-H) subset, and report the results for the two subsets separately. 

Baselines. We compare Muffin with single-agent, majority-voting based multi-agent, and multi-agent debate: • Single-Agent uses only one language model agent to solve the task. We explicitly allow for multiple reasoning steps and not just one-shot inference. • Majority Vote leverages multiple independent single-agent, and gathers their final results and choose the majority answer from them. • Multi-Agent Debate follows the setting of the Multi-agent Debate (Du et al., 2024), where the agents will revise their responses after observing other agents’ output. 

Implementation Details. We evaluate all methods with four LLMs: gemma-4-E4B-it ,

gemma-4-31B-it , Qwen3.8-27B , and Qwen3.5-4B (Team, 2026; Qwen Team, 2026b;a). All models are served on a compute cluster through a vLLM (Kwon et al., 2023) OpenAI-compatible endpoint. All baselines and our method call the same served model in each comparison. We serve the models using tensor parallelism from vLLM , utilizing two H100 GPUs for the smaller models and four H100 GPUs for the larger models. As LLM inference might introduce small run-to-run dif-ference, we repeat each experiment three times and report averaged results. For method execution and agent parameters, unless explicitly stated otherwise, we set the number of steps to five for all methods and fix the number of agents to three for Majority Vote, Multi-Agent Debate, and Muffin. Our code is publicly available: https://anonymous.4open.science/r/Muffin 

4.2 EFFECTIVENESS AND EFFICIENCY 

Hypothesis 1: Asynchronous sharing of intermediate findings through a memory buffer im-proves accuracy over single-agent, majority-vote, and multi-agent debate baselines under the same step budget. 

For the first experiment, we want to support the hypothesis that sharing intermediate findings rather than the full output from others can improve accuracy. Under the default setting defined in Sec-tion 4.1, we compare the task performance of Muffin against the baselines across all selected bench-marks and models. Table 1 shows that Muffin achieves the best accuracy in 17 out of 20 in our evaluation settings and is second-best in the remaining three. The largest improvements appear on the OlymMATH benchmark, and relative to the strongest baseline, Muffin improves accuracy by 11.8 points on OlymMATH-E and 2.6 points on OlymMATH-H on average. On benchmarks where the baselines perform better, the margin is smaller, showing that the main benefit appears when the task leaves room for multi-step collaborative reasoning. Muffin also shows slightly higher standard deviations in some settings, which is expected because dynamic agent roles and LLM-decided shared-finding exchange introduce more variation across runs.

After each step, we check whether the agents’ answers change after a finding is published. We report the mean count per run for each step transition. Figure 7 shows that, on Chess with gemma-4-31B-it , 20.5% of all findings induced a change in the answer. Notably, this insight is highest directly in the first step transition with 43.2% and decreases over all step transitions to 15.8% in the last recorded step, indicating agents’ convergence as the memory buffer is filled with insights. Figure 8 provides more in-depth insights into the changes. Across all step transitions, we observe a majority for wrong-to-correct changes in contrast to correct-to-wrong changes showing a decreasing behavior. In later steps, the shared findings show a more bal-anced view with 34.8% vs. 21.9%. Therefore, early findings shared via the memory buffer have the highest marginal value. 4.3 ABLATION STUDIES 

We conduct ablation studies to inspect which parts of our method contribute to the final performance. These experiments focus on two design choices: whether the final summarizer improves over the agents’ last inference outputs, and how the number of shared findings affects the performance. • Agents’ final outputs versus summarizer output. We compare the final answer produced by the summarizer with the last individual outputs generated by the agents, which include the last findings from the shared buffer in their input. This evaluates whether the summarizer is giving additional benefit by combining agents’ final evidence. We compute this comparison across all benchmarks and two model sizes from the Gemma-4 family. As shown in Table 2, the summarizer changes the last agent answer in 11.14% of cases. Among those changed cases, wrong-to-correct changes account for 32.05%, while correct-to-wrong changes account for 21.20%. This means beneficial corrections are 10.85 percentage points more than harmful changes. This suggests that the summarizer does more than copy or choose the majority from the final agent outputs, and can recover correct answers from the agents’ final evidence while introducing less harmful noise. • Number of shared findings. Next, we control how much information an agent can retrieve from the buffer, and test whether more shared context always improves collaboration. We use OlymMATH-Easy with the Gemma-4 models. Figure 6 shows that increasing the number of shared findings does not always improve accuracy. For gemma-4-E4B-it , the best result appears at 

k = 10 , improving over k = 5 by 5.0 accuracy points, but adding more findings reduces perfor-mance. By contrast, gemma-4-31B-it is less sensitive to this budget, with accuracy changing by only 2.0 points. This suggests that a moderate number of shared findings is sufficient, while adding more findings can introduce noise by including redundant or outdated findings. 4.4 LIMITATIONS AND DISCUSSION 

Our results show that shared intermediate findings in an asynchronous manner can improve multi-agent reasoning without agents exchanging or using the full reasoning traces. Our evaluation is fo-cused on question-answering and reasoning benchmarks. Future work should evaluate shared buffer collaboration on tasks that require tool use, planning, environment interaction, or long-horizon ex-ecution. Our experiments are also limited by compute cost. Although we test multiple models, benchmarks, and agent configurations, we cannot cover all closed- and open-weight models with different experimental settings. Broader evaluation would help to clarify how the shared buffer can adapt across different agentic usages. 

5 CONCLUSION 

Existing multi-agent debate methods rely on synchronous turn-taking and sharing information across different agents. We introduce Muffin , an agentic memory b uff er in ference framework in which an orchestrator first routes queries by expected reasoning demand. For more demanding queries, the collaborating agents exchange intermediate findings asynchronously through a shared memory buffer while keeping private reasoning local. Finally, a summarizer produces the final answer from compact agent summaries. Across four reasoning benchmarks and four language models, Muffin achieves the best accuracy in 17 out of 20 benchmark settings and reaches a better accuracy-token trade-off than multi-agent debate. Muffin improves final accuracy by 19.2 accuracy points while using 77.4% fewer tokens than multi-agent debate, showing that selective sharing of findings is a lightweight alternative to full-trace exchange.
