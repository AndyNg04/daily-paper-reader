# Are Self-Evolving Agents Continual Learners? 

Xiaoyin Chen 1,2,* , Yizheng Huang 3, Yinglun Xu 3, Ziyun Zhao 3, Emmett McQuinn 3, Julie Liu 3 and Hope Yao 3   

> 1Mila – Quebec AI Institute, 2Université de Montréal, 3Google DeepMind, *Work done as a student researcher at Google DeepMind

Large language model agents are often deployed in environments where new knowledge, tools, and workflows keep arriving. Such an agent is therefore expected to adapt continually, learning new tasks as they arrive without forgetting earlier ones. This resembles the continual learning problem, but at a pace that conventional gradient updates cannot sustain. Nonparametric self-evolving agents are a natural alternative: they adapt by rewriting their own harness, such as prompts, memory, and skills, from task feedback while the model weights stay frozen. We study whether such agents are effective continual learners across four drifting task streams that shift in topic, workflow, or domain (built from BIRD, BFCL, and ScienceWorld). Evaluating three representative methods spanning experience retrieval and self-modification (ReasoningBank, GEPA, and Meta-Harness), we find that although self-evolution improves aggregate performance on most streams, higher plasticity consistently comes at the cost of stability. Specifically, self-modifying methods apply global edits to a shared prompt or workspace, interfering with unseen tasks and overwriting earlier knowledge as the stream shifts. Conversely, similarity-based memory retrieval localizes updates across distant domains, but still retrieves foreign memories on unseen tasks and suffers from retrieval collision when similar queries require conflicting workflows. These findings show that current self-evolving agents remain incomplete continual learners. 

1. Introduction 

Large language models (LLMs) are increasingly used as agents that act in interactive environments: they operate software tools and systems (Patil et al., 2025; Yao et al., 2023; Zhang et al., 2025b), navigate embodied simulators (Shridhar et al., 2020; Wang et al., 2022), and query databases or write code on behalf of users (Li et al., 2023; Wang et al., 2025). The skills such an agent requires are not fixed at training time. New tasks, tools, and workflows continue to emerge after the weights are frozen, and an agent that serves users over an extended period must learn each new task as it arrives while preserving what it has already learned. This form of learning resembles the classical continual learning problem, which studies how a model can be trained on new tasks over time without forgetting earlier ones (De Lange et al., 2022; Parisi et al., 2019; van de Ven and Tolias, 2019). Continual learning has recently emerged as a central challenge for LLMs (Jang et al., 2022; Ke et al., 2023; Luo et al., 2023; Shenfeld et al., 2026; Shi et al., 2024; Wu et al., 2024). Conventionally, it has been realized through gradient updates. An LLM agent, however, is expected to adapt at the timescale of use: every interaction with the environment may yield knowledge that is useful in a later session, and that knowledge should be available as soon as the next session begins. Performing gradient updates at this pace is challenging: retraining an LLM after every session is prohibitively expensive, and fine-tuning on a small number of recent interactions is known to erode general capabilities (Luo et al., 2023). The in-context learning ability of LLMs (Brown et al., 2020; Dong et al., 2022) suggests an alternative route to adaptation. Rather than the weights, an agent can update its harness , everything wrapped around the model: the system prompt, the accumulated memory, the skill libraries, and the control code that orchestrates them. Nonparametric self-evolving agents adopt precisely this strategy, refining the harness from task outcomes and environment feedback while the weights remain frozen. Two paradigms have emerged. Self-modification rewrites the artifacts on which the agent runs, such as

In either paradigm the harness constitutes a state carried across tasks; updating it is inexpensive, takes effect immediately, and leaves the model weights untouched. Self-evolving agents are therefore natural candidates for continual learning at inference time. Both paradigms demonstrate substantial gains on stationary, single-domain benchmarks, yet whether they support continual learning has not been examined. Iterative feedback may drive an agent toward narrow, task-specific shortcuts, such as idiosyncratic formatting templates or environ-ment-specific action sequences, rather than transferable problem-solving strategies. Real-world scenarios, moreover, extend beyond a single benchmark: the agent faces a stream of heterogeneous tasks served by one shared harness, and every update made for one task applies to all tasks that follow. Whether self-evolution under these conditions accumulates durable gains or compounding interference is unknown. In short: Are current self-evolving LLM agents effective continual learners? 

We address this question by evaluating the continual learning dynamics of self-evolving agents on non-stationary task streams. After formalizing the evolver , the function that updates the harness from collected experience, together with task streams over multiple task groups (§2), we construct four drifting stream scenarios that train one task group at a time in contiguous blocks (§3, §4.1). Built from BIRD (Li et al., 2023), BFCL (Patil et al., 2025), and ScienceWorld (Wang et al., 2022), these streams isolate shifts in subject matter ( topic drift ), interaction workflow ( workflow drift ), environment and action space ( domain drift ), and their sequential combination ( compound drift ). We evaluate three representative self-evolving methods that span both paradigms and progressively larger harness surfaces: ReasoningBank (Ouyang et al., 2025) retrieves accumulated memory items, GEPA (Agrawal et al., 2025) rewrites a strategy section in the system prompt, and Meta-Harness (Lee et al., 2026) edits the system prompt, memory and skill files, and controller code. To characterize these dynamics, we measure terminal and average advantage over the seed harness (§3.2) and decompose stream performance into within-block plasticity (𝑃 ) and cross-block stability (𝑆 ), combining pre-block interference (¯ 𝐼 ) on unseen groups and post-block forgetting ( ¯ 𝐹 ) on earlier groups. Three main findings emerge: • Current methods trade stability for plasticity (§4.2). While self-evolution improves overall stream performance in most settings, no method achieves both high plasticity and high stability: expanding the editable surface from retrieved memories (ReasoningBank) to the system prompt (GEPA) and full workspace (Meta-Harness) increases plasticity or edit freedom at the cost of cross-block stability. • Self-modification causes cross-task interference and overwriting (§4.3). Because GEPA and Meta-Harness apply a single shared prompt or workspace to every incoming task, task-specific rules specialized to one block interfere with unseen tasks before their block begins and are compressed or overwritten by later blocks. • Similarity-based retrieval cannot prevent interference or collision (§4.4). Retrieving experi-ences by query similarity (ReasoningBank) avoids post-block forgetting across distant domains, but still injects foreign memories into unseen task groups and causes retrieval collision when distinct workflows share the same domain and embedding space. Our results show that current self-evolving agents remain incomplete continual learners, calling for mechanisms that isolate task-specific updates in the harness and condition retrieval beyond surface query similarity.

3. Methodology 

In this work, we study two factors of the problem, the evolver 𝑓 and the weight schedule 𝑤 of the task stream, and we evaluate an evolver by how much it improves the objective ¯ 𝐽 𝑤 ( 𝑓 ) of Eq. 6 over the seed harness. 

3.1. Task Stream Configurations 

We instantiate the task stream as a drifting stream, in which 𝑤 𝑡 is one-hot and piecewise-constant: the stream is a sequence of contiguous blocks, each drawing all of its tasks from a single task group, and the active group changes only at block boundaries. Within a block, every update is driven by the active group, while earlier groups receive no further tasks and hence no further feedback, and later groups have not yet been encountered. In continual deployment, transitions between blocks may alter the subject matter (topic drift), the interaction workflow required for a correct response (workflow drift), the environment and action space itself (domain drift), or a combination of all three (compound drift); we detail the concrete benchmark streams that instantiate these four drift scenarios in §4.1. In every stream the method maintains one shared harness across the entire horizon. The stream never reveals the group label of a task or the block boundaries, and the agent is never told that it operates in a drifting stream or that it should balance performance across groups. The agent must infer the structure of incoming tasks on its own and encode any distinction it finds in the harness, mirroring task-free continual learning scenarios (Aljundi et al., 2019; Buzzega et al., 2020; De Lange et al., 2022).

4.2. Current Methods Trade Stability for Plasticity

Decomposing these aggregate scores into within-block plasticity 𝑃 and cross-block stability 𝑆 ,however, reveals a consistent negative correlation between learning the active block and preserving performance on the others (Table 1; Figure 2). Across all four scenarios, plasticity and stability exhibit a clear trade-off: higher plasticity on the group being trained is accompanied by larger stability losses across blocks, so the most plastic method in each scenario is always less stable than the most conservative one. This trade-off reflects where each method applies its updates. GEPA rewrites a single shared strategy prompt that is injected into every rollout. A rule discovered during a block therefore changes the agent’s behavior broadly across all tasks of that group, giving GEPA the highest plasticity in every scenario ( +6.2 on average, reaching +11 .0 on workflow drift and +7.5 on compound drift). Because later blocks rewrite the same shared prompt and apply it to every group, however, GEPA also incurs the largest stability loss ( −4.3 on average). ReasoningBank, by contrast, leaves the system prompt untouched, appending one memory item per episode to an external store and retrieving only the single most similar item at read time. Because an item is injected only into episodes whose query resembles its source episode, updates remain localized and ReasoningBank achieves the highest average stability ( −1.9, with −0.4 on domain drift and −1.4 on compound drift), at the cost of roughly half the plasticity of GEPA ( +3.3 on average). 5. Related Work 

Self-evolving agents. Self-evolving agents update themselves from their own experience rather than remaining fixed after training. In the nonparametric form studied here, the evolver edits the 

> 11 Are Self-Evolving Agents Continual Learners?

harness and leaves the weights untouched, following one of two paradigms. Self-modification rewrites the artifacts the agent runs on: automatic prompt optimization such as GEPA (Agrawal et al., 2025), TextGrad (Yuksekgonul et al., 2024), and PromptBreeder (Fernando et al., 2024) rewrites the system prompt from rollout feedback, while ADAS (Hu et al., 2025), Darwin Gödel Machine (Zhang et al., 2025c), EvoTest (He et al., 2026), and Meta-Harness (Lee et al., 2026) extend the edits to the agent’s code (Yin et al., 2024). Experience augmentation keeps the artifacts fixed and accumulates an external store that later episodes retrieve from: reflections in Reflexion (Shinn et al., 2023) and ExpeL (Zhao et al., 2024), skills in Voyager (Wang et al., 2024), and memory items in ReasoningBank (Ouyang et al., 2025), MemGen (Zhang et al., 2025a), and Mem0 (Chhikara et al., 2025). Parametric counterparts instead update the weights at test time, through self-correction training in SCoRe (Kumar et al., 2024), reinforcement learning in TTRL (Zuo et al., 2025) and TTT-Discover (Yuksekgonul et al., 2026), or a learned evolver in LSE (Chen et al., 2026). Unlike prior work evaluated within a single task family, we study nonparametric methods on heterogeneous streams. 

Continual learning. Continual learning studies a learner that faces a sequence of tasks and must acquire each without degrading performance on earlier ones, known as catastrophic forgetting (French, 1999; McCloskey and Cohen, 1989). Gradient-based methods counter it by protecting weights important to earlier tasks (Kirkpatrick et al., 2017), rehearsing stored examples (Buzzega et al., 2020; Chaudhry et al., 2019; Lopez-Paz and Ranzato, 2017), or shaping updates to maximize transfer and minimize interference (Riemer et al., 2018); see Parisi et al. (2019) and De Lange et al. (2022) for surveys. Our plasticity and stability metrics adapt standard continual-learning evaluation (Kemker et al., 2018; Lopez-Paz and Ranzato, 2017); task-free and online formulations relax explicit task boundaries (Aljundi et al., 2019; Koh et al., 2022), and continual evaluation exposes transient drops missed by end-of-task evaluation (De Lange et al., 2023), motivating our checkpoint resolution. For LLMs, continual learning has focused on weight updates (Shi et al., 2024; Wu et al., 2024): continual pre-training on emerging corpora (Jang et al., 2022; Ke et al., 2023), forgetting under sequential fine-tuning (Luo et al., 2023), and mitigation algorithms (Shenfeld et al., 2026). Rather than updating weights, the agents studied here keep weights frozen and carry their state in the harness. 

6. Conclusion 

We asked whether nonparametric self-evolving LLM agents are effective continual learners, and found that current methods remain caught in a trade-off between plasticity and stability. Across four drifting stream scenarios spanning shifts in topic, workflow, domain, and their combination, self-evolution improves overall performance over the seed harness in most settings, yet no method learns new task groups strongly without degrading others. Self-modifying methods (GEPA and Meta-Harness) can achieve high plasticity when rewriting a shared prompt, but because task-specific rules are applied globally across all subsequent rollouts, instructions learned on one block interfere with unseen tasks and are compressed or overwritten by later blocks, most severely when consecutive blocks share a domain but require conflicting workflows. Experience augmentation via query-similarity retrieval (ReasoningBank) avoids overwriting the shared prompt and prevents forgetting across distant domains, but still injects foreign memories before a group is encountered and suffers from retrieval collision when distinct workflows occupy the same region of the embedding space. Together, these findings expose the limitations of current self-evolving agents as continual learners.
