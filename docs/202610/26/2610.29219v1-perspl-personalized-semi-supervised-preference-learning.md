## 摘要
个性化奖励模型需要针对特定用户的偏好比较数据，但收集此类反馈成本高昂，而且每位用户能够获得的监督信号有限。与此同时，可以在不提供用户身份或偏好标签的情况下生成大量回答，但现有个性化奖励模型并未利用这些数据。直接从这些回答中学习并不容易：成对目标函数约束的是同一提示下的相对分数，而对单条回答进行伪标注，则要求同一用户的分数在不同提示之间具有可比性。我们提出 PerSPL（个性化半监督偏好学习），这是一种与骨干模型无关的框架，通过对成对回答的平均分数进行中心化，稳定跨提示的分数坐标，并迭代地将无标签回答转化为针对用户的训练信号。在四个基准测试——PersonalLLM、HelpSteer2、Reddit TLDR 和 Chatbot Arena——上与七种具有代表性的基线方法进行比较时，PerSPL 在已见用户和未见用户两种设置下，均取得了所评估方法中报告的最高平均准确率。后两个基准分别提供了真实用户在摘要任务和开放域聊天机器人交互中的偏好比较数据。这些结果表明，当每位用户的偏好标签稀缺时，无标签回答可以为个性化奖励建模提供额外监督。

## Abstract
Personalized reward models require user-specific preference comparisons, but collecting such feedback is costly and provides only limited supervision for each user. At the same time, large pools of responses can be generated without user identities or preference labels, yet existing personalized reward models leave this data unused. Directly learning from these responses is difficult because pairwise objectives constrain relative scores within a prompt, whereas pseudo-labeling individual responses requires scores that are comparable across prompts for the same user. We propose \textbf{PerSPL} (Personalized Semi-supervised Preference Learning), a backbone-agnostic framework that uses pair-mean score centering to stabilize this cross-prompt score coordinate and iteratively turns unlabeled responses into user-specific training signals. Against seven representative baselines across four benchmarks---PersonalLLM, HelpSteer2, Reddit TLDR, and Chatbot Arena---PerSPL achieves the highest reported mean accuracy among the evaluated methods for both seen and unseen users. The two latter benchmarks provide real-user preference comparisons in summarization and open-domain chatbot interaction, respectively. These results indicate that unlabeled responses can provide additional supervision for personalized reward modeling when per-user preference labels are scarce.

# PerSPL：个性化半监督偏好学习论文总结

## 1. 核心问题与研究背景

- **研究目标**：在每位用户只有少量偏好比较数据的情况下，利用大量**无用户身份、无偏好标签的单条回答**，提升个性化奖励模型的预测能力。
- **现实动机**：
  - 不同用户对回答的内容、风格、详细程度等存在系统性分歧，统一奖励模型可能掩盖这些差异。
  - 个性化建模需要用户自己的反馈，但比较两条回答的标注成本较高，新用户尤其缺乏数据。
  - 相比之下，生成或收集回答更容易，因此共享无标签回答池是一种潜在的额外监督来源。

### 关键障碍：成对排序正确，不代表单条分数可比较

传统 Bradley–Terry（BT）目标只要求：同一提示下，用户喜欢的回答得分高于不喜欢的回答。它并不确定这两个分数的共同位置。

例如，两组偏好回答的分数分别为 `(101, 100)` 和 `(1, 0)`，组内排序都正确，但第一组的“不喜欢回答”却远高于第二组的“喜欢回答”。因此，不能直接用一个跨提示阈值判断单条回答是否值得该用户喜欢。

**论文的核心含义是：先稳定同一用户在不同提示上的评分基准，再将单条无标签回答转化为个性化监督。** 研究属于**少样本个性化**，而不是没有任何用户反馈的零样本个性化。

## 2. 方法论：核心思想、技术细节与算法流程

PerSPL 由四个环节组成：**成对均值居中、逐用户校准、置信度筛选、迭代自训练**。

### 2.1 成对均值分数居中

- 保留 BT 成对损失，学习“偏好回答的分数高于拒绝回答”。
- 增加正则项，惩罚每组回答平均分数偏离零的程度：
  - 即最小化“两个回答分数均值的平方”。
- 这一操作直接约束的是**成对分数的共同位置**，而非直接压缩两者差值。
- 但由于分数来自共享模型参数，实际训练仍可能同时改变均值和分差，不能理解为严格保持排序不变的后处理。

**理论解释**：

- 论文证明，跨提示排序的逻辑损失，可以由“组内 BT 损失 + 成对均值方差的四分之一”控制。
- 单条回答相对统一阈值的分类风险，也与成对均值偏离该阈值的程度有关。
- 在特定高斯模型与非对齐条件下，小幅居中正则可带来单条分类准确率的一阶提升，而成对 BT 风险只产生二阶增加。

这些结果说明居中为何可能有用，但**不是完整自训练流程必然提升准确率的普适保证**。

### 2.2 每位用户独立进行保序校准

- 对用户已有的比较数据：
  - 被选回答的分数赋标签 `1`；
  - 被拒回答的分数赋标签 `0`。
- 使用 **isotonic regression（保序回归）**，学习分数到概率的单调映射。
- 根据映射达到 `0.5` 的位置，确定该用户的评分锚点。

需要注意，这里的概率表示“该分数在用户比较数据中出现在被选侧的经验概率”，不等于与候选回答集合无关的绝对满意概率。

### 2.3 生成用户特定的伪标签

对于共享回答池中的每条回答：

- 校准概率高于阈值 `τ`：标为正例；
- 低于 `1−τ`：标为负例；
- 中间区域：放弃标注。

因此，**同一条回答可以对不同用户产生不同伪标签**。保留下来的样本通过相对用户锚点的二元交叉熵参与训练，原始成对比较始终保留。

### 2.4 迭代自训练

1. 首轮仅使用成对标签和居中正则训练模型。
2. 为每位用户拟合校准器，并生成伪标签。
3. 后续轮次联合优化：
   - 原始成对损失；
   - 无标签回答的伪标签损失；
   - 居中正则。
4. 每个内层训练 epoch 后，仅使用原始有标签数据重新拟合校准器。
5. 每轮外层迭代结束后刷新伪标签，下一轮**重新随机初始化奖励模型参数**。

### 2.5 实际使用的模型

- 冻结 **Skywork-Reward-V2-Llama-3.1-8B**，缓存其 **4,096 维末 token 表示**。
- 奖励头学习共享低秩线性基，以及每位用户的 softmax 混合权重。
- 对未见用户，冻结共享基，只根据支持集拟合该用户的权重。
- 主实验居中系数统一为 `0.01`，低秩维度主要为 `2` 或 `5`。

虽然框架被描述为“骨干无关”，但实验主要验证了上述冻结表示与低秩奖励头配置。

## 6. 主要结论与发现

### 6.1 所有主要设置均取得最高报告均值，但增益幅度不同

下表为整体准确率，即已见与未见结果的平均：

| 设置 | PerSPL | 最强基线 | 平均提升 |
|---|---:|---:|---:|
| PersonalLLM，多样性0.1 | 95.6% | LoRe：94.3% | 约1.3个百分点 |
| HelpSteer2，多样性0.1 | 71.4% | MRM：70.8% | 约0.6个百分点 |
| Reddit TLDR，100标签 | 70.4% | MRM：69.9% | 约0.5个百分点 |
| Reddit TLDR，150标签 | 70.6% | MRM：69.8% | 约0.8个百分点 |
| Chatbot Arena | 82.01% | LoRe：79.83% | 约2.19个百分点 |

- 主表所有已见、未见用户列中，PerSPL 均为最高均值。
- 附录配对分析中的5种设置，整体增益区间均排除零。
- 但 HelpSteer2 较高用户异质性设置的**未见用户增益区间包含零**，因此“均值领先”不等于每个条件都获得明确统计支持。

### 6.2 最重要发现：居中与无标签训练存在交互作用

在4个组件消融设置中：

- 单独增加居中正则，已见用户准确率仅变化约 **−0.1至+0.1个百分点**。
- 不居中就使用无标签训练，准确率下降 **2.9至6.5个百分点**。
- 有居中时，无标签训练带来 **0.5至1.8个百分点**提升。

**这支持论文的核心解释：居中的主要价值不是单独提高组内排序，而是让伪标签学习从有害变为有益。** 不过，无标签训练对未见用户的额外收益较小，部分置信区间包含零。

### 6.3 鲁棒性结果有明确边界

- 标签翻转噪声增大时，两种方法都退化，但 PerSPL 在测试范围内持续领先 MRM。
- 在已见用户50–200对标签、未见用户10–50对支持比较的范围内，收益仍然存在。
- 域外生成器比例从0升至100%时，相对有标签参考的整体收益由 **3.21** 降至 **0.66个百分点**。
- 但100%域外时，未见用户均值为82.45%，略低于参考模型82.66%；因此不能把整体收益解读为每类用户都受益。

- **真正实现用户特定伪标签**：共享回答池可以服务不同偏好的用户。
- **理论与实证相互支持**：包含风险界、高斯示例、优化路径分析、真实数据诊断和完整流程消融。

- **包含真实用户任务**：摘要和开放域聊天结果增强了应用相关性。

## 8. 不足与局限

- **不能零反馈冷启动**：每位用户都需要标签来适配和校准。
- **小样本校准不确定**：少量标签下保序映射可能阶梯化或过拟合；高“置信度”不代表真实可靠。
- **偏好标签具有相对性**：被选回答只优于其配对对象，不一定绝对优秀；将其转化为单条正负标签依赖候选分布。
- **自训练可能放大偏差**：错误伪标签会反馈到模型，置信度过滤也可能过度选择容易样本；论文尚未审计不同用户群体的伪标签精度和覆盖率。
- **架构泛化未充分验证**：缺少端到端微调、更大模型及多种骨干的系统比较。
- **人口规模较小**：最多200名用户；逐用户评分与校准在大规模服务中的成本尚未明确。
- **分布偏移范围有限**：仅覆盖指定生成器混合，未验证语义、人口属性、时间或对抗偏移。
- **任务与语言受限**：集中于英文比较、摘要和聊天，未覆盖跨语言、复杂多轮、代码及长期交互。
- **尚未证明下游体验改善**：评价主要是离线偏好预测，而非策略优化后的用户满意度或长期使用效果。
- **隐私与许可约束**：真实用户历史涉及隐私、同意和身份保护；部分数据及软件具有非商业使用限制。

**总体评价**：PerSPL 的主要贡献是揭示并处理了“成对偏好学习如何可靠利用单条无标签回答”的评分基准问题。现有证据较有力地支持该机制在冻结表示、少样本个性化设置中的有效性，但对大规模部署、零样本用户、广泛分布偏移与实际交互收益仍需进一步验证。
