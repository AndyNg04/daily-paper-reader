## 摘要
终身学习型大语言模型（LLM）智能体必须从不断扩展的交互历史中学习，同时在有界上下文窗口内做出每个决策。记忆使过去的经验得以利用，但智能体仍可能需要根据检索到的记录推断如何解决每项新任务。技能提供可复用的流程，但可能缺少应用这些流程所需的任务特定事实。由于检索到的记忆和技能会塑造智能体的行为，它们也会影响未来可用于学习的经验。我们提出 MemCryst，这是一种在冻结语言模型的条件下，通过双向学习记忆与技能实现终身上下文适应的框架。存储在记忆中的重复出现的情节支持技能的创建与修订，而由这些技能引导的交互则为后续学习提供新的记忆。从记忆中检索的事实与学习到的技能共同构成智能体的上下文；任务结果则会调整实际提供给智能体的记录对未来检索的影响力，而不改写记录内容。在涵盖具身控制、长文档阅读、对话、数学和代码的十种设置中，MemCryst 在报告的七项比较中取得领先。在 ALFWorld 上，联合提供记忆与技能的成功率为 63.17%，高于仅提供记忆的 59.83% 和仅提供技能的 50.50%。代码见 https://github.com/tianyi0216/Memcryst.git

## Abstract
Lifelong LLM agents must learn from an expanding history of interactions while making each decision within a bounded context window. Memory makes past experience available, but the agent may still need to infer how to solve each new task from the retrieved records. Skills provide reusable procedures, yet may omit the task-specific facts needed to apply them. Because retrieved memory and skills shape the agent's behavior, they also influence the experience available for future learning. We introduce MemCryst, a framework for lifelong context adaptation through bidirectional learning of memory and skills with a frozen language model. Recurring episodes stored in memory support skill creation and revision, and the interactions guided by those skills supply new memory for subsequent learning. Facts retrieved from memory and learned skills jointly form the agent's context, while task outcomes adjust the future retrieval influence of the records actually served without rewriting their content. Across ten settings spanning embodied control, long-document reading, conversation, mathematics, and code, MemCryst leads seven reported comparisons. On ALFWorld, joint serving achieves 63.17% success, compared with 59.83% for memory-only and 50.50% for skill-only serving. Code is available at https://github.com/tianyi0216/Memcryst.git

## 1. 核心问题与研究背景

### 1.1 论文要解决什么问题？

长期运行的 LLM 智能体会不断积累交互历史，但每次决策能使用的上下文有限。论文研究的是：

> **在不更新语言模型参数的条件下，如何把持续增长的历史经验转化为有用的事实和可复用程序，并不断改善未来的上下文选择？**

现有方法存在两类互补的不足：

- **仅使用记忆**：能够找回历史事实或任务轨迹，但模型可能仍需每次重新推导操作流程。
- **仅使用技能**：能够复用解题步骤，却可能缺少具体人物、日期、物体位置等任务特定信息。
- **简单组合二者仍不够**：正确的事实未必与当前任务有关，已有技能也未必适用，因此还需要学习“什么时候应该检索哪些记录”。

### 1.2 整体含义

论文提出 **MemCryst**，将持续适应放在模型外部状态中，而不是模型权重中：

- 历史经历用于创建和修订技能。
- 技能与事实共同指导后续行为。
- 新行为产生的新经历再次进入记忆。
- 任务结果单独调整记录未来被检索的优先程度。

这里的“双向学习”并非记忆与技能直接相互改写，而是形成：

**记忆 → 技能 → 行为 → 新记忆 → 技能修订**。

因此，它更准确地属于**冻结模型下的外部状态持续学习与上下文适应**，而非参数层面的终身训练。

## 2. 方法论：核心思想、关键技术与算法流程

### 2.1 三类外部记录

MemCryst 将外部内容分为三部分，并为其维护独立的检索统计：

| 记录类型 | 主要内容 | 作用 |
|---|---|---|
| 情节记忆 Episode | 任务证据、结果诊断、可复用经验、来源范围 | 保存经历，支持后续技能学习；部分场景也参与检索 |
| 类型化事实 Fact | 实体、具体声明、类型、来源、重复支持次数 | 提供任务所需的具体信息 |
| 技能 Skill | 适用条件、参数化步骤、能力类别、支持情节 | 提供可复用流程 |

**技能是文本指导，不是直接执行的函数。** 冻结模型需要结合当前观察与事实，将技能步骤落实为动作或答案。

### 2.2 在线运行流程

每个需要回答或行动的事件按以下顺序处理：

1. **检索和组装上下文**
   - 根据领域范围、记录类型和技能适用条件筛选记录。
   - 结合语义相关性与历史使用统计排序。
   - 按各场景的检索配额、字段长度或 token 限制组装上下文。

2. **执行并评价**
   - 冻结 LLM 根据任务和检索上下文生成轨迹或答案。
   - 环境提供原生奖励，以及用于更新的二元成功信号。

3. **结果回传**
   - 只更新真正进入模型上下文的事实和技能。
   - 不直接修改这些记录的文本。

4. **写入新记忆**
   - 从本次交互提取情节、诊断与经验。
   - 提取允许保存的事实，并进行合并。

5. **定期技能整合**
   - 在预设的“睡眠边界”聚类情节，创建或修订技能。

关键时序是：**当前任务先计分，再更新状态；新写入记录不会获得本次结果的回传奖励。** 这样可以避免当前任务结果直接帮助完成当前任务。

### 2.3 从情节中创建和修订技能

技能整合采用“聚类—合成—审核”流程：

- 使用 **HDBSCAN** 对情节嵌入聚类，最小簇大小为 3。
- 综合情节质量、簇规模和聚类稳定性进行排序。
- 每次最多处理 10 个候选簇，每个候选最多选择 5 条高权重情节作为合成依据。
- 用冻结 LLM 将具体经历抽象成带参数槽位的流程，避免固化具体物体、名称或地点。
- 在独立上下文中进行审核，请求检查参数化、适用范围、失败覆盖、流程完整性等 13 项条件；实现中的通过门槛为至少 10 个返回的 PASS。

技能通过以下能力键匹配：

- 动词类别；
- 目标类型；
- 功能或可供性；
- 输出类型。

如果匹配已有技能，则合并新旧支持情节，再次合成并审核修订版本；修订保留技能身份、累计效用和来源关系。

**成功与失败情节都可以参与技能学习。** 但合成时偏向高权重情节，因此保留失败记录并不意味着所有失败证据都能进入合成提示。

### 2.4 内容更新与使用权重更新分离

这是论文的重要设计。

- **内容更新**：依赖情节证据，创建事实、合并来源、创建或修订技能。
- **使用更新**：依赖任务结果，调整已有记录未来的检索影响力。

具体而言：

- **事实得分**采用平滑后的暴露成功率：成功次数加 1，除以暴露次数加 2；新事实初值为 0.5。
- **技能效用**采用指数移动平均，默认更新率为 0.2，更重视近期使用结果。
- 事实检索综合语义相关性、重复支持次数和暴露成功率。
- 技能检索综合语义相关性与技能效用。
- 对话场景额外加入词汇匹配，增强姓名、日期等信息的召回。

需要强调：**事实得分不是事实真实性概率，技能效用也不是该技能的独立因果贡献。** 同一任务中所有被提供的记录共享同一个结果信号。

## 6. 主要结论与发现

### 6.1 七项设置领先，但收益不均衡

MemCryst 在十项设置中领先七项，综合分数为 **52.26%**，高于主表最强基线 SimpleMem 的 **39.92%**。

- **对话记忆收益最明显**：
  - LoCoMo：31.75；
  - LongMemEval：22.20；
  - 姓名替换 DialSim：74.24%，SimpleMem 为 47.85%。
- **具身和部分阅读任务有效**：
  - ALFWorld：63.17%；
  - BABILong：59.00；
  - RULER：64.70，低于 ExpeL 的 71.27。
- **数学与代码收益较小且不稳定**：
  - MATH-hard：60.90；
  - MBPP：80.42，低于 ReAct 的 81.30；
  - MBPP、CodeContests 均由 ExpeL 领先。

### 6.2 事实与技能具有互补性

在匹配设置的 ALFWorld 消融中：

| 配置 | 成功率 |
|---|---:|
| 仅记忆 | 59.83% |
| 仅向模型提供技能 | 50.50% |
| 不修订技能 | 62.00% |
| 完整 MemCryst | **63.17%** |

说明联合提供事实和程序优于单独提供其中一类；持续修订也有额外收益，但幅度较小。

### 6.3 联合结果回传有效，但并非每个通道单独有效

| 技能回传 | 事实回传 | 成功率 |
|---|---|---:|
| 关闭 | 关闭 | 59.67% |
| 关闭 | 开启 | 57.17% |
| 开启 | 关闭 | 60.33% |
| 开启 | 开启 | **63.17%** |

- 双通道相对都关闭提高 **3.50 点**。
- 差分之差交互量为 **+5.33 点**。
- 事实回传单独开启反而降低成绩，说明不能将结论简化为“增加任何反馈都有效”。

### 6.4 技能的压缩价值比准确率优势更明确

冻结同一状态，在 100 道留出任务上：

- 事实与技能：75%；
- 保留事实、以情节替换技能：72%；
- 随机选择近似等长、同类型记录：58%。

相关检索优于随机记录，配对检验 \(p=0.0033\)。但技能与情节替换的准确率差异不显著，\(p=0.664\)。

技能上下文相对情节替换：

- 注入 token 减少约 **62%**；
- actor 输入 token 减少约 **29%**。

因此，证据更明确支持**紧凑表示与成本优势**，尚不能确认准确率更高。

### 6.5 共享状态有益，但适应不保证单调改善

- 五领域交替部署时，均分从 28.30% 提高到 44.50%，仍低于独立领域系统的 48.50%。
- ALFWorld 最终仅有 5 个技能，却发生了 154 次接受的修订，说明学习主要表现为已有技能的持续调整。
- 终态留出成绩并非全面提升：BABILong、LoCoMo 低于其在线成绩。不过两者评价样本不同，不能直接据此认定发生了遗忘。

## 7. 优点与亮点

- **事实、经历和程序分工清楚**，避免将所有历史压缩成单一文本摘要。
- **内容更新与使用权重更新分离**，避免因任务失败就直接改写正确事实。
- **学习闭环完整**：既学习技能，也记录技能引导行为产生的新证据。
- **技能身份和来源可追踪**，修订后保留使用历史与支持情节，便于审计。
- **评价层次丰富**：完整系统、组件消融、回传交互、冻结状态、顺序扰动和效率分析相互补充。
- **结论相对克制**：明确承认非因果归因、代码收益混合，以及技能未证明准确率优于情节上下文。
- **便于冻结模型部署**，无需微调权重，并提供代码仓库。

## 8. 不足、局限与应用风险

### 8.1 反馈与信用分配粗糙

- 同一任务结果分配给全部被提供记录，可能奖励无关内容，或惩罚有用内容。
- 检索影响后续暴露，可能形成“更常检索—更多统计支持—继续优先检索”的反馈循环。
- 对错误、延迟或稀疏反馈的鲁棒性未测试。
- 历史暴露很多的事实更新越来越慢，环境改变后可能适应不足。

### 8.2 事实质量与技能审核仍有隐患

- 相似度合并不等于语义一致性验证，也没有充分展示矛盾消解与时间有效性管理。
- 附录对话案例确实包含冲突日期，以及由错误选项形成的事实式记录，说明记忆污染风险并非纯理论问题。
- 技能合成与审核依赖同一个冻结模型，仅更换上下文，不能保证独立验证或正确性。
- 审核只查看少量代表情节；技能文本在实际提供时还可能被截短，完整审核不保证截短后的指导仍完整。

### 8.3 “终身”规模和迁移范围有限

- 实验覆盖数百至数千计分任务，尚未验证长期开放环境中的规模增长、检索退化、遗忘与存储预算。
- 跨领域混合实验采用领域隔离，未建立对全新领域的技能迁移能力。
- 不同场景依赖专用适配器、能力路由、提示和过滤规则，迁移部署仍需要工程设计。

### 8.4 总体成本与现实安全尚不明确

- 高频技能修订和多阶段 LLM 调用可能产生较高维护成本，但论文缺少端到端成本报告。
- 长期记忆可能保存敏感、错误或带偏见的信息，任务成功也不代表行为合理或事实正确。
- 实际个人智能体需要用户隔离、访问权限、保留期限、删除与申诉机制，以及高风险操作的人类审核；论文未验证这些措施。

**总体评价：** MemCryst 的主要价值是将“具体事实”和“可复用流程”纳入可持续更新的外部学习闭环，并用实验支持联合检索与技能压缩的作用。它为冻结模型的持续适应提供了有用工程方案，但目前证据更适用于受控任务流；对公平归因、长期稳定性、事实治理和总成本，仍需进一步验证。
