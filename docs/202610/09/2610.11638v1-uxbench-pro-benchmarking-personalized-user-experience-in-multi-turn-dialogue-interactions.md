## 摘要
采用自动化计算方法评估用户体验（UX）日益受到关注，UXBench 的实证证据也为此提供了支持。然而，二元偏好预测所能提供的洞见有限；而依赖单一、与用户无关的奖励模型，则忽视了用户固有的异质性——不同用户的期望可能存在显著差异。本文提出 UXBench Pro，包含 1,000 个测试实例，源自真实用户在 12 种任务场景和 82 个领域中的交互。每个实例均配有一个 FACTORS 用户画像，通过七个可解释的行为维度刻画用户，从而区分不同用户群体。为提供更丰富的评估洞见，我们提出一种双视角范式：结合个性化用户奖励模型（URM），用于第三人称评判；以及 Sim4Eval，一个支持多轮交互并从四个认知状态维度进行第一人称评估的用户模拟器。为评估这些评估器的可靠性，我们进一步提出两个元基准 URMBench 和 USimBench，用于衡量它们复现真实人类偏好与行为的忠实度。大量实验揭示了七项关键发现，凸显用户建模与多视角评估的重要性，为以用户为中心的基准测试提供了新的视角，并推动个性化模型优化。

## Abstract
Evaluating user experience (UX) with automated computational methods has gained increasing attention, supported by empirical evidence from UXBench. However, binary preference prediction provides limited insight, while relying on a single user-agnostic reward model overlooks the inherent heterogeneity of users, whose expectations can differ substantially. In this paper, we present UXBench Pro, comprising 1{,}000 test instances derived from real user interactions across 12 task scenarios and 82 domains. Each instance is paired with a FACTORS user profile that characterizes the user through seven interpretable behavioral facets, differentiating user groups. To provide richer evaluation insights, we introduce a dual-perspective paradigm that combines a personalized User Reward Model (URM) for third-person judgment with Sim4Eval, a user simulator that enables multi-turn interactions and provides first-person evaluation across four cognitive state dimensions. To assess the reliability of these based evaluators, we further introduce two meta-benchmarks, URMBench and USimBench, that evaluate how faithfully they reproduce real human preferences and behaviors. Extensive experiments reveal seven key findings that highlight the importance of user modeling and multi-perspective evaluation, offering a fresh perspective on user-centric benchmarking and motivating personalized model optimization.

传统大语言模型基准主要衡量知识、推理、正确性和指令遵循能力，但这些指标不一定能够反映真实用户的体验。例如，回答虽然正确，却可能过于冗长、不符合用户知识水平，或者没有真正解决用户的问题。

论文指出，现有自动化用户体验评估存在三个主要不足：

- **反馈过于粗糙**：点赞、点踩等二元信号难以解释满意或不满意的具体原因。
- **忽略用户异质性**：统一奖励模型隐含假设所有用户都认可相同的“好回答”，但不同用户对篇幅、专业深度、情绪支持和互动方式的偏好不同。
- **缺少多轮动态评估**：单轮回答质量不能完整反映目标推进、反复修正、满意退出或中途放弃等交互过程。

1. 用户画像能否提高自动化体验判断与真人偏好的一致性？
2. 将用户画像提供给助手，能否改善个性化回答？
3. 用户感知、多轮交互评估能否提供更有解释性的模型改进信号？

## 2. 方法论：用户画像、双视角评估与元基准验证

### 2.1 FACTORS：七维用户画像

每个测试实例表示为“对话上下文、用户画像、任务场景”的组合。用户画像包含七个维度：

| 维度 | 含义 | 主要信号 |
|---|---|---|
| F：Feedback | 反馈倾向 | 过去30天的正负反馈及反馈频率 |
| A：Age | 年龄区间 | 平台记录的年龄信息 |
| C：Consumption | 消费能力代理 | 手机价格档位及部分资产信号 |
| T：Technical Usage | AI使用强度 | 提问数量、其他AI产品安装情况 |
| O：Role | 生活阶段或角色 | 学生、工作年龄、退休、育儿等信息 |
| R：Region | 地域类型 | 城市类别、农村群体标记 |
| S：Schooling | 教育水平 | 平台或对话中的教育信息 |

- 各维度离散化编码，并支持未知状态。
- 编码被转换为自然语言“人物卡”，用于条件化助手、奖励模型和模拟器。
- 这些属性是**粗粒度上下文代理**，不应被理解为对个人能力、财富或偏好的准确判定。

### 2.2 第三人称评估：用户奖励模型 URM

URM读取对话、候选回答及用户画像，预测该用户更偏好哪个回答。

论文比较了三种建模方式：

- **逐点生成式奖励模型（Pointwise GRM）**：根据正、负判断词的归一化概率给单个回答评分。
- **Bradley–Terry奖励模型（BTRM）**：使用分类头和偏好对训练相对质量判断。
- **成对生成式奖励模型（Pairwise GRM）**：同时输入两个回答，直接生成比较判断。

训练信号包括：

- 用户重新生成回答产生的偏好信号；
- 用户在双回答中明确选择的偏好；
- 单个回答的点赞、点踩标签。

最终选择了**使用重新生成偏好训练的Pairwise GRM**。

### 2.3 第一人称评估：Sim4Eval多轮用户模拟

模拟器在每轮接收助手最新回答、用户画像和对话历史，输出：

- 下一条用户发言；
- 四维用户状态，每维1—5分；
- 是否继续或离开；
- 反馈及其他行为信号。

四个状态维度分别为：

1. **目标进展**：回答是否推动或完成任务。
2. **情绪契合**：语气是否符合用户情绪、担忧或紧迫感。
3. **认知契合**：长度、术语、结构和细节是否易于理解和使用。
4. **互动偏好契合**：提问、主动行动和后续互动程度是否合适。

论文据此定义轨迹指标：

- **解决率**：轨迹中目标进展达到5分的比例。
- **放弃率**：模拟器提前停止，且最终目标进展不超过2分的比例。

需要注意，这些指标来自模拟器，而非真实用户在新回答上的直接测量。

### 2.4 检索增强用户模拟器

仅有画像不足以说明用户“如何说话和反应”，因此论文引入真实后续发言检索：

- 检索库包含约 **36,000个会话、135,915个后续轮次**。
- 分别为助手回答和用户发言建立TF-IDF表示。
- 检索分数由两部分相似度加权组成：
  - 当前助手回答与历史助手回答的相似度，权重 **0.7**；
  - 当前用户上下文与历史后续用户发言的相似度，权重 **0.3**。
- 用户上下文由开场问题与最近用户发言拼接构成。
- 先取前12个候选，再用字符级Jaccard相似度去重，阈值为 **0.5**，保留3个多样化示例。

这些示例为模拟器提供真实表达长度、语气和反应方式，而不是直接作为用户偏好的标签。

### 2.5 元基准：先验证评估器，再用它评估助手

论文提出“元基准评估”原则：

- **URM-Bench**：检验奖励模型是否复现真人的回答偏好。
- **USimBench**：检验模拟器是否复现真实后续发言和交互行为。

其关键思想是：**不能因为评估器是强大模型，就默认它能够代表用户。**

### 3.1 UXBench Pro主基准

- **15个粗粒度领域、82个细粒度领域**；

### 3.2 数据构建流程

数据来自中国某主流AI助手的用户自愿参与体验项目。构建流程为：

1. 从 **71,221个包含明确负反馈的原始会话** 出发，去重并删除无效交互。
2. 进行安全筛查和多层个人信息清理。
3. 使用本地部署的Hunyuan-3重写查询，尽量保留意图并去除身份信息。
4. 通过“一个提议者、三个批评者”的多智能体审查，排除无法回答、负反馈原因不明确或区分度不足的样本。
5. 进行任务平衡采样，并设置部分群体的最低代表比例。
6. 由10名标注员进行双重独立人工审查。

因此，它更准确地说是**真实用户不满意案例上的体验修复基准**，而不是随机抽样的全部日常交互基准。

### 3.3 两个元基准

## 6. 主要结论与七项发现

### 6.1 双视角相关，但并不等价

- 单轮URM强度与解决率的Spearman相关系数为 **0.857**。
- 单轮与轨迹URM强度的相关系数为 **0.821**。
- 解决率与放弃率却近乎不相关，相关系数为 **0.106**。

说明回答偏好、任务完成和继续交互是不同维度。论文所测七个助手中，Qwen3.7-Max的URM强度最高，DeepSeek-v4-pro的模拟解决率最高，为 **41.4%**。

### 6.2 个性化收益取决于用户和评估器

- 无画像裁判偏好非个性化回答的比例为 **62.5%**；裁判获得真实画像后降为 **54.8%**。
- 个性化回答在表达型、挑剔型用户上的偏好率分别为 **62.8%和61.3%**。
- 在宽容型、沉默型和轻反馈用户上均低于50%。
- 总体个性化偏好率为 **45.2%**，对群体等权后为 **49.9%**。

因此，论文**没有证明简单注入画像能够普遍提高体验**，而是证明其价值高度依赖群体和判断视角。

### 6.3 个性化能力不同于一般模型能力

- GPT-5.5虽在总体单轮强度中排名第六，却是唯一在五类反馈群体中均从画像条件化获益的助手。
- 更大幅度的回答缩短与更低偏好高度相关，但不能据此认定缩短导致体验下降。
- 无历史对话时个性化偏好率为 **50.2%**，有历史时为 **41.2%**。

这表明对话历史可能已提供画像所包含的部分信息，静态画像在冷启动时更有作用。

### 6.4 常见交互失败比事实错误更难修复

- 总体修复率为 **42.9%**。
- 事实错误修复率为 **54.8%**；
- 意图不匹配为 **53.1%**；
- 冗长和格式问题仅为 **32.8%和32.4%**。

而冗长与格式问题占基准 **34.7%**，事实错误仅占 **6.8%**，说明用户体验改进不能只关注知识正确性。

### 6.5 专用裁判与相关用户信息都重要

- Pairwise GRM无画像准确率为 **76.88%**，明显超过其他训练配置及通用裁判。
- 加画像后升至 **81.87%**，接近人类参考值 **82.71%**。
- 收益主要集中于风格适配。
- 增加推理努力并不稳定改善判断，部分模型反而下降。

“接近人类”仅指该偏好任务上的准确率接近参考值，不代表完整理解用户体验。

### 6.6 RAG改善语言相似度，不保证行为真实

- 在12个底座中，RAG改善语义及轮次对齐相似度的模型各有 **11个**。
- 降低综合差异的模型有 **9个**。
- 在10个反馈指标完整的模型中，各类反馈保真指标仅有 **3个**改善，平均变化为负。

所以，模拟器“说得像真人”不等于“行为像真人”。

### 6.7 动态状态和画像行为值得建模，但仍需外部验证

- 普通五分制下，四维状态完全不变化的会话比例最高达 **82.0%**。
- 行为锚定并要求证据的方案中，报告的联合不变化比例最高为 **5.7%**。
- 模拟反馈频率随画像显著变化。

但两类评分方案使用不同底座，因此不能将差异严格归因于评分提示；模拟状态与模拟行为一致，也不能证明其对应真实用户心理状态。

---

## 7. 优点

- **问题定位贴近实际**：关注冗长、需求错配、情绪失配等能力排行榜容易遗漏的失败。
- **框架层次清晰**：区分静态画像、单轮偏好、动态状态和交互结果。
- **元基准原则有价值**：将评估器可靠性作为需要验证的问题，而非默认前提。
- **分析不只看总体均值**：分群结果揭示个性化收益可能被人口构成掩盖。
- **控制实验较丰富**：顺序交换、画像置乱、安慰剂和维度扰动增强了结果解释性。
- **谨慎对待模拟结果**：明确区分语言保真、行为保真和潜在状态有效性。
- **具备隐私保护流程**：用户同意、粗粒度画像、文本脱敏、重写和人工复核相结合。

## 8. 不足与局限

### 8.1 数据覆盖与代表性有限

- 来源为单一中国AI助手平台，跨语言、跨文化和跨产品泛化尚未验证。
- 起点是负反馈会话，且经过多智能体筛选，因此不能直接估计真实线上总体满意度。
- 任务平衡与最低群体比例改变了自然分布，子群聚合结果需要明确权重。
- 编程和翻译任务分别仅 **17和18个实例**，场景级结论不够稳健。
- 查询重写虽然保护隐私，也可能改变表达风格、难度及个性化线索。

### 8.2 用户画像存在代理偏差

- 手机价格不等于消费能力，提问频率不等于技术熟练度，年龄也不能可靠代表职业或退休状态。
- 粗粒度属性容易掩盖个体差异，并诱发刻板印象式适配。
- 技术熟练度一致性测试不显著，说明裁判对画像敏感不等于使用画像充分校准。
- 静态属性对当前目标、知识水平和明确偏好的描述仍不足。

### 8.3 反馈与人类参考并非完美真值

- 重新生成不必然意味着后一个回答更好，也可能只是用户探索不同答案。
- 双回答选择是相对偏好，不等于所选答案达到绝对满意。
- 标注员主要是受训员工，并非所有原始用户群体的代表；人工审查时还不展示画像，其参考判断与个性化评价目标存在一定差异。

### 8.4 模拟评估存在自洽循环风险

- 模拟器既生成行为，又报告状态，二者相关可能部分来自同一生成机制。
- 解决率和放弃率依赖模拟器评分、停止规则，不能直接视为真实用户结果。
- 更动态的状态未必更准确：真实体验也可能保持稳定。
- 尚缺乏真实用户对新生成回答的在线实验，以验证离线分数能否预测实际体验改善。

### 8.5 可复现性与报告一致性仍可改进

- 未充分报告算力、训练预算及总体成本。
- 提供的文本存在少量口径差异：
  - 示意图将URM-Bench标为1,000对，正文明确报告800对；
  - 数据统计为15个粗领域，后续分析提到16个；
  - 反馈定义在正文与附录中涉及的信号范围不完全一致。
- 用户模拟器的最终选择及不同方案的完整比较，在提供文本中不够清晰。

### 8.6 应用限制

- 不能将画像分组差异解读为人口属性的因果效应。
- 不宜把模拟体验分数单独用于医疗、金融等高风险场景的安全判断。
- 作者明确限制发布数据用于模型评估、而非训练，因此基准可支持个性化优化研究，但不能直接作为训练集使用。

**总体评价**：该论文最有价值的贡献是提出了“先验证评估器、再按用户和交互过程评价助手”的框架。实验有力说明了统一裁判和总体平均分的局限，但对真实线上体验、跨平台泛化以及模拟认知状态有效性的证据仍不充分。
