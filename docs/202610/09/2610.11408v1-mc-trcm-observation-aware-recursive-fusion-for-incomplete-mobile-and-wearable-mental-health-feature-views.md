## 摘要
公开的移动与可穿戴心理健康数据集通常提供汇总后的特征表，而非同步的原始传感器流。在这些数据发布中，每个锚点对应一个问卷或标签时间点，可能汇集手机或可穿戴设备的汇总信息、既往症状评分、人口统计学信息、临床变量以及数据源可用性指标。我们提出模态条件化时序递归上下文模型（Modality-Conditioned Temporal Recursive Context Model，MC-TRCM），该模型将每个特征来源保留为独立的 token，并将缺失信息作为输入上下文的一部分。对于已观测的数据源，模型使用其取值和缺失情况摘要进行编码；对于缺失的数据源，则使用可学习的缺失 token；数据集与任务嵌入用于调节融合过程；递归预测头则通过验证集选定的步骤逐步优化各项输出。我们采用参与者级数据划分和仅基于验证集的模型选择，在 DepreST-CAT 和抑郁严重程度变化预测（Prediction of Severity Change-Depression，PSYCHE-D）数据集的六个预定义终点上评估 MC-TRCM。对于 DepreST-CAT 的患者健康问卷-9（PHQ-9）和广泛性焦虑障碍量表-7（GAD-7）严重程度预测，MC-TRCM 的平均绝对误差最低，较最佳表格数据基线分别降低了 0.181 和 0.217 个量表分值。分类终点的表现因任务而异：MC-TRCM 的 GAD-7 类别平衡准确率经四舍五入后与最佳模型持平；在 PSYCHE-D 多分类预测中，其平衡准确率数值最高，比次优模型高 0.002；在 PHQ-9 类别预测和 PSYCHE-D 二分类预测中，其表现也接近最强基线。消融实验支持特征级线性调制、缺失 token、缺失信息投影和递归优化的有效性；校准分析与特征来源控制实验则进一步刻画了各终点的表现。代码见 https://github.com/Botwwt/MC-TRCM。

## Abstract
Public mobile and wearable mental-health datasets often provide summarized feature tables rather than synchronized raw sensor streams. In these releases, each anchor corresponds to a survey or label time and may combine phone or wearable summaries, prior symptom scores, demographics, clinical variables, and source-availability indicators. We propose the Modality-Conditioned Temporal Recursive Context Model (MC-TRCM), which preserves each feature source as a separate token and incorporates missingness as part of the input context. Observed sources are encoded with values and missingness summaries, absent sources use learned absence tokens, dataset and task embeddings condition fusion, and a recursive prediction head refines each output over validation-selected steps. We evaluated MC-TRCM on six predefined endpoints from DepreST-CAT and Prediction of Severity Change-Depression (PSYCHE-D) using participant-level splits and validation-only model selection. MC-TRCM achieved the lowest mean absolute error on DepreST-CAT Patient Health Questionnaire-9 (PHQ-9) and Generalized Anxiety Disorder-7 (GAD-7) severity, improving over the best tabular reference by 0.181 and 0.217 scale points. Classification endpoints showed task-dependent behavior: MC-TRCM matched the best rounded GAD-7 category balanced accuracy, was numerically highest by 0.002 balanced-accuracy points on PSYCHE-D multiclass prediction, and remained close to the strongest references on PHQ-9 category and PSYCHE-D binary prediction. Ablations support Feature-wise Linear Modulation, absence tokens, missingness projections, and recursive refinement, while calibration and feature-source controls characterize endpoint behavior. Our code is available at https://github.com/Botwwt/MC-TRCM.

## 1. 核心问题与整体含义

### 研究背景与动机
- 移动手机和可穿戴设备可提供睡眠、活动、位置移动、通信及设备使用等行为信息，为间歇性的心理健康问卷与临床评估补充背景，但这些信号是**症状的间接代理，而非抑郁或焦虑的直接测量**。
- 公开数据通常不是同步的原始传感器流，而是以问卷或标签时间为“锚点”的汇总特征表，其中还混合了既往症状评分、人口统计学和临床变量。
- 数据源缺失可能来自未佩戴、退出研究、隐私设置、住院或数据发布限制。因此，**“哪些信息可见、哪些信息缺失”本身可能具有预测价值**。

### 核心问题
传统特征拼接与插补方法容易弱化以下区别：
- 不同来源的测量含义与可靠性；
- 真实的低数值、部分缺失和整个来源不可用；
- 不同数据集、不同预测任务所需的融合方式。

论文提出 MC-TRCM，尝试联合利用**观测值、来源身份和缺失模式**。其主要意义是为不完整的多源心理健康特征表提供结构化建模方案，而不是建立一个已经验证可用于临床诊断的系统。

## 2. 方法论：核心思想与技术流程

### 2.1 输入组织：以来源为单位，而非直接拼接全部列
- 将特征按来源组织为独立 token，涉及传感器值、缺失信息、既往症状、静态人口统计学及临床背景。
- 每个锚点包含：
  - 经训练集插补和标准化后的特征值；
  - 列级缺失掩码、缺失比例、时间新近程度代理等缺失摘要；
  - 来源是否整体可用的指示变量。
- 同一参与者的所有锚点始终属于同一个数据划分。

### 2.2 观测感知 token 化
模型区分两种情形：

- **来源已观测**：将来源特征编码为向量，使用由“特征值＋缺失摘要”生成的门控控制其贡献，再加入缺失信息投影和来源嵌入。
- **来源整体缺失**：不执行数值编码和门控，而使用可学习的“缺席 token”，再加入缺失投影和来源嵌入。

关键细节：
- 门控在实现中是一个标量，广播至整个 token 向量。
- 部分缺失仍需要插补，因此该方法**不是取消插补，而是让插补后的数值与缺失状态同时进入模型**。
- 整体缺失来源仍参与融合，使模型可以利用可用性模式。

### 2.3 数据集与任务条件化融合
- 数据集嵌入和任务嵌入共同形成上下文。
- 使用 **FiLM（特征级线性调制）**，根据上下文对表示进行逐维缩放和平移。
- 最终配置在 Transformer 融合前后均应用 FiLM。
- 网络配置包括：
  - 2 个 Transformer block；
  - 隐藏维度 64；
  - 4 个注意力头；
  - 前馈维度 160；
  - dropout 0.1；
  - 池化后投影至 96 维表示。
- 平均池化包含已观测 token 和缺席 token，但排除用于跨数据集对齐的 padding token。

**作用**：让相同架构针对不同队列分布和不同临床终点调整融合方式。

### 2.4 递归预测细化
- 递归状态初始为零。
- 每一步将融合表示、任务上下文及上一轮内部状态送入任务预测头。
- 当前预测经反馈映射后生成下一轮内部状态，继续细化输出。
- 最终使用第 \(K\) 步预测。

递归深度从 **1、2、4、6、8** 中通过验证集选择：
- DepreST-CAT：选择 8 步；
- PSYCHE-D：选择 4 步。

需要注意：这里的递归是**同一锚点预测头的内部迭代**，不是直接沿参与者真实时间序列推进；递归状态也没有被验证为具有临床含义的潜在状态。

### 2.5 训练与后处理
- 对全部递归步骤施加监督，后续步骤权重更高。
- 使用可学习的任务不确定性权重平衡多任务损失。
- 回归损失、分类损失及相关选项通过验证集选择。
- 最终配置使用 PCGrad，缓解不同任务梯度冲突。
- 使用 AdamW、梯度裁剪和早停；模态 dropout 等选项纳入验证搜索。
- 分类阈值、类别偏置修正、温度缩放及递归深度均只根据训练与验证数据确定。

主评价指标：
- **连续严重程度**：MAE，单位是问卷量表分值，越低越好。
- **分类与有序类别**：平衡准确率 BA，即各类别召回率的平均值，越高越好。
- **概率校准**：Brier score 和 ECE，越低越好。

对于有序类别，BA 衡量类别平衡后的区分能力，并不衡量误判跨越了多少等级。

## 6. 主要结论与发现

### 6.1 最明确的收益来自连续严重程度预测

| 终点 | MC-TRCM | 最强基线 | 差异 |
|---|---:|---:|---|
| PHQ-9 MAE ↓ | 5.636 ± 0.035 | EBM：5.817 ± 0.085 | 降低 0.181 分 |
| GAD-7 MAE ↓ | 4.811 ± 0.044 | EBM：5.028 ± 0.088 | 降低 0.217 分 |
| PHQ-9 类别 BA ↑ | 0.246 ± 0.041 | LSTM：0.252 ± 0.031 | 低 0.006 |
| GAD-7 类别 BA ↑ | 0.343 ± 0.031 | LightGBM：0.343 ± 0.031 | 报告精度下持平 |
| PSYCHE-D 二分类 BA ↑ | 0.582 ± 0.011 | EBM：0.589 ± 0.007 | 低 0.007 |
| PSYCHE-D 多分类 BA ↑ | 0.514 ± 0.008 | EBM：0.512 ± 0.003 | 高 0.002 |

相对 EBM，两个严重程度任务的 MAE 分别下降约 **3.1% 和 4.3%**。分类结果则是持平、小幅领先或略低于基线，不能概括为全面最优。

### 6.2 缺失建模和条件化融合获得消融支持
相对完整模型，移除组件后的平均变化为：

| 移除组件 | 两个严重程度任务平均 ΔMAE | 四个分类任务平均 ΔBA |
|---|---:|---:|
| FiLM | +0.136 | −0.017 |
| 缺席 token | +0.125 | −0.012 |
| 缺失投影 | +0.041 | −0.008 |
| PCGrad | +0.008 | −0.003 |
| 任务条件化 | +0.067 | +0.002 |
| 递归细化 | +0.046 | −0.013 |

- FiLM 和缺席 token 的贡献最明显。
- 递归细化与缺失投影提供较小收益。
- PCGrad 的影响较弱。
- 任务条件化对严重程度有益，但分类平均结果并非改善。

### 6.3 输入来源与概率质量具有重要影响
- 症状史、人口统计学和临床背景提供了较强的分类信号；部分任务中，仅这些背景信息已接近或超过完整模型。
- 因而不能把性能全部归因于被动传感器。
- 校准结果不一致：MC-TRCM 改善 PHQ-9 类别的 Brier score 和 ECE，但其他分类终点的相应基线更好。
- 递归深度不是越大越好，PSYCHE-D 在 4 步后验证性能下降。

## 7. 优点

- **贴近公开数据的真实形态**：针对汇总特征视图，而非假设原始同步传感器流可用。
- **显式区分观测值与缺失状态**：为部分缺失和整体缺席提供不同处理路径。
- **保留来源结构**：通过来源 token 和嵌入，避免全部特征完全扁平化。
- **任务自适应与递归预测结合**：支持连续、二分类及多类别终点，并由验证集决定迭代深度。
- **防泄漏协议较完善**：参与者划分和验证集锁定覆盖预处理、选择与后处理。
- **基线较强且分析维度丰富**：特别是纳入 EBM、特征来源控制和校准，减少“复杂模型自然更好”的误判。
- **结论较克制**：明确优势集中在严重程度估计，没有宣称分类全面领先。

## 8. 不足与局限

### 8.1 改进的统计与临床意义尚不明确
- 严重程度误差下降不足 0.22 个量表分值，虽有一致数值收益，但尚无临床意义阈值、决策收益或显著性分析支持。
- PSYCHE-D 多分类仅提升 0.002 BA，小于报告的随机种子标准差，不能据此认定稳定优势。
- PHQ-9 和 GAD-7 的绝对 MAE 仍分别约为 5.6 和 4.8 分，不能将相对领先等同于临床可用。

### 8.2 泛化与缺失机制风险
- 未证明跨设备、跨地区、跨年份或跨队列的迁移能力。
- 缺失模式可能编码研究流程、设备政策和发布规则；模型可能利用与症状无关的“数据采集捷径”。
- 未系统测试随机删失、整模态失效及训练—测试缺失机制改变等场景。

### 8.3 方法归因与基线仍可加强
- 缺少明确的来源 token 数量、逐列分组规则等完整复现细节。
- 序列基线采用四类时间／静态 token，而 MC-TRCM 使用来源结构，性能差异可能部分来自输入组织。
- 缺少深度和参数预算匹配的非递归预测头对照，因此尚难完全分离反馈递归与额外计算的作用。
- 论文按数据集运行训练，数据集条件化设计并不等于已证明跨数据集联合学习或迁移收益。

### 8.4 评价与部署限制
- PSYCHE-D 包含重复锚点，但逐行指标与参与者等权汇总之间的关系未充分说明，频繁记录者是否获得更高评价权重值得澄清。
- 未报告类别阈值、类别分布、混淆矩阵及有序误差，限制对分类结果的解释。
- 未展示人口统计子群公平性、外部临床验证、前瞻部署或用户交互研究。
- 算力和延迟缺失，无法判断递归模型部署收益是否抵消其复杂性。
- 多终点、多组件和多种后处理扩大了验证选择空间，验证集过拟合风险尚未通过嵌套验证或额外独立验证集充分排除。

**总体评价**：这是一项面向不完整心理健康汇总特征的结构化融合研究。它较有说服力地支持了来源感知、缺失状态建模和条件化融合对严重程度估计的价值；但分类优势、跨队列鲁棒性和临床应用价值仍需更大规模、更严格的验证。
