Abstract 

We consider a distributed learning task with agents that have correlated data. Specifically, the label of an agent depends on the input of other agents for the same sample, and these inputs are also correlated. Correlated data is the reality when agents share the same envi-ronment. Existing decentralized methods, such as federated learning, ignore the structure of the problem and perform poorly on correlated data. On the other hand, centralized ap-proaches are infeasible due to privacy and communication constraints. We introduce cordial (correlated and distributed) learning to address this gap by sharing only low-dimensional outputs between the agents while training local models to extract informative signals from peers. This distributed learning induces a game in which the loss function of each agent depends on the models of others. Assuming a linear model, we prove that cordial learning converges with probability one to a globally optimal solution, despite the nonconvex global objective. Experiments on structured multi-digit MNIST tasks demonstrate that cordial learning remains highly effective even in highly nonlinear settings. 

Keywords: Federated Learning, Distributed Training, Game Theory, Collaborative Learning, Stochastic Optimization 

1. Introduction 

When deployed, ML systems rarely operate in a vacuum. Their data comes from a shared environment with many ML systems. Thus, the data of many ML systems can be highly correlated. Current ML architectures are trained in solitude, ignoring any interaction they may encounter after deployment. In distributed learning, and federated learning (FL) in particular, all edge devices (agents) face the same learning task. The data collected by an edge device is valuable to all others since it extends their effective training dataset. FL then avoids sending ex-plicit data to the server, maintaining user privacy, while still allowing agents to learn from each other’s data indirectly. When ML agents share an environment, one agent’s data is helpful not only because more data is better, but mostly because it shows the agent the part of the bigger picture that it cannot see alone. Technically, it means that the label of one agent depends on the 

1arXiv:2610.03330v1 [cs.LG] 2 Oct 2026 Shitrit and Bistritz 

input of others. Even if the agents have different ML tasks, so they cannot learn directly from others’ data, the data of others contains information that explains their label better. The current distributed learning paradigm cannot benefit from the correlated data of ML agents that share an environment after deployment. In this paper, we introduce a new paradigm we term cordial learning (CL), since it is cor related and di stributed. Similar to FL, CL is concerned with edge devices that each have a private dataset. However, the l-th datapoint of all devices is correlated (input and label), for every index l.CL is the practical reality in the following example applications: 

Multi-Digit MNIST: Each classifier sees a handwritten digit as input. However, the digits of all agents are dependent (e.g., credit card numbers, error correction codes, or the same handwriting). For example, adjacent digits must add up to 10, or all digits tend to equal a common hidden digit. 

Remote Sensors: The agents are sensors that collect local environmental features (e.g., temperature, vibration, gas). The task is to classify whether a global phenomenon, such as a fire or earthquake, is occurring. Since all sensors in the same region are exposed to the same event, their data (inputs and labels) are correlated. However, each sensor only observes part of the full picture. Sharing model outputs, rather than raw data, allows the agents to benefit from the collective information while meeting the communication constraints. 

Medical Wearables in Shared Environments: Each agent monitors a different patient using wearable sensors that record local physiological signals (e.g., heart rate, skin temperature). The task is to detect the onset of a disease. When patients are nearby, such as on a hospital ward or during an outbreak, their health outcomes are correlated, as infection spreads. In this case, leveraging cross-patient correlations can improve prediction accuracy. However, direct data sharing is prohibited due to privacy constraints. A distributed learning approach that shares only model outputs can enable collaboration without compromising sensitive health data. 

Formation Control: A group of moving agents often has to maintain a target forma-tion. Examples are platoons of autonomous vehicles or drones. Each vehicle collects local sensor data (e.g., LiDAR, radar, velocity) and must classify whether to accelerate, main-tain speed, or decelerate. Since vehicles influence each other’s decisions, especially those of their neighbors, their data is correlated. However, each vehicle observes only partial information. Sharing embedded outputs rather than raw sensory data allows collaborative real-time decision-making while preserving autonomy. Our goal is to design a distributed training scheme that achieves close to optimal per-formance in this cordial learning scenario, while maintaining low communication overhead. We measure performance by the sum of loss functions of all agents. A centralized architecture would collect data from all agents and train one large model to fit their combined input to their combined labels. Then, the central server is needed in real-time, so all devices can send their input data to the server and receive the result back. Such a centralized architecture requires significant communication between a central server and the agents to collect all their data, both in training and in real-time. Then the central server must train a huge ML model with a large dataset to obtain all agent models. Perhaps even worse, collecting user data in the central server can violate user privacy. It also creates a single point of failure. Communication, latency, complexity, and privacy are known 

> 2Distributed Training with Correlated Data

issues with any centralized architecture. In the context of cordial learning, the centralized architecture is also data-inefficient. The classification tasks are inherently distributed in the sense that each agent observes a different part of the whole problem. A centralized agent will waste a lot of data “understanding” the distributed nature of the problem (e.g., that there are N digits in the multi-digit example). In other words, since the problem is distributed, a data-efficient architecture will also have to be distributed. In CL, the learning tasks of the agents are intertwined. If two agents each observe a digit, knowing that both digits are even or odd together, then each agent only needs the other agent to detect the parity of its digit. However, being able to classify a digit is very much related to classifying its parity. On the other hand, only sending the decision is not enough information. If an agent believes that the digit is six, but digits nine and three together are more likely, then this information is lost. A similar tradeoff exists in remote sensors that detect fire - even if one sensor is sure that currently there is no fire in its region, some indicators can help sensors in more sensitive areas to lower their detection threshold. We propose using an embedded output as the basic communication unit between the agents. The embedding is in the dimension of the output, a short vector compared to the input vectors. This embedded output is similar to the softmax output of a neural network (NN), but not the same. The softmax output of our agents is computed after incorporating the information from other agents, while the embedded output is processed before. In CL, agents maintain coordination layers dedicated to extracting useful information from the inputs they receive from other agents for the same sample. Thus, each agent simultaneously trains its NN along with these additional layers. This introduces a unique coupling (or interaction) between the agents. The weights of the NN of agent n affect not only the loss of agent n, but also the loss of all other agents, since it changes the information they receive from agent n. As our analysis reveals, this interaction requires careful design. The sum of loss functions is nonconvex even in the linear regression case. Thus, many suboptimal stationary points may exist. For the linear theoretical model, we show that if the learning of the “coordination layers” is slower than the learning of the embedding layers, then CL is guaranteed to converge to the optimal agent models that minimize the nonconvex sum of loss functions. This happens even though each agent locally optimizes only its loss function, ignoring the effect of its model on the loss of others. This makes CL a scalable, distributed training algorithm that can incorporate many devices, with little communication overhead. 

2. Previous Work 

Our work belongs to the growing literature on on-device learning. When the datasets of different agents are independent, each agent has a disjoint dataset for the same classification task. This corresponds to the classic on-device learning setting addressed by federated learning (Kairouz et al., 2021; Mitra et al., 2021; Koloskova et al., 2022), where no inter-agent correlation exists. Reducing the communication of federated learning and distributed SGD has been recognized as crucial (Wang and Joshi, 2021). Unlike CL, FL is not designed to deal with correlated data. Additionally, FL requires that all devices have the same architecture so that the weights can be averaged. In CL, different devices can have different architectures. 

> 3Shitrit and Bistritz

In Bistritz et al. (2020), we designed a distributed distillation scheme in which agents share softmax outputs on common unlabeled data to learn from each other’s private data without revealing it. Since softmax is a short vector, the resulting communication overhead is dramatically lower than with FL, and devices with different ML architectures can par-ticipate in the training. Distributed distillation does not deal with correlated data. In CL, agents share embedded outputs to learn from other agents about the same sample they are currently learning from. Game theory and learning have recently become intertwined. The literature on learning in games studies the interaction between players who learn to maximize their reward. Then, convergence to a Nash equilibrium (NE) is guaranteed for various distributed algorithms in many scenarios (Xu et al., 2025; Ratliff et al., 2016; Bistritz et al., 2022; Chasnov et al., 2020; Mazumdar et al., 2020). We study the opposite - how games can help in learning. Game theory has already been proven insightful for learning in generative adversarial networks (GANs; Goodfellow et al., 2020). Unlike the zero-sum games studied in GANs, our players are cooperative and each is an individual ML system (Bistritz and Bambos, 2020). Distributed learning with linear models that observe local measurements with correlated noise was studied in Hong et al. (2022). The risk functions include a term that penalizes for deviating from neighboring models. In our scenario, players do not necessarily converge to the same model. On the contrary, players may face non-identically distributed data and need to take heterogeneous actions (e.g., the medical wearables example above). Performative prediction studies a game scenario where the actions of one learner affect both the risk scores and the distributions of the data of the others (Narang et al., 2023; Lin and Zrnic, 2024; Perdomo et al., 2020). The goal is to compute an equilibrium that predicts the behavior of selfish learners. In contrast, our agents are cooperative. Furthermore, given the distribution, the datapoints of different players in Narang et al. (2023) are independent, while ours are correlated. Finally, Narang et al. (2023) assumes that players can observe each other’s actions, which is unacceptable in our case since it would mean that players can observe the model parameters of everyone. CL resembles vertical federated learning (VFL) (Liu et al., 2024). In VFL, the different agents have different nonoverlapping features of the same sample. This means that the inputs of the agents are correlated. However, in VFL, there is one learning task and one label, which only the “active agent” possesses. In contrast, in CL, each agent has its own local learning task and its own label, and the labels are correlated between agents. In this sense, VFL is a special case of CL, where all labels are identical and only one agent orchestrates the learning. Multitask learning (MTL) (Maurer, 2006) is also concerned with intertwined learning tasks. However, MTL trains a centralized architecture and not distributed agents. Even more important is that MTL is trained for tasks that occur asynchronously in real-time. In contrast, CL trains distributed agents that learn from synchronous correlated data points in real-time. While successive classification shares the idea of interdependent models, it differs from our setting in several fundamental ways. In pipelines such as Faster R-CNN (Ren et al., 2015), the region proposal network and the final classifier share a common feature extraction backbone, introducing architectural coupling. However, the overall computation proceeds sequentially: region proposals are generated and then classified. In contrast, CL involves a

4. Cordial Learning Algorithm and Performance 

We propose a novel algorithm, termed cordial learning (correlated and distributed learning), to deal with the correlated data scenario. In cordial learning (CL), agents only share their embedded outputs and never their explicit datapoints. Then, each agent’s model includes coordination layers to process the inputs from other agents. The pseudocode for CL is given in Algorithm 1. To keep it tractable, our theoretical model is linear (Maurer, 2006), but CL applies more broadly to any scenario in which training data is correlated between agents. We support this claim with experiments on deep neural networks (see Section 6). CL is distributed since each agent calculates the gradients over its local parameters only. Instead of optimizing the global objective (7) directly, each agent optimizes its local

Centralized gradient descent that optimizes (7) would require each agent i to know the gradient of the loss function of agent j with respect to Mi. CL bypasses that, as each agent runs a two-time-scale SGD to minimize its loss function (6) with respect to its parameters alone. The stochastic gradients of an agent employ information sent by others. In general, SGD does not converge in games. When it does converge, it is to a stationary point that, under mild conditions, is a Nash equilibrium (NE) (Mazumdar et al., 2020), which is typically socially inefficient (Roughgarden, 2015; Sessa et al., 2019). Surprisingly, our main theorem shows that in the game induced by the designed loss functions in (6), a two-time-scale SGD converges to a global minimum of the sum of loss functions.

6. Experiments 

In this section, we test CL numerically. The first set of simulations uses our linear theoretical model, assumed in Theorem 2. The second set goes beyond the linear model and runs CL with deep neural networks that classify the digits of a composite MNIST image. 

6.1 Linear Model Simulations Input Data Generation. We simulated N ∈ { 8, 16 , 32 } agents. Agent i has an input 

Xi ∈ Rd and a label Yi ∈ Rm, with d = 2 and m = 1. As assumed in Section 3.1, the inputs have zero mean and are whitened, so that E{XiXTi } = I. The inputs of different agents are correlated coordinate by coordinate. For each coordinate k = 1 , . . . , d , the vector ( X1,k , . . . , X N,k ) has a correlation matrix R ∈ RN ×N , and different coordinates are independent, so that Cov( Xj , X i) = Rji I. In every run we draw a new matrix R with unit diagonal and off-diagonal entries ( Uji + Uij )/2, where the entries of U are drawn uniformly from [ −5/N, 5/N ]. Such a matrix is not always positive semidefinite. In that case, we replace it by a nearby correlation matrix: we raise its eigenvalues to at least 10 −12 and rescale it to a unit diagonal. This was needed in about 60% of the runs with N = 8, in less than 10% of the runs with N = 16, and in none with N = 32. We use two input distributions. In the first, the inputs are Gaussian with correlation matrix R. In the second, the inputs have Laplace marginals: we draw Gaussian inputs as before and map every coordinate g to F −1(Φ( g)), where Φ is the standard normal distribu-tion function and F is that of the Laplace distribution with unit variance. The coordinates of each agent stay independent with unit variance, but their correlations across agents change. For Laplacian inputs, Cov( Xj , X i) = ˜Rji I, where ˜Rji is the correlation of the transformed coordinates, which we compute from Rji by numerical integration. In the rest of this section, Cov( Xj , X i) refers to this matrix for Laplacian inputs.

6.2.1 The Pairwise-10 Dataset 

In the Pairwise-10 dataset, the digits of a sample satisfy two rules. The digits at positions (1 , 2) , (3 , 4) , . . . sum to 10, and so do the digits at positions (2 , 4) , (4 , 6) , . . . . The valid tuples of digits are therefore ( a, 10 − a), ( a, 10 − a, 10 − a, a ) and ( a, 10 − a, 10 − a, a, a, 10 − a) for 

N = 2 , 4, 6, with a ∈ { 1, . . . , 9}. In particular, the digit of any single agent determines the digits of all other agents. Each of the three sets has P composites of every valid tuple, that is, 9 P composites. We report P = 25, 100, and 500, from 225 to 4,500 composites per set. The final runs have 2,250, 600, and 180 epochs, respectively. 

Results. Figure 5 shows the test loss during training for P = 25, 100 and 500, and Table 2 lists the test loss and accuracy of the selected networks. CL is much better than isolated training in every setting. For P = 25, the median test loss per agent of isolated agents is 0.45, 0 .30 and 0 .30 for 2, 4 and 6 agents. Cordial learning reduces it to 0 .23, 0 .014 and 0.0028, and raises the median accuracy from 0 .88, 0 .91 and 0 .91 to 0 .94, 0 .996 and 1 .000. For P = 500, isolated agents reach an accuracy of 0 .98 and a test loss of 0 .06–0 .07, and CL reduces the test loss to 0 .008, 0 .0009 and less than 10 −4. In every setting, every run of CL has a lower test loss than every run of isolated agents on the same draw, except for 2 agents with P = 25, where this holds for 297 of the 300 pairs of runs. The gain grows with the number of agents, which is expected, since every additional agent brings another view of the same information. The draw of the images matters for P = 25: the median test loss of isolated agents with 2 agents is 0 .31, 0 .47 and 0 .49 on the three draws, and that of CL is 0 .093, 0 .30 and 0 .26. The advantage of CL holds on every draw. The centralized network shows what can be achieved when observing all digits. With 

P = 500, it reaches a test loss of 0 .002 for 2 agents and less than 0 .0001 for 4 and 6 agents. CL reaches almost the same accuracy (at least 0 .998), although the agents only exchange their 10-dimensional embedded outputs and never their inputs or gradients. The centralized network has the lower test loss in most pairs of runs. With less data, the centralized network often failed to train. With the selected config-uration, 47 of its 180 runs with P = 25 and P = 100 did not learn at all: the network predicts the uniform distribution over the nine possible digits for every agent, with a test loss of ln 9 ≈ 2.2. 7. Conclusions 

We studied a distributed learning scenario in which agents’ data are correlated. This gener-alizes the federated learning scenario where agents have independent data. To allow agents to learn from each other, we propose cordial learning, where agents send their embedded outputs to others. The agents train layers to learn how to extract valuable information from the embedded outputs of other agents. For a linear model where the label of an agent is a linear mixture of the inputs of all agents, under mild assumptions, we proved that cordial learning converges to models that minimize the sum of losses of all agents. Experiments on multi-digit MNIST with deep neural networks show that cordial learning performs well even beyond the theoretical model we analyzed. Our analysis focused on asymptotic convergence to the optimal models. The question of analyzing and optimizing the convergence rate remains open. The related question of proving optimal regret bounds in online learning settings is also open. Cordial learning is a first step towards studying distributed learning scenarios with correlated data. A challenging open question from this perspective is designing a cordial learning scheme where agents learn how to efficiently compress the information they send based on the loss functions of the receiving agents.
