## Abstract 

User behavior simulation is widely used to evaluate interactive information retrieval systems, but classical state-based approaches (e.g., Markov models) have limited ability to incorporate contextual information relevant for decision-making. We address this limita-tion by introducing a feature-conditioned Markov-style user model, in which transition probabilities are modeled as functions of po-sitional, content-based, and interaction-derived features, enabling context-aware decision making while preserving the structural simplicity and computational efficiency of state-based models. Applying a multi-level framework that assesses predictive fit and behavioral fidelity, we analyze how different sources of contextual information contribute to realistic user simulation across multiple datasets, search settings, and feature configurations. Our results show that incorporating contextual features improves the models’ ability to reproduce key aspects of real user interactions, but that their effectiveness hinges on search scenario and modeling objective. Instead of a “one-size-fits-all” solution, effective simulation requires task- and setting-specific feature selection. Our framework provides a practical and interpretable basis for making these choices.

## 1 Introduction 

User behavior is central to the evaluation of interactive information retrieval (IIR) systems. While user studies provide valuable, user-centric insights [24, 26], much of IR evaluation relies on system-oriented methods that abstract away from actual user interactions, and most common effectiveness measures implicitly assume partic-ular models of user behavior, for example, with respect to attention, examination depth, or stopping behavior [10, 18, 43]. User simulation provides a principled way to make such behav-ioral assumptions explicit and to study their effects in a controlled, repeatable manner, thereby contributing to greater transparency and reproducibility in IIR [5]. By generating interaction sequences rather than relying solely on static relevance judgments, simulation-based evaluation can increase the realism of system-oriented exper-iments. However, the usefulness of simulation critically depends on how well it reflects real user behavior: unrealistic simulators can result in incorrect conclusions about system performance [29]. A wide range of user models has been proposed for this purpose. Classical state-based approaches, such as Markov models, offer transparent and controllable representations of user behavior. They are computationally efficient, easy to analyze, and well-suited for systematic experimentation [7, 37]. However, these models typically assume context-free transitions, despite strong evidence that con-text substantially influences search behavior [14, 27, 36]. This limits their ability to capture important aspects of real user behavior. Recent modeling approaches, such as large language models, can generate user behavior considering rich context and complex decision mechanisms [25, 31]. Despite offering great flexibility, such approaches suffer from high computational cost and limitations in interpretability, systematic analysis, reproducibility, and control [8]. Moreover, in light of documented discrepancies between human and LLM relevance judgments, their validity as proxies for real user behavior remains uncertain [3]. This highlights a methodological gap: there is currently no clear middle ground between simple, interpretable models and highly expressive, yet opaque ones. In this work, we propose a principled extension of state-based user models that aims to bridge this gap. Instead of using constant transition probabilities, we model transitions as functions of con-textual features. This allows decisions to depend not only on the current interaction state but also on various contextual factors. arXiv:2610.06060v1 [cs.IR] 5 Oct 2026 CIKM ’26, November 07–11, 2026, Rome, Italy Jana Isabelle Friese, Andreas Konstantin Kruff, Timo Breuer, Philipp Schaer, and Norbert Fuhr 

This design makes it possible to investigate which contextual factors matter most for reproducing real user interactions across search settings, motivating the following research questions: RQ1 Does conditioning state-based user models on contextual features improve predictive fit and behavioral realism? RQ2 In what ways do different types of contextual features, includ-ing situational and content-based information, contribute to reproducing different behavioral aspects? To answer these questions, we compare a baseline Markov model with a set of feature-conditioned variants and evaluate them using a multi-level evaluation framework that assesses both predictive performance and behavioral fidelity at varying levels of granularity across datasets capturing different search settings. This work makes three main contributions: First, we introduce a framework for feature-conditioned state-based user modeling that combines interpretability with contextual expressiveness. Second, we present a structured evaluation methodology for assessing simu-lation quality across multiple levels of behavioral specificity. Third, we provide an empirical analysis across multiple datasets of how different types of contextual information affect simulated behavior, highlighting both where context improves realism and how the importance of specific features varies across settings. 

## 2 Related Work 

A widely adopted model-based approach for user modeling in in-formation retrieval (IR) is the use of Markov models. Zerhoudi et al. [40] argue that Markov models are popular for modeling user search behavior because of their simplicity, compact representation, and well-established theoretical foundations. In particular, the authors highlight that first-order Markov mod-els are well-suited for simulation-based modeling, as they capture essential sequential dependencies without introducing unnecessary complexity. Thus, here, Markov models are used for user mod-eling, with the model learned from logged user interaction data. Simulation, in contrast, refers to generating synthetic behavior by sampling from the learned model. [38]. The simulation framework SimIIR 2.0 integrates Markov model-based behavior modeling [41]. Beyond first-order and k-th-order Markov models, several other Markov-based approaches have been employed in the IR context. These include Hidden Markov Models (HMMs) [13] and Partially Observable Markov Decision Processes (POMDPs), which allow modeling latent user states and incom-plete observability. Furthermore, decision-oriented frameworks such as Markov Decision Processes (MDPs) and Multi-Armed Ban-dits (MABs) have been successfully applied to capture interactive and adaptive retrieval scenarios [37]. Building on these various Markov-based approaches, first-order Markov models with absorb-ing states were adopted for the experiments. This choice allows to capture sequential user navigation while explicitly modeling terminal behaviors such as session completion. The simplicity of first-order models ensures tractable estimation, while absorbing states provide a more realistic representation of user sessions [32]. Despite the advantages, these models still rely on global transition probabilities, disregarding external factors. To address this limita-tion, context-aware Markov models have been proposed, allowing state transitions to depend on relevant contextual information and thereby improving predictive accuracy and descriptive power. Al-though contextual Markov models were already widely used in cybersecurity, Bar et al. [6] appear to be the first to apply this ap-proach to user modeling in a web browsing scenario, representing URLs as states and transitions between them as actions. They pro-pose different methods of incorporating context; however, only the Naïve-Bayes-style approach directly extends the Markov models with contextual features, representing them as discrete condition-ing variables for look-up-based probability estimations. Building on this, our approach represents context as continuous feature vectors that parametrically shape transition probabilities. In addition to modeling sequential navigation, understanding which signals influence user click behavior is crucial for improving and validating our approach. Previous studies have shown that users are strongly affected by position bias, tending to click more frequently on higher-ranked documents, while results lower in the ranking or on subsequent pages receive considerably less at-tention [17, 22, 28]. Conversely, some domain-specific relevance signals appear to have minimal impact on click decisions; for ex-ample, Kacem et al. [23] found that bibliometric indicators did not significantly influence user clicks. Beyond individual clicks, several studies have also highlighted that the overall quality of the result list can affect users’ stopping behavior, shaping how many results they examine and when they terminate their search session [1, 4, 30]. Taken together, these findings suggest that both contextual factors and list-level signals shape user interactions, highlighting the need for models that can integrate multiple types of information when predicting click behavior and session outcomes. 

## 3 Proposed Model 

In this work, we aim to enhance Markov models by incorporating contextual information, and we evaluate how this affects the realism of simulated behavior. To this end, we consider two types of state-based user models, which we describe in the following sections. 

## 3.1 Base Model 

The base model serves as a baseline for comparison with our en-hanced models. It is a standard Markov model with constant transi-tion probabilities 𝑃 (𝑎 𝑡 +1 |𝑠 𝑡 ), where the state space is 𝑆 = {𝑠 1, ...𝑠 𝑛 }

and the set of possible actions is 𝐴 = {𝑎 1, ..., 𝑎 𝑚 }. The probability of a particular action depends solely on the current state and is independent of any additional context. While simple and inter-pretable, this approach cannot account for contextual factors such as document position, relevance, or the user’s prior interactions. 

## 3.2 Feature-conditioned Model 

To incorporate context, we propose an extension in which each state transition is modeled using a probabilistic classification model. Instead of fixed probabilities that depend only on the current state, the likelihood of each possible next action also depends on a feature vector 𝒙 𝑡 describing the current context at time 𝑡 :

𝑃 (𝑎 𝑡 +1 |𝑠 𝑡 , 𝒙 𝑡 )

By incorporating context, the model can adjust transition proba-bilities based on information available at each point in the session, capturing nuanced aspects of behavior beyond the current state. Strictly speaking, these models are no longer Markovian, because some features implicitly encode session history, which violates the Markov property that the decision depends only on the present state 

𝑠 𝑡 alone. However, the feature-conditioned model can be interpreted as a first-order Markov model over an implicitly augmented state space. We define the augmented state as ˜𝑠 𝑡 = (𝑠 𝑡 , 𝒙 𝑡 )

The transition probability then depends only on the current aug-mented state: 

𝑃 (𝑎 𝑡 +1 | ˜𝑠 𝑡 )

Conceptually, this corresponds to a Markov model with a very large, sparse transition matrix, where each combination of state and feature values is a separate state. While the explicit state space would be prohibitively large, the probabilistic classification parametrization provides a compact representation, allowing the model to remain interpretable and tractable. In summary, the proposed feature-conditioned model a) extends the base Markov model by conditioning transitions on contextual features, b) preserves the Markov property in an augmented state space, c) allows systematic study of how different feature types influence user behavior, and d) remains computationally feasible without explicitly enumerating all state-feature combinations. 

## 3.3 Contextual Features 

Context is a broad concept that encompasses many factors influ-encing a user’s decisions during an interactive search session. To capture these influences, we select a diverse set of features repre-senting complementary aspects of context. These features can be broadly grouped into two categories: situational features , which describe the user’s state and the progress of the search session, and 

content-based features , which characterize the relevance or quality of the document or snippet currently under consideration. 

3.3.1 Situational features. Situational features describe the current context of the user within a session and are here further divided into positional, temporal, and knowledge-based features. Positional and temporal features reflect how far a user has pro-gressed in a search. Indicators such as rank or elapsed time pro-vide information about the depth of interaction and the effort in-vested so far. User behavior is known to be strongly influenced by search progress: rank bias has been described repeatedly, and rank is widely used in information retrieval evaluation as a proxy for user attention [12, 21, 27]. Similarly, elapsed time is associated with factors such as fatigue, diminishing returns, or the likelihood of abandoning a search [20, 42]. For these reasons, positional and temporal features are included as fundamental situational signals. However, progress alone does not capture what a user has learned during a session. Whether a user continues or terminates a search depends not only on how long or how deep they have searched, but on whether their information need has been satisfied and which actions they have already taken [9, 34, 36]. To model this aspect, we introduce a low-level knowledge-state representation that reflects prior user interactions. In particular, we consider how many doc-uments have already been clicked or, where applicable, explicitly marked as relevant. These signals serve as a proxy for accumulated knowledge and perceived success, allowing the model to account for the influence of prior interactions on subsequent decisions. 

3.3.2 Content-based features. Content-based features describe prop-erties of the document or snippet currently under consideration and are independent of the user’s situational state. Examples include a document’s retrieval score or the similarity between document text and query. Such features provide an estimate of result quality from the system’s perspective and can influence how users respond to presented items: low-quality results may encourage query reformu-lation, while high-quality results are more likely to be clicked or to motivate deeper exploration of the current result list [2, 4]. By incorporating content-based features, the model accounts for how perceived relevance shapes user decisions at each interaction step. 

3.3.3 Combined feature representations. In realistic search scenar-ios, user decisions are rarely driven by a single factor; rather, they emerge from the interaction between search progress, accumulated knowledge, and the perceived quality of available results. Evalu-ating feature groups individually and in combination allows us to analyze which sources of contextual information contribute to dif-ferent aspects of behavioral realism and at what levels of behavioral specificity these effects become apparent. 

## 4 Methodology 

We aim to examine how various types of contextual information influence behavioral realism in Markov-style user models, and how these effects manifest in predictive fit and simulated user behavior in different search settings. To this end, we use three heterogeneous session log datasets and train multiple models on the observed in-teractions: a baseline Markov model with constant transition prob-abilities, and feature-conditioned models incorporating different combinations of situational and content-based features. To evaluate model performance while avoiding overfitting, we employ 10-fold cross-validation with repeated simulation. Evaluation is conducted at multiple levels of specificity, ranging from overall aggregated interaction counts to path-level similarity and the preservation of original behaviors such as clicks. To assess the benefit of feature conditioning, we compare the performance of extended models to the baseline. Furthermore, by systematically comparing models with different feature combinations, we identify which types of contextual features contribute most to behavioral realism and map their effects across levels of user interaction. 

## 4.1 Datasets 

For evaluation, we needed datasets with sufficiently long sessions, the required contextual features, and comparable interaction log-ging. These characteristics are typically found in controlled labora-tory studies, so we selected three lab-study datasets. These cover different search settings, enabling a systematic analysis of contex-tual effects across heterogeneous scenarios. While two datasets involve conventional search setups—in news search and argument retrieval—the third uses predefined queries, resulting in a more constrained search process. Moreover, its results are presented in randomized rather than relevance-ranked order, allowing us to study user behavior in the absence of rank-based relevance cues and to disentangle positional effects from document relevance. 4.1.1 TREC Session 2014. The first dataset is based on Session Track data from TREC 2014 [11], a widely used and well-established benchmark for modeling user behavior in search, and represents the most common search scenario in this work. The logs were collected via Mechanical Turk on ClueWeb12 and contain interaction data, including initial queries, reformulations, and document clicks. Only implicit relevance feedback is available; there is no information about user satisfaction or explicit relevance judgments. Of the 1,257 sessions in the dataset, the majority contained too few interactions for an informative analysis. We therefore selected a subset of 200 sessions from the dataset, requiring each session to contain at least two reformulations and three click interactions. Although interaction timings for queries and clicks are recorded, there is no explicit indication of session termination. Furthermore, while document rankings are available, the original retrieval scores could not be reconstructed. However, similarities between queries and document titles or snippets could still be computed. The sessions are typically short and limited to basic interaction types, which constrains the expressiveness of user behavior and reduces the observable differences between models. Nevertheless, the dataset remains an important standard benchmark, allowing for comparison with prior work. 

4.1.2 LISP. The second dataset, LISP [15], consists of session logs from the argument retrieval domain, representing a distinct search task while providing a comparable setup. It contains 122 user ses-sions from 61 distinct users and was collected in a controlled lab environment. Participants were asked to prepare an opinion essay by searching for pro- and con-arguments for a given topic within a fixed time frame of 10 minutes. During a session, users could reformulate queries, explore result pages, read full documents, and mark arguments as relevant, providing explicit relevance feedback. In addition to interactions and document information, the logs include timestamps for query formulation, document expansion and reduction, and marking actions; intermediate snippet observations were not explicitly logged and therefore had to be estimated. More-over, the original retrieval pipeline was published with the dataset, enabling us to compute additional text-based features beyond the provided retrieval scores. Overall, LISP sessions are relatively long and contain a rich set of interactions, offering a detailed view of user behavior. 

4.1.3 TIPPS. Finally, we used interaction logs collected in the study “The Influence of Presentation and Performance on User Satisfac-tion” (here referred to as TIPPS) by Pathak et al. [33] that were kindly provided on request. The study investigated the effects of result card layouts on user search performance and satisfaction. Participants searched for news on given topics using a set of pro-vided queries. While they could decide which queries to inspect and in what order, they could not formulate their own. A particularly interesting aspect of this dataset is that search results were presented in randomized order rather than ranked according to system-estimated relevance. Although the dataset addresses a similar news search task as TREC, the randomized result presentation leads to a substantially different interaction setting, which allows us to examine the influence of positional bias and to investigate whether users are more strongly affected by a document’s presented rank or by its actual relevance. The dataset did not include raw interaction logs but rather pre-processed data from which we reconstructed user sessions. The available data contain clicks, user relevance judgments, both the original and displayed document ranks, and others. The detailed setup description allowed for computation of content-based fea-tures, including retrieval scores, though missing document IDs prevented their extraction for some documents in the logs. We restricted our analysis to sessions originating from one of the evaluated interfaces. Specifically, we selected the interface most comparable to those used in the other datasets with respect to result presentation, ensuring that the same feature sets could be applied reasonably across datasets. This resulted in a final set of 75 sessions. 

## 4.2 Data Preprocessing and Feature Extraction 

For each dataset, the session logs were preprocessed to extract rele-vant user interactions and transform the data into a uniform format suitable for modeling. Non-informative entries were removed, and relevant interactions were represented as single records containing all necessary contextual information. Since snippet views were not explicitly recorded, we estimated seen snippets based on clicked documents and the time intervals between consecutive interactions. After preprocessing, features for the feature-conditioned models were computed where necessary and grouped into related sets: 

• Positional: rank, query rank 

• Knowledge-based: number of previous clicks, number of pre-vious marks (where available) 

• Temporal: time spent in the session 

• Content-based: retrieval score (where available), query-docu-ment/snippet similarity The availability of content-based features differed between data-sets: For TREC, no full texts were available, so query-snippet cosine similarity was used instead of query-document cosine similarity. Regarding temporal features, interaction times in both the simu-lations and the original sessions were set to the average interaction times observed in the dataset. While this normalization leads to the measures being functions of interaction counts and ordering and not independent of other feature sets, it ensures comparabil-ity between real and simulated sessions and avoids distortion by user-specific timing effects. 

## 4.3 Model Training 

For each state, we trained a separate multi-class logistic regression model to predict the next user action. Models were trained for each feature set and for combinations of feature sets. Training was performed within each fold. Observed next actions were encoded as categorical labels, and feature vectors were stan-dardized. Hyperparameters, including the regularization strength, were optimized via 5-fold grid search within the training data, using negative log-likelihood as the scoring metric. After optimization, models were retrained on the full training set within the fold. The baseline Markov model with constant transition probabilities was trained directly from observed transitions, without any contextual features. This approach ensures that each state’s transition prob-abilities are learned independently while allowing comparisons between models trained with different feature sets. ## 4.4 Simulation Procedure 

To assess behavioral realism, we simulated user sessions based on the original session logs. For each observed session, we ran 100 simulations per model, and outcomes were averaged across runs to reduce Monte Carlo noise (i.e., variability due to stochastic sampling). The procedure was identical for both the baseline and feature-conditioned models. Each simulation begins in a dedicated START state and proceeds until the session reaches a STOP state, with a fixed interaction time assigned to each state. At each step, the next action is drawn according to the model’s predicted probabilities, conditioned on the current state and, for feature-conditioned models, the current fea-ture vector. Features that depend on session history (e.g., number of documents already clicked, time spent) are updated dynami-cally during the simulation, and the updated values are used for subsequent transitions. Queries and their corresponding result lists are taken directly from the original session logs. When a simulated user enters a 

QUERY state, the next query and associated ranked documents are retrieved from the corresponding real session. The simulated user then interacts with the result list, clicking or marking documents according to the model’s probabilities. If a query reformulation occurs, the next query is again taken from the original session; if the queries in the session are exhausted, the session terminates at the next reformulation and enters the STOP state. As a consequence of this design, simulated sessions can con-tain at most as many queries as the corresponding real session and are therefore, on average, shorter. We intentionally impose this constraint to ensure that all models are evaluated under iden-tical and realistic conditions. Generating artificial queries would introduce additional modeling assumptions and potential biases that are difficult to quantify, and would remove the direct com-parability between simulated and real sessions that underlies our evaluation. By grounding simulations in the original queries and result lists, we preserve a consistent reference point for assessing behavioral fidelity while allowing the models to express different decision-making patterns at each interaction step. 

## 5 Evaluation 

To assess the quality of the proposed models, we adopt a multi-level evaluation framework. This approach allows us to evaluate not only predictive performance but also behavioral realism at progressively finer levels of detail, from coarse aggregate measures to detailed interaction preservation and session trajectory similarity. 

## 5.1 Evaluation Levels 

We evaluate simulated sessions at six levels: 

1. Predictive Fit. At the coarsest level, we measure negative log-likelihood (NLL) on held-out sessions. NLL quantifies how well a model predicts the observed actions: lower NLL indicates that the model assigns higher probabilities to the actions that users actually took. This provides a basic check of model fit and ensures that the models are capturing fundamental patterns of decision-making. 

2. Aggregate Behavior. Next, we examine session-level statistics to determine whether the models reproduce broad behavioral patterns. We consider: 

• Number of queries issued 

• Number of snippets examined 

• Number of documents clicked 

• Number of documents marked (when available) For each session, results are averaged over the simulation runs and compared to the corresponding real session. These aggregate measures provide insight into whether the models capture overall interaction volume and search effort. 

3. Document-level overlap. To evaluate whether models select the same items as real users, we compute document-level precision, re-call, and accuracy for clicks and marks. Accuracy is restricted to the top 30 ranks to avoid inflation from tail-end documents. This analy-sis captures the models’ ability to reproduce specific document-level decisions, moving beyond coarse aggregate statistics. 

4. Temporal dynamics. User behavior is shaped not only by actions, but also by their timing. We measure the following temporal aspects: 

• time to first click 

• time to first mark (when available) 

• time to relevant (TTR) 

• total session time Time to first click or mark provide straightforward indicators of how quickly users begin interacting with results. TTR captures a more comprehensive notion of efficiency by measuring the average time required to reach relevant documents throughout a session, in-cluding interactions that occur later [35]. As explicit user relevance judgments are available for two datasets, while objective relevance labels are mostly sparse, we use marks to model relevance for LISP and TIPPS, and clicks as implicit relevance signals for TREC. 

5. Outcome quality. We compute session-level normalized discounted cumulative gain (sDCG) [19] to evaluate the effectiveness of simu-lated interactions from a retrieval perspective. While temporal metrics rely on interaction-based relevance prox-ies, sDCG is computed using the dataset relevance judgments so that real and simulated sessions can be evaluated on the same scale. 6. Trajectory similarity. Finally, we assess session-level realism by measuring Fréchet distance. Fréchet distance correlates well with es-tablished evaluation metrics and is particularly effective for longer and more complex interaction sequences, even when interaction data are sparse [39]. By accounting for both the ordering and the spatial alignment of interactions, it captures similarities in complete behavioral paths rather than isolated actions, complementing more specific measures in this evaluation. 

## 5.2 Evaluation Strategy 

To assess the quality and behavioral fidelity of the simulated ses-sions, we adopt a multi-level evaluation strategy that complements the metric definitions. First, each session is simulated 100 times per model to reduce stochastic noise. Metrics are calculated for each simulated session and then averaged across the runs, providing stable per-session estimates. For each metric, we consider both the raw simulation values and the differences relative to the corresponding real session. This approach allows us to evaluate not only overall behavior but also how closely the model reproduces individual user interactions. After computing per-session measures, values are further averaged across all sessions in the dataset to obtain a single summary value per model for cross-model comparisons. As this study is exploratory in nature, our goal is not to identify a single statistically superior model, but rather to analyze how dif-ferent sources of contextual information contribute to simulation realism. We therefore restrict statistical testing to comparisons be-tween each feature-conditioned model and the baseline model. We report paired t-tests with Benjamini–Hochberg FDR correction. In the result tables, statistically significant differences are marked with asterisks (*), while arrows indicate whether the feature-conditioned model produces behavior closer to ( ↑) or further from ( ↓) the real sessions relative to the baseline. The multi-level evaluation provides several advantages. First, progressive specificity—from predictive fit to detailed behavioral and trajectory measures—enables identification of where improve-ments occur. Second, complementary perspectives allow us to detect cases where models reproduce aggregate statistics well but fail to capture fine-grained document choices or temporal patterns. Third, interpretability is enhanced by separating metrics by level, mak-ing it possible to determine which features drive improvements in different aspects of behavior. Finally, robustness is achieved by eval-uating across multiple levels and datasets, ensuring that observed gains are not confined to a single metric or dataset.

Aggregate behavior. At the aggregate level, we compare simulated and real sessions in terms of interaction volume. Rather than abso-lute counts, Table 1 reports the mean per-session deviation between simulated and real sessions for each interaction type, reflecting how closely a model reproduces overall user activity. Across datasets, all models underestimate interaction volume rel-ative to the original logs, which is expected given that simulations are constrained by observed query sequences. Aggregate deviations should therefore be interpreted in light of the simulation setup, as early termination directly affects interaction counts and session duration. As a result, differences at this level partly reflect struc-tural truncation rather than purely behavioral modeling quality. Nevertheless, systematic differences between models are apparent. Overall, feature-conditioned models reduce aggregate deviations compared to the baseline, although no single model consistently per-forms best across all interaction types and datasets. For all datasets, contextual conditioning improves the accuracy of issued query counts, with the temporal model achieving the lowest query-level deviation for TREC and LISP. For LISP, temporal features yield com-paratively strong performance across several aggregate measures, whereas for TREC, their benefits are largely limited to query counts, and for TIPPS, they do not show substantial benefits at all. For snippet interactions, results differ across datasets. On TREC and TIPPS, none of the single-feature models outperforms the base-line, although the combination of positional and knowledge fea-tures yields the smallest deviation for TREC, with an average differ-ence of 10.92 snippets per session. On LISP, however, most feature-conditioned models reduce deviations relative to the baseline. Click and mark interactions show more pronounced improve-ments, though not for all feature sets. Positional features and the full feature combination consistently yield the smallest deviations for clicks and marks across all datasets. In contrast, content-based features do not improve aggregate interaction volumes on any dataset, while temporal and knowledge features lead to modest improvements on LISP but not on TREC or TIPPS. Taken together, positional features exhibit a strong and consis-tent performance profile: while not always yielding the smallest deviations, they reliably outperform the baseline and perform well on the most behaviorally salient measures, such as clicks and marks. The full feature combination generally achieves comparable results with at most small gains over positional features. Notably, certain intermediate feature combinations perform par-ticularly well on specific measures. The combination of positional and knowledge features yields the smallest deviations for snippet interactions on TREC and for clicks and marks on LISP (mean dif-ferences of 1.37 and 2.70, respectively), as well as for query counts on TREC (0.49). On TIPPS, the knowledge-temporal-combination model achieves the best result for number of marked documents with a mean per-session deviation of 3.66. However, these combina-tions perform mostly below average on other measures, highlight-ing trade-offs between feature types. 

Document-level overlap. At the document level, feature-conditioned models consistently outperform the baseline on TREC and LISP (see Table 2). Precision gains are modest, suggesting limited ability to select only the documents users actually chose. In contrast, re-call (i.e., click or mark preservation) and accuracy improve more substantially, indicating that feature conditioning helps recover more of the documents users interacted with, particularly among top-ranked results where attention is concentrated. For TIPPS, where the result lists are not ordered by relevance, several models show little to no improvement over the baseline. By removing the implicit relevance signal that is typically conveyed through document rank, the randomized presentation makes it difficult for models without access to document content to reli-ably predict whether a document will be clicked. Accordingly, the content-based model is the best-performing standalone model on this dataset, achieving the strongest overall results for click preci-sion, mark precision, and mark accuracy. Combining content-based and positional features yields further improvements, resulting in performance that nearly matches that of the full feature set model, which achieves the best overall results on this dataset. On TREC, recall increases from 0.31 to 0.38 and accuracy from 0.79 to 0.84, while on LISP clicks, recall improves from 0.33 to 0.44 and accuracy from 0.65 to 0.77. At this level, the baseline model exhibits a strong performance: for several measures on the LISP and TIPPS datasets, it ranks among the best configurations, contrasting with earlier evaluation levels. Also in contrast to the previous levels, positional features per-form relatively poorly here for TREC and LISP, but notably well for TIPPS. While positional conditioning helps predict which doc-uments users interact with in ordered search settings, it does not appear to capture the timing of these interactions with comparable fidelity. However, it provides the most reliable signal when relevant document placement within the result list is uncertain. For TREC, temporal features expectedly yield strong improve-ments regarding time-based measures, particularly for TTR and time to first click, which is consistent with their design. More no-tably, knowledge- and content-based features also perform very well on these metrics, often matching or exceeding the performance of the temporal model. As observed for TREC, models that showed comparatively weaker performance on aggregate and document-level metrics exhibit stronger perfor-mance on temporal aspects on LISP. On TIPPS, temporal features show uneven effects, with clear improvements over the baseline for some measures but very pro-nounced disadvantages for others. The full feature combination is not among the best models at this level, only leading for overall session time on LISP and frequently underperforming the baseline.

On TREC, improvements are less uniform: while the posi-tional and combined models provide clear benefits, other feature sets yield only minor gains relative to the baseline. Nevertheless, the relative ordering of models is consistent across TREC and LISP, with positional and combined configurations performing best and the remaining feature sets showing similar, intermediate performance. Again, the different setup of the TIPPS study is reflected in a dif-ferent ordering of models. At the same time, the results demonstrate that feature condition-ing is not universally beneficial and can, in some cases, even reduce modeling and simulation quality. Contextual features therefore only improve simulation quality when they are genuinely informative of user decisions, making careful feature selection and consideration of feature interactions essential. Addressing RQ2, different types of contextual features contribute unevenly across behavioral dimensions. Positional features emerge as a strong and robust signal, reliably enhancing document choice and outcome-oriented measures—both of which are particularly relevant indicators of simulation realism, as they directly affect or pose downstream evaluation outcomes—in rank-ordered search settings. This finding aligns with established evidence that rank strongly guides user attention and interactions [16, 22]. At the same time, the TIPPS dataset demonstrates that this effect depends critically on the relationship between rank and relevance. In conventional search settings, rank implicitly conveys information about document quality because results are ordered by estimated relevance. When this assumption is removed through randomized presentation, positional models can still reproduce coarse interac-tion trajectories, but struggle to identify the specific documents users engage with. This highlights the importance of incorporating document-based features: once rank no longer serves as a proxy for relevance, interactions become more strongly driven by the actual content relevance of documents to the user’s information need. Beyond the particularly strong impact of content features on TIPPS, content- and knowledge-based features contribute more strongly to temporal dynamics and trajectory-level similarity. This suggests that result quality provides an important cue beyond posi-tions and reinforces that no single feature type suffices to capture all aspects of user behavior. However, though clearly beneficial at these levels, content-based models underperform the baseline on most aggregate count metrics. Since content-related features pri-marily affect local click or mark decisions rather than higher-level behaviors such as session continuation or stopping, no major im-provements were expected here. Especially in the shuffled setting, where both relevant and non-relevant documents may appear at any rank, predicting how or whether a session will continue based solely on document properties becomes highly difficult without additional search context. Still, it should be noted that this effect is amplified by the constrained simulation setup: restricting sim-ulations to observed query sequences limits the extent to which local improvements can accumulate into session-level differences, potentially masking their impact through early termination. Combined models often perform best by leveraging the strengths of complementary feature types. However, indiscriminately includ-ing features can harm performance. Predictive fit increases with more features, since NLL, the evaluation criterion at this level, is also the model tuning criterion. Comparable to pointwise learning-to-rank, the models optimize transition probabilities at each step with regard to NLL. But this pattern does not extend to evaluation crite-ria not used for model tuning, as seen for temporal measures. Based on path-length, these are more comparable to listwise learning-to-rank. Improvements at one level therefore do not necessarily translate to improvements at the other, emphasizing the need for careful feature selection: While contextual features are generally beneficial, their impact depends on alignment with the behavioral dimension under consideration. Selecting complementary features can substantially enhance realism without greatly increasing model complexity, whereas poorly aligned or excessive features may yield diminishing or even negative returns. This highlights a practical guideline for designing feature-conditioned user simulators: more context is not inherently better, and attention to which features CIKM ’26, November 07–11, 2026, Rome, Italy Jana Isabelle Friese, Andreas Konstantin Kruff, Timo Breuer, Philipp Schaer, and Norbert Fuhr 

support which behavioral outcomes is critical, particularly for sim-ulations intended to inform system-oriented evaluation. In addition to feature selection, the effectiveness of contextual conditioning also depends on session characteristics. While more structured sessions are generally easier to simulate and benefit from the pattern recognition capabilities of feature-conditioned models, less consistent search settings can benefit even more from carefully chosen conditioning features—while also being more sensitive to unsuitable feature choices. Besides, longer sessions, such as those in the LISP dataset, show clearer benefits of feature-conditioned models, as longer sessions provide more opportunities for model behavior to diverge, while shorter sessions, like TREC, constrain interaction volumes and limit differentiation between models. This becomes especially apparent at the aggregate count level, where the effect is likely amplified by the simulation constraint described in Section 4.4. This suggests that the advantages of contextual conditioning become more pronounced as sessions grow longer and interaction dynamics unfold over time. The varying magnitude and consistency of improvements across metrics, as discussed for content-related features above, highlight the importance of a multi-level evaluation perspective. The benefits of contextual conditioning are not uniform across behavioral dimen-sions: while document choice, session effectiveness, and trajectory similarity clearly benefit from it, the picture is more heterogeneous for predictive fit, aggregate counts, and temporal aspects. Moreover, rankings of models vary across different measures. These patterns reinforce the value of assessing user simulation at multiple levels to obtain a comprehensive picture of model realism. Taken together, our findings show that contextual features affect search in various ways, and that contextual conditioning improves user simulation realism, but that its benefits depend on both the be-havioral dimension under consideration and the choice of features. 

## 8 Limitations 

While our study demonstrates the benefits of feature-conditioned state-based user models, some limitations must be acknowledged. First, we only evaluated our approach on three datasets, all of moderate size. Although the results are consistent across these datasets, generalizability to other domains, larger-scale logs, or different interaction scenarios remains to be tested. Second, due to the exploratory nature of this work and the con-sequently limited scope of statistical testing, our conclusions rely primarily on consistent trends observed across metrics and datasets rather than on statistically confirmed effects, and should be inter-preted accordingly. Third, many of the features considered in this study are highly abstracted. For example, the knowledge signal is a simple count of previously clicked or marked items, and content-related features reflect only limited aspects of result relevance. These simplifications may affect both the relative performance of models and the absolute realism achieved. Finally, our simulations rely on real session query sequences, which limits the length and variability of simulated sessions. While this choice ensures realistic grounding, it also restricts the expres-sion of long-term behavioral effects, particularly for feature types whose influence is primarily local. Exploring approaches that can generate plausible novel queries or extend session structures in a controlled manner could provide additional insight into simulation fidelity and allow testing more diverse interaction scenarios. 

## 9 Conclusion and Outlook 

We introduced a feature-conditioned extension of state-based user models that enables context-aware decision making while pre-serving their interpretability and structural simplicity. Beyond the scope of conventional search methodologies, this framework can be regarded as a comprehensive approach to modeling sequential, context-dependent interactions, thereby indicating its relevance to emerging domains such as conversational search. Rather than proposing a single “best” model, we used this frame-work to systematically study how different sources of contextual information affect the realism of simulated search behavior: Across multiple datasets and evaluation levels, incorporating contextual features frequently improves predictive fit and behavioral fidelity over a context-free baseline. Positional features provide the most consistent gains, while other feature types contribute more selec-tively across behavioral levels. Content-based features, in particular, show no benefits for aggregate session counts—partly due to the simulation setup—but substantially improve the accuracy of click and mark decisions and the modeling of temporal dynamics in ways not captured by positional information alone. Combining features, when done deliberately, further increases simulation realism: even a small number of carefully chosen features can yield notable im-provements in behavioral fidelity. However, the effectiveness of contextual features depends on the search setting and modeling objective. Our proposed framework enables the identification of appropriate feature configurations, thereby maximizing the bene-fits of feature conditioning while avoiding potential drawbacks by supporting informed, task-dependent feature selection. Methodologically, our study demonstrates the value of a multi-level evaluation framework, which captures both predictive ac-curacy and behavioral realism across aggregate, document-level, temporal, and trajectory-based dimensions. Overall, this work shows that even relatively simple, context-aware extensions of state-based models can enhance the realism of user simulations. This suggests a practical use case for constructing and applying realistic user models grounded in real world session logs. By learning model parameters from these session logs, the proposed models make behavioral assumptions explicit and provide an empirical foundation for evaluating the effects of various facets (e.g., alternative retrieval models, automated query (re)formulation). Compared to existing simulation approaches that rely on implicit or arbitrary behavioral assumptions, this enables more realistic and reproducible evaluations of interactive search systems.
