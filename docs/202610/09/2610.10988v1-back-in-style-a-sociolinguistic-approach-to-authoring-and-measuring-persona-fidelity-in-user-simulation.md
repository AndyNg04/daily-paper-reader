## 摘要
随着智能体系统日益受到商业领域青睐，用户模拟器也越来越多地被用作评估这些系统的测量工具。然而，与真实用户相比，模拟用户的忠实度通常较低，且其评估往往依赖成本高昂、带有主观性的 LLM 评判。本试点研究探讨，能否以确定性方式衡量忠实度：从社会语言学角度看待用户角色，将其视为一种由可观察的语言风格呈现的社会类型，而非依据模型必须推演为行为的标签或描述来预测的类型。我们将角色设定为具体的风格指标，由此得以将两种成熟的无模型工具——作者身份验证中的文体计量分析和基于词典的内容分析——用于诊断忠实度。我们在五种面向任务的客服智能体上进行 A/B 测试，将社会语言学方案与扁平化描述基线进行比较。结果显示，对于大多数受测模型，社会语言学方案都提升了风格遵循度和文体计量上的可区分性；但需注意，角色风格的忠实度并不必然等同于角色的“自然度”。我们认为，社会语言学方法为设计更多样、更具代表性的用户角色提供了可行路径；这些指标在错误归因分析中尤为有用，能够定位忠实度在哪些环节出现偏差。这是迈向相关干预措施的第一步，旨在使用户模拟更忠实地呈现多样且可变的语言输出。

## Abstract
As agentic systems gain commercial popularity, user simulators increasingly serve as measurement instrument for their evaluation. However, the fidelity of simulated users in comparison to real human users is generally low, and typically assessed by costly, subjective LLM judges. In this pilot study, we ask whether fidelity can instead be measured deterministically by treating a user persona sociolinguistically: as a social type that emerges from observable linguistic style, rather than one predicted by labels or descriptions a model must extrapolate into behaviour. We author personas as concrete stylistic rates, which lets us transfer two established, model-free instruments -- authorship-verification stylometry and lexicon-based content analysis -- as fidelity diagnostics. We A/B-test the sociolinguistic schema against a flat descriptive baseline across five task-oriented customer-service agents. Results show that the sociolinguistic schema improves both stylistic adherence and stylometric distinguishability for most of the tested models, with a caveat that persona style fidelity does not necessarily equal persona "naturalness". We argue that a sociolinguistic approach to persona design is a promising path towards more diverse and representative user personas, and that these metrics are most valuable in an error-attribution analysis, localizing where fidelity breaks down. This is a first step towards interventions that move user simulations closer to faithful renderings of diverse and variable linguistic outputs.

## 2. 方法论：核心思想与技术流程

### 2.1 人设设计：从“你是谁”转为“你应如何表达”
论文比较两种人设方案：

- **描述性原型方案（archetype）**
  - 使用性格标签、沟通风格、情境动机及示例语句。
  - 例如：犹豫、反复确认、需要安慰、经常道歉。
- **社会语言学定义方案（definition）**
  - 将情感立场、认知确定性及与对话方的关系落实为语言风格要求。
  - 使用 `NONE < LOW < MEDIUM < HIGH` 四级目标，规定各人设应相对多用或少用哪些语言特征。
  - 区分文本与语音通道，并增加 `MUST / MUST_NOT` 行为契约，约束模型不要回归默认的“友善助手”表达方式。

主要评估八类特征：
- 提问频率；
- 消息长度；
- 缓和或不确定表达；
- 礼貌标记；
- 填充词；
- 全大写；
- 网络缩写，如 `lol`、`omg`；
- 情感效价。

**这些主要是序数等级要求，而非经过真人数据校准的精确频率区间。** 人设模板还包含表情、语速、音高等设定，但并非全部进入核心评估指标。

### 2.2 指标一：文体可区分性
借用作者身份验证方法，判断同一人设的对话是否更相似，不同人设的对话是否更不同。

算法流程：
1. 拼接每段对话中的模拟用户发言。
2. 使用字符级 TF-IDF 表示，采用 `char_wb` 和长度为 2～4 的字符 n-gram。
3. 计算各对话对的余弦相似度。
4. 将对话对标为“同一人设”或“不同人设”。
5. 用相似度预测该标签，计算 **ROC-AUC**。

解释：
- AUC 为 0.5：无法区分。
- AUC 为 1：完全区分。
- 同时报告人设内部相似度、人设之间相似度及两者差值，辅助判断低分来自内部不稳定还是人设间重叠。

作者还采用标签置换、bootstrap 90% 置信区间、配对 bootstrap 差值估计及统一字符预算等检查。

### 2.3 指标二：风格遵循度
判断“被要求更多使用某特征的人设，是否真的更多使用该特征”。

- 将目标等级编码为序数。
- 从实际对话提取特征：
  - 规则计数：提问、消息长度、全大写；
  - 人工小词典：礼貌、缓和语、填充词、网络缩写；
  - VADER：情感效价。
- 计算目标等级与实际特征量之间的 **Kendall’s τb**，并辅报 Spearman’s ρ。
  - 接近 1：相对排序符合设定；
  - 接近 0：没有明显对应关系；
  - 小于 0：与设定方向相反。

评估分为：
- **人设级**：先聚合同一人设的多段对话；
- **对话级**：保留单次对话的波动；
- 对目标等级存在变化的特征取平均，形成综合遵循度。

### 2.4 两项指标的互补性
- 可区分性回答：**人设是否不同且内部一致？**
- 遵循度回答：**不同之处是否符合设计要求？**

二者结合用于诊断，但均不能独立判断表达自然性、语义适切性或真实用户行为一致性。

## 6. 主要结论与发现

### 6.1 多数配置受益，但效果存在明显模型差异

以下为五个智能体上的均值：

| 模型/通道 | 可区分性 AUC：原型 → 定义 | 人设级遵循度 τb：原型 → 定义 |
|---|---:|---:|
| GPT-5-mini | 0.449 → 0.636 | 0.153 → 0.573 |
| Claude Opus-5 | 0.565 → 0.670 | 0.236 → 0.634 |
| Claude Haiku-4-5 | 0.509 → 0.651 | 0.315 → 0.604 |
| GPT-4o-mini | 0.483 → 0.593 | 0.194 → 0.428 |
| 实时语音 | 0.477 → 0.608 | 0.255 → 0.489 |

- 六种配置获得较明确改善，包括 OpenAI 文本模型、三个 Claude 配置和实时语音配置。
- Gemini 三种配置和 Gemma 整体提升有限，部分指标仍低于随机可区分水平。
- 模型能力等级与模拟器可操控性并不单调对应：较小模型有时获得更大的方案增益。
- 作者据此提出模型家族或偏好对齐可能更重要，但实验不能直接确证这一因果机制。

### 6.2 增益主要来自细粒度语言标记
- GPT-5-mini 的网络缩写遵循度提升 **0.838**。
- 多个模型的全大写特征由反向遵循变为正向遵循。
- 语音中，缓和语和填充词分别提升约 **0.47、0.42**。
- 提问和情感效价总体较难控制；礼貌等默认助手已经常用的特征，提升通常较小。

### 6.3 行为契约有重要贡献
在消融所用的配对有效子集上，GPT-5-mini：
- 去除行为契约后，AUC 从 **0.652 降至 0.518**；
- 人设级 τb 从 **0.619 降至 0.489**；
- 但仍高于描述性基线。

这说明风格设定本身有作用，显式行为约束还能进一步提高效果。消融表来自不同有效子集，数值不宜与主表直接混用。

### 6.4 忠实度不等于自然度
高分输出可能重复固定礼貌语，或机械地在句首加入“um”。因此，**排序符合目标，不代表表达自然、情境恰当或像真人**。

此外，忙碌者和技术专家等主要通过“少用标记”定义的人设较难区分；社交健谈者与模糊叙事者也容易收敛。

## 7. 优点与亮点

- **设计与测量对齐**：将抽象人设变成可检查的语言规格。
- **低裁判依赖、可复现**：规则、词典与文体指标比 LLM 打分更透明、稳定。
- **指标互补**：避免把“风格不同”直接当作“忠实于设定”。
- **诊断粒度细**：能够定位模型、人设和具体语言特征的失效位置。
- **具有设计反馈价值**：低可区分性可以反向提示哪些人设设定过于接近。
- **实验覆盖较有层次**：跨模型家族、跨服务场景，并加入语音与消融。
- **结论较克制**：明确承认风格忠实度、自然性和真实性不是同一概念。

## 8. 不足与局限

### 8.1 缺乏真实用户效度验证
- 没有真实用户对照，也没有证明该方法改善了智能体评测与真实部署表现之间的一致性。
- 人设等级由专家手工设定，未验证其代表真实群体的频率分布。
- 尚未评估决策、目标、退出行为等非风格层面的忠实度。

### 8.2 指标覆盖有限且可被机械满足
- 八类特征无法覆盖语用策略、句法复杂度、动态情绪和完整互动风格。
- τb 衡量相对排序，不衡量是否达到绝对目标频率。
- 词典计数容易遗漏变体、依赖语境的表达与反讽，也可能奖励机械堆叠标记。
- 英语词典和 VADER 的跨语言、跨方言适用性未被验证。

### 8.3 主题与长度可能影响可区分性
- 复用场景减少了主题不平衡，但不足以证明字符 n-gram 完全排除内容影响。
- 跨场景同人设对话仍可能比同场景不同人设对话更不相似；低于 0.5 的 AUC 不宜简单解释为“人设坍缩”。
- 对话长度与定义方案 AUC 的相关系数达 **0.79**，与方案增益的相关系数达 **0.73**。
- 统一字符截断保留总体优势，但不能完全消除长度和信息密度影响。

### 8.4 因果归因与报告仍不完整
- 方案包含多个同时变化的组件，单模型消融不足以分离各组件贡献。
- 4,103 段对话与简述采样设计之间的对应关系不清楚。
- 附录称 Opus-5 获得最大遵循度增益，但主表中 GPT-5-mini 的增益更大，存在表述不一致。
- 关键资源成本、失败率、完整统计细节及复现材料信息不足。

### 8.5 应用边界
- 仅在单一平台的客服任务中验证，不能直接推广到开放式社会模拟、教育或心理咨询。
- 语音核心指标主要分析转录文本，未直接验证音高、语速、重音等声学设定。
- 人设只在开始时注入，未系统分析逐轮漂移或动态强化策略。
- 不依赖人口标签不等于消除刻板印象：手工设定的“焦虑者”“技术恐惧者”等风格组合，仍可能固化对群体的想象。

**总体评价：**本文最有价值的贡献，是把人设忠实度转化为可复现、可定位的风格诊断问题。其证据支持将该方法用于模拟器选型和人设迭代，但尚不足以将指标作为用户模拟真实性的最终判据。
