## 摘要
大型语言模型能够给出听起来合理的经济政策应对，但这并不能说明其行动符合经济动态。我们通过将一个经过指令微调的语言模型置于六个由 Snowdrop 驱动的动态随机一般均衡（DSGE）模拟器中，对此进行检验。在每个回合中，模型观察经济状况及经济论述的变化，选择一项有界政策行动，并接收下一模拟状态和经济奖励。我们实现了一个通用 Python 接口，用于重复展开模拟、持续冲击、状态克隆和滚动时域模拟。

这一设定带来了长时域信用分配问题。政策效果可能在采取行动数个季度后才显现。PPO 具有学习得到的价值函数，可通过广义优势估计将延迟奖励传递给较早生成的词元。GRPO 不包含学习得到的价值函数，而是根据完整展开模拟的回报分配组内相对优势。因此，它无法区分是哪个较早回合导致了结果；如果所有展开模拟获得相同回报，归一化后的优势便为零。我们采用 PPO 作为主要方法，并将 GRPO 作为匹配的无评论家基线。实验还检验了方向性语义信号、奖励时域、轨迹热启动、跨模拟器迁移，以及以历史为锚点的疫情和货币政策冲击。研究旨在依据政策行动的模拟经济后果评估其效果，而非仅凭语言表述是否合理作出判断。

## Abstract
Large language models can produce economic policy responses that sound reasonable, but this does not show that their actions are consistent with economic dynamics. We test this by placing an instruction-tuned language model inside six Snowdrop-backed dynamic stochastic general equilibrium (DSGE) simulators. At each turn, the model observes the economy and a change in economic discourse, selects a bounded policy action, and receives the next simulated state and an economic reward. We implement a common Python interface for repeated rollouts, persistent shocks, state cloning, and rolling-horizon simulation.   This setting creates a long-horizon credit-assignment problem. Policy effects may appear several quarters after an action is taken. PPO has a learned value function that can propagate delayed reward to earlier tokens through generalized advantage estimation. GRPO has no learned value function and instead assigns a group-relative advantage from complete rollout returns. It therefore cannot distinguish which earlier turn caused the outcome; if every rollout receives the same return, the normalized advantage is zero. We use PPO as the primary method and GRPO as a matched critic-free baseline. The experiments also test directional semantic signals, reward horizon, trajectory warm starts, cross-simulator transfer, and historically anchored pandemic and monetary-policy shocks. The objective is to judge policy actions by their simulated economic consequences rather than by plausible language alone.

## 1. 核心问题与整体含义

- **研究动机**：大语言模型可以写出流畅、看似合理的经济政策建议，但语言上的可信度不等于政策实施后能够稳定经济。尤其当政策效果滞后数个季度时，很难从最终结果判断早期哪项行动起了作用。
- **核心问题**：能否让语言模型在动态随机一般均衡（DSGE）模拟器中连续决策，并依据模拟出的经济后果，而不是回答的措辞，评价和改进政策？
- **整体定位**：论文提出的是一个将语言模型接入结构化经济模型的控制与评估框架，**不是新的 DSGE 模型，也不声称模拟器是现实经济的裁判**。其结论始终取决于模型方程、校准参数和允许使用的政策工具。

## 2. 方法论与关键技术

- **闭环政策控制**：每一回合，模型接收当前经济观测及经济话语的变化，输出包含政策工具和有界幅度的 JSON 行动。环境校验行动，将其与外生冲击一同送入 Snowdrop 模拟器，推进一个时期，再返回新状态、经济损失和奖励。已实现的统一接口覆盖六类 DSGE 模型，并支持状态克隆、持续冲击、滚动预测和不可回写的历史状态。
- **经济目标与奖励**：经济损失主要是预测时域内通胀、产出等变量偏离目标的加权平方和；奖励由损失的归一化改善构成，并扣除行动幅度、无效行动等惩罚。作者强调要同时报告**塑形奖励和原始经济损失**，并用相同初始状态下的“不干预”轨迹作反事实比较，以免奖励设计掩盖实际表现。
- **延迟奖励的信用分配**：论文以 **PPO** 为主要训练方法，利用价值函数和广义优势估计，把行动结束时获得的反馈传递到先前生成的词元；以 **GRPO** 为无价值函数的对照，对同一初始状态克隆出的多条完整轨迹按总回报计算组内相对优势。后者若组内回报相同，就没有该组的任务梯度；其轨迹级信号也难以区分不同回合的贡献。**这是待检验的机制判断，而非本文已证实的性能排序。**
- **语义与探索**：语义模块比较连续两个经济文本窗口的表示，以“表示之差”的方向作为有噪声的冲击线索，不将文本变化视为已识别的因果冲击。另拟用带随机扰动的规则控制器生成少量有效轨迹，测试轨迹热启动能否缓解模型因即时行动成本而倾向于“不作为”的探索困难。

- **模拟场景**：六个 Snowdrop 支持的模型包括季度预测模型（QPM）、Smets–Wouters（SW）、Galí–Smets–Wouters（GSW）、Ireland 新凯恩斯模型、美国多变量滤波模型和实际经济周期模型。受控冲击涵盖衰退、滞胀、成本推动、生产率、封锁、劳动力供给及潜在产出变化。

- **比较基线**：不干预、随机合法行动、未经任务训练的指令模型、模型专属线性稳定规则、GRPO 和 PPO；另计划比较仅用经济状态、静态文本、方向性语义及“已知冲击标签”条件下的 PPO。

## 7. 优点

- 将政策文本生成改写为**有约束、可反馈的多回合决策**，评价依据更明确。
- 采用状态克隆、不可回写的状态转换和匹配的“不干预”轨迹，便于控制初始条件并核查反事实。
- 明确区分**信用分配、探索不足、奖励设计和语义信息**四类问题，避免把所有效果归因于优化算法。
- 预设行动合法性、经济损失、失败率和模型间最坏表现等指标，对经济应用中的安全性与模型不确定性较为谨慎。

## 8. 不足与局限

- **证据缺口是首要限制**：关键训练对比和多数消融尚无数值结果，无法检验论文的主要假设。
