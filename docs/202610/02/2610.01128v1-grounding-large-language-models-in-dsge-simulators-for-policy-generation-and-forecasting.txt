# ABSTRACT 

Large language models can produce economic policy responses that sound rea-sonable, but this does not show that their actions are consistent with economic dynamics. We test this by placing an instruction-tuned language model inside six Snowdrop-backed dynamic stochastic general equilibrium (DSGE) simulators. At each turn, the model observes the economy and a change in economic discourse, selects a bounded policy action, and receives the next simulated state and an eco-nomic reward. We implement a common Python interface for repeated rollouts, persistent shocks, state cloning, and rolling-horizon simulation. This setting creates a long-horizon credit-assignment problem. Policy effects may appear several quarters after an action is taken. PPO has a learned value function that can propagate delayed reward to earlier tokens through generalized advantage estimation. GRPO has no learned value function and instead assigns a group-relative advantage from complete rollout returns. It therefore cannot distinguish which earlier turn caused the outcome; if every rollout receives the same return, the normalized advantage is zero. We use PPO as the primary method and GRPO as a matched critic-free baseline. The experiments also test directional semantic signals, reward horizon, trajectory warm starts, cross-simulator transfer, and historically anchored pandemic and monetary-policy shocks. The objective is to judge policy actions by their simulated economic consequences rather than by plausible language alone. 

# 1 INTRODUCTION 

An economic policy response can be fluent and well argued while still implying an unstable or internally inconsistent trajectory. Language models are normally judged on the response itself; the economic consequences remain outside the learning loop. We instead use a DSGE simulator as the environment that applies an action, advances the economy, and returns numerical feedback. At each turn, the model observes the current state, the policy instruments available in that simulator, and a change in economic discourse. It returns a bounded JSON action. The environment combines this action with the scenario shocks, simulates the next period, and returns the new state and loss. Policy generation therefore becomes repeated control rather than a one-shot prompt. This creates two different problems. First, policy transmission is delayed, so an early action must receive credit for an outcome that appears several turns later. PPO can use its critic to assign different values within the trajectory. Vanilla GRPO instead compares complete rollout returns and has no learned value function for within-trajectory credit. Second, both algorithms are local optimizers: they cannot learn a useful trajectory that the starting policy never generates. With an immediate action penalty, this can produce an inaction ravine in which doing little is safer than exploring an intervention whose benefit arrives later. We lack a large expert trajectory bank for task-specific SFT. We therefore start from an instruction-tuned model, separate credit assignment from exploration, and test a small rule-based trajectory warm start. The semantic component is also directional: it uses the change between consecutive discourse windows as a noisy shock signal, not as a causally identified shock. # 2 RELATED WORK 

Simulator grounding. GLAM trains language agents using feedback from an interactive envi-ronment, and bilevel systems let an LLM propose hypotheses whose numerical consequences are checked by a simulator (Carta et al., 2026; Ma et al., 2024). We use the same idea for structural macroeconomics. Snowdrop is the Python numerical backend, and the registered models draw on established DSGE implementations (Goumilevski & Otterson, 2025; Smets & Wouters, 2007; Ireland, 2004). These simulators make assumptions and counterfactuals explicit; they are not an oracle for the real economy. 

Multi-turn RL and exploration. PPO, RLOO, GRPO, and related methods are commonly used where reward follows one response. In multi-turn control, the outcome may arrive after several decisions, breaking this direct action–reward link. PPO combines a critic, GAE, and clipped updates, whereas GRPO replaces the critic with relative returns from grouped rollouts (Schulman et al., 2018; 2017; Shao et al., 2024). Multi-turn studies therefore motivate finer credit assignment (Wang & Ammanabrolu, 2025; Wei et al., 2026). This is separate from exploration. GEP-PG first finds diverse trajectories and then applies policy gradients; hindsight replay, return redistribution, curiosity, and SAC-GLAM provide related replay or exploration mechanisms (Colas et al., 2018; Andrychowicz et al., 2018; Arjona-Medina et al., 2019; Pathak et al., 2017; Gaven et al., 2026). 

Training stages and semantic signals. Standard RLHF combines SFT, reward modeling, and policy optimization (Ouyang et al., 2022). Here the DSGE loss replaces a learned preference reward. SFT can expand the set of correct reasoning paths, while RL concentrates probability on paths the model already produces (Matsutani et al., 2026). This motivates the trajectory warm-start ablation. Generic embeddings can miss small changes in financial narratives, and discourse may itself respond 2Preprint

Snowdrop supplies the numerical solvers and structural model implementation (Goumilevski & Otterson, 2025); the RL interface is our implementation. Our wrapper turns these solvers into a stateful environment for repeated, matched language-agent rollouts. The wrapper adds four capabilities needed here: (i) shock abstraction, which accepts scalar, full-path, or sparse time–value schedules; (ii) named parameter updates for controlled regime experiments; (iii) deep state cloning, which copies the calibration, committed state, active shocks, and loss state; and (iv) an RL step that validates an action, advances the simulator, and returns the next observation, loss, reward, termination flag, and validity flag. Rolling forecasts and irreversible one-period commits preserve the DSGE temporal structure while allowing many counterfactual trajectories to begin from the same economy. For GRPO, the environment is cloned G times and one complete trajectory is sampled from each clone before group-relative advantages are computed. PPO retains the trajectory and generation-time token probabilities while a separate critic supplies token values. Both algorithms therefore receive the same initial state and exogenous shock path. 3.2 VALIDATED ACTIONS AND IRREVERSIBLE TRANSITIONS 

An action is a JSON object with a lever, signed magnitude, and optional short rationale. Model-specific bounds are enforced before simulation. Invalid JSON, unknown levers, and out-of-range magnitudes incur a penalty rather than being silently repaired. A policy shock persists for a fixed duration with geometric decay. The environment computes a rolling forecast, commits only the first transition, and appends it to immutable realized history. Consequently, a later turn cannot rewrite earlier outcomes. Evidence motivating the comparison. Two observations determine our primary comparison. First, PPO’s critic can estimate which parts of a long decision sequence require updating. The multi-turn formulation of Wang & Ammanabrolu (2025) makes the mechanism explicit: value bootstrapping gives tokens preceding a command-ending reward non-zero advantages. On their Qwen-1.5B TextWorld experiments, PPO reaches 59% success versus GRPO’s 2% on w4-o6-q8, and 88% versus 18% on w2-o3-q4. At 7B, PPO still leads GRPO by 72% to 36% on the harder task, while the gap narrows to 98% versus 79% on the simpler task. These are results from the cited TextWorld study, not from our DSGE environment. Second, GRPO’s main learning signal depends on the return distribution within a group of stochastic rollouts. Equal returns give zero advantage, while incidental variation can make the relative ranking noisy; group-relative estimation can also weight easy and hard prompts unevenly (Yang et al., 2026). We therefore hypothesize that vanilla GRPO becomes less reliable as DSGE transmission lags increase. This is not a universal claim against GRPO. It remains attractive when a terminal verifier sharply separates rollouts, as in the cited SWE-Gym setting, and turn-level variants can restore finer credit (Wang & Ammanabrolu, 2025; Wei et al., 2026). Credit assignment is not exploration. A critic can propagate reward along an observed trajectory, but it cannot assign credit to a useful trajectory that the policy never generates. This is especially relevant when training starts from an instruction model without a large domain-specific SFT corpus. We therefore interpret PPO–GRPO as a credit-assignment comparison and separately test exploration initialization. A rule-based controller with randomized perturbations builds a small library of valid, non-trivial trajectories; warm-starting from this library follows the explore-then-optimize logic of GEP-PG (Colas et al., 2018). Replay-based hindsight learning and return redistribution are reserved as extensions because they alter the on-policy objective rather than merely its initialization. 

# 6 DATASETS AND SCENARIO CONSTRUCTION 

Controlled scenarios from the six registered DSGE models provide training and mechanistic tests under fixed initial states and shock paths. They cover recession, stagflation, cost-push, productivity, lockdown, labor-supply, and potential-output disturbances. External data are reserved for evaluation. The McKibbin–Fernando release provides six COVID-19 scenarios, their source shocks, and G-Cubed outcomes (Mckibbin & Fernando, 2020; McKibbin & Fernando, 2023). Because G-Cubed is not our GSW model, a documented adapter maps its productivity, demand, risk, fiscal, morbidity, and mortality quantities to quarterly GSW shock paths; Scenario 6 is marked as approximate. The planned comparison reports output/inflation RMSE and correlation separately from policy-loss improvement against a cloned no-action GSW trajectory. The ECB evaluation uses meeting-level and monthly Jaroci´ nski–Karadi shocks derived from EA-MPD event windows (Altavilla et al., 2019; Jaroci´ nski & Karadi, 2020). Only the identified monetary component enters the policy-shock channel; the central-bank-information component remains an observation. The planned metrics are action direction, response timing, and stabilization loss, not agreement with the historical ECB decision. Controlled scenarios are split by shock family and simulator, semantic data are split chronologically, and both external sources remain locked until model and reward selection are complete. 

# 7 EXPERIMENTAL PROTOCOL 

7.1 RESEARCH QUESTIONS AND HYPOTHESES 

We evaluate six questions. RQ1: Does grounded RL reduce economic loss relative to the base LLM, random valid actions, no action, and a simple rule-based controller? RQ2: Does PPO outperform trajectory-level GRPO as horizon and scenario difficulty increase? RQ3: Does a temporal semantic signal improve shock recognition and policy choice over static text or state-only control? RQ4: 

Which reward geometry best represents delayed stabilization rather than immediate target chasing? 

RQ5: Does a small library of exploratory rule-based trajectories improve learning from the instruction model? RQ6: Do policies learned in one simulator retain value under held-out models and real-event shock paths? The hypotheses are: (H1) grounded policies outperform linguistic and ungrounded baselines; (H2) PPO’s margin over vanilla GRPO grows with delayed feedback and its critic propagates terminal reward to earlier tokens; (H3) directional semantic conditioning improves shock classification and downstream economic loss; (H4) rolling-horizon and tolerance-band rewards produce more informative policy rankings than one-step exact-target loss; (H5) exploration warm-starting improves both action diversity and final economic loss; and (H6) multi-model training improves held-out-simulator robustness but cannot remove model misspecification. 6Preprint 7.2 TRAINING AND BASELINES 

The policy is Qwen2.5-1.5B-Instruct (Qwen et al., 2025), quantized to four bits and adapted with LoRA (Hu et al., 2021). PPO uses a separate token-value model, γ = 0 .99 , λ = 0 .95 , policy clip 0.2, and four PPO epochs. GRPO samples four trajectories per prompt, each from a clone of the same economic state, normalizes total returns within the group, applies a 0.2 ratio clip, and uses a reference-policy KL penalty. Each episode has four decision turns and an eight-period forecast horizon. Confirmatory runs will retain seeds, scenario order, states, actions, per-turn rewards, economic losses, parse failures, and checkpoints. Baselines are: (i) no intervention; (ii) uniformly sampled valid action; (iii) the untuned instruction model; (iv) a model-specific linear stabilization rule; (v) GRPO; and (vi) PPO. We additionally report state-only PPO, static-text PPO, temporal-semantic PPO, and an oracle-shock PPO upper bound. RLOO and MT-GRPO are extensions, separated from the core table unless their implementations pass the same rollout-accounting tests. We update LoRA parameters throughout the compact language model rather than training only an action-classification head. This choice makes the transfer test meaningful: success requires the language policy to reuse its learned mapping from economic observations and discourse to actions under a different set of structural equations. It does not imply that the model recovers those equations or identifies causal shocks from text. The pipeline therefore differs from full preference-based RLHF: general instruction tuning supplies the initialization, the DSGE loss replaces a learned reward model, and LoRA PPO or GRPO performs the task update. For the proposed warm-start condition, a dataset-to-trajectory translator will record each source shock, converted path, state, legal action, next state, and horizon outcome. Randomized rule-based policies will populate a small trajectory library; direct-RL runs will omit it. This tests whether better initial trajectory coverage is required in addition to simulator feedback. 7.3 ABLATIONS , METRICS , AND CONTROLS 

The predeclared ablations isolate credit assignment (PPO versus GRPO), horizon (one step versus 4/8/12 quarters), reward geometry (quadratic versus tolerance-band or asymmetric), exploration (direct RL versus rule-based warm-start), semantics (none, static, directional, or oracle), actor/critic conditioning, and single- versus multi-model training. This separation prevents an aggregate score from attributing an exploration or reward-design effect to the optimizer. Primary outcomes are discounted return and target-weighted economic loss. Secondary outcomes are policy energy, worst-case loss, action validity, return variance, zero-advantage group frequency, shock-label macro-F1, and calibration of predicted semantic volatility. Each comparison uses identical shock paths and initial states. The confirmatory tables will report means, standard errors, and paired bootstrap confidence intervals across seeds and scenarios. Model selection will use validation scenarios only; external events will be evaluated once after selection.

8.4 REWARD -HORIZON CALIBRATION DIAGNOSTIC 

We isolate reward design from language-model learning by replacing the policy with manually selected actions. Table 6 reports the measured base and action losses under the original short-horizon objective. Negative ∆ means that the action increased that particular objective; it does not by itself establish that the intervention is economically invalid over a longer horizon. The sensitivity of the sign to action magnitude and target weights is the reason horizon and reward geometry are varied in the confirmatory protocol. We call this a reward-horizon inversion : an intervention with a plausible long-run stabilizing interpre-tation can receive a worse short-horizon score. Under stagflation, even the sign of the comparison depends on the relative inflation and output weights. This is a property of the evaluated objective, not evidence for or against a particular RL optimizer. It motivates rolling forecast loss, matched no-action counterfactuals, persistent actions, and the predeclared horizon and reward-geometry ablations. 

# 9 EXTENSIONS AND RESEARCH DIRECTIONS 

The main experiments keep PPO, GRPO, the action schema, and environment interactions comparable. The next extensions address the two remaining problems: discovering useful trajectories and locating delayed economic credit. 

Exploration before optimization. The rule-based warm start is a small goal-exploration stage. Randomized Taylor-style controllers search for trajectories that improve on matched no-action paths; policy-gradient training then concentrates probability on the useful region (Colas et al., 2018). The same archive could support a compact task-specific SFT stage. Curiosity may widen coverage (Pathak et al., 2017), but novelty must be restricted to economically relevant state changes. 

Replay and off-policy learning. A DSGE transition can be reproduced from the simulator version, calibration, initial state, action, and shock path. This makes rare successful trajectories reusable. An off-policy extension based on SAC-GLAM would use an action-conditioned critic Q(o, a ), entropy regularization, and hindsight goals such as target bands reached by the trajectory (Gaven et al., 2026; Andrychowicz et al., 2018). Replay records must retain model, calibration, and reward hashes so that stale returns are not reused under a different environment. 

Delayed reward and structural intent. RUDDER-style decomposition could move long-horizon return toward the decisions that produced it (Arjona-Medina et al., 2019). It must be compared 9Preprint with simpler rolling rewards, tolerance bands, and asymmetric penalties using held-out economic loss. A later interface could also let the model state a policy intent, regime, direction, intensity, and duration. A deterministic compiler would map that intent to legal simulator shocks, while trace-state observations expose recent actions, active shock schedules, forecasts, and violations (Ma et al., 2024). The simulator would retain numerical authority. 

# 10 LIMITATIONS , S AFETY , AND REPRODUCIBILITY 

A DSGE-grounded answer is conditional on equations, calibration, measurement, and the admissible action space. It is not a policy recommendation for a real government or central bank. Model uncertainty is therefore a first-class output: we report results per simulator and worst-case performance rather than collapsing disagreement into a single authoritative score. External shock mappings are approximate and will be released with units, signs, and scaling choices. Text corpora can reflect media attention and institutional bias; chronological evaluation limits leakage but not representation error. For full-scale training, the simulator layer must pass replay invariance, lag-state continuity, no-action counterfactual equality, shock-sign, and unit tests. The semantic policy must also pass a behavior-policy log-probability replay test before PPO updates are interpreted. These checks matter because a syntactically successful simulation can still implement the wrong transition. On the available RTX 2080 Ti (11GB), the 1.5B actor fits with four-bit LoRA; PPO’s separate critic is the tighter memory constraint, so rollouts and updates are serialized and semantic embeddings are precomputed. We use FP16 on this hardware and reserve larger-model scaling for separate compute. Code and experimental configurations are available at https://github.com/vasudeywos/ Grounding_LLM_in_DSGE_Simulators_for_Policy_Generation_and_ Forecasting.git .Without task-specific SFT, on-policy RL can refine only behaviors explored by the instruction model; the warm-start ablation measures, but does not eliminate, this limitation. 

# 11 CONCLUSION 

We treat policy generation as repeated interaction with an explicit economic model. The contribution is a common control interface, not a new DSGE model: Snowdrop remains the numerical backend. The language model chooses a bounded action, the simulator determines its conditional consequences, and the next decision starts from the committed economic state. A temporal encoder adds the direction of discourse change as a noisy shock observation. The experiment design separates the main claims. PPO versus GRPO tests multi-turn credit assign-ment; reward and horizon ablations test the economic objective; trajectory warm starts test exploration; and semantic and cross-simulator ablations test whether the policy uses directional language and transfers across structural assumptions. Pandemic and ECB shock paths provide historically anchored evaluation. The final criterion is not whether a policy sounds convincing, but whether it improves clearly reported economic outcomes under explicit model assumptions.
