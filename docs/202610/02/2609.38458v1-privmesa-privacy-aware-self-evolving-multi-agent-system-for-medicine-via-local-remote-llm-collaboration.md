## 摘要
部署于本地的临床大语言模型（LLM）智能体可以向能力更强的远程模型求助，但这可能导致患者信息泄露。注重隐私的委派机制由本地智能体决定披露哪些信息；然而，仅删除明确标识符并不足够：准标识符可能在多轮会诊和患者重复就诊过程中累积，从而导致患者被重新识别。我们提出 PrivMeSA，这是一种隐私感知的自进化多智能体系统，能够学习控制信息披露，并将远程模型的专业知识保留供本地复用。本地智能体负责管理每次就诊，并向可能要求补充信息的远程专科智能体咨询。强化学习在任务准确性、直接信息披露风险与基于患者登记库的重新识别风险之间进行权衡，并基于每次就诊完整的对外发送记录评估隐私。系统通过本地经验记忆，将已完成的会诊提炼为通用临床指导，并在发送信息前检索相关经验，使后续病例能够复用专业知识，而无需再次与远程模型交互。记忆库的扩展不需要额外的结果标签或参数更新。在基于 MIMIC-IV-ED 记录构建的急诊科基准测试中，与委派方案相比，PrivMeSA 的平均任务准确率最高提升 15.8 个百分点。在相同设置下，PrivMeSA 将包含个人详细信息披露的病例比例从 98.0% 降至 0.2%，并将患者可被缩小至登记库中 10 名或更少患者范围内的病例比例从 74% 降至 0%。

## Abstract
Clinical large language model (LLM) agents deployed locally can consult more capable remote models, but doing so risks exposing patient information. Privacy-conscious delegation places disclosure decisions with a local agent, yet removing explicit identifiers is insufficient: quasi-identifiers can accumulate across multi-turn consultations and repeated patient visits to enable re-identification. We introduce PrivMeSA, a privacy-aware self-evolving multi-agent system that learns to control disclosure and retains remote expertise for local reuse. A local agent manages each encounter and consults remote specialists that may request additional information. Reinforcement learning balances task accuracy against direct disclosure and registry-based re-identification risk, with privacy evaluated over the complete outbound transcript of each encounter. A local lesson memory distills completed consultations into generalized clinical guidance and retrieves relevant lessons before transmission, allowing subsequent cases to reuse expertise without another remote exchange. Memory grows without additional outcome labels or parameter updates. On an emergency-department benchmark built from MIMIC-IV-ED records, PrivMeSA improves mean task accuracy over delegation by up to 15.8 percentage points. In the same setting, PrivMeSA reduces the disclosure of personal details from 98.0% to 0.2% of cases and the share of cases in which the patient can be narrowed to ten or fewer registry patients from 74% to 0%.

# PrivMeSA 论文总结

## 1. 核心问题与研究意义

- **问题**：医院内运行的本地临床模型能力有限，向更强的远程模型咨询又可能泄露患者信息。即使删去姓名、地址，年龄、生命体征、主诉等“准标识符”仍可能在**多轮会诊和重复就诊**中累积，使患者在登记库中被缩小到很小的候选范围。
- **研究目标**：让本地智能体同时决定“需要咨询什么、向谁咨询、披露多少”，并把已获得的远程专家知识留在本地，减少后续病例重复对外咨询。论文的关键主张是：隐私保护不应只检查单条消息，还应检查整次对外交流及跨就诊的信息累积。

## 2. 方法：披露控制与本地经验复用

- **多智能体会诊**：本地智能体管理急诊病例，可向远程的检查结果解读、诊断编码和处置决策专家求助。专家看不到完整病历，可追问一项信息；本地智能体决定提供还是拒绝。
- **记忆门控**：每次拟发起咨询时，草稿先在院内检索既往“临床经验”。系统按向量相似度筛选候选经验，再由固定的 LLM 判断是否适用。本地智能体可以采纳经验、独立继续，或将草稿修改为更少披露信息的版本后发给远程专家。经验只从**已结束病例**的会诊中提炼，不使用新增结局标签，也不在部署时更新模型参数。
- **隐私感知强化学习**：采用 GRPO 训练本地策略，以整次病例轨迹计算奖励，包括三部分：
  - 三项临床任务的平均准确率；
  - 合成个人信息未被披露的比例；
  - 对外消息中的准标识符在患者登记库中仍能匹配多少人，以归一化的对数匿名性衡量，同时考虑全部专家合并后的视图和单个专家的视图。
  
  训练设定中，直接披露与匿名性奖励权重分别为 **0.5** 和 **0.4**。隐私按一次就诊的**完整对外消息记录**计分，包含对专家追问的回复；跨就诊链接风险则在评估时另行测量。
- **威胁模型**：院内模型被视为可信；远程专家“诚实但好奇”，可能保留并汇总收到的信息。重识别风险是在攻击者能够用披露属性匹配参考登记库的条件下衡量的，并非现实攻击成功率的直接估计。

## 3. 实验设计与对比

- **数据与基准**：基于 MIMIC-IV-ED 构建急诊就诊回放环境，智能体可查看生命体征、既往就诊、用药，订检查并等待记录中的结果。训练集为 **1,700 名患者、7,635 次就诊**；留出集为 **200 名患者、897 次就诊**。主结果使用其中 **100 名患者**；测试时记忆增长实验使用全部 897 次就诊。用于匹配准标识符的参考登记库包含 **205,504 名患者**。
- **任务与指标**：预测主要急诊诊断（按 CCS 类别评分）、最终处置，以及入院后是否有编码的操作；报告三项准确率均值。隐私指标包括合成个人信息披露率，以及单次就诊和关联同一患者多次就诊后，登记库候选人数 \(k\) 与 **\(k\leq10\)** 的比例。
- **对比方法**：包括未经训练的本地—远程委派、逐条消息改写的 PAPILLON、本地模型单独决策及其准确率强化学习版本，以及可访问完整病历的远程模型单独决策。另有去除训练、去除敏感追问等消融，以及记忆开启／关闭的配对比较。

## 4. 资源与算力

- 本地模型分别为 **Gemma 4 12B** 和 **Granite 4.2 8B**，均使用 rank-32 LoRA 与 GRPO 训练。
- Gemma：**2 张 H100 80GB**，训练 **200 步、约 48 小时**。
- Granite：**2 张 RTX PRO 6000 96GB**，训练 **120 步、约 21 小时**。
- 远程专家使用 GPT-5.6-Luna；论文说明了模型配置，但**未给出完整远程 API 调用量、费用或端到端实验总算力**。

## 5. 实验规模与充分性

- 实验覆盖**一个临床数据来源、两个本地模型、三项预测任务**，并分别考察基线、组件消融、奖励设计、攻击模型替换和测试时记忆增长。对“多轮披露”和“跨就诊链接”的测量，比只审查最终输出或单条消息更充分。
- 但比较并非完全同条件：PAPILLON 使用单个远程顾问和自身发布的提示词，PrivMeSA 使用三个专科顾问并接受任务专项训练；“远程单独决策”还能看到完整病历，更适合作为能力参照，而非同等隐私约束下的基线。文中也未报告多随机种子或置信区间，因此小幅准确率差异的稳定性尚不明确。

## 6. 主要结论与发现

- **Gemma 本地模型**下，PrivMeSA 三任务平均准确率为 **0.592**，高于委派的 **0.564** 和 PAPILLON 的 **0.526**；个人信息披露率为 **0.9%**，跨就诊关联后 \(k\leq10\) 的患者占比为 **0%**，委派方案则分别为 **94.3%** 和 **92%**。
- **Granite 本地模型**下，平均准确率由委派的 **0.425** 提升至 **0.583**，即提升 **15.8 个百分点**；个人信息披露率由 **98.0%** 降至 **0.2%**。单次就诊的 \(k\leq10\) 比例由 **74%** 降至 **0%**，跨就诊关联后由 **99%** 降至 **0%**。
- 测试时逐病例积累本地经验，远程消息数从平均每例 **7.02** 条降至 **5.98** 条，约减少 **15%**；各阶段准确率与关闭记忆的对照相当或略高。消融还表明，仅有架构或一般隐私提示不足以达到低泄露率；训练时让智能体面对专家索要敏感背景的追问很重要。

## 7. 优点

- 将隐私控制嵌入**连续临床决策**，而不止是发送前的一次性文本改写。
- 同时衡量直接泄露、整次会诊的准标识符组合风险和跨就诊链接风险，并使用独立于训练攻击模型的评估模型。
- 通过“先查本地经验、再决定是否外传”，把减少披露次数与保持临床能力结合起来；记忆增长无需额外结局标签。
- 提供了基线、组件和奖励消融，使准确率提升与隐私改善的来源更易分析。

## 8. 不足与局限

- **外部有效性有限**：仅在 MIMIC-IV-ED 的历史记录回放中测试，预测的是记录结果而非真实前瞻性诊疗效果；尚不能证明可安全用于临床决策。
- **隐私指标有边界**：直接披露主要检测注入的合成个人信息；重识别依赖指定 LLM 提取的准标识符、匹配规则及该登记库。附录说明，提取出与患者原记录不符的属性时会将该就诊排除出相关统计；这些设计均可能影响风险估计。“\(k\leq10\) 为 0%”不等于不存在其他渠道的泄露或重识别可能。
- **记忆质量与安全尚待验证**：经验由远程建议提炼，增长过程不依赖真实结局反馈；错误、过时或不适用的建议可能被保留或误用。论文主要检验了任务分数与对外披露，对长期知识质量和记忆本身的泄露风险覆盖不足。
- **泛化与成本未知**：仍需在其他医院、患者群体、专科、语言和真实工作流中验证；多模型调用、记忆检索与审核带来的总体延迟及费用，也缺少完整量化。
