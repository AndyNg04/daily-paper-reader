## 摘要
长期运行的大语言模型助手必须随着交互不断推进，反复决定应呈现哪些先前上下文，以及由哪个模型作答。现有记忆系统和模型路由器通常将这两项决策分开处理，尽管记忆构建会改变最终输入中的证据、干扰信息及其难度。我们提出 MARS，这是一种记忆感知路由框架，利用会话状态作为记忆构建与模型选择之间的共享控制接口。查询与主题管理器（QTM）估计与决策相关的紧凑状态，以指导固定的状态条件记忆策略和在线路由器，使每一轮交互都能在质量、记忆与成本之间的权衡下获得适当的记忆视图和合适的模型。我们在 RealMem 和 MultiChallenge 上评估 MARS，每个基准均采用 16 种系统配置，涵盖由长期历史记忆驱动的交互，以及具有结构化上下文干扰的有限会话。在 RealMem 上，MARS 在仅使用 GPT-4o 全上下文问答生成 API 成本 14.5% 的情况下，保留了其 98.2% 的问答性能；其中成本统计包含 MARS 的生成调用和控制器调用。与所比较的系统相比，MARS 的实测记忆召回和检索得分最高。在 MultiChallenge 上，MARS 的整体表现逊于最强静态系统，但在一个聚焦于机制的子集上，以更低的记录成本接近其性能。总体而言，这些结果表明，对于依赖记忆的长期交互，MARS 能够实现良好的质量、记忆与成本权衡。

## Abstract
Long-term LLM assistants must repeatedly decide what prior context to expose and which model should answer as an interaction evolves. Existing memory systems and model routers usually make these decisions separately, although memory construction changes the evidence, distractors, and difficulty of the resulting input. We introduce MARS, a memory-aware routing framework that uses session state as a shared control interface between memory construction and model selection. A Query and Topic Manager (QTM) estimates compact decision-relevant state that guides a fixed state-conditioned memory policy and an online router, enabling each turn to receive an appropriate memory view and a suitable model under a quality-memory-cost trade-off. We evaluate MARS on RealMem and MultiChallenge with 16 system configurations each, covering long-history memory-driven interaction and bounded sessions with structured context interference. On RealMem, MARS preserves 98.2% of full-context GPT-4o's QA while using only 14.5% of its generation API cost, including both generation and controller calls for MARS, and achieves the strongest measured memory-recall and retrieval scores among compared systems. On MultiChallenge, MARS trails the strongest static system overall but approaches its performance at lower recorded cost on a mechanism-focused subset. Together, these results support a favorable quality-memory-cost trade-off for long-history, memory-dependent interaction.

## 1. 核心问题与研究背景

### 1.1 研究问题

长期运行的 LLM 助手需要在多轮、跨会话交互中反复做出两个决策：

- **记忆决策**：哪些历史信息应进入当前提示词，哪些应省略？
- **模型决策**：当前任务应交给哪个模型，以兼顾质量与成本？

现有系统通常将记忆管理与模型路由分别处理，但两者实际高度耦合：**选入的记忆会改变证据完整性、过时信息与干扰信息的数量、上下文长度以及推理难度，进而影响哪个模型最合适。**

例如，用户要求完成一份发布简报，系统既需要采用更新后的发布日期，又要保留此前“恰好三段”的格式约束。遗漏约束、检索到旧版本，或选择无法可靠处理这些信息的模型，都可能导致失败。

### 1.2 整体含义

论文提出 **MARS（Memory-Aware Routing for Session-Level LLM Assistants）**，主张通过共享的结构化会话状态，协调“给模型看什么记忆”和“调用哪个模型”。

其目标不是单纯最大化准确率或压低调用价格，而是在**回答质量—记忆可靠性—API 成本**之间取得更好的折中。最适合的应用是需要恢复历史约束、延续任务、修改已有产物的长期助手。

## 2. 方法论：共享状态驱动记忆构建与在线路由

### 2.1 核心思想与优化范围

MARS 引入查询与主题管理器 **QTM（Query and Topic Manager）**，先将当前交互映射为紧凑状态，再由同一状态同时指导：

1. **固定的状态条件记忆策略**；
2. **在线更新的模型路由器**。

需要特别区分：**MARS 并不是端到端联合学习记忆策略与模型选择。**QTM 提示词、状态模式、保护规则和状态到记忆策略的映射均预先固定，只有路由器在线学习。

### 2.2 QTM：将会话转换为决策状态

QTM 使用 **Qwen2.5-7B-Instruct**，输出受约束的 JSON，而不是自由文本摘要。主要状态包括：

- **线程关系**：延续当前主题，还是切换到新主题；
- **查询类型**：静态、动态、时间相关、主动型；
- **任务阶段**：探索、约束、修订、综合、验证；
- **记忆控制**：是否需要记忆、局部或全局检索、是否偏好近期信息；
- **暴露预算**：检索数量提示为 3、5 或 8；
- **难度信息**：记忆跨度、歧义及风险等元数据。

系统对非法字段进行修正；遇到修订、收尾等可能依赖历史的请求时，采取保守的“继续线程并启用记忆”策略。

### 2.3 记忆构建：先形成候选视图，再按模型预算打包

候选记忆视图由三类信息组成：

- 当前活跃线程或任务产物的状态；
- 最近若干轮交互；
- 检索到的历史证据。

固定策略依据 QTM 状态决定各类信息的包含范围、检索数量和排序。例如：

- 自包含问题尽量减少记忆；
- 局部修改优先保留当前产物和近期交互；
- 跨会话追问采用全局检索；
- 综合与验证任务可使用更丰富的证据。

关键顺序是：

> **先构建候选记忆视图 → 再选择模型 → 最后按该模型的上下文预算裁剪与组装。**

最终提示词按“系统规则—记忆指导—记忆内容—当前问题”组织。若发生模型回退，则按回退模型的预算重新打包。

### 2.4 在线路由：LinUCB 上下文老虎机

路由器根据以下信息选择回答模型：

- QTM 状态；
- 候选记忆的估计 token 数、块数量；
- 检索相似度统计；
- 会话深度、修订或收尾标志等。

实现采用 **LinUCB**，选择“预测效用加探索奖励”最高的模型。主实验候选池包括：

- Llama-3.2-3B；
- Mixtral-8×7B；
- Qwen2.5-72B；
- GPT-4o。

路由特征为 30 维，探索系数为 0.8。特征不包含原始主题标识，以鼓励学习状态层面的选择规律。

### 2.5 反馈与逐轮流程

生成后，由 **GPT-4o-mini** 对当前回答进行局部评分，检查帮助性、状态一致性、修订执行、最终整合，以及主题漂移、幻觉、缺失历史等问题。

奖励大意为：

- 将记忆使用、回答正确性、回答质量分别按 **0.45、0.40、0.15** 加权；
- 扣除失败惩罚并裁剪到有限范围；
- 再减去“成本权重 × 当前生成模型调用成本”。

每轮只更新被选中的模型对应参数，不训练底层 LLM。在线反馈不使用未来轮次、最终标准答案或基准通过标签。

完整流程为：

> 状态估计 → 记忆控制 → 候选视图 → 路由特征 → 模型选择 → 上下文打包 → 回答生成 → 局部评分 → 路由更新 → 历史与记忆更新。

## 6. 主要结论与发现

### 6.1 RealMem：质量接近全上下文 GPT-4o，成本显著下降

| 系统 | QA | 记忆召回 | Recall@20 | NDCG@20 | 生成＋控制器成本 |
|---|---:|---:|---:|---:|---:|
| MARS | 0.7406 | **0.6794** | **0.8015** | **0.6168** | 26.65 美元 |
| 全上下文 GPT-4o | **0.7540** | 0.1640 | 0.5188 | 0.3216 | 184.40 美元 |
| A-MEM + MetaLLM-style | 0.7044 | 0.6471 | 0.6817 | 0.5846 | **20.29 美元** |

- MARS 保留 GPT-4o **98.2% 的相对 QA 表现**，不是绝对正确率达到 98.2%；
- QA 绝对差值为 0.0134；
- 主表成本为 GPT-4o 的 **14.5%**；
- 纳入估算在线反馈成本后，该比例约为 **17.6%**；
- MARS 的记忆召回与检索指标在比较系统中最高，但并非成本最低的系统。

此外，全上下文 Qwen 和 Mixtral 各有 **1,344/1,415** 个查询发生上下文限制错误。因此，这些系统的低分主要反映该配置下的不可执行性，不能直接解释为模型推理能力差。

### 6.2 MultiChallenge：整体未超越强静态模型

- MARS：**58/245，23.67%**；
- 全上下文 Qwen2.5-72B：**67/245，27.35%**；
- 全上下文 GPT-4o：**64/245，26.12%**。

全量结果上，Qwen 不仅通过率更高，记录成本也略低：3.1665 美元对 MARS 的 3.2504 美元。按已报告指标，MARS 在该场景**没有形成质量—成本优势**。

在推断记忆与版本编辑组成的 137 场景子集上：

- MARS 为 **44/137**，Qwen 为 **45/137**；
- MARS 记录成本约低 **15.4%**；
- MARS 在版本编辑上更好，但在指令保持和自我一致性上仍有明显不足。

### 6.3 消融发现

- 状态引导记忆优于仅使用原始查询语义检索；
- 近期记忆并不能替代长期证据检索，近期优先变体的记忆召回大幅下降；
- 好的检索结果不保证好的回答，生成模型能力仍然关键；
- 无 QTM 的语义检索变体 QA 为 0.7387，接近完整 MARS 的 0.7444，且更便宜，表明简单方案也是有竞争力的选择；
- 成本权重影响运行折中，但实验结果并不呈现严格单调关系。

## 7. 优点与亮点

- **问题定义有实际价值**：将长期助手中的记忆暴露与模型能力配置联系起来，而非分别优化。
- **共享状态接口清晰**：状态既控制检索，也用于路由与生成指导，便于追踪决策原因。
- **区分候选记忆与最终输入**：先路由再按模型预算打包，有助于适配异构模型。
- **无需底层模型训练**：通过小型控制器与轻量在线路由实现适应，工程集成门槛相对较低。
- **质量指标不局限于 QA**：同时考察记忆召回、检索排序和失败诊断。
- **负面结果披露较充分**：明确报告完整 MultiChallenge 排名、溢出失败和成本口径限制，没有仅用有利子集代替整体结论。

## 8. 不足与局限

### 8.1 方法与长期优化限制

- **协调不等于联合优化**：记忆策略固定，无法通过反馈直接学习更优的记忆选择规则。
- **局部奖励难以代表长期价值**：方法虽作用于会话序列，但采用逐轮上下文老虎机，未显式优化当前回答对后续任务成功的影响。
- **预打包特征存在信息差**：路由器看到的是候选视图统计，而不是不同模型实际裁剪后能获得的证据，可能高估某个模型的信息充分性。
- **QTM 错误可能传播**：线程切分错误会影响归档、检索和模型选择，且可能累积。

### 8.2 评测与偏差风险

- 在线裁判只能依据当前可见上下文判断，**难以识别未被检索出来的关键事实**；
- 在线反馈与最终评测均依赖 LLM 裁判，存在评分偏好与误判风险，尚缺充分人工核验；
- MultiChallenge 被转换为最终 YES/NO 验证任务，且满足标准时预期答案为 YES；虽然轨迹联合判断降低了投机空间，但与自然生成任务仍有差异；
- 机制子集有解释价值，但无法替代完整基准，也不能据此宣称全面优于静态模型；
- 提示和控制器稳定性仅验证固定快照上的决策一致性，**不等于长期轨迹或回答质量稳定**。

### 8.3 部署与泛化限制

- 每轮 QTM 和反馈调用可能增加延迟，而论文没有端到端延迟数据；
- 总成本未覆盖本地算力、存储、工程维护，部分反馈费用还是重建估算；
- 未充分覆盖工具调用、多模态、真实用户长期使用及高风险任务；
- 记忆隐私、恶意历史内容与记忆污染防护未形成系统评测；
- 代码、提示词和配置在文中仍处于计划发布阶段，独立复现尚待验证。

**总体判断：MARS 的主要价值是证明了“共享会话状态协调记忆暴露与模型选择”是一种有效的系统设计，尤其适用于长历史、强记忆依赖的交互；但现有证据尚不足以支持其在一般多轮助手任务上全面优于简单或静态方案。**
