Abstract 

Human–AI interactions are becoming a rich source of data for improving AI systems: while many model responses are already satisfactory, others expose failures that could become valuable supervision if identified and corrected. We study this setting through the notion of an editor : a more capable evaluation process that can inspect a response and either confirm it or modify it, but whose invocation is costly. The editor may be a human expert, a stronger AI system, or the same model equipped with additional computation, context, tools, or information. The key challenge is to decide which interactions to send to the editor before knowing whether an edit will actually be made, since invoking the editor itself consumes limited resources such as expert time, inference cost, latency, or tool-use overhead. We formulate this problem as Edit Discovery Optimization (EDO), which seeks to minimize edit opportunities missed among skipped interactions while controlling unnecessary confirmations and respecting an editor-cost budget. We characterize the population-optimal policy and show that it takes the form of a cost-adjusted threshold on the posterior probability of an edit. Building on this structure, we develop EDIT ( Edit Discovery via Iterative Thresholding ), an online algorithm for the partial-feedback setting in which edit labels are revealed only for selected interactions. EDIT combines an adaptive edit score, a confirmation-control threshold, and a cost-aware selection rule; it satisfies the editor budget at every round and controls the average confirmation rate up to a vanishing finite-horizon term, without distributional assumptions on the interaction stream. Across four reasoning and factual question-answering benchmarks, EDIT achieves a better trade-off between editor cost, Type-I error, and Type-II error than direct LLM-based batch selection. 1

# 1 Introduction 

Data has been instrumental to the progress in modern artificial intelligence. Until recently, this largely meant collecting human- or naturally-generated content, including text, code, images, and other forms of information. However, the most readily available sources of such data have become increasingly saturated: much of the public, high-quality content has already been used, while obtaining new data of comparable quality is becoming more difficult. This calls for a rethinking of what should count as useful data for the next generation of AI systems. One emerging source is the rapidly growing stream of human–AI interaction data, which we refer to as HAI data. In many settings, users now interact with AI systems that answer questions, handle requests, write code, summarize documents, and provide customer support. This source of data is fundamentally different from traditional supervised data. The responses are generated by the deployed system itself, and therefore are not uniformly useful as new supervision: many are already satisfactory or reflect capabilities the system has already acquired, while others expose mistakes, ambiguity, incompleteness, or misalignment with user intent. If these failure cases can be identified and corrected, however, they can be transformed from raw interaction logs into valuable supervision for improving future systems.

The editor may be a human expert, a stronger but more expensive AI system, or even the same model given additional computation, context, tools, or access to external information. Interactions on which the editor would make a modification are precisely the cases that can yield corrective supervision. The difficulty is deciding which interactions are worth sending to the editor. Consider a large e-commerce platform such as Amazon, where customer inquiries may increasingly be handled through AI-generated responses. Such a platform could generate tens of thousands of customer–AI interactions each day. Sending every interaction to the editor would maximize the opportunity to discover useful corrections, but could require substantial resources: human experts consume time and specialized effort, stronger AI systems incur additional inference cost, and enhanced evaluation pipelines may introduce latency or tool-use overhead. At the other extreme, invoking the editor too sparingly risks missing precisely the interactions that would provide the most valuable corrective signal. The challenge is therefore to allocate limited editorial resources toward interactions that are most likely to benefit from correction, while avoiding unnecessary editor invocations on responses that would simply be confirmed. This motivates the central question of this paper: 

Can we selectively identify the interactions on which the editor would make an edit, while substantially reducing the cost of invoking the editor? 

We answer this question in two steps. First, we formulate Edit Discovery Optimization (EDO), a constrained selection problem that formalizes the trade-off between discovering edit opportunities, avoiding unnecessary confirmations, and respecting the available editor budget. We characterize the population-optimal solution and show that it takes the form of a cost-adjusted threshold on the posterior probability of an edit. Building on this structure, we then develop EDIT ( Edit Discovery via Iterative Thresholding ), a practical online algorithm for the setting in which edit outcomes are observed only for interactions that are actually sent to the editor. This partial-feedback setting creates an additional algorithmic challenge: edit labels are revealed only for selected interactions, yet the discovery errors of interest depend on both selected and skipped interactions, so in particular the policy never observes online the skipped labels that determine missed edits. The policy must therefore learn where edits are likely to occur from selectively revealed feedback while regulating its selections without access to the full set of labels. EDIT addresses this by combining an adaptive edit score with a dynamically updated confirmation-control threshold and a cost-aware selection rule.

# 2 Related Work 

We summarize the closest work here and provide an extended review in Appendix A. 

Efficient evaluation and selective supervision. Prediction-powered inference combines model predic-tions with a small labeled sample to estimate population quantities with valid uncertainty [Angelopoulos et al., 2023], while cost-optimal active evaluation allocates an annotation budget between cheap weak raters and expensive strong raters [Angelopoulos et al., 2025]. Active learning selects informative examples for model improvement [Settles, 2009], PAC labeling combines expert and AI labels while bounding overall dataset labeling error [Cand` es et al., 2026], and learning to defer allocates prediction responsibility by accounting for the complementary capabilities of models and experts [Mozannar and Sontag, 2020]. 

Human–AI collaborative procedures. Conformal prediction sets narrow experts’ choices while controlling exclusion of the correct answer [Straitouri et al., 2023]. Counterfactual extensions optimize assistance through online learning using nested sets and monotonicity of expert decisions [Straitouri and Gomez Rodriguez, 2024]. Collaborative uncertainty quantification prunes and augments human-proposed sets to preserve correct judgments and recover overlooked answers [Noorani et al., 2025, 2026]. Related frameworks use weak scores to accept, reject, or request strong verification [Kiyani et al., 2026b], and selectively acquire costly support while controlling missed beneficial assistance [Kiyani et al., 2026a]. Together, these approaches combine human and computational effort to improve decision quality. 

Calibrated selection and online control. Conformal selection uses calibrated p-values to select instances whose unobserved outcomes satisfy a target criterion while controlling false discoveries [Jin and Cand` es, 2023]. Conformal Alignment extends this perspective to foundation-model outputs, selecting responses that satisfy a specified trustworthiness criterion [Gui et al., 2024]. Related extensions address interactive data analysis [Gui et al., 2025], online conformal selection with irreversible decisions [Liu 3et al., 2026], and more general bounded risk criteria [Bai and Jin, 2026]. Adaptive conformal inference uses sequential feedback to adjust prediction thresholds and regulate coverage under distribution shift [Gibbs and Candes, 2021], while conformal risk control extends calibration beyond coverage to expected monotone losses [Angelopoulos et al., 2024]. 

# 3 Fundamentals of Edit Discovery 

In this section, we formalize Edit Discovery Optimization ( EDO ) and characterize its optimal population policy. The formulation makes explicit the two ways a selection policy can fail: spending editor effort on responses ultimately confirmed without modification, or skipping responses that would have benefited from editing. It also incorporates the cost of invoking the editor under limited evaluation resources. The resulting analysis characterizes how selection should depend on edit likelihood and cost and reveals the structure that our finite-sample method seeks to emulate. 

3.1 Problem Formulation 

Let X and Y be the prompt and answer spaces. For each prompt X ∈ X , the AI system produces a response eY ∈ Y . Before editor feedback, the observable item is the prompt–response pair 

Z = ( X, eY ) ∈ Z , Z := X × Y .

If the item is selected, the editor inspects the AI response and provides a validated final answer Y ∈ Y .When the response is unsatisfactory, this answer may correct an error, resolve ambiguity, complete missing information, or better align the response with the user’s intent. Invoking the editor consumes limited resources such as expert time, annotation budget, or latency, so the goal is to select interactions most likely to yield useful corrections rather than review every response. For each selected item, define the edit indicator as the function 

A(Z, Y ) := 

(

1, if the editor modifies the AI answer, Y̸ = eY , 

0, if the editor confirms the AI answer, Y = eY . 

For notational brevity, we write A := A(Z, Y ) when the underlying interaction and validated answer are clear from context. Thus, A = 1 marks an informative edit outcome in which the interaction reveals a failure mode and produces corrective data that can be used, for example, as supervision for subsequent model training. Conversely, A = 0 indicates that the editor accepts the AI response without modification. Such confirmations may still be useful for auditing system behavior and for reinforcing capabilities that the model already performs reliably. 

Central population quantity. Efficient edit discovery requires predicting which AI responses are most likely to trigger an editor modification before the editor is invoked. The central population quantity is therefore the posterior edit probability 

η(z) := Pr[ A = 1 | Z = z] .

For a given interaction z, this quantity measures the probability that invoking the editor will result in an edit rather than a confirmation. It therefore provides a natural measure of the expected corrective value of selecting that interaction. Responses with larger values of η(z) are more likely to produce corrective data, whereas responses with smaller values are more likely to be confirmed without modification. As we show in Section 3.2, this quantity determines the ordering of interactions under the population-optimal policy, up to an adjustment that accounts for the cost of invoking the editor. 4Editor cost. Each interaction has a finite editor cost c(z) > 0, known at selection time. It may encode human time, monetary expense, latency, domain expertise, or any normalized resource needed to obtain feedback in practice. For instance, asking the editor to inspect a long mathematical derivation can be substantially more costly than checking a short factual answer. Allowing c to depend on z lets the policy trade off the expected value of an edit against the total effort required to obtain it. 

Selection policy and discovery errors. A population selection policy is a measurable function 

π : Z → [0 , 1], where π(z) is the probability that item z is sent to the editor. Conditional on Z = z, let 

Sπ ∈ { 0, 1} denote the realized selection decision, with Pr[ Sπ = 1 | Z = z] = π(z), generated independently of A given Z. Thus π(z) = 1 means the item is selected, π(z) = 0 means it is skipped, and intermediate values allow randomization. Selecting broadly consumes scarce resources on responses that the editor may simply confirm, whereas selecting narrowly can miss failures that would have produced valuable corrections. Edit discovery therefore seeks to concentrate selection on likely edits while controlling both the confirmation burden and total editor cost. We define the Type-I error of a policy π as Err I(π) := Pr[ A = 0 | Sπ = 1] , (1) the confirmation rate among selected examples. This is the probability that a selected item is already correct and does not require editor modification. Similarly, we define the Type-II error of π as Err II (π) := Pr[ A = 1 | Sπ = 0] , (2) the edit rate among unselected examples. This is the probability that a skipped item would have produced an editor correction. The goal is to minimize Type-II error while controlling Type-I error and respecting the available editor budget.

Let 0 ≤ ε < 1 denote the Type-I error tolerance, and let B ≥ 0 be the population editor budget. The population edit-discovery problem is 2

53.2 Optimal Policy in the Population Regime 

We study EDO in the population regime, where the joint distribution of ( Z, A ) is assumed known. Although unavailable in practice, this regime provides a useful benchmark for understanding the structure of the optimal policy and how posterior edit probability and editor cost should jointly determine selection. This characterization guides the method in Section 4, where these quantities are unknown and the policy must learn from partial feedback revealed only for selected interactions. 

Theorem 1 (Optimal population policy) . Let π⋆ be an optimal policy for (EDO ). Then there exist scalars α⋆, β ⋆ ≥ 0 such that 

π⋆(z) = 1 {η(z) > α ⋆ + β⋆c(z)} , (3) 

with possible randomization on the boundary {z : η(z) = α⋆ + β⋆c(z)}, if needed. 

Theorem 1 reduces a constrained set-selection problem to a one-dimensional ranking rule. An interaction is selected when its probability of producing an edit exceeds a global threshold plus a cost-dependent adjustment. The scalar α⋆ controls how informative the selected set must be, with larger values filtering out interactions with relatively low edit probability. The term β⋆c(z) accounts for scarce editor capacity by requiring a higher edit probability for more expensive interactions. This characterization also explains why learning an edit score is central. The online controller need not reconstruct the full joint distribution of ( Z, A ), it only needs a score that orders interactions like η

and adaptive analogues of the population thresholds. The cost term reflects scarce editor capacity, as it is active only when the budget is restrictive and vanishes otherwise. This directly motivates the online algorithm. In practice, η, α⋆, and β⋆ are unknown, so we replace 

η with an adaptive score eηt, update the global threshold from observed feedback, and choose the cost multiplier each round to enforce the budget. The online policy thus preserves the structure of the population-optimal rule using quantities observable during deployment. 

# 4 Online Edit Discovery 

The population analysis identifies the form of the optimal EDO policy, but its ingredients are unavailable in deployment: the interaction distribution is unknown, η cannot be evaluated, and edit labels are observed only for selected responses. In this section, we address the same edit discovery task under this information constraint, without imposing any distributional assumptions on the incoming stream. We replace the population errors in Section 3.1 by their online counterparts and replace the unknown population threshold rule by an adaptive finite-sample policy. Thus, the online setting specifies how to operationalize EDO 

from a stream of partially revealed feedback. We now describe the online interaction protocol used throughout this section.

• Random score (EDIT-RAND). As an uninformative control, each interaction receives an indepen-dent score eηt(Zt,i ) ∼ Uniform(0 , 1). It retains the same αt update and budget-feasible rule as EDIT

# 6 Conclusion and Limitations 

We introduced edit-discovery optimization and EDIT , a cost-aware online method that combines edit scoring with adaptive Type-I control and per-round budget enforcement. The population analysis shows that optimal selection follows a cost-adjusted threshold on edit probability, motivating the decomposition used by EDIT . In the online setting, the method controls the confirmation rate among selected interactions without distributional assumptions while satisfying the editor budget by construction. Across four reasoning and factual question-answering benchmarks, EDIT-REP reduces missed edits relative to direct LLM-based batch selection while maintaining reliable Type-I behavior, showing the value of separating edit scoring, online control, and budget allocation. The results further indicate that score quality matters: even a lightweight representation model provides useful rankings, while stronger encoders can further improve edit discovery. This modular design allows stronger edit predictors to be incorporated without changing the online control rule. Our experiments use benchmark-derived edit labels, supported by a limited 200-example human audit, rather than large-scale human editing. We also evaluate edit discovery itself rather than the downstream value of incorporating the resulting corrections into model training or adaptation. Future work can study 10 richer human editing workflows, heterogeneous editing costs, and whether discovered edits translate into measurable downstream model improvements in realistic human–AI deployment settings with diverse users, domains, editor expertise, and resource constraints.

Efficient AI evaluation. A growing line of work studies how model predictions can reduce the cost of evaluation. Prediction-powered inference combines a small labeled sample with predictions on a much larger unlabeled sample to estimate population quantities with valid uncertainty [Angelopoulos et al., 2023]. This idea has been specialized to hybrid language-model evaluation through stratified sampling [Fisch et al., 2024], while cost-optimal active evaluation allocates queries between weak and strong raters to obtain an efficient estimate of mean strong-rater performance [Angelopoulos et al., 2025]. Active statistical inference similarly chooses which labels to acquire in order to improve the precision of confidence intervals or tests [Zrnic and Cand` es, 2024]. These works are closely related to our motivation because they explicitly account for expensive human evaluation. Their objective, however, is accurate statistical inference about an aggregate quantity. In contrast, our goal is to identify the individual interactions that should be edited, while controlling confirmations among selected interactions and respecting the available editor budget. Standard LLM evaluation frameworks and LLM-based judges also focus on measuring model quality [Liang et al., 2023, Zheng et al., 2023], rather than deciding which interactions should enter an online human feedback loop. 

AI-assisted data collection. Classical active learning selects examples whose labels are expected to improve a predictive model [Settles, 2009, Zhang et al., 2022]. More recent work considers hybrid annotation pipelines in which an AI system supplies some labels and an expert supplies the remainder. PAC labeling uses model uncertainty to construct a completed dataset with bounded aggregate labeling error [Cand` es et al., 2026], whereas Conformal Labeling controls the false discovery rate among labels assigned by the AI system [Huang et al., 2026]. Although these methods also reduce human annotation effort, their output is a fully labeled dataset in which skipped expert labels are replaced by model labels. In our setting, skipped responses remain unlabeled, and the purpose of selection is to discover corrections rather than to approximate all missing labels. This distinction is important in practice because our policy must learn from only the edit decisions revealed for the interactions it previously selected. 

Conformal selection and online calibration. Conformal selection wraps a prediction model with calibrated p-values and selects units whose unobserved outcomes exceed a target while controlling false discoveries [Jin and Cand` es, 2023]. Conformal Alignment applies this perspective to foundation-model outputs and certifies a selected set as trustworthy [Gui et al., 2024]. Related extensions support interactive data analysis, irreversible online decisions, and general bounded risks [Gui et al., 2025, Liu et al., 2026, Bai and Jin, 2026]. These methods select outputs to accept or trust, whereas our positive decision sends an output to a human because it is likely to require correction. Reversing an acceptance rule does not preserve its guarantee or yield control of confirmations among selected items. Moreover, these methods generally require labeled calibration data or exchangeability-type conditions. Our threshold update is technically related to adaptive conformal inference and conformal risk control [Gibbs and Candes, 2021, Angelopoulos et al., 2024], but our guarantee applies to an arbitrary stream with labels revealed only after editor feedback and is coupled to a per-round cost constraint. 

Selective prediction and learning to defer. Selective prediction allows a model to abstain on inputs for which its prediction is unreliable, including end-to-end methods that optimize the risk–coverage trade-off [Geifman and El-Yaniv, 2019]. Learning to defer extends this formulation by explicitly accounting for the accuracy, bias, or cost of a downstream human expert [Madras et al., 2018, Mozannar and Sontag, 2020]. In these formulations, deferral is an alternative action used to improve the accuracy or utility of the deployed prediction system. Our setting differs in two ways. First, the model response has already been produced, and the human is asked to edit or confirm it in order to create corrective data. Second, a selection policy can fail both by selecting responses that are ultimately confirmed and by skipping 15 responses that would have been edited. Standard deferral methods do not address this edit-discovery objective or the partial feedback induced by selective editor invocation. 

Human–AI collaborative procedures. A complementary line of work designs procedures that combine human and AI judgments or selectively acquire costly assistance. [Straitouri et al., 2023] construct conformal prediction sets from which experts choose a label, balancing the risk of excluding the correct answer against the difficulty of choosing among many candidates. [Straitouri and Gomez Rodriguez, 2024] optimize this assistance through online learning, exploiting nested prediction sets and a counterfactual monotonicity assumption without requiring a parametric expert model. [Noorani et al., 2025] instead refine human-proposed prediction sets through AI-guided pruning and augmentation, with explicit counterfactual-harm and complementarity criteria and offline and online calibration algorithms. For reasoning systems, [Kiyani et al., 2026b] study policies that accept, reject, or request strong verification using a weak score, and develop randomized online procedures that control incorrect acceptance and rejection. [Kiyani et al., 2026a] minimize support-call frequency subject to controlling missed beneficial support, using adaptive thresholding and randomized exploration under partial feedback. These works provide algorithmic foundations for human–AI collaboration and selective assistance. Our formulation focuses on discovering editor modifications under constraints on confirmations and interaction-specific review costs.

D.2 Human Audit of Benchmark-Derived Edit Labels 

The benchmark experiments use task correctness as a scalable proxy for whether a response requires modification, so we directly validate this assumption on 200 held-out prompt–response pairs: 50 examples each from MATH-500, MMLU-Pro, PopQA, and GPQA. A human annotator evaluates every example with the interface in Figure 3 and assigns either confirm as-is or needs edit ; the interface exposes the user prompt, candidate response, and reference answer and optionally records a reason category. GPT-5.6 Sol independently annotates the same 200 examples using the same binary criterion and the common evaluation prompt reported in Appendix D.4.4. We treat the human labels as the primary validation target and use GPT-5.6 Sol only as an additional consistency check. The benchmark-derived labels closely track the human judgments at both the aggregate and example levels. Across all 200 examples, benchmark and human labels agree on 96 .5% of interactions, with Cohen’s 

κ = 0 .930 and edit-class F1 = 0 .963; their overall edit rates are also nearly identical, 0 .470 for the benchmark proxy versus 0 .465 for the human annotator. Dataset-level benchmark–human agreement remains between 0 .960 and 0 .980, with κ > 0.916 for every dataset. GPT-5.6 Sol produces an edit rate of 0.460, agrees with the benchmark in 0 .980 of cases ( κ = 0 .960), and agrees with the human annotator in 0.975 of cases ( κ = 0 .950). Table 4 gives the complete dataset-level breakdown. Taken together, the audit provides direct support for using benchmark correctness as the edit indicator in the main experiments rather than merely matching edit prevalence by coincidence. The benchmark proxy disagrees with the human annotator on only 7 of 200 audited interactions, while its per-dataset edit rates stay close to the human rates and its example-level agreement is consistently high. The independent GPT-5.6 Sol annotations lead to the same qualitative conclusion, which further suggests that the benchmark labels capture a stable notion of substantive edit need. 

D.3 Operating-Point Trade-offs and Complementary Metrics.
