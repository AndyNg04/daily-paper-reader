## ABSTRACT 

The learning algorithm view of in-context learning (ICL) studies how fixed-parameter Transformers learn from supplied examples. Language model agents extend this setting through interaction: their actions determine what evidence en-ters context next. We call this regime Agentic In-Context Learning (Agentic ICL). Existing studies largely depend on externally supplied contexts or reward-bearing interaction histories, while work on general tool-using agents lacks a learning algorithm view. We represent an interactive learner by its state, update, and de-cision rule, covering active learning, bandits, and online reinforcement learning (RL). For expressivity, we construct causal Transformers that approximate these algorithms over a finite horizon, and bound the resulting loss in return. For training, we characterize when optimizing process rewards preserves behavior that maxi-mizes the final outcome. Distillation experiments show that Transformers can learn to execute three representative recursions. We then train models from outcome or process rewards without oracle action or state targets, as in RL post-training. Different rewards yield distinct decision policies. Improving the alignment of pro-cess supervision with outcome-optimal action preferences shifts learned decisions accordingly. Such behavioral differences persist in a pretrained language model across textual paraphrases. 

## 1 INTRODUCTION 

In-context learning (ICL) is a central way in which language models adapt at inference time: informa-tion in the prompt changes subsequent predictions while the model parameters remain fixed. This has motivated a learning algorithm view of ICL, which asks what estimator, update rule, or other learning computation a Transformer (Vaswani et al., 2017) implements through its forward passes over an externally supplied prompt (Xie et al., 2022; Garg et al., 2022; Akyürek et al., 2023; von Oswald et al., 2023; Bai et al., 2023; Wu et al., 2025). Modern language-model agents routinely operate in an analogous but closed-loop regime. An agent can browse the web, call tools, edit code, or run experiments, then use the returned results to choose later actions (Yao et al., 2023; Shinn et al., 2023; Zhao et al., 2024; Lutz et al., 2024). A search query determines which page is read, a code edit determines the next test result, and an experiment determines the next measurement. The agent therefore does not merely learn from a supplied context: through its actions, it helps determine the context from which it will learn next. We call this execution regime Agentic In-Context Learning (Agentic ICL). Starting from an initial prompt or task description, a fixed-parameter model chooses an action, receives feedback, and incorporates that feedback into its next decision. Its context grows through interaction with the environment. The returned feedback can be a search result, compiler error, measurement, critique, or reward. This motivates extending the learning algorithm view of ICL to interactive computations in which decisions shape subsequent evidence. The central question is: 

What interactive algorithms can Transformers learn in context, and how do training objectives shape their behavior?

In-context reinforcement learning (ICRL) provides the closest precedent (Laskin et al., 2023; Lee et al., 2023; Lin et al., 2024; Wang et al., 2025; Liang & Lai, 2026), but requires scalar rewards to be included in the interaction history. However, an agent usually receives non-reward feedback: a search result, compiler diagnostic, or measurement can guide the next action. We therefore develop Agentic ICL allowing agents to learn from non-reward feedback. This also separates the evidence used for in-context adaptation from the objective used for training and evaluation. Agentic ICL includes ICRL as a special case. Answering these questions requires both a construction showing what Transformers can execute and experiments examining what they learn under different objectives. Our contributions are fourfold: • Closed-loop framework (Section 3). We factor an interactive learner into a sufficient state, a feedback update, and a decision rule. The same interface covers active learning, bandits, and online RL. • Transformer realization (Section 4). We give a constructive proof that compiles regular finite-horizon recursions into causal Transformers. The construction realizes their action choices and yields a bound on autonomous return loss. • Training objectives and diagnosis (Section 5). We theoretically characterize when pro-cess supervision preserves outcome-optimal behavior, then develop behavioral diagnostics for trained Transformers. • What training learns (Section 6). Supervised distillation tests learned execution of supplied interactive recursions. RL without oracle action shows how outcome and process rewards lead to different decisions, and how those decisions change with controllable reward intervention. 

## 2 RELATED WORK 

Learning algorithm views of ICL and ICRL. ICL has been characterized as implicit Bayesian inference, regression, gradient descent, algorithm selection, and data-dependent learning-to-learn (Xie et al., 2022; Garg et al., 2022; Akyürek et al., 2023; von Oswald et al., 2023; Bai et al., 2023; Wu et al., 2025). Constructive, behavioral, and mechanistic studies identify familiar estimators inside Transformers (Akyürek et al., 2023; von Oswald et al., 2023; Bai et al., 2023); we extend this standard to closed-loop recursions whose decisions determine subsequent in-context data. ICRL extends this perspective to RL updates and control, including pretraining on stored state-action-reward trajectories with source-policy or oracle actions (Laskin et al., 2023; Lee et al., 2023; Lin et al., 2024). These models can nevertheless generate their own interaction histories at deployment. Prior work implements posterior sampling, bandit, TD, SARSA, or policy-improvement computations and distinguishes model-free from model-based strategies (Wang et al., 2025; Fang & Rajan, 2025; Liang & Lai, 2026). Our interface permits both reward-hidden and history-dependent feedback. Rewards used for training and evaluation need not be revealed in the agent’s transcript, and individual returned records need not be Markov states: the feedback law may depend on the full interaction history, from which the learner constructs its sufficient state. Agentic ICL unifies active learning, 2bandits, online RL, and tool use. The primary discovery experiments provide neither oracle actions nor sufficient-state targets. 

Tool agents and interactive language feedback. Tool agents append search results, test outputs, or other feedback to the context (Yao et al., 2023; Shinn et al., 2023; Zhao et al., 2024; Lutz et al., 2024), but are usually evaluated by success or transfer. Work on language feedback instead studies when language feedback is informative enough to enable efficient online learning (Xu et al., 2026) or how to incorporate teacher-selected critique (Klissarov et al., 2026). We treat language as one possible returned record and compare candidate descriptions of the model’s state, update rule, and decision rule, separating compilation from behavior learned with terminal outcome reward. “Agentic in-context learning” has also named a stance-aggregation method (Lee et al., 2025); we use the term for the interaction regime in Definition 3.1. 

Closed-loop learning settings and algorithms. We focus on learning settings in which the learner’s input history is generated online through interaction: its actions affect which observations enter context, rather than merely processing a dataset fixed in advance. This includes adaptive data collection, where decisions determine which labels, measurements, rewards, or state transitions arrive next. In active learning, previously observed labels guide the choice of subsequent queries to improve downstream predictions (Settles, 2009); bandits reveal selected-arm rewards (Auer et al., 2002a; Li et al., 2010; Russo et al., 2018; 2026); and online RL also controls persistent state and long-horizon return (Sutton & Barto, 2018; Zanette & Brunskill, 2018). We instantiate BALD for active learning; Thompson sampling, UCB, LinUCB, and EXP3 for bandits; and Q-learning, SARSA, actor-critic, and learned-model planning for online RL, alongside VOI and KG for adaptive query selection (Frazier et al., 2008; Auer et al., 2002b; Watkins & Dayan, 1992; Azar et al., 2017). Bayesian updating, optimism, and planning recur across these settings. 

Transformer expressivity for recursive algorithms. Universal approximation and recurrent-depth Transformers establish broad expressivity (Yun et al., 2020; Dehghani et al., 2019). Our construction exposes a sufficient-state wavefront, shares parameters across turns, and converts per-action approximation into an autonomous return bound. 

Process supervision and reward shaping. Process supervision scores intermediate steps, but shaping can change the optimal policy unless action-value ordering is preserved (Lightman et al., 2023; Cui et al., 2025; Cheng et al., 2025; Ng et al., 1999). We use potential-based shaping to construct an outcome-preserving process-reward control. 

## 3 AGENTIC ICL: A C LOSED -L OOP LEARNING FRAMEWORK 

Consider an LLM agent asked to solve a coding task. It searches for documentation, executes code, and uses the returned pages or errors to decide what to try next. Each action changes its future evidence. We separate this process into the interaction that generates the transcript and the learner computation that updates evidence and selects actions. 3.1 INTERACTION WITH THE ENVIRONMENT 

We first specify how the agent’s actions determine the observations added to its context. Let x0

be the initial prompt, containing the task description and any public information available before interaction. Fix a task M , which contains the task parameters and any fixed episode-level latent state, with environment kernel KM , a finite action space, and horizon H. Write πθ for the action policy induced by the frozen causal Transformer Tθ. Define h0 = x0 and ht = ( ht−1, a t, x t), where at is the t-th action and xt its returned record. Before action t, the model receives ht−1.

Definition 3.1 (Agentic in-context learning) . An Agentic ICL episode is the closed loop 

at ∼ πθ (· | ht−1), xt ∼ KM (· | ht−1, a t), t = 1 , . . . , H, (1) 

This is called Agentic ICL as the parameters θ remain fixed during deployment, and learning in context occurs through the dependence of πθ on the growing transcript ht−1.

This definition specifies the execution regime. For an LLM agent, πθ is typically a Transformer. 33.2 INTERACTIVE LEARNING ALGORITHM 

In the coding example, the agent maintains an information state, updates it after each tool result, and uses it to select the next search or code execution. Thus an interactive learner can be described by a sufficient state st before action t, an update Ut, a decision rule Gt, and legal actions Lt(st). Coupled to the environment step in Definition 3.1, its learner’s recursion is 

s1 = U0(x0), a t ∼ Gt(· | st), s t+1 = Ut(st, a t, x t), t = 1 , . . . , H. (2) The induced history policy is Gt(· | st(ht−1)) . The environment KM supplies feedback, while the learner maps (Ut, G t) incorporate it and select the next action. This factorization separates how evidence is incorporated from how actions are selected. Consider three representative and widely studied settings of learning problems: active learning selects queries and receives labels to improve downstream predictions; bandits select an arm and reveal its outcome for cumulative reward or regret; and online RL controls both immediate feedback and future states for long-horizon return or regret. They are all included in this framework and distinguished by how actions shape future context. At the interface level, any finite-horizon policy can be expressed in this recursive form by taking st = ht−1. Importantly, the feedback need not itself be the task reward, separating the records used for in-context adaptation from the task objective. Appendix A gives instantiations. 

## 4 COMPILING INTERACTIVE LEARNING ALGORITHMS INTO TRANSFORMERS 

The framework expresses an interactive algorithm through its state, update, and decision rule. We now construct a frozen causal Transformer that executes (2) by serializing the transcript, routing the state between turns, incorporating feedback, and producing the next action distribution. Assume fixed-width encoders Ex and Ea for public records and actions. We serialize the prompt and extend it recursively, for 1 ≤ t < H :

Prompt( h0) = [ Ex(x0), SUM , ACT ],

Prompt( ht) = [Prompt( ht−1), E a(at), E x(xt), SUM , ACT ]. (3) Each field occupies one vector token. The SUM token provides workspace for the learner state; the final ACT token emits the next action. The action and its returned record are then appended to form the next prompt. This encoding makes the learner’s computation explicit. It is a non-exclusive abstraction of LLM agents’ data flow, not a lossless encoding of arbitrary natural-language records. Given this serialization, the following theorem states that a frozen causal Transformer can uniformly realize the policy of any regular finite-horizon recursion with arbitrarily small error. Unless noted otherwise, metrics are averaged within each seed and reported as mean ± standard deviation across five independently trained seeds. 6.1 BTS: AN EXACTLY DIAGNOSABLE AGENTIC ICL ENVIRONMENT 

Multi-round Bayesian Tool Selection (BTS) models sequential tool use while keeping its optimal policy exactly computable. Each task asks the agent to predict a hidden target Z ∈ [K] using tools 

e ∈ [E] with likelihoods Le(y | z) = Pr( Y = y | Z = z, tool e), costs ce, discount δ, and a query budget. A tool-call action e returns an observation Y ∼ Le(· | Z), which is appended to the next prompt; an answer action g ∈ [K] terminates the episode with reward δC 1{g = Z}, where C is the total call cost. Tools are legal only while calls remain and their costs fit the budget; answers are always legal. The initial prompt contains all task-specific parameters, and is followed by the action-evidence transcript. Bayes dynamic programming (Bayes DP) computes an optimal policy for this task. At history ht−1,Bayes DP makes decisions from a sufficient state, consisting of the posterior bt(z) = Pr( Z = z |

ht−1), remaining call horizon, and remaining budget. It compares immediate answers with the discounted value of future adaptive queries and is exactly outcome-optimal in this finite known environment. Appendix G gives details of this optimal policy. Priors, likelihood matrices, labels, costs, discounts, budgets, and query horizons are randomized across episodes, preventing a fixed tool-calling script from matching the task-specific oracle. We evaluate autonomous return on fresh tasks and exact action probabilities on frozen diagnostic histories. Longer-horizon results control for budget feasibility and realized interaction length; Appendix G gives the complete task distribution and protocol. 6.2 LEARNED COMPILATION : CAN TRANSFORMERS EXECUTE THE RECURSION ?The construction establishes the existence of Transformer parameters that execute interactive recur-sions. Distillation demonstrates learned execution when the target policy is supplied. We next remove oracle action and state targets and train only from rewards, as in RL post-training of language model agents. The central question is how training objectives shape candidate-relative decisions. In particular, we test whether learned behavior tracks changes in the training objective under controlled interventions. We consider four supervision conditions. Outcome reward targets terminal BTS return, for which Bayes DP is optimal; one-step process reward scores immediate local progress; outcome-preserving process reward adds a potential-based shaping term with a fixed bounded perturbation; and Bayes DP-score distillation provides a supervised reference using a softmax over unregularized Bayes DP action values. A verifier scores immediate information gain or apparent progress without computing globally optimal continuation values. Its three parameters (α, τ v , γ ) control the local score and credit assignment. A call is rewarded when its realized gain in answerability and distributional certainty offsets its cost. The confidence weight α trades top-answer probability against normalized certainty, τv controls how strongly each observation updates the verifier belief, and the credit discount γ controls how much later verifier progress is assigned to the current action. The primary setting uses (α, τ v , γ ) = ( .75 , . 75 , 0) ,and we refer to its γ = 0 objective as the one-step process reward. Following Proposition 5.1, the outcome-preserving process reward uses a perturbed potential-shaped dense signal while preserving the outcome-optimal policy set. To describe the learned policy with (7), here we consider four candidates sharing the Bayesian update but using different decision rules: Bayes DP, one-step knowledge gradient (KG), one-step entropy reduction, and an open-loop oracle. These candidates distinguish outcome-optimal planning, one-step value of information, a surrogate information objective, and feedback-insensitive acquisition. Appendix G gives the formal definitions of the rewards and candidate policies, the diagnostic histories, and the complete training protocol. Figure 3 shows that outcome reward training produces behavior closest to Bayes DP, whereas one-step process reward training produces behavior closest to KG. The latter is consistent with the one-step objective violating the ordering condition in Proposition 5.1. The outcome-preserving process reward instead remains Bayes DP-like. The bounded perturbation changes individual step rewards, but telescoping leaves the ordering of cumulative action values unchanged. This provides an empirical test of the proposition’s ordering criterion without requiring the process and outcome rewards to be numerically equal. ## 7 CONCLUSION AND LIMITATIONS 

We formalize Agentic ICL as interactive adaptation in which a fixed-parameter Transformer shapes its future evidence through actions, without requiring observations to reveal rewards. Our construction realizes regular finite-horizon recursions with a bound on autonomous return loss, and distillation demonstrates learned execution. Reward experiments link decision differences to outcome-optimal action ordering: a perturbed process reward that preserves this ordering retains behavior close to outcome training, while objective interventions shift learned decisions as alignment changes. The out-come/process decision contrast also persists across textual paraphrases in a pretrained language model. The theory establishes expressivity under regularity assumptions without guaranteeing optimization convergence. Behavioral comparisons are candidate-relative, and probes do not identify a unique internal algorithm. Experiments use small structured tasks, hand-specified verifiers, and a potential-based control whose perturbation preserves optimal actions exactly. These results do not establish robustness to arbitrary process-reward errors or learned verifiers. Language-model tests supply observation models and constrain actions, leaving generalization to open-ended agents with unknown tool semantics, longer interactions, and context compression unresolved. 98 AI U SE STATEMENT

G.9 NATURAL -LANGUAGE EXPERIMENTS WITH A PRETRAINED LLM 

Text interface. We render the same BTS task distribution as a chat transcript for Qwen2.5-1.5B-Instruct, including the independently sampled training-time horizons and budgets in Table 3. The initial user message states the four candidate targets and their prior probabilities, the six tool cards and their conditional outcome probabilities, tool costs, the cost discount, and the initial budget and call horizon. Subsequent user messages append the selected tool, its returned outcome, and the mechanically updated resources. Every probability used by the simulator and the exact oracles is the value printed in the prompt; the sampled target, posterior belief, oracle values, correctness, and trainer reward are never shown. Target, tool, and outcome names are random nonce words, and their order is independently permuted across tasks. We use four training-template families and reserve eight disjoint paraphrase families for evaluation; a family jointly specifies the wording of the task, tool cards, resource records, and returned observations. The model emits no rationale. Ten tokenizer-verified single-token action identifiers represent the four terminal answers and six tool calls, and their assignment is randomly permuted and stated in each initial prompt. At the first assistant-token position we restrict the softmax to the legal identifiers, sample one action during autonomous rollouts, and append the sampled identifier to the transcript. Thus the complete legal-policy is obtained directly from the corresponding next-token logits, without parsing free-form generations. An abbreviated example of the initial user message follows; every actual prompt enumerates all ten action-ID assignments and all six complete tool cards.                                                                         

> Identify one hidden target. Output exactly one legal action ID. Prior: norvik 0.28; pelnor 0.24; saiven 0.26; tudor 0.22. Score: 0.98^(total tool cost) if the final answer is correct; otherwise 0. Budget: 3. Remaining calls: 3. Action B: answer norvik. Action G: answer pelnor. ... Action E: call tool mira, cost 1. If norvik: amber .80, blue .15, gray .05. If pelnor: amber .69, blue .21, gray .10. ... Legal actions: ABCDEFGHIJ.

Optimization. We fine-tune in bfloat16 with a maximum context length of 4,096 and zero dropout. Each PPO update collects multiple fresh episodes, followed by four epochs over episode minibatches of size 32. We use AdamW with actor learning rate 1 × 10 −6, value-head learning rate 5 × 10 −6,weight decay 0.01, a 3% linear warmup followed by cosine decay, PPO clip ratio 0.2, value-loss coefficient 0.5, and gradient-norm clipping at 1. Outcome-reward advantages use GAE with γPPO = 1 

and λ = 1 , which reduces to the Monte Carlo return on complete episodes. One-step process reward advantages use γPPO = 0 , so the target at each decision is its immediate realized verifier reward. 34 All visited decision positions contribute to the PPO loss, but a later verifier score is not credited to an earlier action. Value targets and advantages are standardized over all decision positions in each rollout batch. The entropy coefficient decreases linearly from 0.01 to zero during the first 30% of updates; no reference-policy KL reward is used. Distillation uses the same pretrained initialization, context length, full-parameter update, batch size of 128 fresh oracle trajectories, and 4,000-update budget. It uses AdamW with learning rate 1 × 10 −5,weight decay 0.01, the same warmup and cosine schedule, and gradient-norm clipping at 1. Five seeds are fixed before training. Every result uses the final-budget checkpoint; neither candidate distances nor paraphrase evaluations are used for hyperparameter choice or checkpoint selection.
