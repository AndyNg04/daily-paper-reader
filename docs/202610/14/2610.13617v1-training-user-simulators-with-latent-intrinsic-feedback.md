## 摘要
用户模拟器作为训练大语言模型（LLM）助手的环境日益受到关注，有助于助手更好地应对与真实用户进行多轮对话时的细微差异。以往关于用户模拟的研究侧重于生成逼真的用户话语，却未探索其作为直接反馈来源、用于评价助手回复的潜力。这类评估信号未必会通过语言明确表达，也可能存在于用户的潜在推理之中。在本研究中，我们提出了具备内在反馈的用户模拟器，即配备潜在评估状态的模型：这些状态包括内部想法、反应和标量评分，能够在每轮对话中从用户的第一人称视角评价助手。我们利用真实用户与助手之间的交互日志训练基于 LLM 的模拟器，并证明，与通过提示词构建的模拟器基线相比，内在反馈能够提升模拟的真实性和批评能力，同时提供现有微调模拟器所不具备的轮级评估。此外，我们训练的模拟器所生成的评估与人工判断的相关性，高于同等规模的提示词模拟器。最后，实验表明，具备内在反馈的模拟器能够为多轮强化学习（RL）训练提供有效的奖励信号，其效果可媲美依赖外部评审 LLM 提供奖励的方案，同时将 RL 计算开销降低一半以上。

## Abstract
User simulators are gaining attention as environments to train LLM assistants that can better cope with the nuances of multi-turn conversations with real users. Prior work on user simulation has emphasized generating realistic user utterances, leaving unexplored their potential as a source of direct feedback on the assistant's responses. Such evaluation signals may not be explicitly communicated in language, but can instead reside in the latent reasoning of users. In this work, we introduce user simulators with intrinsic feedback, namely, models equipped with latent evaluation states: internal thoughts, reactions, and scalar ratings that evaluate the assistant from a first-person user perspective at each conversation turn. We train LLM-based simulators using interaction logs between real users and assistants and demonstrate that intrinsic feedback improves simulation realism and critiquing behaviors versus prompted simulator baselines, while also providing turn-level evaluations that existing fine-tuned simulators lack. Further, evaluations generated by our trained simulators correlate better with human judgments than those of prompted simulators of the same size. Lastly, our experiments reveal that simulators with intrinsic feedback provide effective reward signals for multi-turn RL training, matching setups that rely on external judge LLMs for rewards while cutting RL compute by more than half.

## 1. 核心问题与整体含义

### 研究背景与动机
- 多轮对话中的 LLM 助手容易出现误解用户需求、忽略约束、偏离目标等问题。为了训练更可靠的助手，研究者越来越多地使用**用户模拟器**生成交互环境。
- 现有模拟器主要学习“用户下一句话会怎么说”，通常不能直接回答“用户对助手上一轮回答有多满意”。因此，多轮强化学习往往需要额外调用**外部裁判模型**计算奖励。
- 这种分离式设计存在两个问题：
  - **评价视角不一致**：外部裁判对回答质量的判断，不一定符合真实用户的主观体验。
  - **计算成本较高**：每轮交互除助手与模拟器推理外，还需要裁判模型推理。

### 核心研究问题
论文研究：**能否让用户模拟器同时生成真实的用户话语，并提供逐轮、第一人称的助手评价，从而兼任交互环境与奖励来源？**

- 作者认为，用户的不满不一定表现为显式批评，也可能体现为重述需求、继续追问或调整请求。
- 因此，仅模仿用户话语不足以完整描述用户体验，需要建模话语背后的评估状态。
- 整体意义在于将用户模拟从“语言生成器”扩展为**具有评价能力的交互式训练环境**。

> 这里的“内在反馈”指模拟器内部生成的评价，而不是直接观测到的真实用户心理，也不是传统意义上基于探索或新颖性的内在奖励。

## 2. 方法论：核心思想与技术流程

### 2.1 潜在评估状态（LES）
作者提出 **Latent Evaluation States，LES**。模拟器在生成下一轮用户话语之前，先生成包含五个字段的结构化状态：

| 字段 | 内容与作用 |
|---|---|
| `Internal_Thought` | 第一人称评估性想法，判断助手是否符合用户期待；主要关注格式、长度、指令完成度等用户可观察的问题 |
| `Rating` | 1–5 分满意度评分，作为直接评价信号 |
| `Instruction_Followed` | `Yes / No / Partially`，表示指令遵循程度 |
| `Reaction` | `Critique / Praise / Neutral`，表示批评、表扬或中性反应 |
| `Feedback` | 批评或表扬主题的 2–5 词摘要；中性反应时为 `null` |

- LES 以 JSON 形式生成，置于 `<eval>` 与 `</eval>` 标记之间。
- 用户话语随后生成，并受到 LES 的条件约束。
- 这些“潜在”状态实际上是**显式生成的文本中间表示**，并非不可观测的神经网络隐变量。

### 2.2 建模方式
- 普通用户模拟器直接建模：**给定对话历史，生成下一轮用户话语**。
- LES 模拟器将其拆为两个阶段：
  1. 根据对话历史生成评估状态。
  2. 根据对话历史和评估状态生成用户话语。
- LES 内部各字段也按照自回归方式依次生成。
- 模型还可在对话开始前接收一个高层次**用户意图**，帮助其持续围绕指定任务展开交互。

### 2.3 数据构造与监督训练
1. 从真实用户—助手交互日志中筛选、去重并移除评测集重叠数据。
2. 使用 **Gemini3.1-Pro** 为对话生成高层用户意图。
3. 从第二轮用户发言开始，为每轮生成 LES：
   - 标注模型可以看到实际用户下一轮话语。
   - 因此，这一步属于结合已发生行为进行的**事后状态推断**。
4. 对 **Gemma3 4B、12B、27B 基座模型**进行全参数监督微调，学习生成“LES + 用户话语”。
5. 另外训练仅生成用户话语的 SFT 模型作为对照，并比较是否使用意图条件。

### 2.4 用于多轮强化学习
- 将训练好的模拟器作为助手的交互环境。
- 助手输出回答后，模拟器同时产生评价和下一轮用户话语。
- 使用模拟器的逐轮评分，以**对话各轮平均评分**作为优化目标，通过多轮 GRPO 训练助手。
- 对照方案则由外部 **Qwen2.5-14B-Instruct** 裁判计算奖励。

**关键设计是：同一次模拟器生成同时完成用户行为模拟与奖励生成，减少额外裁判调用。**

## 6. 主要结论与发现

### 6.1 相比提示式模拟器，LES 通常更真实
- Gemma3-12B：
  - 统计对齐分数：IT **0.5135** → LES **0.8635**。
  - PPL：IT **13.41** → LES **3.13**。
- 相比普通 SFT，LES 的 PPL 在三个 Gemma 规模上均更低。
- 但统计对齐并非全面胜出：Gemma3-27B 的 SFT 为 **0.8590**，LES 为 **0.8475**。

### 6.2 批评行为改善具有边界
- LES 相比同规模提示式基线，在 4B、12B 上提高了批评 F1。
- **27B 是例外**：IT 为 **72.39**，LES 为 **69.91**。
- 普通 SFT 在三个 Gemma 规模上的 F1 均高于 LES；LES 主要损失在批评召回率，表现得更谨慎。

因此，不能概括为 LES 在所有规模、所有基线上都改善批评行为。

### 6.3 评分与人类判断的相关性提高，但仍属中等
SimulatorArena 总体相关系数：

| 规模 | 提示式 Gemma | LES |
|---|---:|---:|
| 4B | 0.244 | **0.384** |
| 12B | 0.295 | **0.401** |
| 27B | 0.343 | **0.383** |

- 4B、12B 的总体提升具有统计显著性；27B 不显著。
- 部分任务并未改善，例如 Gemma 27B 的数学子集相关性下降。
- Qwen 家族呈现相似总体趋势，但并非所有规模或子任务都显著提升。

### 6.4 评估能力与语言真实性存在权衡
- 仅使用评分字段时，12B 消融模型的批评 F1 和评分相关性最高，分别为 **76.42、0.4474**。
- 加入语言化评估字段后，真实性提高，但部分反馈指标下降。
- 完整五字段方案在该消融中具有最佳统计对齐与最低 PPL，体现的是**综合折中**，不是所有指标上的最优。

### 6.5 内在奖励支持低成本 RL
- 初始助手要求满足率：**28.78%**。
- LES + 外部裁判：**41.08% ± 0.97**。
- LES + 内在奖励：**41.44% ± 0.63**。
- 两者表现接近，内在奖励的平均值略高，但论文没有证明这 **0.36 个百分点**的差异具有显著性。
- 最稳健的结论是：**内在奖励达到相近效果，同时显著降低估算 RL 计算量。**

## 7. 优点与亮点

- **统一环境与奖励来源**：模拟器在生成用户行为的同时提供评价，设计直接且有实际效率价值。
- **区分满意度与显式反应**：允许用户不满意却不直接批评，比单纯从话语判断满意度更细致。
- **基于真实交互数据**：减少仅靠提示词扮演用户时的风格偏差。
- **结构化状态便于控制与诊断**：评分、指令遵循、反应与反馈各有明确功能。
- **评测链条较完整**：覆盖语言真实性、批评行为、真实人类评分和下游训练效用。
- **有跨家族和消融支持**：结果并非仅来自单一模型或单一配置。
- **主要实用收益清晰**：性能提升虽小，但减少裁判调用带来的计算节省较大。

## 8. 不足与局限

### 8.1 合成状态不等于真实心理
- LES 来自 Gemini 对日志的推断，没有真实用户逐轮心理报告作为直接监督。
- 标注可能混合了用户主观满意度与模型对回答客观质量的判断。
- WildChat 评分相关性衡量的主要是与合成标签的一致性；SimulatorArena 才提供独立人类验证。

### 8.2 训练与推断存在信息条件差异
- LES 标注时能看到真实下一轮用户话语，推断时却需要先生成 LES，再生成话语。
- 这种事后标注有助于学习行为关联，但可能产生**后见偏差**，不能证明模型准确恢复了行为发生前的真实状态。
- 用户意图也是从整段对话生成，可能包含开场时尚未披露的信息。

### 8.3 评测口径与裁判偏差
- LES 标注提示主要依据显式批评，而生成结果裁判还纳入隐式重述、绕行等批评形式，两者口径并非完全一致。
- Gemini 同时参与标注和多项评测，存在共享评价偏好的风险。
- 留出集刻意提高批评样本比例，因此其 F1 不完全代表自然交互分布中的效果。

### 8.4 泛化和长期交互证据有限
- 训练主要使用英语、经无毒筛选的 ChatGPT 日志。
- 域外真实评分只覆盖文档生成与数学辅导，尚缺少多语言、专业领域、工具使用和复杂个性化任务验证。
- 三轮 RL 不能充分检验长期目标变化、累积误解或长期满意度。
- WildBenchV2 的最终评测描述主要针对助手生成回答，**并非真实用户参与的长期交互评测**。

### 8.5 奖励利用与安全边界
- 同一模拟器同时负责互动与打分，助手可能学会迎合其偏好，而非改善真实用户收益。
- 论文未系统检验奖励投机、模拟器适应性失效或策略分布变化后的稳健性。
- 满意度也不能替代正确性与安全性：合理拒绝可能被用户低评分，直接优化满意度需配合独立安全约束。

### 8.6 成本与统计证据仍不完整
- RL 计算节省没有统一计入合成标注与模拟器训练成本，也没有充分报告实际时间或经济成本。
- 真实性和 RL 指标缺少全面显著性分析。
- 所以论文支持“LES 是一种有前景的高效奖励来源”，但尚不足以证明它能普遍取代外部裁判或真实人类反馈。
