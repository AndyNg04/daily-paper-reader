Abstract 

Multi-agent systems promise to solve problems by bringing together information beyond the reach of any individual agent. Retrieval and tool use can distribute this information across agents, making communication essential to collaboration. A central challenge is keeping crucial evidence visible in each agent’s context as messages accumulate. Repeated information can crowd out rare, decisive evidence. Models of cortical circuits suggest a principle for addressing this imbalance: inhibition can selectively suppress shared inputs while preserving sensitivity to weaker signals. We adapt this principle into inhibitory message passing, a training-free communication router that cancels redundant evidence separately for each evidence sentence and receiver. Each round, it forwards evidence sentences restated in agents’ messages, delivering each at most once to receivers whose own evidence lacks it and excluding the senders’ reasoning and answers. Against standard message passing, accuracy in peer groups rose by 39–77 percentage points across three benchmarks, and tokens per run fell by 10–46%. Gains held across seven open models spanning four to thirty-two billion parameters and two commercial models, in groups up to sixty-four agents, and across multi-agent architectures including peer-to-peer, orchestrator–worker, and multilevel hierarchical organizations. These findings support a scalable design pattern for more accurate and token-efficient multi-agent reasoning. 

# 1 Introduction 

A group of agents can collectively possess all the evidence needed to solve a task and still reach the wrong conclusion. Retrieval and tool use give agents access to different evidence, but communication does not guarantee that these pieces are combined (Anthropic, 2026). Evidence shared by many agents can recur throughout a discussion, while private evidence held by individual agents receives little attention or never reaches the decision maker. Hidden profiles make this problem explicit: the shared evidence favours a wrong answer, and identifying the correct answer requires combining private evidence (Stasser and Titus, 1985). Language-model groups exhibit this failure, sometimes remaining less accurate than a single agent given all the evidence (Li et al., 2026b; Anthropic, 2026). Scaling multi-agent systems raises the stakes of communication design: coordination can yield diminishing returns, and errors can propagate across agents (Kim et al., 2025). Standard message passing can amplify the imbalance between shared and private evidence. Each sender’s message reaches its receivers as written, carrying both the evidence it restates and the sender’s reasoning and answer, whether in a debate between peers or a worker’s report to its lead (Du et al., 2024). Hearing every sender increases the input each receiver must process, and repetition can sway a model’s judgment (Xie et al., 2024; Schuster et al., 2026). Restricting the number of senders keeps inboxes smaller but risks excluding the few agents holding decisive evidence. How can we design multi-agent communication that preserves accurate collective reasoning as groups grow, despite increasing information load and reinforcement of shared mistakes? 1arXiv:2610.24718v1 [cs.AI] 17 Oct 2026 Models of cortical circuits suggest a principle for regulating this information flow: inhibition can balance excitation input by input, counteracting strong or shared drive while preserving responsiveness to weak and changing inputs (van Vreeswijk and Sompolinsky, 1996; Vogels and Abbott, 2009; Renart et al., 2010; Rostami et al., 2024). We propose inhibitory message passing as a communication design pattern based on this principle (Figure 1). It couples broad access to distributed evidence with cancellation tailored to each evidence sentence and receiver. A training-free communication router forwards evidence sentences restated in agents’ messages, delivering each at most once per round to receivers whose own evidence does not contain it. Agents continue to reason and produce answers, while the router excludes the senders’ reasoning and answers. The router requires no additional model calls. Across the evaluated benchmarks, inhibitory message passing improved group accuracy while reducing token use. The gains persisted across the tested model families, group sizes and communication architectures (Figure 2). Controls showed that limiting inbox size alone did not reproduce these gains. Preserving access to evidence holders, cancelling redundant input for each receiver, and forwarding the evidence itself without the senders’ reasoning and answers all mattered (Figures 3 and 4). Together, these results support a communication design pattern for maintaining accurate and efficient collective reasoning as groups grow. 

# 2 Inhibitory message passing 

2.1 Distributed evidence 

In a multi-agent system, N agents work on a task together, and each agent’s context holds the task, the evidence the agent has and whatever arrives from the others. The evidence is of two kinds. Shared evidence is what every agent has, such as a chart they all read. Private evidence is what one agent alone has, such as the result of its own tool call or search; we call that agent the holder of that evidence. In any architecture, agents pass on what they hold: each message carries the evidence its sender relies on and the sender’s reasoning and answer. The communication rule, which decides what from other agents enters an agent’s context, therefore determines what each agent can combine. Figure 1a gives an example. Agents diagnosing a patient with chest pain all read the chart, which suggests a heart attack, and three of them query their own tools, each obtaining one result. Together the results rule out a heart attack and point to an aortic dissection, but no agent holds more than one of them: the shared evidence favours a wrong answer, and only the private evidence combined reveals the correct one. Tasks of this kind are hidden profiles (Stasser and Titus, 1985), and our benchmarks are built this way: every agent receives the same shared evidence, each private evidence sentence is given to one holder, and the shared evidence alone leads to a wrong answer or to none (Appendix A.1). The agents communicate in rounds: in round 0 each agent answers alone, and in each later round it reads its own evidence, its previous message and an inbox, and writes a new message with its reasoning and answer. The two conditions differ only in the inbox (Figure 1b). Under standard message passing, the inbox holds the senders’ messages as written, so the shared evidence returns in almost every message with the answer it supports, and the receiver in the example concludes heart attack, as most of its senders did. Under inhibitory message passing, a router builds each inbox from the same messages. When a sender’s message restates one of its own evidence sentences, the router forwards that evidence sentence, once per round, to every receiver that lacks it, and nothing else of the message. What reaches the receiver is the private evidence of others, and with the normal troponin and the unequal arm pressures in view, the same receiver concludes that the cause is a dissection. 2.2 The routing rule 

Under both conditions every agent writes a message each round, and the group’s answer is read from these messages. The router changes only what a receiver gets from the senders it hears, by three rules (Figure 4a). (1) Evidence, not messages: when a sender’s message restates one of the sentences the sender itself holds, that original sentence, not the message, is what can travel. (2) Once per round: however many senders restate the same sentence, the receiver gets it once. (3) Only if missing: a sentence already among the receiver’s own evidence is not delivered. Nothing else of a message travels, neither the sender’s reasoning nor its answer. 4.2 The gain held across models and architectures 

Scaling or swapping the language model did not remove the bottleneck of standard message passing. On HiddenBench at N = 16 , the router outperformed standard message passing in all seven open models, Qwen3 from 4B to 32B parameters among them (76–89% against 6–16%), and in both commercial models, GPT-6 Luna and Claude Haiku 5.5 (Figure 2d; Appendix E); in the pre-registered commercial evaluations across group sizes, group accuracy rose by 63 and 59 percentage points. Centralizing the decision in an orchestrator lead or a hierarchical head did not rescue standard message passing either (Figure 2e), as the same communication rule carries the staff’s reports up to each lead. Averaged over group sizes on HiddenBench and the decoy puzzles, every decider scored 5% or less under standard message passing and 36–68% under the router. At N = 32 , cancellation shrank the decider’s prompt by roughly four fifths in orchestrator–worker teams and by almost half in hierarchical teams (Table F.2), which cut total run tokens by about a tenth once the workers’ own task prompts are counted (Figure 2f). Within inhibitory message passing, peer plurality voting remained 16–45 percentage points more accurate than single-decider teams, even though the orchestrator lead’s final inbox contained 81–91% of the private evidence sentences (Figure F.1). How the group combines evidence and selects its answer therefore remains consequential after communication improves. Assigning the holders was not what made the difference. When 32 agents instead searched MuSiQue for their own paragraphs, so that an evidence sentence could have one holder, several or none, the router still exceeded standard message passing by 19–32 percentage points at fewer tokens (Appendix G and Figure G.1). 

4.3 Cancellation absorbs the copies, so every holder can be heard 

The two rules of Equation (1b), once per round and only if missing, are what kept the inbox, and with it accuracy, flat as the group grew. On HiddenBench, the number of times each shared evidence sentence arrived at a Qwen3-8B inbox rose from 1.9 at N = 4 to 41.3 at N = 64 , yet the router cancelled every one of them, because every receiver already held these sentences. Delivered tokens therefore stayed flat while arriving ones grew, the scaling sketched in Figure 1c: at N = 64 , 3,641 tokens of evidence sentences arrived per inbox and 85 were delivered (Figure 3a). At the same time, each missing private evidence sentence reached 80–81% of the receivers lacking it at every group size and failed to arrive only when its holder had not yet restated it. Removing both rules (once per round and only if missing) shows what the cancelled copies would have done. With all restated copies passed through, accuracy at N = 16 and 32 fell to 42–53% on HiddenBench and 7–24% on the decoy puzzles, at 2.4–4.7 × the router’s tokens (Table H.3). On the puzzles, this accuracy fell steadily as N grew from 4 to 32 for both models, whereas the router remained stable (Appendix H.1). Even in single-receiver tests without multi-agent interaction, repeating each shared sentence eight times reduced accuracy for both models on HiddenBench and the puzzles (Appendix H.1): repeated copies alone degrade reasoning. Keeping once per round but dropping only if missing separates the two: under deduplication only, each restated sentence arrives once but nothing is subtracted, so one copy of every shared evidence sentence still 8arrives. Cut to the router’s inbox size (the number of sentences the router delivers that round), it reached 56–81% on HiddenBench and only 25–48% on the puzzles, because the shared evidence consumed the slots; without a size limit it came within 6–15 points of the router at 13–16% more tokens (Appendix H.2). With one holder per private evidence sentence, the once-per-round rule already removes all but one copy of each shared evidence sentence, and the only-if-missing rule removes that last copy (Appendix C.3); the first accounts for most of the gain over all restated copies and the second for the rest. 4.4 What must travel: the original evidence sentence, not the sender’s restatement of it 

Rules (2) and (3) decide how many copies get through; rule (1) decides what each copy is. Before testing it, we ask whether a filter that knows less could do the router’s job at the same inbox size. None did (Figure 4b). A random sample of the same size from all arriving copies, with no threshold per evidence sentence, rarely selected the rare missing evidence sentences (Appendix H.2) and fell 68–86 percentage points below the router, and an LLM summary of each round’s messages, written within the router’s inbox length in words, reached 2–9%, no better than the random sample; the opposite remedy, a full inbox history added to standard message passing, reached 5–22% at more than twice its tokens (Appendix H.2). The text that carries each evidence sentence then mattered (Figure 4b). Forwarding the sender’s sentence that restates each evidence sentence instead of the original evidence sentence, with the selection rule unchanged, lowered accuracy ( −51 to −35 points). Claims an LLM extracted from the messages, without seeing the original sentences, fell short in the same way ( −58 to −23 points), whereas a neutral LLM paraphrase of each evidence sentence nearly matched the original ( −2 to 0 points; Appendix H.3): what matters is where the text comes from, not its exact words. The logs show why (Appendix H.3): 59–73% of the senders’ sentences came from agents then arguing for a wrong answer, and 38–68% restated, beside the missing evidence sentence, one the receiver already held, which carried the decoy back into the inbox. Reintroducing the senders’ reasoning and answers beside the routed evidence sentences had the same effect as forwarding the senders’ sentences: at N = 16 on HiddenBench it lowered group accuracy from 88% to 44% for Qwen3-8B and from 88% to 54% for Olmo-3-7B (Appendix H.4). # 5 Related work 

Like human groups, language-model collectives overweight shared information and underuse evidence held by a small minority (Gigone and Hastie, 1993; Lu et al., 2012; Li et al., 2026b); agents withhold information (Cemri 9et al., 2025) or gather enough of it yet fail to combine it (Zhang et al., 2026). Even when every agent sees the whole problem, debate often does no better than independent sampling or self-correction at an equal or lower budget (Wang et al., 2023; Huang et al., 2024; Smit et al., 2024; Choi et al., 2025; Bertalaniˇ c and Fortuna, 2026). Recent interventions preserve dissent, optimize or prune the communication graph, prompt agents to surface private evidence, choose who speaks, or route messages by stated needs (Nguyen et al., 2026; Zhuge et al., 2024; Zhang et al., 2025a,b; Li et al., 2026b; Babu et al., 2026; Zeng et al., 2025; Tambwekar et al., 2026); others compress messages or merge similar ones for each receiver (Huang et al., 2026; Guan et al., 2026). None removes the evidence a receiver already holds or delivers each evidence sentence once however many senders repeat it, although the value of a message depends on what its receiver can already see (Xie et al., 2026). Individual components of our router have precedents: quotes verified against the source text (Khan et al., 2024), shared blackboards (Erman et al., 1980; Han and Zhang, 2025), evidence pooled for a judge without the agents’ answers (Ji et al., 2026), and debate without speaker labels (Choi et al., 2026). Counting a repeated source once is the norm of probabilistic inference and decentralized data fusion (Pearl, 1988; Grime and Durrant-Whyte, 1994); its violation when agents reuse each other’s reports is called “data incest” (Krishnamurthy and Hoiles, 2014; Jain and Krishnamurthy, 2025). People neglect such correlations (Enke and Zimmermann, 2019), and LLM aggregators count a restated copy as a fraction of a new observation unless prompted otherwise (Gao et al., 2026). Brain-inspired designs have treated agents as cortical areas in a sparse debate graph (Sun et al., 2025). Our contribution combines source grounding, deduplication, and receiver-specific subtraction into a per-sentence, per-receiver communication rule (Appendix K) and demonstrates its scaling and architectural generality. 

# 6 Discussion 

As a group of agents grows, its communication has to keep the evidence within reach while limiting the repetition. In our experiments, inhibitory message passing improved accuracy and reduced token use by forwarding the evidence sentences that receivers lacked and cancelling the repeated copies, and no filter that merely shortened the inbox reproduced the gain (Figure 4). A communication rule, then, has to account for two things at once: the evidence a message refers to and the evidence its receiver already holds. What travels matters as much as how much. Forwarding the original evidence sentence lets a receiver weigh it without the sender’s preferred answer: the sender’s sentence and the claims an LLM extracted from the messages carried that answer along and cost accuracy, whereas a neutral paraphrase did not. Letting the senders’ reasoning and answers back in beside the routed evidence undid much of the gain, as knowing the other members’ preferences impedes human groups on hidden profiles (Mojzisch and Schulz-Hardt, 2010). Excluding the senders’ conclusions thus closes one route by which a shared mistake spreads. Current models know that consensus is not evidence but do not act on that knowledge unprompted (Anthropic, 2026); the router does not ask them to. For system design, the rule separates the transport of evidence from the exchange of answers (Table C.1). Applying it needs a reliable link between a message and the evidence it refers to. Word overlap with the holder’s own sentences provides that link without asking anything of the agents; where documents already carry identifiers, a source tag can provide it directly, as with the declared tags of Appendix C.4. With that link in place, repeated copies of one source count once while independent sources stay distinct, and a receiver’s prompt stops growing with the group. Shorter inputs help in their own right, since models use long contexts less reliably even when the extra text only duplicates the relevant passages (Liu et al., 2024; Levy et al., 2024), but only if the filter keeps the missing evidence: delegation, full inbox histories and LLM summaries did not substitute for the cancellation. The gains across models and architectures suggest that the rule can serve as one reusable component in several forms of agent organization. 10 7 Limitations 

Our experiments concern tasks in which agents combine distributed evidence to reach a scored answer, and most scaling comparisons keep the required evidence fixed as the group grows. The router bounds the repetition; the distinct evidence a receiver must process can still grow. When the required evidence grew with the group, accuracy declined as delivery and integration both became limiting (Appendix I.1). The results therefore establish scalability with respect to repeated evidence; growth of the underlying information is further work. The rule also depends on identifying which evidence a message refers to and what the receiver already holds. Our implementation matches messages against known evidence sentences (Appendix C.1). Less structured settings need reliable provenance, including the distinction between repeated reports of one observation and independent observations of the same claim; errors in it would suppress useful evidence or let redundant input accumulate. The router does not assess the truth or credibility of what it forwards: a planted false sentence cost accuracy (Appendix I.3), and the rule has no way to withdraw evidence that is later corrected or outdated. Learning source reliability and revising or withdrawing evidence are open extensions. Finally, the router forwards original evidence and excludes the senders’ reasoning and answers. Coding, planning and distributed computation may require workers to exchange intermediate results that no original evidence contains, and our experiments do not establish when excluding them would impede collaboration. Extending the rule to such tasks means preserving useful intermediate results while still controlling repetition and the spread of mistaken conclusions. 

# 8 Conclusion 

The circuit models that gave the router its rule also suggest where to look next. The router adapts a simple principle from them, in which inhibition grows with the excitation it meets and a neuron responds to the small difference between the two: strong or shared drive is largely counteracted, while a weak input still gets through (van Vreeswijk and Sompolinsky, 1996; Vogels and Abbott, 2009; Renart et al., 2010; Rostami et al., 2024). Equation (2) is this balance taken input by input, with an evidence sentence as the input and a receiver as the neuron, and our controls test only this arithmetic: cancellation that grows with repetition carried most of the gain, its dependence on what the receiver holds carried the rest, and a cap on inbox size alone, the analogue of balancing excitation and inhibition only in sum, reproduced neither effect. The cortex is far richer than this cartoon, in its interneuron types, its timescales, its divisive as well as subtractive inhibition and its plasticity (Isaacson and Scanziani, 2011; Vogels et al., 2011); none of that is modelled here, and the connection is a shared computational principle, not a shared mechanism (Appendix J). Those features are also the next steps for message passing between agents: inhibition that is learned could cancel, per receiver, the sources that have misled it before; inhibition that divides could weight a sentence by its independent sources; inhibition over several timescales could let delivered evidence fade or be withdrawn. One piece of this arithmetic already changes what a group of agents can do.

A.1 Benchmarks 

Every item gives all agents the same shared evidence and gives each private evidence sentence to one agent, its holder. The three benchmarks differ in what the shared evidence does (Table A.1). In HiddenBench (Li et al., 2026b) and in the decoy puzzles, navigation stories generated with Enigmata (Chen et al., 2025), it favours a wrong answer, so a group that follows what everyone knows goes wrong together; in MuSiQue-Ans (Trivedi et al., 2022) it merely falls short, and the private paragraphs have to be combined across hops. Each benchmark is split once by item hash into a development set and a test set. C.1 Matching 

A message restates one of its sender’s evidence sentences when it repeats enough of that sentence’s distinctive words. Words are weighted by inverse document frequency over the item’s U evidence sentences, idf = ln U +1 df+0 .5 ,and a message sentence counts as a restatement when it covers at least half of the evidence sentence’s idf weight, or holds at least two of its rare words (words in at most two of the item’s evidence sentences), at least one of them absent from the question and options. The router forwards whole sentences, so evidence stated together is not split, and it runs centrally, although the rule could run at each receiver. It identifies a piece of evidence by its sentence, which stands in for the evidence’s source only when the sentence has a single source.

When each private evidence sentence has one holder, as in every comparison with assigned holders, it arrives at most once ( Eiu ≤ 1), so cancellation acts only on the shared evidence sentences, which every receiver holds: once per round removes all but one copy of each, and only if missing removes that last copy. C.5 The rule as a design pattern 

For system designers, Table C.1 states the rule in the form of a design pattern: the problem it addresses, the solution, its consequences, and what it does not do. 

Table C.1: Inhibitory message passing is a design pattern for routing evidence between agents. Token savings: the two main models, against standard message passing. 

Problem In any system whose agents pass on what they hold, messages repeat the evidence every agent has, while an evidence sentence one agent holds reaches few receivers. The repetition grows with the group. 

Solution Each round, forward the evidence sentences each sender’s messages restate once to each receiver that lacks them, keyed on the source (here word overlap with the holder’s sentence; a source tag where available). Omit the senders’ reasoning and answers. 

Consequences Higher accuracy; 10–46% fewer tokens per run in peer groups; a shorter prompt for the decider; no model calls. 

Applies to Evidence that can be traced to original sentences, passed between agents in any architecture.

# D Pre-registered tests 

The confirmatory claims rest on 48 tests fixed before the test-set runs (Table D.1); 47 passed, and the exception is a test of timing, not of the gain. For each main model and benchmark, three tests ask whether inhibitory message passing beats standard message passing by at least 5 points averaged over N , beats the best prior-work baseline averaged over N , and beats its own inbox built from six random senders at the largest N . This late-evidence test failed for Qwen3-8B ( p = 0 .10 ) because the share it compares is a ratio, and standard message passing had almost no gain to lose: it gained 7 points over no communication with early evidence and 0 21 with late evidence, while the router kept 69 of its 75 points (Olmo-3-7B: 61 of 68). The router’s gain survives late evidence; the index measures it poorly when the baseline has nothing to lose. # F Team architectures 

In a team, Equation (1) holds at every level: a lead or head hears the staff that report to it, and a worker hears only the task its lead sends. Every round runs in phases, the workers first, then any team leads, then the decider, each 23 phase reading the reports of the one before. In an orchestrator–worker team the lead writes up to three tasks, one per line, and its workers receive them in turn; in a hierarchical team the head gives tasks to team leads in the same way, and each team lead to four workers. Every lead and head holds the question, the options and the shared evidence. Under the router a report is replaced by the evidence sentences it restates that the receiver lacks, and a team lead’s report also carries the received sentences it restates, so evidence sentences travel up to the decider verbatim. Fan-out/gather, which Saboo (2025) describes as a single pass, is here a lead that delegates nothing: in each round it reads every worker’s report, and the workers read its last message. The router raised group accuracy in every architecture and at every N (Table F.1, every run; Table D.1 and the levels of Section 4.2 apply the pre-registered exclusions, which move the gains by a few points). What changed for the decider shows in its inbox (Table F.2). Under standard message passing it held 2.6–76 copies of the shared evidence, more as N grew, and an orchestrator–worker lead saw 51–70% of the private evidence sentences; under the router it held no copy, and the lead saw 81–91%. At N = 32 the decider’s prompt shrank to 0.16–0.27 of its length in orchestrator–worker teams and 0.50–0.58 in hierarchical teams, and whole runs to 0.87–0.92 and 0.88–0.91, since the decider’s prompts are only 4–18% of a run’s tokens under standard message passing. The fan-out/gather lead reached 57–69% with the router and 1–7% without it, and a lead given all restated copies, still without reasoning and answers, scored 46–59 points below the router at N = 32 (pre-registered, Table D.1): removing the copies helped beyond removing the answers. Delivery is not the whole story. Under the router each decider still stayed 16–45 points below a peer group on the same items (Table F.1), although most private evidence sentences reached it (Figure F.1): a single decider is more exposed to its own reasoning errors than a vote.

# H Taking the router apart 

Sections 4.3 and 4.4 remove the router’s rules one at a time. This section adds what the main text leaves out, in four questions: what repeated copies do to a group and to a single receiver, whether a smaller inbox alone explains the gain, whether the text that carries the evidence matters, and what the senders’ reasoning and answers do once they are let back in. Table H.1 defines every variant by the rule it drops and what the receiver gets, and Table H.2 gives the levels of the variants it lists, on development items. Unless a caption says otherwise, all used both main models on HiddenBench and the decoy puzzles at N = 16 and 32. 

H.1 Repeated copies 

Under all restated copies, each restated evidence sentence arrives once per sender that restated it. On the puzzles, group accuracy then fell from 45% at N = 4 to 16% at N = 32 for Qwen3-8B and from 20% to 5% for Olmo-3-7B, while the router held 85–89% and 75–78%. The damage starts early: letting one, two or four copies of each shared evidence sentence through the router at N = 16 also lowered accuracy, from the first copy on the puzzles and by four copies on HiddenBench (Figure H.1). The group is not needed for this effect. Single receivers answered once from a fixed inbox on HiddenBench and the puzzles: each was an agent without private evidence, taken from a run of the router at N = 16 with its own evidence and round-0 answer (four HiddenBench tasks whose inboxes would overflow the context were left out), and its inbox held every private evidence sentence once and each shared evidence sentence up to eight times, with no answers. Eight copies of each shared evidence sentence lowered the share of correct receivers in all four settings: on HiddenBench from 78% to 70% for Qwen3-8B and from 67% to 44% for Olmo-3-7B, and on the puzzles from 75% to 25% and from 54% to 9%.

H.3 The text that carries the evidence 

The logs show why the sender’s sentence cost accuracy. Each delivered sentence restated an evidence sentence the receiver lacked, but 59–73% of them came from a sender then backing a wrong answer, and 38–68% also restated an evidence sentence the receiver already held. Some restate the original faithfully; others add a verdict, reverse a hazard or attach evidence about another option (Table H.4). On test items, against the original evidence sentence, the sender’s sentence lowered accuracy ( −51 to −35 points), as did the LLM-extracted claims ( −58 to 

−23), whose extractor never saw the original sentences and kept the senders’ inferences; the LLM paraphrase of the evidence stayed within −2 to 0 points of the original (the paraphrases were checked for length and kept numbers, not for meaning). Two further variants locate the effect: latest message only changed accuracy by −15 to −2 points, so the sentences restated in earlier rounds matter little, and cancellation still helped the sender’s 28 sentence, which scored +24 to +59 points above the sender’s sentence, all copies.

H.4 Reasoning and answers beside the evidence 

Letting the senders’ reasoning and answers back in beside the routed evidence sentences undoes much of the gain at N = 32 and on the puzzles as at N = 16 on HiddenBench (Table H.2, row “+ reasoning and answers”). Single receivers (Appendix H.1) show the pull directly: with every private evidence sentence in the inbox, they were correct in 95–100% of cases when eight messages with reasoning and answers backed the correct option and one the decoy, and in 11–35% when one backed the correct option and eight the decoy. 

# I Evidence growth and evidence quality 

The following development-set tests examine how accuracy changes when the required evidence grows, distractors accumulate, or a false sentence is planted. Inhibitory message passing retained its advantage over standard message passing with growing required evidence (Appendix I.1), distractor paragraphs (Appendix I.2) and a planted false sentence (Appendix I.3). 

I.1 Needed evidence that grows with the group 

In HiddenBench, the decoy puzzles and MuSiQue, at most four agents hold private evidence, so a larger group adds only agents with shared evidence. To let the needed evidence grow with the group, we generated elimination problems: the group picks the one option (a supplier, a venue, a suspect, . . . ) that no evidence sentence rules out. Each wrong option is ruled out by one private evidence sentence (“Supplier Onyx failed the March safety inspection, so it cannot get the contract”), nothing positive is said of the answer, and the shared evidence favours a decoy. I.2 Distractor paragraphs 

On MuSiQue, each agent beyond the holders also held a distractor paragraph from the question’s source that neither answers it nor is shared, so a group of N holds N − H distracting paragraphs. The router led standard message passing by +25 to +36 points at every N from 4 to 16, but its accuracy fell with N , from 56% to 45% for Qwen3-8B and from 47% to 37% for Olmo-3-7B. The distractors hurt whether or not they are routed: against the same items without them at N = 16 , they changed the router’s accuracy by −11 [ −17, −6] and −17 [ −24, 

−11] points and that of full information by −11 [ −16, −6] and −11 [ −18, −5]. 

I.3 A planted falsehood 

The planted-falsehood test adds one false “official update” favouring the decoy to one agent’s evidence in the HiddenBench profile at N = 16 . The router forwarded it only when restated. Although accuracy fell, inhibitory message passing remained substantially more accurate than standard message passing in both models (Table I.1), and its loss was smaller than that of full information. The router preserves an advantage in this test while leaving evidence verification to the receiving agents.

30 J The circuit analogy and its limits 

The analogy of Section 2.2 and Figure 1c is between rules for controlling input, not between mechanisms. In circuit models, inhibition can track excitation input by input (detailed balance) or only in total (global balance) (Vogels and Abbott, 2009); Table J.1 maps these and the related circuit-model concepts onto the router.       

> Table J.1: Computational analogy between cortical circuit models and evidence routing. Circuit-model concept Router counterpart neuron or local circuit receiving agent shared feedforward input evidence sentence initially held by multiple agents input to a subset of neurons evidence sentence initially held by only some agents recurrent excitation reinforcing influence of peers’ reasoning and answers excitation–inhibition balance input by input (detailed balance) cancellation computed per evidence sentence and receiver balance of total excitation and inhibition (global balance) limit on total inbox size, independent of content

The analogy stops at this arithmetic. Agents reason in language and the router operates on evidence sentences, not on currents: restatements are matched by word overlap, cancellation uses the identity of a sentence and the receiver’s initial evidence, and a sentence pools copies from many senders, so it does not denote one projection. Omitting reasoning and answers removes a source of recurrent influence within the analogy; cancellation per evidence sentence is its only subtractive operation.

Each operation of the router has a precedent, listed in Table K.1 with what it leaves open; what the router adds is their combination, per evidence sentence and per receiver, in the communication rule between reasoning agents.
