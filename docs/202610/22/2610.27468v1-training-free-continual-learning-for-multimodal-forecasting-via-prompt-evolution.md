## 摘要
传统上，要使预测系统适应不断变化的世界，就意味着重新训练。我们探讨：能否将时间序列预测中对不同机制的持续学习表示为一段文本——即通过基于结果的反思不断演化，并用于冻结的 LLM 预测器提示中的指导文本块？在一个更新后的多模态基准上（每个时间窗口均配有通过网络检索的新闻；数据包括每周搜索指数、每日汇率和每日大宗商品数据），我们在严格的污染控制下进行 GEPA 风格的提示演化，以防止时间序列基准中常见的数据泄漏：预测器的知识截止日期早于所有评估窗口。由 Llama-3.3-70B 承载的、经演化得到的 900 词指导文本，在留出数据上优于时间序列基础模型（TSFM）：GM MASE 为 0.776，而 TabPFN-TS-3 为 0.898；迁移到更新的模型时性能没有可测量的损失，且更新成本以美元计，而非以 GPU 天计。我们分析了这一迭代过程：循环外的收益主要集中在首次反思中；若没有未参与优化的监测集进行裁决，循环内的改进会将循环外收益夸大 2 至 3 倍；仅以误差为目标会在不知不觉中抑制文本模态。我们还提出两项扩展。第一，将指导文本编译为可执行代码，并将 TSFM 作为可调用工具，可确定性地恢复大部分收益。第二，消融实验表明，预测跨度较短时，该方法的优势更大；移除新闻文本并不会损害受指导的预测器，这与文本的价值在学习过程中被提炼进策略的解释一致。我们认为，持续提示演化是多模态预测中一种实用且无需训练的重新训练替代方案。

## Abstract
Adapting a forecasting system to a changing world classically means retraining. We ask whether the task of continually learning regimes for time series forecasting can be represented by a piece of text: a guidance block, evolved by outcome-driven reflection and used in a frozen LLM forecaster's prompt. On a refreshed multimodal benchmark (weekly search indices, daily currencies, daily commodities, each window paired with web-retrieved news), we run GEPA-style prompt evolution under strict contamination control to prevent the data leakage common in timeseries benchmarks: the forecaster's knowledge cutoff predates every evaluated window. A 900-word evolved guidance carried by Llama-3.3-70B beats TimeSeries Foundation Models (TSFMs) on held-out data (GM MASE 0.776 vs. 0.898 for TabPFN-TS-3), transfers to more recent models without measurable loss, and costs dollars rather than GPU-days to update. We characterize the loop: out-of-loop gains concentrate in the first reflection, in-loop improvements overstate out-of-loop gains 2-3x unless an untouched monitor arbitrates, and error-only objectives silently suppress the text modality. We provide two extensions. First, compiling the guidance into executable code with a TSFM as a callable tool recovers most of the gain deterministically. Second, ablations show the advantage widens at short horizons and that removing the news text does not hurt the guided forecaster, consistent with the text's value being distilled into policy during learning. We argue that continual prompt evolution is a practical, training-free alternative to retraining for multimodal forecasting.

## 1. 核心问题与整体含义

### 研究动机
- **时间序列预测需要持续适应分布变化**：汇率、商品价格及搜索热度会受到政策、季节和突发事件影响，静态预测策略可能失效。传统方案依赖重新训练或微调，增加了计算和维护成本。
- **数值模型与语言模型各有短板**：
  - 时间序列基础模型（TSFM）善于处理数值历史，但通常无法直接利用新闻叙事。
  - 大语言模型（LLM）可以理解新闻，却容易将近期变化或新闻情绪外推成不合理的长期趋势。
- **既有评估可能受到知识污染影响**：若预测窗口早于 LLM 的知识截止时间，模型可能利用记忆而非真正预测。

### 核心问题与意义
论文研究：**能否冻结所有模型权重，仅通过持续修改一段预测指导文本，实现低成本的预测策略学习与更新？**

其核心转变是将“学习状态”从模型参数迁移到约 900 词的提示文本，使更新具有可读、可比较、可回滚、跨模型迁移等特点。这里的“免训练”指**不更新模型权重**，并不意味着不使用历史真实结果进行优化。

## 2. 方法论：核心思想与算法流程

### 2.1 优化对象：预测指导，而非模型参数
- 预测器接收：
  - 96 步历史数值；
  - 预测时点可获得的新闻、背景、节假日和相关序列信息；
  - 固定的数据说明；
  - 待优化的指导文本 \(g\)。
- 普通提示版本限制在约 1,000 词以内。
- 默认预测器为 **Llama-3.3-70B**，反思器为 **Claude Opus 5**；所有模型权重保持冻结。

### 2.2 GEPA 风格的结果驱动演化
每轮包含四个步骤：

1. **预测**
   - 使用当前指导预测训练小批次，典型批量为 16 个窗口。
   - 输出预测值和简短理由。

2. **反思**
   - 反思器读取完整轨迹：数值历史、新闻、预测、真实结果、误差及预测理由。
   - 据此重写指导，将具体失败归纳为通用规则。
   - 禁止写入具体序列名称、预测起点之后的特定结果等。

3. **接受门控**
   - 子指导必须在该小批次上优于父指导，否则被丢弃。
   - **正文方法明确使用同一个小批次进行反思和门控**，因此门控本身并不是独立泛化检验。

4. **选择与合并**
   - 在固定选择集上评估候选。
   - 使用实例级 Pareto 保留机制：在至少一个窗口上表现最佳的候选可被保留，并按独占最佳窗口数抽样父代。
   - 每四轮尝试一次具有互补性的候选合并。

### 2.3 三层评估机制
- **选择集**：反复参与候选筛选，结果天然偏乐观。
- **独立监测集**：原则上不参与优化决策，用于衡量泛化差距。
- **最终测试集**：用于报告最终性能。

这一设计旨在区分“提示越来越适合优化数据”和“策略真正具有泛化能力”。

### 2.4 学到的主要策略
数值优先指导 \(G_{\text{num}}\) 的实质是一套保守的时间序列规则：
- **每日汇率、商品**：以最新值和近期均值构造锚点，限制漂移并使其逐步衰减。
- **阶梯式、低波动序列**：优先保持当前平台，而非人为制造变化。
- **每周搜索指数**：优先参考去年同期形状，处理季节峰值、峰后衰减和淡季下界。
- **新闻使用门控**：仅对有日期、可量化且位于预测期内的事件作有限调整，避免重复计入已反映在价格中的消息。

另一个指导 \(G_{\text{text}}\) 加入方向性目标，以避免单纯追求误差最小化导致模型全面回避文本和方向判断；不过其目标权重等细节在提供文本中交代有限。

### 2.5 扩展：将指导编译成代码
- 将指导容量扩展至最多约 6,000 词。
- 编码 LLM 将指导编译为确定性的 Python 预测函数。
- 程序可以调用 **TabPFN-TS-3**，按序列类型决定信任、混合或忽略其预测。
- 最后由 LLM 在严格约束下决定是否修正代码输出。

需要区分：**代码阶段是确定性的，但论文表中的完整编译系统仍包含 LLM 仲裁，不是完全确定性的端到端系统。**

### 3.2 污染控制
- Llama-3.3-70B 的知识截止时间为 2023 年 12 月，早于其评估窗口。

## 6. 主要结论与发现

- **短文本可以承载有效的预测策略**：冻结 LLM 加上指导后，总体优于所比较的零样本 TSFM。
- **收益高度依赖领域**：商品提升最大，不能概括为所有时间序列任务都领先。
- **首次反思贡献最大**：后续多轮演化通常不能显著超过首次得到的强候选，候选合并也未显示稳定收益。
- **环内收益会高估泛化收益**：优化数据上的改进约为独立监测改进的 2—3 倍。
- **指导具有跨模型可迁移性**：从 Llama 迁移至 Opus 后，差异在约一个标准误以内；这不等于已证明严格等效。
- **短期预测优势更强**：
  - 12 步：0.776 对 0.898；
  - 3 步：0.291 对 0.434，误差约降低 33%。
  - 专门为 3 步重新演化，没有优于截断 12 步预测。
- **推理时新闻不是主要增益来源**：
  - \(G_{\text{num}}\) 去新闻后由 0.776 改善至 0.761；
  - \(G_{\text{text}}\) 由 0.824 改善至 0.780。
- **训练阶段文本有小幅校准价值**：完整文本反思与无文本反思的配对实验分别为 0.741 和 0.768；但无文本版本已恢复绝大部分收益。
- **学习式组合优于简单 TSFM 平均组合**：编译系统总体为 0.807，搜索指数达到论文实验中的最佳值 1.042，但总体并未超过最佳纯提示方法。

- **学习产物可审计**：规则变化可以直接阅读、比较和回滚，而非隐藏在参数中。

- **文本到程序的扩展有实用价值**：可将自然语言策略转化为更可复现、低运行成本的代码。

## 8. 不足与局限

### 8.1 泛化与应用范围有限
- 单一基准无法代表医疗、工业、能源负荷等其他预测场景。
- 保守、接近持平的策略适合本文数据和 MASE 目标，未必适合强趋势或极端冲击环境。
- 未评估交易收益、风险控制、预测区间或决策成本，不能由误差下降直接推导投资价值。

### 8.2 多模态解释应保持克制
- 主收益来自数值策略，而非持续依赖新闻理解。
- “新闻知识被蒸馏进策略”与实验结果一致，但并非唯一解释；数值反馈及模型已有先验也贡献了大部分能力。
- 数据中的新闻可能已被市场定价，限制了对真正前瞻性、决定性文本的检验。

### 8.3 评估协议仍有需要澄清之处
- 正文反思与门控使用同一批数据，与部分“新鲜窗口门控”的表述不完全一致。
- 一方面称监测集不参与决策，另一方面又强调其裁决和确定冠军的作用；需更明确区分事后分析与实际选择。
- 多项消融和再适应结果均在同一最终层级报告，特别是观察到搜索领域失效后再修复并报告该层级新最佳值，**不能自动等同于在全新未来数据上验证成功**。

### 8.4 机制解释与统计证据仍有限
- 将首次反思后的平台期归因于文本容量，是合理假设，但未通过系统改变字数上限充分验证。
- 编译版本同时改变了容量、执行方式和工具使用，难以单独归因于“更大容量”。
- “一个标准误以内”只表示未检测到明确差异，不是严格等效检验。
- 多候选、多个组合和多项分析带来多重比较风险，文中未系统说明校正方式。

### 8.5 持续学习与成本优势尚需长期验证
- 仅完成一次再适应，缺少多时期滚动评估、累计遗忘及错误更新恢复实验。
- 提示更新虽便宜，部署仍依赖大模型推理；缺少与轻量统计模型、长期推理成本及重训练方案的完整比较。

**总体而言，论文有说服力地展示了“通过可审计提示学习预测策略”的可行性；但更强的结论应限定为该基准上的低成本策略适应，而非已经全面证明多模态预测能力或长期持续学习优势。**
