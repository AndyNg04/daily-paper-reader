## 摘要
机器人可以通过向旁观者求助来从故障中恢复，但有效的人在回路中的故障恢复需要在沟通中考虑人们的知识差异。先前的逆语义学研究使用单一听者模型生成求助请求，尚未检验听者知识差异的影响。我们提出“人机交互中的听者差异”（LD-HRI），它集游戏、数据集和基准于一体，通过人类听者的表现评估请求发出者。我们的评估在控制听者所掌握信息差异的条件下，考察请求的属性、大语言模型（LLM）请求发出者，以及基于逆语义学的请求选择算法。该语料库包含446条由人类撰写的请求和1,302次听者试验。此外，我们还让70名人类听者在560次试验中评估了24条预先生成并固定的大语言模型请求。在全部四项任务中，模型撰写的请求对应的新手成功率在描述性统计上均较高；然而，两种来源的请求都存在显著的专家与新手表现差距，其中大语言模型请求的差距为16个百分点。LD-HRI使这些差距可被量化，为在人机交互和人与智能体交互中设计更稳健的沟通方式奠定了基础。

## Abstract
Robots can recover from failures by asking bystanders for help, but effective human-in-the-loop recovery requires communication that accounts for differences in people's knowledge. Prior inverse-semantics work generates requests using a single listener model, leaving differences in listener knowledge untested. We introduce Listener Differences in Human-Robot Interaction (LD-HRI), a game, dataset, and benchmark that evaluates speakers through human listener performance. Our evaluation examines request properties, large language model (LLM) speakers, and inverse-semantics request-selection algorithms under controlled differences in listener information. The corpus contains 446 human-written requests and 1{,}302 listener trials. We additionally evaluated 24 frozen LLM-written requests with 70 human listeners across 560 trials. Novice success is descriptively higher with model-written requests across all four tasks, yet both request sources leave substantial expert--novice gaps, including 16 percentage points for LLM requests. LD-HRI makes these gaps measurable, providing a foundation for designing more robust communication in human-robot and human-agent interaction.

## 1. 核心问题与整体含义

- **研究问题**：机器人故障后向人求助时，同一句请求可能对掌握机器人部件、操作界面或环境信息的人有效，却让缺少这些信息的人无法完成任务。既有求助语言生成方法通常采用单一听者模型，难以衡量这种差异。
- **研究动机**：仅判断请求是否清楚，或只测量总体任务成功率，都可能掩盖“专家能完成、新手却不能完成”的沟通鸿沟。论文主张以**真实人类听者的行动结果**检验机器人请求是否提供了足够的信息。

## 2. 方法论：LD-HRI 游戏、数据集与基准

- **核心设计**：构建 *Listener Differences in Human-Robot Interaction*（LD-HRI）。发话者根据机器人目标撰写一条求助请求；听者阅读后在网页游戏中执行任务，不能追问。系统固定请求措辞，改变听者可见的参考信息，并记录客观任务结果、操作轨迹和主观体验。
- **四类信息差异**：
  1. **遥操作**：专家可见按键与运动方向的对应关系，新手不可见。
  2. **硬件维修**：专家可见部件技术名称，新手需要依靠颜色、形状等可见特征辨认。
  3. **导航取物**：专家预先获得场景信息；新手起初缺少房间和物体标签，但可通过进入房间发现部分信息。
  4. **导航并维修**：同时隐藏新手所需的房间与部件标签。
- **评估与算法流程**：
  - 以游戏最终状态判定成功，而非依据听者自评；同时统计耗时、操作成本、NASA-TLX 工作负荷，以及请求的清晰度和有用性评分。

## 6. 主要结论与发现

- **信息差异确实影响任务结果**：在全部 1,302 次人写请求的听者试验中，专家成功率为 **76.2%**，新手为 **47.9%**；在用于控制请求措辞的 321 条配对请求分析中，两者分别约为 **76.9%** 和 **60.1%**，相差 **16.8 个百分点**。这两组数字对应不同统计样本，不应混用。
- **新手承担更高负荷**：按听者汇总后，新手平均 NASA-TLX 为 **47.4**，专家为 **37.7**；两组中，请求清晰度越高，报告的工作负荷通常越低。
- **补足不可自行获得的信息可能很关键**：硬件维修中，仅用部件名称的请求对应专家／新手成功率为 **88.9%／7.3%**；名称加可见描述时为 **93.6%／57.9%**；仅用可见描述时为 **85.7%／68.8%**。这是观察到的关联，尚不能证明增加描述本身造成成功率提升。
- **LLM 请求仍有沟通鸿沟**：24 条固定模型请求对应的专家成功率为 **73.9%**、新手为 **57.5%**，相差 **16.4 个百分点**。模型请求在四项任务中的新手成功率均高于较早收集的人写请求结果，但该跨研究比较不是因果实验。
- **缩小差距不等于整体更好**：\(S_1\) 所选请求对应专家／新手成功率为 **87.5%／25.0%**；\(S_2\) 均为 **62.5%**。后者的差距虽消失，专家成功率却下降，而且相同的总体成功率还可能掩盖不同场景中的失败。

## 7. 优点

- **固定请求、操纵信息**：能够比只比较不同请求的总体表现更直接地揭示听者信息差异。
- **以真人行为为主要结果**：任务成功由实际操作状态判定，并辅以操作日志和工作负荷，避免只依赖模型代理或主观评分。
- **覆盖多种知识缺口**：区分控制映射、部件识别、场景信息及其组合，并注意到缺失信息是否可通过探索恢复。
- **基准目标明确**：不仅考察新手成功率，也考察专家表现和人的负担，避免用单一“差距”指标优化出不理想的结果。

## 8. 不足与局限

- **外部效度有限**：浏览器游戏、一次性文字请求与真实机器人现场不同；研究未覆盖语音、手势、澄清对话或实体操作风险。“专家／新手”的受控信息条件也不能代表现实中的全部知识与能力差异。
- **部分比较存在偏差风险**：四项任务并非只在信息类型上不同，组合任务还是后期加入的；参与者角色人数不平衡，招募样本中计算、工程或机器人相关背景占比较高。
- **请求属性与算法证据偏探索性**：可见描述的效果来自观察性分组，而非随机增删描述的实验；\(S_1\)、\(S_2\) 是在既有请求中回顾性选取，八个场景的结果不足以推断广泛部署效果。
- **LLM 评估范围有限**：每个模型每个场景仅有一条固定生成请求，未检验重复生成的波动，也未检验明确告知模型目标听者知识水平后的适应能力。论文还指出，LLM 后续研究有较多 NASA-TLX 问卷的六项评分均停留在初始中点，主观负荷结果需谨慎解读。

**总体而言**，论文最重要的贡献是提供了一个能将“请求说了什么”与“听者已知道什么”联系起来、并用真人行动检验的评估框架；它揭示了现有人写和模型生成请求的共同缺口，但尚未证明某一种生成方法能够因果性地弥合该缺口。
