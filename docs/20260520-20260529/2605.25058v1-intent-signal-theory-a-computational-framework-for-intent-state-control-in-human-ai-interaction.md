## 摘要
当前的人工智能交互模型将提示视为主要的交换对象，忽略了一个关键层：用户的潜在源意图，即先于并促使提示产生的目标状态。本文引入意图信号理论（Intent Signal Theory, IST），这是一个形式化了这一缺失意图层的计算框架。IST区分了四个通常被混为一谈的对象：潜在源意图（I*）、可观测意图代理（I-hat）、编码载体（P）和模型输出（O）。它形式化了维度权重、编码掩码、结构和保真度恢复分数以及公私意图分解。意图不可逆损失定理指出，载体中缺失的私有意图无法通过通用替换恢复。来自四项配套研究的证据，涵盖六个LLM、三种语言和三个任务领域，显示了结构-保真度分裂、人类验证的度量分离以及与IST预测一致的权重容忍平台。IST将提示工程重新定义为意图协议设计，并识别了当前AI系统缺失的一个计算层。

## Abstract
Current AI interaction models treat the prompt as the primary object of exchange, omitting a critical layer: the user's latent source intent, the goal state preceding and motivating the prompt. Here we introduce Intent Signal Theory (IST), a computational framework that formalises this missing intent layer. IST distinguishes four objects routinely conflated: latent source intent (I*), observable intent proxy (I-hat), encoded carrier (P), and model output (O). It formalises dimensional weights, encoding masks, structural and fidelity recovery scores, and public-private intent decomposition. The Theorem of Irreversible Intent Loss establishes that private intent absent from the carrier cannot be recovered beyond generic substitution. Evidence from four companion studies spanning six LLMs, three languages and three task domains shows structural-fidelity splits, human-validated metric dissociation, and weight-tolerance plateaus consistent with IST's predictions. IST reframes prompt engineering as intent-protocol design and identifies a computational layer that current AI systems lack.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：当前大语言模型（LLM）的人机交互研究将提示（prompt）视为主要交换对象，忽视了用户**潜在源意图**（latent source intent）——即先于并促使提示产生的目标状态。这导致一种系统性失败：模型输出可能结构完美、流畅合理，但完全偏离用户真正想表达的内容（例如要求企业客户分析，模型却输出面向消费者的分析）。
- **现有方案不足**：
  - 提示工程只关注文本优化，不涉及意图编码理论；
  - 对齐研究依赖整体人类偏好，不能区分结构完整性与意图保真度；
  - 幻觉研究仅从模型端解决问题，未考虑用户端编码失败；
  - 评价体系将输出质量聚合为单一标量分数，混淆结构完整性和意图再现。
- **整体含义**：作者提出**意图信号理论（IST）**，添加一个缺失的**意图计算层**，将提示工程重新定义为**意图协议设计**，为可治理的人机交互提供理论基础。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 四个对象与传输链
IST 定义四个理论上不同的对象：
- **潜在源意图 I\***：用户持有的固定目标状态（不可直接观测）。
- **可观测意图代理 Ĩ**：I\* 的结构化近似，可分解为可计分维度。
- **编码载体 P**：实际输入模型的提示文本。
- **模型输出 O**。

传输链：**I\* → Ĩ → P → O**。每个环节都可能发生信息损失、权重不匹配或模型先验补偿。

### 2.2 基本假设与建模约定
- **F1（源意图完整性）**：单轮交互开始时用户持有固定参考对象 I\*。
- **F2（维度可分解性）**：Ĩ 可表示为有限加权维度集合，分解方式是建模选择而非唯一自然分解。
- 其他约定：层次可精化、编码独立性。

### 2.3 维度分解与任务条件权重
Ĩ = {(eᵢ, wᵢ)}，wᵢ≥0，∑wᵢ=1。权重 wᵢ 依任务类型 T 而定，缺失高权重维度对保真度影响更大。

### 2.4 编码掩码与编码损失
编码掩码 mᵢ ∈ {0,1} 表示维度 eᵢ 是否显式编码于载体中。编码损失：L_enc = 1 − ∑ wᵢ mᵢ。该值度量任务加权意图中被显式编码的部分。

### 2.5 结构恢复、保真度恢复与意图漂移
- **结构恢复得分 rᵢ**：输出是否填充了该维度的结构槽（无论内容是否正确）。
- **保真度恢复得分 fᵢ**：输出是否再现了用户特定的意图值。
- 聚合指标：s-ICMw = ∑ wᵢ rᵢ，f-ICMw = ∑ wᵢ fᵢ。
- **结构-保真度分裂**：当 s-ICMw ≫ f-ICMw 时，模型恢复了结构支架但用默认值替换了私有内容。
- **意图漂移**：D_drift = 1 − f-ICMw。

### 2.6 公共-私有分解
相对于给定任务上下文和模型先验，意图维度可分为：
- **公共成分**：模型可从训练分布中充分预测其值。
- **私有成分**：用户特定的、偏离聚合默认值的内容。模型可能填充通用的默认值，造成结构-保真度分裂。
分类是操作性的而非本体论的，可通过消融实验估算。

### 2.7 意图不可逆损失定理（TIIL）
假设：单轮交互、维度 eₖ 未编码（mₖ=0）、eₖ 为私有维度（I(vₖ; P₋ₖ, M)≈0）。则：**任何解码器 g 基于纯载体信息无法恢复 vₖ 超过通用替换**。依据数据处理不等式。边界条件：多轮、检索、更丰富先验可突破。模型规模提升可扩大公共成分，但不能解决真正个体特定内容的缺失。

## 6. 论文的主要结论与发现

1. **结构化意图编码显著改善对齐**（行为层）：协议结构prompt比无结构prompt获得更高GA。
2. **效果跨语言和模型泛化**（泛化层）：中英日语和六个模型均表现一致，且弱模型受益更大（弱模型补偿效应）。
3. **结构化意图作为协议层**（协议层）：超出模板技巧，具有可测量的稳定特性，优于CO-STAR和RISEN。
4. **结构-保真度分裂是系统性的**（测量层）：中文25.7%、英文58.6%的输出处于分裂区（GA高但f-ICMw低）。人类评分也验证了分裂存在（人类GA平均3.12 vs. LLM GA 5.0；人-LLM在f-ICMw上相关系数ρ=0.695 vs. GA ρ=0.251）。
5. **公共-私有不对称**：31.5%为公共区，68.5%为私有区；高惯例任务（旅行）公共区更多，低惯例任务（商务/技术）私有区更多。
6. **权重容忍平台**：中等权重偏差下f-ICMw变化<0.02，严重反转下100%降解——非线性敏感模式。
7. **TIIL定理**：私有意图一旦缺失，无法通过模型规模提升恢复，编码失败不是模型错误。
