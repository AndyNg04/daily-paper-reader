## 摘要
尽管AI代理在推理和工具使用方面展现出卓越能力，但它们从根本上仍是反应式的：仅在收到明确的用户提示后才进行计算。这种范式忽视了一个关键机会：交互之间的空闲时间基本被浪费，导致代理无法为未来的用户需求做好准备。为弥补这一差距，我们提出ProAct，一种利用空闲时间计算来预测并满足可能即将到来的用户需求的主动型代理架构。通过分析不断演变的对话历史与持久记忆，ProAct预测即将到来的需求并迭代获取信息，使代理能够在用户发起查询之前解决知识缺口并准备证据。为严格评估主动能力，我们还引入了ProActEval，一个包含40个领域200个场景的综合基准测试，具有可预测的需求链和多样化的用户认知特征。实证结果表明，与反应式基线相比，ProAct具有显著优势。在ProActEval上，ProAct通过减少14.8%的必要对话轮次来加速任务完成，降低用户努力11.7%，并将幻觉率降低28.1%。此外，MemBench评估证实ProAct实现了最先进的反思准确性，突显其持续且稳健的性能。

## Abstract
While AI agents demonstrate remarkable capabilities in reasoning and tool use, they remain fundamentally reactive: they compute responses only after explicit user prompts. This paradigm ignores a critical opportunity: the idle time between interactions is largely wasted, leaving agents unable to prepare for future user needs. To bridge this gap, we introduce ProAct, a proactive agent architecture that leverages idle-time compute to anticipate and fulfill likely upcoming user needs. By analyzing evolving dialogue history together with persistent memory, ProAct predicts upcoming needs and iteratively acquires information, allowing the agent to resolve knowledge gaps and prepare evidence before the user initiates a query.To rigorously evaluate proactive capabilities, we also introduce ProActEval, a comprehensive benchmark comprising 200 scenarios across 40 domains, featuring predictable need chains and diverse user cognitive profiles. Empirical results demonstrate significant advantages over reactive baselines. ProAct accelerates task completion by reducing required turns by 14.8%, decreases user effort by 11.7%, and cuts hallucination rates by 28.1% on ProActEval. Furthermore, MemBench evaluations confirm that ProAct achieves state-of-the-art reflective accuracy, underscoring its sustained and robust performance.

### 1. 核心问题与整体含义（研究动机和背景）

当前主流 AI 代理（如 LLM 驱动的助手）本质上是**反应式**的：只在收到用户明确提示后触发计算（请求-响应模式）。交互之间的空闲时间完全被浪费，代理无法为即将到来的用户需求做任何准备。这种静态设计与心理学中的“主动应对”概念形成鲜明对比——人类会主动预测未来需求并提前积累资源。

本文旨在将空闲计算时间转化为主动准备的机会，提出 **ProAct**（Proactive Agent）架构，使代理在对话间隙中预测用户可能的未来需求、获取证据并准备知识，从而在用户发起请求前提供帮助或形成回应基础，提升交互效率和可靠性。

### 2. 方法论：核心思想、关键技术细节与流程

**核心思想**：将空闲时间转化为一个结构化的“预测-获取-交付”循环。  
**整体架构**（参见论文图 2）：

- **持久记忆层**（Persistent Memory M_t）：维护用户画像、实体级事实、对话摘要和之前获取的知识制品。支持向量、关系、文档存储，并具备生命周期管理。
- **未来状态预测**（Future‑State Prediction）：利用对话历史 H_t 和记忆 M_t 生成紧凑的候选未来需求集合 Z_t = f_pred(H_t, M_t)。候选需求表示为 z = (q_z, e_z, c_z, ρ_z)，分别代表需求文本、依据、置信度和检索计划。来源包括：本地场景推断、相关话题扩展以及记忆层反馈的知识缺口。
- **空闲时间获取**（Idle‑Time Acquisition）：对每个候选 z 计算价值分数 S(z) = w_r r_z + w_g g_z + w_v v_z + w_τ τ_z（r：用户相关性，g：知识缺口，v：增量价值，τ：时效性），只有达到阈值 θ_val 的候选才分配计算预算。已接受的候选先检查记忆覆盖度，若不足则进行迭代检索和证据验证，生成简洁的知识制品 A_z。
- **效用感知交付策略**（Utility‑Aware Delivery）：根据推送分数（PushScore = Value - Cost + 50）决定交付模式 d_z ∈ {push, queue, store}。只有当预期未来效用超过中断成本时才会主动推送给用户；否则排队或静默存储。

**闭环优化目标**（公式化表述）：  
max_π E[U_future(π) - λ_i C_interrupt(π) - λ_b C_budget(π) - λ_h R_hallucination(π)]  
其中 U_future 为预期收益（如减少用户努力），各项由超参数平衡。

**关键流程**（一个完整循环）：
(H_t, M_t) → Z_t → 价值评分 → 获取证据与生成制品 → 交付决策 → 更新记忆 M_{t+1}。

### 3. 实验设计

**数据集与基准**：
- **ProActEval**：自建的主动能力评估基准，包含 200 个场景、40 个领域（个人生活、工作、教育、金融等），每个场景包含虚构事实表和具有可预测依赖关系的用户需求序列。评价指标包括 T80/T100（达到 80%/100% 必须需求覆盖的轮数）、用户努力（用户显式提问轮数）、事实准确率、幻觉率、总体覆盖率和预测召回率。
- **MemBench**：用于评估长期反思记忆能力的基准（基于偏好/情感推断）。

**基线方法**：
- **Reactive**：无空闲计算（反应式基线）。
- **Undirected Idle**：启用空闲获取但无预测方向（即随机或全量背景搜索）。

- MemBench 上反射准确率比较（10k/100k token 规模），对比 7 种基线（FullMemory, RecentMemory, RetrievalMemory, GenerativeAgent, MemoryBank, MemGPT, SCMemory）。

### 6. 主要结论与发现

1. **预测指导型空闲计算显著优于反应式基线**：在 ProActEval 上，Directed Idle 相比 Reactive 将完成所有必须需求的轮数（T100）减少 14.8%，用户努力降低 11.7%，幻觉率降低 28.1%，事实准确率提高 1.3%，总覆盖率提高 7.2%。
2. **预测方向是关键**：Undirected Idle（无预测）活跃 token 消耗 69.8k 但仅带来微乎其微的改进（T100 降 0.9%），而 Directed Idle 增加 42k token 后改善显著（T100 再降 14.1%），说明单纯增加背景搜索不够，必须定向到预测需求。
3. **记忆支撑有效**：在 MemBench 上，ProAct 在 10k/100k token 尺度下达到 84.3%/86.3% 反思准确率，超越所有基线（包括 GPT-4 支持的 MemoryBank 等）。
4. **搜索预算存在边际递减**：增加搜索预算会持续提高预测召回率，但端到端效率（T100、用户努力）并不单调改善，反而平坦或波动，表明需要权衡主动计算成本与收益。

### 7. 优点

- **概念创新**：将空闲计算引入代理主动行为，打破了纯反应式范式。
- **架构完整**：统一了记忆、预测、获取、交付四个环节，且各模块设计细致（如价值评分权衡、增量获取、效用感知推门）。
- **评估体系**：构建 ProActEval 基准，包含多样需求链和认知原型，提供标准化测试平台；并且与通用记忆基准 MemBench 结合评估，覆盖全面。
- **实验严谨**：包含预算消融、方向消融、领域分解、统计置信区间、失败案例分析，结论可靠。
- **实际意义**：证明主动准备可以显著减少用户交互负担并提升事实可靠性，对 AI 助手设计有指导价值。

### 8. 不足与局限

- **封闭世界假设**：ProActEval 所有场景基于虚构但有固定事实表的设定，未验证在开放、不可控的真实用户环境中表现（需考虑用户隐私、动态变化、噪声等）。
- **依赖 LLM 裁判和阈值**：评估和门控机制本身依赖 LLM（如价值判断、覆盖判断），可能导致偏差或成本膨胀；实际部署需要人工监控和调节。
- **可能产生反效果**：在少数场景中（如博物馆场景），主动推送改变了对话轨迹，导致最终覆盖率不升反降。这提示主动准备需要与反应式回答协调。
- **预算增加边际收益递减**：更大的搜索预算不一定带来更优交互效率，系统需要在效率与计算开销间选择合适的操作点。
- **隐私与伦理风险**：长期记忆和预测可能侵犯用户隐私，文中声明使用合成数据避免该问题，但指出实际部署需添加用户控制、数据最小化、审计等机制。
