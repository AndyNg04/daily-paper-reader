## 摘要
个性化对话需要的不仅仅是回忆显式的用户历史：系统还需要推断通过交互演变并塑造适当响应策略的隐藏用户状态。现有的基于记忆和基于配置文件的方法主要重用可观察的用户信息，在建模用户状态动态或基于它们如何塑造未来用户状态来选择行动方面支持有限。我们提出了PUMA（面向行动选择的预期用户状态建模），这是一个基于自由能原理（FEP）的框架，将个性化问题表述为部分可观测下的决策，其核心是一个显式的用户状态模型，捕捉潜在用户状态及其受行动影响的状态动态。在每个轮次中，PUMA维持对用户隐藏状态的信念，精炼用于观测生成和受行动影响的状态转移的用户状态模型，并通过最小化期望自由能来选择对话行动，在统一准则下平衡认知和实用目标。这种表述将个性化从被动记忆检索转变为基于模型的用户演变决策。我们在面向医疗的咨询和动机性访谈基准测试上实例化了PUMA，这些基准带有潜在状态注释以便进行严格评估。实验表明，PUMA改善了长期对话结果，同时保持了强大的响应质量，并且跨数据集研究展示了更可靠的用户状态估计和下一个状态预测。

## Abstract
Personalized dialogue requires more than recalling explicit user histories: systems also need to infer hidden user states that evolve through interaction and shape appropriate response strategies. Existing memory- and profile-based methods primarily reuse observable user information, offering limited support for modeling user-state dynamics or selecting actions based on how they shape future user states. We propose PUMA (Prospective User-state Modeling for Action selection), a framework grounded in the Free Energy Principle (FEP) that formulates personalization as decision-making under partial observability, centered on an explicit user state model that captures latent user states and their action-conditioned dynamics. At each turn, PUMA maintains a belief over the user's hidden state, refines the user state model for observation generation and action-conditioned state transition, and selects dialogue actions by minimizing expected free energy, balancing epistemic and pragmatic objectives under a unified criterion. This formulation shifts personalization from passive memory retrieval to model-based decision-making over user evolution. We instantiate PUMA on healthcare-oriented counseling and motivational interviewing benchmarks with latent state annotations for rigorous evaluation. Experiments show that PUMA improves long-horizon dialogue outcomes while maintaining strong response quality, and a cross-dataset study demonstrates more reliable user-state estimation and next-state prediction.

## 论文总结

### 1. 核心问题与整体含义（研究动机和背景）
- **问题**：现有个性化对话系统主要依赖显式记忆或用户档案，重用过往可观察信息（如偏好、历史陈述）。但用户话语中的关键信息（如焦虑、动机、准备程度）往往是隐含且动态演变的，相同话语在不同状态下需要完全不同的回应。系统缺乏对用户隐藏状态及其受系统动作影响的变化进行推理的能力。
- **含义**：个性化不应仅是信息检索，而应是基于模型的、面向用户状态演化的主动决策。为此，论文提出**PUMA**框架，将对话个性化建模为部分可观测环境下的序贯决策问题，核心是对用户状态及其动力学进行显式建模。

### 2. 方法论
- **核心思想**：基于自由能原理（Free Energy Principle, FEP）和主动推理，将用户视为一个潜在动态系统。系统维护对用户隐藏状态的概率信念，学习世界模型（观测生成与状态转移），并通过最小化期望自由能（Expected Free Energy, EFE）选择动作，平衡认知不确定性降低（认知价值）与目标导向结果（实用价值）。
- **关键技术细节**：
  - **用户表示**：区分三个概念：
    1. **用户状态**（User State）：当前决策相关的潜在内部条件（如动机阶段）。
    2. **世界模型**（World Model）：分解为 `p(st|st-1, at-1)`（动作条件状态转移）和 `p(ot|st)`（状态到观测的生成模型）。
    3. **语义记忆**（Semantic Memory）：存储具体对话内容，包括短期和长期记忆，用于响应生成但不参与状态跟踪。
  - **推理与更新流程**（每轮）：
    1. **信念更新**：通过最小化变分自由能 `Ft = D_KL(q(st) || ˜p(st)) - E[log p(ot|st)]` 更新对当前用户状态的后验信念 `q(st)`。
    2. **世界模型更新**：优化观测模型和转移模型参数，损失函数包含观测对数似然和状态转移对数似然，并用 λ 平衡。
    3. **动作选择**：对每个候选动作 a，计算期望自由能 `G(a) = E[H(q(st+1|ot+1,a))] + E[-log p_pref(ot+1)]`，选择使 G 最小的动作。第一项为认知价值（降低不确定性），第二项为实用价值（导向偏好结果）。
    4. **响应生成**：基于选定动作、更新后的信念、检索记忆和当前用户话语，由语言模型生成自然语言响应。
- **算法流程**（文字说明）：
  - 初始化用户状态信念和世界模型参数。
  - 在每一轮 t：
    - 接收用户观测 ot。
    - 使用变分贝叶斯方法更新信念 q(st)。
    - 利用观测和信念更新世界模型参数（观测模型和转移模型）。
    - 对每个候选动作，预测下一轮状态和观测的分布，计算期望自由能。
    - 选择期望自由能最小的动作。
    - 根据选定动作、信念、记忆和当前观测，生成系统响应 yt。
    - 系统响应影响用户状态转移，进入下一轮。

### 8. 不足与局限
- **依赖模拟器**：动态评估基于自建客户模拟器（DynPatient），尽管经过验证，但模拟器仍是对真实客户行为的近似，结论在真实临床场景中的有效性未直接证明。
- **状态空间需预定义**：当前框架要求用户状态有预定义的离散标签（如CAMI的阶段），这限制了其在没有此类标注数据领域的直接应用。

- **未考虑跨用户差异**：模型假设所有用户共享相同的状态空间和转移动力学，个性化仅通过信念和记忆体现，可能无法捕捉高度异质的个体行为模式。
