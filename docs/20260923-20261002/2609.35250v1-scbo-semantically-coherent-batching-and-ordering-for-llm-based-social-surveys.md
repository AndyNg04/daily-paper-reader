## 摘要
大语言模型（LLMs）提供了一种可扩展的方法，能够利用人口统计学特征和已观测的参考回答来模拟调查受访者。然而，传统的每次提示仅预测一个问题的方法会反复编码相同的上下文，将每个目标问题可利用的参考回答限制在较小范围内，并使后续预测无法利用先前回答中的信息。在一次提示中预测多个问题，可以降低这些开销、共享更广泛的参考回答池，并使后续预测建立在先前预测的基础上。这需要构建语义一致的批次、选择共享参考回答，并有效安排问题和参考回答的顺序。我们提出语义一致批处理与排序（Semantically Coherent Batching and Ordering，SCBO），这是一种无需训练的框架，用于应对上述挑战。SCBO 首先利用大语言模型从调查题目中提取紧凑的语义表示，并滤除模板噪声。随后，将相关问题分组形成批次，并通过针对目标问题的检索和基于质心的补全构建共享参考回答库。最后，将目标问题按由易到难的顺序排列，并根据参考回答与这些问题的语义匹配程度安排参考回答的顺序。在四个大规模调查数据集和四种大语言模型上的实验表明，与不采用批处理的基线方法相比，SCBO 显著减少了词元消耗和推理时间，同时总体上提高了预测准确率。代码可在 https://anonymous.4open.science/r/SCBO-41D8 获取。

## Abstract
Large Language Models (LLMs) offer a scalable way to simulate survey respondents using demographic profiles and observed reference responses. However, the conventional approach of predicting one question per prompt repeatedly encodes the same context, limits each target to a narrow set of reference responses, and prevents later predictions from using information in earlier answers. Predicting multiple questions in one prompt can reduce these costs, share a broader pool of references, and let later predictions build on earlier ones. This requires forming coherent batches, selecting shared references, and ordering questions and references effectively. We propose Semantically Coherent Batching and Ordering (SCBO), a training-free framework that addresses these challenges. SCBO first uses an LLM to extract compact semantic representations from survey items and filter out template noise. It then groups related questions into batches and builds a shared reference bank using target-specific retrieval and centroid-based completion. Finally, it orders target questions from easy to hard and arranges references according to their semantic alignment with those questions. Experiments on four large-scale survey datasets and four LLMs show that SCBO substantially reduces token consumption and inference time while generally improving prediction accuracy over a non-batched baseline. Code is available at https://anonymous.4open.science/r/SCBO-41D8.

## 1. 核心问题与研究背景

- **研究任务**：给定某位受访者的人口统计画像，以及其已经回答过的部分调查题目，利用大语言模型预测该受访者对其他题目的回答。本质上，这是**有个体历史信息约束的问卷回答预测**，而不是仅凭人口属性生成“典型人群”的意见。
- **研究动机**：真实社会调查存在招募成本高、拒答和覆盖不足等问题。LLM 可以辅助扩大调查模拟规模，但常用的“每个提示只预测一道题”存在三项局限：
  1. **上下文重复**：每题都重新输入任务说明、人口画像和参考回答，增加词元与请求开销。
  2. **参考信息隔离**：不同目标题分别检索参考回答，无法共享其他题找到的相关证据。
  3. **预测相互独立**：后续预测无法利用前面生成的答案，忽略同一受访者不同态度之间的关联。
- **整体思路**：将同一受访者的多个相关问题放入一个提示，既摊薄固定上下文成本，又共享参考信息，并利用自回归生成中的答案依赖。
- **论文的核心挑战**不只是“批量输入”，而是：
  - 哪些问题应放进同一批次、共享哪些参考回答？
  - 问题与参考回答应按什么顺序组织？

## 2. 方法论：核心思想与技术流程

SCBO 是一个**无需训练或微调预测模型的提示组织框架**，包含语义预处理、分批与参考选择、排序三个环节。

### 2.1 问题语义实例化：过滤模板噪声

- 使用 GPT-5.5 将原始题目提炼为：
  - **主题**；
  - **核心意图**；
  - **关键实体**。
- 去除“您认为”“请评价”等重复问卷措辞，尽量保留实际语义。
- 使用 `text-embedding-3-small` 编码紧凑表示，并进行 L2 归一化；后续通过余弦相似度进行聚类、检索和排序。
- **受访者真实答案不参与嵌入计算**，只作为检索后参考条目的标签，避免直接利用目标答案组织问题。

### 2.2 语义分批：兼顾相关性与固定容量

- 将目标题划分为容量为 \(C\) 的批次，优化目标是**降低批次内部的语义离散程度**。
- 实际算法分两步：
  1. 使用 KMeans++ 初始化并运行 KMeans，获得语义中心。
  2. 将每个中心展开为指定数量的容量槽位，再用**匈牙利算法**将题目分配到槽位，保证批次大小符合要求。
- 该过程是固定容量聚类目标的**近似求解**，不是对联合聚类问题的全局最优求解。
- 对不能整除的情况，最后一个批次允许小于 \(C\)。

### 2.3 共享参考库：逐题检索与质心补全

- 每道目标题先检索最相关的 \(n\) 条历史问答。
- 将批内所有题目的检索结果取并集，形成初始共享参考库。
- 批次参考预算设为 \(m=nC\)，与逐题预测的总参考条数预算一致。
- 如果并集存在重复、条数不足，则按参考题与**批次语义质心**的相似度补充，直到达到预算或参考池耗尽。
- 每道目标题还附有“相关参考 ID”：
  - 在更宽的检索集合中查找相关题；
  - 与共享库取交集；
  - 实验中检索深度设为 \(r=10\)。
- 模型优先使用这些指定参考，再结合整个共享库与人口画像。

### 2.4 课程式排序：由易到难生成

- **题目难度代理**：目标题与共享库中最相似参考题的相似度越高，就被认为越容易预测。
- 按该分数从高到低排列目标题，希望先生成较可靠的答案，再辅助较难的问题。
- **参考排序**：将参考位置映射到目标题，最大化参考条目与对应目标题的总语义相似度，使参考顺序与目标顺序对齐。
- 最终一次提示输出全部目标题的 JSON 答案。

### 2.5 效率机制

- 对 \(N\) 道目标题，逐题方法需要重复输入 \(N\) 次固定上下文。
- 批处理后约需 \(N/C\) 次，固定上下文部分理论上减少为原来的 \(1/C\)。
- **这不等于总词元必然减少 \(C\) 倍**：题目文本、参考条目、ID 标注和输出仍有开销。

## 6. 主要结论与发现

- 在 48 个配置中，SCBO：
  - **全部降低 MAE**；
  - **46 个提高 ACC**；
  - **45 个提高 F1**。
- 准确率收益并非每个配置都存在，但总体趋势一致。
- BSA 上 ACC 相对提升最高约 **12.2%**。例如 0.492 提升至 0.552，实际为提高 **6.0 个百分点**，不是 12.2 个百分点。
- 平均提示词元减少约 **58.0%**，范围为 **30.1%–71.1%**。
- 每题摊销请求耗时加速约 **3.3–14.0 倍**。
- 批大小增大通常持续降低词元成本，但准确率非单调变化；适中批次往往更好，过大批次可能产生注意力干扰。
- 消融总体支持：**语义分批最关键，排序进一步改善预测，语义实例化提供辅助增益**。
- 这些结果证明的是相对基线的效率与预测质量提升，**不证明生成回答能够替代真实调查**。

## 7. 优点与亮点

- **问题结构利用充分**：围绕“同一受访者、相关题目、共享历史”设计，而非简单拼接独立任务。
- **无需微调**：可作为现有 API 模型外部的检索和提示组织层。
- **参考选择兼顾局部与整体**：先保留每题最相关证据，再补充代表批次主题的历史回答。
- **固定容量分批可操作**：KMeans 与匈牙利算法结合，兼顾语义相关性和批次管理。
- **效率与质量同时改善**：不是单纯以准确率换取成本下降。
- **复现信息较完整**：给出提示模板、数据过滤、容量分配、API 设置，并明确解释延迟指标的适用范围。

## 8. 不足、偏差风险与应用限制

- **难度与关联度都是启发式代理**：
  - 语义相似不必然意味着容易预测；
  - 题目主题相近不必然意味着回答强相关；
  - 由易到难也不是按实际错误概率排序。
- **自回归错误传播**：早期错误可能影响后续答案，生成的“内部一致性”未必符合真实个体态度。
- **机制证据有限**：没有直接分离参考共享、答案依赖和参考排序各自的贡献；排序消融同时移除了两种排序。
- **MAE 的解释存在限制**：选项按原始代码转为索引，但名义类别未必有大小顺序或等距含义，跨题平均 MAE 也受选项数量影响。
- **社会科学有效性评估不足**：未系统报告群体偏差、人口分组表现、总体意见分布或题间相关结构保真度。
- **适用范围有限**：主要针对历史回答较丰富的单选题；对冷启动、严重缺失、开放题、多选题及新领域的效果尚不明确。
- **实际部署成本未完全覆盖**：逐受访者聚类与匈牙利分配有额外计算开销，预处理、调参与重试的完整成本未量化。
- **伦理风险仍在**：预测可能继承数据和模型的刻板印象，不宜用于对个人或人口群体的高风险决策。

**总体评价**：SCBO 是一个结构清晰、工程实用的调查回答预测框架，对“语义组织能否让批处理同时更便宜、更准确”提供了较扎实的实验支持；但它对真实社会意见的代表性、偏差控制和跨场景有效性仍需进一步验证。
