## 摘要
情感计算已提升了可穿戴状态推断，但在设备端关于是否、何时以及如何干预的推理仍具挑战性。我们提出 Affective Agent，一种面向可穿戴级硬件的、在不确定性下进行个性化干预推理的三层参考架构。它结合紧凑的十亿参数以下语言模型与生理证据、情境和用户历史，在不依赖云端且无需按用户重新训练的情况下，决定是否、何时以及如何干预。该架构由三个相互作用的层（感知、个性化与推理）组成，通过由主机管理的结构化记忆演化而非按用户权重更新来适应个体用户。我们在室内环境质量控制中实例化 Affective Agent，并在留出的、由模拟器生成的纵向场景上评估它，这些场景涵盖生理变化、情境、信号质量和干预历史。结果表明，记忆驱动的个性化与两遍结构化推理在该合成评估中改进了干预决策。通过将决策层移至设备端，这项工作展示了一条从可穿戴状态推断走向可穿戴级硬件上闭环、个性化干预的路径。

## Abstract
Affective computing has advanced wearable state inference, but on-device reasoning about whether, when, and how to intervene remains challenging. We present Affective Agent, a three-layer reference architecture for personalized intervention reasoning under uncertainty on wearable-class hardware. It combines a compact sub-billion-parameter language model with physiological evidence, context, and user history to decide whether, when, and how to intervene, without cloud dependency or per-user retraining. The architecture is organized into three interacting layers (perception, personalization, and reasoning), adapting to individual users through host-managed structured memory evolution rather than per-user weight updates. We instantiate Affective Agent in indoor environmental quality control and evaluate it on held-out, simulator-generated longitudinal scenarios spanning physiological variation, context, signal quality, and intervention history. Results show that memory-driven personalization and two-pass structured reasoning improve intervention decisions within this synthetic evaluation. By moving the decision layer on-device, this work demonstrates a path from wearable state inference toward closed-loop, personalized intervention on wearable-class hardware.

# Affective Agent 论文详细总结

## 1. 核心问题与研究动机

- **背景**：可穿戴情感计算在**状态推断**方面已相当成熟（如基于 EDA、BVP、HRV 估计压力），但从"感知状态"到"决定该做什么"之间存在断层。
- **核心问题**：端侧设备上**是否（whether）、何时（when）、如何（how）干预**的推理仍未被解决。同一生理信号（如心率升高）可能对应运动、压力、喝咖啡等截然不同的情境，单靠信号无法确定合适的响应。
- **现有方案痛点**：
  - 现有 JITAI（Just-in-Time Adaptive Interventions）在自适应性、接受性、情境感知与决策规则上存在持续局限，多依赖预设规则，难以跨用户/跨时间适应。
  - 个性化通常需要逐用户重训，而隐私、延迟、功耗约束使持续云端推理或按用户微调不可取。
  - 现有边缘智能体工作（TinyAgent、CAMPHOR）聚焦工具调用与 API 执行，而非**记忆条件下的干预推理**。
- **整体含义**：论文将缺失的"决策层"重新定义为一个**结构化的端侧推理问题**，提出五条设计属性：端侧不确定性推理、持久用户记忆、以状态演化替代重训实现个性化、有界可解释决策输出、隐私保护本地运行。

## 2. 方法论

### 2.1 核心思想：三层闭环参考架构

- 架构由**感知层、个性化层、推理层**三层构成，在设备端形成闭环；每次决策后结果回写记忆，数据不出设备。
- 个性化**完全解耦于模型权重**：不做逐用户参数更新，而是依靠主机（host）管理的结构化记忆演化来适配个体。

### 2.2 感知层

- 原始多模态信号**不直接送入语言模型**；主机按 **5 分钟窗口**做本地特征提取，输出统计聚合量 + **信号质量指标**（让模型知道何时该信任信号）。
- 同时融合三个**冻结的**任务专用分类器输出作为**辅助证据**（非真值）：3 类 XGBoost（基线/压力/愉悦）、随机森林（认知负荷/无负荷）、二分类 KNN（热舒适/不舒适）。
- 感知层只"报告观察到什么"，不判断是否行动。

### 2.3 个性化层

- **情景记忆（短期）**：有界 FIFO 缓冲（容量 5），记录近期干预的模态与取值、情境、时间戳、观测到的近期生理响应。
- **语义记忆（长期）**：有界的学习模式库与情境摘要库，存储跨时间泛化结论（如"该用户晨间生理基线偏低""认知负荷下热调节持续有效"），仅部分条目进入提示词。
- **偏好生命周期三阶段**：群体默认（前两个日历日，冷启动）→ 临时（个体模式开始影响决策）→ 已学习（确认偏好优先）。进入"已学习"需**至少 20 次反馈且至少 5 天活动**，避免过早固化；新证据冲突时可修正，以跟踪偏好漂移。
- **写入治理**：模型提出记忆更新意图，主机按显式规则校验后才落盘；记忆以紧凑的每用户 JSON 本地持久化；语言模型本身**跨调用无状态**。

### 2.4 推理层

- 采用**亚十亿参数微调语言模型**（Qwen2.5-0.5B / Qwen3-0.6B），在**固定结构化 schema** 上工作，输入为固定 schema，输出为 schema 约束的决策契约（intervene / wait / abstain + 有界理由字段）。
- **两遍推理（Two-Pass）**：
  - **第一遍（评估）**：把证据组织为显式字段——生理解释、信号质量、分类器支持度、历史模式、情境适配性、环境错配、预期效果，形成临时状态判断。
  - **第二遍（验证/修订）**：核对历史一致性、情境适当性、偏好对齐、置信度校准，并决定是否修订动作与置信度。
- 推理时主机对动作做**安全边界校验**，仅在运行约束满足时执行执行器更新。

### 2.5 训练工作流（以结构化监督补偿模型容量）

- **合成数据生成**：14 名 20–30 岁虚拟用户队列，生理先验参考 WESAD（压力）、SWELL-KW（认知负荷）、En-Gage（热舒适）；注入传感器掉线、间歇丢失、削波、接触不良、运动伪影等真实伪迹。
- **数据层级**：batch = 一次连续占用会话（记忆与环境状态延续）；scenario = 25 分钟局部片段，含 5 个连续 5 分钟决策窗口，训练模型在部分观测下推理并随证据累积更新判断。
- **监督目标**：由模拟器潜状态推导的**有界干预目标区间**（非生理标签、非自评），取决于信号质量、偏好生命周期阶段、既往干预结果与智能体不可见的安全约束。
- **六层推理复杂度课程（T0–T5）**：T0 群体默认（清晰信号、高置信）→ T1 情境门控 → T2 已学习偏好 → T3 冲突 → T4 临时/冷启动 → T5 深度推理（多因素不确定，置信 0.30–0.55）；用配额管理保证各层覆盖均衡。
- **程序化两遍监督**：推理链由模拟器真值条件、偏好历史与干预结果**确定性生成**，而非蒸馏大模型或自由链式思考，保证内部一致。

## 6. 主要结论与发现

- **学习式推理显著优于规则基线**：Qwen3 与 Qwen2.5 的动作准确率为 0.782 与 0.811，规则基线为 0.482，分别提升 30.0 与 32.9 个百分点。
- **两个骨干存在指标反转**：Qwen2.5-0.5B 顶层动作准确率（0.811 vs 0.782）与宏 F1（0.677 vs 0.616）更高；Qwen3-0.6B 模态准确率更高（0.864 vs 0.701）。作者认为这反映 checkpoint 差异，而非"一个擅长判断是否行动、另一个擅长判断如何行动"的证据。
- **记忆主要改善个性化路由**：去掉记忆后宏 F1 从 0.616 降至 0.501，模态准确率从 0.864 降至 0.605（降幅尤其大），说明记忆条件化主要帮助**正确选择干预通道**而非粗粒度动作选择；同时验证了"以主机管理状态演化替代逐用户权重更新"这一设计。
- **两遍推理对可靠性至关重要**：去掉验证遍后宏 F1 降至 0.463，ECE 从 0.301 恶化至 0.377，且失去可解释、可审计的结构化推理。
- **Schema 合规近乎完美**：两个模型均达 0.993，表明亚十亿模型可稳定生成 schema 约束输出。
- **校准是最大短板**：模型 ECE（0.255–0.301）反而差于规则基线（0.097），主机需通过动作边界与置信度阈值下的强制弃权来兜底。
- **解码主导边缘延迟**：约 900 token 的两遍完成占 Qwen3 平均延迟的 75.9%、Qwen2.5 的 84.7%；平均延迟分别占 5 分钟感知间隔的 27.8% 与 17.9%，故建议执行前重新校验情境与安全约束、丢弃过期决策。
- **总体结论**：亚十亿模型可在端侧执行结构化干预推理（不止于分类）；主机管理记忆可在不重训的前提下提升个性化；显式两遍推理同时提升可靠性与置信度校准，展示了一条从状态推断走向闭环个性化干预的可行路径。

## 7. 优点

- **架构定位清晰**：明确把"决策层"从感知/分类中剥离，五条设计属性与三层结构一一对应，可复用性强（作者声称领域无关）。
- **个性化机制有巧思**：以主机管理的结构化记忆 + 偏好生命周期（20 次反馈 / 5 天门槛、可修订）替代逐用户重训，同时用写入治理与有界 FIFO 控制提示词规模，兼顾隐私、成本与稳定性。
- **以结构化监督补偿小模型容量**：合成场景生成 + 六层推理复杂度课程 + 程序化两遍监督，思路明确且可复现；用确定性真值生成推理链，避免自由 CoT 的不一致。
- **消融设计直接对应设计属性**：no-memory 与 one-pass 分别检验"状态演化个性化"和"有界可解释输出"两项主张，结论指向明确。
- **兼顾算法与部署**：在真实边缘硬件（Raspberry Pi CM5）上实测延迟、内存与温度，并给出"执行前重新校验、丢弃过期决策"的工程建议。
- **诚实报告局限**：明确指出 ECE 反而不如规则基线、两遍推理示例不能独立证明推理忠实性、合成结果不构成真实干预有效性证据。

## 8. 不足与局限

- **评估全为合成**：无真实用户、无真实干预效果验证；真值来自模拟器潜状态而非真实世界结果，模拟器也未涵盖情绪驱动的拒绝

、主观抗拒、干预疲劳、执行器故障、多用户共用设备、传感器长期漂移等真实闭环因素；因此“干预是否被接受、是否真正改变状态”未被验证。

- **模拟器偏差与真值定义风险**：监督目标由模拟器潜状态推导，动作“正确性”本质上由模拟器规则决定，可能系统性偏向某些干预策略；模型学到的可能是模拟器的决策边界，而非真实用户的合理干预边界。
- **领域泛化未验证**：论文声称架构领域无关，但只在 IEQ（室内环境质量/热舒适）一个场景实例化；跨领域（如压力管理、睡眠、运动）是否只需替换分类器与提示 schema，缺少实证。
- **模型与训练细节不足**：未报告训练 GPU、时长、token 量、能耗；合成数据规模、质量与多样性依赖模拟器设计；偏好生命周期阈值（20 次反馈 / 5 天）缺少消融或敏感性分析。
- **统计与复现局限**：每个配置仅一个微调 checkpoint、贪心解码，未报告多随机种子、方差分解或显著性检验；1,600 个决策点虽用聚类 bootstrap 缓解纵向相关，但仍来自同一合成评估集，外部效度有限。
- **校准短板可能影响闭环安全**：ECE 明显差于规则基线，说明模型“自信地犯错”的风险存在；论文依赖主机动作边界与强制弃权兜底，但该安全层本身未在对抗性、边界性输入下系统测试。
- **部署测量不完整**：延迟只统计模型提示到输出，未包含感知、特征提取、分类器执行、提示组装与主机校验；53–83 秒的决策延迟对部分即时干预场景可能偏慢；功耗、长期热节流、电池续航与反复唤醒成本未测。
- **隐私与治理仍属设计声明**：数据不出设备、记忆本地 JSON 持久化是优点，但记忆可能包含敏感行为/生理推断；写入治理规则由主机硬编码，未讨论用户查看、修正、删除记忆的机制，也未分析模型被诱导写入错误记忆的风险。
- **可解释性证据偏弱**：两遍推理输出结构化、可审计，但论文示例只能说明输出形式，不能证明推理链忠实反映模型内部计算；去掉验证遍后的性能下降支持其工程价值，却不等于“推理忠实性”已被验证。
- **基线比较范围窄**：规则基线可能未充分调优；未与云端大模型、其他边缘智能体框架、传统 JITAI 自适应策略或经典上下文 bandit/RL 方法横向比较，因此“学习式推理更优”的结论边界有限。

## 9. 总体评价与启示

- **核心贡献在于问题重构与架构可行性**：论文把可穿戴情感计算从“状态推断”推进到“端侧干预决策”，提出感知层—个性化层—推理层闭环，并用主机管理记忆替代逐用户重训，给出了一个可落地、隐私友好的参考设计。
- **最有价值的工程结论**：亚十亿参数模型可以在端侧稳定输出 schema 约束的结构化决策；记忆条件化主要改善干预通道选择；两遍推理对宏 F1 与校准均有帮助；但校准仍是最大弱点，必须由主机安全层兜底。
- **证据强度定位**：当前结果应视为**合成环境下的架构验证与可行性证明**，而非真实世界干预有效性、跨领域泛化能力或长期个性化收益的证明。
- **后续研究优先级**：真实用户纵向闭环试验；端到端延迟与功耗测量；跨领域/跨设备迁移；校准与弃权策略改进；记忆治理、用户可解释与可删除机制；与云端大模型、RL/JITAI 基线的公平对比；多随机种子与敏感性分析。
- **一句话总结**：这篇论文的价值不在于证明“小模型已经能做好情感干预”，而在于清晰展示了“如何在端侧把感知、记忆、推理与安全约束组织成一个可审计的个性化干预闭环”，并诚实地暴露了校准、真实性与泛化方面的关键缺口。
