## 摘要
大语言模型（LLMs）显著革新了现代社会，实现了人类与AI代理之间的众多高级交互，然而包括ChatGPT在内的大多数大语言模型的使用并非友好开源，且需要用户持续为这类AI服务支付高昂费用。因此，将开源大语言模型部署在本地服务器上，可以视为一种以更低成本、更稳定免费使用的方式设计和实现创造性具身AI算法的有效途径。受这一朴素动机的启发，我们原创性地提出并实现了“Socratic Models-ChatGLM”，这是一种基于离线大语言模型、通过简便的PyBullet平台实现机械臂多模态交互控制的性能优良算法，甚至展现出解决复杂的文本-图像集成多步长时程机器人操作任务的非凡潜力。

## Abstract
Large Language Models (LLMs) have significantly revolutionized the modern society with numerous advanced interactions between humans and AI agents, whereas the usage of most large language models including ChatGPT are not friendly open-sourced and must require the users paying a lot for such AI services continuously. Therefore, deploying open-sourced large language models on local servers can be considered as an efficient approach to design and implement creative embodied AI algorithms with lower cost and more stable free usage. Inspired by this ordinary motivation, we originally propose and implement the "Socratic Models-ChatGLM", which is a well-performed algorithm for multi-modal interactive control of robotic arm based on offline large language models via the facile PyBullet platform, even presents extraordinary potential to address complicated text-image integrated multi-step long-horizon robotic manipulation tasks.

## 2. 方法论：核心思想与关键技术

### 核心思想
- 提出 **“Socratic Models-ChatGLM”** 算法，借鉴 Socratic Models 的多模型协同推理范式，但将原框架中依赖的在线 ChatGPT 替换为**本地离线部署的 ChatGLM2-6B** 开源大语言模型。
- 通过"视觉感知→语言理解→代码策略生成→策略执行"的模块化流水线，实现文本与图像信息融合的机械臂多模态交互控制。

### 系统三大核心模块
1. **大语言模型（ChatGLM2-6B）**：负责文本需求交互与代码策略生成。
2. **视觉推理模块（ViLD）**：使用开放词汇目标检测模型 ViLD 对桌面场景进行视觉推理，返回检测物体列表（如`objects = ["yellow block", "pink bowl", ...]`），作为场景描述输入给语言模型。
3. **策略执行模块（CLIPort）**：基于 pick-place 热力图执行语言模型生成的机器人操作代码策略。

### 关键实现步骤
1. **离线模型部署**：通过 Github 和 Huggingface 下载 ChatGLM2-6B 开源模型，利用 FastChat 平台和 Autogen 框架在本地 GPU 服务器上部署 OpenAI 兼容的 API 服务，用户无需联网、无需付费 API key 即可直接调用。
2. **人机交互流水线**：用户输入文本指令（如"Pick the gray block and place it on the pink bowl"）→ ViLD 检测场景物体 → ChatGLM2-6B 结合指令与场景描述，基于机械臂抓取代码提示词（prompt）生成为自然语言步骤或伪代码形式的层级规划代码（如`robot.pick and place("gray block", "pink bowl")`）→ CLIPort 执行该策略完成操作。
- **模型规模**：ChatGLM2-6B 基于 GLM 架构，拥有 62 亿参数，支持中英双语，通过 INT4 量化可在最低 6GB 显存的消费级显卡上运行。
- **重要参数**：离线模型生成代码时设置最大 token 数为 50，论文指出可通过调整 max token、temperature 等参数优化不同场景下的生成效果。

- **任务类型**：共设计两大类任务，涵盖多组子任务：

    - Task B："Move the blocks to the corners"（将积木移到角落），4 种颜色碗和积木
    - Task C："Move the blocks in the middle"（将积木移到中间）
  - **（b）连续组合多任务（Continuous Combination Multiple Tasks）**：共 4 组连续长时程任务
    - Task A：连续 3 个子任务（拾取灰色积木放到粉色碗中 → 移动黄色积木到底侧 → 将所有积木放到右上角）
    - Task B：2 个子任务（将粉色物体聚集 → 将积木与同色碗匹配）
    - Task C：2 个子任务（将积木移到底侧 → 将积木按颜色分类放入对应碗中）
    - Task D：4 个连续长时程子任务（将灰色积木左移约 3cm → 将黄色积木下移约 4cm → 尽量将积木叠放在粉色碗上 → 将青色积木移至右上角），其中前两个任务专门测试距离+方位控制的精细操作能力

## 6. 主要结论与发现

- 论文提出的 "Socratic Models-ChatGLM" 算法能够通过本地部署的 ChatGLM2-6B 离线大模型，快速生成正确、清晰的多步代码策略，并成功完成多种单指令多步任务与连续组合多任务机械臂操作。
- 系统在全部测试任务中达到 **约 100% 的任务完成率**，性能评分达到 **80%~92%**（单指令任务：85%~88%；连续多任务：82%~92%）。
- 特别发现：离线部署的大模型在"移动指定颜色物体一定距离到特定方向"的精细空间操作任务上，能取得与在线 GPT-4 相当的性能表现（对应 Code as Policies 中的能力）。

- 总体结论：开源离线大语言模型为具身智能提供了一种低成本、高潜力、可无限次调用的多模态交互控制方案。
