## 摘要
由多模态大语言模型（MLLMs）驱动的移动GUI代理在人机智能方面展现出前景。然而，当前研究主要关注反应式任务执行，缺乏对用户意图的理解-预测-执行全过程，而这是主动代理的核心需求。在本文中，我们提出了Act2Intention框架，通过整合理解、预测用户意图和执行决策来构建主动移动代理。首先，我们通过数据收集和验证生成构建了Act2Intention Bench，涵盖52个应用中的72,511个意图和超过700,000个操作，从而建立了首个通过连续意图-操作轨迹评估主动代理的基准。我们进一步开发了Act2Intention代理，通过面向主动的意图理解、个性化主动意图预测和经验引导的意图执行来实现主动服务。实验结果表明，在相同代理框架下，基于Act2Intention Bench的监督微调在意图理解、预测和执行方面相比未微调版本分别实现了+32.0 Acc-S、+10.25 Acc-S和+6.9 SSR分的绝对提升。这一成功凸显了Act2Intention Bench的必要性和价值，它为开发和评估主动代理建立了标准化平台，从而为意图驱动的人机交互研究铺平了道路。

## Abstract
Mobile GUI Agents powered by multimodal large language models (MLLMs) show promise in human-computer intelligence. However, current research primarily focuses on reactive task execution while lacking a comprehensive understanding-prediction-execution process for user intentions, which are the core requirements of active agents. In this paper, we propose the Act2Intention framework that builds an active mobile agent by integrating understanding, predicting user intentions, and executing decisions. First, we construct the Act2Intention Bench through data collection and validated generation, comprising 72,511 intentions and over 700,000 actions across 52 apps, thereby establishing the first benchmark for evaluating proactive agents via continuous intention-action trajectories. We further develop the Act2Intention Agent, achieving proactive services through Proactive-oriented Intention Understanding, Personalized Proactive Intention Prediction, and Experience-guided Intention Execution. Experimental results show that supervised fine-tuning on Act2Intention Bench yields absolute improvements of +32.0 Acc-S, +10.25 Acc-S, and +6.9 SSR points over non-fine-tuned counterparts under the same agent framework for intention understanding, prediction, and execution, respectively. This success underscores the necessity and value of the Act2Intention Bench, which establishes a standardized platform for developing and evaluating proactive agents and consequently paves the way for research on intention-driven human-computer interaction.

## 1. 核心问题与整体含义

- **研究背景**：现有移动 GUI 智能体（如 AutoGLM、CogAgent 等）主要作为“反应式执行者”，依赖用户明确下达的文本/语音指令，按部就班地完成单次任务。这类系统缺乏对用户潜在意图的主动感知、推理与干预能力，难以在用户尚未明确表达需求时提供预判式服务。
- **核心问题**：真实的移动使用场景中，用户往往不会显式表达每一步意图，而是通过连续的 GUI 操作流呈现其目标。因此，如何从原始 GUI 行为序列中**理解用户意图**、**预测下一步意图**并**主动执行**，是迈向主动式移动智能体的关键。
- **整体含义**：论文提出“理解 → 预测 → 执行”的主动智能体范式，并构建了首个支持连续“意图-操作”轨迹的基准 `Act2Intention Bench`，旨在推动移动智能体从被动响应转向主动服务，为意图驱动的人机交互研究奠定评测基础。

## 2. 方法论

- **核心思想**：以“用户意图”为中间语义桥梁，将低层 GUI 动作流转化为高层意图描述，再基于历史意图、用户画像和当前时间预测下一步需求，最后将用户确认的意图执行回 GUI 操作。
- **基准构建**（Act2Intention Bench）：
  - 数据来源：由手机厂商采集的 90 名用户真实使用日志（2024年3月-4月），包含时间戳、前台应用、操作类型、参数、截图及用户自报的意图描述。
  - 轨迹格式：每条样本为连续 N 个意图片段，每个片段包含时间戳、上下文、状态观察和动作序列。
  - 合成数据增强：基于真实轨迹生成行为画像（Text-to-Persona），并进一步生成新画像（Persona-to-Persona），利用 LLM 生成意图轨迹，再用 GUI 智能体（UI-TARS-1.5-7B）在安卓模拟器上执行得到动作轨迹。
  - 质量验证：两步过滤——①用 Deepseek-R1 重建画像并计算余弦相似度（<0.7 剔除）；②用 Deepseek-R1 结合终端截图评估轨迹是否达成意图。保留率分别为 92.63% 和 87.03%。
  - 最终规模：52 个应用、360 个画像、72,511 个意图、超过 70 万个动作；三个子集：RR（真实画像-真实轨迹）、RG（真实画像-生成轨迹）、GG（生成画像-生成轨迹）。
- **Agent 架构**（Act2Intention Agent）：
  - **意图理解**：先由 VLM 将动作与前后截图转换为动作描述（格式：`[On/In] App, Action, to Purpose`），再由 SFT 后的 LLM 进行会话分割（找到意图边界）和意图描述（为每个片段生成自然语言标签）。
  - **意图预测**：输入历史意图序列 `I_1:t`、用户画像 `P`、当前时间 `T`，预测下一个意图及其类别。训练采用 SFT，数据来自基准中的连续轨迹，长度为 50。
  - **意图执行**：当预测意图被用户确认后，先从记忆中检索相似历史轨迹作为经验，再将意图、经验轨迹和当前观察输入 GUI 智能体（如 UI-TARS），迭代决策下一步动作，直至完成任务。
- **核心公式**（文字说明）：
  - 意图分段：`I_1:m = f_φ({d_p_i, ..., d_q_i})`，即从动作描述序列中同时进行分段和意图解释。
  - 意图预测：`hat{I}_{t+1} = f_θ(I_1:t, T, P)`。
  - 意图执行：`a_{t+1} = f_π(I, h_{t-1}, o_t, τ*)`，其中 `τ*` 为检索到的相似历史操作轨迹。

## 3. 实验设计

- **数据集/场景**：
  - 使用自建的 Act2Intention Bench，划分为训练集、ID 测试集和 OOD 测试集。ID 测试集来自 RR 子集 80 名用户的后 20% 数据，OOD 测试集来自另外 10 名用户的随机数据。
  - 执行任务在安卓模拟器中进行评估。
- **对比方法**：
  - **意图理解与预测**：闭源模型（GPT-3.5/4o/4o-mini、Claude-3.5、Gemini-1.5-pro、Qwen-max）和开源模型（Qwen2.5-7B、Llama3.1-8B、Deepseek-7B、Mistral-7B）及其 SFT 版本。
  - **意图执行**：UI-TARS-2B-SFT、UI-TARS-7B-SFT、GUI-R1-3B、CogAgent-9B，并对比有无经验引导轨迹。
- **评测指标**：
  - 理解：分段准确度（Acc-G）、语义准确度（Acc-S，基于嵌入余弦相似度）、词汇相似度（BLEU-4）。
  - 预测：类别准确度（Acc-C）、Acc-S、BLEU-4。
  - 执行：步骤成功率（SSR，需与参考动作逐位匹配）。
  - 端到端：预测意图的 Acc-S 以及在线执行的任务成功率（SR）。
- **主要结果**：
  - SFT 带来显著提升：如 Qwen2.5-7B-SFT 在理解上 Acc-G 从 12.14% 升至 100%，Acc-S 从 0.24 升至 0.49；Llama3.1-8B-SFT 在预测上 Acc-C 达 54.2%，比基础模型提升 +16.4。
  - 经验引导的执行：UI-TARS-2B-SFT 的 SSR 从 47.0 提升至 56.9（+9.9），UI-TARS-7B-SFT 从 59.6 提升至 62.8（+3.2）。
  - 端到端最佳 SR 为 22.7%（Llama3.1-8B-SFT 理解/预测 + UI-TARS-7B-SFT），而使用真实意图时 SR 升至 47.6%，说明意图预测是当前主要瓶颈。

## 6. 主要结论与发现

- Act2Intention Bench 是首个支持连续“意图-动作”轨迹的移动主动智能体基准，能够有效训练和评估意图理解、预测与执行。
- 在基准上做 SFT 能显著提升各模型在理解、预测和执行上的性能，且轻量级开源模型（如 7B/8B）在微调后可以超过更大的闭源模型。
- 意图理解与预测的解耦是有益的：直接从原始动作预测意图会显著降低性能。
- 执行阶段引入历史经验引导能稳定提高操作成功率，但完整端到端系统仍受限于预测不准和长序列执行鲁棒性不足。

## 7. 优点

- **问题新颖**：首次明确提出移动智能体应从“反应式”转向“主动式”，并落地为“理解-预测-执行”的完整闭环。
- **基准价值高**：大规模、多应用、连续轨迹，兼顾真实数据与合成数据的可扩展性，为后续研究提供标准化评测平台。
- **模块化设计**：意图理解、预测、执行可解耦，分别适配不同模型，便于分工研究和持续迭代。
- **消融系统**：对描述模型、理解模块、训练集构成、画像作用等进行了多角度验证，研究严谨。
- **实用导向**：设计了置信度回退和用户确认机制，贴近真实部署需求。

## 8. 不足与局限

- **性能瓶颈**：意图预测准确率仍有限，端到端 SR 不高（最佳 22.7%），离实用化有较大距离。
- **泛化风险**：SFT 后 OOD 性能下降，说明模型可能过拟合训练分布；数据仅覆盖 90 名参与者和 52 个应用，缺乏人口统计信息，存在用户群体偏差。
- **合成数据局限**：生成轨迹可能带有理想化或刻板模式，不能完全替代真实多样行为。
- **缺少干预时机建模**：基准聚焦于“预测什么”，未考虑“何时打断用户”，对用户接受度和打扰成本缺乏评估。
- **缺乏用户研究**：没有在真实用户环境中验证建议的有用性、及时性和非侵入性。
- **隐私与效率**：部署涉及截图与个人历史数据，需隐私保护；大模型在移动端的延迟和能耗问题未解决。
