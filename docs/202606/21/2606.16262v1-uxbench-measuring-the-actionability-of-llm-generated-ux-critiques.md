## 摘要
大型语言模型（LLMs）越来越多地被部署为UX评判者，用于检查界面、诊断可用性问题并提出修复建议。然而，目前还没有受控的基准来衡量这些评论在不同产品表面上的可靠性和可操作性。我们引入了UXBench，这是一个用于评估LLMs作为交互基础的UX评判者的基准。UXBench包含覆盖十个产品表面系列的本地优先可运行的Web测试夹具，并配以覆盖率门控的浏览器探索，迫使模型在报告之前收集交互证据。每个评判模型在七个评估维度上生成结构化的UX报告；报告质量通过一个固定的下游修复代理是否能够基于评论改进界面来衡量。我们在自动化修复提升协议和盲人人工验证研究下评估了八个前沿模型。结果表明，UX评判既未饱和也非一维：模型在报告可操作性上存在显著差异，展现出不同的维度级修复特征，夹具级可靠性各不相同，并在不同表面类别上存在领导力权衡。

## Abstract
Large language models (LLMs) are increasingly deployed as UX judges that inspect interfaces, diagnose usability problems, and propose repairs. Yet no controlled benchmark measures whether the resulting critiques are reliable and actionable across heterogeneous product surfaces. We introduce UXBench, a benchmark for evaluating LLMs as interaction-grounded UX judges. UXBench comprises local-first runnable web fixtures spanning ten product-surface families, paired with coverage-gated browser exploration that forces models to collect interaction evidence before reporting. Each judge model produces a structured UX report over seven rubric dimensions; report quality is measured by whether a fixed downstream repair agent can improve the interface based on the critique. We evaluate eight frontier models under both an automated repair-lift protocol and a blind human validation study. Results show that UX judging is neither saturated nor one dimensional: models differ meaningfully in report actionability, exhibit distinct rubric-level repair signatures, vary in fixture-level reliability, and trade leadership across surface categories

## 6. 论文的主要结论与发现

1. **UX 评判能力未饱和，模型间差异显著**：GPT-5.4 取得最高修复提升（+0.22），Gemini 3.1-Pro 最低（+0.14），表明目前前沿模型并非可互换的 UX 评判者。
2. **模型呈现不同的维度级修复签名**：如 GPT-5.4 在错误恢复上最强，Kimi K2.5 在反馈和信任透明度上领先，Claude Sonnet 4.6 在目标清晰度上最强，Qwen 3.6 在流程效率和可扫描性上最强。聚集总分类似的模型其能力分布不同。
3. **模型在夹具级可靠性不同**：高平均提升的模型（如 GPT-5.4）夹具间方差较大，稳定性较低；低平均提升模型可能更一致但峰值较低。
4. **领导力随表面类别变化**：在文档类上 GPT-5.4 最强，在仪表板上 Gemini 3.1-Pro 最强，在聊天机器人上 Sonnet 4.6 最强。分类别胜率矩阵显示没有单一模型主导所有类别。
5. **成对胜率揭示顶级集群**：GPT-5.4、Kimi K2.5、GLM 5.1 形成约 0.57 胜率的上集群，但相互之间接近 0.5 并非严格排序。
6. **人工验证确认自动信号但加强区分**：人工评分中 GPT-5.4 和 Claude Sonnet 4.6 组成更清晰的头部，而自动评分中一些模型（如 GLM 5.1）的修复提升未能转化为同样高水平的人类感知质量。人机评分相关系数为 Spearman ρ=0.635，方向一致但排名非严格匹配。

## 7. 优点

1. **创新评估框架**：将 UX 评判评价从静态截图/偏好比较提升为**交互证据驱动的报告条件修复问题**，更接近真实 UX 评估流程。
2. **可控且可复现的基准**：本地静态 fixtures 消除环境漂移，配有真实锚点和合成兄弟组合，兼顾外部效度与对照能力。
3. **覆盖率门控机制**：强制模型在停止前充分探索，确保报告基于交互证据而非浅层印象，提高评估有效性。
4. **多维细致分析**：不仅报告总分，还按维度、表面类别、夹具、成对胜率等多粒度进行分析，揭示模型能力异质性。
5. **结合自动化与人工验证**：自动评分提供高效率筛选，人工盲评提供校准和外部验证，提升结论可信度。

## 8. 不足与局限

1. **静态夹具限制**：本地静态网页无法模拟生产环境中的个性化、后端错误、第三方服务波动等动态特性，可能低估或高估模型在真实产品上的表现。
2. **可操作性的间接度量**：报告可操作性通过单一固定修复代理（Claude Code）和单一评分器（GPT-5.4-Mini）衡量，结果可能依赖这些固定组件的偏好；其他修复工具或评分器可能给出不同排名。
3. **人工验证规模有限**：仅 6 名评审员，且均为专家，不代表普通用户群体；评审员间一致性未详细报告（论文未提 Kappa 等指标），可能存在主观偏差。
4. **模型覆盖不全**：只评估了 8 个前沿模型，缺乏对更多开源小模型或早期模型的对比，也未探索模型大小与 UX 评判能力的关系。
5. **未评估移动原生应用**：fixtures 仅限 web 界面，虽然包括移动视口模拟，但未覆盖原生 iOS/Android 应用的特殊交互模式。
6. **资源消耗未透明**：论文未提及每个模型在一次评估中的平均调用次数、token 消耗、推理时间等，不利于复现和成本估算。
7. **评分器自身偏见**：使用 GPT-5.4-Mini 作为固定评分器，其自身对某些类型的修复风格可能更偏好，造成系统偏差。论文通过人工验证部分缓解，但未做评分器消融实验。
