## 摘要
对于LLM代理来说，长期记忆不仅仅是适时检索正确的段落。当前的记忆系统将信念修正、因果耦合和跨领域抽象压缩到一个为表面回忆而调整的单一检索面上，因此在需要对用户如何演变进行推理的隐式个性化任务中表现不佳。我们提出了DCPM，它沿着认知能力层级重新组织代理记忆，从原始输入和原子事实，经过历时信念轨迹和身份，到领域模式、潜在意图和跨领域模式，逐级上升。该层级由继承双过程理论架构分离的两个过程驱动：同步的日间写入器（系统1）将信念修正记录为双重链接的取代链，以及异步的夜间引擎（系统2）归纳模式和意图，并扫描跨领域碰撞，将其抽象为更高级的核心模式。在LongMemEval、PersonaMem和PersonaMem-v2上，系统2的启用贡献最大之处在于基准测试奖励隐式跨会话推理（在PersonaMem-v2上最多提升+5.20），而在跨度回忆上贡献最小，这与架构预测一致。

## Abstract
Long-term memory for an LLM agent is more than retrieving the right passage at the right time. Current memory systems collapse belief revision, causal coupling, and cross-domain abstraction into a single retrieval surface tuned for surface recall, and consequently struggle on implicit personalisation that requires reasoning over how a user has evolved. We propose DCPM, which reorganises agent memory along a cognitive capability hierarchy ascending from raw inputs and atomic facts, through diachronic belief trajectories and identity, to domain schemas, latent intentions and cross-domain patterns. The hierarchy is driven by two processes inheriting the architectural split of dual-process theory: a synchronous daytime writer (System1) that records belief revisions as doubly linked supersedes chains, and an asynchronous nighttime engine (System2) that induces schemas and intentions and sweeps for cross-domain collisions abstracted into higher-level core schemas. On LongMemEval, PersonaMem and PersonaMem-v2, enabling System2 contributes most where the benchmark rewards implicit cross-session inference (up to +5.20 on PersonaMem-v2) and least on span recall, matching the architectural prediction.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：现有LLM代理的长期记忆系统将信念修正、因果耦合和跨领域抽象压缩到单一的检索表面（通常为向量检索或知识图谱），仅优化于表面回忆（surface recall）。这导致系统无法处理**隐式个性化**（implicit personalisation）任务——即需要推理用户如何随时间演变、偏好如何迁移、跨领域行为如何关联的情形。
- **整体含义**：作者指出“记忆即存储”与“记忆即认知”的混淆，主张按**认知能力层级**而非存储层级组织记忆，使代理具备类似人类的记忆重构、历时跟踪和抽象归纳能力，从而支持自我演化。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- **认知能力层级**：从底层到高层依次为：
  1. 原始输入（raw inputs）
  2. 原子事实（atomic facts）和身份项（identity items）
  3. 历时信念轨迹（diachronic belief trajectories）——通过取代链（supersedes chains）记录修订
  4. 领域内行为模式（within-domain schemas）
  5. 潜在意图（latent intentions）
  6. 跨领域核心模式（cross-domain core schemas）
- **双过程架构**：继承双过程理论（Kahneman, 2011）的架构分离：
  - **系统1（日间写入器）**：同步、按需调用，负责实时写入原始输入、提取事实与身份、进行调和（reconcile）并建立双向取代链。
  - **系统2（夜间引擎）**：异步、空闲时运行，负责对新鲜事实聚类、归纳模式和意图、扫描跨领域碰撞并抽象为更高级的核心模式。

### 关键技术细节

#### 系统1：同步日间写入器
- **触发条件**：仅在用户或应用显式调用 `add_memory` 时执行，而非每个对话轮次。
- **四步流程**：
  1. **原始持久化**：将原始输入直接写入向量存储，作为不可变基础。
  2. **提取**：提取LLM `Me` 从当前轮次+短历史窗口提取身份项（长期属性）和原子事实（单轮陈述），每个包含类型、主题、显著性、时间戳。
  3. **调和**：调和LLM `Mr` 将每个新项与向量存储中 top-k 最近邻比较，决定三种操作之一：
     - `ADD`：全新无矛盾
     - `SUPERSEDE`：矛盾或演化的版本
     - `UPDATE`：补充或扩展
     - 重复项被静默丢弃。
  4. **批量嵌入与取代链写入**：对保留项批量嵌入并写入，对于 `SUPERSEDE` 操作，添加双向指针 `n_new.SUPERSEDES = n_old` 和 `n_old.SUPERSEDED_BY = n_new`，不删除旧项，形成双向链表。这是区别于原地更新系统的关键设计，保证历时连续性。

#### 系统2：异步夜间引擎
- **阶段1（预处理，无LLM）**：对未纳入任何模式或意图节点的新鲜事实进行两阶段DBSCAN聚类（初始ε=0.35，细化ε=0.25，min_samples=3），计算质心嵌入并检索就近现有图节点。
- **阶段2（LLM归纳）**：每个聚类调用一个归纳代理 `Ma`，使用四个工具（`CREATE_SCHEMA`、`CREATE_INTENTION`、`ADD_EVIDENCE`、`ADD_EDGE`）逐步构建图 `G`。图节点携带 `evidence_vdb_ref` 边指向支持事实。
- **阶段3（跨领域扫描器）**：
  - **行为抽象**：对每个模式节点，LLM抽象器生成简短行为描述（如“在沉没成本后升级承诺”），然后分别用嵌入器获得行为-认知空间嵌入 `E_beh` 和语义空间嵌入 `E_sem`。
  - **碰撞扫描**：枚举跨领域模式对 `(si, sj)`，当 `cos(E_beh(si), E_beh(sj)) > θ_beh` 且 `cos(E_sem(si), E_sem(sj)) < θ_sem` 时标记为碰撞。阈值分别为0.72和0.40（在PersonaMem-v2上调优）。
  - **核心归纳**：对每个碰撞簇，核心LLM `Mc` 归纳出更高级的核心模式节点，写回图 `G` 并与所有成员模式相连。

#### 读路径
- 查询嵌入对事实和身份存储进行向量相似度搜索，沿取代链遍历，并检索图 `G` 中通过 `evidence_vdb_ref` 连接的节点。**全程不调用LLM**，延迟主要由向量搜索决定。

#### 复杂度
- 写入：`O(N log N)`（HNSW）+ 每个轮次的LLM调用（提取+调和）。
- 系统2：预处理无LLM调用，归纳 `O(|C|)` 个LLM调用，扫描 `O(D·\bar{s})` 行为抽象调用 + `O((D\bar{s})^2)` 向量比较 + 每个碰撞簇一个核心归纳调用。实践中 `D ≤ 20`, `\bar{s} ≤ 30`。
- 读取：`O(log N + \bar{k})`，\bar{k}平均链长度≤4。

## 6. 主要结论与发现

1. **双过程架构有效地分离了实时记录与高层归纳**：系统1提供历时信念轨迹（取代链），系统2提供模式和跨领域抽象。两者在隐式个性化任务上协同增益显著。
2. **系统2贡献按任务类型呈现不对称性**：在需要隐式跨会话推理的PersonaMem-v2上，启用系统2带来最大提升（+2.51/+5.20）；在显式表面回忆任务上提升微小（LongMemEval +0.44/+0.33；PersonaMem +1.31/+2.41）。这验证了双过程理论的架构预测。
3. **跨领域碰撞（核心模式）是上层最大的贡献来源**：消融显示移除双空间碰撞导致4.10点下降，而进一步移除模式/意图仅额外下降1.10点。核心模式节点虽仅占全部节点的1.3%，却承载了约4.1个百分点的增益。
4. **取代链对信念恢复至关重要**：在知识更新子集上，78%的正确回答涉及至少一个取代指针（错误回答仅31%），链遍历是成功恢复信念状态的有力预测因子。
5. **DCPM full 在PersonaMem-v2上超过长上下文基线**（+1.10点），表明结构化记忆能有效克服长上下文中的“中间迷失”问题。
6. **读路径无LLM调用**，使得推理延迟与纯检索系统相似，保持了部署效率。

## 7. 优点

- **认知层级设计**：将记忆组织为认知能力递增的层级（原始→事实→轨迹→模式→跨领域），而非简单的存储层级，具有理论依据（Theory-of-Mind、双过程理论、重构记忆等）。
- **历时连续性**：通过双向取代链记录信念修订路径，而非覆盖旧信息，保留了中间状态和因果链条。
- **双过程分离**：系统1实时、轻量（少次LLM调用）；系统2异步、深度处理，资源友好且可解释。
- **读路径无LLM**：推理时仅向量搜索+指针遍历，高效可控，适合实际部署。
- **新颖的跨领域碰撞检测**：利用行为-语义双空间对比，自动发现表面不相关的行为模式之间的深层联系，生成核心模式。
- **丰富的分析实验**：除了准确率，还提供节点分布、链统计、定性示例、消融分解，增强了透明度和可理解性。
- **在最具挑战的基准上取得领先**：PersonaMem-v2上DCPM full达到59.30%（kimi），超过长上下文基线和所有基线，证明方法有效。

## 8. 不足与局限

- **实验覆盖有限**：仅限英文对话助手场景；未评估跨语言、具身代理或多智能体协作；未在更多样化基准（如LoCoMo、PerLTQA、LMEB）上测试；仅对比了Mem0、Zep/Graphiti，缺少与HippoRAG、A-MEM、CoALA等的直接对比。
- **双空间阈值未学习**：碰撞阈值（θ_beh=0.72, θ_sem=0.40）仅通过PersonaMem-v2 hold-out手工调优，可能过拟合该基准，缺乏鲁棒性。
- **潜在侵入性推断风险**：跨领域核心模式可能合成用户未明确链接的信息，产生用户感到冒犯的推断。作者虽提出隐私建议，但未在实验中评估这种风险。
- **系统2的计算成本随模式存储增长**：虽然D ≤ 20，但跨领域扫描在`(D\bar{s})^2`比较，在更广泛部署时可能成为瓶颈。
- **单领域用户收益有限**：对于历史集中在单一领域的用户，跨领域核心模式可能贡献有限。
- **自然语言节点的局限性**：模式、意图节点以自然语言存储，继承提取LLM的输出不确定性和冗长性，难以进行代数操作（如偏好集合交）。
