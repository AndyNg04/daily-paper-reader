## 摘要
空间推理是多模态大语言模型（MLLMs）在物理世界中感知和运作的基础能力。然而，现有基准测试主要依赖被动评估（如静态VQA）或特定模拟器的流程，未能评估通用的交互式空间理解。我们引入了SpatialWorld，这是一个专门设计用于评估多模态智能体在复杂真实世界任务中交互式空间理解能力的统一基准测试。SpatialWorld在共享的、与模拟器无关的协议下整合了八个异构模拟后端，涵盖了跨多个领域（如家务日常、旅行、社交协作）的760个人工标注任务。智能体必须在仅视觉部分可观测的条件下解决问题，主动收集以自我为中心的视觉证据，并通过MLLMs原生的、基于文本的统一动作接口表达决策。为了进行可靠评估，每个任务都包含一个经过人工验证的初始状态、一条参考轨迹和一个终端状态验证器。对15个先进智能体的评估显示，稳健的空间任务解决仍然具有挑战性：最强的模型GPT-5的平均任务成功率（TSR）仅为17.4%，而领先的开源模型Qwen-3.5达到了14.1%。进一步分析揭示了任务成功与执行效率之间的明显不匹配，以及显著的领域特定性能差异。这些在主动探索和长期规划方面的瓶颈使得SpatialWorld成为未来空间智能体的严格测试平台。

## Abstract
Spatial reasoning is a foundational capability for multimodal large language models (MLLMs) to perceive and operate within the physical world. However, existing benchmarks predominantly rely on passive evaluation (e.g., static VQA) or simulator-specific pipelines, failing to assess general interactive spatial understanding. We introduce SpatialWorld, a unified benchmark designed specifically for evaluating the interactive spatial understanding of multimodal agents in complex real-world tasks. Integrating eight heterogeneous simulation backends under a shared, simulator-agnostic protocol, SpatialWorld features 760 human-annotated tasks across diverse domains (e.g., household routines, travel, social collaboration). Agents must solve tasks under vision-only partial observability, actively gathering egocentric visual evidence and expressing decisions via a unified, text-based action interface native to MLLMs. For reliable evaluation, each task includes a human-validated initial state, a reference trajectory, and a terminal-state verifier. Evaluating 15 advanced agents reveals that robust spatial task solving remains challenging: the strongest model, GPT-5, achieves an average task success rate (TSR) of only 17.4%, while the leading open-source model, Qwen-3.5, reaches 14.1%. Further analysis exposes a clear mismatch between task success and execution efficiency, alongside substantial domain-specific performance variations. These bottlenecks in active exploration and long-horizon planning position SpatialWorld as a rigorous testbed for future spatial agents.

- **核心问题：** 当前的多模态大语言模型（MLLMs）在没有特定模拟器训练的情况下，能否通过第一人称视觉观察、基于语言的高层决策，在异构的3D环境中进行闭环交互并完成真实世界的任务？现有基准无法公正评估这种通用的交互式空间推理能力。
- **整体含义：** 本文提出了一个名为 **SpatialWorld** 的统一基准，旨在创建一个通用的、与模拟器无关的测试平台，以严格评估多模态智能体的主动探索、空间理解和长期规划能力，并揭示了当前最先进的模型在这方面的巨大不足。

### 2. 论文提出的方法论

- **核心思想：** 设计一个跨平台、统一的评估框架，将异构的3D环境抽象出来，提供标准的交互接口，使评估只关注于智能体的视觉感知、空间推理和决策能力，而非特定模拟器的适配。
- **任务形式化：** 每个任务被形式化为一个“仅视觉”的部分可观测马尔可夫决策过程（POMDP） `<S, O, A, T, Ω, R>`。智能体只能接收自然语言指令和第一人称RGB图像，没有深度图或全局地图等“特权信息”（Privileged State）。
- **关键技术细节：**
    1.  **统一接口：** 设计了**观测接口**（统一提供第一人称RGB图像）和**动作接口**（将复杂模拟器指令抽象为高层、基于文本的标准动作，如`move forward`, `pick up`, `rotate right`, `Done`等）。这使得通用的MLLM无需针对性微调即可在不同环境中工作。
    2.  **动作空间抽象**：将底层模拟器指令映射为四类高层原语：**导航**（如移动）、**视角与姿态**（如旋转）、**交互**（如拾取/放置、改变物体状态）、**任务控制与协调**（如结束任务）。
    3.  **执行验证机制**：采用终端状态验证（Terminal-state Verification）而非轨迹匹配。每个任务都有一个自定义的验证器 `Vi`，检查最终环境状态是否满足“成功条件”，从而允许模型通过多种路径完成任务，评估更灵活和开放。
- **算法流程**（文字描述）：智能体与环境进行多轮交互。在每一步 `t`，智能体接收指令 `g` 和当前第一人称视图 `ot`。基于历史轨迹 `Ht`，策略 `πθ` 预测并输出一个高层动作 `at`。模拟器执行该动作，更新隐藏环境状态 `st+1`，并返回下一帧视觉观测 `ot+1`。此过程循环直至智能体执行 `EndTask` 或达到最大步数。

### 3. 实验设计

- **使用的数据集/场景：** **SpatialWorld 基准**，包含 760 个由人工标注的任务，横跨多个领域：

    - **底层仿真后端：** 整合了8个异构模拟器，包括室内模拟（AI2-THOR, ProcTHOR, VirtualHome）、户外导航（CARLA, EmbodiedCity）、这些模拟器的多智能体变体，以及简化但聚焦几何推理的3D游戏（如魔方、迷宫）。
- **对比的方法：** 评估了 15 个最先进的多模态大模型（MLLMs），涵盖了开源和闭源两大阵营：

- **评估指标：**
    - **主要指标：** 任务成功率。
    - **效率指标：** 步骤效率，衡量在成功完成任务时，模型执行步骤与人类标注参考步骤的比值。

### 6. 论文的主要结论与发现

1.  **当前模型与真实世界空间任务存在巨大鸿沟**：最强大的模型GPT-5在物理世界任务中平均成功率仅为 **14.4%**，而最好的开源模型Qwen-3.5也仅为 12.2%，表明交互式空间推理仍是巨大挑战。
2.  **成功与效率不匹配**：高成功率并不一定意味着高执行效率。例如，Kimi-K2.5与GPT-5.4成功率相近，但其步骤效率显著低于后者，表明其成功更依赖于更多的试错。
3.  **空间复杂性需要多维度评估**：没有一个模型在所有领域都表现最佳。GPT-5在家庭日常和旅行任务中领先，而在数字游戏领域Gemini-3.1-Pro最佳。这表明不同任务需要不同的空间推理能力，单一排名不足以反映全貌。
4.  **核心瓶颈在于主动探索与长期规划**：很多模型的失败源于过早终止任务或在原地打转，无法进行有效的长程探索和规划。
5.  **感知与推理的分离**：研究发现，图像分辨率对最终空间推理性能影响不大，表明模型的瓶颈主要在于认知和决策层面，而非底层的视觉感知。

- **高度解耦的架构**：通过设计统一的观测和动作接口，成功地将MLLMs的推理过程与底层模拟器的物理实现解耦，使评估只关注模型的核心智能。
- **严谨的评估流程**：采用人类验证的初始状态、参考轨迹和终端状态验证器，确保了任务的可实现性和评估结果的可靠性、可重复性。
- **深入的错误分析**：不仅报告了成功率，还对失败模式（如空间迷失、物体幻觉、过早中止、行动循环）进行了定性和定量分析，具有很强的诊断价值。

### 8. 不足与局限

- **模拟与现实的差距**：作为基准，所有任务均在模拟器中进行，虽然模拟器很逼真，但与真实世界的物理属性、传感器噪声和不可预测性仍有差距，模型的表现在真实环境中可能会显著下降。
- **任务规模的有限性**：为了保证人工标注的质量，当前基准包含760个任务，规模相对较小。作者也指出，与自动生成的基准相比，其覆盖的多样性有限，未来可以扩展。
- **偏差风险**：尽管宣称“与模拟器无关”，但动作空间的设计（如移动步长、交互定义）可能仍然隐含了对特定模拟器特性的适应，存在一定偏差。同时，标注者的偏好也可能引入偏差。
- **应用限制**：论文主要定位于诊断和研究工具，直接应用于构建可靠的家用机器人等现实场景仍存在巨大挑战。此外，能力增强可能被滥用于监控或恶意物理交互，需要配套的安全指南。
