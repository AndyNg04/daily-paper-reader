## 摘要
AI智能体通常通过任务成功率、奖励、延迟和成本进行评估。这些指标虽然有用，但常常忽略智能体行为的重要方面：智能体是否探索过多、是否过于僵化地重复自身、是否有效使用工具、是否随时间减少不确定性、或在多次运行中保持鲁棒性。本文提出基于熵的AI智能体评估（EEA），一种通过熵来测量智能体行为的轻量级框架。EEA不将智能仅视为最终任务完成情况，而是研究智能体决策过程的结构。该框架引入了行动熵、轨迹熵、工具熵、信息增益、探索效率和鲁棒性熵。这些指标旨在补充而非替代传统评估方法。我们还提供了一种实用的Python实现，旨在与LangChain、Google ADK、自定义智能体循环以及存储的可观测性轨迹等智能体框架集成。

## Abstract
AI agents are commonly evaluated using task success, reward, latency, and cost. These metrics are useful, but they often miss important aspects of agent behavior: whether an agent explores too much, repeats itself too rigidly, uses tools effectively, reduces uncertainty over time, or remains robust across repeated runs. This paper proposes Entropy-Based Evaluation of AI Agents (EEA), a lightweight framework for measuring agent behavior through entropy. Rather than treating intelligence as only final task completion, EEA studies the structure of the agents decision process. The framework introduces action entropy, trajectory entropy, tool entropy, information gain, exploration efficiency, and robustness entropy. These metrics are intended to complement, not replace, traditional evaluation methods. We also present a practical Python implementation designed to integrate with agent frameworks such as LangChain, Google ADK, custom agent loops, and stored observability traces.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：当前AI智能体评估主要依赖任务成功率、奖励、延迟和成本等传统指标，但这些指标无法捕捉智能体的行为模式差异，例如：过度探索、僵化重复、工具使用效率低下、决策不确定性变化、跨运行鲁棒性等。两个智能体可能都能完成任务，但一个直接高效，另一个却通过不必要的工具调用或混乱的推理路径完成；两个智能体可能都失败，但一个在收集有用证据后失败，另一个则随机失败。传统指标无法区分这些行为特征。
- **整体含义**：论文提出一种轻量级框架——基于熵的AI智能体评估（EEA），通过信息论的熵来量化智能体决策过程的结构化特征，作为传统评估的补充。EEA旨在揭示智能体行为模式，帮助研究者和工程师更深入地比较和设计智能体。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 将智能体的每次运行表示为事件序列（工具调用、模型调用、规划步骤、行动、最终答案等）。
- 利用信息熵衡量智能体行为的不确定性、多样性、集中度和不确定性变化。
- 不试图定义通用智能，而是提供一组可量化的行为信号。

### 关键技术细节（六个熵指标）

1. **行动熵（Action Entropy）**  
   - 测量智能体在一次或多次运行中行动的多样性。  
   - 公式：\( H_A = -\sum_i p(a_i) \log_2 p(a_i) \)，其中 \( p(a_i) \) 是行动 \( a_i \) 的概率。  
   - 低熵表示行动集中（可能僵化），高熵表示探索（可能不稳定）。

2. **轨迹熵（Trajectory Entropy）**  
   - 测量完整策略路径的多样性。用于同一任务多次运行或比较不同智能体。低轨迹熵表示智能体总是走相同路径，高轨迹熵表示使用多种策略。

3. **工具熵（Tool Entropy）**  
   - 测量智能体使用工具的分布情况。低值表示工具使用高度集中（专门化），高值表示广泛探索或低效选择。

4. **信息增益（Information Gain）**  
   - 测量智能体在收集证据前后对假设分布的不确定性减少程度。  
   - 公式：\( IG = H_{\text{before}} - H_{\text{after}} \)。正增益表示减少不确定性，负增益表示更不确定。需暴露概率分布时可用。

5. **探索效率（Exploration Efficiency）**  
   - 结合成功率和行动熵：\( EE = \frac{S}{H_A + \epsilon} \)，其中 \( S \) 是成功率，\( \epsilon \) 避免除零。奖励低行为随机性下的成功，但也承认困难任务可能需要更多探索。

6. **鲁棒性熵（Robustness Entropy）**  
   - 多次运行相同任务，比较轨迹熵与结果熵。理想模式：中等轨迹熵、低结果熵、高成功率、可控成本。

- **复合分数**：可配置的**熵智能体分数（EAS）**，综合有用不确定性减少、任务成功、行为熵和成本，用于特定基准的比较信号。

### 实现细节
- 提供Python包 `entropy-agent-eval`，定义框架无关的数据契约（`AgentRun` 表示）。  
- 核心指标计算器（`EntropyEvaluator`）、命令行界面、事件记录器、LangChain/Google ADK适配器、基准测试封装、可选绘图工具。  
- 不依赖任何智能体框架，可与实时回调、导出日志、数据库跟踪、可观测性系统集成。  
- 论文开源代码：https://github.com/olahsymbo/agent-eval

## 3. 实验设计

## 6. 论文的主要结论与发现

- **熵指标能捕捉传统指标遗漏的行为差异**：例如，直接LLM智能体轨迹熵最低但成功率也低；规划器-执行器成功率和信息增益最高但成本、延迟和行动熵也最高；ReAct智能体显示出不同的工具使用模式。这些差异无法从成功率看出。
- **跨框架比较可行**：学习路线图智能体在LangChain和Google ADK上表现相似（动作熵和工具熵相同），说明EEA能提供统一的行为表示。Google ADK的信息增益和EAS略高，但成本数据缺失，不能简单推为更优。
- **EEA是传统评估的补充**：不应单独使用熵指标，需结合成功率、成本、延迟和人工判断。

## 7. 优点

- **轻量级且框架无关**：不依赖特定智能体框架，易于集成到现有系统（LangChain、ADK、自定义循环、可观测性日志）。
- **指标可解释**：熵具有信息论基础，直观反映行为的不确定性、多样性和集中度。
- **行为洞察丰富**：能揭示智能体是否过度探索、僵化、工具分配是否合理、不确定性是否有效降低。
- **可视化支持**：提供绘图工具，便于分析。
- **开源实现**：代码公开，易于复现和扩展。
- **强调补充性**：明确指出熵指标不是取代传统指标，而是提供额外视角。

## 8. 不足与局限

- **实验覆盖不足**：真实实验仅6次运行，缺乏多次重复和统计检验；任务类型单一（路线图生成）。
- **偏差风险**：自动评分可能无法评估内容质量；成本核算不完整（Google ADK成本显示为零是数据缺失）。
- **应用限制**：
  - 某些指标依赖轨迹质量：若智能体框架不暴露中间步骤、工具调用或不确定状态，只能计算部分指标。
  - 熵值需结合上下文解释：高熵可能好（探索）或坏（混乱），低熵可能好（专注）或坏（僵化）。同一数值在不同难度、设计下含义不同。
  - 未处理连续动作空间或高维行为。
  - 框架仅适用于可分解为离散事件序列的场景。
- **缺乏消融实验**：未分析每个指标对整体评估的贡献或冗余。
- **未与人类评估对比**：没有验证熵指标是否与人类对智能体行为质量的主观判断一致。
