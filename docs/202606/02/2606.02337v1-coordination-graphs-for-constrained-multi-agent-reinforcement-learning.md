## 摘要
约束多智能体强化学习（CMARL）面临两个相互交织的挑战：联合动作空间随智能体数量呈指数级增长，以及额外的约束条件以奖励结构本身无法捕捉的方式将智能体耦合在一起。我们提出面向约束多智能体强化学习的协调图（CG-CMARL），该框架通过将协调图与拉格朗日对偶性相结合来应对这两个挑战。该系统将联合问题分解为成对区域，每个区域由一组共享Q函数服务，其中一个用于主要目标，每个约束对应一个，使得学习模型的数量与智能体数量无关。在运行时，Max-Sum消息传递在因子图上协调动作，而拉格朗日乘子控制目标-约束权衡，使得单个训练好的模型无需重新训练即可追踪帕累托前沿。我们在温和条件下提供了收敛保证，以及一个组合误差界，该误差界可分解为多个可解释的独立来源，每个来源均可追溯到特定的设计选择并独立可控。在协作导航任务（其中最多10个智能体的团队必须协调到达目标位置同时满足成对约束）上的实验表明，我们的方法产生的帕累托前沿优于在固定奖励塑造比率下训练的主流基线，同时可扩展到集中式方法难以处理的团队规模。

## Abstract
Constrained Multi-agent reinforcement learning (CMARL) faces two intertwined challenges: the joint action space grows exponentially with the number of agents, and additional requirements couple agents in ways that reward structure alone does not capture. We introduce Coordination Graphs for Constrained Multi-Agent Reinforcement Learning (CG-CMARL), a framework that addresses both challenges by combining coordination graphs with Lagrangian duality. The system decomposes the joint problem into pairwise regions, each served by a set of shared Q-functions, one for the primary objective and one for each of the constraints, so that the number of learned models is independent of the number of agents. At execution time, Max-Sum message passing coordinates actions across the factor graph, while a Lagrangian multiplier controls the objective--constraint tradeoff, allowing a single trained model to trace a Pareto front without retraining. We provide convergence guarantees under mild conditions, together with a compositional error bound that decomposes into separate interpretable sources, each traceable to a specific design choice and independently controllable. Experiments on cooperative navigation tasks (where teams of up to 10 agents must coordinate to reach target positions while satisfying pairwise constraints) show that our method produces Pareto fronts dominating established baselines trained at fixed reward-shaping ratios, while scaling to team sizes where centralized approaches become intractable.

- **核心挑战二：安全约束耦合问题**。许多多智能体任务（如碰撞避免、能量预算、带宽限制）施加的安全约束不仅依赖于奖励结构，而且会以奖励本身无法捕捉的方式耦合智能体。独立学习者无法协调约束满足：若每个智能体独立优化自己的拉格朗日乘子，团队可能集体违反全局约束。
- **已有工作的不足**：集中式原始-对偶方法需要访问全局状态和联合动作空间，这正是因子化方法试图克服的瓶颈；现有因子化方法（DCG、QMIX等）无法处理显式CMDP风格约束；而约束方法（MACPO、MAPPO-Lagrangian等）并未利用协调图实现分布式执行。
- **本文目标**：首次将协调图的可扩展性与拉格朗日方法的约束处理能力结合在一个去中心化架构中，并提供收敛保证。

## 2. 论文提出的方法论：核心思想、关键技术细节

**核心思想**：  
CG-CMARL 在协调图的每个成对区域（pairwise region）上维护**两个Q函数头**（主目标Q和约束Q），并通过参数共享使学习模型数量为 O(1)（与智能体数量无关）。在行动选择时，通过拉格朗日乘子 λ 将两个Q头线性组合得到增广Q函数，然后通过 Max-Sum 消息传递协调联合动作。训练完成后，通过改变 λ 值即可追踪覆盖–安全帕累托前沿，无需重新训练。

**关键技术细节**：

1. **双Q函数头架构**：
   - 主Q函数 `Q_prim,R`：对主要奖励进行标准Q学习，目标更新为：  
     `y_prim = r0_R + γ * max_{a'_R} Q_prim,R(s'_R, a'_R)`
   - 约束Q函数 `Q_cost,R`：对约束奖励进行**策略评估**，目标更新使用主头贪心动作：  
     `y_cost = r1_R + γ * Q_cost,R(s'_R, argmax_{a'_R} Q_prim,R(s'_R, a'_R))`  
     这种设计确保约束Q预测的是**在主目标贪心策略下**的约束值，从而避免两种Q函数反映不同策略导致的不一致性。
   - 参数共享：所有成对区域（共 C(N,2) 个）共享同一组Q网络参数，使学习模型数量为 O(1)。

2. **Max-Sum 消息传递**：
   - 在因子图上迭代执行因子到变量和变量到因子消息，采用阻尼（damping）以稳定收敛（d=0.3）。
   - 消息复杂度：O(N² * |A| * K)，多项式于智能体数，且远优于指数级集中式搜索。

3. **拉格朗日约束处理**：
   - 训练时每个智能体维护本地乘子 λ_i，每回合后根据观测到的约束奖励进行投影对偶上升：  
     `λ_i ← clip(λ_i - η*(V_hat_i - c_thresh), [0, λ_max])`
   - 行动选择时使用平均乘子 `¯λ = (1/N) Σ λ_i` 构造增广Q：`Q_aug = Q_prim + ¯λ * Q_cost`
   - 评估时直接外部指定 λ，扫描不同 λ 值即可获得整个帕累托前沿。

4. **区域观测构造**：每个成对区域只使用本地可观测信息（两个智能体的速度、位置、所有地标位置、相对位置），确保完全去中心化执行。

5. **信用分配**：采用每个智能体的反事实奖励（difference rewards）计算区域主奖励，提供更细粒度的信用分配。

## 3. 实验设计：使用的数据集/场景、基准测试、对比方法

**实验环境**：  
Simple Spread 环境（来自 MPE 套件），N 个智能体需要覆盖 N 个地标（连续2D世界 [-1,1]²），同时避免碰撞。该环境满足独立转移（A1）和奖励可加性（A2）两个结构假设。

**团队规模**：N ∈ {3, 4, 6, 10}。对于 N>4 时自动缩放智能体半径以避免过度拥挤。

**对比方法**：
- **IQL**（独立Q学习，无协调）
- **QMIX**（单调混合网络）
- **DCG**（深度协调图，但无约束处理）
- **MAPPO**（多智能体PPO基线，共享奖励）
- **MAPPO-Lagrangian**（MAPPO扩展拉格朗日乘子处理约束）

对于基于价值的方法（IQL、QMIX、DCG），通过固定碰撞惩罚混合比例 α ∈ {0.0, 0.3, 0.6} 控制覆盖–安全权衡，每个混合比例产生一个操作点。MAPPO-Lagrangian 在训练中学习自己的乘子但冻结于训练后的 actor 中，因此也只产生一个点。

**评估指标**：
- **覆盖度（Coverage）**：每回合结束时至少有一个智能体在阈值距离内的地标比例。
- **碰撞（Collisions）**：每时间步平均重叠智能体对的数量（越低越好）。还计算了每对碰撞率以公平比较不同N。

**额外评估**：还在三个固定地标场景（spread_uniform、line、clustered_pair）上对每个训练好的模型进行了评估。
