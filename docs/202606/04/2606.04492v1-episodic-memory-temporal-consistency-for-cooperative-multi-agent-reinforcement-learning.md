## 摘要
合作多智能体强化学习常面临严重的奖励稀疏性和探索瓶颈。尽管情景记忆机制通过重用高回报轨迹缓解了这些问题，但由于激励分配无约束和语义表示坍塌，往往导致智能体陷入局部最优。为此，我们提出情景记忆时间一致性（EMTC）框架，该框架鲁棒地构建并选择性利用历史经验。EMTC引入两个协同组件：（1）时间一致性语义嵌入器，融合对比学习与时间条件状态重建，防止表示坍塌并实现精确记忆检索；（2）时间一致性门控机制，根据时间一致性误差动态调节情景激励。该自适应门控从伪成功轨迹中过滤误导信号，有效缓解Q值过估计。我们提供理论保证，建立了严格的误差界，将可观测的时间一致性误差直接关联到潜在轨迹最优性和表示质量。在SMAC和GRF基准上的广泛评估表明，EMTC持续优于最先进的基线方法。值得注意的是，与最强的情景基线相比，EMTC在超难SMAC场景中实现了高达24%的绝对胜率提升，在GRF任务中平均提升28%。

## Abstract
Cooperative Multi-Agent Reinforcement Learning (MARL) frequently suffers from severe reward sparsity and exploration bottlenecks. While episodic memory mechanisms mitigate these issues by reusing high-return trajectories, they often trap agents in local optima due to unconstrained incentive distribution and semantic representation collapse. To address this, we propose Episodic Memory Temporal Consistency (EMTC), a framework that robustly constructs and selectively leverages historical experiences. EMTC introduces two synergistic components: (1) a Temporally Consistent Semantic Embedder that integrates contrastive learning with time-conditioned state reconstruction, preventing representation collapse and enabling precise memory retrieval; and (2) a Temporal Consistency Gating Mechanism that dynamically modulates episodic incentives based on temporal consistency error. This adaptive gate filters misleading signals from pseudo-successful trajectories, effectively mitigating Q-value overestimation. We provide theoretical guarantees, establishing a strict error bound that directly links the observable temporal consistency error to the underlying trajectory optimality and representation quality. Extensive evaluations on the SMAC and GRF benchmarks demonstrate that EMTC consistently outperforms state-of-the-art baselines. Notably, compared to the strongest episodic baseline, EMTC achieves absolute win-rate improvements of up to 24% in super-hard SMAC scenarios and an average improvement of 28% across GRF tasks.

  - **表示坍塌（Representation Collapse）**：标准编码器过度强化时间序列特征，削弱空间语义判别性，导致有害状态被错误映射到成功经验簇中，破坏距离基记忆检索的有效性。
  - **Q值过估计（Value Overestimation）**：检索歧义直接引发激励失真——伪成功轨迹被盲目注入内在奖励，人为膨胀Q值，使智能体陷入局部最优，最终导致整局失败。
- **整体含义**：为解决上述问题，论文提出**情景记忆时间一致性框架（EMTC）**，旨在鲁棒地构建并选择性利用历史经验，打破传统的无约束激励分配和语义坍塌困境。

#### 2. 论文提出的方法论

- **核心思想**：EMTC 包含两个协同组件，形成一个两阶段流水线：先构建结构化的语义潜在空间确保检索精确性，再根据 Bellman 最优性准则动态门控激励，防止误导性信号污染策略优化。
- **关键技术细节**：

  - **时间一致性语义嵌入器（TCSE）**：
    - 双目标学习：使用确定性条件自编码器（dCAE）损失 \(L_{\text{dCAE}}\)（包含状态重建和最高回报预测）与对比学习 InfoNCE 损失 \(L_{\text{cl}}\) 的组合：
      \[
      L_{\text{total}} = L_{\text{dCAE}} + \lambda_{\text{cl}} L_{\text{cl}}
      \]
    - 对比学习正例由同一状态的两种数据增强（随机掩码 + 高斯噪声）生成，负例为其他不同时间或状态。
    - 时间条件：编码器 \(f_\phi(s, t)\) 同时接收状态和时间步，使嵌入既保留瞬时空间拓扑又锚定时间演进。
    - 结构化记忆缓存：每条记录存储原始状态 \(s_i\)、当前编码 \(x_i\)、最高回报 \(H_i\)、成功标志 \(\xi_i\) 以及下一状态索引 \(\text{idx}_{\text{next}}\)，支持动态重投影和因果链遍历。

  - **时间一致性门控机制（TCGM）**：
    - 计算时间一致性误差 \(\Delta_{\text{mem}} = |r + \gamma H(s') - H(s)|\)，衡量一步 Bellman 更新与实际存储值的偏差。
    - 通过高斯调制函数转换出门控系数：
      \[
      \beta(\Delta_{\text{mem}}) = \exp\left(-\frac{\Delta_{\text{mem}}^2}{2\tau^2}\right)
      \]
    - 温度 \(\tau\) 采用线性退火策略：初始较大（鼓励早期探索），后期较小（严格过滤伪记忆）。
    - 最终激励 \(\tilde{r}_p = \beta \cdot r_p\)，代替原始无约束内在激励融入 TD 损失 \(L_\beta^\theta\)。
  - **理论保证**：
    - 命题1：\(\Delta_{\text{mem}} \leq \Delta_{\text{opt}} + \alpha\)，其中 \(\alpha = (1+\gamma)(\epsilon_{\text{rep}} + \epsilon_{\text{store}})\)。TCSE 通过维持语义判别性保证 \(\epsilon_{\text{rep}}\) 有界。
    - 命题2：渐进无偏性——当策略趋近最优且记忆成熟时，门控梯度准确恢复最优梯度，不引入渐近偏差。
