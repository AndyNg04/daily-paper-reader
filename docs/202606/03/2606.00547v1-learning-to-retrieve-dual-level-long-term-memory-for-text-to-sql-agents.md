## 摘要
交互式Text-to-SQL智能体通过多轮交互解决数据库任务，包括模式探索、查询执行、反馈解释和决策修订。长期记忆有助于智能体重用过去的经验，但现有的检索方法仍然有限。静态方法依赖于固定的相似度启发式，无法优化下游效用；而动态方法通常从稀疏的最终结果中学习，并在单一决策范围内检索记忆。当记忆的有用性随交互阶段变化时，这种方法是不够的，因为初始规划有用的记忆可能不同于局部、状态条件执行所需的记忆。我们提出MERIT，一种动态多范围记忆检索框架。MERIT维护情节级记忆以获得全局策略指导，以及回合级记忆以支持局部决策。两个级别都使用通过强化学习训练的学习检索策略。为了在有限的中间监督下训练回合级检索，MERIT使用轻量级过程奖励模型为局部记忆选择提供密集代理奖励。在BIRD-Interact上的实验表明，MERIT在成功率上优于无记忆、静态检索和动态检索基线，同时减少了平均交互轮次。在Spider2-Snow上的迁移结果进一步显示了跨基准的正迁移，无需基准特定调优。这些结果表明，多范围检索改善了交互式Text-to-SQL智能体中的经验重用。

## Abstract
Interactive text-to-SQL agents solve database tasks through multi-turn interactions involving schema exploration, query execution, feedback interpretation, and decision revision. Long-term memory helps agents reuse past experiences, but existing retrieval methods remain limited. Static methods rely on fixed similarity heuristics that do not optimize downstream utility, while dynamic methods often learn from sparse final outcomes and retrieve memories at a single decision horizon. This is insufficient when memory usefulness changes across interaction stages, since memories useful for initial planning may differ from those needed for local, state-conditioned execution. We propose MERIT, a dynamic multi-horizon memory retrieval framework. MERIT maintains episode-level memory for global strategic guidance and turn-level memory for local decision support. Both levels use learned retrieval policies optimized with reinforcement learning. To train turn-level retrieval despite limited intermediate supervision, MERIT uses a lightweight Process Reward Model to provide dense proxy rewards for local memory selection. Experiments on BIRD-Interact show that MERIT outperforms no-memory, static-retrieval, and dynamic-retrieval baselines in success rate while reducing average interaction turns. Transfer results on Spider2-Snow further show positive cross-benchmark transfer without benchmark-specific tuning. These results suggest that multi-horizon retrieval improves experience reuse in interactive text-to-SQL agents.

# 论文总结：《Learning to Retrieve: Dual-Level Long-Term Memory for Text-to-SQL Agents》

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：交互式 Text-to-SQL 智能体（agent）通过多轮交互完成数据库查询任务，包括模式探索、SQL 执行、反馈解释和计划修订。长期记忆可以帮助智能体重用过往经验，但现有检索方法存在两大局限：
    - **静态方法**（如 BM25、余弦相似度）使用固定的相似度启发式，不优化下游任务效用。
    - **动态方法**（如 Memento、MemRL）虽然从最终结果中学习，但仅在单一决策范围（episode 级）检索，且仅依赖稀疏的终端奖励，无法适应交互过程中不同阶段对记忆需求的变化（例如：初始规划有用的记忆在 SQL 错误后的局部调试场景中可能不再相关）。
- **整体含义**：需要一种能够感知决策范围（horizon-aware）的记忆检索机制，同时支持全局策略指导和局部状态条件支持，以提升交互式 Text-to-SQL 智能体的经验和性能。

## 2. 方法论
- **核心思想**：提出 **MERIT**（Multi-horizon mEmory Retrieval with Intermediate and Terminal rewards）框架，维护两个级别的长期记忆：
    - **Episode 级记忆**：记录完整交互轨迹、任务约束、执行结果和提炼的策略洞察，在交互开始时注入，提供全局策略指导。
    - **Turn 级记忆**：记录状态签名、抽象动作、观察摘要和局部执行状态，在每轮交互前注入，提供状态条件下的局部提示。
- **关键技术细节**：
    - **两阶段检索流水线**：每个级别先通过嵌入相似度（cosine similarity）生成候选集，然后由**学习的选择器**（Selector）决定实际注入的记忆子集。
    - **强化学习训练选择器**：使用 PPO（Proximal Policy Optimization）优化两个选择器。
        - Episode 级选择器：基于终端任务奖励（最终 SQL 执行正确性）进行优化。
        - Turn 级选择器：面临信用分配问题（中间步的贡献难追溯），因此引入**过程奖励模型（PRM）** 提供密集代理奖励。PRM 对每个状态-记忆对输出一个结构化评分（7个维度，包括状态匹配、可行动性、模式泛化性等），最终转换为标量奖励 $r_t^T$ 用于 PPO。
    - **PRM 训练**：使用教师模型（GPT-5）标注状态-记忆对的结构化评分，先进行 SFT 模仿，再使用 GRPO（Group Relative Policy Optimization）优化，奖励函数包括维度评分匹配、二分类准确率、文本相似度等。
    - **数据增强**：采用 SQL 优先的合成管线——先对种子 SQL 进行受控扰动（列替换、数值修改、排序反转等），再生成完全指定和欠指定的自然语言请求以及消歧元数据，增强训练数据多样性和可执行性。
- **公式/算法关键点**：PRM 奖励函数包含 $R_{PRM} = \text{clip}(0.7R_{dim} + 0.2R_{bin} + 0.1R_{text} - 0.5 I_{extra}, -1, 1)$，其中 $R_{dim}$ 基于预测评分与教师评分的误差和 Jaccard 相似度计算。

## 3. 实验设计
- **数据集与 Benchmark**：
    - **BIRD-Interact**：用于域内评估。训练使用 BIRD-Interact-Lite（236 个基础任务，后通过数据增强扩充至约 7000 个示例），测试使用 BIRD-Interact-Full（600 个复杂任务）。结果分为 Phase 1（初始请求）和 Phase 2（状态相关的后续请求），并区分 READ 和 WRITE 操作。
    - **Spider2-Snow**：用于跨基准迁移测试。所有训练仅基于 BIRD-Interact，不做 Spider2-Snow 特定调优。
- **评估指标**：Success Rate（执行正确性）、Average Number of Interaction Turns。
- **对比方法**：
    - **无记忆**：Vanilla GPT-5（非 agent）、No Memory Agent、Demo Agent（官方静态演示）。
    - **静态检索**：BM25、Cosine Similarity、TopicK。
    - **动态检索**：Memento、MemRL（均为 episode 级动态方法）。
- **模型配置**：主 agent 使用 GPT-5（低推理 effort），用户模拟器用 GPT-4o。PRM 初始化为 DeepSeek-R1-Distill-Qwen-7B，选择器用 LoRA 微调的 Qwen3-4B-Instruct-2507。

## 6. 主要结论与发现
- MERIT 在 BIRD-Interact 上取得**最高成功率**（Phase 1: 33.01%，Phase 2: 22.17%），超越所有基线，同时**平均交互轮数最低**（7.84 vs 无记忆 8.93）。
- 在 Spider2-Snow 上，MERIT 实现**正迁移**（Success Rate 69.29% vs 无记忆 66.00%），且平均轮次接近无记忆基线，低于其他记忆基线。
- 消融实验显示：episode 记忆不可或缺（去除后成功率下降最大），turn 记忆和 RL 优化均贡献明显，尤其对 Phase 2 的后续交互。
- PRM 经过 SFT+GRPO 训练后，格式有效性达 100%，与教师标注的平均准确率达 73.59%，MAE 0.29。
- 多水平检索设计有效分离了全局策略与局部执行支持，学习的选择器优于固定相似度检索。

## 7. 优点
- **方法创新**：双水平记忆架构（episode + turn）明确对应不同决策范围，解决单一水平检索的局限。
- **信用分配解决方案**：首次在 turn 级记忆检索中引入 PRM，提供密集的中间奖励，使得 RL 训练成为可能。
- **数据增强策略**：SQL 优先的合成管线保证了可执行性和多样性，且生成的消歧元数据可支撑交互环境。
- **迁移验证**：在 Spider2-Snow 上的正迁移表明学习到的检索策略具有跨任务泛化能力。
- **效率和有效性兼顾**：在提升成功率的同时减少交互轮次，并未引入过多计算开销（选择器轻量，压缩状态签名）。

## 8. 不足与局限
- **PRM 监督信号的局限性**：PRM 训练依赖教师模型（GPT-5）生成的结构化评分，而非真正的中间步效用标签，属于代理信号。教师模型的偏差可能影响下游策略。
- **backbone 单一性**：仅使用 GPT-5 作为主 agent，未评估开源或更弱推理模型（如 Llama、Qwen 系列 agent），结论的泛化性有待验证。
- **计算资源**：虽然声称轻量，但需要训练两个 RL 选择器和一个 PRM，且需要多 GPU 环境（4 个 B200），资源门槛仍较高。
- **正面记忆偏倚**：默认只使用成功轨迹记忆，虽然实验显示优于使用全部记忆，但可能忽略了失败轨迹中的有用警告信息（文中提到可使用警告模式，但未充分探索）。
- **实验覆盖**：未涉及多轮交互中记忆更新（如记忆删除、重写）的消融，仅聚焦检索；未评估在更复杂任务（如跨数据库或长对话）中的表现。
