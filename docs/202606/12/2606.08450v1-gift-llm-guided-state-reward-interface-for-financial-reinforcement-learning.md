## 摘要
金融组合交易自然地被表述为一个强化学习问题，其中智能体在不断变化的市场条件下顺序地重新平衡资产，以平衡收益、风险和交易成本。然而，在非平稳市场中，原始的OHLCV状态和短视的收益奖励往往提供了一个欠指定的学习接口，从而促使大型语言模型作为一种将金融知识注入状态和奖励设计的方式，同时约束开放式生成。为此，我们提出了GIFT，这是一个基于PPO的金融强化学习中的状态-奖励接口设计的LLM引导框架。GIFT不是使用LLM来做出交易决策，而是使用因子引导的状态增强从金融因子原语生成状态特征，使用风险规则引导的奖励塑形从投资组合风险规则生成辅助奖励，以及使用诊断引导的修正利用PPO rollout诊断来修订候选接口。在修正之后，GIFT在评估之前固定选定的状态-奖励接口，测试时不再有LLM查询或接口更新。跨不同市场机制和投资组合场景的全面滚动窗口实验表明，GIFT相较于基线提高了学习信号质量和样本外的风险调整后投资组合性能。代码和数据可在 https://github.com/KAG778/GIFT 获取。

## Abstract
Financial portfolio trading is naturally formulated as a reinforcement learning problem, where an agent sequentially rebalances assets under changing market conditions to balance return, risk, and transaction costs. Yet in non-stationary markets, raw OHLCV states and short-horizon return rewards often provide an under-specified learning interface, motivating large language models as a way to inject financial knowledge into state and reward design while constraining open-ended generation. To this end, we propose GIFT, an LLM-guided framework for state-reward interface design in PPO-based financial reinforcement learning. Rather than using the LLM to make trading decisions, GIFT uses Factor-guided State Enhancement to generate state features from financial-factor primitives, Risk-rule-guided Reward Shaping to generate auxiliary rewards from portfolio-risk rules, and Diagnostic-guided Refinement to revise candidate interfaces using PPO rollout diagnostics. After refinement, GIFT fixes the selected state-reward interface before evaluation, with no further LLM queries or interface updates at test time. Comprehensive rolling-window experiments across diverse market regimes and portfolio scenarios demonstrate that GIFT improves learning-signal quality and out-of-sample risk-adjusted portfolio performance over baselines. Code and data are available at: https://github.com/KAG778/GIFT .

## 1. 核心问题与研究动机

- **背景：** 金融投资组合交易可建模为强化学习（RL）序列决策问题，但实际市场具有非平稳、高噪声特性。
- **问题：** 原始OHLCV状态（开高低收量）仅记录基础价格-量变动，隐含的动量、波动率、下行风险、流动性等金融结构未能显式表达；短期组合回报奖励受市场冲击、交易成本、随机波动影响，难以提供稳定的长期收益-风险信号。这导致RL学习接口（state-reward interface）欠指定，策略需同时从噪声中恢复金融结构和学习交易策略。
- **动机：** 大语言模型（LLM）能注入金融知识，但直接让LLM做交易决策或开放式生成接口可能引入虚假相关、过度交易等风险。因此需要约束LLM生成，使其设计更信息丰富的状态-奖励接口，而非替代RL策略。
- **初步实验证据：** 图1展示了有金融引导的LLM-PPO（Guided LLM-PPO）在训练累积奖励变化、斜率、自相关性、信噪比上均优于无引导的自由形式LLM-PPO和普通PPO，验证了引导设计的必要性。

## 2. 方法论：GIFT框架

- **核心思想：** 将LLM作为受约束的接口设计师，利用金融因子库和风险规则库生成可执行的状态增强函数和奖励塑形逻辑，并通过PPO rollout诊断进行多轮迭代精炼。最终接口在评估前固定，测试阶段不再调用LLM。
- **三个关键组件：**
  - **因子引导状态增强（Factor-guided State Enhancement, FSE）：** 基于金融因子库（动量、波动率、下行风险、流动性、均值回归、趋势强度等20个注册指标+9个构建块函数）由LLM选择、变换、组合生成紧凑因子通道，附加到原始OHLCV状态后形成增强状态。
  - **风险规则引导奖励塑形（Risk-rule-guided Reward Shaping, RRS）：** 基于风险规则库（7条组合级规则：集中度惩罚、分散化奖励、换手率惩罚、回撤惩罚、波动率缩放、制度防御、动量对齐）由LLM选择2-4条规则，并生成内在奖励项，与基础组合回报、回撤惩罚项共同构成塑形奖励。
  - **诊断引导精炼（Diagnostic-guided Refinement, DGR）：** 将每个候选接口训练PPO后，提取状态诊断（因子信息量IC、纯critic归因）、奖励诊断（趋势、稳定性）、组合诊断（收益、回撤、风险调整指标）压缩为反馈记忆，指导下一轮LLM修订。经过M轮迭代后选择最高rollout得分的接口作为最终接口（F*, R*）。
- **算法流程（Algorithm 1简述）：** 初始化反馈记忆H1为空；对每轮m，LLM生成K个候选（状态增强函数+奖励函数+风险规则）；验证可执行性后训练PPO并计算诊断；选择该轮最优候选并更新H；最终跨所有轮选择全局最优接口。
- **离线设计+评估协议：** 只利用每个测试窗口前的历史数据设计接口；评估时固定接口，新初始化PPO在测试窗口前半段适应、后半段评估。无LLM查询或接口更新。

## 3. 实验设计

- **数据和环境：**
  - 市场：美国标普500成分股，数据范围2000年1月–2024年6月（日频）。
  - 测试窗口：6个滚动窗口（2020.12–2023.12），覆盖后疫情复苏牛市（W1）、紧缩前牛市（W2）、紧缩加地缘冲击熊市（W3）、高利率筑底（W4）、银行危机+AI繁荣（W5）、利率冲击后V型复苏（W6）。
  - 组合面板：六个面板，每个含5只股票+现金。具体：Technology（AAPL、MSFT、NVDA、GOOGL、META）、Healthcare（JNJ、LLY、UNH、MRK、PFE）、Energy（XOM、CVX、COP、SLB、EOG）、Industrials（BA、CAT、UNP、LMT、WM）、Light Mix（TSLA、NFLX、AMZN、MSFT、JNJ）、Heavy Mix（TSLA、NVDA、XOM、CAT、JNJ）。
  - 观测：20日OHLCV相关特征；行动：长期多头分配于5股+现金；交易成本：0.1%/单位换手。
- **基线对比：**
  - 主基线：Pure PPO（相同架构、超参、时间分割，仅使用原始状态和短期回报奖励）。
  - 接口变体：固定指标（Fixed Indicators）、固定奖励（Fixed Reward）、固定状态-奖励（Fixed State-Reward）、自由形式LLM（Free-form LLM）。
  - 传统交易基线：SMA、WMA、ATR、Bollinger、Turn-of-the-Month、XGBoost。
  - 其他：A2C迁移实验、强基线（增加历史训练+适应）。
- **评估指标：** 累积收益（Return）、夏普比率（Sharpe）、索提诺比率（Sortino）、最大回撤（MDD）、卡尔玛比率（Calmar）。每窗口比较5个指标，胜出至少4个视为该窗口胜出。另分析有效分散化（Neff）等行为指标。

## 6. 主要结论与发现

- GIFT在36个面板-窗口单元中赢得35个（至少4/5指标胜出），总计180个指标级比较中胜出160个，在熊市窗口（W3、W4）改进尤为明显，主要体现为更低回撤、更高夏普/索提诺/卡尔玛比率。
- 接口变体对比显示GIFT（29/30胜出）优于固定指标（60%）、固定奖励（66.7%）、固定状态-奖励（73.3%）、自由形式LLM（63.3%）。自由形式LLM部分窗口（W2、W6）甚至不如原始PPO，说明无引导的LLM生成可能引入不稳定信号。
- 消融实验：去除DGR导致最大退化（夏普-0.393，卡尔玛-0.513，收益-3.10pp）；去除IC/SHAP诊断导致MDD增大3.59pp；RRS主要影响下行风险指标；FSE贡献较温和。
- GIFT在不同窗口自适应选择不同接口（牛市偏好分散化/多因子，熊市侧重均值回归、风险控制等）。
- 鲁棒性：A2C迁移实验28/30胜出；多种子下72.2%种子级胜出；增强基线（更多PPO历史训练）下28/30胜出；搜索预算（候选数K、轮数M）变化时GIFT仍优于Pure PPO。
- 因此，LLM作为受约束的离线接口设计师能有效提升RL学习信号质量，且固定接口后测试阶段无需LLM干预。

## 7. 优点

1. **创新性：** 首次提出将LLM作为金融RL的状态-奖励接口设计者，而非交易决策者，避免了LLM直接交易带来的风险。
2. **约束设计：** 通过因子库和风险规则库限制LLM搜索空间，生成可执行、可解释、数值稳定的接口，降低了开放式生成的不可控性。
3. **迭代精炼：** DGR利用RL训练中的诊断反馈驱动接口修订，使接口设计基于实际学习效果而非纯先验知识。
4. **评估隔离：** 离线设计+固定接口+测试时无LLM查询，避免了数据泄露和计算开销，评估协议公平严谨。
5. **全面实验：** 涵盖多种市场制度、组合面板、消融、鲁棒性、迁移性分析，证据链充分。

## 8. 不足与局限

1. **数据限制：** 仅使用日频OHLCV历史数据，无法反映真实交易中的流动性不足、执行延迟、市场冲击、税收、时变成本等摩擦。
