## 摘要
经验学习通过将过往交互整合为可复用知识，在增强LLM智能体规划与推理方面取得了有前景的成果。然而，现有方法仍局限于显式文本空间，通过语义相似性检索经验并将其拼接至上下文窗口，导致显著的token开销以及检索与生成相分离的解耦架构。为解决这些局限，我们提出ExpWeaver，一个通过潜在检索增强生成使LLM智能体从经验中学习的框架，无需独立的RAG模块。ExpWeaver利用LLM自身的隐藏状态对经验进行编码，在每个解码步骤直接在潜在空间中检索相关经验，并通过交叉注意力聚合与门控残差机制加以整合。整个流程通过强化学习进行端到端优化，同时支持生成与排序任务。我们在涵盖问答、推理、编码、科学预测与推荐的13项多样化任务上评估ExpWeaver。结果表明，ExpWeaver在13项任务中的12项上达到最先进性能，比最强基线高出6.8%以上；在基于文本的检索方法需要1.5至2倍token的情况下，保持与非检索基线相当的token效率；并展现出卓越的跨域泛化能力，在零样本迁移下比最强基线高出16.32%，在少样本迁移下高出15.21%。ExpWeaver的代码已在https://github.com/ulab-uiuc/ExpWeaver发布。

## Abstract
Experience learning has achieved promising results in enhancing LLM agent planning and reasoning by integrating past interactions as reusable knowledge. However, existing methods remain confined to explicit text space, retrieving experiences via semantic similarity and concatenating them into the context window, leading to substantial token overhead and a decoupled architecture that separates retrieval from generation. To address these limitations, we propose ExpWeaver, a framework that enables LLM agents to learn from experience via latent retrieval-augmented generation, without requiring a separate RAG module. ExpWeaver encodes experiences using the LLM's own hidden states, retrieves relevant experiences directly in latent space at each decoding step, and integrates them through cross-attention aggregation and gated residual mechanisms. The entire pipeline is optimized end-to-end with reinforcement learning, supporting both generative and ranking tasks. We evaluate ExpWeaver on 13 diverse tasks spanning question answering, reasoning, coding, scientific prediction, and recommendation. Results demonstrate that ExpWeaver achieves state-of-the-art performance on 12 out of 13 tasks, outperforming the strongest baseline by over 6.8%; maintains token efficiency comparable to non-retrieval baselines while text-based retrieval methods require 1.5 to 2 times more tokens; and exhibits superior cross-domain generalization, outperforming the strongest baseline by 16.32% under zero-shot transfer and 15.21% under few-shot transfer. Our code for ExpWeaver is released at https://github.com/ulab-uiuc/ExpWeaver.

## 1. 论文的核心问题与整体含义（研究动机和背景）

**核心问题**：现有的大语言模型（LLM）智能体经验学习方法均局限于**显式文本空间**——将过去交互总结为文本摘要，通过语义相似度检索并直接拼接到上下文窗口中。这导致两大瓶颈：①**高 token 开销**（检索到的经验文本占据大量上下文，限制了可检索经验的数量）；②**检索与生成解耦**（需要独立的 RAG 模块，无法端到端联合优化，检索标准固定为语义相似性，而非任务效用）。

**研究意义**：作者提出一种超越文本约束的范式，将经验学习重新定义为**隐空间检索增强生成（Latent RAG）**问题，使经验编码、检索、集成均在 LLM 的隐藏状态空间中完成，从而消除上下文窗口约束、实现可学习的检索标准，并统一检索与生成过程。

## 2. 方法论

### 2.1 核心思想
ExpWeaver 维护一个**经验库**，其中每条轨迹被压缩为文本摘要，并使用**LLM 自身的隐藏状态**（而非独立检索器）将其编码为稠密向量 `z = hθ(s)`。生成时，在**每个解码步骤**，以当前隐藏状态 `ht` 为查询，从经验库中检索 top-K 个经验向量。这些向量通过**交叉注意力聚合**（一个可学习查询 token `u` 对 K 个经验向量做交叉注意力）得到一个聚合经验表示 `et`，再通过**门控残差机制**（包含保留门 `rt` 和输入门 `it`）与原始隐藏状态进行**范数保持的插值**，得到增强后的隐藏状态 `h'`，用于后续的 token 预测或排序得分计算。

### 2.2 关键技术细节
- **经验库**：每条经验存储 `(x, z, y, y*, r, s, z)`，其中 `s` 是 LLM 生成的文本摘要，`z = hθ(s)` 是 LLM 编码该摘要的最终层最后一个 token 的隐藏状态。经验库容量固定，满时淘汰最旧条目。
- **隐空间检索**：`Ct = TopK_{e∈M} sim(ht, ze)`，使用余弦相似度。所有向量 L2 归一化。
- **跨注意力聚合**：`et = LN(CrossAttn(u, Zt, Zt))`，输出再缩放至与 `ht` 相同的范数。
- **门控残差**：`rt = σ(Wr ht)`, `it = σ(Wi ht)`，混合系数 `at = exp(-α·softplus(-λ)⊙rt)`，最终 `h't = at⊙ht + sqrt(1-at^2)⊙(it⊙et)`。初始时 `at` 接近 1（优先保留原隐藏状态）。
- **任务适配**：生成任务直接使用增强后的隐藏状态进行解码；排序任务（如推荐）用一个候选编码与最终隐藏状态计算余弦相似度作为得分。
- **训练**：使用 GRPO（Group Relative Policy Optimization），组大小 G=4，KL 系数 β=0.005。额外参数 ψexp = {u, Wr, Wi, λ} 与 LoRA 参数一起通过策略梯度优化。

### 2.3 算法流程（文字说明）
1. 初始化空经验库。
2. 对每个 mini-batch 中的每个 query，采样 G 个回答（若经验库大小小于阈值则冷启动，否则使用带隐空间检索的生成）。
3. 计算每条回答的奖励（生成任务用精确匹配/pass@1，排序任务用 1/排名位置）。
4. 将每条轨迹总结为文本并编码，加入经验库。
5. 计算组内优势值，构造 GRPO 损失（包含 KL 散度正则项）。
6. 更新 LLM 参数（LoRA）和经验模块参数。

- **创新性**：首次将经验学习完全转移到 LLM 隐空间，避免了文本拼接的开销和解耦问题，是 RAG 范式在智能体学习领域的创造性应用。

- **泛化**：跨域实验证明了隐空间表示比文本表示更具有迁移性。
