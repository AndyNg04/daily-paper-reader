## 摘要
检索增强生成（RAG）在将大型语言模型（LLMs）与外部知识结合方面显示出强大的有效性。然而，现有的RAG和图RAG框架大多将知识视为静态，或将时间与粗粒度的时间戳或元数据关联，未能捕捉丰富的时间结构，如持续时间、重叠和包含关系。我们提出IA-RAG，一个分层的时间RAG框架，将知识建模为时间区间，并在形式化时间约束下进行检索。IA-RAG将事实表示为区间事件单元（IEUs），并将其组织成层次化的主题森林，其中时间依赖关系由Allen的区间代数管理。为了处理不完整或不确定的时间边界，IA-RAG进一步引入子图时间收紧机制，通过连接事件子图中的逻辑约束来细化模糊区间。此外，IA-RAG通过区间代数引导的遍历支持隐式时间语义检索。在多个时间问答基准（包括TimeQA、TempReason和ComplexTR）上的实验表明，IA-RAG在时间检索和推理任务上取得了强劲性能，特别是在复杂组合时间推理任务上。我们的代码已在https://github.com/xiaoAugenstern/LogicalRAG_TemporalQA发布。

## Abstract
Retrieval-Augmented Generation (RAG) has shown strong effectiveness in grounding Large Language Models (LLMs) with external knowledge. However, existing RAG and Graph RAG frameworks largely treat knowledge as static or associate time with coarse-grained timestamps or metadata, failing to capture rich temporal structures such as duration, overlap, and containment. We propose IA-RAG, a hierarchical temporal RAG framework that models knowledge as time intervals and performs retrieval under formal temporal constraints. IA-RAG represents facts as Interval Event Units (IEUs) and organizes them into a hierarchical Thematic Forest, where temporal dependencies are governed by Allen's Interval Algebra. To handle incomplete or uncertain temporal boundaries, IA-RAG further introduces a Sub-graph Time Tightening mechanism that refines fuzzy intervals through logical constraints within connected event subgraphs. In addition, IA-RAG supports implicit temporal semantic retrieval through interval-algebra-guided traversal. Experiments on multiple temporal question answering benchmarks, including TimeQA, TempReason, and ComplexTR, demonstrate that IA-RAG achieves strong temporal retrieval and reasoning performance, particularly on complex compositional temporal reasoning tasks. Our code is released at https://github.com/xiaoAugenstern/LogicalRAG_TemporalQA.

#### 2. 方法论：核心思想、关键技术细节、算法流程
- **核心思想**：用 **Interval Event Unit (IEU)** 表示事实，每个 IEU 包含描述文本、上下文、时间区间 [t_start, t_end]、模糊标志（fuzzy flag）和来源文档。利用 Allen 区间代数的 13 种基本关系（如 before、overlaps、during 等）在相邻 IEU 之间建立时间边，构建**区间感知事件图**。
- **关键技术细节**：
  - **Interval Event Unit (IEU) 提取**：将文档切分为重叠块，提取事件句子并规范化时间区间；模糊表达式（如“early 1990s”）被标记为 fuzzy=1 并映射为粗粒度区间；通过语义相似度进行去重。
  - **Sub-graph Time Tightening（子图时间收紧）**：对于 fuzzy=1 的 IEU，利用其所在连通分量中其他 IEU 的显式 Allen 关系，通过 LLM 推理得到更精确的时间边界（τ*），若证据足够则更新 fuzzy=0。
  - **Macro Event Unit (MEU) 与层次化主题森林**：将连通分量中的 IEU 聚合为更高层次的 MEU，并递归构造多层图结构（最多 4 层），形成**主题森林**，实现从细粒度到主题级的组织。
  - **IA-Guided Traversal（区间代数引导遍历）**：对于查询 q，首先提取其时间窗口 Tw；随后通过语义相似度检索 top-K1 MEU 和 top-K2 IEU，并根据检索单元时间区间 Ti 与 Tw 的相对位置（Ti 整体在 Tw 之前/之后/之内）动态选择前向/后向/双向的 Allen 关系集合进行遍历，获取补充证据。最终合并所有相关单元作为生成答案的背景。
- **算法流程**（文字说明）：
  1. 对语料库进行分块，提取 IEU（含时间区间和模糊标志）。
  2. 对 IEU 进行语义去重；在语义相似的 IEU 对间根据时间区间计算 Allen 关系，构建 0 层图。
  3. 对 fuzzy=1 的 IEU，在其所在连通分量内进行时间收紧，更新区间。
  4. 将连通分量聚合为 MEU，并递归构建更高层图（最多 4 层），形成主题森林。
  5. 查询时，先使用 LLM 解析查询的时间窗口 Tw；然后语义检索 top-K MEU 和 IEU；对每个检索单元，根据其时间与 Tw 的相对位置，按照 Allen 关系定向遍历邻居；合并所有结果作为检索证据。
  6. 将检索结果输入 LLM 生成最终答案。
