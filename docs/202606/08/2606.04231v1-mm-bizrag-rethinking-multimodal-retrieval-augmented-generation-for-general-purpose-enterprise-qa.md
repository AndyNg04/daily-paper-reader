## 摘要
近期多模态检索增强生成（MM-RAG）的进展趋向于最小化解析，依赖页面级图像来生成检索器嵌入并用于答案生成。虽然高效，但这种趋势往往忽略了复杂企业文档中丰富、结构化信息的显式处理，而是依赖预训练嵌入或视觉语言模型隐式地捕捉此类结构。在本工作中，我们采用了一种更直接的方法：MM-BizRAG 通过一种文档结构感知的分割方法主动提取和表示文档结构，该方法将文档动态路由到面向方向的摄取流水线中，对垂直结构化文档（如报告）应用显式的布局感知解析，对水平结构化文档（如幻灯片）应用整体页面级表示。一个统一的 LLM 驱动的工件转换流水线，结合基于占位符的位置对齐，保留了自然的阅读顺序，而推理时的多模态组装将检索表示与生成上下文解耦，从而在无需微调的情况下实现更丰富、更有依据的答案。通过在大型异构企业数据集和两个公开基准（SlideVQA 和 FinRAGBench-V）上的实验，MM-BizRAG 持续优于最先进的以视觉为中心的基线方法，最高提升 32 个百分点，尤其在报告式布局上表现突出。此外，我们引入了 FastRAGEval，一种单次调用的 LLM 评估指标，用于细粒度的生成召回，其成本仅为 RAGChecker 的一半，同时实现了更强的人类对齐。

## Abstract
Recent advances in multimodal retrieval-augmented generation (MM-RAG) have shifted toward minimal parsing, relying on page-level images for producing retriever embeddings and for answer generation. While efficient, this trend often neglects explicit handling of the rich, structured information in complex enterprise documents, instead depending on pre-trained embeddings or vision-language models to implicitly capture such structure. In this work, we take a more direct approach: MM-BizRAG proactively extracts and represents document structure via a document structure-aware split that dynamically routes documents through orientation-specific ingestion pipelines, applying explicit layout-aware parsing for vertically structured documents (e.g., reports) and holistic page-level representations for horizontally structured documents (e.g., slide decks). A unified LLM-driven artifact transformation pipeline with placeholder-based positional alignment preserves natural reading order, while inference-time multimodal assembly decouples retrieval representations from generation context, enabling richer, more grounded answers without any finetuning requirement. Through experiments on a large, heterogeneous enterprise dataset and two public benchmarks (SlideVQA and FinRAGBench-V), MM-BizRAG consistently outperforms state-of-the-art vision-centric baselines by up to 32% points, with especially strong gains on report-style layouts. Furthermore, we introduce FastRAGEval, a single-call LLM Judge metric for fine-grained generative recall that halves RAGChecker's cost while achieving stronger human alignment.

- **研究动机**：现有主流多模态检索增强生成（MM-RAG）方法普遍采用“最小解析”策略，直接依赖页面级图像生成检索嵌入和答案，通过预训练的视觉语言模型（VLM）或嵌入模型隐式捕捉文档结构。然而，复杂的企业文档（如财务报告、法律文件、技术文档）包含丰富的结构化信息（表格、图表、跨页引用等），这种隐式处理方式在训练数据之外的领域表现不佳，导致检索和生成质量受限。
- **核心问题**：如何显式地提取和利用企业文档的结构化信息，以实现更准确、更可信的多模态问答，同时避免微调。
- **整体含义**：MM-BizRAG 重新强调了显式文档结构理解和布局感知解析在多模态 RAG 中的价值，为处理异构企业文档提供了一种无需微调、可直接部署的系统级方案，并在此基础上提出了更高效的评估指标 FastRAGEval。

### 2. 论文提出的方法论

- **核心思想**：基于文档结构感知的“分割与定向处理”思路，将文档分为纵向（报告、PDF）和横向（幻灯片）两类，分别采用不同的摄取与表示策略，并在推理时解耦检索表示与生成上下文，从而在不膨胀索引的前提下构建更丰富的上下文。
- **关键技术细节**：
  - **文档结构感知分割**：使用 LLM 分类器（或文件元数据）将文档分为 `V`（纵向）和 `H`（横向）两类。
  - **纵向文档（V）处理**：
    - 使用布局解析工具（Docling）提取文本块、表格和图片，保留阅读顺序。
    - 在文本中插入占位符（`<picture_i>`、`<table_i>`）定位表格和图片位置。
    - 对每个表格生成 Markdown 和行级描述；对每张图片生成描述并过滤无用内容（如 logo）。
    - 保留页面图像。
  - **横向文档（H）处理**：
    - 不对页面进行细粒度布局解析，而是将整个页面视为语义单元，使用 VLM 生成详细文本描述（涵盖所有文字、视觉元素及其关系），同时保留页面图像。
  - **三种变体（TCTE、PCMHE、TCMIE）**：
    - **TCTE（Token级分块 + 文本嵌入）**：对纵向文本进行 token 级切分，表格/图片描述作为独立块；对横向每页描述作为独立块；使用文本嵌入（text-embedding-3-large）和混合稀疏-稠密检索。
    - **PCMHE（页面级分块 + 多模态嵌入）**：每页同时生成文本块（布局解析文本或 LLM 描述）和图像块，均使用多模态嵌入（Nomic / Cohere），独立检索后融合排序。
    - **TCMIE（Token级分块 + 多模态交错嵌入）**：将表格 Markdown 与描述、图片与描述直接嵌入到文本块的占位符位置，形成统一的单块多模态单元；使用多模态嵌入检索。
  - **推理时多模态组装**：检索到的块在生成前被重新组装：纵向文档中，根据占位符将表格图片的 artifact 注入对应文本块；横向文档中，将页面描述与页面图像拼接。此过程不依赖微调。
  - **FastRAGEval 评估指标**：单次 LLM 调用，同时抽取参考答案和生成答案的原子事实，计算精确率、召回率和 F1，替代传统两阶段 RAGChecker，成本减半且与人类判断一致性更高。

- MM-BizRAG 在所有数据集上显著优于 vision-centric 基线，在垂直结构文档（FinRAGBench-V）上提升高达 32 个百分点；在幻灯片文档（SlideVQA）上也持续领先。

### 7. 优点

- **结构感知的分割设计**：首次在 MM-RAG 中显式区分纵向与横向文档，并针对性设计处理管线，避免“一刀切”。
- **无需微调**：全部使用预训练模型和 LLM API，易于在新的企业场景快速部署。
- **推理时多模态组装**：解耦检索表示与生成上下文，允许生成时动态引入图像、Markdown 等 artifact，不增加索引负担。
- **FastRAGEval 指标**：高效（单次调用）、与人类判断对齐度更高，有潜力成为替代 RAGChecker 的标准。
- **系统级评估**：不仅报总体指标，还按模态、文档类型分解，并比较不同变体的延迟-性能折中，具有工程实用性。
- **充分的消融与变体研究**：控制了摄取和嵌入策略的差异，揭示了不同设计选择的优劣。
